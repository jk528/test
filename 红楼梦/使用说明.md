# SplitTxtByChapter —— 按章节拆分TXT的VBA工具

## 一、功能说明

将以「第N章/第N回/第N节/第N卷 标题」作为章节起点的中文长文本，按章节拆分为多个独立 `.txt` 文件。

| 项目 | 说明 |
|------|------|
| 输入 | 单个TXT文本文件（UTF-8，含/不含BOM均可） |
| 输出 | 每章一个文件，命名 `[序号]-[标题].txt` |
| 编码 | 输入/输出均为 UTF-8（输出无BOM，与源文件一致） |
| 适配验证 | 红楼梦.txt（2.57MB / 120章 / 3367行，识别与切片零误差） |

## 二、文件清单

| 文件 | 说明 |
|------|------|
| `SplitTxtByChapter.bas` | VBA模块：每章拆为一个文件（命名规则与Python一致） |
| `SplitTxtByGroups.bas` | VBA模块：按聚合格式多章合并拆分（功能与 split_by_groups.py 一致） |
| `split_honglou_to_west_style.py` | Python脚本：每章拆为一个文件（命名规则与VBA一致） |
| `split_by_groups.py` | Python脚本：按聚合格式 `长度,间距\|长度,间距` 多章合并拆分 |
| `使用说明.md` | 本说明文档 |

## 三、运行方式

### 方式A：一键拆分红楼梦（默认）

1. 打开 WPS 文字 / Excel，按 `Alt + F11` 进入 VBA 编辑器
2. 在左侧工程窗口右键 → **导入文件** → 选择 `SplitTxtByChapter.bas`
3. 按 `Ctrl + G` 打开立即窗口（或在视图菜单打开）
4. 在立即窗口输入并回车：
   ```vba
   拆分红楼梦
   ```
5. 弹出预览对话框 → 确认后即开始拆分
6. 完成后输出到：`红楼梦\红楼梦_拆分\`

### 方式B：通用拆分（自定义参数）

在立即窗口调用 `SplitTxtByChapter`，传入参数：

```vba
' 拆分红楼梦.txt，默认参数（输出到 源目录\红楼梦_拆分\）
SplitTxtByChapter "C:\...\红楼梦.txt"

' 拆分红楼梦.txt，输出到指定目录，文件名前缀"HL"，序号3位
SplitTxtByChapter "C:\...\红楼梦.txt", "D:\out", "HL", 3
' 生成：HL_001-甄士隐梦幻识通灵 贾雨村风尘怀闺秀.txt ...

' 拆分其他小说（如"第N回"格式的三国演义）
SplitTxtByChapter "D:\三国演义.txt", "", "", 3
```

### 方式C：作为按钮宏

在VBA编辑器中导入模块后，可在WPS文档中通过「开发工具 → 宏」选择 `拆分红楼梦`、`选择文件拆分` 或 `SplitTxtByChapter` 运行。

### 方式D：通过文件选择窗体拆分（无需硬编码地址）

无需预先知道文件路径，运行后弹出文件选择对话框，选中任意 TXT 即可拆分。适合临时拆分不同来源的文本文件，最灵活通用。

1. 在立即窗口输入并回车：
   ```vba
   选择文件拆分
   ```
2. 弹出「选择要拆分的TXT文件」对话框（默认筛选 `*.txt`）→ 选中目标文件 → 打开
3. 弹出预览对话框 → 确认后即开始拆分
4. 输出目录默认为：所选文件所在目录\<文件名>_拆分\

> 该方式使用 `Application.FileDialog(msoFileDialogFilePicker)`，兼容 WPS文字 / WPS表格 / Excel。若当前环境不支持文件对话框，会提示改用 `拆分红楼梦` 或 `SplitTxtByChapter` 传入路径。

### 方式E：VBA聚合分组拆分（SplitTxtByGroups.bas）

将多章合并为一份（如1-40章一份、41-80章一份），需导入 `SplitTxtByGroups.bas` 模块。三个入口：

1. **聚合拆分红楼梦**（一键，默认 `3,40`）：
   ```vba
   聚合拆分红楼梦
   ```
2. **选择文件聚合拆分**（窗体选文件，灵活）：
   ```vba
   选择文件聚合拆分
   ```
3. **SplitTxtByGroups**（传参，可自定义聚合格式）：
   ```vba
   SplitTxtByGroups InputPath:="D:\三国.txt", ChunkStr:="2,60", SerialWidth:=3
   ```

**聚合格式**（与 Python `split_by_groups.py` 一致，详见第十一节）：
- `3,40` → 3个文件每个40章
- `40` → 每40章一份（便捷模式，等价于 `3,40`）
- `1,20|1,20|1,80` → 3份（1-20、21-40、41-120）
- 不足总章数时余数自动追加1个文件

输出命名 `[前缀_]<序号补零>_第<起>-<止><单位>.txt`（如 `001_第1-40章.txt`），序号位数自适应（突破999/9999章自动扩展）。写入前弹预览对话框确认。

## 四、参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `InputPath` | String | 是 | — | 源TXT完整路径 |
| `OutputDir` | String | 否 | `""` | 输出目录；空串 = 源目录下 `<源文件名>_拆分\` |
| `FileNamePrefix` | String | 否 | `""` | 文件名前缀；空串 = 仅 `序号-标题.txt` |
| `SerialWidth` | Long | 否 | `3` | 序号位数；3 → 001/002/.../120；章节数超容量时自动扩展（见下） |

## 五、章节识别规则

正则：`^第([0-9一二三四五六七八九十百千万零两]+)(章|回|节|卷)(\s*)(.*)$`（中文数字含"万"，支持大章节号）

| 支持的标题格式 | 示例 |
|------|------|
| 阿拉伯数字+章 | `第1章 甄士隐梦幻识通灵 贾雨村风尘怀闺秀` ✓ |
| 中文数字+章 | `第一章 序章` ✓ |
| 回/节/卷 | `第五回 满江红` / `第三节 引子` ✓ |
| 零/两 | `第零章 楔子` / `第二回` ✓ |
| 万级大章节 | `第一万章` / `第十万章` / `第10000章` ✓ |

> 标题行必须独占一行、位于行首。行内出现的「第N章」字样不会误判（如正文 "看官听说第3章里..."）。

## 六、文件名清洗规则

标题中以下字符将被替换为空格：`\ / : * ? " < > |`

- 连续空格折叠为单个空格
- 标题长度限制 60 字符（防止路径过长）
- 标题为空时退化为 `第N章`

## 八、工程约定与边界处理

本项目遵循以下工程约定（来自项目记忆）：

- ✅ 所有 `Dim` 语句声明在过程顶部（WPS VBA 严格性要求，循环内重复Dim会报"重定义"编译错误）
- ✅ 字符串拼接使用 `数组 + Join`，避免循环内反复 `&` 拼接
- ✅ UTF-8 读写使用 `ADODB.Stream`（VB内置 `Open/Print` 默认GBK会乱码）
- ✅ 写入前显示预览并经用户确认（避免误操作）
- ✅ 显示计时与处理速率（性能可量化）
- ✅ 单一职责：拆分、识别、清洗、I/O 分别封装为独立函数

## 九、常见问题

### Q1：运行报错"未识别到任何章节标题"
检查源文件首行是否为 `第N章 标题` 格式。如有自定义格式（如 `Chapter 1`），需调整 `reg.Pattern`。

### Q2：导入 .bas 报错"同名模块已存在"
VBA 编辑器中右键旧模块 → 移除 → 重新导入；或先在编辑器中删除同名模块。

### Q3：输出文件中文乱码
确认源文件为 UTF-8。如源文件为 GBK，需将 `ReadTextUTF8` 中 `stm.Charset = "utf-8"` 改为 `"gbk"`。

### Q4：路径含中文导致找不到文件
WPS VBA 对中文路径支持良好。如遇问题，将 `红楼梦` 目录改名为英文，或使用 `Shell` 调用。

### Q5：能否去除每章末尾的 `(本章完)` 标记？
当前实现保留原样。如需去除，在切片后对 `body` 做替换：
```vba
body = Replace(body, vbCrLf & "(本章完)" & vbCrLf, vbCrLf)
```

## 十一、按章节聚合分组拆分（split_by_groups.py）

`split_by_groups.py` 参照 `READ_聚合生成折线堆叠图.bas` 的输入字符串逻辑，支持将连续多章按自定义规则聚合合并为文件，可随意组合章节范围。

### 聚合格式

```
长度,间距|长度,间距|...
```

| 字段 | 含义 |
|------|------|
| `长度` | 该段生成多少个**文件** |
| `间距` | 每个文件包含多少**章** |
| `段消耗` | `长度 × 间距`，各段累计须 ≤ 总章数 |
| 余数 | 累计 < 总章数时，剩余章节自动追加1个文件 |

便捷模式：纯数字 `N` 表示"每N章一份"，份数 = `ceil(总章数 / N)`，末份可能不足。

> 与VBA/旧脚本区别：`split_by_groups.py` 的 `长度,间距` 顺序为 **(文件数, 每文件章数)**；`3,40` 表示3个文件、每个40章。

### 参数说明

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `--src` | 否 | 红楼梦.txt | 源TXT路径 |
| `--out` | 否 | 红楼梦_分组 | 输出目录 |
| `--chunk` | 否 | `3,40` | 聚合格式 `长度,间距\|...` 或便捷 `N` |
| `--prefix` | 否 | 空 | 文件名前缀 |
| `--serial-width` | 否 | `3` | 序号位数（3 → 001/002/...；文件数超容量时自动扩展） |

### 用法示例

```bash
python split_by_groups.py --chunk 3,40                 # 3份各40章: 1-40/41-80/81-120
python split_by_groups.py --chunk 40                   # 便捷模式，同上
python split_by_groups.py --chunk 1,20|1,20|1,80        # 1-20/21-40/41-120
python split_by_groups.py --chunk 2,30|1,60            # 1-30/31-60/61-120
python split_by_groups.py --chunk 1,40                 # 1-40/41-120（余数自动补齐）
python split_by_groups.py --chunk 20,1|50,2            # 前20章每章一文件，后100章每2章一文件
python split_by_groups.py --src D:\三国.txt --chunk 2,60 --prefix SG  # 通用拆分
```

### 聚合组合示例（红楼梦120章）

| 聚合格式 | 份数 | 各份范围 | 说明 |
|---------|------|---------|------|
| `3,40` | 3 | 1-40 / 41-80 / 81-120 | 标准均分 |
| `40` | 3 | 同上 | 便捷模式 |
| `1,20\|1,20\|1,80` | 3 | 1-20 / 21-40 / 41-120 | 多段组合 |
| `2,30\|1,60` | 3 | 1-30 / 31-60 / 61-120 | 多段组合 |
| `1,40` | 2 | 1-40 / 41-120 | 余数自动补齐 |
| `20,1\|50,2` | 70 | 前20章每章一文件，后100章每2章一文件 | 细粗混合 |
| `10,10\|5,4` | 15 | 前100章每10章，后20章每4章 | 多段不同间距 |
| `4,30` | 4 | 1-30 / 31-60 / 61-90 / 91-120 | 均分4份 |

### 输出命名与编码

- 命名：`[前缀_]<序号补零>_第<起>-<止><单位>.txt`（如 `001_第1-40章.txt`，单章时为 `001_第5章.txt`；序号位数由 `--serial-width` 控制，**文件数超过当前位数容量时自动扩展**：1000+ 份→4 位、10000+ 份→5 位，保证排序正确）
- 单位（章/回/节/卷）自动从源文件首个章节标题识别
- 编码 UTF-8 无 BOM，正文保持源文件原样
