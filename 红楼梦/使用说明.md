# SplitTxtByChapter —— 按章节拆分TXT的VBA工具

## 一、功能说明

将以「第N章/第N回/第N节/第N卷 标题」作为章节起点的中文长文本，按章节拆分为多个独立 `.txt` 文件。

| 项目 | 说明 |
|------|------|
| 输入 | 单个TXT文本文件（自动检测编码：ANSI/UTF-8/UTF-16，含/不含BOM均可） |
| 输出 | 每章一个文件，命名 `[序号]-[标题].txt` |
| 编码 | 输入自动检测（由 ReadTxtUniversal.bas 实现）；输出 UTF-8 无BOM |
| 适配验证 | 红楼梦.txt（2.57MB / 120章 / 3367行，识别与切片零误差） |

## 二、文件清单

| 文件 | 说明 |
|------|------|
| `SplitTxtByChapter.bas` | VBA模块：每章拆为一个文件（命名规则与Python一致） |
| `SplitTxtByGroups.bas` | VBA模块：按聚合格式多章合并拆分（功能与 split_by_groups.py 一致） |
| `ReadTxtUniversal.bas` | VBA模块：通用TXT读写，自动检测编码（ANSI/UTF-8/UTF-16） |
| `split_honglou_to_west_style.py` | Python脚本：每章拆为一个文件（命名规则与VBA一致） |
| `split_by_groups.py` | Python脚本：按聚合格式 `每份章数,份数\|每份章数,份数` 多章合并拆分 |
| `readtxt_universal.py` | Python模块：通用TXT读写，自动检测编码（与 ReadTxtUniversal.bas 对齐） |
| `使用说明.md` | 本说明文档 |

> **导入/运行顺序**：
> - VBA: 先导入 `ReadTxtUniversal.bas`，再导入 `SplitTxtByChapter.bas` / `SplitTxtByGroups.bas`
> - Python: `split_by_groups.py` 和 `split_honglou_to_west_style.py` 自动 import `readtxt_universal.py`，需在同一目录

## 三、运行方式

### 方式A：每章一文件（SplitTxtByChapter.bas）

1. 打开 WPS 文字 / Excel，按 `Alt + F11` 进入 VBA 编辑器
2. 在左侧工程窗口右键 → **导入文件** → 选择 `SplitTxtByChapter.bas`
3. 按 `Ctrl + G` 打开立即窗口（或在视图菜单打开）
4. 在立即窗口输入并回车：
   ```vba
   拆分
   ```
5. 弹出文件选择对话框 → 选中 TXT 文件
6. 弹出预览对话框 → 确认后即开始拆分
7. 输出目录默认为：所选文件所在目录\<文件名>_拆分\

### 方式B：通用拆分（自定义参数）

在立即窗口调用 `SplitTxtByChapter`，传入参数：

```vba
' 拆分指定TXT，默认参数（输出到 源目录\<文件名>_拆分\）
SplitTxtByChapter "D:\三国演义.txt"

' 输出到指定目录，文件名前缀"HL"，序号3位
SplitTxtByChapter "D:\三国演义.txt", "D:\out", "HL", 3
' 生成：HL_001-...txt ...
```

### 方式C：作为按钮宏

在VBA编辑器中导入模块后，可在WPS文档中通过「开发工具 → 宏」选择 `拆分` 或 `SplitTxtByChapter` 运行。

### 方式D：VBA聚合分组拆分（SplitTxtByGroups.bas）

将多章合并为一份（如1-40章一份、41-80章一份），需导入 `SplitTxtByGroups.bas` 模块。单一入口，三步完成：

1. 在立即窗口输入并回车：
   ```vba
   聚合拆分
   ```
2. 弹出文件选择对话框 → 选中 TXT 文件
3. 弹出 InputBox 输入聚合格式（预填 `40,3`，支持 `|` 多段）→ 确认
4. 预览分组清单 → 确认后清理旧文件并写入

也可直接调用核心过程传参：
```vba
SplitTxtByGroups InputPath:="D:\三国.txt", ChunkStr:="60,2", SerialWidth:=3
```

**聚合格式**（与 Python `split_by_groups.py` 一致，详见第十一节）：

格式为 `每份章数,份数`，以 `|` 分割多段：

| 输入 | 含义 | 结果（120章） |
|------|------|--------------|
| `40,3` | 每份40章，共3份 | 1-40 / 41-80 / 81-120 |
| `40,2` | 每份40章，共2份（余数自动补齐） | 同上，实际3份 |
| `40` | 便捷模式：每40章一份 | 同上 |
| `20,1\|20,1\|80,1` | 多段：1×20章 + 1×20章 + 1×80章 | 1-20 / 21-40 / 41-120 |

输出命名 `[前缀_]<序号补零>_第<起>-<止><单位>.txt`（如 `001_第1-40章.txt`），序号位数自适应（突破999/9999章自动扩展）。写入前弹预览对话框确认并清理旧文件。

## 四、参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `InputPath` | String | 是 | — | 源TXT完整路径 |
| `OutputDir` | String | 否 | `""` | 输出目录；空串 = 源目录下 `<源文件名>_拆分\` |
| `FileNamePrefix` | String | 否 | `""` | 文件名前缀；空串 = 仅 `序号-标题.txt` |
| `SerialWidth` | Long | 否 | `3` | 序号位数；3 → 001/002/.../120；章节数超容量时自动扩展（见下） |

## 五、章节识别规则

正则：`^第([0-9一二三四五六七八九十百千万零两]+)(章|回|节|卷)(\s*)(.*)$`（中文数字含"万"，支持大章节号）

| 支持的标题格式 | 示例 |
|------|------|
| 阿拉伯数字+章 | `第1章 甄士隐梦幻识通灵 贾雨村风尘怀闺秀` ✓ |
| 中文数字+章 | `第一章 序章` ✓ |
| 回/节/卷 | `第五回 满江红` / `第三节 引子` ✓ |
| 零/两 | `第零章 楔子` / `第二回` ✓ |
| 万级大章节 | `第一万章` / `第十万章` / `第10000章` ✓ |

> 标题行必须独占一行、位于行首。行内出现的「第N章」字样不会误判（如正文 "看官听说第3章里..."）。

## 六、文件名清洗规则

标题中以下字符将被替换为空格：`\ / : * ? " < > |`

- 连续空格折叠为单个空格
- 标题长度限制 60 字符（防止路径过长）
- 标题为空时退化为 `第N章`

## 八、工程约定与边界处理

本项目遵循以下工程约定（来自项目记忆）：

- ✅ 所有 `Dim` 语句声明在过程顶部（WPS VBA 严格性要求，循环内重复Dim会报"重定义"编译错误）
- ✅ 字符串拼接使用 `数组 + Join`，避免循环内反复 `&` 拼接
- ✅ 编码读写统一由 `ReadTxtUniversal.bas` 提供（自动检测 ANSI/UTF-8/UTF-16，无需手动指定）
- ✅ 写入前显示预览并经用户确认（避免误操作）
- ✅ 显示计时与处理速率（性能可量化）
- ✅ 单一职责：拆分、识别、清洗、I/O 分别封装为独立函数

## 九、常见问题

### Q1：运行报错"未识别到任何章节标题"
检查源文件首行是否为 `第N章 标题` 格式。如有自定义格式（如 `Chapter 1`），需调整 `reg.Pattern`。

### Q2：导入 .bas 报错"同名模块已存在"
VBA 编辑器中右键旧模块 → 移除 → 重新导入；或先在编辑器中删除同名模块。

### Q3：输出文件中文乱码
源文件编码自动检测由 `ReadTxtUniversal.bas` 处理，支持 ANSI(GBK)/UTF-8/UTF-16。如仍乱码，可在立即窗口单独检测编码：
```vba
Debug.Print DetectEncodingFile("D:\红楼梦.txt")   ' 返回 ANSI / UTF-8 / UTF-8 BOM / UTF-16LE / UTF-16BE
```

### Q4：路径含中文导致找不到文件
WPS VBA 对中文路径支持良好。如遇问题，将 `红楼梦` 目录改名为英文，或使用 `Shell` 调用。

### Q5：能否去除每章末尾的 `(本章完)` 标记？
当前实现保留原样。如需去除，在切片后对 `body` 做替换：
```vba
body = Replace(body, vbCrLf & "(本章完)" & vbCrLf, vbCrLf)
```

## 十、编码自动检测（ReadTxtUniversal.bas）

`ReadTxtUniversal.bas` 是通用 TXT 读写模块，提供编码自动检测和多编码读取能力。`SplitTxtByChapter.bas` 和 `SplitTxtByGroups.bas` 均依赖此模块。

### 支持的编码

| 编码 | 检测方式 | 读取方式 |
|------|---------|---------|
| UTF-8 BOM | BOM: `EF BB BF` | ADODB.Stream (Charset=utf-8) |
| UTF-8 无BOM | 字节模式扫描（多字节序列匹配） | ADODB.Stream (Charset=utf-8) |
| UTF-16LE | BOM: `FF FE` | FileSystemObject (TristateTrue) |
| UTF-16BE | BOM: `FE FF` | FileSystemObject (TristateTrue) |
| ANSI (GBK) | 无BOM且非UTF-8字节模式 | 原生 Open + Line Input |

### 对外接口

| 函数 | 类型 | 说明 |
|------|------|------|
| `ReadTextAuto(filePath)` | Function | 自动检测编码并读取全文 |
| `DetectEncodingFile(filePath)` | Function | 返回编码名称字符串 |
| `WriteTextUTF8NoBOM(path, text)` | Sub | 写入 UTF-8 无 BOM |
| `WriteTextANSI(path, text)` | Sub | 写入 ANSI (GBK) |
| `WriteTextUTF8BOM(path, text)` | Sub | 写入 UTF-8 含 BOM |

### 独立使用

```vba
' 在立即窗口检测文件编码
Debug.Print DetectEncodingFile("D:\红楼梦.txt")

' 独立读取任意编码的TXT
Dim content As String
content = ReadTextAuto("D:\gbk编码的小说.txt")
```

## 十一、按章节聚合分组拆分（split_by_groups.py）

`split_by_groups.py` 参照 `READ_聚合生成折线堆叠图.bas` 的输入字符串逻辑，支持将连续多章按自定义规则聚合合并为文件，可随意组合章节范围。

### 聚合格式

```
每份章数,份数|每份章数,份数|...
```

| 字段 | 含义 |
|------|------|
| `每份章数` | 每个文件包含多少**章** |
| `份数` | 该段生成多少个**文件** |
| `段消耗` | `每份章数 × 份数`，各段累计须 ≤ 总章数 |
| 余数 | 累计 < 总章数时，剩余章节自动追加1个文件 |

便捷模式：纯数字 `N` 表示"每N章一份"，份数 = `ceil(总章数 / N)`，末份可能不足。

### 参数说明

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `--src` | **是** | — | 源TXT路径 |
| `--out` | 否 | 空 | 输出目录；空 = 源目录下 `<文件名>_分组` |
| `--chunk` | 否 | `40,3` | 聚合格式 `每份章数,份数\|...` 或便捷 `N` |
| `--prefix` | 否 | 空 | 文件名前缀 |
| `--serial-width` | 否 | `3` | 序号位数（3 → 001/002/...；文件数超容量时自动扩展） |

### 用法示例

```bash
python split_by_groups.py --src 红楼梦.txt                          # 默认40,3: 1-40/41-80/81-120
python split_by_groups.py --src 红楼梦.txt --chunk 40              # 便捷模式，同上
python split_by_groups.py --src 红楼梦.txt --chunk 20,1|20,1|80,1  # 1-20/21-40/41-120
python split_by_groups.py --src 红楼梦.txt --chunk 30,2|60,1       # 1-30/31-60/61-120
python split_by_groups.py --src 红楼梦.txt --chunk 40,1            # 1-40/41-120（余数自动补齐）
python split_by_groups.py --src 红楼梦.txt --chunk 1,20|2,50       # 前20章每章一文件，后100章每2章一文件
python split_by_groups.py --src D:\三国.txt --chunk 60,2 --prefix SG  # 通用拆分
```

### 聚合组合示例（红楼梦120章）

| 聚合格式 | 份数 | 各份范围 | 说明 |
|---------|------|---------|------|
| `40,3` | 3 | 1-40 / 41-80 / 81-120 | 标准均分 |
| `40,2` | 3 | 同上 | 余数自动补齐 |
| `40` | 3 | 同上 | 便捷模式 |
| `20,1\|20,1\|80,1` | 3 | 1-20 / 21-40 / 41-120 | 多段组合 |
| `30,2\|60,1` | 3 | 1-30 / 31-60 / 61-120 | 多段组合 |
| `40,1` | 2 | 1-40 / 41-120 | 余数自动补齐 |
| `1,20\|2,50` | 70 | 前20章每章一文件，后100章每2章一文件 | 细粗混合 |
| `10,10\|4,5` | 15 | 前100章每10章，后20章每4章 | 多段不同间距 |
| `30,4` | 4 | 1-30 / 31-60 / 61-90 / 91-120 | 均分4份 |

### 输出命名与编码

- 命名：`[前缀_]<序号补零>_第<起>-<止><单位>.txt`（如 `001_第1-40章.txt`，单章时为 `001_第5章.txt`；序号位数由 `--serial-width` 控制，**文件数超过当前位数容量时自动扩展**：1000+ 份→4 位、10000+ 份→5 位，保证排序正确）
- 单位（章/回/节/卷）自动从源文件首个章节标题识别
- 编码 UTF-8 无 BOM，正文保持源文件原样

### 核心函数对应关系

| split_by_groups.py | READ_聚合生成折线堆叠图.bas | 作用 |
|----|----|----|
| `parse_groups` | `ParseInputStringToArray` | 解析 `每份章数,份数\|...` 为段列表，处理余数 |
| `expand_groups` | `AggregateDataWithArrays` | 按段展开为具体文件/聚合单元 |
