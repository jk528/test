# SplitTxt —— 按章节拆分TXT的VBA工具

## 一、功能说明

将以「第N章/第N回/第N节/第N卷 标题」作为章节起点的中文长文本，按章节拆分为多个独立 `.txt` 文件。支持两种模式：

- **按章节一一拆分**：每章一个文件，命名 `序号 标题.txt`
- **聚合拆分**：按聚合格式将多章合并为一份，命名 `序号_第起-止单位.txt`

| 项目 | 说明 |
|------|------|
| 输入 | 单个TXT文本文件（自动检测编码：ANSI/UTF-8/UTF-16，含/不含BOM均可） |
| 输出 | 每章一个文件 或 多章合并文件（UTF-8无BOM） |
| 编码 | 输入自动检测（由 ReadTxtUniversal.bas 实现）；输出 UTF-8 无BOM |
| 适配验证 | 红楼梦.txt（2.57MB / 120章 / 3367行，识别与切片零误差） |

## 二、文件清单

| 文件 | 说明 |
|------|------|
| `SplitTxt.bas` | VBA模块：章节拆分（一键入口，支持每章拆分+聚合拆分两种模式） |
| `ReadTxtUniversal.bas` | VBA模块：通用TXT读写，自动检测编码（ANSI/UTF-8/UTF-16） |
| `split_txt.py` | Python脚本：章节拆分（含每章拆分+聚合拆分，与VBA功能对齐） |
| `readtxt_universal.py` | Python模块：通用TXT读写，自动检测编码（与 ReadTxtUniversal.bas 对齐） |
| `使用说明.md` | 本说明文档 |

> **导入/运行顺序**：
> - VBA: 先导入 `ReadTxtUniversal.bas`，再导入 `SplitTxt.bas`
> - Python: `split_txt.py` 自动 import `readtxt_universal.py`，需在同一目录

## 三、运行方式

### 方式A：一键拆分（推荐）

1. 打开 WPS 文字 / Excel，按 `Alt + F11` 进入 VBA 编辑器
2. 在左侧工程窗口右键 → **导入文件** → 先选 `ReadTxtUniversal.bas`，再选 `SplitTxt.bas`
3. 按 `Ctrl + G` 打开立即窗口
4. 在立即窗口输入并回车：
   ```vba
   拆分TXT
   ```
5. 弹出文件选择对话框 → 选中 TXT 文件
6. 弹出模式选择对话框：
   - **[是]** 按章节一一拆分（每章一个文件）
   - **[否]** 聚合拆分（多章合并为一份）→ 再输入聚合格式（默认 `40,3`）
7. 弹出预览对话框 → 确认后即开始拆分
8. 输出目录默认为：所选文件所在目录\<文件名>_拆分\ 或 _分组\

### 方式B：直接调用核心过程（自定义参数）

```vba
' 按章节一一拆分
SplitByChapter "D:\三国演义.txt"

' 聚合拆分（每份60章，共2份）
SplitByGroups InputPath:="D:\三国.txt", ChunkStr:="60,2", SerialWidth:=3
```

### 方式C：作为按钮宏

在VBA编辑器中导入模块后，可在WPS文档中通过「开发工具 → 宏」选择 `拆分TXT`、`SplitByChapter` 或 `SplitByGroups` 运行。

### 聚合格式说明

格式为 `每份章数,份数`，以 `|` 分割多段：

| 输入 | 含义 | 结果（120章） |
|------|------|--------------|
| `40,3` | 每份40章，共3份 | 1-40 / 41-80 / 81-120 |
| `40,2` | 每份40章，共2份（余数自动补齐） | 同上，实际3份 |
| `40` | 便捷模式：每40章一份 | 同上 |
| `20,1\|20,1\|80,1` | 多段：1×20章 + 1×20章 + 1×80章 | 1-20 / 21-40 / 41-120 |

输出命名 `序号_第起-止单位.txt`（如 `001_第1-40章.txt`），序号位数自适应（突破999/9999章自动扩展）。写入前弹预览对话框确认并清理旧文件。

## 四、参数说明

### SplitByChapter 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `InputPath` | String | 是 | — | 源TXT完整路径 |

| `FileNamePrefix` | String | 否 | `""` | 文件名前缀；空串 = 仅 `序号 标题.txt` |
| `SerialWidth` | Long | 否 | `3` | 序号位数；章节数超容量时自动扩展 |

### SplitByGroups 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `InputPath` | String | 是 | — | 源TXT完整路径 |
| `OutputDir` | String | 否 | `""` | 输出目录；空串 = 源目录下 `<源文件名>_分组\` |
| `ChunkStr` | String | 否 | `"40,3"` | 聚合格式 `每份章数,份数\|...` 或便捷 `N` |
| `FileNamePrefix` | String | 否 | `""` | 文件名前缀；空串 = 仅 `序号_范围.txt` |
| `SerialWidth` | Long | 否 | `3` | 序号位数；文件数超容量时自动扩展 |

## 五、章节识别规则

正则：`^第([0-9一二三四五六七八九十百千万零两]+)(章|回|节|卷)(\s*)(.*)$`（中文数字含"万"，支持大章节号）

| 支持的标题格式 | 示例 |
|------|------|
| 阿拉伯数字+章 | `第1章 甄士隐梦幻识通灵 贾雨村风尘怀闺秀` ✓ |
| 中文数字+章 | `第一章 序章` ✓ |
| 回/节/卷 | `第五回 满江红` / `第三节 引子` ✓ |
| 零/两 | `第零章 楔子` / `第二回` ✓ |
| 万级大章节 | `第一万章` / `第十万章` / `第10000章` ✓ |

> 标题行必须独占一行、位于行首。行内出现的「第N章」字样不会误判（如正文 "看官听说第3章里..."）。

## 六、文件名清洗规则

标题中以下字符将被替换为空格：`\ / : * ? " < > |`

- 连续空格折叠为单个空格
- 标题长度限制 60 字符（防止路径过长）
- 标题为空时退化为 `第N章`

## 八、工程约定与边界处理

本项目遵循以下工程约定（来自项目记忆）：

- ✅ 所有 `Dim` 语句声明在过程顶部（WPS VBA 严格性要求，循环内重复Dim会报"重定义"编译错误）
- ✅ 字符串拼接使用 `数组 + Join`，避免循环内反复 `&` 拼接
- ✅ 编码读写统一由 `ReadTxtUniversal.bas` 提供（自动检测 ANSI/UTF-8/UTF-16，无需手动指定）
- ✅ 写入前显示预览并经用户确认（避免误操作）
- ✅ 显示计时与处理速率（性能可量化）
- ✅ 单一职责：拆分、识别、清洗、I/O 分别封装为独立函数

## 九、常见问题

### Q1：运行报错"未识别到任何章节标题"
检查源文件首行是否为 `第N章 标题` 格式。如有自定义格式（如 `Chapter 1`），需调整 `reg.Pattern`。

### Q2：导入 .bas 报错"同名模块已存在"
VBA 编辑器中右键旧模块 → 移除 → 重新导入；或先在编辑器中删除同名模块。

### Q3：输出文件中文乱码
源文件编码自动检测由 `ReadTxtUniversal.bas` 处理，支持 ANSI(GBK)/UTF-8/UTF-16。如仍乱码，可在立即窗口单独检测编码：
```vba
Debug.Print DetectEncodingFile("D:\红楼梦.txt")   ' 返回 ANSI / UTF-8 / UTF-8 BOM / UTF-16LE / UTF-16BE
```

### Q4：路径含中文导致找不到文件
WPS VBA 对中文路径支持良好。如遇问题，将 `红楼梦` 目录改名为英文，或使用 `Shell` 调用。

### Q5：能否去除每章末尾的 `(本章完)` 标记？
当前实现保留原样。如需去除，在切片后对 `body` 做替换：
```vba
body = Replace(body, vbCrLf & "(本章完)" & vbCrLf, vbCrLf)
```

## 十、编码自动检测（ReadTxtUniversal.bas / readtxt_universal.py）

通用 TXT 读写模块，提供编码自动检测和多编码读取能力。VBA 的 `SplitTxt.bas` 和 Python 的 `split_txt.py` 均依赖此模块。

### 三层检测策略

| 优先级 | 层 | 方法 | 精度 | 依赖 |
|--------|---|------|------|------|
| 1 | BOM 快速检测 | 检查文件头 BOM 字节 | 100%确定 | 无 |
| 2 | charset-normalizer | 统计分析（Python最佳实践） | 最高 | `pip install charset-normalizer` |
| 3 | UTF-8 字节模式扫描 | 多字节序列模式匹配 | 高 | 无 |

> Python 优先使用 `charset-normalizer`（编码检测最佳实践库），未安装时自动降级为手动扫描。
> VBA 使用 BOM + 字节模式扫描（两层），无第三方依赖。

### 支持的编码

| 编码 | 检测方式 | VBA 读取 | Python 读取 |
|------|---------|---------|------------|
| UTF-8 BOM | BOM: `EF BB BF` | ADODB.Stream | raw.decode("utf-8-sig") |
| UTF-8 无BOM | 字节扫描 / 统计分析 | ADODB.Stream | raw.decode("utf-8") |
| UTF-16LE | BOM: `FF FE` | FileSystemObject | raw.decode("utf-16") |
| UTF-16BE | BOM: `FE FF` | FileSystemObject | raw.decode("utf-16") |
| ANSI (GBK) | 无BOM且非UTF-8 | 原生 Open + Line Input | raw.decode("gbk") |
| GB18030 | charset-normalizer | — | raw.decode("gb18030") |
| Big5 | charset-normalizer | — | raw.decode("big5") |

### 对外接口

| 函数 | VBA | Python | 说明 |
|------|-----|--------|------|
| 读取全文 | `ReadTextAuto(path)` | `read_text_auto(path)` | 自动检测编码并读取 |
| 检测编码 | `DetectEncodingFile(path)` | `detect_encoding(path)` | 返回编码名称 |
| 写UTF-8无BOM | `WriteTextUTF8NoBOM(path, text)` | `write_text_utf8_nobom(path, text)` | — |
| 写ANSI(GBK) | `WriteTextANSI(path, text)` | `write_text_ansi(path, text)` | — |
| 写UTF-8含BOM | `WriteTextUTF8BOM(path, text)` | `write_text_utf8_bom(path, text)` | — |

### 独立使用

```vba
' VBA: 在立即窗口检测文件编码
Debug.Print DetectEncodingFile("D:\红楼梦.txt")   ' 返回 "ANSI" / "UTF-8" / "UTF-16LE" 等

' VBA: 独立读取任意编码的TXT
Dim content As String
content = ReadTextAuto("D:\gbk编码的小说.txt")
```

```bash
# Python: 命令行检测
python readtxt_universal.py 红楼梦.txt

# Python: 代码调用
from readtxt_universal import read_text_auto, detect_encoding
enc = detect_encoding("红楼梦.txt")    # 返回 "utf-8" / "gb18030" / "UTF-16LE" 等
content = read_text_auto("红楼梦.txt")  # 自动检测并读取
```

## 十一、Python脚本用法（split_txt.py）

`split_txt.py` 是合并版 Python 脚本，支持每章拆分和聚合拆分两种模式，与 VBA `SplitTxt.bas` 功能对齐。

### 参数说明

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `--src` | **是** | — | 源TXT路径 |
| `--mode` | 否 | `chapter` | 拆分模式: `chapter`=每章一文件, `groups`=聚合拆分 |
| `--out` | 否 | 空 | 输出目录；空 = 自动派生 |
| `--chunk` | 否 | `40,3` | 聚合格式（传入时自动切换 groups 模式） |
| `--prefix` | 否 | 空 | 文件名前缀 |
| `--serial-width` | 否 | `3` | 序号位数（文件数超容量时自动扩展） |

### 用法示例

```bash
# 按章节一一拆分（每章一个文件）
python split_txt.py --src 红楼梦.txt
python split_txt.py --src 红楼梦.txt --prefix HL --serial-width 4

# 聚合拆分（传 --chunk 自动切换 groups 模式）
python split_txt.py --src 红楼梦.txt --chunk 40,3
python split_txt.py --src 红楼梦.txt --chunk 20,1|20,1|80,1
python split_txt.py --src 红楼梦.txt --mode groups --chunk 30,2|60,1

# 通用拆分其他文件
python split_txt.py --src D:\三国.txt --chunk 60,2 --prefix SG
```

### 聚合格式

格式为 `每份章数,份数`，以 `|` 分割多段：

| 输入 | 含义 | 结果（120章） |
|------|------|--------------|
| `40,3` | 每份40章，共3份 | 1-40 / 41-80 / 81-120 |
| `40,2` | 每份40章，共2份（余数自动补齐） | 同上，实际3份 |
| `40` | 便捷模式：每40章一份 | 同上 |
| `20,1\|20,1\|80,1` | 多段：1×20章 + 1×20章 + 1×80章 | 1-20 / 21-40 / 41-120 |
| `1,20\|2,50` | 前20章每章一文件，后100章每2章一文件 | 70份 |

### 输出命名与编码

- 每章拆分：`<序号> <标题>.txt`（标题内半角空格转全角）
- 聚合拆分：`<序号>_第<起>-<止><单位>.txt`（如 `001_第1-40章.txt`）
- 序号位数自适应：文件数超容量时自动扩展（1000+→4位，10000+→5位）
- 编码：输入自动检测（ANSI/UTF-8/UTF-16），输出 UTF-8 无BOM
