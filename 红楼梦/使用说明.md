# SplitTxtByChapter —— 按章节拆分TXT的VBA工具

## 一、功能说明

将以「第N章/第N回/第N节/第N卷 标题」作为章节起点的中文长文本，按章节拆分为多个独立 `.txt` 文件。

| 项目 | 说明 |
|------|------|
| 输入 | 单个TXT文本文件（UTF-8，含/不含BOM均可） |
| 输出 | 每章一个文件，命名 `[序号]-[标题].txt` |
| 编码 | 输入/输出均为 UTF-8（输出无BOM，与源文件一致） |
| 适配验证 | 红楼梦.txt（2.57MB / 120章 / 3367行，识别与切片零误差） |

## 二、文件清单

| 文件 | 说明 |
|------|------|
| `SplitTxtByChapter.bas` | 独立VBA模块（可在WPS/Excel VBA编辑器中导入） |
| `使用说明.md` | 本说明文档 |

## 三、运行方式

### 方式A：一键拆分红楼梦（默认）

1. 打开 WPS 文字 / Excel，按 `Alt + F11` 进入 VBA 编辑器
2. 在左侧工程窗口右键 → **导入文件** → 选择 `SplitTxtByChapter.bas`
3. 按 `Ctrl + G` 打开立即窗口（或在视图菜单打开）
4. 在立即窗口输入并回车：
   ```vba
   拆分红楼梦
   ```
5. 弹出预览对话框 → 确认后即开始拆分
6. 完成后输出到：`红楼梦\红楼梦_拆分\`

### 方式B：通用拆分（自定义参数）

在立即窗口调用 `SplitTxtByChapter`，传入参数：

```vba
' 拆分红楼梦.txt，默认参数（输出到 源目录\红楼梦_拆分\）
SplitTxtByChapter "C:\...\红楼梦.txt"

' 拆分红楼梦.txt，输出到指定目录，文件名前缀"HL"，序号3位
SplitTxtByChapter "C:\...\红楼梦.txt", "D:\out", "HL", 3
' 生成：HL_001-甄士隐梦幻识通灵 贾雨村风尘怀闺秀.txt ...

' 拆分其他小说（如"第N回"格式的三国演义）
SplitTxtByChapter "D:\三国演义.txt", "", "", 3
```

### 方式C：作为按钮宏

在VBA编辑器中导入模块后，可在WPS文档中通过「开发工具 → 宏」选择 `拆分红楼梦` 或 `SplitTxtByChapter` 运行。

## 四、参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `InputPath` | String | 是 | — | 源TXT完整路径 |
| `OutputDir` | String | 否 | `""` | 输出目录；空串 = 源目录下 `<源文件名>_拆分\` |
| `FileNamePrefix` | String | 否 | `""` | 文件名前缀；空串 = 仅 `序号-标题.txt` |
| `SerialWidth` | Long | 否 | `3` | 序号位数；3 → 001/002/.../120 |

## 五、章节识别规则

正则：`^第([0-9一二三四五六七八九十百千零两]+)(章|回|节|卷)(\s*)(.*)$`

| 支持的标题格式 | 示例 |
|------|------|
| 阿拉伯数字+章 | `第1章 甄士隐梦幻识通灵 贾雨村风尘怀闺秀` ✓ |
| 中文数字+章 | `第一章 序章` ✓ |
| 回/节/卷 | `第五回 满江红` / `第三节 引子` ✓ |
| 零/两 | `第零章 楔子` / `第二回` ✓ |

> 标题行必须独占一行、位于行首。行内出现的「第N章」字样不会误判（如正文 "看官听说第3章里..."）。

## 六、文件名清洗规则

标题中以下字符将被替换为空格：`\ / : * ? " < > |`

- 连续空格折叠为单个空格
- 标题长度限制 60 字符（防止路径过长）
- 标题为空时退化为 `第N章`

## 八、工程约定与边界处理

本项目遵循以下工程约定（来自项目记忆）：

- ✅ 所有 `Dim` 语句声明在过程顶部（WPS VBA 严格性要求，循环内重复Dim会报"重定义"编译错误）
- ✅ 字符串拼接使用 `数组 + Join`，避免循环内反复 `&` 拼接
- ✅ UTF-8 读写使用 `ADODB.Stream`（VB内置 `Open/Print` 默认GBK会乱码）
- ✅ 写入前显示预览并经用户确认（避免误操作）
- ✅ 显示计时与处理速率（性能可量化）
- ✅ 单一职责：拆分、识别、清洗、I/O 分别封装为独立函数

## 九、常见问题

### Q1：运行报错"未识别到任何章节标题"
检查源文件首行是否为 `第N章 标题` 格式。如有自定义格式（如 `Chapter 1`），需调整 `reg.Pattern`。

### Q2：导入 .bas 报错"同名模块已存在"
VBA 编辑器中右键旧模块 → 移除 → 重新导入；或先在编辑器中删除同名模块。

### Q3：输出文件中文乱码
确认源文件为 UTF-8。如源文件为 GBK，需将 `ReadTextUTF8` 中 `stm.Charset = "utf-8"` 改为 `"gbk"`。

### Q4：路径含中文导致找不到文件
WPS VBA 对中文路径支持良好。如遇问题，将 `红楼梦` 目录改名为英文，或使用 `Shell` 调用。

### Q5：能否去除每章末尾的 `(本章完)` 标记？
当前实现保留原样。如需去除，在切片后对 `body` 做替换：
```vba
body = Replace(body, vbCrLf & "(本章完)" & vbCrLf, vbCrLf)
```
