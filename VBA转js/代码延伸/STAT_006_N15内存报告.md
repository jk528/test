## 二、N=15 重点分析

### 2.1 内存

- dp 三维数组：`dp(0 To 32767, 0 To 14, 0 To 15)` As Double
- 元素总数：32,768 × 15 × 16 = **7,864,320**
- 内存占用：7,864,320 × 8 bytes = **60.0 MB**
- VBA 可接受（32 位 WPS/Excel 地址空间上限约 2 GB）

### 2.2 耗时

- 内循环次数：**13,762,560**（约 1380 万次）
- JS V8 实测：**594ms**
- VBA 预估（×40 系数）：**~24 秒**
- 实际 VBA 中因 `If dp > 0` 跳过空状态，耗时可能更短

### 2.3 正确性验证

- 行和 = Σ T(N,k) = 1,307,674,368,000 = **15! ✅**
- 满分公式 T(15,15) = **30** = 2×15 ✅
- 空缺公式 T(15,14) = **0** ✅

## 四、内存计算公式

```
dp 数组元素数 = 2^N × N × (N + 1)
内存 (MB)    = 2^N × N × (N + 1) × 8 / 1,048,576
```

### VBA Long 类型安全范围

- `full = 2^N - 1`，VBA Long 上限 = 2,147,483,647 (2^31 - 1)
- N ≤ 30 时 bitmask 安全
- 但内存限制使得 N > 18 不可行（数组太大）

---

## 五、优化建议

若需支持 N > 15：

1. **稀疏存储**：用 `Scripting.Dictionary` 替代 3D 数组，仅存非零状态
   - 大部分 `dp(mask, last, c)` 为 0，稀疏率 > 90%
   - 预估可支持 N = 18~20

2. **滚动数组**：按 mask 大小分层计算，只保留当前层和上一层
   - 无法直接适用（转移是 mask → mask|{j}，非严格分层）

3. **对称性剪枝**：利用 C_N 的旋转对称性减少状态数
   - 固定 first=1 已减少 N 倍
   - 进一步可用反射对称性再减半
