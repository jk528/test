# T(N,k) 闭式公式从零推导

> 问题：N 个元素 {1,...,N} 的所有排列视为有向 Hamilton 圈，环形相邻对满足 `|a-b|=1 或 |a-b|=N-1`（即参考无向圈图 C_N 的边）恰好有 k 对的排列数，记为 T(N,k)。

---

## 第零章：学术命名

### 结论：暂未有标准命名，但有紧密相关的数学对象

在 OEIS 和近年论文中检索到以下关联，但**没有与本三角表逐行精确匹配的已知条目**：

| 名称 | 作者/出处 | 与本问题的关系 |
|------|----------|---------------|
| **Cyclic adjacency coincidences** | Possibly Wrong (2013) blog | 研究"排列中相邻对与参考顺序恰好重合 k 次"的分布，含循环边界条件，与本问题定义一致，但作者未给出一般 k 的闭式 |
| **Graphical r-Stirling numbers of C_n** | Yaqubi & Mirzavaziri (2026, arXiv:2602.02046) | 图型第一类 Stirling 数 `[C_n/k]_r`，推导出 `[C_n/k] = n/k · C(k, n-k)` for k≥2。这与本文 f(N,j,c) 公式中的环上组合计数结构**完全一致** |
| **k-matchings of C_n (A034807)** | OEIS A034807, Kaplansky 1943 | C_n 上选 k 条互不相邻边的方式数。这是本问题 j 条边无邻接（c=j）的特例 |
| **Cyclic consecutive ascents (A180188)** | OEIS A180188 | 升序相邻环形继承数，仅考虑递增边 `(i,i+1)`。其满分值 n 恰好 = T(n,n)/2，**但其他 k 无简单倍数关系** |

### 本问题的标准学术描述

> **"The distribution of the number of shared edges between a random Hamiltonian cycle and the fixed reference cycle C_N in the labeled complete graph K_N"**
>
> K_N 中随机 Hamilton 圈与固定参考圈 C_N 共享边数的精确分布

## 第一章：问题图论化重述

### 1.1 相邻条件的边集

对 N ≥ 3，定义参考无向圈图 C_N：

```
V(C_N) = {1, 2, ..., N}
E(C_N) = {(1,2), (2,3), ..., (N-1,N), (N,1)}    共 N 条边
```

观察：相邻条件 `|a-b|=1 或 |a-b|=N-1` 等价于 `{a,b} ∈ E(C_N)`。

### 1.2 排列到 Hamilton 圈的双射

每个排列 π ∈ S_N 对应 N 个顶点上的一个**有向 Hamilton 圈**：

```
π(1) → π(2) → ... → π(N) → π(1)
```

共形成 N 个有向相邻对 `(π(i), π(i+1))`（含闭合边 `(π(N), π(1))`）。对每个有向对取其无向基础边 {π(i), π(i+1)}。

### 1.3 T(N,k) 的重定义

> **定义**：T(N,k) = 有向 Hamilton 圈（即排列，含旋转+方向）中，其无向边集与 C_N 的边集交集大小恰好等于 k 的排列数。

等价地：
```
T(N,k) = # { π ∈ S_N : |{{π(i),π(i+1)}} ∩ E(C_N)| = k }
```

其中 i+1 取模 N。

### 1.4 直接验证

N=4, C_4:
```
E(C_4) = {{1,2}, {2,3}, {3,4}, {4,1}}
π = [1,2,3,4] → 边 {1,2}{2,3}{3,4}{4,1} = E(C_4) → k=4
π = [1,3,2,4] → 边 {1,3}{3,2}{2,4}{4,1} → {3,2}=E, {4,1}=E → k=2
```
对应 T(4,4)=8（4 个方向×2 个起点），T(4,2)=16。

## 第二章：容斥原理框架

### 2.1 标准"恰好 k"转化

直接计数"恰好 k 条共享边"很难，改为计数"至少 j 条共享边"，再容斥反演。

定义对边子集 S ⊆ E(C_N)：
```
A_S = { π ∈ S_N : S ⊆ {{π(i),π(i+1)}} }
```
即排列的边集**包含** S 中每条边（方向任选）。注意 S 是边集合，非"恰好"。

### 2.2 E(N,j) 的定义

定义 E(N,j) 为所有 j 条边组合 S 的 |A_S| 之和：

```
E(N,j) = Σ_{S⊆E(C_N), |S|=j} |A_S|
```

**引理（子集大小的组合恒等式）**：
```
E(N,j) = Σ_{k≥j} C(k, j) · T(N, k)       —— （1）
```

证明：考虑对每个排列 π 其共享 k ≥ j 条边，则它被 C(k,j) 个子集 S 各计算一次，所以总贡献为 Σ_{π} C(k_π, j) = Σ_{k≥j} C(k,j)·T(N,k)。

### 2.3 容斥反演公式

从恒等式 (1) 可以反解出 T(N,k)（标准二项式反演 / 容斥恰好 k 公式）：

> **定理 1（容斥反演）**：
> ```
> T(N, k) = Σ_{j=k}^{N} (-1)^{j-k} · C(j, k) · E(N, j)       —— （2）
> ```

证明概要：在恒等式 C(k,j)·T 求和 = E 中，代入 T = Σ (-1)^{j'-k}C(j',k)·E_{j'}，利用二项式系数正交性 Σ_{j}^{j'} (-1)^{j'-j}C(j',j)·C(j,k) = [j'=k] 即可验证。

**这就是我们需要的闭式公式骨架**。接下来只需把 E(N,j) 算出来。

## 第三章：|A_S| 的计算 —— 给定边集 S 的排列数

### 3.1 S 作为 C_N 上的子图

取固定 S ⊆ E(C_N), |S|=j。因为 C_N 本身是一个圈，选 j 条边相当于在 N 个顶点的圈上"涂色" j 条边。

这张涂色子图的结构是**若干条互不相交的路径**（因为原图是圈，边是无向简单边，涂色边的连接分量只能是路径，不可能成圈——除非 j=N 时涂满整个圈，成为一个连通圈）。

设 S 的连通分量数（路径条数）为 c。

### 3.2 c 条路径 → 排列数的化简

当 S 的 c 条路径必须都出现在排列的相邻边中时：

- 每条路径是一段"整体"（内部顺序和方向可互换，但两端点是自由的）
- 将每条路径视为一个"超级顶点"，共有 c 个超级顶点 + (N - j - c) 个未在任何路径中的独立顶点
- 实际上：N 个顶点由 j 条边连出 c 条路径，路径顶点 + 孤立点 = N，路径边共 j 条 → c = N - j？**不对！**

重新数：一条含 ℓ 个顶点的路径有 ℓ-1 条边。c 条路径共 N 个顶点，j 条边：
```
j = Σ (ℓ_i - 1) = N - c
∴ c = N - j                        —— （3）
```

哦，这太简洁了！**c 条路径段是所有 c = N-j 个 "超级块"吗？** 不——等一下，c 是 S 的连通分量（路径）数。每条路径是一个超级块，孤立点是 1 顶点路径（长度 0）。没错，式 (3) 正确：**j 条边连出 c = N-j 个连通分量（含孤立点）**。

但是不对——我们的边是**无向**的，每条路径可以正向或反向出现在 Hamilton 圈中，有 2 种方向。

### 3.3 正确的排列计数

当 c 个"超级块"要放入一个长度为 c 的**环形**排列中（因为最终是有向 Hamilton 圈，超级块的顺序本身是环形排列）：

- c 个超级块的线性排列：c! 种
- 每条超级路径的方向（内部翻转）：每条路径 = ℓ ≥ 2 的连通分量？不——所有连通分量（包括 1-顶点的孤立点）都是超级块。对 1-顶点块，方向翻转是恒等操作，只有 ℓ ≥ 2 的才贡献 2。

哦，这里有个更简单的方法——线性化 + 旋转因子。

### 3.4 固定起点法的统一推导

我们先固定排列起点为 1（利用旋转对称性），最后乘 N。

在固定起点后，超级块形成线性顺序，排列数 =

```
(超级块线性排列数) × (每条长度≥2 的路径的方向因子)
= (c - 1)! × 2^{#(长度≥2 的路径)}   (环形排列的 c-1!？)
```

等一下——我们还没有乘 N 还原旋转。若直接线性排列 c 个块共 c! 种，再乘每条路径方向 2（只要 ≥2 顶点）：

```
#(长度≥2 的路径) = N - j - (#孤立点)？ 不对，长度≥2 路径数 = c - 孤立点数
                    = c - (c - (总路径含 ℓ≥2 数))
更清晰：S 中 j 条边连成 c 个连通分量，其中恰好
  c_1 = 个分量长度 = 1（孤立顶点）
  c_≥2 = c - c_1 个分量长度 ≥ 2，每贡献方向 2

总方向因子 = 2^{c - c_1}
```

这太复杂了——因为它依赖于 S 的具体形状，而不仅仅是 c 和 j！

**关键突破**：所有 |S|=j 的边集 S 可以按它们形成的"路径数 c"分类，再对每类求和。

## 第四章：环上选 j 边形成 c 段的计数 f(N,j,c)

### 4.1 问题重述

在 N 个顶点的**无向圈** C_N 上，选 j 条边（无重选），使得所选边恰好形成 c 个连通分量（每条是路径）的方式数，记为 f(N,j,c)。

等价地：在圆周上放 N 个"位置"表示 N 条边，选 j 个位置涂黑色，形成 c 个"相邻黑色段"（黑块）的方式数。

这是经典的**圆周上不相邻组合的精细计数**问题，有闭式。

### 4.2 线段上的经典公式（热身）

先考虑线性情形：n 个位置排成线，选 j 个涂黑，形成 c 个黑块的方式数 = C(j-1, c-1) · C(n-j-1, c-1)（n ≥ j ≥ c ≥ 1）。

解释：j 个黑球排成一排，在 j-1 个相邻间隙中选 c-1 个"不插入隔板"来保留 c 个块；剩余 n-j 个白球排成一排，在 n-j-1 个间隙选 c-1 个"插入隔板"分成 c 个组；黑白块严格交替。

### 4.3 环上公式（核心引理）

> **引理 2（Kaplansky, 1943）**：圆周上 N 个位置，选 j 个涂黑，形成 c 个相邻黑块的方式数：
> ```
> f(N, j, c) = N/c · C(j-1, c-1) · C(N-j-1, c-1)     —— （4）
> ```
> 其中 1 ≤ c ≤ min(j, N-j)，否则为 0。

**推导概要**：
1. 固定一个黑块"锚定"在圆周上（包含某特定位置），有 N 种方式
2. 该块长度为 ℓ ≥ 1，消耗 ℓ 个黑位
3. 剩余 j-ℓ 个黑位分成 c-1 个块，用线性公式 C(j-ℓ-1, c-2)·...
4. 最后对 ℓ 求和得到 N/c 因子。简洁证明见 A034807 Nieto (2012) 的评论。

**验证 N=5, j=2：**
```
f(5,2,1) = 5/1 · C(1,0)·C(2,0) = 5
f(5,2,2) = 5/2 · C(1,1)·C(2,1) = 5/2 · 1·2 = 5
总和 = 5+5 = 10 = C(5,2)  ✅
```

## 第五章：E(N,j) 的闭式（对所有 S 求和）

### 5.1 对固定形状的 |A_S|

取 S，形成 c 条路径（连通分量）。注意 S 的 c 个连通分量是 c 个"超级块"，每个超级块大小 ≥ 1（≥1 顶点）。

每个超级块（路径）在排列中可正向或反向嵌入 Hamilton 圈。对 1-顶点块，翻转=恒等；对 ≥2 顶点块，翻转贡献真正的 2 选 1。

但我们有统一公式：每条路径（不论长度）内部的排列自由度为 2^c_path？不对——每条连通路径（>1 顶点）有 2 个方向，共 2^{#(长度≥2 的路径)}。

**等等——有更简洁的方法**：不区分 1-顶点与长路径。考虑将每条 S-连通分量视为一个"可定向边块"。

思考：有 c 个超级块要排成一个有向 Hamilton 圈（起点固定为 1 所在的块）。线性排列超级块有 (c-1)! 种（环形）× c（旋转自由度） = c! 种线性排列。每条路径有 2 个方向，因此总方向因子 = 2^c？

不对——因为路径含所有顶点，每条 S 边是无向的，嵌入 Hamilton 圈时，这条边的两个端点的访问方向决定了路径方向。让我们来验证一下 N=5 基准。

### 5.2 基准特例：E(N,j) 已知情形

用容斥恒等式反推验证。由 STAT_005 实测 E(N,j) 值对 N=4:
```
E(4,0)=24=4!, E(4,1)=4·2!·(2^{1}+...) = ？  直接计数：C(4,1)·2·3! /4? 不好说
```
换更直接的方法。让我们推导：固定 S 形成 c 段 → A_S 大小。

将 c 条路径视为 c 个超级顶点。S 的 c 条路径 + (零个孤立点——不，孤立点已算在 c 的 1 顶点路径中) = N 个顶点全部被覆盖。

现在，**把每条路径"折叠"成一个顶点后**，我们要在 c 个超级顶点上构造一个有向 Hamilton 圈——这等价于 c 个超级顶点的任意排列，然后每条超级路径选择一个内部方向，最后超级路径之间的连接边必须是非 S 边（没要求，因为 S 只是"必须包含"的边）。

等等！A_S 的定义只要求"S 必须作为子集出现"——排列可以包含更多的 C_N 边。这就是为什么 A_S 的计数简单：超级顶点可以任意排列（没有约束），只要路径内部保持连通（但方向可选择）。

所以：
- c 个超级块的线性排列数 = c!（不考虑旋转）
- 每条路径有 2 个方向 → 2^c（即使路径长度=1，这个"翻转"也是恒等，难道不是吗？！）

**关键修正**：对 1 顶点路径，翻转 = 恒等，实际没有 2 倍。让我们考虑另一种思路：不用超级块，直接用"线性延伸"。

### 5.3 正确的 |A_S| 公式

**另一种等价观点**：j 条强制边的存在，将 N 个点"粘"成一些块。每个块是一条路径，内部顺序被部分固定——实际上，S 的每条路径可以两个方向出现在排列中（如果长度≥2），或者唯一（长度=1）。

更系统：N 个顶点中放置 j 条强制边（在 C_N 圈上，c 段）。每个块（路径）是一个"定向珠子"。共 c 个珠子。将 c 个珠子排成任意线性序列（对应排列除去旋转的 (c-1)!？或直接 c! ·N？）。

我们使用更直接的测试。**对任何固定的 S，|A_S| 的值只依赖 c，而不依赖 S 的具体位置**（因为 C_N 是传递的）。这个对称性关键！！

由于 C_N 是弧传递图，任意相同 c 值的 S 都等价。因此我们可以对每类取代表算 |A_S|，再乘以 f(N,j,c)。

### 5.4 最小例子检验：N=5, j=2

| 情形 | S 选取 | c | A_S | 说明 |
|------|--------|---|-----|------|
| 1 | 两条边相邻（一条 3-路径） | N-j=3 → c=3？不对 j=2 边连起 3 个顶点 → 1 条 3-顶点路径 + 2 孤立 = 3 分量 → c=3 | |
| 2 | 两条边不相邻 | c=4 ？2 边连 4 个顶点 → 2 条 2 顶点路径 + 1 孤立 = 3 分量？不对，2 边不相邻在 N=5 圈也有两种结构 |

我需要重新精确 f(N,j,c) 的 c。

对于 N=5, j=2，我们已经知道 f(5,2,1)=5（两条边相邻成 3 路径），f(5,2,2)=5（两条边不相邻，各是 2 路径 + 1 孤立）。总共 10。

情形 c=1（S 是 3 顶点路径，占 2 边 + 1 跳空？不对 f(5,2,1)=5 的 c=1 表示 1 个黑块）：
- S = {{1,2},{2,3}}（邻接两黑边）：1 个黑块
- 这在顶点上形成路径 1-2-3（3 顶点），加上孤立点 4,5
- 连通分量数 = 路径 {1,2,3} + {4} + {5} = **3 个**

**哦！f(N,j,c) 的 c 是 **黑边段的段数**，不是顶点连通分量数！** 我混淆了两个概念。**

重新整理：
- 设 b = 黑边段的段数（f(N,j,c) 的 c，这里改为 b）
- 在每条黑边段中，b_k 条连续黑边连成一条路径，此路径含 b_k+1 个顶点
- 顶点连通分量数 = b + (N - j - b) = N - j
  - 解释：b 条黑边段各自是 1 个连通分量；此外，每段黑边段之间的"白区域"可以有孤立顶点...等等不对。

让我们直接数：N 个顶点，j 条边，连通分量数确实总 = N - j（不论如何选），因为每个连通分量是一条路径，ℓ 顶点路径有 ℓ-1 边。

所以顶点连通分量数恒为 N-j，与 S 形状无关！

那超级块排列计数就是：c = N - j 个超级块，每个超级块是 1 条路径。每条路径的方向：只有路径长度 ≥ 2 的才贡献 2 种——而路径长度 ≥ 2 当且仅当对应的黑边段长度 ≥ 1。每个黑边段对应一条长度 ≥ 2 的路径（因为段中至少 1 条边 → 至少 2 顶点）。

**方向因子 = 2^b，其中 b = 黑边段的段数！**

因为 b 个黑边段 → b 条长度 ≥ 2 的路径 → 每条 2 种方向；剩余 (N-j) - b = N-j-b 个连通分量是 1-顶点块（孤立），方向无变化。

### 5.5 |A_S| = N · (N-j-1)! · 2^b（固定黑段数 b）

有了 (N-j) 个超级块：
- 超级块的有向 Hamilton 圈数 = N · (N-j-1)!
  - N 种旋转起点 × (N-j-1)!（环形排列 N-j 个超级块）
- 每条长度 ≥2 的路径（对应 b 个黑边段）的方向因子 = 2^b
- 总计：|A_S| = N · (N-j-1)! · 2^b

### 5.6 E(N,j) 求和 = 按 b 分类

```
E(N,j) = Σ_{S, |S|=j} |A_S|
       = N · (N-j-1)! · Σ_{b=1}^{min(j,N-j)} [f(N,j,b) · 2^b]       —— （5）
```

其中 b 为黑边段段数，f(N,j,b) = N/b · C(j-1,b-1) · C(N-j-1,b-1)。

代入后：

> **定理 2（E(N,j) 闭式）**：
> ```
> E(N,0) = N!
> E(N,j) = N · (N-j-1)! · Σ_{b=1}^{min(j,N-j)} N/b · C(j-1,b-1) · C(N-j-1,b-1) · 2^b
>              (1 ≤ j ≤ N-1)
> E(N,N) = 2N
> ```
> —— （6）

E(N,N) 特殊情况：S = E(C_N) 全集，形成一个连通圈（b=1 黑段覆盖全部），此时超级块数 = 1，即整个圈必须作为一个整体出现在排列中。此时只有 2 种方向 × N 种起点 = 2N，正确。

## 第六章：代入容斥，得到 T(N,k) 闭式

### 6.1 汇总公式

将（6）代入（2）：

> **定理 3（T(N,k) 通用闭式）**：
> ```
> 对 0 ≤ k ≤ N:
>   T(N,k) = Σ_{j=k}^{N} (-1)^{j-k} · C(j, k) · E(N, j)
> ```
> 其中 E(N,j) 如上。

### 6.2 特例验证：T(N,N)

仅 j=N 项：
```
T(N,N) = (+1) · C(N,N) · E(N,N) = 1 · 2N = 2N
```
**QED —— 满分定理**。

### 6.3 特例验证：T(N,N-1)

j = N-1 和 j = N 两项：
```
T(N,N-1) = (-1)^{(N-1)-(N-1)}C(N-1,N-1)·E(N,N-1) + (-1)^{N-(N-1)}C(N,N-1)·E(N,N)
         = E(N,N-1) - N · 2N
```
计算 E(N,N-1)：j=N-1，N-j=1，min(N-1,1)=1，b 只能=1
```
E(N,N-1) = N · (1-1)! · [N/1 · C(N-2, 0) · C(0, 0) · 2^1]
         = N · 1! · 1 · N · 1 · 1 · 2
         = 2N²
```
于是 T(N,N-1) = 2N² - 2N² = 0。**QED —— 空缺定理**。

### 6.4 数值验证 N=5

用公式计算 T(5,k):

E(5,0)=120, E(5,1)=5·3!·Σ_{b=1}^1 5/b·C(0,b-1)·C(3,b-1)·2^b = 30·[5·1·C(3,0)·2]=30·10=300

E(5,2): b=1: 5/1·C(1,0)·C(2,0)·2=5·1·1·2=10; b=2:5/2·C(1,1)·C(2,1)·4=5/2·1·2·4=20. 总和 30. E(5,2)=5·2!·30=300

E(5,3): b=1:5·C(2,0)·C(1,0)·2=10; b=2:5/2·C(2,1)·C(1,1)·4=5/2·2·1·4=20. 总和 30. E(5,3)=5·1!·30=150

E(5,4): b=1:5·C(3,0)·C(0,0)·2=10. E(5,4)=5·0!·10=50

E(5,5)=10

容斥：
- T(5,0) = E-E1+E2-E3+E4-E5 = 120-300+300-150+50-10 = 10 ✅
- T(5,1) = 0（公式：无 j<1 项，代入计算也为 0）✅
- T(5,2) = C(2,2)E2 - C(3,2)E3 + C(4,2)E4 - C(5,2)E5 = 300-450+300-100 = 50 ✅
- T(5,3) = C(3,3)E3 - C(4,3)E4 + C(5,3)E5 = 150-200+100 = 50 ✅
- T(5,4) = E4-C(5,4)E5 = 50-50 = 0 ✅

## 第八章：最终公式汇总

### 完整定义

- **参考圈图 C_N**：顶点集 {1,...,N}, 边集 E(C_N) = {{i,i+1}:1≤i≤N-1} ∪ {{N,1}}
- **T(N,k)**：# { π ∈ S_N : 恰好 k 条无向边 {π(i),π(i+1)} ∈ E(C_N) } （i+1 mod N）

### 辅助函数

```
f(N,j,b) = N/b · C(j-1, b-1) · C(N-j-1, b-1),     1 ≤ b ≤ min(j, N-j)
          （C_N 上选 j 条边恰好形成 b 个相邻黑段的方式数，Kaplansky 1943）
```

### E(N,j) = Σ_{|S|=j} |A_S|

```
E(N,0) = N!
E(N,j) = N · (N-j-1)! · Σ_{b=1}^{min(j,N-j)} f(N,j,b) · 2^b,   1 ≤ j ≤ N-1
E(N,N) = 2N
```

### 通用闭式

```
T(N, k) = Σ_{j=k}^{N} (-1)^{j-k} · C(j, k) · E(N, j),    0 ≤ k ≤ N
```

### 端点闭式

```
T(N,N)   = 2N,      N ≥ 3
T(N,N-1) = 0,       N ≥ 3
Σ_k T(N,k) = N!
```
