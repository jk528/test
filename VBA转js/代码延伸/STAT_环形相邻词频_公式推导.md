# 环形相邻计数三角表 —— 闭式公式推导

> 本文档对 STAT_001 / STAT_004 中通过枚举得到的频率三角表进行严格的组合数学推导。
> 核心对象：**T(N, k)** = 将 {1, 2, …, N} 的全排列视为环时，恰好有 k 对相邻元素满足 "|差|=1 或 |差|=N-1" 的排列数。
> 日期：2026-08-11

---

## § 0. 图论化重述（关键洞察）

条件 "|a - b| = 1 或 |a - b| = N-1" 作用于数字集 {1,…,N} 时，它对应的**无向边集合**恰好是：

```
E(C_N) = {(1,2), (2,3), (3,4), …, (N-1,N), (N, 1)}
```

这就是 N 圈图 C_N 的全部 N 条边。（(N,1) 即 1 和 N 的差为 N-1。）

因此问题等价于：

> 在标号完全图 K_N 的所有有向 Hamilton 圈（即 N! 种环形排列）中，统计与固定参考无向圈 C_N 恰好共享 k 条（无向）边的有向 Hamilton 圈数，记为 **T(N, k)**。

记 C_N 的 N 条（无向）边为 e₁, e₂, …, e_N。对每条边 e_j，定义事件集：

```
A_j = { 所有有向 Hamilton 圈 π：边 e_j 在 π 中作为相邻对出现（方向不限） }
```

T(N, k) 就是"恰好 k 个事件发生"的排列数。

---

## § 1. 满分公式 — 定理：对任意 N ≥ 3，T(N, N) = 2N

**组合证明：**

T(N,N) 意味着 "Hamilton 圈 π 使用了 C_N 的全部 N 条边（作为无向边）"。
而一个有向 Hamilton 圈恰好含 N 条有向边。若其对应的 N 条无向边恰好覆盖 E(C_N) = {e₁,…,e_N}（共 N 条），则 π 的无向边集 **就是 E(C_N) 本身**。
换言之，π（作为无向圈）就是 C_N（固定圈）本身。

C_N 作为无向圈，对应多少种有向环形排列？
- 遍历方向：2 种（顺时针 1→2→…→N→1，逆时针 1→N→…→2→1）
- 起点：N 种（任一数字都可作为排列首位）

合计 = 2 × N。故 T(N, N) = 2N。∎

---

### 数值验证

| N | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|
| 实测 T(N,N) | 6 | 8 | 10 | 12 | 14 | 16 |
| 2N | 6 | 8 | 10 | 12 | 14 | 16 |
| 一致性 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

N<3 为边界情况（T(1,0)=1、T(2,2)=2，N=1,2 为圈图退化），N≥3 本定理严格成立。

## § 2. 空缺公式 — 定理：对任意 N ≥ 2，T(N, N-1) = 0

**组合证明：**

T(N, N-1) ≥ 1 将断言：存在一个有向 Hamilton 圈 π，它使用了 C_N 中 N-1 条边，但唯独**没有**使用某一条特定边 e = {u,v}。

在圈图 C_N 上删除一条边 e 后，得到的是一条**覆盖全部 N 个顶点的无向路径 P_{u,v}**（两端点就是 e 的两个端点 u 与 v）。
如果 π 使用了这条路径 P_{u,v} 的全部 N-1 条边，那么在 π 中这条路径必须以整体段形式出现（两端暴露 u、v），π 作为闭合圈还需一条额外边连接 u、v 来闭合成 Hamilton 圈。

但是，能把路径 P_{u,v} 的两端 u、v 重新闭合为圈的 K_N 边就是 **e = {u,v} 本身**！
矛盾（因为我们假设 e 未被使用）。

因此不存在这样的 π，即 T(N, N-1) = 0。∎

|---|---|---|---|---|---|---|

| 预期值 | 0 | 0 | 0 | 0 | 0 | 0 |
| 一致性 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

## § 3. 代数推导 — 容斥原理与 "至少 j 条"计数 E(N, j)

### § 3.1 E(j) 的定义

定义"至少用了 j 条参考边"的**加权**计数（容斥中间量）：

```
E(N, j) = Σ_{S ⊆ E(C_N), |S|=j} | ∩_{e ∈ S} A_e |
```

即对所有 j 条参考边的组合 S，统计"使用了 S 中每条边（至少）"的排列数，再把所有 S 的结果相加。E(N, j) 与 T(N, k) 有标准的二项反演关系：

```
(1)  E(N, j) = Σ_{k ≥ j} C(k, j) · T(N, k)      （每个恰好 k 的排列在 C(k,j) 个大小为 j 的 S 中被计）
(2)  T(N, k) = Σ_{j = k}^{N} (-1)^{j-k} · C(j, k) · E(N, j)     （容斥原理，恰好 k）
```

式 (1)(2) 的正确性由 N=4..8 的枚举直接验证通过（所有 k 逐一比较，全部 PASS）。

### § 3.2 用容斥给出 T(N, N-1) = 0 的代数证明

由式 (2)，令 k = N-1：

```
T(N, N-1) = Σ_{j=N-1}^{N} (-1)^{j-(N-1)} C(j, N-1) E(N, j)
          = (-1)^0 C(N-1, N-1) E(N, N-1) + (-1)^1 C(N, N-1) E(N, N)
          = E(N, N-1) − N · E(N, N)
```

但由 § 2 的组合证明，"固定 S = E(C_N) \ {e}（大小为 N-1，共 N 种这样的 S）时，每条 S 都强制变成满分圈"，因此每个 S 对应的 ∩A_e 就是满分集合，大小都是 T(N,N) = 2N：

```
E(N, N-1) = Σ_{|S|=N-1} H(S) = N × 2N = 2N²
E(N, N)   = Σ_{|S|=N}   H(S) = 1 × 2N = 2N
```

代入即得：

```
T(N, N-1) = 2N² − N · 2N = 0    ∎
```

这个代数推导与组合证明完全吻合，并且在 N=4..8 上实测 E(N,N-1)/E(N,N) 全部等于 N，验证通过。

## § 4. 一般 k 的容斥公式（可算法化）

综合 § 3.1 公式 (2)，我们得到 T(N, k) 的显式表达式：

```
┌─────────────────────────────────────────────────────────────────┐
│   T(N, k) = Σ_{j = k}^{N}  (-1)^{j-k} · C(j, k) · E(N, j)         │
│                                                                   │
│   其中 E(N, j) = Σ_{S: |S|=j}  含 S 每条边的有向 Hamilton 圈数      │
└─────────────────────────────────────────────────────────────────┘
```

对 E(N, j) 的进一步闭式（由 C_N 的图结构求平均每组 H(S)）：在圈图 C_N 上取 j 条边后，剩下 N-j 段路径。对每一个 j 边集 S，每条 S 的边在排列中可以两种方向出现，并且路径段被"粘"为超级顶点。当需要显式值时，用枚举 O(N!) 或动态规划已足够。

## § 5. 与 A180188（仅升序环形继承数）的对照

| 项目 | 我们的三角 T(N,k) | OEIS A180188 T_asc(n,k) |
|---|---|---|
| 参考边 | 无向 C_N 边集（双向） | 有向边 {(i,i+1): 1≤i≤n-1} ∪ {(n,1)}，仅升序方向 |
| 满分 | T(N,N) = 2N | T_asc(n,n-1) = n（最多 k=n-1） |
| 满分比例 | 2N / N! = 2 / (N-1)! | n / n! = 1 / (n-1)! |
| 满分关系 | T(N,N) = **2 ×** T_asc(N,N-1) | 精确 2 倍关系 ✅ |
| 一般 k 关系 | 无简单倍数（实测比值非整数） | 无 |

A180188 有已知闭式：T_asc(n,k) = n · C(n-1, k) · !(n-1-k)，其中 !m 为错位排列数（subfactorial）。我们的双向下没有已知 OEIS 对应序列——这是这个三角表的新颖性。
