# 动态窗体范例 — 纯模块实现

> 用纯模块代码动态创建 UserForm + 控件，关闭窗体后自动删除整个窗体组件。

## 核心流程

```
StartDynamicForm（入口）
  │
  ├─ 1. 获取 ThisWorkbook.VBProject
  ├─ 2. 清理残留同名窗体
  ├─ 3. VBComponents.Add(3) → 创建 UserForm
  ├─ 4. Designer.Controls.Add → 逐一添加控件
  ├─ 5. CodeModule.AddFromString → 注入事件代码
  ├─ 6. UserForms.Add → Show 显示
  │
  └─ 用户关闭窗体
       │
       ├─ btnClose_Click → Unload Me + OnTime 延迟删除
       └─ QueryClose (X按钮) → 同样 OnTime 延迟删除
            │
            └─ DeleteDynamicForm → VBComponents.Remove → 窗体彻底消失
```

## 为什么需要 OnTime 延迟？

窗体在 `Unload` 后仍短暂存活在内存中，此时直接 `VBComponents.Remove` 会报错。
`Application.OnTime Now + 1秒` 确保窗体完全卸载后再执行删除。

## 控件清单

| 控件 | 名称 | 类型 | 作用 |
|------|------|------|------|
| 标签 | lblTitle | Label | 标题文字 |
| 文本框 | txtInput | TextBox | 用户输入 |
| 按钮 | btnOK | CommandButton | 读取输入并弹窗 |
| 按钮 | btnClose | CommandButton | 关闭并触发删除 |
| 标签 | lblNote | Label | 灰色说明文字 |

## 使用前提

**必须**在 Excel 中开启：
> 文件 → 选项 → 信任中心 → 信任中心设置 → 宏设置
> → 勾选 **信任对 VBA 工程对象模型的访问**

否则 `ThisWorkbook.VBProject` 返回 Nothing，无法动态创建组件。

## "全部清零"含义

关闭窗体后：
- 窗体文件（`DynamicForm`）从 VBProject 中**彻底移除**
- 所有控件随之消失
- 下次调用 `StartDynamicForm` 会全新创建，无任何残留

等价于：动态生成 → 使用 → 销毁，生命周期完全由代码控制。

## 关键 API 速查

| API | 作用 |
|-----|------|
| `VBProject.VBComponents.Add(3)` | 添加 UserForm（3 = vbext_ct_MSForm） |
| `VBComponent.Designer.Controls.Add(...)` | 向窗体添加控件 |
| `VBComponent.CodeModule.AddFromString(...)` | 注入事件代码 |
| `VBProject.VBComponents.Remove(...)` | 删除整个窗体组件 |
| `Application.OnTime(...)` | 延迟执行删除（等窗体卸载） |
