# 四方镜子 - 完整总结

## 一、功能概述

**四方镜子** 是一个多列数据循环组合生成工具，支持两种核心算法和多种输出格式。

### 两种核心算法

| 算法 | 原理 | 结果行数 | 适用场景 |
|------|------|----------|----------|
| **四方循环**（笛卡尔积） | 每列各取一个元素，生成所有排列组合 | 各列行数的 **乘积** | 全排列、实验条件组合、测试用例 |
| **双边循环**（LCM独立循环） | 每列各自独立循环，互不影响 | 各列行数的 **最小公倍数** | 周期对齐、循环填充、批量命名 |

### 八种操作模式

```
┌─────────────────────────────────────────────────┐
│                  四方循环                         │
│  （笛卡尔积：2列×3列 = 6行结果）                   │
├─────────────┬─────────────┬─────────────┬───────┤
│  反向 竖向   │  正向 竖向   │  正向 横向   │ 反向 横向│
│  A1B1       │  A1B1       │ A1B1 A2B1… │       │
│  A1B2       │  A2B1       │             │       │
│  A2B1       │  A1B2       │             │       │
│  A2B2       │  A2B2       │             │       │
└─────────────┴─────────────┴─────────────┴───────┘

┌─────────────────────────────────────────────────┐
│                  双边循环                         │
│  （LCM独立循环：LCM(2,4) = 4行结果）               │
├─────────────────────┬───────────────────────────┤
│    竖向输出          │       横向输出              │
│    A1 B1            │  A1 B1  A2 B2  A1 B3  A2 B4│
│    A2 B2            │                           │
│    A1 B3            │                           │
│    A2 B4            │                           │
└─────────────────────┴───────────────────────────┘
```

每种模式又分为 **合并模式**（用连接符拼成一个字符串）和 **分开模式**（各列独立显示）。

## 三、使用方法

### 方法一：VBA 单模块版（推荐）

**优点**：一个 `.bas` 文件搞定，不需要额外窗体文件，复制粘贴即用。

#### 步骤

1. 打开 Excel / WPS 表格
2. 按 `Alt + F11` 打开VBA编辑器
3. 菜单 → 插入 → 模块
4. 把 `四方镜子_单模块版.bas` 的全部内容粘贴进去
5. 启用"信任对VBA工程对象模型的访问"：
   - 文件 → 选项 → 信任中心 → 信任中心设置 → 宏设置
   - 勾选"信任对VBA工程对象模型的访问"
6. 按 `F5` 运行 `四方镜子_主入口`，或在表格中添加按钮关联此宏

#### 运行效果

- 自动弹出一个"四方镜"窗体
- 输入连接符号（默认 `-`）
- 勾选/取消"合并"切换模式（按钮图示会变化）
- 点击任意按钮执行对应操作
- 执行完毕窗体自动关闭，结果写入工作表

---

### 方法二：JS 单模块版（WPS专用）

**优点**：界面更美观，CSS样式自定义，不需要额外权限设置。

#### 步骤

1. 打开 WPS 表格
2. 开发工具 → WPS宏编辑器
3. 插入模块 → 粘贴 `PC_003_四方镜子_单模块版.js` 的全部内容
4. 运行 `四方镜子_主入口()`

#### 运行流程

```
运行 主入口
    ↓
把内嵌HTML写入临时文件（工作簿目录下）
    ↓
Application.ShowDialog 弹出HTML窗体
    ↓
用户在HTML界面操作 → window.external.Notify 回传参数
    ↓
JS接收回调 → 执行对应算法 → 写入工作表
    ↓
关闭窗体 → 删除临时HTML文件
```

#### 降级方案

如果 `ShowDialog` 不可用（某些WPS版本差异），会自动回退到 `InputBox` 模式，通过连续弹出输入框让用户选择操作。

## 四、底层逻辑详解

### 4.1 核心数学基础

#### 循环索引函数

```
循环索引(序号, 周期长度) = ((序号 + 周期长度 - 1) mod 周期长度) + 1
```

把任意正整数映射到 `[1, 周期长度]` 的循环范围内，就像钟表一样循环。

```
序号:   1  2  3  4  5  6  7  8  9 ...
结果:   1  2  3  1  2  3  1  2  3 ...  (周期=3)
```

#### 向上取整除法

```
向上取整除法(被除数, 除数) = ceil(被除数 / 除数)
```

用于计算"当前是第几个周期"。

---

### 4.2 四方循环（笛卡尔积）算法

#### 问题：给定 M 列数据，每列有 C₁, C₂, ..., Cm 个元素，生成所有排列组合

**总行数** = C₁ × C₂ × ... × Cm （笛卡尔积）

#### 循环步长

每一列有一个"步长"，表示该列经过多少行才变化一次。

**正向循环**（左列最慢，右列最快）：
```
步长[0] = 1                              第1列每行都变
步长[1] = 步长[0] × C₁ = C₁               第2列每 C₁ 行变一次
步长[2] = 步长[1] × C₂ = C₁×C₂            第3列每 C₁×C₂ 行变一次
...
步长[i] = 步长[i-1] × Cᵢ₋₁
```

**反向循环**（左列最快，右列最慢）：
```
步长[i] = 总行数 / (C₁ × C₂ × ... × Cᵢ)
```

#### 源行号计算公式

```
源行号 = 循环索引( 向上取整除法(当前行号, 步长), 该列元素数 )
```

即：
1. 当前行号 ÷ 步长 → 得到"第几个周期"
2. 对元素数取模循环 → 映射到源数据的行号

#### 示例：2列（A列2个, B列3个），正向循环

| 行号 | A列步长=1 | 第几个周期 | ys(周期,2) | A列值 | B列步长=2 | 第几个周期 | ys(周期,3) | B列值 |
|-----|-----------|-----------|------------|-------|-----------|-----------|------------|-------|
| 1 | 1 | 1 | 1 | A1 | 2 | 1 | 1 | B1 |
| 2 | 1 | 2 | 2 | A2 | 2 | 1 | 1 | B1 |
| 3 | 1 | 3 | 1 | A1 | 2 | 2 | 2 | B2 |
| 4 | 1 | 4 | 2 | A2 | 2 | 2 | 2 | B2 |
| 5 | 1 | 5 | 1 | A1 | 2 | 3 | 3 | B3 |
| 6 | 1 | 6 | 2 | A2 | 2 | 3 | 3 | B3 |

---

### 4.3 双边循环（LCM独立循环）算法

#### 问题：每列各自独立循环，总行数 = LCM(各列行数)

每列直接用行号对自身长度取循环：

```
第j列第i行的源行号 = 循环索引(i, 每列元素个数[j])
```

#### 完整循环 vs 残缺循环

- **完整循环**：乘积 = LCM → 各列互质，一个完整周期内所有列都轮完整数遍
- **残缺循环**：乘积 > LCM → 存在公约数，还没等所有列轮完一遍就开始重复了

工作表命名规则：
- 完整循环：`完整_LCM_sheet序号`
- 残缺循环：`残缺_乘积|LCM_sheet序号`

---

### 4.4 数据流向

#### 四方循环数据流

```
读取工作表
    ↓
统计每列行数 → 计算乘积（总行数）→ 超限检查
    ↓
批量读取源数据（一次Range读取，性能最优）
    ↓
计算循环步长数组（正向/反向）
    ↓
构建笛卡尔积矩阵 [列][行]  ← 核心：逐列逐行计算源行号
    ↓
┌─────────────┴──────────────┐
│                             │
横向输出                     竖向输出
│                             │
├─ 合并：按行拼接字符串        ├─ 合并：按行拼接字符串
│   结果：1行 × N列            │   结果：N行 × 1列
│                             │
└─ 分开：直接输出矩阵          └─ 分开：矩阵转置
    结果：M列 × N行                结果：N行 × M列
    ↓
写入工作表（F2起始）
```

#### 双边循环数据流

```
读取工作表 → 统计每列行数 → 计算LCM和乘积 → 超限检查
    ↓
批量读取源数据
    ↓
构建LCM循环矩阵（每列独立循环）
    ↓
新建工作表（"重复字"之后，命名为完整/残缺）
    ↓
根据输出方向和合并模式准备数据
    ↓
写入新工作表（A1起始）
```

---

### 4.5 性能优化点

| 优化手段 | 说明 | 提升幅度 |
|----------|------|----------|
| **批量读取** | 一次性 `Range.Value2` 读取全部数据，而非逐单元格 | 10~100倍 |
| **批量写入** | 构建完整数组后一次性写入 | 10~100倍 |
| **关闭屏幕刷新** | `ScreenUpdating = False` | 2~5倍 |
| **手动计算模式** | `Calculation = xlManual` | 1.5~3倍 |
| **数组操作** | 全部在内存数组中计算，最后才写表 | 5~20倍 |
| **Join拼接** | 用 `Array.join()` 代替字符串累加 | 1.2~2倍 |
| **按列预处理格式** | 整列格式相同的只需判断一次日期格式 | 列数倍 |

### 4.6 动态创建窗体原理

#### VBA 版（动态创建UserForm）

```
VBComponents.Add(3)   → 创建空白窗体（3=vbext_ct_MSForm）
    ↓
Controls.Add("Forms.Label.1")       → 添加标签
Controls.Add("Forms.TextBox.1")     → 添加文本框
Controls.Add("Forms.CheckBox.1")    → 添加复选框
Controls.Add("Forms.CommandButton.1") → 添加按钮
    ↓
CodeModule.AddFromString(代码)     → 注入事件处理代码
    ↓
UserForms.Add(名称).Show           → 显示窗体
    ↓
使用完毕 → VBComponents.Remove     → 删除临时窗体
```

#### JS 版（HTML窗体 + 临时文件）

```
获取内嵌HTML字符串
    ↓
FSO.CreateTextFile → 写入临时HTML文件
    ↓
Application.ShowDialog(临时文件路径) → 弹出对话框
    ↓
window.external.Notify → HTML回调JS
    ↓
关闭后 → FSO.DeleteFile → 删除临时文件
```

## 七、常见问题

### Q: 提示"已超出表格限制"
A: Excel最大行数是1048576。笛卡尔积增长很快，5列各10个元素就是10万行，6列就是100万行。如果列太多或每列元素太多，会超出限制。

### Q: 合并模式下连接符为空会怎样？
A: 连接符为空时，会切换到分开模式（各列独立输出），等价于取消"合并"勾选。

### Q: 双边循环为什么叫"双边"？
A: 原意是"两边各自独立循环"，两列各走各的，只是恰好同时开始同时结束（LCM周期对齐）。扩展到多列也是一样，每列独立循环。

### Q: VBA单模块版提示权限不足
A: 需要在 选项→信任中心→宏设置 中勾选"信任对VBA工程对象模型的访问"。如果无法修改设置，使用传统窗体版即可。

### Q: JS单模块版点击按钮没反应
A: 不同WPS版本的 `ShowDialog` 回调机制可能有差异。代码中已包含降级方案，会自动回退到InputBox模式。
