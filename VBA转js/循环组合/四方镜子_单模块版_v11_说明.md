## 二、四象限镜像对称

### 2.1 核心发现：方向反转 ≠ 左右镜像

用 A1A2 / B3B4B5 / C6C7C8C9（2×3×4=24组）验证后，发现：

| 概念 | 是否真正镜像 | 说明 |
|------|------------|------|
| 方向反转（正↔反） | ❌ 不是 | 只是不同的遍历顺序，不是镜像 |
| 数据反转（上下颠倒） | ✅ 是 | 等价于行顺序反转，真正的上下镜像 |
| **元素反转（列顺序反转）** | ✅ 是 | 每行元素左右翻转，真正的左右镜像 |

### 2.2 真正的四象限镜像

以基准数据为左上，通过两种翻转生成另外三个象限：

| 位置 | 变换方式 | 说明 | 示例（A1B3C6） |
|------|---------|------|--------------|
| 左上 | 原始（基准） | 基准 | A1B3C6 |
| 右上 | 左右镜像 | 每行元素反转（列顺序翻转） | C6B3A1 |
| 左下 | 上下镜像 | 行顺序反转（第1行 ↔ 最后1行） | A2B5C9 |
| 右下 | 中心镜像 | 行反转 + 元素反转 | C9B5A2 |

**对称性验证（全部严格成立）：**
- ✅ 左右对称：右上 = reverse(左上每行)
- ✅ 上下对称：左下 = 左上行反转
- ✅ 中心对称：右下 = 行反转 + 元素反转

### 2.3 4 种基准

四象限开关打开时，点击按钮 1~4 分别生成不同基准的四象限：

| 按钮 | 基准 | 布局 | 说明 |
|------|------|------|------|
| 按钮1 | 反竖 | 竖向 | 左慢右快为基准的竖向四象限 |
| 按钮2 | 正横 | 横向 | 左快右慢为基准的横向四象限 |
| 按钮3 | 正竖 | 竖向 | 左快右慢为基准的竖向四象限 |
| 按钮4 | 反横 | 横向 | 左慢右快为基准的横向四象限 |

布局自动跟随基准：竖按钮 → 竖四象限，横按钮 → 横四象限。

## 三、两种布局对比

### 3.1 竖向布局（按钮1、按钮3）

组合**竖向排列**（一列一组），四象限按 2×2 摆放：

```
┌───────────────┬───────────────┐
│【原始】       │【左右镜像】   │
│ A1-B3-C6      │ C6-B3-A1      │
│ A2-B3-C6      │ C6-B3-A2      │
│ A1-B4-C6      │ C6-B4-A1      │
│ ...           │ ...           │
├───────────────┼───────────────┤
│【上下镜像】   │【中心镜像】   │
│ A2-B5-C9      │ C9-B5-A2      │
│ A1-B5-C9      │ C9-B5-A1      │
│ A2-B4-C9      │ C9-B4-A2      │
│ ...           │ ...           │
└───────────────┴───────────────┘
```

特点：每个组合占 1 行，适合**列数少、行数多**的数据。

### 3.2 横向布局（按钮2、按钮4）

组合**横向排列**（每列一个组合，元素向下延伸），四象限按 2×2 摆放。

**合并模式**（每个组合1个单元格，横向排列）：
```
┌──────────────────────────────────────────┐
│【原始】         │【左右镜像】             │
│ A1B3C6 A2B3C6… │ C6B3A1 C6B3A2…         │
├────────────────┼─────────────────────────┤
│【上下镜像】     │【中心镜像】             │
│ A2B5C9 A1B5C9… │ C9B5A2 C9B5A1…         │
└────────────────┴─────────────────────────┘
```

**分开模式**（每列一个组合，元素从上往下读，3列元素 × 24列组合 = 3行 × 24列 = 72格）：
```
每象限：3行 × 24列 = 72个单元格

  组1  组2  组3  ...  组24
  A1   A2   A1   ...  A2    ← 第1列元素
  B3   B3   B4   ...  B5    ← 第2列元素
  C6   C6   C6   ...  C9    ← 第3列元素
```

### 3.3 布局尺寸（M=组合数，K=列数）

| 模式 | 竖向布局（每象限） | 横向布局（每象限） |
|------|------------------|------------------|
| 合并 | M 行 × 1 列 | 1 行 × M 列 |
| 分开 | M 行 × K 列 | K 行 × M 列 |

例：3 列 × 24 组合 = 24 组
- 竖合：24 行 × 1 列 = 24 格
- 横合：1 行 × 24 列 = 24 格
- 竖分：24 行 × 3 列 = 72 格
- **横分：3 行 × 24 列 = 72 格** ✅

四象限整体尺寸 = 每象限 × 2 + 分隔（空行/空列）+ 标签行

## 四、使用方法

### 4.1 基本操作

1. 将 `四方镜子_单模块版_v11.bas` 导入 Excel VBA 工程
2. 运行 `四方镜子()` 宏
3. 勾选/取消顶部开关：
   - **合并**：组合元素合并成一列 vs 多列分开
   - **数据反转**：每列数据从下往上读取
   - **四象限对称**：按钮1~4生成四象限 vs 单表
4. 点击对应按钮生成结果

### 4.2 四象限使用技巧

- 想看竖向四象限 → 点按钮1（反竖基准）或按钮3（正竖基准）
- 想看横向四象限 → 点按钮2（正横基准）或按钮4（反横基准）
- 正竖 vs 反竖的区别：生成顺序不同（左快右慢 vs 左慢右快），但镜像关系相同
- 4 种基准生成的表名不同（四象限_正竖_…、四象限_反横_… 等），不会互相覆盖

### 4.3 如何选择竖版还是横版

| 数据特征 | 推荐 | 原因 |
|---------|------|------|
| 2列各3行（2×3=6组合） | 竖版 | 6行少，竖版紧凑 |
| 3列各2行（3×2=6组合） | 横版 | 6列少，横版紧凑 |
| 行数 < 列数 | 横版 | 行数少，横排更直观 |
| 行数 > 列数 | 竖版 | 列数少，竖排更直观 |

简单说：**数据瘦高用竖版，数据矮胖用横版**。

## 五、备选算法（按钮7）

7 种算法在同一张表中对比输出，方便验证结果一致性：

| 代号 | 算法 | 说明 |
|------|------|------|
| A | 进位计数法 | mixed-radix odometer，经典笛卡尔积实现 |
| B | 回溯法 DFS | 递归生成，易于添加约束条件 |
| C | 随机抽样 | Fisher-Yates 洗牌，随机顺序输出 |
| D | LCM双边循环 | 各列独立循环，总数=LCM |
| E | 逐列扩展法 | 一列一列加入，每列复制已有结果 |
| F | 格雷码遍历 | 相邻组合仅一列变化 |
| G | 混合进制随机访问 | 直接计算第k个组合，无需遍历 |

### 核心认知迭代

- **v10/v11**：四象限 = 方向反转 + 数据反转（错误地把方向反转当镜像）
- **v11.4**：增加基准方向选择（在错误的方向上走得更远）
- **v11.5 初版**：4 基础元素 × 4 位置 = 16 样式（还是方向反转的思路）
- **v11.5 优化**：方向反转不是镜像！真正的左右镜像 = 元素反转，上下镜像 = 行反转
- **v11.5 最终**：四象限开关绑定到四方循环按钮，界面最简洁

**最简结论**：四象限 = 原始 + 左右镜像（元素反转）+ 上下镜像（行反转）+ 中心镜像（双反转），严格对称，简洁直观。
