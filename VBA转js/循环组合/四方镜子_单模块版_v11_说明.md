# 四方镜子 - v11 版本说明：四象限横竖双版

> v11 在 v10 基础上**新增"四象限对称·横"**，现有功能完全不变。按钮8 竖向版 + 按钮9 横向版，两种四象限对称方式都有。原有单表生成功能全部保留。

## 二、两种四象限对比

### 2.1 四象限·竖（按钮8，紫色）

组合**竖向排列**（一列一组），四象限左右并排：

```
┌───────────────┬───────────────┐
│【左上 正竖】  │【右上 反竖】  │
│ A1-B1         │ A1-B1         │
│ A2-B1         │ A1-B2         │
│ A1-B2         │ A1-B3         │
│ A2-B2         │ A2-B1         │
│ ...           │ ...           │
├───────────────┼───────────────┤
│【左下 正竖+反转】│【右下 反竖+反转】│
│ A2-B3         │ A2-B3         │
│ A1-B3         │ A2-B2         │
│ A2-B2         │ A2-B1         │
│ A1-B2         │ A1-B3         │
│ ...           │ ...           │
└───────────────┴───────────────┘
```

**特点**：
- 每个组合占 1 行（合并模式）或 K 行（分开模式）
- 左右两列并排，中间空 1 列分隔
- 上下两部分堆叠，中间空 1 行分隔
- 适合**列数少、行数多**的数据
- 阅读方向：从上往下读组合

### 2.2 四象限·横（按钮9，橙色）

组合**横向排列**（一行一组），四象限上下堆叠：

```
┌───────────────────────────────────────────────────────┐
│ 【左上 正横】            │ 【右上 反横】               │
│ A1-B1  A2-B1  A1-B2 ... │ A1-B1  A1-B2  A1-B3 ...   │
├───────────────────────────────────────────────────────┤
│ 【左下 正横+反转】       │ 【右下 反横+反转】          │
│ A2-B3  A1-B3  A2-B2 ... │ A2-B3  A2-B2  A2-B1 ...   │
└───────────────────────────────────────────────────────┘
```

**特点**：
- 每个组合占 1 列（合并模式）或 K 列（分开模式）
- 上下两行堆叠，中间空 1 行分隔
- 左右两部分并排，中间空 1 列分隔
- 适合**行数少、列数多**的数据
- 阅读方向：从左往右读组合

### 2.3 对比总结

| 维度 | 四象限·竖（按钮8） | 四象限·横（按钮9） |
|------|-------------------|-------------------|
| 组合排列方向 | 竖向（一列一个） | 横向（一行一个） |
| 对应单表按钮 | 正竖 / 反竖 | 正横 / 反横 |
| 象限分隔 | 左右空1列 / 上下空1行 | 左右空1列 / 上下空1行 |
| 适用场景 | 列数少、行数多，纵向阅读 | 行数少、列数多，横向阅读 |
| 对称关系 | 完全相同（上下+左右+中心） | 完全相同（上下+左右+中心） |
| 按钮颜色 | 紫色 | 橙色 |

## 三、对称关系（横竖都一样）

两种四象限的对称逻辑完全一致，只是排列方向不同：

| 对称类型 | 两象限 | 实现方式 |
|---------|--------|---------|
| **左右对称** | 左上 ↔ 右上 | 正向 ↔ 反向（列方向反转） |
| **上下对称** | 左上 ↔ 左下 | 正常数据 ↔ 反转数据（行序颠倒） |
| **中心对称** | 左上 ↔ 右下 | 正向+正常 ↔ 反向+反转（双反转=还原） |

**验证方法**：
- 2×2 数据的四个角，值都是同一个组合（中心对称）
- 左上第 i 行 ↔ 右上第 i 行：左右镜像
- 左上第 i 行 ↔ 左下第 M-i+1 行：上下镜像

## 四、布局细节

### 4.1 合并模式

| 版本 | 行 | 列 |
|------|---|---|
| 竖向版 | 2M+3 行（标签+M行+空+标签+M行） | 3 列（左+空+右） |
| 横向版 | 5 行（标签+行+空+标签+行） | 2M+3 列（左M+空+右M） |

### 4.2 分开模式

| 版本 | 行 | 列 |
|------|---|---|
| 竖向版 | 2M+3 行 | 2K+1 列（左K+空+右K） |
| 横向版 | 5 行 | 2MK+K+2 列（左MK+空+右MK） |

注：M = 组合总数（各列行数乘积），K = 列数

象限之间都留有空行/空列作为分隔，每个象限上方有标签说明。

## 五、使用方法

### 5.1 基本操作

1. 将 `四方镜子_单模块版_v11.bas` 导入 Excel VBA 工程
2. 运行 `四方镜子()` 宏
3. 在窗体底部找到两个四象限按钮：
   - **四象限对称·竖**（紫色，左下）— 组合竖向排列
   - **四象限对称·横**（橙色，右下）— 组合横向排列
4. 点击对应按钮生成结果

### 5.2 如何选择竖版还是横版

| 数据特征 | 推荐 | 原因 |
|---------|------|------|
| 2列各3行（2×3=6组合） | 竖版 | 6行少，竖版紧凑 |
| 3列各2行（3×2=6组合） | 横版 | 6列少，横版紧凑 |
| 行数 < 列数 | 横版 | 行数少，横排更直观 |
| 行数 > 列数 | 竖版 | 列数少，竖排更直观 |
| 行数 ≈ 列数 | 都可以 | 看个人习惯 |

简单说：**数据瘦高用竖版，数据矮胖用横版**。

### 6.4 修复与优化（v11.1）

**修复：重复定义变量**
- `四象限_执行` 函数中，`列 As Long` 被声明了两次（第1次在函数开头与 `总列数` 一起声明，第2次在写入前与 `行` 一起声明）
- VBA 同一过程内同名变量不能重复 Dim，会导致编译错误
- 修复方式：保留函数开头的一次声明，删除第二次重复声明

**优化：四象限对称关系说明**

正横/反横分开模式与四象限的对称关系：

| 对称类型 | 实现方式 | 象限对应 |
|---------|---------|---------|
| 左右对称 | 正向 ↔ 反向（步长方向反转） | 左上 ↔ 右上 |
| 上下对称 | 正常数据 ↔ 反转数据（每列行序颠倒） | 左上 ↔ 左下 |
| 中心对称 | 正向+正常 ↔ 反向+反转（双反转） | 左上 ↔ 右下 |

- **正横分开 vs 反横分开**：组合顺序不同（左快右慢 vs 右快左慢），构成左右对称
- **正横分开 vs 正横分开+数据反转**：每个元素值上下颠倒，构成上下对称
- 四象限同时利用以上两种对称，生成 2×2 = 4 个象限，整体上下左右都对称
