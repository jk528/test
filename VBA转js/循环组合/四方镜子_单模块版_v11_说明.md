# 四方镜子 - v11.5 版本说明：四象限 = 四元模型

> v11.5 重构：四象限从多个按钮简化为 **一个按钮**。四个象限正好对应 1234 四个按钮（正竖、反竖、正横、反横），2×2=4 元模型，一目了然。

---

## 一、v11 新增了什么

| 对比项 | v10 | v11 |
|--------|-----|-----|
| 四方循环 4 按钮（正/反 × 横/竖） | ✅ | ✅ **不变** |
| 双边循环 2 按钮（横/竖） | ✅ | ✅ **不变** |
| 备选算法验证（7种：A/B/C/D/E/F/G） | ✅ | ✅ **不变** |
| 数据反转开关 | ✅ | ✅ **不变** |
| 按钮8 四象限对称·竖 | ✅ | ✅ **不变**（改名加"·竖"后缀） |

**核心原则**：v11 = v10（原样）+ 四象限横向版（新增）。所有原有功能零改动。

## 二、两种四象限对比

### 2.1 四象限·竖（按钮8，紫色）

组合**竖向排列**（一列一组），四象限左右并排：

```
┌───────────────┬───────────────┐
│【左上 正竖】  │【右上 反竖】  │
│ A1-B1         │ A1-B1         │
│ A2-B1         │ A1-B2         │
│ A1-B2         │ A1-B3         │
│ A2-B2         │ A2-B1         │
│ ...           │ ...           │
├───────────────┼───────────────┤
│【左下 正竖+反转】│【右下 反竖+反转】│
│ A2-B3         │ A2-B3         │
│ A1-B3         │ A2-B2         │
│ A2-B2         │ A2-B1         │
│ A1-B2         │ A1-B3         │
│ ...           │ ...           │
└───────────────┴───────────────┘
```

**特点**：
- 每个组合占 1 行（合并模式）或 K 行（分开模式）
- 左右两列并排，中间空 1 列分隔
- 上下两部分堆叠，中间空 1 行分隔
- 适合**列数少、行数多**的数据
- 阅读方向：从上往下读组合

### 2.2 四象限·横（按钮9，橙色）

组合**横向排列**（一行一组），四象限上下堆叠：

```
┌───────────────────────────────────────────────────────┐
│ 【左上 正横】            │ 【右上 反横】               │
│ A1-B1  A2-B1  A1-B2 ... │ A1-B1  A1-B2  A1-B3 ...   │
├───────────────────────────────────────────────────────┤
│ 【左下 正横+反转】       │ 【右下 反横+反转】          │
│ A2-B3  A1-B3  A2-B2 ... │ A2-B3  A2-B2  A2-B1 ...   │
└───────────────────────────────────────────────────────┘
```

**特点**：
- 每个组合占 1 列（合并模式）或 K 列（分开模式）
- 上下两行堆叠，中间空 1 行分隔
- 左右两部分并排，中间空 1 列分隔
- 适合**行数少、列数多**的数据
- 阅读方向：从左往右读组合

### 2.3 对比总结

| 维度 | 四象限·竖（按钮8） | 四象限·横（按钮9） |
|------|-------------------|-------------------|
| 组合排列方向 | 竖向（一列一个） | 横向（一行一个） |
| 对应单表按钮 | 正竖 / 反竖 | 正横 / 反横 |
| 象限分隔 | 左右空1列 / 上下空1行 | 左右空1列 / 上下空1行 |
| 适用场景 | 列数少、行数多，纵向阅读 | 行数少、列数多，横向阅读 |
| 对称关系 | 完全相同（上下+左右+中心） | 完全相同（上下+左右+中心） |
| 按钮颜色 | 紫色 | 橙色 |

## 三、对称关系（横竖都一样）

两种四象限的对称逻辑完全一致，只是排列方向不同：

| 对称类型 | 两象限 | 实现方式 |
|---------|--------|---------|
| **左右对称** | 左上 ↔ 右上 | 正向 ↔ 反向（列方向反转） |
| **上下对称** | 左上 ↔ 左下 | 正常数据 ↔ 反转数据（行序颠倒） |
| **中心对称** | 左上 ↔ 右下 | 正向+正常 ↔ 反向+反转（双反转=还原） |

**验证方法**：
- 2×2 数据的四个角，值都是同一个组合（中心对称）
- 左上第 i 行 ↔ 右上第 i 行：左右镜像
- 左上第 i 行 ↔ 左下第 M-i+1 行：上下镜像

## 四、布局细节

### 4.1 合并模式

| 版本 | 行 | 列 |
|------|---|---|
| 竖向版 | 2M+3 行（标签+M行+空+标签+M行） | 3 列（左+空+右） |
| 横向版 | 5 行（标签+行+空+标签+行） | 2M+3 列（左M+空+右M） |

### 4.2 分开模式

| 版本 | 行 | 列 |
|------|---|---|
| 竖向版 | 2M+3 行 | 2K+1 列（左K+空+右K） |
| 横向版 | 5 行 | 2MK+K+2 列（左MK+空+右MK） |

注：M = 组合总数（各列行数乘积），K = 列数

象限之间都留有空行/空列作为分隔，每个象限上方有标签说明。

## 五、使用方法

### 5.1 基本操作

1. 将 `四方镜子_单模块版_v11.bas` 导入 Excel VBA 工程
2. 运行 `四方镜子()` 宏
3. 在窗体底部找到两个四象限按钮：
   - **四象限对称·竖**（紫色，左下）— 组合竖向排列
   - **四象限对称·横**（橙色，右下）— 组合横向排列
4. 点击对应按钮生成结果

### 5.2 如何选择竖版还是横版

| 数据特征 | 推荐 | 原因 |
|---------|------|------|
| 2列各3行（2×3=6组合） | 竖版 | 6行少，竖版紧凑 |
| 3列各2行（3×2=6组合） | 横版 | 6列少，横版紧凑 |
| 行数 < 列数 | 横版 | 行数少，横排更直观 |
| 行数 > 列数 | 竖版 | 列数少，竖排更直观 |
| 行数 ≈ 列数 | 都可以 | 看个人习惯 |

简单说：**数据瘦高用竖版，数据矮胖用横版**。

## 六、v11.5 改动清单

### 6.1 核心概念：4 基础元素 × 4 对称位置 = 16 样式

**每个按钮对应一个基础元素，四象限就是把一个元素放在左上，然后通过上下左右对称生成另外三个位置。**

4 个基础元素（按钮 1~4）：正竖、反竖、正横、反横
4 个对称位置：左上（基准）、右上（左右镜像）、左下（上下镜像）、右下（中心镜像）

4 × 4 = **16 种样式排列**，全部满足上下左右对称。

### 6.2 对称变换规则

| 布局 | 左右镜像 | 上下镜像 | 中心镜像 |
|------|---------|---------|---------|
| 竖向 | 方向反转（正↔反） | 数据反转（上下颠倒） | 方向+数据双反转 |
| 横向 | 数据反转（左右颠倒） | 方向反转（正↔反） | 方向+数据双反转 |

### 6.3 四种基准 × 四种四象限

选择不同的基准元素，得到不同的对称四象限：

| 基准 | 左上 | 右上 | 左下 | 右下 | 布局 |
|------|------|------|------|------|------|
| **正竖** | 正竖 | 反竖 | 正竖+反转 | 反竖+反转 | 竖向 |
| **反竖** | 反竖 | 正竖 | 反竖+反转 | 正竖+反转 | 竖向 |
| **正横** | 正横 | 正横+反转 | 反横 | 反横+反转 | 横向 |
| **反横** | 反横 | 反横+反转 | 正横 | 正横+反转 | 横向 |

- 选正竖或反竖 → 四象限统一**竖向**布局
- 选正横或反横 → 四象限统一**横向**布局
- 所有四象限都严格满足：左右对称 + 上下对称 + 中心对称

### 6.4 界面说明

**界面结构：** 一个框架 + 4 个单选按钮（选基准） + 1 个生成按钮

```
┌─ 四象限（选择基准元素） ────────────────┐
│ ○正竖  ○反竖  ○正横  ○反横   [生成四象限] │
└───────────────────────────────────────┘
```

- 默认选中「正竖」
- 按钮 1~7 功能完全不变

### 6.5 历史演进回顾

| 版本 | 四象限方式 | 交互方式 | 按钮数 |
|------|-----------|---------|-------|
| v10 | 仅竖向对称版 | 1个按钮 | 8 |
| v11.0 | 竖/横各一种对称 | 2个按钮 | 9 |
| v11.4 | 两种基准 × 两种布局 | 4个按钮 | 11 |
| **v11.5** | **4基准 × 4位置 = 16样式** | **4选1 + 生成按钮** | **8** |

**核心认知迭代：**
- v10/v11：四象限 = 一种布局的对称展示
- v11.4：四象限 = 2种基准 × 2种布局 = 4个按钮
- **v11.5：4个基础元素，每个都可以作为基准生成对称四象限，共 16 种样式**

最简结论：**4 元素 × 4 位置 = 16 样式，全部上下左右对称。**

### 6.6 横向分开模式修复（v11.3 遗留）

修正前的错误写法：每个组合占 K 列（横排），M 个组合从左到右排开 → 视觉上是"男男男"（元素横排）

修正后的正确写法：每个组合占 1 列 K 行（竖排），M 个组合从左到右排开 → 视觉上是"男/男/男"（元素竖排）

| 模式 | 每组合占 | 总尺寸（上半） | 示例（2列, 6组合） |
|------|---------|-------------|-----------------|
| 修正前（错误） | K 列 × 1 行 | 1 行 × M*K 列 | `男男男男男男` 一行横排 |
| 修正后（正确） | 1 列 × K 行 | K 行 × M 列 | 两行，每行6个，从上往下读组合 |

与单表「正横分开」按钮的输出格式保持一致。
