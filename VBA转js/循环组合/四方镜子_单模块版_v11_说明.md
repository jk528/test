## 二、两种四象限对比

### 2.1 四象限·竖（按钮8，紫色）

组合**竖向排列**（一列一组），四象限左右并排：

```
┌───────────────┬───────────────┐
│【左上 正竖】  │【右上 反竖】  │
│ A1-B1         │ A1-B1         │
│ A2-B1         │ A1-B2         │
│ A1-B2         │ A1-B3         │
│ A2-B2         │ A2-B1         │
│ ...           │ ...           │
├───────────────┼───────────────┤
│【左下 正竖+反转】│【右下 反竖+反转】│
│ A2-B3         │ A2-B3         │
│ A1-B3         │ A2-B2         │
│ A2-B2         │ A2-B1         │
│ A1-B2         │ A1-B3         │
│ ...           │ ...           │
└───────────────┴───────────────┘
```

**特点**：
- 每个组合占 1 行（合并模式）或 K 行（分开模式）
- 左右两列并排，中间空 1 列分隔
- 上下两部分堆叠，中间空 1 行分隔
- 适合**列数少、行数多**的数据
- 阅读方向：从上往下读组合

### 2.2 四象限·横（按钮9，橙色）

组合**横向排列**（一行一组），四象限上下堆叠：

```
┌───────────────────────────────────────────────────────┐
│ 【左上 正横】            │ 【右上 反横】               │
│ A1-B1  A2-B1  A1-B2 ... │ A1-B1  A1-B2  A1-B3 ...   │
├───────────────────────────────────────────────────────┤
│ 【左下 正横+反转】       │ 【右下 反横+反转】          │
│ A2-B3  A1-B3  A2-B2 ... │ A2-B3  A2-B2  A2-B1 ...   │
└───────────────────────────────────────────────────────┘
```

**特点**：
- 每个组合占 1 列（合并模式）或 K 列（分开模式）
- 上下两行堆叠，中间空 1 行分隔
- 左右两部分并排，中间空 1 列分隔
- 适合**行数少、列数多**的数据
- 阅读方向：从左往右读组合

### 2.3 对比总结

| 维度 | 四象限·竖（按钮8） | 四象限·横（按钮9） |
|------|-------------------|-------------------|
| 组合排列方向 | 竖向（一列一个） | 横向（一行一个） |
| 对应单表按钮 | 正竖 / 反竖 | 正横 / 反横 |
| 象限分隔 | 左右空1列 / 上下空1行 | 左右空1列 / 上下空1行 |
| 适用场景 | 列数少、行数多，纵向阅读 | 行数少、列数多，横向阅读 |
| 对称关系 | 完全相同（上下+左右+中心） | 完全相同（上下+左右+中心） |
| 按钮颜色 | 紫色 | 橙色 |

## 三、对称关系（横竖都一样）

两种四象限的对称逻辑完全一致，只是排列方向不同：

| 对称类型 | 两象限 | 实现方式 |
|---------|--------|---------|
| **左右对称** | 左上 ↔ 右上 | 正向 ↔ 反向（列方向反转） |
| **上下对称** | 左上 ↔ 左下 | 正常数据 ↔ 反转数据（行序颠倒） |
| **中心对称** | 左上 ↔ 右下 | 正向+正常 ↔ 反向+反转（双反转=还原） |

**验证方法**：
- 2×2 数据的四个角，值都是同一个组合（中心对称）
- 左上第 i 行 ↔ 右上第 i 行：左右镜像
- 左上第 i 行 ↔ 左下第 M-i+1 行：上下镜像

## 五、使用方法

### 5.1 基本操作

1. 将 `四方镜子_单模块版_v11.bas` 导入 Excel VBA 工程
2. 运行 `四方镜子()` 宏
3. 在窗体底部找到两个四象限按钮：
   - **四象限对称·竖**（紫色，左下）— 组合竖向排列
   - **四象限对称·横**（橙色，右下）— 组合横向排列
4. 点击对应按钮生成结果

### 5.2 如何选择竖版还是横版

| 数据特征 | 推荐 | 原因 |
|---------|------|------|
| 2列各3行（2×3=6组合） | 竖版 | 6行少，竖版紧凑 |
| 3列各2行（3×2=6组合） | 横版 | 6列少，横版紧凑 |
| 行数 < 列数 | 横版 | 行数少，横排更直观 |
| 行数 > 列数 | 竖版 | 列数少，竖排更直观 |
| 行数 ≈ 列数 | 都可以 | 看个人习惯 |

简单说：**数据瘦高用竖版，数据矮胖用横版**。

### 6.4 四象限映射关系（核心总结 + 演进过程）

#### 核心结论（一句话记住）

> **竖反转 = 上下颠倒，横反转 = 左右颠倒**

这是理解四象限对称的关键。同样是"数据反转"，在竖向和横向布局中产生的镜像方向不同：

| 布局 | 方向反转的效果 | 数据反转的效果 | 四象限基准 |
|------|-------------|-------------|-----------|
| 竖向 | 左右镜像 | 上下镜像（上下颠倒） | 正竖（正向） |
| 横向 | 上下镜像 | 左右镜像（左右颠倒） | 反横（反向） |

**为什么横竖基准不同？**

四象限需要"左上为基准、右上=左右镜像、左下=上下镜像"的标准布局。

- 竖向布局中，**数据反转=上下镜像**，所以基准用正竖（正向），左下 = 正竖+反转
- 横向布局中，**数据反转=左右镜像**，方向反转才是上下镜像，所以基准用反横（反向），左下 = 正横（方向反转）

#### 演进过程：

| 版本 | 基准 | 问题 |
|------|------|------|
| v10 / v11.0 | 反向为基准（横竖统一） | 基准不符合直觉 |
| v11.4 | 正向为基准（横竖统一） | 横向四象限不对，正横/反横的上下对称关系搞反了 |
| **v11.5** | **竖=正向基准，横=反向基准** | **正确** |

**关键认知：竖和横的四象限基准不同！**

正竖与反竖是**左右对称**（方向反转=列方向交换），正竖与正竖反转是**上下对称**（数据反转=行方向颠倒）。

正横与反横是**上下对称**（方向反转=行方向交换），反横与反横反转是**左右对称**（数据反转=列方向交换）。

因此两种四象限的映射关系完全不同：

#### 竖向四象限（基准 = 正竖 = 正向）

| 象限 | 内容 | 对称关系 |
|------|------|---------|
| 左上 Q1 | 正（正常数据） | 基准 |
| 右上 Q2 | 反（正常数据） | 左右镜像（方向反转） |
| 左下 Q3 | 正（反转数据） | 上下镜像（数据反转） |
| 右下 Q4 | 反（反转数据） | 中心镜像（方向+数据双反转） |

- 左右对称：正 ↔ 反（方向反转）
- 上下对称：正 ↔ 正+反转（数据反转）
- 中心对称：正 ↔ 反+反转（双反转）

### 6.5 两种元模型 × 四种四象限按钮（v11.5）

**核心洞察：里面快和外面快是两种元模型**

四象限的基准方向（左快=里快 / 右快=外快）决定了整个四象限的"元模型"。同一套数据，选择不同基准，得到的是完全不同的对称体系。

**四个四象限按钮：**

| 按钮 | 布局 | 基准方向 | 元模型 |
|------|------|---------|-------|
| 四象限竖·左快 | 竖向 | 正向基准（左快右慢） | 里快模型 |
| 四象限竖·右快 | 竖向 | 反向基准（右快左慢） | 外快模型 |
| 四象限横·左快 | 横向 | 正向基准（左快右慢） | 里快模型 |
| 四象限横·右快 | 横向 | 反向基准（右快左慢） | 外快模型 |

#### 正向基准（左快右慢 = 里快）

**竖向四象限（基准 = 正竖 = 正向）**

| 象限 | 内容 | 对称关系 |
|------|------|---------|
| 左上 Q1 | 正（正常数据） | 基准 |
| 右上 Q2 | 反（正常数据） | 左右镜像（方向反转） |
| 左下 Q3 | 正（反转数据） | 上下镜像（数据反转） |
| 右下 Q4 | 反（反转数据） | 中心镜像（方向+数据双反转） |

- 左右对称：正 ↔ 反（方向反转）
- 上下对称：正 ↔ 正+反转（数据反转）
- 中心对称：正 ↔ 反+反转（双反转）

**横向四象限（基准 = 反横 = 反向）**

| 象限 | 内容 | 对称关系 |
|------|------|---------|
| 左上 Q1 | 反（正常数据） | 基准 |
| 右上 Q2 | 正（反转数据） | 左右镜像（方向+数据双反转） |
| 左下 Q3 | 正（正常数据） | 上下镜像（方向反转） |
| 右下 Q4 | 反（反转数据） | 中心镜像（数据反转） |

- 左右对称：反 ↔ 正+反转（双反转）
- 上下对称：反 ↔ 正（方向反转）
- 中心对称：反 ↔ 反+反转（数据反转）

#### 反向基准（右快左慢 = 外快）

基准方向翻转后，四象限的"正/反"标签整体互换，对称关系保持不变。

**竖向四象限（基准 = 反竖 = 反向）**

| 象限 | 内容 | 对称关系 |
|------|------|---------|
| 左上 Q1 | 反（正常数据） | 基准 |
| 右上 Q2 | 正（正常数据） | 左右镜像（方向反转） |
| 左下 Q3 | 反（反转数据） | 上下镜像（数据反转） |
| 右下 Q4 | 正（反转数据） | 中心镜像（方向+数据双反转） |

**横向四象限（基准 = 正横 = 正向）**

| 象限 | 内容 | 对称关系 |
|------|------|---------|
| 左上 Q1 | 正（正常数据） | 基准 |
| 右上 Q2 | 反（反转数据） | 左右镜像（方向+数据双反转） |
| 左下 Q3 | 反（正常数据） | 上下镜像（方向反转） |
| 右下 Q4 | 正（反转数据） | 中心镜像（数据反转） |

**数据反转开关的接入方式：**
- 四象限的对称关系是**内在固定的**，不受外部开关影响
- 数据反转开关：四个象限位置不变，各自内容整体上下翻转（源数据和反转数据互换）

**动态标签生成：**
- 每个象限的标签由 `象限标签(方向, 是否反转, 正名, 反名)` 函数动态生成
- 标签内容反映该象限的实际方向（正/反）和数据状态（正常/反转）
- 确保无论选择哪种基准，标签都与数据一致

### 6.6 横向四象限·分开模式修复（v11.3）

修正前的错误写法：每个组合占 K 列（横排），M 个组合从左到右排开 → 视觉上是"男男男"（元素横排）

修正后的正确写法：每个组合占 1 列 K 行（竖排），M 个组合从左到右排开 → 视觉上是"男/男/男"（元素竖排）

| 模式 | 每组合占 | 总尺寸（上半） | 示例（2列, 6组合） |
|------|---------|-------------|-----------------|
| 修正前（错误） | K 列 × 1 行 | 1 行 × M*K 列 | `男男男男男男` 一行横排 |
| 修正后（正确） | 1 列 × K 行 | K 行 × M 列 | 两行，每行6个，从上往下读组合 |

与单表「正横分开」按钮的输出格式保持一致。

### 6.7 变量声明统一化（v11.2）

**问题**：`四象限_执行` 函数中，`列`、`每列行数`、`Q1/Q2/Q3/Q4`、`正名/反名` 等变量在不同分支重复 `Dim` 声明，导致编译错误。

**修复方式**：把四象限函数的所有变量（共30+个）统一在函数开头集中声明，按用途分组注释：
- 基础变量：ws、总列数、列、行、每列行数、总行数、源数据
- 反转相关：反转数据、r、反转行
- 四象限核心：Q1/Q2/Q3/Q4、正名/反名/横竖名、合并名、反转后缀、新表
- 竖向合并/分开用：左列、右列、片段、每象限列数、右起始列、下起始行
- 横向合并/分开用：上左横/上右横/下左横/下右横、片段横、列索引、右起始列横、每组合行数、右起始列横2、下起始行横、ci、ri

分支内只保留 `ReDim`（用于重定维），不再重复 `Dim`。
