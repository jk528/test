## 二、四象限对称是什么

### 2.1 布局结构

一张结果表中同时放 4 组组合，形成 2×2 的四象限布局：

```
┌─────────────────┬─────────────────┐
│  【左上 正竖】   │  【右上 反竖】   │
│  左快右慢       │  右快左慢       │
│  （原始数据）   │  （原始数据）   │
│                 │                 │
│  A1-B1          │  A1-B1          │
│  A2-B1          │  A1-B2          │
│  A1-B2          │  A1-B3          │
│  A2-B2          │  A2-B1          │
│  ...            │  ...            │
├─────────────────┼─────────────────┤
│  【左下 正竖+反转】│ 【右下 反竖+反转】│
│  左快右慢       │  右快左慢       │
│  （反转数据）   │  （反转数据）   │
│                 │                 │
│  A2-B3          │  A2-B3          │
│  A1-B3          │  A2-B2          │
│  A2-B2          │  A2-B1          │
│  A1-B2          │  A1-B3          │
│  ...            │  ...            │
└─────────────────┴─────────────────┘
```

### 2.2 对称关系

| 对称类型 | 两象限 | 对称方式 |
|---------|--------|---------|
| **左右对称** | 左上 ↔ 右上 | 正竖 ↔ 反竖（列序方向反转） |
| **上下对称** | 左上 ↔ 左下 | 正常数据 ↔ 反转数据（每行内容上下颠倒） |
| **中心对称** | 左上 ↔ 右下 | 正竖+正常 ↔ 反竖+反转（双反转） |
| **左右对称** | 左下 ↔ 右下 | 正竖+反转 ↔ 反竖+反转 |
| **上下对称** | 右上 ↔ 右下 | 反竖+正常 ↔ 反竖+反转 |

整体效果：**上下对称 + 左右对称 + 中心对称**，四象限拼在一起是一个完整的对称图案。

### 2.3 以 2×2 数据为例

源数据：
```
A列  B列
 A    1
 B    2
```

**四象限输出（合并模式，正向）：**

| 行 | 左上（A列） | 空 | 右上（C列） | 说明 |
|----|-----------|---|-----------|------|
| 1 | 【左上 正竖】 | | 【右上 反竖】 | 标签行 |
| 2 | A-1 | | A-1 | |
| 3 | B-1 | | A-2 | |
| 4 | A-2 | | B-1 | |
| 5 | B-2 | | B-2 | |
| 6 | （空行） | | （空行） | 分隔行 |
| 7 | 【左下 正竖+反转】 | | 【右下 反竖+反转】 | 标签行 |
| 8 | B-2 | | B-2 | |
| 9 | A-2 | | B-1 | |
| 10 | B-1 | | A-2 | |
| 11 | A-1 | | A-1 | |

观察对称：
- 左右：左上第2行 `A-1` ↔ 右上第2行 `A-1`；左上第3行 `B-1` ↔ 右上第5行 `B-1`
- 上下：左上第2行 `A-1` ↔ 左下第11行 `A-1`；左上第3行 `B-1` ↔ 左下第10行 `B-1`

## 三、两种模式：单表 vs 四象限

| 维度 | 单表生成（按钮1~6） | 四象限生成（按钮8） |
|------|-------------------|-------------------|
| 结果数量 | 1 张表，1 组数据 | 1 张表，4 组数据（四象限） |
| 适用场景 | 单独验证某一方向 | 整体对称效果预览 / 四方镜实际使用 |
| 合并模式 | 1 列 | 2 列（中间空1列分隔） |
| 分开模式 | K 列 | 2K+1 列（中间空1列分隔） |
| 行数 | M 行 | 2M+2 行（上下各M行，中间空1行+标签） |
| 方向可选 | 正/反 × 横/竖（4种） | 四象限同时包含正竖+反竖 |
| 数据反转 | 全局开关控制 | 内部自动同时生成正常+反转 |

**什么时候用单表？**
- 只需要某一个方向的结果
- 要对结果做进一步处理（筛选、排序等）
- 数据量很大，四象限装不下

**什么时候用四象限？**
- 做四方镜对称图案，需要一眼看到整体效果
- 对比正/反、正常/反转的差异
- 直接用于实际的四方镜拼接

## 四、四象限的实现原理

### 4.1 核心思路

四象限同时生成 4 组数据：

```
Q1 左上 = 正竖（左快右慢，正常数据）
Q2 右上 = 反竖（右快左慢，正常数据）
Q3 左下 = 正竖（左快右慢，反转数据）
Q4 右下 = 反竖（右快左慢，反转数据）
```

**为什么用正竖/反竖（竖向）？**
- 竖向排列时，左右两列并排放置，视觉上就是"左右对称"
- 上下两行堆叠放置，视觉上就是"上下对称"
- 如果用横向，左右并排会变成"行"，不符合直觉

### 4.2 数据反转（内部）

四象限内部有一个独立的"数据反转"逻辑，与全局的"数据反转"开关是**分开**的：

- 全局开关：影响**所有**算法（四方/双边/备选/四象限）的源数据读取
- 四象限内部：始终同时生成"正常"和"反转"两个版本，用于上下对称

**如果全局勾选了"数据反转"会怎样？**
- 左上 = 正竖（已全局反转的数据）
- 右上 = 反竖（已全局反转的数据）
- 左下 = 正竖（全局反转后再内部反转 = 恢复正常）
- 右下 = 反竖（全局反转后再内部反转 = 恢复正常）

简单说：全局开关是"整体翻不翻"，四象限内部是"上下两部分互为镜像"。

### 4.3 布局细节

**合并模式（每象限1列）：**
- 列：A=左列两象限，B=空列，C=右列两象限
- 行：第1行=上标签，2~M+1=上半，M+2=空行，M+3=下标签，M+4~2M+3=下半

**分开模式（每象限K列）：**
- 列：1~K=左列两象限，K+1=空列，K+2~2K+1=右列两象限
- 行：与合并模式相同

象限之间都留有空行/空列作为分隔，避免混淆。

## 五、使用方法

### 5.1 基本操作

1. 将 `四方镜子_单模块版_v10.bas` 导入 Excel VBA 工程
2. 运行 `四方镜子()` 宏
3. 在窗体上设置：
   - 连接符号（默认 `-`）
   - 合并 / 分开
   - 数据反转（可选，整体翻转）
4. 点击 **"四象限对称"** 按钮（紫色，右下角）
5. 生成一张包含四个象限的结果表

### 5.2 快速验证（2×2 数据）

源数据：
```
A列  B列
 a    x
 b    y
```

操作：
1. 运行四方镜子，保持默认设置（合并模式）
2. 点击"四象限对称"
3. 检查结果表：
   - 左上第一行 = `a-x`
   - 右上第一行 = `a-x`
   - 左下最后一行 = `a-x`
   - 右下最后一行 = `a-x`
   - 四个角都是 `a-x`，中心对称

### 5.3 验证对称关系

用 2×3 数据（A列2行、B列3行）：

| 验证项 | 方法 | 预期结果 |
|--------|------|---------|
| 左右对称 | 左上第i行 vs 右上第i行 | 左右两列方向相反（正竖vs反竖） |
| 上下对称 | 左上第i行 vs 左下第(M-i+1)行 | 每行内容上下颠倒 |
| 中心对称 | 左上第i行 vs 右下第(M-i+1)行 | 完全相同（双反转=还原） |

## 六、v10 改动清单

### 6.1 新增内容

1. **按钮8 "四象限对称"**：紫色按钮，位于窗体底部右侧（与"备选算法验证"并排）
2. **`四象限_执行` 函数**：核心生成逻辑，一次生成 4 组结果并按象限布局写入
3. **`生成scct结果` 辅助函数**：封装 scct 核心算法，供四象限调用 4 次
4. **象限标签**：每个象限上方有 `【左上 正竖】` 等文字标签，方便辨识
5. **空行空列分隔**：四象限之间留有空行/空列，视觉清晰

### 6.2 不变内容

- 按钮1~7 的所有功能**完全不变**
- 四方循环、双边循环、备选算法的核心逻辑**完全不变**
- 数据反转开关、合并/分开、连接符**完全不变**
- 窗体尺寸 570×520 不变（按钮7和8并排放在底部）
- 按钮预览图示功能不变

### 6.3 兼容性

- v10 完全向下兼容 v9：不点击按钮8 时，与 v9 完全一致
- v10 模块名：`四方镜子_单模块版_v10.bas`，可与 v8/v9 共存
- 四象限结果表名：`四象限_合并_1` / `四象限_分开_反序_1` 等
