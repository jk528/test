# 四方镜子 - v9 版本说明：数据反转版

> v9 在 v8 基础上**新增"数据反转"开关**，现有功能完全不变。勾选后每列数据从下到上读取（行序颠倒），适用于四方镜对称场景。

| 对比项 | v8 | v9 |

## 二、数据反转是什么

### 2.1 效果说明

**正常模式**（不勾选）：数据从上到下读取
```
A列数据：    组合（正向）：
  A1          A1-B1
  A2    →     A2-B1
              A1-B2
              A2-B2
```

**反转模式**（勾选）：数据从下到上读取
```
A列数据：    组合（正向）：
  A1          A2-B3    ← 原来的最后一行变成第一行
  A2    →     A1-B3
              A2-B2
              A1-B2
              A2-B1
              A1-B1    ← 原来的第一行变成最后一行
```

**核心公式**：反转后第 i 行元素 = 原第 (n - i + 1) 行元素，其中 n = 该列行数。

### 2.2 以 2×2×2 为例验证

源数据（3列，每列2行）：
```
A列  B列  C列
 1    1    1
 2    2    2
```

| 模式 | 输出前3行 | 输出后3行 | 说明 |
|------|----------|----------|------|
| 正常（正向） | 1-1-1, 2-1-1, 1-2-1 | ...1-2-2, 2-2-2 | 1开头在前，2开头在后 |
| **反转（正向）** | **2-2-2, 1-2-2, 2-1-2** | **...2-1-1, 1-1-1** | 2开头在前，1开头在后 |

反转模式下，数据填写顺序从 `111 / 222` 变为 `222 / 111`（从上到下看）。

## 三、为什么需要数据反转

### 3.1 四方镜的对称场景

四方镜的核心用途是生成**左右对称、上下对称**的图案组合。当源数据本身有方向含义时（如"上/下"、"左/右"、"正/反"），镜像翻转后数据方向也应该同步翻转。

**举个直观例子**：
- A列存图案的"左半部分"，从上到下是 A1, A2, A3
- 正常模式下，左右对称时右边还是 A1, A2, A3 的顺序
- 但真正的"镜像"应该是：左边从上到下 A1→A2→A3，右边从下到上 A3→A2→A1

**勾选"数据反转"后**，生成的组合就像把源数据上下颠倒了再组合，配合四方镜的正/反向按钮，就能得到真正对称的效果。

### 3.2 四种对称组合方式

| 操作 | 效果 |
|------|------|
| 不反转 + 正向 | 正常左快右慢 |
| 不反转 + 反向 | 正常右快左慢 |
| **反转 + 正向** | **数据颠倒，左快右慢**（上下镜像） |
| **反转 + 反向** | **数据颠倒，右快左慢**（上下+左右镜像） |

这四种方式对应四方镜的四种对称形态，点击一下即可生成。

数据反转是**全局开关**，勾选后所有算法自动生效：

| 备选A | 进位计数 | ✅ | 通过 `读取源数据` 自动反转 |
| 备选B | 回溯法 | ✅ | 通过 `读取源数据` 自动反转 |
| 备选C | 自定义周期 | ✅ | 通过 `读取源数据` 自动反转 |
| 备选D | 随机抽样 | ✅ | 通过 `读取源数据` 自动反转 |

| 备选F | 格雷码 | ✅ | 通过 `读取源数据` 自动反转 |

**按钮预览图示也同步反转**——勾选"数据反转"后，窗体上8个按钮的示例文字会实时更新为反转后的效果。

## 五、结果表命名规则

勾选"数据反转"后，所有结果表名末尾增加 `_反序` 后缀：

| 算法 | 正常表名 | 反转表名 |
|------|---------|---------|
| 四方_正竖_合并 | `四方_正竖_合并_1` | `四方_正竖_合并_反序_1` |
| 四方_反横_分开 | `四方_反横_分开_1` | `四方_反横_分开_反序_1` |
| 双边_竖_完整_合并 | `双边_竖_完整_合并_1` | `双边_竖_完整_合并_反序_1` |
| 备选A_进位计数 | `备选A_进位计数_1` | `备选A_进位计数_反序_1` |
| 备选G_随机访问 | `备选G_随机访问_1` | `备选G_随机访问_反序_1` |

这样可以直观区分正序和反序的结果，避免混淆。

## 六、使用方法

### 6.1 基本操作

1. 将 `四方镜子_单模块版_v9.bas` 导入 Excel VBA 工程
2. 运行 `四方镜子()` 宏
3. 在窗体上设置：
   - 连接符号（默认 `-`）
   - 合并 / 分开
   - **数据反转**（v9 新增，默认不勾选）
4. 点击对应按钮生成结果

### 6.2 验证反转效果（快速验证）

用 2×2 简单数据验证：

```
A列  B列
 a    b
 c    d
```

1. 不勾选"数据反转" → 点"四方 正竖 合并" → 第1行 = `a-b`
2. 勾选"数据反转" → 点"四方 正竖 合并" → 第1行 = `c-d`

如果第1行从 `a-b` 变成了 `c-d`，说明反转生效了（a/c 互换，b/d 互换）。

### 6.3 完整验证（2×3 数据）

源数据：
```
A列  B列
 A1   B1
 A2   B2
      B3
```

| 行号 | 正常（正向） | 反转（正向） | 验证点 |
|------|------------|------------|--------|
| 1 | A1-B1 | A2-B3 | 首行：原来最后 → 现在最前 |
| 2 | A2-B1 | A1-B3 | |
| 3 | A1-B2 | A2-B2 | |
| 4 | A2-B2 | A1-B2 | |
| 5 | A1-B3 | A2-B1 | |
| 6 | A2-B3 | A1-B1 | 末行：原来最前 → 现在最后 |

规律：反转后的第 i 行 = 正常的第 (M-i+1) 行，但每列内部元素也反转了。**不只是整体倒序，是每列各自反转后的重新组合**。

## 七、v9 改动清单

### 7.1 新增内容

1. **全局变量**：`数据是否反转 As Boolean`（默认 False）
2. **窗体控件**：CheckBox2 "数据反转" 复选框（位置：合并复选框右侧）
3. **事件代码**：`CheckBox2_Click` 事件（切换反转状态 + 更新按钮预览）
4. **辅助函数**：`反序后缀()` 函数（返回 `""` 或 `"_反序"`）
5. **数据反转逻辑**：`读取源数据` 中增加反转处理
6. **四方/双边循环**：各自的源数据读取后也增加反转处理
7. **结果表命名**：所有结果表名增加 `_反序` 后缀（反转时）
8. **按钮预览**：示例数据同步反转（a1↔a2, b1↔b3）

### 7.2 不变内容

- 所有算法的核心逻辑（scct/zxgbs/A/B/C/D/E/F/G）**完全不变**
- 窗体尺寸 570×520 不变
- 按钮布局和数量（7个按钮）不变
- 连接符、合并/分开功能不变
- 备选算法菜单和交互方式不变

### 7.3 兼容性

- v9 完全向下兼容 v8：不勾选"数据反转"时，输出与 v8 完全一致
- v9 模块名：`四方镜子_单模块版_v9.bas`，可与 v8 共存
- 结果表名带 `_反序` 后缀，方便区分
