# 四方镜子 - 核心算法大全

> 多列数据的循环组合生成工具：把多列数据按特定规律排列组合，生成组合结果。本文档讲解现有两种核心算法，并演示 4 种可实现同样功能的备选算法。

---

## 一、总览

### 1.1 功能定义

给定多列数据（每列若干个元素），按一定规律生成组合序列。核心问题是：**如何决定每一行每列取哪个元素**。

### 1.2 算法全景

| 类别 | 算法 | 行数公式 | 本质 |
|------|------|---------|------|
| **现有** | 四方循环 `scct` | 各列行数**乘积** | 笛卡尔积（全组合） |
| **现有** | 双边循环 `zxgbs` | 各列行数**LCM** | 每列独立循环，共同周期 |
| 备选A | 进位计数法（Odometer） | 各列行数**乘积** | 笛卡尔积的混合进制实现 |
| 备选B | 回溯法（DFS递归） | 各列行数**乘积** | 笛卡尔积的递归实现 |
| 备选C | 自定义周期独立循环 | 各周期**LCM** | 双边循环的推广（任意周期） |
| 备选D | 随机抽样组合 | 用户指定 N 行 | 随机生成（新增能力） |

> 现有算法是"直接按公式定位元素"；备选算法提供不同实现视角或新增能力，输出可相同也可不同。

---

## 二、现有核心算法详解

### 2.1 四方循环 `scct`（笛卡尔积）

**原理**：从每列各取一个元素，生成**所有**可能组合。行数 = 各列行数乘积。

**核心工具函数**：
```
ys(n, Y) = ((n + Y - 1) Mod Y) + 1    ' 循环索引：把任意序号映射回 1~Y
cd(c, d) = RoundUp(c / d)              ' 向上取整除法
```

**步长计算**（决定每列隔几行变化一次）：
```
正向步长 fwd(n) = fwd(n-1) × colCounts(n-1)   → 左列慢、右列快
反向步长 rev(n) = totalRows / (colCounts(1)×...×colCounts(n))  → 左列快、右列慢
```

**源行号**：`源行号 = ys( cd(行号, 步长(nn)), colCounts(nn) )`

**2×3 数据演示**（A列A1,A2 / B列B1,B2,B3）：

| 行 | 正向（左慢右快） | 反向（左快右慢） |
|----|-----------------|-----------------|
| 1 | A1-B1 | A1-B1 |
| 2 | A2-B1 | A1-B2 |
| 3 | A1-B2 | A1-B3 |
| 4 | A2-B2 | A2-B1 |
| 5 | A1-B3 | A2-B2 |
| 6 | A2-B3 | A2-B3 |

> 正反向是同一组 6 个组合的不同排列顺序。正向=右列先循环，反向=左列先循环。

**特点**：
- ✅ 生成全部组合，覆盖完整
- ✅ 步长定位，性能好（O(行数×列数)）
- ⚠️ 组合数随列数/行数指数增长（5列各10个=10万行）

---

### 2.2 双边循环 `zxgbs`（LCM 独立循环）

**原理**：每列**各自独立循环**，互不影响。总行数 = 各列行数的最小公倍数（LCM），因为各列在 LCM 行时恰好同时完成整数个循环。

**源行号**：`源行号 = ys(行号, colCounts(列))`，每列独立计算。

**完整循环 vs 残缺循环**：
- 乘积 = LCM → **完整**（各列行数互质）
- 乘积 > LCM → **残缺**（存在公约数，未等全部轮完就开始重复）

**2×3 数据演示**（A列A1,A2 / B列B1,B2,B3，LCM(2,3)=6，完整循环）：

| 行 | A列 | B列 |
|----|-----|-----|
| 1 | A1 | B1 |
| 2 | A2 | B2 |
| 3 | A1 | B3 |
| 4 | A2 | B1 |
| 5 | A1 | B2 |
| 6 | A2 | B3 |

> 第7行 = A1-B1 回到起点。对比笛卡尔积（同样6行），双边循环走"对角线"顺序（A1B1, A2B2, A1B3...）。

**2×4 数据对比**（A列A1,A2 / B列B1..B4，LCM(2,4)=4，残缺循环）：

| 行 | 双边循环（4行） | 笛卡尔积（8行） |
|----|----------------|----------------|
| 1 | A1-B1 | A1-B1 |
| 2 | A2-B2 | A2-B1 |
| 3 | A1-B3 | A1-B2 |
| 4 | A2-B4 | A2-B2 |
| 5 | — | A1-B3 |
| 6 | — | A2-B3 |
| 7 | — | A1-B4 |
| 8 | — | A2-B4 |

**特点**：
- ✅ 行数更少（LCM ≤ 乘积），适合只想要"周期对齐"效果
- ✅ 每列独立，列之间无依赖
- ⚠️ 可能产生"残缺"（没覆盖全部组合）

## 三、其他核心算法

### 3.1 算法A：进位计数法（Odometer / 混合进制）

**原理**：把每一列看成一个"数字位"，整个组合序列 = 一个**混合进制计数器**（像汽车计程表）。初始每位=1，每次"末位+1"，满则进位（重置为1、前一位+1）。

**VBA 核心代码**：
```vba
For 行 = 1 To 总行数
    For 列 = 1 To 总列数
        结果(行, 列) = 源数据(索引(列), 列)      ' 取当前索引的组合
    Next 列
    For 列 = 总列数 To 1 Step -1                 ' 末位+1，满则进位
        索引(列) = 索引(列) + 1
        If 索引(列) <= 每列行数(列) Then
            Exit For
        Else
            索引(列) = 1                          ' 进位到前一位
        End If
    Next 列
Next 行
```

**2×3 输出**（与 scct 正向完全一致）：
```
A1-B1 → A2-B1 → A1-B2 → A2-B2 → A1-B3 → A2-B3
```

**特点**：
- 与 `scct` **输出完全相同**，但实现不同：无需预计算步长，天然支持任意列数
- 逐行递推，逻辑直观（"计程表"思维）
- 适合理解"混合进制"本质的教学场景

---

### 3.2 算法B：回溯法（DFS 递归生成）

**原理**：从第1列开始**递归**，逐列选择一个元素，选满所有列（到达叶子）时输出一行，然后**回溯**换下一个元素继续。输出顺序 = 第1列最慢、最后一列最快（与正向一致）。

**VBA 核心代码**：
```vba
Private Sub 递归生成(源数据, 每列行数, 总列数, 当前列, 临时行)
    If 当前列 > 总列数 Then
        输出临时行到结果                        ' 叶子：已选满所有列
        Exit Sub
    End If
    For i = 1 To 每列行数(当前列)
        临时行(当前列) = 源数据(i, 当前列)
        Call 递归生成(源数据, 每列行数, 总列数, 当前列 + 1, 临时行)
    Next i
End Sub
```

**2×3 输出**（与 scct 正向一致）：
```
A1-B1 → A2-B1 → A1-B2 → A2-B2 → A1-B3 → A2-B3
```

**特点**：
- 与 `scct` 输出相同，递归视角最贴近"笛卡尔积的数学定义"
- **最容易加约束**：例如"只输出 B > A 的组合"、"跳过某些列值组合"，在叶子判断处加条件即可
- 递归深度 = 列数，列数过多时注意栈开销

**约束扩展示例**（只输出两列值不相同的组合）：
```vba
If 当前列 > 总列数 Then
    If 临时行(1) <> 临时行(2) Then 输出当前行   ' 加筛选条件
    Exit Sub
End If
```

---

### 3.3 算法C：自定义周期独立循环（zxgbs 的推广）

**原理**：双边循环 `zxgbs` 中每列周期 = 该列行数；这里允许**给每列指定任意周期**，每列按各自周期独立循环，总行数 = LCM(所有周期)。比 `zxgbs` 更灵活（不要求周期等于列实际行数）。

**VBA 核心代码**：
```vba
Dim 周期() As Long      ' 每列的循环周期（用户指定）
周期(1) = 2: 周期(2) = 3
Dim lcm As Long: lcm = 最小公倍数(周期)
For 行 = 1 To lcm
    For 列 = 1 To 总列数
        源行 = ys(行, 周期(列))                 ' 每列按自己的周期循环
        结果(行, 列) = 源数据(源行, 列)
    Next 列
Next 行
```

**2×3 输出**（周期取 2, 3，LCM=6）：
```
A1-B1 → A2-B2 → A1-B3 → A2-B1 → A1-B2 → A2-B3
```

**特点**：
- 是 `zxgbs` 的**超集**：`zxgbs` 是周期=列行数的特例
- 可实现"A列每2行循环、B列每3行循环"这类不对称节奏
- 周期可大于列实际行数（数据循环复用）

---

### 3.4 算法D：随机抽样组合

**原理**：不生成全组合，而是**每次随机**从每列各取一个元素组成一行。支持有放回（可重复）和无放回（不重复）两种模式。

**VBA 核心代码**：
```vba
Randomize
For 行 = 1 To 抽样数
    For 列 = 1 To 总列数
        源行 = Int(Rnd * 每列行数(列)) + 1     ' 随机取该列一个元素
        结果(行, 列) = 源数据(源行, 列)
    Next 列
    ' 无放回模式：用 Dictionary 记录已出现组合，重复则重新生成
Next 行
```

**2×3 输出示例**（随机抽 3 行，每次运行结果不同）：
```
A1-B3
A2-B1
A1-B2
```

**特点**：
- **新增能力**：现有 scct/zxgbs 都无法生成随机组合
- 适合随机测试用例、抽样调查、彩票式组合
- 无放回模式需记录已生成组合（数据量大时用哈希）

## 四、算法对比总表

| 维度 | scct 笛卡尔积 | zxgbs LCM | A 进位计数 | B 回溯法 | C 自定义周期 | D 随机抽样 |
|------|--------------|-----------|-----------|----------|-------------|-----------|
| 行数 | 乘积 | LCM(列行数) | 乘积 | 乘积 | LCM(周期) | N（指定） |
| 覆盖 | 全部组合 | 部分（周期对齐） | 全部组合 | 全部组合 | 部分 | 随机子集 |
| 顺序 | 正向/反向 | 对角线 | 正向 | 正向 | 自定义 | 随机 |
| 实现 | 步长定位 | 独立取模 | 递增进位 | 递归 | 独立取模 | 随机索引 |
| 性能 | 快 | 快 | 快 | 中（递归） | 快 | 快 |
| 约束筛选 | 难 | 难 | 难 | **易** | 难 | 可（去重） |
| 随机性 | 无 | 无 | 无 | 无 | 无 | **有** |
| 通用性 | 固定相邻列乘积 | 周期=列行数 | 任意列数 | 任意列数 | **任意周期** | 任意 |

## 五、选用指南

| 需求场景 | 推荐算法 |
|---------|---------|
| 生成全部组合（最常用） | `scct`（性能）或 回溯法B（需筛选时） |
| 只想要周期对齐效果、不要全部组合 | `zxgbs` 或 自定义周期C |
| 需要自定义各列循环节奏（如 2-3-4 错开） | 自定义周期C |
| 组合带条件（如"B 必须大于 A"） | 回溯法B（叶子加判断） |
| 随机测试数据 / 抽样 | 随机抽样D |
| 教学理解"混合进制" | 进位计数法A |
