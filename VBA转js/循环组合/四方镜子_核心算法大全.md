# 四方镜子 - 核心算法大全

> 多列数据的循环组合生成工具：把多列数据按特定规律排列组合，生成组合结果。
> 本文档收录 **9 类核心算法**（含多种实现与随机抽样变体），覆盖"全组合生成、周期循环、随机抽样"三大能力。

---

## 一、总览

### 1.1 功能定义

给定多列数据（每列若干个元素），按一定规律生成组合序列。核心问题是：**如何决定每一行每列取哪个元素**。

### 1.2 算法全景

| 类别 | 算法 | 行数公式 | 本质 |
|------|------|---------|------|
| **现有** | 四方循环 `scct` | 各列行数**乘积** | 笛卡尔积（步长定位，正/反向） |
| **现有** | 双边循环 `zxgbs` | 各列行数**LCM** | 每列独立循环，共同周期 |
| 备选A | 进位计数法（Odometer） | 各列行数**乘积** | 笛卡尔积（混合进制递推） |
| 备选B | 回溯法（DFS递归） | 各列行数**乘积** | 笛卡尔积（递归，易加约束） |
| 备选C | 自定义周期独立循环 | 各周期**LCM** | 双边循环推广（任意周期） |
| 备选D | 随机抽样组合 | 指定 N 行 | 随机生成（3 种抽样方式） |
| 备选E | 逐列扩展法（Array Expansion） | 各列行数**乘积** | 笛卡尔积（逐列叉乘拼接） |
| 备选F | 格雷码遍历（Gray Code） | 各列行数**乘积** | 相邻组合仅一列变化 |
| 备选G | 混合进制随机访问 | 各列行数**乘积** | 序号→组合直接定位（随机访问） |

> 现有算法"按公式定位元素"；备选算法提供不同实现视角（递推/递归/扩展/编码）或新增能力（随机、单元素变化、随机访问）。

## 二、现有核心算法详解

### 2.1 四方循环 `scct`（笛卡尔积）

**原理**：从每列各取一个元素，生成**所有**可能组合。行数 = 各列行数乘积。

**核心工具函数**：
```
ys(n, Y) = ((n + Y - 1) Mod Y) + 1    ' 循环索引：把任意序号映射回 1~Y
cd(c, d) = RoundUp(c / d)              ' 向上取整除法
```

**步长计算**（决定每列隔几行变化一次）：
```
正向步长 fwd(n) = fwd(n-1) × colCounts(n-1)   → 左列慢、右列快
反向步长 rev(n) = totalRows / (colCounts(1)×...×colCounts(n))  → 左列快、右列慢
```

**源行号**：`源行号 = ys( cd(行号, 步长(nn)), colCounts(nn) )`

**2×3 数据演示**（A列A1,A2 / B列B1,B2,B3）：

| 行 | 正向（左慢右快） | 反向（左快右慢） |
|----|-----------------|-----------------|
| 1 | A1-B1 | A1-B1 |
| 2 | A2-B1 | A1-B2 |
| 3 | A1-B2 | A1-B3 |
| 4 | A2-B2 | A2-B1 |
| 5 | A1-B3 | A2-B2 |
| 6 | A2-B3 | A2-B3 |

> 正反向是同一组 6 个组合的不同排列顺序。正向=右列先循环，反向=左列先循环。

**特点**：
- ✅ 生成全部组合，覆盖完整
- ✅ 步长定位，性能好（O(行数×列数)）
- ⚠️ 组合数随列数/行数指数增长（5列各10个=10万行）

---

### 2.2 双边循环 `zxgbs`（LCM 独立循环）

**原理**：每列**各自独立循环**，互不影响。总行数 = 各列行数的最小公倍数（LCM），因为各列在 LCM 行时恰好同时完成整数个循环。

**源行号**：`源行号 = ys(行号, colCounts(列))`，每列独立计算。

**完整循环 vs 残缺循环**：
- 乘积 = LCM → **完整**（各列行数互质）
- 乘积 > LCM → **残缺**（存在公约数，未等全部轮完就开始重复）

**2×3 数据演示**（A列A1,A2 / B列B1,B2,B3，LCM(2,3)=6，完整循环）：

| 行 | A列 | B列 |
|----|-----|-----|
| 1 | A1 | B1 |
| 2 | A2 | B2 |
| 3 | A1 | B3 |
| 4 | A2 | B1 |
| 5 | A1 | B2 |
| 6 | A2 | B3 |

> 第7行 = A1-B1 回到起点。双边循环走"对角线"顺序（A1B1, A2B2, A1B3...）。

**2×4 数据对比**（A列A1,A2 / B列B1..B4，LCM(2,4)=4，残缺循环）：

| 行 | 双边循环（4行） | 笛卡尔积（8行） |
|----|----------------|----------------|
| 1 | A1-B1 | A1-B1 |
| 2 | A2-B2 | A2-B1 |
| 3 | A1-B3 | A1-B2 |
| 4 | A2-B4 | A2-B2 |
| 5 | — | A1-B3 |
| 6 | — | A2-B3 |
| 7 | — | A1-B4 |
| 8 | — | A2-B4 |

**特点**：
- ✅ 行数更少（LCM ≤ 乘积），适合只想要"周期对齐"效果
- ✅ 每列独立，列之间无依赖
- ⚠️ 可能产生"残缺"（没覆盖全部组合）

## 三、其他核心算法

### 3.1 算法A：进位计数法（Odometer / 混合进制）

**原理**：把每一列看成一个"数字位"，整个组合序列 = 一个**混合进制计数器**（像汽车计程表）。初始每位=1，每次"末位+1"，满则进位（重置为1、前一位+1）。

**VBA 核心代码**：
```vba
For 行 = 1 To 总行数
    For 列 = 1 To 总列数
        结果(行, 列) = 源数据(索引(列), 列)      ' 取当前索引的组合
    Next 列
    For 列 = 总列数 To 1 Step -1                 ' 末位+1，满则进位
        索引(列) = 索引(列) + 1
        If 索引(列) <= 每列行数(列) Then Exit For Else 索引(列) = 1
    Next 列
Next 行
```

**2×3 输出**（与 scct 正向完全一致）：
```
A1-B1 → A2-B1 → A1-B2 → A2-B2 → A1-B3 → A2-B3
```

**特点**：
- 与 `scct` **输出完全相同**，但无需预计算步长，天然支持任意列数
- 逐行递推，逻辑直观（"计程表"思维）

---

### 3.2 算法B：回溯法（DFS 递归生成）

**原理**：从第1列开始**递归**，逐列选择一个元素，选满所有列（到达叶子）时输出一行，然后**回溯**换下一个元素。输出顺序 = 第1列最慢、最后一列最快（与正向一致）。

**VBA 核心代码**：
```vba
Private Sub 递归生成(源数据, 每列行数, 总列数, 当前列, 临时行)
    If 当前列 > 总列数 Then
        输出临时行到结果                        ' 叶子：已选满所有列
        Exit Sub
    End If
    For i = 1 To 每列行数(当前列)
        临时行(当前列) = 源数据(i, 当前列)
        Call 递归生成(源数据, 每列行数, 总列数, 当前列 + 1, 临时行)
    Next i
End Sub
```

**特点**：
- 与 `scct` 输出相同，递归视角最贴近"笛卡尔积的数学定义"
- **最容易加约束**：在叶子处加判断即可（如"只输出 B > A 的组合"）
- 递归深度 = 列数，列数过多时注意栈开销

**约束扩展示例**：
```vba
If 当前列 > 总列数 Then
    If 临时行(1) <> 临时行(2) Then 输出当前行   ' 加筛选条件
    Exit Sub
End If
```

---

### 3.3 算法C：自定义周期独立循环（zxgbs 的推广）

**原理**：每列按**指定周期**独立循环，总行数 = LCM(所有周期)。比 `zxgbs` 更灵活。
**注意**：周期**不能超过该列实际行数**，否则循环到超出部分时源数据越界（如 2×2×2 数据下周期取 2,3,2 会因第2列只有2行而越界）。

**VBA 核心代码**（含越界保护）：
```vba
Dim 周期() As Long
ReDim 周期(1 To 总列数)
周期(1) = 2: If 每列行数(1) < 周期(1) Then 周期(1) = 每列行数(1)   ' 越界保护
周期(2) = 3: If 每列行数(2) < 周期(2) Then 周期(2) = 每列行数(2)
For 列 = 3 To 总列数: 周期(列) = 每列行数(列): Next

Dim lcm As Long: lcm = WorksheetFunction.Lcm(周期)
For 行 = 1 To lcm
    For 列 = 1 To 总列数
        源行 = ys(行, 周期(列))                 ' 每列按自己的周期循环
        结果(行, 列) = 源数据(源行, 列)
    Next 列
Next 行
```

**2×3 输出**（周期取 2, 3，LCM=6）：
```
A1-B1 → A2-B2 → A1-B3 → A2-B1 → A1-B2 → A2-B3
```

**特点**：
- 是 `zxgbs` 的**超集**（zxgbs 是周期=列行数的特例）
- 可实现"A列每2行循环、B列每3行循环"的不对称节奏
- 周期取值上限 = 该列实际行数（数据不够则自动降级，避免越界）

### 3.4 算法D：随机抽样组合（3 种方式）

**原理**：不生成全组合，而是**随机**从每列各取一个元素组成一行。

#### 方式1：有放回（可重复）
```vba
Randomize
For 行 = 1 To N
    For 列 = 1 To 总列数
        源行 = Int(Rnd * 每列行数(列)) + 1     ' 每列随机取一个
        结果(行, 列) = 源数据(源行, 列)
    Next 列
Next 行
```

#### 方式2：无放回（Fisher-Yates 洗牌法，推荐）
**原理**：生成 1..M 的索引数组，Partial Fisher-Yates 只洗前 N 个，取前 N 个索引解码成组合。
**优势**：O(N) 时间、零重试零查重，**N 接近 M 也不慢**（比"随机尝试+查重"高效得多）。

```vba
' 1. 生成索引数组 1..M 并洗牌（只洗前 N 个）
For i = 1 To M: 索引(i) = i: Next
For i = 1 To N
    j = Int(Rnd * (M - i + 1)) + i
    tmp = 索引(i): 索引(i) = 索引(j): 索引(j) = tmp
Next i
' 2. 取前 N 个索引，用混合进制解码成组合
For 行 = 1 To N
    余 = 索引(行) - 1: 权重 = 1
    For 列 = 1 To 总列数
        结果(行, 列) = 源数据((余 \ 权重) Mod 每列行数(列) + 1, 列)
        权重 = 权重 * 每列行数(列)
    Next 列
Next 行
```

#### 方式3：无放回（Floyd 抽样，O(N) 空间）
**原理**：`Floyd's Algorithm` 只需 O(N) 空间（哈希集），适合 M 极大时。
```vba
Dim 集合 As Object: Set 集合 = CreateObject("Scripting.Dictionary")
Dim 候选 As Long, j As Long
For 候选 = M - N + 1 To M
    j = Int(Rnd * 候选) + 1
    If 集合.Exists(j) Then 集合(候选) = True Else 集合(j) = True
Next 候选
' 集合的键 = N 个不重复随机索引，再解码成组合
```

**三种方式对比**：

| 方式 | 空间 | 时间 | 重复性 | 适用 |
|------|------|------|--------|------|
| 有放回 | O(N) | O(N×列数) | 可重复 | 一般抽样 |
| Fisher-Yates | O(M) | O(N+M) | 不重复 | 通用（推荐） |
| Floyd | O(N) | O(N×列数) | 不重复 | M 极大时 |

### 3.5 算法E：逐列扩展法（Array Expansion）

**原理**：从第1列开始，维护"已生成组合数组"；处理每列时，把当前数组**复制该列行数份**，第 i 份追加该列第 i 个元素（列叉乘）。

**VBA 核心代码**（正向：新列慢变）：
```vba
' 初始：第1列
ReDim 结果(1 To 每列行数(1), 1 To 1)
For 行 = 1 To 每列行数(1): 结果(行, 1) = 源数据(行, 1): Next

For 列 = 2 To 总列数
    Dim 新行数 As Long: 新行数 = UBound(结果, 1) * 每列行数(列)
    Dim 新结果() As Variant: ReDim 新结果(1 To 新行数, 1 To 列)
    Dim 行 As Long, k As Long, 旧列 As Long
    ' 外层按新列元素份数复制，内层展开已有组合 → 正向顺序（旧列快变）
    For k = 1 To 每列行数(列)
        For 行 = 1 To UBound(结果, 1)
            For 旧列 = 1 To 列 - 1: 新结果((k - 1) * UBound(结果, 1) + 行, 旧列) = 结果(行, 旧列): Next
            新结果((k - 1) * UBound(结果, 1) + 行, 列) = 源数据(k, 列)
        Next 行
    Next k
    结果 = 新结果
Next 列
```

**2×3 输出**（与 scct 正向一致）：
```
A1-B1 → A2-B1 → A1-B2 → A2-B2 → A1-B3 → A2-B3
```

**特点**：
- 思路直观（逐列"叉乘"扩展），适合教学
- 天然支持任意列数、任意列长
- 内存需先建全量数组；可用在"组合拼接"场景（比字符串累加快）

---

### 3.6 算法F：格雷码遍历（Gray Code）

**原理**：让**相邻两个组合只差一个元素**变化（某一列取相邻的下一个/上一个元素）。适合需要"相邻组合差异最小"的场景。

**2×3 格雷码序列示例**（相邻仅一列变化）：
```
A1-B1 → A1-B2 → A1-B3 → A2-B3 → A2-B2 → A2-B1
  │B变    │B变    │A变    │B变    │B变     （每步只变一列）
```

**递归反射构造思路**：
```vba
' 对当前列做"反射"：先正向取该列全部，再反向取（保持上一列不变）
Sub 格雷递归(当前列)
    If 当前列 > 总列数 Then 输出当前行: Exit Sub
    For 方向 = 1 To 2
        If 方向 = 1 Then
            For i = 1 To 每列行数(当前列)      ' 正向
                当前行(当前列) = 源数据(i, 当前列): Call 格雷递归(当前列 + 1)
            Next
        Else
            For i = 每列行数(当前列) To 1 Step -1  ' 反向（反射）
                当前行(当前列) = 源数据(i, 当前列): Call 格雷递归(当前列 + 1)
            Next
        End If
    Next 方向
End Sub
```

**特点**：
- 相邻组合**仅一列变化**，差异最小化
- 典型应用：穷举测试时让相邻用例只改一个参数；传感器/机械扫描路径；状态遍历

---

### 3.7 算法G：混合进制随机访问（Index → Combination）

**原理**：已知组合在序列中的序号 k，直接用**混合进制解码**得到该组合——无需生成前面所有行，可**随机访问任意第 k 个组合**。这是 Fisher-Yates 洗牌解码的核心，也是按需生成/并行分区的基础。

**VBA 核心代码**：
```vba
Function 第k个组合(k As Long) As Variant
    Dim 余 As Long, 权重 As Long, 列 As Long
    余 = k - 1: 权重 = 1
    For 列 = 1 To 总列数
        结果(列) = 源数据((余 \ 权重) Mod 每列行数(列) + 1, 列)
        权重 = 权重 * 每列行数(列)
    Next 列
    第k个组合 = 结果
End Function
```

**示例**（2×3 数据）：
```
第1个 = A1-B1
第3个 = A1-B2
第6个 = A2-B3
```

**特点**：
- O(列数) 时间**随机访问任意组合**，不需生成全序列
- 是算法D（Fisher-Yates）、并行分区、断点续算的基础
- 与算法A（Odometer）互为"逆运算"：A 是从组合推下一个，G 是从序号直接定位

## 五、选用指南

| 需求场景 | 推荐算法 |
|---------|---------|
| 生成全部组合（最常用） | `scct`（性能）或 回溯法B（需筛选时） |
| 只想要周期对齐效果、不要全部组合 | `zxgbs` 或 自定义周期C |
| 需要自定义各列循环节奏（如 2-3-4 错开） | 自定义周期C |
| 组合带条件（如"B 必须大于 A"） | 回溯法B（叶子加判断） |
| 随机测试数据 / 抽样 | 随机抽样D（Fisher-Yates 推荐） |
| 需要"相邻组合只改一个参数" | 格雷码F |
| 需要按序号直接取第 k 个组合（断点续算/并行） | 混合进制随机访问G |
| 教学理解"混合进制"/"列叉乘" | 进位计数A / 逐列扩展E |
