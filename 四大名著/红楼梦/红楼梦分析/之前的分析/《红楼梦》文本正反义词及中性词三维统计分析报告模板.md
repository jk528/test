## 2. 词汇判定标准

为确保统计的客观性与一致性，本次分析采用以下三类词汇判定标准：

### 2.1 正意词（Positive）

指代美好、善良、愉悦、赞赏、和谐等**积极情感或状态**的词汇。

| 类别  | 示例               |
| --- | ---------------- |
| 形容词 | 良善、清香、心神爽快、清秀、英豪 |
| 动词  | 夸、陪笑、悟彻、飞腾       |
| 名词  | 神仙、知己、团圆、妙极      |

### 2.2 反意词（Negative）

指代恐惧、邪恶、愤怒、欺骗、冲突、悲伤等**消极情感或状态**的词汇。

| 类别  | 示例                 |
| --- | ------------------ |
| 形容词 | 荒唐、痴、辛酸、污臭、可厌、狼狈、穷 |
| 动词  | 啼哭、烧、悔恨、唬          |
| 名词  | 火坑、烦恼、病、瓦砾、荒冢、锁枷   |

### 2.3 中性词（Neutral）⭐ 新增

指**不带褒贬色彩、仅用于客观表达概念**的词语，具体含义常随语境呈现动态变化。

| 类别  | 示例                | 说明             |
| --- | ----------------- | -------------- |
| 名词  | 人家、街坊、书院、杯盘、小童、银子 | 客观事物名称，无明显情感倾向 |
| 动词  | 走来、听见、笑道、归坐、设下、命  | 描述动作行为，情感中性    |
| 时间词 | 今夜、半夜、天明、一月、三月十五  | 客观时间表述         |
| 数量词 | 五十两、两套、几人、一夜      | 客观数量描述         |
| 处所词 | 田庄、岳丈家、街前、葫芦庙     | 客观地点名称         |

> **中性词判定原则**：
>
> 1. 词语本身不带情感色彩
> 2. 需结合语境判断，同一词在不同语境可能呈现不同色彩
> 3. 专有名词、普通名词、客观动词优先归入中性词
