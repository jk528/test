## 0. 结论（先行）

> **一句话**：汉语把"一个人／一件事消逝后，其影响以物性方式残存"这件事，做成了一个完整的词汇家族——**借物理余存之名，表德业余存之实**。核心字按物性分**十一系**（水火声光香味线荫温力势德），修饰字八字（余遗流残坠贻休手）分工精确，全族构成古人对"**影响如何延续**"的分类学建模与衰减动力学。

**总判定表**：

| 项目 | 判定 |
| :--- | :--- |
| 语义场三要件 | ①源主体已逝/离去②属性载体（水火声光等物性）③**衰减中的存量**——缺一不入此族 |
| 十一系（载体轴） | 水（泽润波澜）·火（烈烬焰）·声（音响韵）·光（晖霞明）·香（芳香馨芬）·味（味甘）·线（绪缕缕）·荫庇·温触·力势（威力势勇）·德业（庆殃爱直训则） |
| 修饰八字（方式轴） | **余**（自然剩余）·**遗**（留赠/失落）·**流**（主动传播）·**残**（缺损）·**坠**（断绝）·**贻**（预先安排）·**休**（美称）·**手**（亲身触迹） |
| 命名法总规律 | 物理系先有名（余烬·余音），社会系借物系词赋义（余泽→恩泽、余烈→遗业、余荫→庇护）——**第一命名法：借物存之名，赋德存之实** |
| 衰减五型 | 火速衰型·水缓衰型·声律动型（可共鸣再激发）·香扩散转化型（花泥封存）·德再生产型（不衰反增，靠人念诵效法） |
| 双极书证 | "君子之泽五世而斩"（水系衰减律）vs"奋六世之余烈"（火系透支律）——族内两支曲线 |
| 策源地 | **《左传》**：余烬·余勇·遗爱·遗直·三不朽五证群出——春秋贵族"身后名"焦虑催生此族 |

## 1. 语义场判定：三要件与边界排除

**三要件**（同时满足方入此族）：

1. **源主体**已消逝或离去（人死、火熄、曲终、事毕）；
2. **属性载体**仍在，且载体是可感的物性（湿润、火温、声响、光、香、味）或抽象属性（德、爱、力、势）；
3. **存量处于衰减轨道**——此为关键：词义预设"正在变少、终将耗尽"（"余音"不再响、"余烬"将冷）。

**边界排除**（像而不属）：

| 词 | 排除理由 |
| :--- | :--- |
| 余数、剩余 | 纯数量剩余，无属性载体（要件②缺） |
| 遗书、遗物 | 是**实体遗留物**非"属性残存"——东西还在，谈不上衰减 |
| 余年、余生 | 源主体（自己）未逝（要件①缺）——"余"字泛剩余义族 |
| 遗恨、余悸 | 已入情感残余族，与物性衰减不共语义场（族外近邻，可注记） |

> 判定卡与《新名词释义解析方法》四维定位卡同构：先定"在不在族内"，再定系（载体）、位（修饰字）、值（衰减型）。

## 2. 修饰字谱系：八字分工（"余X"的"余"不止一个意思）

| 修饰字 | 本义 | 存留方式 | 代表词 | 姿态 |
| :--- | :--- | :--- | :--- | :--- |
| **余** | 剩（我之剩余） | 自然剩余，被动 | 余烬、余音、余威 | 中性·量减 |
| **遗** | 亡失→留赠（读 wèi 为赠） | 离去时留下（有意）或失落（无意） | 遗爱、遗音、遗训 | 有赠与感 |
| **流** | 水行 | 主动传播扩散 | 流芳、流风、流誉 | 有方向感 |
| **残** | 伤缺 | 破损不全地存 | 残照、残烬、残喘 | 贬损·怜惜 |
| **坠** | 落 | 断续中失落 | 坠绪、坠绪茫茫 | 危殆·待接 |
| **贻/诒** | 赠 | 活着时预先安排 | 诒厥孙谋、贻谋 | 筹划感 |
| **休** | 美 | （美称后缀） | 休烈、休光 | 赞颂 |
| **手** | 亲手 | 主体身体痕迹的残留 | 手泽 | 触迹·人非物是 |

> **总口诀**：余是剩，遗是赠，流是散，残是损，坠是断，贻是留策，休是美，手是迹。

## 3. 十一系全谱（载体轴枚举——本篇主体）

体例：每系给【字源】（《说文》本义）→【词条】→【代表例句】（A 经文／B 正史诸子／C 后世诗文）。

### 3.1 水系：泽·润·波·澜·滴

【字源】泽＝光润（水聚之表）；润＝水浸滋；波／澜＝水之动；滴＝水之末。

| 词条 | 释义 | 书证 |
| :--- | :--- | :--- |
| **余泽／遗泽** | 先人德业如水之润，残存之滋养 | 《孟子·离娄下》"君子之泽，五世而斩"【A】；"利泽施于万世"《庄子·大宗师》（措辞待核） |
| **手泽** | 先人手汗余润存于其遗物上——人非物是之悼 | 《礼记·玉藻》"父没而不能读父之书，手泽存焉尔"【A】 |
| **余波／余澜** | 大事件之后扩散的次级影响 | "其余波"后世文常语【C】；余波藉甚 |

> **水系＝德系的默认计量词**："泽"自先秦起直接表恩德（恩泽、泽被苍生、泽及万世），物性义反成引申——全部余绪里最成功的一次"借物赋德"。

### 3.2 火系：烈·烬·焰

【字源】烈＝火猛；**烬＝火之余木也（《说文》——本字就是"火之余"的专字）**；焰＝火之光锋。

| 词条 | 释义 | 书证 |
| :--- | :--- | :--- |
| **余烈** | ①火之余焰→②**遗留之功业**（义项二为主用） | 《过秦论》"奋六世之余烈"【B】（义项二）；"余烈"作为火之余为字面义 |
| **余烬** | 火灭后的残燃之物；**喻溃散的残军、劫后的残生** | 《左传·成公二年》鞌之战，国佐曰"请收合余烬，背城借一"【A】——**喻残军的首见** |
| **余焰／遗焰** | 将熄未熄的火光；喻残余势力 | 后世文语【C】 |

> **"余烬"的引申路径**：火之余（本义）→烧残之军（国佐）→劫余之人（"自谓终当为死灰，既而复然"系其反义表达，见《史记·韩长孺列传》死灰复燃典【B】）。一族之内反义词也成对（死灰复燃 vs 余烬将熄）。

### 3.3 声系：音·响·韵（＋缕意象）

【字源】音＝声成文者（《说文》"声成文谓之音"）；响＝回声（向声而应）；韵＝和声（后起字），渐引申为"延伸的回味"。

| 词条 | 释义 | 书证 |
| :--- | :--- | :--- |
| **余音／遗音** | 曲终后残存之响；遗音特指"有未尽之意" | 《列子·汤问》韩娥鬻歌"**余音绕梁欐，三日不绝**"【B】；《赤壁赋》"**余音袅袅，不绝如缕**"【C】；《礼记·乐记》"壹倡而三叹，**有遗音者矣**"【A】 |
| **余响／遗响** | 声之余的迟响 | 《赤壁赋》"**托遗响于悲风**"【C】——同篇出余音、遗响双词 |
| **余韵／遗韵** | 由声之余引申出的意味之延伸 | 后世诗文／书评常语【C】；"流风余韵"合水风声三系 |

> **声系三级**：音（源声）→响（回声）→韵（延伸回味）——物理距离逐级远离声源，语感距离逐级靠近"意味"。**"缕"借入**：不绝如缕——声中见线，线系意象（见 3.7）。
> **声系的独特物理性**：余音可**共鸣再激发**（绕梁三日是建筑共鸣＋心理回响），衰减律与火水不同。

### 3.4 光系：晖·霞·明

【字源】晖＝光；霞＝赤云之气；明＝日月之光。

| 词条 | 释义 | 书证 |
| :--- | :--- | :--- |
| **余晖／残照** | 日落后残散之光；喻暮年、王朝末世 | 谢朓《晚登三山还望京邑》"**余霞散成绮，澄江静如练**"【C】；残照入后世咏史常语【C】 |
| **余明／余光** | 光之余芒；喻借他人之力 | 《史记·樗里子甘茂列传》甘茂引贫女绩事"妾以无烛……**愿借余明**"【B】——"借光"的祖源 |
| **休光** | 美盛之光（休＝美，德业的辉光） | 汉《封禅文》一系【C】 |

> **光系＝空间型衰减**：随角度（日落）而非随时间线性亡逝——余晖不灭于久，灭于角度。咏史家的最爱（斜阳、残照、晚霞喻朝代之余）。

### 3.5 香系：芳·馨·芬·香

【字源】馨＝香之远闻（《说文》）；芬＝香气分布；芳＝香草。

| 词条 | 释义 | 书证 |
| :--- | :--- | :--- |
| **遗芳／余芳** | 花谢后残余之香；喻身后美名 | 龚自珍《己亥杂诗》"**落红不是无情物，化作春泥更护花**"【C】——转化型存续的宣言 |
| **余馨** | 残存之远香 | 后世诗文常语【C】 |
| **流芳／遗芬** | 美名随传（流）／残留之芬芳 | "流芳百世"（与"遗臭万年"成对——族内的正负对称）【C】 |
| **香如故** | 香的抗衰减宣言：形灭质存 | 陆游《卜算子·咏梅》"**零落成泥碾作尘，只有香如故**"【C】 |

> **香系的独特性**：本体可被彻底摧毁（成泥碾尘），属性借另种形态封存转化——全族唯一主张"**转化存续**"的系，文学价值最高。

### 3.6 味系：味·甘

【字源】味＝滋味；甘＝甜，引申一切美好回味。

| 词条 | 释义 | 书证 |
| :--- | :--- | :--- |
| **遗味／余味** | 味的残存；遗味特指"淡中之余不尽" | 《礼记·乐记》"大羹不和，**有遗味者矣**"【A】——**与"遗音"同段双出**："清庙之瑟……有遗音者矣。大飨之礼……有遗味者矣"——礼家以声味二遗共喻"不极而有余" |
| **余甘** | 甜味退后的回甘（橄榄） | 后世常语【C】；"余甘回苦"入诗品 |

> **《乐记》双遗段是家族内部互证的枢纽**：同段言遗音（声系）与遗味（味系），显示先秦已把"余绪"当**跨物性的公共范畴**使用，非偶然修辞。

### 3.7 线系：绪·缕

【字源】绪＝**丝耑（端）也**（《说文》）——丝线的头绪；缕＝麻线。

| 词条 | 释义 | 书证 |
| :--- | :--- | :--- |
| **余绪／坠绪** | 事之头绪残端；坠绪＝将断之绪 | 《尚书·五子之歌》"荒坠厥绪"【A（今文）】；韩愈《进学解》"**寻坠绪之茫茫，独旁搜而远绍**"【C】——"远绍坠绪"即韩愈版"私淑接续" |
| **不绝如缕** | 线意象借入声系（余音袅袅如一丝） | 《赤壁赋》合用【C】 |

> **线系独有性**：绪是"**可抓取一端而再续**"的余存——全族唯一**可逆衰减**型（坠绪可绍、断线可接）。孟子私淑、韩愈远绍都属此系操作。

### 3.8 荫庇系：荫

【字源】荫＝草木质字，树冠覆地之影——空间性遮蔽。

| 词条 | 释义 | 书证 |
| :--- | :--- | :--- |
| **余荫／遗荫** | 祖上余势之庇护；荫生、荫庇制度的语源 | 封妻荫子（明代荫叙制）【B】；"前人栽树，后人乘凉"【D】——俗谚全译 |

> **荫系＝空间型存续**：树在荫在、树倒荫亡——不衰减于时间，存亡系于**载体存续**。与光系（角度型）对偶。

### 3.9 温触系：温·热

【字源】温＝水名→温度；热＝火之感觉层。

| 词条 | 释义 | 书证 |
| :--- | :--- | :--- |
| **余温／余热** | 触觉性残余温度 | 现代口语为主【D】；"发挥余热"（当代退休语汇）——**族内唯一词义上扬的现代转化** |

> 温触系书证层晚（中古后），但**体感最直接**——"人走茶凉"即其反义定律（世情的温度＝器物的温度）。

### 3.10 力势系：威·力·势·勇

【字源】四字皆状态量词，非物性——社会性"力"的存留。

| 词条 | 释义 | 书证 |
| :--- | :--- | :--- |
| **余威** | 权势消长后的残震慑 | 《过秦论》"始皇既没，**余威震于殊俗**"【B】——**与"奋六世之余烈"同篇呼应**：余烈（取）→余威（余）首尾成环 |
| **余勇** | 士气之存量过剩 | 《左传·成公二年》高固"**欲勇者贾余余勇**"【A】——余勇可贾；**与"收合余烬"同役（鞌之战）** |
| **余力** | 力之剩余 | 《论语·学而》"**行有余力，则以学文**"【A】 |
| **余势** | 动量的惯性延续 | 唐人咏碑书"飞白之余势"一系【C】 |

> 力势系＝**惯性衰减**，即刻性强（余勇当场可贾），与世系计量（五世）异轴。

### 3.11 德业系：庆·殃·爱·直·训·则（烈之义业归此义项）

【字源】纯社会属性词，无物性本源——此系**必须借物系词赋形**（见第 5 节命名法）。

| 词条 | 释义 | 书证 |
| :--- | :--- | :--- |
| **余庆／余殃** | 积德／积恶的跨世利息 | 《易·坤·文言》"**积善之家，必有余庆；积不善之家，必有余殃**"【A】——族内最早的全称计量律（不设世数，言"必"） |
| **遗爱** | 施爱者逝而其爱被民怀念 | 《左传·昭公二十年》子产卒，仲尼曰"**古之遗爱也**"【A】 |
| **遗直** | 直道人格的历史残存 | 《左传·昭公十四年》"叔向，**古之遗直也**"【A】 |
| **遗训／遗则** | 先人言教规制的存文本 | 《尚书》"训"字群【B】；"恪守遗训"后世常语【C】 |
| **休烈／遗烈** | 美业／遗功（"烈"的义项二） | "休烈"汉碑史册颂词一系【C首见待核】 |
| **三不朽** | 德系的理论总纲 | 《左传·襄公二十四年》叔孙豹"**太上有立德，其次有立功，其次有立言，虽久不废，此之谓不朽**"【A】——**德系"不衰减"的机制定义：靠"不废"（有人继续立）** |

## 4. 衰减动力学：六型总表（族内物理分类学）

| 衰减型 | 代表系 | 衰减规律 | 时间尺度 | 可否逆转 |
| :--- | :--- | :--- | :--- | :--- |
| **速衰型（火）** | 火、温 | 指数骤降，烬后无焰 | 分钟—夜 | 不可（复燃＝借新火） |
| **缓衰型（水）** | 水 | 长尾浸润，泽干于渗 | 季—年 | 不可（可储蓄：湖泽） |
| **律动型（声）** | 声 | 振荡衰减＋**共鸣再激发**；心理回声无衰减上限（绕梁三日） | 秒；记忆无限 | **可**（再奏即再激发） |
| **转化型（香）** | 香 | 本体灭而属性经**形态转化**封存（花→泥→香） | 随载体 | 质存形变 |
| **空间型（光／荫）** | 光、荫 | 不衰于时间，存亡系于**角度／载体存活** | 随日／随树 | 系于外物 |
| **再生产型（德）** | 德业、力势之威 | **不衰反增**——靠人念、诵、效法、书写再生产；一旦停止再生产则斩 | 世系（五世律） | **唯此系可"接"**（私淑、远绍） |
