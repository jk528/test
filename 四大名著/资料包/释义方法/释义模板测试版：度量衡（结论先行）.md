## 0. 结论（先行）

> **确诂一句话**：度量衡＝**长度（度）、容量（量）、重量（衡）三大测量门类之标准体系的并称总名**（制度与标准器双指），中国传统计量的核心名词。三家单位系列为**分寸尺丈引／龠合升斗斛／铢两斤钧石**，全部锚定于黄钟律管——管长定度、管容黍重定量与衡（"以律起度"），黄钟即古代中国的第一基准常数。词序上经典作"同律度量衡"（《舜典》）"一法度衡石丈尺"（《史记》），变序并存而义不变——与"东西南北"相反，构成"语序即义"的**阴性对照**。现代语用扩容为一切计量之总称。
>
> 全词唯一的"词义成分"是治理属性：古籍中它几乎从不作为中性工具词出现，永远站在"统一、校验、立法"的政权句里——**度量衡是国家主权词，不是五金词汇**。

| 项目 | 判定 |
| :--- | :--- |
| 词性 | 制度性并称名词组（无数字，系列首例"无数字并称集合"） |
| 构词 | 三家并列无中心词；三字皆名动兼类（度长短之度／量多少之量／衡轻重之衡——动词短语压成名词并称） |
| 定义句 | 《汉书·律历志》三分定义："度者……所以度长短也；量者……所以量多少也；权者……所以称物平施，知轻重也"（系列首见自带定义） |
| 进制 | 度量十进制（分寸尺丈引）；量首环二进制（合龠为合）后十进制（合升斗斛）；衡权非十进制（24 铢＝两、16 两＝斤、30 斤＝钧、4 钧＝石） |
| 基准 | 黄钟律管＋秬黍（**长度**＝黄钟九寸、一黍之广为一分；**容量**＝黄钟之龠、容千二百黍；**重量**＝千二百黍重十二铢） |
| 语篇属性 | 治理话语：谨权量（论语）／同律度量衡（舜典）／一法度衡石丈尺（史记）／法度量、皆明壹之（秦诏）／计量法（今） |
| 古今关系 | **名恒值变**：三字词形三千年稳定，量值逐代通胀漂移（1 斤约 250 g → 661 g → 596.8 g → 500 g） |
| 语序 | "度量衡"与"衡度量／权量"变序并存义不变（阴性对照，见 §5.1） |
| 引申链 | 三家门类标准体系（先秦本义）→ 泛指一切计量（现代法与行政语用） |

## 3. 六步解析实操（古语词组版·制度枚举改造）

### ① 读语境（定场＋语篇功能定位）

- 三问：**谁说**——立法者、史家、礼家；**对谁**——天下之民、百工、商旅；**什么场合**——巡守、革命、统一、立法。
- **语篇功能问（句子型第四问移植到词组）**：这个词在章内干什么？逐条书证检索后判明：度量衡的每一次出场都挂在**政权行为动词**之后——同（舜典巡守）、谨（尧曰为政）、一法（始皇二十六年）、明壹（秦诏）。它从不描写"一件工具"，只命名"一项国家工程"。
- **产出**：场＝**国家治理话语中的技术名词**。此定性直接规定确诂必须含"制度"义——把度量衡注成"尺斗秤"（纯器物）即失去半个词义。

### ② 拆词（三家并称，定义句直接命中——系列首见）

| 训点 | 名动兼类（动词短语） | 制度本位（名词门类） | 器物链 |
| :--- | :--- | :--- | :--- |
| 度 | 度长短（d u ó） | 长度标准 | 分寸尺丈引（度以正体，取则于律） |
| 量 | 量多少（l i á n g） | 容量标准 | 龠合升斗斛（量以盛谷） |
| 衡 | 衡轻重（权衡之衡） | 重量标准 | 权（锤）＋衡（杆）＋秤盘组合（**衡＝秤杆非秤锤**——"权"才配成体系） |

- **产出**：三家并称穷举当时计量三大门类（时／温等尚无门类可占）——枚举即完备，非示举。与"柴米油盐酱醋茶"（七项穷举生活必需）同属"并称穷举"型，但度量衡穷举的是**制度门类**且每项自带完整单位系统。

### ③ 追声音（无通假；防拆词漂移）

- 度、量、衡三字在本词内**未见通假异读**，标"未见通假说"。
- 本步的实际收益转为**防字组拆散后的漂移**：①"度量"脱离"衡"独立成词后，衍生"心胸度量（d ù l i a n g）"义——字组拆散即义变，读古文见"度量"须回语境还原；②《尧曰》以"**权量**"代"度量衡"，先秦权、衡量词各有代称系统（权量＝衡＋量），并称形式不止一套——异名同指与语序不敏感互为表里。
- **产出**：无通假可立；两条拆词漂移入陷阱清单。

### ④ 查书证（定义句锚定＋量值书证——本步两处新用法）

- **定义句锚定**：本词自带班固三分定义——释义不是从用例反推义项，而是文内定义直接命中。制度词多如此（今之"法定计量单位"亦然）：**先查定义句，再集用例**，与方法文档第 4 步"探本义、查流变"的顺序在此对调。
- **量值书证**：制度词的义项含数值，数值须实物坐实——商鞅方升 200 ml、故宫诏文权 0.260 kg 级列、营造尺 32 cm、库平两 37.3 g。**释义首次需要考古报告作为证据链的一环**；纯文献考据在此失效（历代文献互相抄袭旧值，唯出土器不撒谎）。
- **产出**："度量衡＝三家标准体系"由定义句（性质）＋实物（量值）双向闭合。

### ⑤ 正反验证（核心环节）

| 检验 | 内容 | 结论 |
| :--- | :--- | :--- |
| 正例一 | 班固三分定义＋《舜典》《论语》《史记》、秦诏用例链条一贯 | 存在性坐实 |
| 正例二 | 传世标准器（商鞅方升、嘉量、诏权）与文献记载量值互证 | 实物旁证坐实 |
| 反例一（一票否决） | **"度＝度量衡总称"说**（某百科今训：度量衡统称计量，度＝总名）——若度＝总称，则"度量衡"为"总名＋两子项"层级结构；而班固三句平列对称（各冠"者……所以……也"），且《舜典》"律度量衡"四字同列，义可推及"律亦子项"——层级说被定义句式直接击穿 | **排除** |
| 反例二 | **"衡＝秤"器物说**（整秤即衡）——《律历志》"衡，平也；权，重也，衡所以任权"，衡是杆、权是锤，二字一物二件；"权（秤锤）→权衡／权力"的引申链也证明"衡"从无"整器"义 | **排除**（器物专指义；确诂采"制度＋标准器"双指） |
| 反例三 | **语序即义说**（仿"东西南北"：度量衡／衡度量若两序异义）——实测《尚书》作"度量衡"、《史记》作"衡石丈尺"、《论语》作"权量"，三序并存而历代无歧义注疏；两序用法**对称同义**，与"东南西北／东西南北"的用法不对称（典籍严守次序、仅两序通行）根本不同 | **排除**——元规则 10 需补适用判据（见 §5.1） |
| 反例四 | **古今值恒定说**（读史者默认"斤＝500 g"）——1 斤实走 250 g（秦汉）→约 661 g（唐大制）→约 596.8 g（清库平）→500 g（今市制）曲线；石之容量衡重双轨；换算必绑朝代 | **排除**——名恒值变 |
| 正例三（扩容义） | 现行《计量法》"计量"涵一切测量（电、温、光……），"度量衡"作为旧词扩容指metrology 全域 | 存在性坐实→附列为**现代引申义** |

### ⑥ 防陷阱（定稿）

- **以今律古三大坑（本例实测）**：其一，**斤值恒定**（拿 500 g 套任何朝代）——唐清之斤是今斤的 1.2～1.3 倍；其二，**进制恒定**（"半斤八两"1959 年后市制改十两，成语的物理基础已亡，成为"死进制活化石"）；其三，**石之双轨**（容量之石＝斛、重量之石＝120 斤；汉俸禄"二千石"以容量计为通说，学界有异说，标**待考**）。
