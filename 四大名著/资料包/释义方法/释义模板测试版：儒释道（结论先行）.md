## 0. 结论（先行）

> **确诂一句话**：儒释道＝**儒、佛（释）、道三家教化传统之并称总名**——"三教"框架。三字构词各不同源：**儒＝职业名**（《说文》"柔也，术士之称"——相礼之师→孔子学派）、**释＝教祖姓氏**（释迦之"释"，经东晋道安"沙门姓释"制度化为教团标识，以祖姓代教）、**道＝思想核心概念**（老庄之道，道家道教共祖一名）——三个字恰好是"身份、姓氏、义理"三种命名路径。今序"儒释道"中"儒"居首位恒定（政治正统），"释／道"次序历史浮动（儒释道与儒道释两序并存——佛道之争的语言残留）。功能性定型说："以佛治心，以道治身，以儒治世"（宋孝宗《原道论》原作"以佛修心，以老治身，以儒治世"）。**"教"字本义为教化（《说文》"上所施，下所效也"），非西方 religion 义**——"儒家是不是宗教"之问，一半是"教"字古今义错位的伪问题。

| 项目 | 判定 |
| :--- | :--- |
| 词性 | 三教并称总名（思想史框架词） |
| 三字构词 | 儒＝术士职业名→学派；释＝教祖姓（释姓制度）；道＝核心义理名——**一字一法，来源不对称** |
| "教"字义 | 汉语本位＝教化之教；近代以 religion 对译后重组为"宗教"义 |
| 词义定型点 | 北朝三教论衡（帝王主持的排序政治）→ 唐宋三教并立格局 |
| 排序规律 | 儒恒居首（正统），道释浮动（儒释道／儒道释并存） |

## 3. 六步解析实操（古语词组版·三教门类改造）

### ① 读语境（定场）

- 三问：**谁说**——帝王（排序者）、僧道儒三方（论衡者士大夫（论衡记录者）；**对谁**——朝堂与天下思想界；**什么场合**——三教论衡（朝廷仪式）、典籍注疏、民间劝善。
- **历史语篇功能**：这个词不在描述世界，而在**摆桌子**——三教论衡的实质是政治为三家排座次（座位＝资源：僧尼度牒、道观数额、科举经义）。词形（谁前谁后）即会议纪要。
- **产出**：释义必须含"排序政治"一维——纯义理（三家思想各是什么）不是这个词的释义核心，"三者并立且被排序"才是。

### ② 拆词（三字三命名法——第 2 步新式样）

| 训点 | 命名法 | 演变路径 |
| :--- | :--- | :--- |
| 儒 | **职业名** | 术士（相礼之师）→孔门六艺之教→儒教／儒家 |
| 释 | **教祖姓氏** | 释迦（Śākya）→道安释姓制度→释教／释氏／释子（以祖姓代教，如"孔教"？不同：儒家不用"孔"代称，用职业名"儒"——两教命名法自觉不同源） |
| 道 | **核心义理名** | 道路→天道义理→道家（哲学）／道教（宗教）共祖一名 |

- **构词不对称发现（本案核心）**：并称词各成员的命名来源通常同构（度量衡三家皆制度单位、柴米皆物资），儒释道却是**职业名＋祖姓＋义理名**混编——因三家并非同批造词：儒、道是汉语自名（自称），释是外来宗教借教祖姓汉化改造的名（他称转自称）——**词内藏着"两土生＋一外来"的结构**。与"诸子百家"（人／派双层）异构，与"度量衡"（同构门类）也不同构。
- **语序检验**：儒释道／儒道释两序并存（道释可换）；儒恒居首。检索通例：佛教文献倾向"儒释道"，道教文献倾向"儒道释"（各自把自己排第二），世俗政论用"儒释道"渐成今日压倒正序（音韵两序同调 rú-shì-dào／rú-dào-shì，声调无别——排序浮动纯是文化政治的残留）。**首位恒定＋后位浮动**＝语序敏感第四档。
- **产出**：确诂含三层——三家教化传统并称（本义层）、排序政治（语用层）、两土一外结构（构词层）。

### ③ 追声音（无通假；转"教"字义层防护）

- 儒、释、道无通假问题。
- 本步实际收益＝**"教"字的语义层防护**："教"古义＝教化（《说文》"上所施，下所效也"——施效结构，无所不包的文明养成活动），近代以日语径译西文 religion 为"宗教"后，"教"字新带"有神论、教会组织、救赎承诺"义涵——**"儒教是不是宗教"之争（任继愈命题）的一半，是拿 religion 义倒灌古语"教"字的层错**：在汉语本位里，"儒教"＝以儒治之教化，如"道教"原可指"以道治之教化"（汉人语，《老子》"善建者不拔"注家语境），不必含神设教会。儒家的祭天祭祖祀孔系统是否够格 religion，是宗教学的第二问，与词义考无关。
- **产出**："教"字古今义双层表入陷阱清单——释义学第一问（这个词里的"教"是什么义），宗教学第二问（儒家够不够宗教），两问不得合流。

### ④ 查书证（词义迁移史——本步核心）

- **"三教"一词的五百年漂移**：汉《白虎通》"三教"＝夏忠殷敬周文（**纵向时间轴**：三代循环之教）→北朝（六朝）"三教"＝儒道佛（**横向空间轴**：三家并立之教）→唐宋定型。迁移动力＝佛教传入后思想版图重画：旧的"三代教化循环"框架装不下新格局，旧瓶"三教"被灌入新酒（儒道佛）——**词壳恒定、坐标轴转向**（时间轴→空间轴），为"名恒义变律"添一极致样本：跨时距约五个世纪。
- **三教各起点系谱表**（刘谧《三教平心论》整合）：儒教始于伏羲画八卦（牵附，儒家自认道统更早）／道教始于老子著《道德经》（哲学起点）／佛教始于汉明帝梦金人（传入起点，永平求法，白马寺系谱）——三个起点三种性质（神话／著述／传入），又是不对称。
- **产出**：词义迁移轴＋起点系谱轴，双轴入库。

### ⑤ 正反验证（核心环节）
