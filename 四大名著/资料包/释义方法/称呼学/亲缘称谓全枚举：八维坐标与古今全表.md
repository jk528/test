> **一句话**：汉语亲缘称谓是一个以己身为原点、按**线系×世代×直旁×长幼×性别×血姻×存殁×语体**八维定位的**闭合枚举系统**——《尔雅·释亲》四章（宗族／母党／妻党／婚姻）给出最早的四通道分区（前 3—4 世纪），今称在原骨架上完成三处大改写（**舅＝岳父→"外舅"让位给"岳"；姨从妻党（妻之姊妹）换位到母党（母之姊妹），顶替"从母"；"侄"从女子专称扩容为两性通称**），其余古今同格、名目互补，系统至今闭合未破。

## 1. 八维坐标（维度划分）

任何一个称谓，先问八个维度，位格即被唯一定位（缺一不可，多余不取）：

| 维度 | 取值 | 决定什么 |
| :--- | :--- | :--- |
| D1 线系（走哪条通路） | 父党／母党／女出／妻党／夫党／姻娅互称 | 入哪个区块（B1–B10） |
| D2 世代（上／平／下，第几世） | 上四世（高曾祖考）／己世／下四世（子孙曾玄）及其外 | 行位高低；也是"五世而斩／六世而斩"的计量轴 |
| D3 直系／旁系（及其层数） | 直系／一从（堂、表首环）／再从／三从（族） | 直系单线，旁系按"从／再从／族"三环递减 |
| D4 长幼 | 伯仲叔季（男）／孟（庶长）／姊兄弟妹（平辈） | 伯叔之分、大舅子小舅子之分 |
| D5 性别（及配偶连带） | 男格／女格／其配偶连带格 | 长一格必有"配套"配偶称谓（嫂、婿、妗） |
| D6 血亲／姻亲 | 血亲（父党／母党／女出）／姻亲（妻党／夫党／姻娅） | 服制轻重、法律的"血亲"边界 |
| D7 存殁 | 生称／亡称 | 生曰父母，死曰考妣（《礼记·曲礼下》【A】） |
| D8 语体 | 面称（当面叫）／背称（对人提及）／古称／谦称／敬称 | 同一关系在不同语体里换词：父（背称）—爸（面称）—家父（对人称）—令尊（称对方） |

**八维合用示例**："妗"＝母党（D1）＋祖／父世下二等（D2）＋旁系一环（D3）＋舅之配偶（D5 连带）＋姻亲（D6）＋活着（D7）＋口语背称（D8）——八维一锁，全表中只有一个格子属于它。

**与《尔雅》四党的映射**：宗族章→父党（B1–B3、B6 的父系半）；母党章→母党（B5）；妻党章→中表与女出（被本文析为 B4 姑房跨章、B6、B7）；婚姻章→夫党＋姻娅（B9、B10）。《尔雅》无"妻党专表"（外舅见妻党章而归"外"系）——今人称妻党以"岳／内／连襟"重构，属系统改写而非简单沿用。
