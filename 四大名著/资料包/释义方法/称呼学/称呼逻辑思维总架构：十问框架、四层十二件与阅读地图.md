## 0. 结论（先行）

> **一句话**：称呼学的研究对象是**"人与人之间如何用词定位彼此"的全部逻辑**——称呼不是名词，是**事件**：以词库为库存、以立场为引擎、以通信为过程、以成本为底线。每一次开口叫人，发话方在零点几秒内跑完一条流水线——**词库取词（有什么）→立场收敛（用哪档）→帧结构组装（怎么说）→信道适配（在哪说）→成本核算（值不值）**；同时，听话方的黑盒也在并行跑解码流水线。这套流水线、它的全部事故与攻防，就是本体系的全部内容。
>
> **双公式**（体系收束，首尾相衔）：
> - **生成公式**（选词端，四因子乘法）：**最终称呼＝立场×见识×智慧×对话者**——立场定色带、见识定词库、智慧定一词、对话者定路由。三因子乘法非加法，任一为零全式归零；第四因子（对话者）由三方篇补入——同一对象，听众一换，入口即换。
> - **通信公式**（发帧端，五维分解）：**一次称呼＝WHO（路由：叫谁·对谁叫）×STANCE（立场：色带档位）×MOOD（情绪：调制方式）×CHANNEL（信道：密级等级）×LEXEME（词库：最终一词）**。
> - **衔接关系**：生成公式的输出（"该用哪一词"）正是通信公式的末维 LEXEME——**前者是导演选角，后者是成片发行**；两条公式一道，构成"从心里有数到脱口而出"再"到对面入耳"的完整链路。

**总判定表**：

| 项目 | 判定 |

**层间咬合**（体系不是仓库，是流水线）：

- L1→L2：词库向引擎供词——场景与时代直接是立场篇六维坐标中的两维（D5/D6）；
- L2→L3：引擎选定的词作为 LEXEME 维进入帧结构，评价色决定帧的意图位（升档/降档），情绪定 MOOD 调制；
- L3→L4：协议知道帧怎么发，治理层决定发什么类型的帧（敬帧/攻击帧/增益帧）并核算这帧划不划算；
- **一条主线贯穿**：**库存→运算→传输→结算**——每一层都作用于同一枚称呼，如同四个车间加工同一件产品。

**读图口诀**：**词库给米，立场掌勺，信道传菜，成本买单**——四层缺一，饭做不成。

## 3. L1 词库层：两网一桥（有什么词）

### 3.1 件①亲缘网——汉语唯一可穷举的称呼词库

以己身（Ego）为原点，八维坐标（线系×世代×直旁×长幼×性别×血姻×存殁×语体）唯一定位每个称谓——《尔雅·释亲》四章给出最早分区，今称在原骨架上仅三处大改写（外舅→岳父；姨从妻党换位母党；侄扩容两性通称），**系统至今闭合未破**。规模 110 枚举单位。谦敬双轨（称己亲属"家／舍／犬／拙"系、称人亲属"令／尊／贤"系）不可互串。

**关键性质**：格有限（血缘网络是有限图），故**可穷举**——一人立原点，全表皆可得。

### 3.2 件②场景网——永不闭合的词库

六大场景区（B1–B8：通用社交／官场体制／商务职场／学界师门／市井江湖／服务业／网络社区／古典书面），规模 91 枚举单位。**关键性质**：格随场景增生、随时代变味（小姐两度反转、"同志"分场合），故**不可穷举，只能做代际快照**——与亲缘网"可穷举/不可穷举"构成一对镜像：**血缘格有限而稳定，场景格无限而流变**。

### 3.3 件③拟亲属桥——两网之间的人行桥

亲属词社会借用（大哥、大姐、叔叔阿姨、大爷、家人们）：**血缘的温度可以借，血缘的义务不能借**——借出货自带"年龄暗示"风险区（阿姨、大姐的变味即踩线）。

### 3.4 本层三定律

| 定律 | 内容 |
| :--- | :--- |
| 万能通货更替律 | 每个时代都有一个安全万能称呼，约 20–40 年一轮换：老爷→同志→师傅→老师／美女→亲→宝 |
| 语用腐蚀律 | 泛化越广变味越快——三阶段：溢价期（安全礼貌）→透支期（滥用）→崩盘期（敬义剥离） |
| 拟亲属储备律 | 亲缘词库是社会称呼的蓄水池，借出必带年龄暗示风险 |

## 4. L2 生成层：选词引擎（这个词怎么选）

立场篇的核心思想转折：**称呼不当名词表查，当谓词算**——先算立场函数，再查名词表；立场定了，词几乎是唯一的。

### 4.1 三个调制器（对选出的词做三重定性）

**件④立场调制器**——六维坐标（对象位 D1／极性 D2／通道 D3／内外 D4／场景 D5／时代 D6）：对彼极性五档（敬—平—亲密—贬—蔑）×对己三档（谦—平—自大），在三通道（面称/背称/书称）展开成完整矩阵。三条硬规律：**让渡分界律**（谦让渡地位、贬让渡人格——"家父"得体与"奴才"失格的分界）、**蔑称构词律**（职业＋等第，九式：加贬缀／降身份场／借贱籍……）、**蔑称挪用律**（群体自领攻击词则攻击性归零转同盟——牛马／码农／社畜；与语用腐蚀律恰好互为镜像：**一个敬词在堕落，一个蔑词在升华**）。

**件⑤评价调制器**——同一对象备有褒／中性／贬三套现成名（周公/姬旦/周贼式）：同人异称，词色即站队。**三色不对称律**（贬词库远大于褒词库）、**中性最贵律**（长期中性词最稀缺——"先生"百年不锈）、**褒端先锈律**（敬词先腐蚀）；转换四机制（立场换色/时间换色/自他换色/谥法定色）；死亡词谱八级（病故→牺牲→阵亡→毙命……——选词即站队）、春秋笔法（一字定色，"郑伯克段"式书法）。

**件⑥情绪调制器**——情绪是称呼的底层驱动与能量源：三轴（强度／复杂度／分辨率），怒喜哀惧四谱梯度（愠＜恚＜忿＜愤＜怒的先秦分辨率），复合三型（对冲/邻近/社会型）；**颗粒度即分辨率律**（词汇有多细，体验才能被看见多细）；骂人的能量表＝怒谱（攻击帧的燃料读数）。情绪调制器决定 MOOD 维：平静叙述／盛怒攻击／含笑试探，同词不同 MOOD 即不同帧。

### 4.2 生成器三步与四线检查（操作化，详立场篇 §7）

```
STEP 1 定立场（四问：对象位？极性档？通道？内外与场景？）
STEP 2 查型谱（主表＋专表＋三色对照表按坐标检索）
STEP 3 套构词公式（敬谦八式／构词九式）， 过风险检查四线
```

风险四线：**年龄线**（大姐／阿姨越线即事故）／**时代线**（通货贬值期／敏感期）／**场景线**（敬语进昵场、昵称进职场）／**通道线**（背称词当面用）。

四步与四因子的对应：STEP1＝立场、STEP2＝见识、STEP3＝智慧（*生成公式就是这三步的原理化*）。

## 5. L3 执行层：通信协议（这帧怎么发出去）

### 5.1 件⑦点对点协议（双机篇：你我）

**五段回路**：信号源（编码）→介质Ⅰ→接收方（黑盒）→介质Ⅱ→被接收方（闭环）——称呼＝**关系状态同步协议的握手帧**："X 老师"＝我声明我们是敬距关系。**编码五要素**、三种信道（声波/书面/中继）＋噪声四源、**黑盒四部件**（解码器＋状态寄存器＋转移函数＋输出器）与**黑盒三定律**（**不可观测**／**路径依赖**——十年前一声"胖子"今日仍有权重／**情绪污染**）。反馈帧语义：回称＝ACK、纠正＝NACK、沉默＝丢包。协议现象十项（握手／超时重传／版本失效／禁用信号位〔避讳〕……）。

**本件定律**：关系的本质＝两台状态机在回路中维持的**共识状态**——非强一致而是**最终一致性**；"名不正则言不顺"＝握手失败则整条会话报废（两千五百年前的协议学表述）。

### 5.2 件⑧网络协议（三方篇：你我他）

**三址帧**：To（收件人）／CC（在场抄送）／BCC（暗送）——A 喊"王总"，收件人是王，听众是全屋：**一旦引入第三方，称呼就从"两个人的事"变成"演给第三个人看的两个人的事"**。"指桑骂槐"＝To 写着桑树、真寄给槐树后的猴子。**称谓路由表**：称谓是二元函数 **g（对话者，对象）**＝词——同一父亲三个入口："我爸"对同事、"咱爸"对妻子、"你爸"对妻子生气时。**谦敬系统的三方基因**：家／令全套为"当着外人说家人"设计——第三方不是新发明，是先秦礼仪的第一批代码。路由事故三型（传话改包／抬错人／当众失序）与齐美尔"渔利的第三者"（路由投毒）。

### 5.3 件⑨信道密级（安全篇：在哪说）

**场合即密级**——五级信道：**L1 国礼**（仪式公开：全控制全记录零真情——最公开反而最安全）→**L2 公共**（墙有耳）→**L3 私密**（凭证准入但客厅会漏）→**L4 安全屋**（合约保密，威胁在时效——今天的枕边人≠明天的保密人）→**L5 潜意识**（终极自管仓，威胁在自己——口误/梦/身体是三条越狱通道）。**正反律**：公开度↑＝帧模板化↑＝信息量↓（国礼的"废话"是安全设计）；密级↑＝帧裸露度↑（安全屋里的小名是明文）。开口前**评估四问**：在场盘点→密级评估→后果评估→撤回评估——密级错配即事故（酒后失言＝L4 内容发进 L2 信道）。

## 6. L4 治理层：应用与成本（这帧怎么反着用·值不值）

### 6.1 正用基准：敬谦系统

正用就是礼仪本身——总纲"自卑而尊人"（《礼记·曲礼》）；敬谦构词八式（令尊系／家父系）；让渡分界律守底线（谦得体、贬失格）。**正用是体系的默认态，L4 其余两件是它的镜像与底账。**

### 6.2 件⑩攻击帧（骂——协议的战争用法）

**四支柱**（统合总纲）：

| 支柱 | 内容 |
| :--- | :--- |
| 燃料定律 | 骂生效前提是对方有**分别心**（内化的价值等级表）——分别心为零者，天下最强的骂也伤不了；**骂的威力一半由被骂者提供** |
| 靶心定律 | 每人心中一张价值排序表（出生/智识/贫富/容貌/年龄/名节/能力/关系八轴）——骂中榜首破防，骂偏徒劳（靶谱错配：对和尚骂酒肉无效） |
| 真值类型学 | **虚构骂**（攻击不存在或未发生之事——"小畜生"骂出生：不可反驳，只能不接）／**实际骂**（攻击现状——"乞丐"骂穷：以真为毒，反驳即加深）／**混合骂**（实际锁死退路＋虚构压上审判——骂死王朗构型） |
| 破防公式 | 破防＝靶心命中×分别心共振×（不可驳性或深度认同）——三态：爆发／溃缩／后疗愈 |

防御五法（不接帧／自干／自嘲移靶／破防承认／燃料拆除——修行级）与免疫祖型（宋荣子"举世非之而不加沮"）：**防御不是挡帧，是撤燃料、移靶心——骂人攻防的最终战场在双方心里**。骂出生的伤害走三方 CC 帧（骂在儿身，痛在爹娘）——攻击帧全套复用 L3 的三址与密级（**当众骂重于私下骂十倍**：信道选择本身是攻击的一部分）。

### 6.3 件⑪增益帧（夸——攻击帧的镜像反演）

- **燃料反演**：分别心→**共鸣心**（认同其珍贵才夸得出诚意；共鸣为零的夸＝拍马）；
- **公式反演**：夸效＝靶心命中×共鸣厚度×可信度（与骂效同构——变量仍在对方手里）；
- **真值反演**：实际夸以真为药（夸真实成就，一句顶一万句）／虚构夸不可接收（对方无法 ACK 一帧不存在的东西——"我配吗"的猜疑链）／策略夸（夸未来可能成的——教育者的杠杆，过量则透支未来）；
- **风险镜像**：夸错靶（对不看重处夸＝把最不自信处放上聚光灯——**等价于骂**）、夸不到点（隔靴搔痒）、夸过度（捧杀滑坡链）。
- **结论**：骂与夸共享同一张靶心谱、同构的信道、同一套防御动作——**同一门手艺，方向相反**：骂是把人拉下他站的台阶，夸是把人送上他想站却不敢站的那级。

### 6.4 件⑫成本底账（夸骂经济学——每次开口的账本）

- **三重成本**：能量（微）＋**风险（主项：关系烧桥／报复升级／名声损耗）**＋机会（此帧占用的信道与时间）——发出任何帧都有成本；
- **两向收益**：获利型（夸——买未来资源）／避损型（骂——买即时边界）；**损失厌恶不对称**（损失之痛约两倍于收益之乐）→ 避损型骂的心理预算永远高于获利型夸——**骂比夸激烈的结构性原因不是愤怒更强，是账本不对称**；
- **handicap 铁律**（成本定可信）：**花多少钱的话，就值多少钱的信**——雪中送炭＞锦上添花（患难本身就是成本）；机制核验三问（有无真实成本？成本与质量绑定否？作弊空间封死否？）；
- **零成本通胀律**：无成本信号必然超发→贬值→需加成本重建（"美女"的贬值史、"亲"的油腻、夸夸群空转）——**凡是不花本钱的夸，最终都不值钱**；
- 市场终裁：长期净收益＝Σ（预期收益×兑现率）−Σ成本——只发不收者终被出清；**最高级的夸骂功夫都是"出市"功夫**（共鸣心之夸不入流通，拆除燃料之旅不入战场——皆无账可算）。
