# 称呼信号学解构·三方篇：第三方的引入与你我他的通信拓扑

> 文档性质：称呼信号学解构（双机篇）的**直接续篇**——用户命题：双篇只算了"你和我"，现在引入第三方，解构"你我他"的三方结构。双篇是点对点协议，本篇是**多机网络协议**。

## 0. 结论（先行）

> **一句话**：一旦引入第三方，称呼就从"两个人的事"变成"**演给第三个人看的两个人的事**"——A 喊一声"王总"，收件人是王，但听众是全屋：这帧信号同时携带对王的声明（我认你的地位）、对在场者的声明（我们都认他的地位）、对自己的声明（我懂规矩）。三方结构的三次质变：①**帧的三址化**（To 收件人／CC 在场抄送／BCC 暗送——"指桑骂槐"＝To 写着桑树、真寄给槐树后面的猴子）；②**称谓的路由表化**（称谓不是 f（对象）的一元函数，而是 g（对话者，对象）的二元函数——"我爸"对同事说、"咱爸"对妻子说、"你爸"对妻子生气时说：同一个父亲，三个入口）；③**协议的公共化**（谦敬系统整套是为第三方设计的——"家父""令尊"的全部功能就是"当着外人说家人"，三方结构不是新发明，是先秦礼仪的第一批代码）。一句话："对子骂父，则是无礼"（《世说新语》七岁元方语）——古人早就知道：骂帧的伤害半径不止收件人。

**总判定表**：

| 项目 | 判定 |
| :--- | :--- |
| 三方与双方的关系 | 质变非叠加：出现广播、路由表、表演性、传话链四种双方模型不存在的新协议 |
| 帧的地址结构 | 三址：To（收件人）／CC（在场抄送）／BCC（暗送——真收件人藏在帧外） |
| 称谓索引维度 | 二元函数：g（对话者，对象）→词——对象相同，听众不同，称呼不同 |
| 谦敬系统的本质 | **三方协议的最古老成品**：家／令、尊／舍全套针对"当着外人谈家人"设计 |
| 第三方角色谱 | 旁观者／见证者／仲裁者／信使／竞争者／权威者（六角色六种协议行为） |
| 三方最危险操作 | 传话（信使改包）与抬错（当着 A 高称 A 的对手） |
| 与双篇的接口 | 双篇的黑盒定理全部升级：黑盒不止解码帧，还解码"这帧是发给我的吗""还有谁在收" |
| 最大陷阱 | ①以为称呼只被收件人听见（漏看 CC 域）；②以为对同一个人只有一种叫法（漏看路由表）；③以为谦敬是双方礼节（漏看其三方本质） |

**证据链一句话**：《世说新语·陈太丘与友期》"尊君在不／家君期日中／对子骂父则是无礼"一段藏齐三址、路由、三方违礼三机制 →《论语·述而》陈司败案（避君讳＋借信使转述＋回调认错）展示三方通信完整五帧 →《礼记·曲礼上》"入竟而问禁，入国而问俗，入门而问讳"＝进入他人通信域前的协议查询 → 齐美尔三方论（渔利的第三者 tertius gaudens）立社会学地基 → 婆媳"你妈／咱妈／妈"三段升级（D 级通行观察）证路由表演进 → 本篇模型成。

## 1. 帧的三址结构（升级一：从单播到广播）

双方模型里，帧只有一个收件人。三方场景中，帧携带三个地址：

| 地址 | 语义 | 称呼实例 |
| :--- | :--- | :--- |
| **To**（显式收件） | 帧的语法对象——词面上的那个"你" | A 喊"王总早"——To=王总 |
| **CC**（在场抄送） | 所有在场者的隐式收件权——他们都在解码这帧 | 全办公室同事都收到了"我认同王总的地位"的声明 |
| **BCC**（暗送） | 帧的真正目标藏在词面之外——显式收件人只是路由借口 | "指桑骂槐"：To=桑（倒霉的传令兵），真收件=槐后的猴子——**杀鸡儆猴的协议学定义：目标地址造假** |

**三址三现象**：

1. **抬称表演**——权威者（领导）入场瞬间，全员对第三方的称呼集体升档（"老王"变"王总"，音量提高一度）：这帧 To 是王，真目标 CC 是**在场所有人对协议版本的确认**——广播同步事件，一次完成全网协议版本升级。
2. **降称区隔**——孩子当同学面拒绝叫"爸爸"而说"那个人说了算"：To 不变（父亲仍是指称对象），但帧的极性位被刻意拉低——**牺牲一段私人关系，换取在另一个听众域（同侪）的身份声明**。
3. **骂帧的辐射半径**——"对子骂父，则是无礼"：客骂陈太丘（帧 To 本是元方之对话语境中的父亲），但元方在场即被抄送——七岁小孩一眼看穿：这帧伤害的是我们两个人。**三方礼仪的立法原理：帧的实际伤害域＝To＋在场血亲域**——当着妻子骂她丈夫、当着父母骂其孩子，都是双倍伤害帧（古礼"当面教子，背后教妻"？反着用——当面训子可以，当众骂妻即是把私帧广播化）。

## 2. 称谓路由表（升级二：一维索引变二维索引——本篇核心贡献）

双篇模型默认：一个人一个称呼。三方现实是：**同一个人在你的词库里有很多个入口，按"正在跟谁说话"切换**——

**称谓是一元函数还是二元函数？路由表证明是二元**：

```
称呼 ＝ g（对话者，对象）——不是 f（对象）

A 的路由表（节选）：
────────────────────────────────────────
对话者      │ 对象（A 的丈夫）  │ A 所用称谓
────────────┼──────────────────┼──────────
同事        │ 丈夫             │ "我家先生"
闺蜜        │ 丈夫             │ "老陈""我们家那口子"
婆婆        │ 丈夫             │ "他""陈明（直名，敬避夫名反不可）"或"明儿"
孩子老师    │ 丈夫             │ "陈明爸爸"
────────────────────────────────────────
```

**"我爸／你爸／咱爸"三词三档**（汉语三方称谓的基因级标本）：同一位父亲，随对话者与情绪切换——

| 词 | 对话者语境 | 路由语义 | 极性温度 |
| :--- | :--- | :--- | :--- |
| **我爸** | 对外（同事／朋友） | 声明归属：血缘直连，外人止步 | 中性（默认路由） |
| **咱爸** | 对配偶 | 声明合并：你的父亲就是我的父亲——**婚姻协议的关系合并手续** | 高（拉进） |
| **你爸** | 对配偶（冲突时刻） | 声明拆分：这老头归你，别摊给我——**路由的临时降级，关系退回声明** | 低（推开） |

同源系统："你儿子／咱儿子"（母亲对父亲说，责任推卸与共同体的瞬时切换）；"你妈／咱妈／妈"——**婆媳称谓的三段升级协议**：婚后先叫"咱妈"（快进协议：跳级声明合亲）或"你妈"（保持距离），到"妈"（无前缀直呼）是关系状态机的**显式 commit**——直呼单字"妈"那一刻，两个家族的路由表正式合并。这个升级不可逆的民间自觉（再从"妈"改回"咱妈"即关系破裂的信号）证明：**称谓前缀就是关系状态机的版本号**。

**路由表事故三型**：①**路由切换失败**——用错了对话者入口（拿跟闺蜜的亲昵称谓跟婆婆说丈夫，帧到婆婆黑盒被转移为"轻浮"）；②**双入口并行暴露**——电话这边说"我们王总"（对客户），转身对同事说"老王咋还没来"，被客户听见——**两套路由表同台，声明互相打脸**；③**旧路由残留**——离婚后忘改口，仍在孩子面前说"你爸"时用了婚姻期的"咱爸"语调——路由表未同步更新的情感幽灵帧。

> **路由表是"最终称呼总公式"（立场×见识×智慧）的三方修订**：公式补第四维——**听众维**。立场定色带、见识定词库、智慧定一词，如今再加"对象×听众"二元查表：同一智慧，对同一人，因听话者不同而当选不同词。

## 3. 第三方角色全谱（六角色六协议）

| 角色 | 协议学定义 | 典型场景 | 该角色在场时的称呼效应 |
| :--- | :--- | :--- | :--- |
| **旁观者** | 被动 CC 节点——只收不发 | 电梯里的陌生人 | 双方称呼自动升半档（前台化）——**旁观者在场本身即是协议约束** |
| **见证者** | 存档节点——帧将被记录并复述 | 记者、史官、媒人 | 称呼进入书写档（改用书称通道）；"有证人"的会话更谨慎 |
| **仲裁者** | 被动升级为判定节点 | "你给大家评评理" | 双方对第三方的称呼刻意升格（"您给评评"）——**向裁判席提交的状态声明** |
| **信使** | 双向中继——帧的转发端口 | 传话的中间人、家庭里的孩子 | 转述语法："我哥说……""你妈让你……"——信使必须在帧里声明路由头 |
| **竞争者** | 对同一 To 的通道争用 | 情敌、二孩争叫"妈妈"、夺嫡诸子 | "我的""咱们"占有性前缀爆发——**排他帧的出现是竞争者上线的标志** |
| **权威者** | 协议管理员——可改全网版本 | 领导、族长、老师 | 全员对其及相互间的称呼升档同步（"组播更新"）；权威离场后逐帧回落 |

**齐美尔三方论的接入**【D 社会学常识】：第三者三种经典姿态——**渔利的第三者**（tertius gaudens：AB 相争，C 得利——两人争夺同一称呼权，C 坐收声明红利）；**中介者**（mediator：调停者把 A 帧翻成 B 可接受的帧——外交辞令的专业即"改帧"）；**分治者**（divide et impera：故意错开路由表，让 AB 用互相冲突的称呼各自表态——离间的协议学本质是**路由投毒**：向 A 声称 B 背后如何称呼你）。

## 4. 三方拓扑六形（AB 之间的每种关系都套着 C 的位置）

| # | 拓扑形 | 结构 | 协议态 | 实例 |
| :---: | :--- | :--- | :--- | :--- |
| 1 | **现场三角** | A、B、C 全在场 | 广播态：所有帧三址 | 饭桌上夫妻对C谈家常，每句互相的称呼都被第三者解码 |
| 2 | **缺席三角** | A 与 B 对话，谈不在场的 C | 转述态：C 的路由入口被调用 | "你妈说你……" |
| 3 | **信使三角** | A→C→B（C 是信道） | 中继态：帧经手第三机 | 经孩子传话的婆媳："跟奶奶说饭好了" |
| 4 | **隔离三角** | A、B 在场，C 被协议性拒提 | 禁区态：C 的路由入口禁用 | 妯娌同席绝口不提分家事 |
| 5 | **杠杆三角** | A 对 B 用 C 抬升或施压 | 背书态：拉第三方信誉给帧加签 | "连你师尊都说……""这可是老X的意思" |
| 6 | **仲裁三角** | A 邀 C 评 AB 之争 | 求断态：向第三方提交双方帧 | 当着领导吵到桌上"您说句公道话" |

**拓扑互换**：所有家庭／职场／政治戏剧的深层结构就是这六形的排列组合——同一组人，换一次拓扑（谁进来、谁出去、谁被隔离、谁升级为仲裁），称呼系统全盘重写。

## 7. 经典三方案例全解（五案——书证锚区）

### 7.1 陈司败案（《论语·述而》7.31）——三方通信完整五帧的教科书

原文【A 多源核实】："陈司败问：'昭公知礼乎？'孔子曰：'知礼。'孔子退，揖巫马期而进之，曰：'吾闻君子不党，君子亦党乎？君取于吴，为同姓，谓之吴孟子。君而知礼，孰不知礼？'巫马期以告。子曰：'丘也幸，苟有过，人必知之。'"

**逐帧诊断**：①陈司败发帧（To=孔子，问昭公）——**设问即陷阱帧**（昭公违礼娶同姓，答"知礼"即偏袒，答"不知礼"即犯"臣言君恶"之讳）；②孔子答"知礼"——**避讳协议压倒诚实协议**：昭公作为不在场第三方（尊者），其路由入口对孔子是禁用位（"为尊者讳"）；③孔子退场后，陈司败揖**巫马期**而发难——**To=巫马期，真 To=借门徒回调孔子**（BCC 帧：当面驳君子是撕破脸，借第三方转述既送达批评又维持外交——春秋外交辞令的标准操作）；④巫马期以告——信使忠实转发（未加注的模范中继）；⑤孔子"丘也幸，苟有过，人必知之"——**状态更新并向全网广播**：不辩解、不追责信使、自认路由错误。五帧四跳：设陷帧、避讳帧、间接帧、中继帧、认错帧——三方通信的完整时序图。

### 7.2 陈太丘案（《世说新语·方正》）——"尊君／家君"双轨与三方违礼条款

原文【A 多源核实】："客问元方：'尊君在不？'答曰：'待君久不至，已去。'友人便怒曰：'非人哉！与人期行，相委而去。'元方曰：'君与家君期日中。日中不至，则是无信；**对子骂父，则是无礼**。'"

**双轨同框**：客问元方之父用"**尊君**"（对他人之尊长的专用路由——敬），元方自称父亲用"**家君**"（对他人称己方尊长的专用路由——谦）——**同一个陈太丘，在一场对话里被双方各自按自己的路由表称呼**，一敬一谦，严丝合缝——三方称谓路由的最美演示。而客人失约后怒骂，元方的反击直指协议要害："对子骂父"＝三方违礼条款：骂的是 To 之外的父亲，伤害的是在场的儿子——帧的**辐射域大于收件域**，即为无礼。七岁即通协议，故入《方正》。

### 7.3 入竟问禁（《礼记·曲礼上》）——进入他人通信域前的协议查询
