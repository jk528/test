## 0. 结论（先行）

> **一句话**：称呼不是名词，是**立场的函数**——f（对象位 × 通道 × 极性 × 内外 × 场景 × 时代）→ 具体称呼。极性谱远不止敬与谦两极：**敬—平—亲密—贬—蔑**构成对彼五档，**谦—平—自大**构成对己三档，八档在三个通道（面称/背称/他称）里展开成完整矩阵。极性的三条硬规律：①**让渡分界律**（谦向对方让渡地位，贬向对方让渡人格——"家父"得体、"奴才"制度化的分界线）；②**蔑称构词律**（蔑称九成产自"职业＋等第"：或加贬缀〔臭＋老九〕、或降身份场〔大夫→戏子〕、或借贱籍〔皂隶〕——元代"九儒十丐"十等序列是其制度的完成形态）；③**蔑称挪用律**（蔑称被指称群体自己认领后攻击性归零转同盟——"牛马""码农"自称即是；与《社会称呼篇》"语用腐蚀律"恰好反向）。地址层之外另有**评价层**——同一对象备有褒／中性／贬三套现成名字（第 6 节）：同人异称，词色即站队。全系统收束为总公式：**最终称呼＝立场×见识×智慧**——立场定色带，见识定词库，智慧定一词（第 9 节展开，用户命题）。

**总判定表**：

| 项目 | 判定 |
| :--- | :--- |
| 系统性质 | 立场网络——对象与场景皆不变时，立场（谁叫／怎么叫／当不当面叫）仍使称呼变化 |
| 对彼极性五档 | 敬（君）→平（汝，挚友）→亲密（你小子）→贬（匹夫）→蔑（竖子） |
| 对己极性三档 | 谦（在下）→平（我）→自大（乃公——对己的"负谦称"） |
| 三通道 | 面称（当面叫）／背称（对人提）／书称（书面）——亲缘篇两栏制扩为三通道 |
| 内外维 | 家父／令尊之别：己方亲属于外人称"家"，对方亲属于己称"令"——内外就是立场 |
| 蔑称主产地 | 职业＋等第（元"九儒十丐"，谢枋得／郑思肖双源，版本异文见 §5.3） |
| 通用模板 | 第 7 节：三步生成器＋构词公式九式＋称呼卡 |
| 三色评价层（§6） | 同一对象有褒／中／贬三套现成名——十类对照＋转换四机制（立场／时间／自他／谥法）＋死亡词谱八级活体检验 |
| **最终称呼总公式** | **最终称呼＝立场×见识×智慧**——立场定色带、见识定词库、智慧定一词；乘法关系，任一为零全式归零（§9 展开，用户命题） |
| 最大陷阱 | ①谦贬不分（自贬过度即失格）；②通道错配（背称词当面用／面称词书面用）；③蔑称不识史（"戏子""臭老九"的等第背景）；④极性旧档残留（"同志"在部分语境仍是敬语） |

**证据链一句话**：《礼记·曲礼》"自卑而尊人"立总纲 →《史记》"乃公"（自大自称）＋"竖儒"（蔑称）双出 →《孟子》"公输子"＋《庄子》"运斤成风"（斧正典）定敬语动词 → 谢枋得《叠山集》／郑思肖《心史》双源证"九儒十丐" → 清代奴才制（满汉臣工分途）证自贬制度化 → 现代语用（码农／牛马）证蔑称挪用律 →《春秋》“郑伯克段”“天王狩于河阳”书法＋《孟子》“乱臣贼子惧”证一字褒贬 → 谥法（《逸周书·谥法解》）证褒贬制度化 → 三色评价层、矩阵、模板与总公式成。

## 1. 立场坐标系（六维）

| 维度 | 取值 | 决定什么 |
| :--- | :--- | :--- |
| D1 对象位 | 自称／对称／他称（提第三方） | 入主表哪一区（§2） |
| D2 极性 | 对彼：敬／平／亲密／贬／蔑；对己：谦／平／自大 | 入哪一带 |
| D3 通道 | 面称／背称／书称 | 面上可昵、背后须描述、书面可抬格 |
| D4 内外 | 自己人／外人 | 己方亲属于外人前称"家Ｘ"，于家中直呼 |
| D5 场景 | 承《社会称呼篇》B1–B8 | 通行词库与腐蚀状态 |
| D6 时代 | 古／今／退场中 | 极性档位随时代整体平移（"同志"从通货到戏称） |

**核心思想转变**（与前两篇的分野）：亲缘篇与场景篇都把称呼当**名词表**查；本篇把称呼当**谓词**算——先答四个问题（我以什么身份、对谁、当不当面、内外），再查词。**立场定了，词几乎是唯一的**。

**概念辨析（释义）**：

| 概念 | 定义 | 分界 |
| :--- | :--- | :--- |
| 自谦 | 礼制内自愿、得体地自降一档 | 让渡**地位**（在下、晚生） |
| 自贬 | 让渡人格或制度强制的过度自低 | 让渡**人格**（奴才、草民）；或非自愿（清代旗制） |
| 敬语 | 礼制内抬对方一档 | 有制度边界（令尊、阁下） |
| 谀语 | 越界的敬（抬到失格） | 敬语过极限即谀（"老板英明"式滥用） |
| 贬称 | 压低对方一档的对称 | 有愤怒语境（匹夫！） |
| 蔑称 | 否定对方身份资格的称呼 | 连愤怒都省了（竖子——不屑之轻） |
| 昵称 | 亲密者间的低位互称（你小子） | 贬的形式、爱的内容——**负极性正使用** |

## 6. 褒贬中性三色词全谱（评价层：同人异称——据用户命题增补）

> 主表与专表一二三管的是**地址层**（被称呼的对象坐在哪一格）；本节开**评价层**：给“人”定性的称谓词——同一个对象，词库里现成备着**褒、中性、贬**三套名字。评价层是立场最裸露的地带：地址层失当尚可推说失礼，评价层选错词直接交代立场——**词色即站队**。

### 6.1 三色的生成机制与三条规律

| 色 | 生成机制 | 代表词 |
| :--- | :--- | :--- |
| 褒称 | 诉诸超常——以稀有物、功业、美喻拔高一档 | 国士、翘楚、巾帼 |
| 中性称 | 诉诸事实——以身份、职能、数量直述本相 | 士人、官员、百姓 |
| 贬称 | 诉诸降格——换视角（以贱物／贱业／私德代全人） | 独夫、乡愿、铜臭 |

**三规律**：①**褒贬不对称律**【E】——褒称须有超常事实支撑，贬称只须降格视角（未必诬枉），故贬词产量恒大于褒词（骂人的词总是最多）；②**中性最贵律**——三色词都不难，难的是不着一色：史笔的“持平”是评价层的最高功力（见 6.5 春秋笔法）；③**褒端先锈律**——承场景篇语用腐蚀律：评价词的褒端最先通胀（大师、专家、泰斗相继贬值），老练的褒称正在转向**事实型称号**（X 奖得主、X 学科奠基人——事实不可贬值）。

| :--- | :--- | :--- | :--- |
| 德望之士 | 国士（《史记》“国士无双”【B】）、君子、耆宿 | 士人、长者 | 乡愿（《论语·阳货》“乡愿（原），德之贼也”【A】——骂“老好人”的祖词）、伪君子、道学先生（敬词贬化） |

### 6.3 三色转换机制（四条）

1. **立场换色**（同时同人异口）：同一场战争，己方“起义”、敌方“叛乱”；同一位死者，我方“牺牲”、敌方“毙命”——评价词是立场的直接输出，最诚实的身份证明。
2. **时间换色**（异时同人）：王安石——时人贬称“拗相公”（宋人笔记【C】），后世尊“荆公”（封号敬）；曾国藩——民谚“曾剃头”（贬）对朝廷谥“文正”（文臣谥极）。词色随定谳而翻转，盖棺犹可论定再翻（钩连《余绪语义场全枚举》：身后名的计量维度）。
3. **自他换色**（同词异性异口）：“老朽”自称谦、他称贬；“孺子”骂幼是蔑、“孺子可教”是识——褒贬不止由词决定，还由**谁在对谁说**决定（立场维 D1×D2 同调）。
4. **制度化换色（谥法）**：国家把褒贬做成制度——《逸周书·谥法解》“经纬天地曰文”（极褒）／“好内远礼曰炀”（恶谥）【B】：隋炀帝之“炀”正是唐人所加。谥法＝官定三色词库；当代残存形态：授勋、称号、处分决定——褒贬文书化，古今一贯。

### 6.4 死亡词谱（三色理论的活体检验：八个“死”字）

| 词 | 色 | 语感与机制 |
| :--- | :--- | :--- |

| 殉国／殉职 | 褒 | 以使命格其死 |
| 阵亡 | 中（军事） | 战场事实陈述 |

| 死 | 中（裸） | 最中性也最硬 |

### 6.5 春秋笔法：一字褒贬的祖制（评价层的政治学原型）

- **一字定色的祖型**：《春秋·隐公元年》书“郑伯克段于鄢”——《左传》释：“段不弟，故不言弟；如二君，故曰克；称郑伯，讥失教也。”【A】一个“克”字（当两国交战讲）贬段之不弟，一个“伯”字（不称兄）讥庄公失教——**两贬嵌在一行五字里**。
- **讳书即立场**：《春秋·僖公二十八年》书“天王狩于河阳”——实为晋文公召周天子，仲尼曰“以臣召君，不可以训”，故书天子自行“田猎”替尊者讳【A】——委婉本身就是判决。
- **威力**：《孟子·滕文公下》“孔子成《春秋》而乱臣贼子惧”【A】——一个字的贬，胜过刀斧；后人括范宁《穀梁传序》语意为“一字之褒，荣于华衮；一字之贬，严于斧钺”（措辞待核）【C】。
- **当代业态**：《史记》“太史公曰”、朱熹《通鉴纲目》书法（“微言大义”语本《汉书·艺文志》【B】）、今日新闻标题的选词（“击毙”vs“打死”vs“身亡”）——**史论、标题、讣告，全是春秋笔法的当代业态**。
- **与本篇总公式的关系**：春秋笔法是“最终称呼”的极端形态——在**一个字**里完成立场（尊王室）、见识（知召王实情）、智慧（讳而不没其实：既不撒谎也不全说）的三重收敛，然后“狩”字出口。一字即全公式。

## 7. 通用模板：称呼生成器（用户核心诉求）

### 7.1 三步操作

```
STEP 1 定立场（四问）
  ① 对象位：自称 / 对称 / 他称（第三方）？
  ② 极性档：敬 / 平 / 亲密 / 贬 / 蔑——（自称则：谦 / 平 / 自大）
```

## 9. 钩连：三部曲总收与最终称呼总公式

- **亲缘篇**（血缘网络）答"你是谁"：格可穷举，一人立原点全表出。
- **场景篇**（场景网络）答"我们在哪"：通货更替、语用腐蚀、拟亲借用。
- **本篇**（立场网络）答"**我以什么身份叫你**"：极性八档×三通道×内外——立场一变词变。
- 三网咬合处：拟亲属称谓是亲缘网向两网的借货口；场景通货是本篇 D5 维的词库池；而本篇的极性轴给前两篇每格加了"档位标签"——**前两篇是名词表，本篇是动词表**：拿到任何称呼，先算立场函数，再查名词表。
- **最终称呼总公式（用户命题定纲）**：称呼的本质，是**立场、见识、智慧共同收敛出的最终那个词**。三因子分工——**立场定色带**（本篇极性系统：你是谁、站哪边、以何身份开口——决定敢用与该用哪一档）；**见识定词库**（三部曲全部词表与词史：血缘格、通货史、漂移史——不知“巾帼”本为激将之辱，用不好“巾帼英雄”；不知“小姐”两度反转，开口就踩雷）；**智慧定一词**（场景适配、时代敏感、对象接受、后果评估——§7.4 四线检查的全部）。**三因子是乘法不是加法**：有立场无见识＝敢判而词穷（只剩“好人坏人”）；有见识无立场＝词富而不敢断（考据家失语）；有立场有见识而无智慧＝词对而境错（真话失时即失礼）——任一为零，全式归零。
- 一句总收（修订）：**称呼的完整地址＝场景（哪）＋对位（谁）＋立场（哪个我）＋评价（什么色）**——三部曲三张网加评价层即四层门牌；而门牌的最终落笔，是**立场×见识×智慧的乘积**——称呼从来不是查表查出来的，是三重判断收敛出来的（第 7 节生成器的三步，就是三因子的操作化）。
