### 6.4 完整性检测机制（V2.2 新增）

> **目的**：通过三重指标自动检测信息完整性，触发告警时启动复测流程。

#### 6.4.1 检测指标与阈值

| 检测项        | 计算方法                 |     告警阈值     |  当前状态 |
| :--------- | :------------------- | :----------: | :---: |
| **事件数量校验** | 事件接入清单总数 vs 原文段落数    |  遗漏>3 个触发预警  | ⚪ 待检测 |
| **人物出场核验** | 人物出场频次统计 vs 原文人名出现次数 |  遗漏>5 人次触发预警 | ⚪ 待检测 |
| **情感词覆盖率** | 情感词统计总数 vs 全文词汇总数    | 覆盖率<80% 触发预警 | ⚪ 待检测 |

#### 6.4.2 检测流程

```
步骤 1：执行事件数量校验 → 若通过进入步骤 2，若失败触发告警
步骤 2：执行人物出场核验 → 若通过进入步骤 3，若失败触发告警
步骤 3：执行情感词覆盖率检测 → 若通过标记"检测完成"，若失败触发告警
步骤 4：生成检测报告，记录第 9.1 节人工校验表
```

#### 6.4.3 告警处理机制

| 告警级别    | 触发条件      | 处理方式            |
| :------ | :-------- | :-------------- |
| 🔴 严重告警 | 3 项检测全部失败 | 启动复测机制，人工全面复核   |
| 🟡 中度告警 | 2 项检测失败   | 启动复测机制，重点复核失败项  |
| 🟢 轻度告警 | 1 项检测失败   | 人工校验标记，记录备注     |
| ⚪ 正常    | 0 项检测失败   | 标记"检测通过"，进入下一环节 |
