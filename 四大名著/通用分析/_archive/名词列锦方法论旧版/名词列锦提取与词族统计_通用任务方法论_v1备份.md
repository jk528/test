# 名词列锦提取与词族统计 · 通用任务方法论

> **性质**：本文是「对已拆分长文本做名词列锦逐章提取 + 同类词族纵向统计」这一任务的完整口径与生成逻辑——判定标准、两类产物、流程、模板、校验与防错全部来自一次实际跑通的实战（见 §9），未经过验证的环节不写入。
> **通用性约定**：全文不绑定任何具体书名、章数与绝对路径。凡随项目变化的量，一律使用统一占位符（见 §0.2），复用时替换占位符即可；文档内示例路径均为相对路径形式。
> **总原则**：**宁可多不要少**。多了可删，少了不好找。凡有疑义一律先收并标注，不擅自剔除；只有"零新增"底线不放宽。
> **与白描方法论的关系**：本任务是同系列"白描手法逐回分析"的姊妹任务。白描拆的是**写作手法**，本任务拆的是**名词列锦与同类词族**；两者共用"只提取、不改写、逐字引证"的底层约束，可并行跑、交叉引用。

## 0. 阅读约定

### 0.1 任务一句话定义

输入「一部已按章拆分的文本 + 名词列锦判定与词族口径」，输出「一份含逐回**名词列锦全集**与**全书词族统表**的统合 md」。全程由主控调度、子代理逐回阅读与提取，主控负责统计、拼接与校验；**同类词无论出现几次、是否已在别的条目里出现，一律在词族表中逐处单列**。

## 1. 名词列锦判定（宜宽不宜严）

### 1.1 定义

白描 25 手法中，名词列锦原义为"同处境名词排列成景"（信号：原文已有几个同属一处境的名词；撤掉：名词无共同关系、只像清单）。本任务**反向使用**：不改写、只提取，用它作识别框架拆解成熟文本。

### 1.2 三条判定（满足任意一条即先收）

| 条件 | 含义 |
|---|---|
| **同境** | 成员属同一处境／体系：时辰、方位、器物、果品、禽兽、草木、职分、辈分、气象、景物、处所…… |
| **成列** | 原文以并列、对仗、铺陈、枚举呈现，或虽散落但同类关系明确，或可经剔除修饰语归组 |
| **成景** | 排列后能读出画面、秩序或层级结构 |

对偶句、韵文、偈语、长尊号、动宾短语中的名词、数字＋名词组合，**只要能成组，一律先收**，存疑的按 §3 标注体系处理。

### 1.3 三类界定

| 类 | 名称 | 判定 | 处理口径 |
|---|---|---|---|
| **①** | 原文完备 | 原文成组写全、顺序边界清楚 | 原样提取；依据栏写"原文完备" |
| **②** | 缺失补全 | 成员被**压缩**（四字格并俩）、**散落**（藏于叙述）、**截尾**（以"等／般般件件"收束） | 还原或展开；补全字必须全部出自原文 |
| **③** | 跨章节 | 成员不集中单回、散见全书、靠体系关系维系 | 单回记线索并标"待全书校验"；全书汇集后单列统表 |

**合条**：一句含多组时可合为一条，但成员清单必须分组写清。

### 1.4 纳入清单（从宽，优先收）

1. 完整枚举的名物组：地支、部洲、四象、五形、三才、辈分字等；
2. 铺陈式对偶／排比中的同类名词：果品、器物、禽兽、草木、穿戴、气象、山水；
3. 层级／序列词：帝王世系、名色品类、职分、亲属称谓、身体部位；
4. 散落但可归组的同类名词（如时辰散在叙述里、瑞兽分置四句）；
5. 数字＋名词咬合的秩序组合；
6. 长尊号、成串职名、地名叠称等"名词连缀成景"者；
7. **韵文、偈语、歌词中的名物**（照收，标注来源为韵文）；
8. **动宾短语中的名词**（剔除动词后成组，按②类收）；
9. **原文只给总数未列成员的组**：照收，标 `[待考·外部补全]`；
10. 同一回内重复出现的组：逐回条目首次详列、复现回指；**但词族表仍按出现次数逐处单列**；
11. **同一语义类的词族**：无论是否已在逐回条目中出现，均须在词族表中全部列出。

### 1.5 排除清单（从窄，仅这三种）

1. 完全不成组的孤立的词——某名词仅此一处、无任何同类可归并；
2. 纯抽象概念连缀、无画面也无秩序者；
3. 原文残缺到无法辨认成员的字（保留原字"□"，不据此编造成员）。

> 拿不准的一律不进排除清单，改走 §3 标注体系收进正文。

## 2. 词族纵向统计（本方法的核心维度）

### 2.1 为什么必须有这一维度

逐回条目按"当场成组的名词"提取，会天然漏掉三类东西：
- **别名/近义**：同一集团的多种称谓（如"三等名色／三等人／三者／佛仙神圣"）分散在不同句；
- **同词复现**：同一词出现多次，逐回条目里只记一次或被合条覆盖；
- **跨回呼应**：某类词贯穿全书，单回看不出规模。

词族统计按"同一语义类的全部词"纵向归并，**与逐回条目并行、互不替代**。

### 2.2 六条执行细则

> **核心规则**：一个词即使已在某条逐回条目中出现过，仍须在所属词族表中**单列一次**，不得因"已经算进某组"而折叠、省略。

1. **覆盖对象**：同一语义类的所有词与别称——同义、近义、俗称、雅称、动词化表述，全收；
2. **跨位置归并**：同回多处、跨回、韵文与散体中的同类词，一律归入同一族；
3. **逐处标注**：每个词标出**全部出处**（回号＋原文片段），并注明"已见逐回第几条"以便双向核对；
4. **单列不合并**：同族内别名分行单列，不合并计数；同一词出现 N 处，记 N 条；
5. **异形各自成词**：词序不同（如"不老长生／长生不老"）、连称与分称（如"三者／佛仙神圣"）各自单列；
6. **独立成篇**：全书词族汇总为单独统表，附在统合 md 末尾，与逐回条目互不覆盖、互不扣减。

### 2.3 种子族清单（先定后补）

先列种子族，全书提取中发现的新类随时并入：

| 组 | 种子族示例 |
|---|---|
| 时空秩序 | 地支时辰、方位部洲、节令四时、纪年数字 |
| 生命观 | 长生不死、冥界死亡、轮回果报、仙凡品类 |
| 品类序列 | 名色品类、辈分字、职分官阶、亲属称谓 |
| 物象铺陈 | 器物、果品、禽兽、草木、穿戴、建筑、山水 |
| 数量秩序 | 数字＋名词的组合（尺寸／历数／卦数／里程） |

### 2.4 词族表格式

```markdown
### 词族名（共 N 词次）
| 词形 | 出处 | 原文片段 | 已见逐回条目 |
|---|---|---|---|
| 词A | 第N回·段落 | 「……」 | Cxx |
| 词A | 第M回·段落 | 「……」 | — |
```

## 3. 标注体系（"多收可删"的实现）

每条逐回条目必须带一个标记，方便后续批量删减：

| 标记 | 含义 | 默认 |
|---|---|---|
| `[核心]` | 三类判定毫无争议 | 保留 |
| `[韵文]` | 出自诗、偈、词、歌，名物成立但文体存疑 | 保留，可删 |
| `[动作]` | 从对偶动作短语中剔除动词取名词 | 保留，可删 |
| `[尊号]` | 长称号连缀，是并列名物还是单一专名存疑 | 保留，可删 |
| `[待考]` | 成员靠外部文化知识补全，非原文所有 | 保留，但**不计入统计** |
| `[复现]` | 同回或跨回重复出现，回指首见条目 | 保留，逐回条目层不重复计数（词族表仍逐处单列） |

**删减梯度**：先删 `[待考]`，再删 `[尊号]`／`[韵文]`，最后视需要精简 `[动作]`；`[核心]` 是全集骨干。
**注意**：删减只作用于逐回条目层；**词族表不受删减影响，始终全列**。

### 3.1 三条铁律

1. **逐字引证**：引文直接来自所读章，禁止凭记忆改写、缩写、拼接不相连的原句（节选须标明）；
2. **零新增**：`[待考]` 类之外，补全字必须全部出自原文，仅做剔除修饰语、拆分并列、还原顺序；
3. **不改写原文**：说明文字指向"原文怎么写（信号）—排成了什么景（效果）"，不写"淋漓尽致"类空评。

## 4. 输入要求与前置勘察

### 4.1 输入硬性要求

1. **文本已拆分**：每 {章单位} 一个独立 txt，位于同一 {拆分目录}；
2. **文件名含序号**：序号在文件名前缀且可机械提取（如 `001_xxx.txt`），这是分批与排序唯一依据；
3. **文件内首行为标题**，供条目引用；
4. **无缺号**：序号从起点到终点连续；缺号先补拆或把实际清单作为事实源；
5. **口径先定**：判定与词族口径（§1–§3）先于读文本确定，防止各代理自行发挥造成漂移。

### 4.2 勘察步骤（主控执行）

| 勘察项 | 方法 | 用途 |
|---|---|---|
| 文件总数与序号连续性 | 列目录 + 序号集合检查 | 确定 {总章数}，缺号即报 |
| 单文件字节数区间 | 列目录取大小 | 决定 {批次大小}（读入侧） |
| 标题行格式 | 抽读首尾各 1 文件 | 确定条目标题写法与 {章单位} |
| 文件名特殊字符 | 检查全角空格等 | 决定代理用 glob 还是明确列表 |
| 编码 | 抽读确认乱码情况 | 决定脚本读写编码参数 |
| **单章列锦密度**（抽样） | 抽 3–5 章试跑，数条目数 | 估输出量，定 {批次大小}（输出侧） |
| **种子族适配性**（抽样） | 对照 §2.3 看哪些族在本文本高频 | 增删种子族 |

> 实测提示：中文拆分文件名常含**全角空格**，不手工拼路径：调度方给完整文件名清单，或指示代理 glob 列目录后按序号筛选。

## 6. 完整生成流程（八步）

流程总览：勘察 → 分批 → **首轮逐回提取（全集）** → 统计与词族归并 → 头尾撰写 → 统合拼接 → 校验 →（**仅异常时**）补漏轮。

### 步骤 1：文本勘察
按 §4.2 执行，产出：{总章数}、{批次大小}、{总批数}、{单章列锦密度}、文件名清单、编码与特殊字符结论、适配后的种子族。
**验收**：序号集合 = 1..N 无缺口；种子族已定稿。

### 步骤 2：批次规划

```
读入侧：{批次大小} ≤ floor(100KB ÷ max{单章字节区间})
输出侧：{批次大小} ≤ floor(60KB ÷ 单章输出预算)
        其中 单章输出 ≈ 逐回条目 + 本回词族表，实测约 2–3KB/章
{批次大小} = min(两者)，落在 [6, 12]
{总批数}   = ceil({总章数} ÷ {批次大小})
```

**并行调度**：一次消息内并发多个子代理（实测每波 5 个稳定）。批次按序号连续切块，不交错。
**验收**：批次表已建（批次号 → 章号区间 → 文件清单 → 输出文件名）。

### 步骤 3：首轮逐回提取（并行，产出全集）
派发模板 A（§7.1）。核心约束：
1. 按序号逐个读文件，读完一章立即写完该章全部条目 + 本回词族表，再读下一章；
2. **全集口径**：命中即写，不挑典型、不设上限；
3. 引文逐字摘自所读文本，禁止凭记忆改写；
4. **词族表按出现次数逐处单列**，同词多次分列、别名分行；
5. **分段落盘**：每完成 3–6 章写一次文件（先覆写前段，再追加后段）；
6. 返回只给两行：完成状态 + 本批词族命中汇总，不粘贴全文。

**验收**：每批文件存在、章标题数 = 该批章数、每章有条目、词族表逐处单列。

### 步骤 4：统计与词族归并
1. 汇总各批词族表，按 §2.2 规则合并为全书词族统表（同名族合并，词次累加，出处逐条保留）；
2. 统计每族词次、每词出现回数、高频族排名；
3. 顺带跑 §8 的双向校验（逐回条目 ↔ 词族表）；
4. 统计结论回填 head.md / tail.md。

**验收**：词族统表覆盖全部种子族；每词次都有出处。

### 步骤 5：头尾撰写（主控）
- **head.md**：任务元信息 → 口径来源与判定表 → 三类界定 → 条目结构 → 统计口径声明 → 词族口径声明（必写：同类词逐处单列、不受删减影响）→ 全书统计；
- **tail.md**：**全书词族统表**（按族分组）→ 统合观察（支柱族、跨回呼应、零命中族）→ 使用与复用说明。

**验收**：head 统计数字与脚本输出一致；两处口径声明显式存在。

### 步骤 6：统合拼接
按 `head + batch_01 … batch_N + tail` 顺序拼接（脚本见 §7.3），无 BOM UTF-8 写入。
**验收**：文件存在；逐回标题数 = {总章数}，序号无缺；词族统表在末尾。

### 步骤 7：完整性校验（见 §8）
**验收**：缺漏 = 0；双向校验通过。

### 步骤 8：补漏轮（异常专用）
仅在批次空返回/中断，或校验发现漏项时启用：算差集 → 派发模板 B → 分批写入 → 重跑校验与拼接。

## 10. 文体适配与局限

1. **非章回文本适配**：{章单位} 换成"节/讲/篇"即可用于课程文稿、连载技术等；但"成景"判定对说明文类文本应放宽为"成系统"。
2. **词族颗粒度**：同一组词可粗可细（"兵器"一族可拆为"刀/枪/剑/戟"四族）。种子族先粗后细，全书统计中按实际密度调整；一旦定稿中途不改。
3. **`[待考]` 的处理**：靠外部文化知识补全的成员（如"五虫"的具体名目）保留在正文但不计统计；若某任务禁止外部知识，整族可从种子族移除。
4. **口径差异不可消除只能声明**：分批并行的本质是多个判定者，批次间尺度差异数个百分点到一倍都有可能。在 head 中显式声明；词族归并时以"宁可多收"为准吸收差异。
5. **本方法不做改写**：白描框架含"成熟文本原样返回"前提，本流程只读不写原文。
6. **全集口径的代价**：首轮即全集 + 词族表，单批输出长；写盘失败风险上升，用"每 3–6 章落盘"对冲。若某文本单章条目极高（>20），把批次大小下调至 6–8，或把落盘加密到每 2–3 章。
7. **全书词族统表的规模**：词次可能达数千条，统表宜按族分节、每节再加"高频词 Top N"小表，避免一张巨表不可读。
