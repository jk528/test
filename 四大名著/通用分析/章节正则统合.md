## 2. splittxt 原版（单一正则）

**来源**（四处同式）：

- ./splittxt/split_txt.bas L31（`CHAPTER_PATTERN` 常量）
- ./splittxt/split_txt.py L54
- ./splittxt/split_txt.js L28
- ./残留/SplitTxt.bas L26、./残留/split_txt.py L34

```
^第([0-9一二三四五六七八九十百千万零两]+)(章|回|节|卷)(\s*)(.*)$
```

- 4 个捕获组：`1=数字序号`、`2=单位词`、`3=空白`、`4=标题`
- 缺 `〇`（第一〇〇章 误判不了）；缺大写数字

## 3. splittxt2 九套预设（VBA 多正则版）

**来源**：./splittxt2/split_txt.bas `InitRegexPatterns()`（L73-138）。**此为事实源**。

> ⚠ 文档滞后提示：./splittxt2/使用说明.md §4.1 表格为旧版（`\s*`/`(.*)$` 松散尾部、无行首容错、字符类缺 `○/億/兩`），代码已全面升级为「终极数字字符类 + 行首容错 + 单位后必须有空白」。下表以代码为准。

| 序号 | 名称 | 正则表达式 | unitGroupIdx | 默认单位 |
|------|------|------------|--------------|----------|
| 1 | 标准中文 | `^[ \t　]*第([0-9０-９一二三四五六七八九十百千万亿億零〇○两兩壹貳贰叁參肆伍陸陆柒捌玖拾佰仟廿卅卌皕萬]+)(章\|回\|节\|卷)(?:[ \t　]+(.*))?$` | 1 | 章 |
| 2 | 纯阿拉伯数字 | `^[ \t　]*第([0-9０-９]+)(章\|回\|节\|卷)(?:[ \t　]+(.*))?$` | 1 | 章 |
| 3 | 英文Chapter | `^[ \t　]*[Cc]hapter\s+([0-9０-９]+)(?:[ \t　]*[:\.\-]?[ \t　]+(.*))?$` | -1 | Chapter |
| 4 | 序章/楔子/番外 | `^[ \t　]*(序章\|楔子\|尾声\|番外\|引子\|后记\|终章\|序言\|前言)(?:[ \t　]+(.*))?$` | -1 | 章 |
| 5 | 数字+标题（无"第"） | `^[ \t　]*([0-9０-９]+)(章\|回\|节\|卷)(?:[ \t　]+(.*))?$` | 1 | 章 |
| 6 | 精简中文 | `^[ \t　]*第([零〇○一二三四五六七八九十百千两兩]{1,7})(章\|节)(?:[ \t　]+(.*))?$` | 1 | 章 |
| 7 | 宽松匹配 | `^[ \t　]*第(.+?)(章\|回\|节\|卷)(?:[ \t　]+(.*))?$` | 1 | 章 |
| 8 | 纯数字起始 | `^[ \t　]*([0-9０-９]{3,4})(?:[ \t　]+(.*))?$` | -1 | 章 |
| 9 | 自定义 | 用户输入 | -1 | 章（聚合时询问） |

捕获组约定：`1=序号`、`2=单位词`（`unitGroupIdx` 指其 SubMatches 下标，`-1` 表示无单位组）；标题取整行 `m(0).Value`（不依赖捕获组）。尾部 `(?:[ \t　]+(.*))?$` 表示**单位后接内容必须有空白**，防正文「第四回中…」误判（同 ColorTxt 收紧策略）。

## 4. 红楼梦范例（TypeScript）

**来源**：../红楼梦范例/app/src/lib/chapters.ts L25

```javascript
/^第([0-9一二三四五六七八九十百千万零〇两壹贰叁肆伍陆柒捌玖拾佰仟]+)(章|回|节|卷)\s*(.*)$/
```

- 与 splittxt2 预设 1 同字符类（含大写数字，用于《道诡异仙》式 `第壹卷`），但**去掉了独立的空白捕获组**：`2=单位词` 后直接 `\s*(.*)$`
- 3 个捕获组：`1=数字序号`、`2=单位词`、`3=标题`
- L41 注释：避免把「　　……第一回也」这类正文误判为标题（靠 `\s*` 消化行首缩进 + 整行锚定）

## 5. ColorTxt 内置规则（现行，均已收紧）

**来源**：../彩读分析/.temp/ColorTxt/src/shared/chapterMatchBuiltinPatterns.ts（常量定义）；消费方 renderer/src/chapter.ts。

**捕获约定差异**：ColorTxt 用 2 组捕获 —— `1=完整序号（含"第"与单位）`、`2=副标题`。

### 5.1 内置三条

| 规则 id | 正则表达式 | 默认启用 |
|---------|-----------|----------|
| builtin-main 主规则 | `^\s*(第[零一二三四五六七八九十百千万亿億两兩〇○壹貳贰叁參肆伍陸陆柒捌玖拾佰仟廿卅卌皕萬0-9０-９]{1,12}[章回卷节集部篇])(?:\s+(.{1,40}))?\s*$` | 是 |
| builtin-alt 特殊章节 | `^\s*(目录\|序章\|楔子\|引子\|尾声\|后记\|番外\|完结感言)(?:\s+(.{1,40}))?\s*$` | 是 |
| builtin-num-ordered 数字顿号 | `^\s*([0-9０-９]+、)\s*(.{0,40})\s*$` | 否 |

主规则数字字符类（终极版，与 splittxt2 同源）：

```
零一二三四五六七八九十百千万亿億两兩〇○壹貳贰叁參肆伍陸陆柒捌玖拾佰仟廿卅卌皕萬0-9０-９
```

- 覆盖：简/繁小写（亿億、两兩）、汉字零 3 变体（零〇○）、大写+繁体数字、俗写（廿卅卌皕）、半角/全角数字
- 单位比 splittxt2 多 `集、部、篇`；`\s` 在 JS 引擎含全角空格，故行首/副标题空白用 `\s` 即可（VBA 需显式 `[ \t　]`）

### 5.2 splittxt2 适配 8 条（builtin-st2-*，默认均未启用）

| id 后缀 | 对应 R2 预设 | 适配后正则表达式 |
|---------|--------------|------------------|
| std-cn | 1 | `^\s*(第[0-9０-９一二三四五六七八九十百千万亿億零〇○两兩壹貳贰叁參肆伍陸陆柒捌玖拾佰仟廿卅卌皕萬]+[章回节卷])(?:\s+(.*))?\s*$` |
| arabic | 2 | `^\s*(第[0-9０-９]+[章回节卷])(?:\s+(.*))?\s*$` |
| chapter-en | 3 | `^\s*([Cc]hapter\s+[0-9０-９]+)(?:\s*[:.\-]?\s+(.*))?\s*$` |
| special | 4 | `^\s*(序章\|楔子\|尾声\|番外\|引子\|后记\|终章\|序言\|前言)(?:\s+(.*))?\s*$` |
| num-unit | 5 | `^\s*([0-9０-９]+[章回节卷])(?:\s+(.*))?\s*$` |
| brief-cn | 6 | `^\s*(第[零〇○一二三四五六七八九十百千两兩]{1,7}[章节])(?:\s+(.*))?\s*$` |
| loose | 7 | `^\s*(第.+?[章回节卷])(?:\s+(.*))?\s*$` |
| digits | 8 | `^\s*([0-9０-９]{3,4})(?:\s+(.*))?\s*$` |

适配要点：单位并入第 1 组（保证标题显示含「第N章」前缀）；`digits` 由「整行任意」改为「序号单独成组 + 可选副标题」。

## 6. 废弃版本（宽松版，已自动升级）

**来源**：renderer/src/chapter.ts `SUPERSEDED_BUILTIN_PATTERNS`（L306-337）。旧版持久化数据加载时静默升级为新版，用户手改过的规则不动。

| 规则 | 废弃旧式（宽松） | 现行新式（收紧） |
|------|------------------|------------------|
| main | `^\s*(第[…]{1,12}[章回卷节集部篇])\s*(.{0,40})\s*$` | `(?:\s+(.{1,40}))?` |
| alt | `^\s*(目录\|序章\|…\|完结感言)\s*(.{0,40})\s*$` | 同上收紧 |
| st2 各条 | `...\s*(.*)$` / `...(.*)$` | `(?:\s+(.*))?\s*$` |

**收紧的核心规则（防误判关键）**：

```
副标题前必须有至少一个空白：(?:\s+(.{1,40}))?
```

| 输入 | 宽松旧版 | 收紧新版 |
|------|---------|---------|
| `第一章 你好` | ✓ 误判风险低 | ✓ 命中 |
| `第一章` | ✓ | ✓（纯序号行仍命中） |
| `第一章你好` | ✗ 误判为章节 | ✗ 正确拒绝 |
| `第四回中既将…`（红楼梦正文） | ✗ 误判（123回事故根因） | ✗ 正确拒绝 |

事故背景：红楼梦全书因 `第四回中…`、`第三十八回林…`、`第一一九回中…` 三行零空白匹配，120 回被误判为 123 章。

| 版本 | 字符类 | 相比上一版新增 |
|------|--------|----------------|
| R1 splittxt | `0-9一二三四五六七八九十百千万零两` | 基线 |

终极版字符类全文（两处共用）：

```
0-9０-９一二三四五六七八九十百千万亿億零〇○两兩壹貳贰叁參肆伍陸陆柒捌玖拾佰仟廿卅卌皕萬
```

限长对照：R2-6 与 ColorTxt brief-cn 用 `{1,7}`；ColorTxt 主规则 `{1,12}`（`第十七` 占 3 字符，`{1,2}` 会配不全，勿改小）。

## 8. 设计要点沉淀

| 要点 | 说明 |
|------|------|
| 两套捕获约定 | 工具族：序号/单位/标题；ColorTxt：完整序号 + 副标题 两组。splittxt2 标题取整行 `m(0).Value`，不依赖捕获组 |
| 整行锚定 | 全部为 `^...$` 全行匹配，防止正文内「第…章」句式误判 |
| **行首容错需配尾部约束** | 加行首 `[ \t　]*`（含全角空格）后，**必须**同步把尾部改为「单位后接内容须有空白」`(?:[ \t　]+(.*))?$`，否则正文缩进行「　第四回中…」会被误判（实测 121>120） |
| `\s*` 与 `\s+` 的分界 | 行首行尾用 `\s*`（消化缩进/尾空白）；副标题**前**用 `\s+`（必须有空白才认为是标题） |
| VBA 与 JS 的空白差异 | VBScript `\s` **不含**全角空格 U+3000，须显式写 `[ \t　]`；JS `\s` 含全角空格，写 `\s` 即可 |
| 宽松兜底的代价 | R2-7 / st2-loose 用 `.+?` 可配 `第序章`，但正文中「第…回」句式有风险，仅作最后手段 |
| ○ 与 〇 双收 | `○`（U+25CB 白圈）与 `〇`（U+3007 汉字零）字形相同、编码不同，**常见小说文本混用**，数字字符类应同时包含两者 |
| 全角数字/繁体 | 部分小说全文全角数字（`第１２３章`）、繁体 `億萬兩`、大写 `貳參陸` 均需收入字符类 |
| 升级兼容 | ColorTxt 用 SUPERSEDED 表静默升级旧规则，保留用户自定义；splittxt2 无持久化无此问题 |
