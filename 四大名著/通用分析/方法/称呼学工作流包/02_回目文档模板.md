# 02_回目文档模板：单回 MD 的六节骨架

> 纪律速记：引文只从拆分底本复制｜星号不进引文｜跳引标 `……`｜异文照录＋尾注存档｜三处计数一致。

## 关键约束（质检脚本逐维对应）

| 维 | 约束 | 正则/检查点 |
| :--- | :--- | :--- |
| 结构 | §0–§5 六节 `## 0.`～`## 5.` 齐全 | `^##\s*N\s*\.` |
| 头标 | 头部含 `（N/120）` 且 N＝文件名回号 | `（(\d+)/120）` |
| 尾注 | 含 `（注：` 块与 `> AI生成` 行 | 行首 `>\s*AI生成` |
| 锚记 | 事件行含【A】 | 任意 `【A】` |
| 底本引用 | 头标含 `红楼梦_拆分/<NNN>_` | 子串匹配 |
| 计数 | §0 `本回解构 X 件`＝§1 表行数（Nb 行 `| 1b |`/`| 4b |` 计入）＝尾注 `计数：本回称呼事件 X 件`；`重点解构 Y 段`＝### 数 | 正则抽数比对 |
| 字符 | 零宽字符=0、错字"诒"=0 | 码点扫描 |
| 锚定 | 全部「」引文归一化后在底本/名词列锦可 Contains | 见 06 方法论 §2.2 |
