# 签到程序本地文件夹与配置路径说明

> 目的：梳理签到程序（及 6 个签到平台客户端）在**本机**创建/使用文件夹与配置文件的路径逻辑，用于判断哪些目录会出现在仓库里、是否需要加入 Git 忽略，避免把本机运行状态同步到 Gitee。
> 代码依据：`自动化与工具/签到程序/checkin_all.js`（单文件自包含，6 平台逻辑与公共工具）
> 关联文档：[使用说明.md](../自动化与工具/签到程序/文档/使用说明.md)、[Git忽略配置说明.md](../自动化与工具/签到程序/文档/Git忽略配置说明.md)
> 编写日期：2026-10-23

---

## 〇、结论先行

1. **程序没有独立的“路径配置文件”**（没有 .json / .ini / .conf 专门记录路径）。所有路径都在 `checkin_all.js` 里按 **环境变量 + 常量** 实时拼出，因此只有两种逻辑，而不是两种配置文件：
   - **逻辑 A：本机数据目录**（客户端登录后在本机生成的目录，脚本只读其中的凭证）；
   - **逻辑 B：安装目录**（通过注册表 `InstallLocation` 探测，脚本只读其中的版本号 / 运行态 / 证书）。
2. 脚本**唯一主动新建的文件夹**是脚本目录下的 `.temp\`（存放 WorkBuddy 密钥缓存）。其余目录均由平台客户端自行创建，脚本只读取。
3. 真正会进入仓库的只有两类：`签到程序\.temp\`（已在 .gitignore 中忽略）和 `签到程序\checkin_all.log`（**目前未被忽略**，建议补规则）；平台在仓库子目录内生成的工作区目录已由根 `.gitignore` 统一忽略（2026-10-22 起）。

---

## 一、逻辑 A：本机数据目录（本地新建，客户端生成，脚本只读）

路径全部由 `%APPDATA%`、`%LOCALAPPDATA%`、`%USERPROFILE%` 拼出，不读任何路径配置项。

| 平台 | 根目录（变量写法） | 本机展开示例 | 具体配置文件 | 用途 | 脚本行为 |
|---|---|---|---|---|---|

| TeleAgent | `%USERPROFILE%\.local\share\TeleAgent` | `C:\Users\Administrator\.local\share\TeleAgent` | `current-owner.json`<br>`users\<ownerDir>\app-auth\token.json`<br>`users\*\app-auth\token.json`（兜底）<br>`app-auth\device-meta.json` | 当前账号、token、设备 ID | 只读 |
| WorkBuddy | `%LOCALAPPDATA%\CodeBuddyExtension\Data\Public\auth`<br>（LOCALAPPDATA 为空时兜底 `%USERPROFILE%\AppData\Local\...`） | `C:\Users\Administrator\AppData\Local\CodeBuddyExtension\Data\Public\auth` | `workbuddy-desktop.info`<br>（兜底：目录内最新的非时间戳 `.info` 文件） | accessToken 密文、uid | 只读 |
| CodeArts | `%APPDATA%\codearts-agent` | `...\AppData\Roaming\codearts-agent` | `Local State`（AES 主密钥）<br>`User\globalStorage\state.vscdb`（`ItemTable` 中的 `HuaweiCloudSession`） | 登录态（sqlite 库） | 只读（Node 22.13+ 内置 sqlite） |
| Qoder CN | `%APPDATA%\com.qodercn.app.stable` | `...\AppData\Roaming\com.qodercn.app.stable` | `Local State`<br>`auth.v1.dat`<br>`auth.machine-id` | 登录态、机器码 | **读 + 必要时原子写回**（见第三节） |

- Trae 的数据目录探测逻辑：按 `Trae CN` → `TRAE SOLO CN` 顺序找，**以目录内是否存在 `User\globalStorage\storage.json` 为准**，找到即用。

- WorkBuddy 固定在 `CodeBuddyExtension` 下，不随客户端改名而变化（客户端版本只影响 exe 位置）。

## 二、逻辑 B：安装地址目录（注册表探测，脚本只读）

探测函数 `regQueryInstallLocation(keyword)` 执行：

```powershell
reg query "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall" /s /f "<关键词>" /d
```

取输出中**第一条** `InstallLocation REG_SZ <路径>`；查不到或路径不存在时，按下方候选路径兜底。

| 平台 | 注册表关键词 | 安装目录下读取的具体文件 | 兜底候选安装路径 | 用途 |
|---|---|---|---|---|
| Trae | `Trae` | `resources\app\package.json` | `%LOCALAPPDATA%\Programs\Trae CN`<br>`%LOCALAPPDATA%\Programs\TRAE SOLO CN`<br>`B:\Trae CN`<br>`B:\trae work\TRAE SOLO CN` | 版本号（`x-app-version` 请求头）；`run_checkin.cmd` 还用此目录找 `Trae CN.exe` 当 Node 运行时 |
| TeleAgent | `TeleAgent` | `resources\app\package.json` | `%LOCALAPPDATA%\Programs\TeleAgent` | 版本号（`X-App-Version`） |
| WorkBuddy | `WorkBuddy` | `WorkBuddy.exe`（不读 package.json） | `%LOCALAPPDATA%\Programs\WorkBuddy`<br>`C:\Program Files\WorkBuddy`<br>`C:\Program Files (x86)\WorkBuddy` | 启动 `WorkBuddy.exe -e ...` 提取密钥（`ELECTRON_RUN_AS_NODE=1`），无需客户端运行 |
| CodeArts | —（不探测安装目录） | — | — | 仅依赖数据目录 A |
| Qoder | —（固定 exeDir） | `resources\app\package.json`<br>`resources\app.asar.unpacked\package.json`<br>`resources\umid\runtime-info.exe` | `%LOCALAPPDATA%\Programs\Qoder CN`<br>`%LOCALAPPDATA%\Programs\Qoder` | 版本号（`Cosy-Version`）、设备指纹（风控） |
| OfficeAce | `OfficeAce` | `.office-claw\run\windows\runtime-state.json`<br>`.env` / `.inner.env`<br>`.office-claw\certs\root-ca.pem` | `%LOCALAPPDATA%\Programs\OfficeAce`<br>`%USERPROFILE%\OfficeAce`<br>`C:\Program Files\OfficeAce`<br>`C:\Program Files (x86)\OfficeAce` | 本地 API 端口（优先运行态快照，再 .env，再默认 3004/3002，最后扫描回环端口）、自签 TLS 根证书 |

说明：

- 安装目录逻辑**只读不写**：脚本不会向安装目录写入任何文件。
- `runtime-state.json`、`.env`、`root-ca.pem` 都是果办客户端自己生成的，属于“安装目录内的本机配置”；它们不在仓库里，无需 Git 处理。
- 注册表探测取“第一条匹配”，若本机有多个名称相近的软件，可能命中非目标项；脚本会再校验路径是否存在，失败则走候选路径。

## 三、程序自身写盘行为（唯一与 Git 相关的部分）

### 1. 主动新建文件夹：`.temp\`

- 位置：`<签到程序目录>\.temp\`，即本机 `c:\Users\Administrator\Desktop\JK-temp\自动化与工具\签到程序\.temp\`
- 触发：WorkBuddy 密钥获取成功后缓存（`fs.mkdirSync(dir, { recursive: true })`，checkin_all.js 约 613–617 行）
- 文件：`wb_key.json`（`atRestSecretKey`，44 位），兼容旧名 `wb_atrest_key.json`
- 失效处理：解密校验失败时 `wbClearKeyCache()` 删除两个缓存文件，重新获取并写回
- **该目录含本机密钥，严禁提交**；根 `.gitignore` 已有 `/自动化与工具/签到程序/.temp/`

### 2. Qoder 原子写回（写入已有目录，不新建目录）

- 备份：`auth.v1.dat.bak-<时间戳>`，只保留最近 3 份（超出自动删除）
- 临时文件：`auth.v1.dat.<pid>.<uuid>.tmp`，写入后 `rename` 覆盖 `auth.v1.dat`
- 位置在 `%APPDATA%\com.qodercn.app.stable`（或国际版目录），**在仓库之外**，不影响 Git

### 3. 日志文件（由外部重定向创建，不是脚本创建）

| 文件 | 位置 | 生成方式 | Git 状态 |
|---|---|---|---|
| `checkin_all.log` | `<签到程序目录>\checkin_all.log` | 计划任务 `cmd /c "... >> checkin_all.log 2>&1"` | **未忽略，会被同步**（建议补规则） |
| `sync_gitee.log` | 仓库根或同步脚本目录 | `sync_gitee.ps1` 自身写入，超 256KB 轮转为 `.old` | 已忽略（`.gitignore` 第 150 行） |

## 四、仓库内会被平台客户端自动生成的工作区目录（与同步直接相关）

6 个平台客户端/智能体在“打开某个仓库子目录”时会自建以下目录与文件，属于本机运行状态：

| 类别 | 名称 | 说明 |
|---|---|---|
| 平台根目录 | `.arts/`、`.codeartsdoer/`、`.office-claw/`、`.workbuddy/`、`.agent_history/`、`.workspace` | 各客户端配置/历史 |
| OfficeAce/小通 工作区 | `agents/`、`coding_memory/`、`context/`、`memory/`、`messages/`、`prompt_attachment/`、`skills/`、`todo/`、`docs/` | 智能体会话、记忆、技能 |
| 身份/引导文件 | `AGENT.md`、`SOUL.md`、`IDENTITY.md`、`USER.md`、`HEARTBEAT.md`、`BACKLOG.md` | 智能体人设与待办 |

根 `.gitignore` 第一分区（2026-10-22）已对上述名称做**任意层级**忽略，例如 `6签到创建的本地文件\CodeArts\.codeartsdoer\.gitignore` 也不会被纳入版本库。

## 五、Git 同步检查清单

### 已覆盖的规则（无需操作）

- `/自动化与工具/签到程序/.temp/`（密钥缓存）
- `sync_gitee.log`
- 平台工作区目录与身份文件（`.arts/`、`.codeartsdoer/` 等）
- `/自动化与工具/签到程序/文档/任务计划配置记录.md`（含本机绝对路径）

### 建议补充的规则

| 规则 | 原因 |
|---|---|
| `/自动化与工具/签到程序/checkin_all.log` | 每日签到日志持续增长，无版本价值 |
| `/6签到创建的本地文件/`（可选） | 本次演示用的 6 个空目录；空目录本身 Git 不跟踪，但若以后写入文件可整目录忽略 |

### 验证命令（PowerShell，绝对路径）

```powershell
cd "C:\Users\Administrator\Desktop\JK-temp"
git check-ignore -v "自动化与工具\签到程序\.temp\wb_key.json"
git check-ignore -v "自动化与工具\签到程序\checkin_all.log"
git status --porcelain
git ls-files | Select-String "签到程序"
```

### 注意事项

1. 空文件夹 Git 不会跟踪；本次创建的 6 个空目录本身不会出现在 Gitee。
2. 若某文件**已被跟踪**，后加忽略规则无效，需 `git rm --cached -- <路径>` 后提交。
3. `文档/` 目录名是“文档”而非 `docs/`，不受 `.gitignore` 中 `docs/` 规则影响；若把本说明放入 `签到程序\文档\`，会随仓库同步。
4. 所有平台数据目录均位于 `%APPDATA%` / `%LOCALAPPDATA%` / `%USERPROFILE%` 下，**天然在仓库之外**，不需要 Git 规则。
