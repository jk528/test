# 01 口腔与牙齿 —— 全身最忙碌的零件组

> 覆盖零件：总表 001–007（006 扁桃体的免疫职能详见 13 章）
> 本章是全套手册的"样板章"：牙齿的养护维度最全（刷牙/牙线/漱口/舌苔/饮食/检修六维），其余章节沿用同一框架。
> 口腔账本：一颗牙从浅龋补牙（数百元）→根管+冠（数千元）→拔除+种植（上万元），维护越晚，维修越贵。

## 0. 本章速览

- 口腔是消化道入口、语言发生器，也是全身少数"完全暴露在磨损环境"的零件组。
- 零件账：32 颗牙 + 牙龈牙周 + 牙槽骨地基 + 舌头 + 三大唾液腺 + 扁桃体 + 口咽，共 7 类零件。
- 失牙两大主因：儿童与青年期=龋齿；成年后期=牙周病。两条路径都能被日常养护大幅推迟。

## 1. 牙齿（001）：32 个高硬度零件

### 1.1 结构解剖（认识你的零件）

| 结构 | 说明 | 养护含义 |
|---|---|---|
| 牙釉质 | 人体最硬组织（莫氏硬度约6-7），覆盖牙冠 | 无细胞、不可再生，磨掉不会长回来 |
| 牙本质 | 釉质下层，内含神经末梢小管 | 暴露后=冷热酸甜敏感的来源 |
| 牙髓 | 牙内部的血管神经束（俗称"牙神经"） | 感染不可逆，多数需根管治疗 |
| 牙骨质与牙周膜 | 牙根外层+减震悬吊系统 | 牙周病破坏后牙齿松动 |
| 牙槽骨 | 牙齿的"地基" | 吸收不可逆，是失牙的直接原因 |

### 1.2 32 颗牙的分工表

| 类型 | 数量 | 功能 | 磨损风险 |
|---|---|---|---|
| 切牙 | 8 | 切断食物 | 门牙最易受外伤（球类运动建议护齿套） |
| 尖牙 | 4 | 撕扯 | 牙根最长、天然抗拔 |
| 前磨牙 | 8 | 捣碎过渡 | — |
| 磨牙 | 8 | 咀嚼主力区，咬合力主要产生于此 | 咬合面窝沟深，龋齿高发区 |
| 智齿 | 0-4 | 现代人的"退休零件" | 阻生、顶坏邻牙、冠周炎高发 |

### 1.3 日常养护 · 维度一：刷牙（核心中的核心）

#### 工具层

| 项目 | 推荐 | 说明 |
|---|---|---|
| 刷头 | 小头，以覆盖约2颗牙为宜 | 大头刷够不到后牙远中面 |
| 刷毛 | 软毛/中软细丝 | 硬毛=楔状缺损与牙龈退缩的推手 |
| 手动 vs 电动 | 电动（声波/旋转震荡）清洁效率更稳定，方法正确的手动同样有效 | 懒人或手法不标准者选电动；带压力感应的更防用力过猛 |
| 牙膏 | 含氟（成人约1350-1500ppm） | 氟促再矿化，是防龋第一有效成分 |
| 牙膏用量 | 成人豌豆大小；3岁以下米粒大小 | 不追求"满刷头" |
| 更换周期 | 每3个月，或刷毛外翻即换 | 感冒后建议更换 |

#### 方法层：巴氏刷牙法（Bass，金标准）五步

1. 刷毛与牙面成约45°角，指向牙龈沟；
2. 小幅水平颤动（幅度约1-2mm，位置基本不动）；
3. 每组2-3颗牙，颤动约10次后向咬合面方向拂刷；
4. 顺序固定：外侧→舌侧→咬合面，不漏区（舌侧与最后一颗牙最易漏）；
5. 全程至少2分钟（可分上下左右各30秒计时）。

- 替代方案：圆弧刷牙法（Fones）适合儿童与手部不便者。
- 儿童由家长"帮助刷"到小学低年级，孩子自己刷完后家长补刷一遍最稳。

#### 频率与时机

- 每天2次（早晚），每次≥2分钟；睡眠期唾液分泌锐减=细菌"高速公路"，睡前那次最重要。
- 进食酸性食物/饮料（碳酸、果汁、醋、柠檬水）后不要立即刷牙：酸软化的釉质立刻刷=加速磨蚀；先清水漱口，约30分钟后再刷。
- 刷完"吐不漱"：吐掉泡沫即可，让微量氟留在牙面（尤其睡前）。

#### 常见错误 Top 8（对照自查）

| 错误 | 后果 | 改法 |
|---|---|---|
| 横向拉锯式刷牙 | 楔状缺损、牙龈退缩 | 改巴氏45°小幅颤动 |
| 用力过猛 | 刷毛3个月内炸开就是信号 | 电动选压力感应款 |
| 30秒草草了事 | 清洁不到一半牙面 | 分区计时2分钟 |
| 只刷外侧 | 舌侧牙结石堆积 | 顺序固定不漏区 |
| 酸食后立刻刷 | 釉质磨蚀 | 先漱口等约30分钟 |
| 牙刷用到炸毛 | 清洁力归零 | 3个月一换 |
| 大头刷够不到智齿区 | 最后一颗牙成龋齿重灾区 | 小头+末牙专刷 |
| 刷完猛漱口 | 冲掉氟保护层 | 吐不漱（睡前尤其） |

### 1.4 日常养护 · 维度二：牙缝清洁（牙刷管不到的区域）

- 原理：牙刷刷不到相邻两牙的接触面（邻面），这里是成年人邻面龋与牙龈出血的重灾区；牙缝清洁与刷牙是互补关系，不能互相替代。

| 工具 | 适用人群 | 要点 | 频率 |
|---|---|---|---|
| 牙线 | 牙缝紧的正常人群首选 | 取约40-50cm，两端绕中指，C形包绕牙面上下刮4-5次，每个牙缝换干净段 | 每天至少1次（睡前） |
| 牙间刷（齿间刷） | 牙缝宽、牙周炎、正畸人群 | 直径约0.6-1.5mm按缝选号，以略有阻力为宜 | 每天1次 |
| 冲牙器（水牙线） | 正畸托槽、种植牙、桥体、手部不便者 | 定位为补充工具，不能替代牙线/牙间刷的机械刮擦 | 每天1次 |

- 手法纠错：牙线不是"锯"进牙缝硬拽，而是贴牙面滑入、贴牙面刮出。
- 初用牙线出血多=已有牙龈炎；坚持1-2周多可缓解，持续出血需就诊。

### 1.5 日常养护 · 维度三：漱口水与舌苔

| 项目 | 定位 | 要点 |
|---|---|---|
| 漱口水 | 辅助，不替代机械清洁 | 日常选无酒精温和款；含氯己定等药用漱口水遵医嘱，连续使用一般≤2周（易染色） |
| 刮舌苔 | 口臭来源管理 | 刮舌器从舌根向舌尖轻刮数下；勿用牙刷猛刷引发呕吐反射 |
| 无糖口香糖 | 餐后应急 | 木糖醇类，餐后嚼约10分钟促唾液缓冲；不能替代刷牙 |

### 1.6 日常养护 · 维度四：饮食与习惯（给牙减负）

| 维度 | 要点 |
|---|---|
| 糖的"频率">总量 | 每次进食糖后口腔酸化约30-40分钟；一天8次零嘴=8轮产酸，比一顿大餐更伤牙。糖集中在正餐后吃 |
| 酸性饮料 | 碳酸/果汁直接酸蚀釉质：用吸管、不细品久含、喝完清水漱口 |
| 咀嚼平衡 | 不长期单侧咀嚼（面部不对称+废用侧牙结石堆积） |
| 硬物 | 不用牙开瓶盖/咬核桃壳/咬线头——牙隐裂高发原因 |
| 夜磨牙 | 磨牙症者夜间戴咬合垫，否则釉质磨平、牙敏感、颞下颌关节受损 |
| 吸烟 | 牙周炎强风险因素+口腔黏膜白斑/癌变风险 |

### 1.7 定期保养（检修计划）

| 项目 | 频率 | 说明 |
|---|---|---|
| 口腔检查 | 每6-12个月 | 浅龋早发现=小修，补牙几百元解决 |
| 洗牙（龈上洁治） | 每年1-2次 | 去除牙结石；牙龈炎在此阶段可完全逆转 |
| 涂氟 | 儿童每3-6个月1次；成人高危者遵医嘱 | 强化釉质 |
| 窝沟封闭 | 磨牙萌出后（约6-8岁、11-14岁） | 给深窝沟"封路"，防龋利器 |
| 咬合/关节检查 | 出现弹响、张口受限时 | 颞下颌关节评估 |

### 1.8 磨损信号分级（按紧急度）

| 级别 | 信号 | 建议 |
|---|---|---|
| 绿（观察） | 偶发短暂冷热敏感、刷牙偶有出血 | 完善牙线+观察1-2周 |
| 黄（1-2周内就诊） | 持续敏感、反复出血、持续口臭、牙面黑点黑线、牙龈退缩 | 常规门诊 |
| 红（尽快/急诊） | 夜间自发痛、跳痛、脸肿、牙松动、外伤脱位、张口受限、发热 | 尽快就诊；外伤脱位牙可放入牛奶或含在口中，约30分钟内急诊再植 |

### 1.9 常见故障与维修梯度（价格为参考区间，因地区与机构差异大）

| 故障 | 发展路径 | 维修层级 | 说明 |
|---|---|---|---|
| 龋齿 | 浅龋→中龋→深龋→牙髓炎→根尖炎 | 补牙（数百元）→根管+冠（数千元）→拔除+种植/桥（上万元） | 每晚一步，代价上一个数量级 |
| 牙龈炎→牙周炎 | 刷牙出血→探诊出血→牙周袋→骨吸收→松动 | 洗牙→龈下刮治→牙周手术/夹板固定 | 牙龈炎可逆；骨吸收不可逆 |
| 牙隐裂 | 咬硬物后咬合痛 | 调合→嵌体→冠→根管 | 越早固定代价越小 |
| 智齿问题 | 冠周炎反复、顶坏邻牙 | 消炎后拔除 | 位置正、有咬合功能、能清洁到的可保留 |
| 牙敏感 | 楔状缺损/釉质磨耗/牙龈退缩 | 抗敏牙膏→充填/脱敏治疗 | 先查原因再处理 |
| 牙外伤 | 冠折/根折/脱位 | 修补/根管/再植 | 断片保存好可再粘接 |

### 1.10 牙齿寿命表（保养决定论）

| 保养水平 | 大致结局 |
|---|---|
| 全套保养（刷牙+牙线+定期洗牙检查） | 天然牙用到老的比例显著提高 |
| 只刷牙、不洁牙不检查 | 牙周病失牙主路径，多在中老年显现 |
| 基本不维护 | 龋齿+牙周病双路径，失牙明显提前 |

- 天然牙理论寿命=终身；实际取决于保养投入。
