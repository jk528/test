### 1.4 磨损信号

- 红旗（当日就医）：突发视力下降、视野缺损、眼前闪光+飞蚊剧增（视网膜脱离先兆）、眼痛+视力降+看灯有彩虹圈（急性青光眼）。
- 常规信号：视物模糊、干涩酸胀、复视（突发复视需就医查神经/肌肉原因）。

### 1.5 常见故障与维修

| 故障 | 说明 | 处理 |
|---|---|---|
| 近视 | 眼轴变长，不可逆 | 防控>矫正； OK镜/低浓度阿托品等遵医嘱 |
| 干眼 | 泪膜不稳定 | 不含防腐剂人工泪液+热敷睑板腺+减少盯屏 |
| 白内障 | 晶状体混浊（年龄性为主） | 成熟后手术换人工晶体=成熟的"更换件" |
| 青光眼 | 眼压损伤视神经，不可逆 | 早筛早治，视野定期复查 |
| 糖网 | 视网膜微血管病变 | 控糖+年检眼底+激光/抗VEGF治疗 |

### 1.6 禁忌操作

- 揉眼（尤其过敏季）、黑暗中长时间看屏幕、侧躺单眼压床玩手机（双眼度数差增大）。
- 自行长期使用"去红血丝"滴眼液（血管收缩剂类）。
- 眼睑卫生（008补充）：麦粒肿（针眼）勿挤压，热敷观察；反复发作查睑缘炎与血糖。

## 2. 耳（015–019）

### 2.1 结构速览

| 编号 | 结构 | 一句话定位 |
|---|---|---|
| 015 | 外耳与外耳道 | 采音喇叭+耵聍自清通道 |
| 016 | 鼓膜 | 话筒振膜（薄而易破） |
| 017 | 中耳（听小骨·咽鼓管） | 功率放大器+气压平衡阀 |
| 018 | 耳蜗（听觉毛细胞） | 信号转换器（毛细胞死一个少一个，不可再生） |
| 019 | 前庭 | 陀螺仪（平衡传感器） |

### 2.2 日常养护

- 耵聍（耳屎）自排：外耳道上皮有自外向内的迁移蠕动，正常不需掏耳；棉签只会把它推得更深。
- 耳机60-60原则：音量≤60%、连续时长≤60分钟；嘈杂地铁里反而建议降噪耳机（减少音量补偿）。
- 噪声防护：长期≥85分贝环境（演唱会/工地/机舱）戴耳塞。
- 进水处理：歪头单脚跳+低温吹风机远吹，勿用棉签深捅。

### 2.3 定期保养与信号

- 长期噪声暴露职业者年度测听；40+出现听不清高频（耳鸣、电视音量越开越大）时就诊测听。
- 红旗：**突发性耳聋**（数小时至数天内听力骤降，治疗黄金窗约72小时，按急诊处理）；眩晕+耳闷+耳鸣三联（就诊查内耳）。
- 常规信号：耳鸣持续>1周、渐进听力下降、耳痛流脓。

### 2.4 常见故障与禁忌

| 故障 | 要点 |
|---|---|
| 耵聍栓塞 | 软化冲洗即解，勿自掏 |
| 中耳炎 | 感冒后儿童高发（咽鼓管作祟），耳痛及时就诊 |
| 突发性耳聋 | 急诊级别，越早治疗恢复率越高 |
| 梅尼埃病 | 反复眩晕+耳闷+波动听力下降，专科管理 |

- 禁忌：棉签/挖耳勺深掏、采耳店过度清理、用力擤鼻（连累中耳）。

## 3. 鼻与鼻窦（020–021）

### 3.1 日常养护

- 生理盐水洗鼻（约0.9%浓度）：过敏性鼻炎与感冒期的物理清洁，早晚各1次。
- 室内湿度40-60%；戒挖鼻抠鼻（黏膜损伤+感染入口）。

### 3.2 磨损信号与鼻出血正确处理

- 晨起喷嚏阵+清水样涕=过敏性鼻炎；黄绿脓涕+面颊胀痛=鼻窦炎倾向；**单侧鼻塞+血涕持续**（需就诊排除占位）。
- 鼻出血正确姿势：低头前倾+捏住鼻翼10-15分钟+冷敷面颊；**不仰头**（血吞入胃刺激呕吐）、不塞纸团。>20分钟不止或反复出血就诊。

### 3.3 常见故障与禁忌

| 故障 | 管理 |
|---|---|
| 过敏性鼻炎 | 回避过敏原+洗鼻+鼻用激素规律使用（遵医嘱，不"好一点就停"） |
| 急性鼻窦炎 | 脓涕+面痛+嗅觉下降，及时就诊 |
| 药物性鼻炎 | 减充血鼻喷剂连续使用不超过约1周 |

- 禁忌：双鼻同时用力擤鼻（压力冲入咽鼓管→中耳炎）。

## 5. 泪器（009 详述）

- 干眼管理三步：环境（加湿/避风直吹）→行为（完整眨眼/20-20-20/热敷）→补充（不含防腐剂人工泪液）。
- 泪道阻塞（持续溢泪）→眼科冲洗泪道，多数可通。

## 6. 眼外肌（014 详述）

- 长时间近距离用眼=眼外肌持续紧张（睫状肌痉挛→假性近视成分）。
- 突发复视=红旗（神经或肌肉原因），当日就医。
