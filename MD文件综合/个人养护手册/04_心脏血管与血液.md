# 04 心脏血管与血液 —— 动力泵与管网

> 覆盖零件：总表 030–041（082 心肌在本章与09章双向引用）
> 心血管系统的特点：故障常在"静默期"积累（动脉粥样硬化从青少年就开始），而第一次报警可能就是大修级别——所以点检（血压/血脂）比感觉重要。

## 1. 心脏（030–032）

### 1.1 零件参数

- 每天搏动约10万次，静息每分钟泵血约5L（全天约7000-10000L血液）。
- 三大子零件：心肌（030，动力）、心瓣膜（031，单向阀）、传导系统（032，节拍器/窦房结等）。

### 1.2 日常养护

| 项 | 通识口径 |
|---|---|
| 有氧 | 每周150-300分钟中等强度（快走/慢跑/游泳/骑行）+每周2次力量 |
| 饮食 | 地中海式；盐<5g/天；反式脂肪尽量归零；鱼每周2次 |
| 体重 | BMI 18.5-23.9；腰围男<90cm、女<85cm |
| 烟酒 | 戒烟（戒烟1年冠心病风险约减半）；酒越少越好 |
| 睡眠 | 7-9小时；响鼾憋气要查（睡眠呼吸暂停是高血压推手） |
| 情绪 | 暴怒与极端应激是心梗诱因之一 |

### 1.3 定期保养

| 项目 | 频率 |
|---|---|
| 血压 | 每年至少；家庭自测更真实（坐位休息5分钟、袖带与心脏同高、测2次取均值） |
| 血脂 | 40岁前每2-3年；40岁后每年；已异常者遵医嘱 |
| 心电图 | 随年度体检 |
| 心脏彩超 | 40岁起可加入体检；有心悸/杂音随时 |
| 颈动脉超声 | 三高/吸烟/家族史等高危人群 |

### 1.4 磨损信号

- 红旗：胸痛压榨/闷胀感>5分钟不缓解，可放射至左臂/下颌，伴冷汗→立即120（用药听从120与医生指导）。
- 常规信号：活动耐力进行性下降、爬两层楼气短、夜间憋醒坐起、下肢对称性凹陷水肿。

### 1.5 常见故障与维修梯度

| 故障 | 说明 | 维修层级 |
|---|---|---|
| 冠心病 | 冠状动脉斑块狭窄（心绞痛→心梗：斑块破裂+血栓） | 药物→支架（解除局部狭窄，术后双抗+终身保养）→搭桥 |
| 心律失常 | 房颤常见：心悸+血栓风险（卒中风险明显升高） | 药物/抗凝/消融 |
| 瓣膜病 | 阀门老化（狭窄/反流） | 随访→修复/置换（可更换件） |
| 心衰 | 泵功能衰退的终点站 | 药物+生活方式，重在早期预防 |

### 1.6 禁忌操作

- 饱餐后剧烈运动、寒冷中猛用力、屏气用力（如憋便）、自行停药（尤其抗凝/降压药）。

## 2. 冠状动脉（033）

- 心脏的"自供油路"；动脉粥样硬化从青少年期即开始（血管壁出现脂纹），保养窗口终身有效——从什么时候开始养护都不晚，但越早越便宜。

## 3. 动脉系统（034–035）

| 维度 | 内容 |
|---|---|
| 功能定位 | 高压输油管（主动脉弹性储能，中小动脉分配血流） |
| 点检指标 | 血压=管网压力表：诊室标准≥140/90（非同日3次）考虑高血压；家庭自测≥135/85即需关注 |
| 老化机制 | 高血压/吸烟/高血糖/高血脂=四把刻刀，刻痕即斑块 |
| 保养 | 与心脏养护同源；控压是给全身管网"降工作压力" |

## 4. 静脉（036）

| 维度 | 内容 |
|---|---|
| 功能定位 | 低压回油路，靠肌肉泵+单向瓣把血送回心脏 |
| 日常养护 | 久坐每小时踝泵（勾脚绷脚10次）；久站职业用弹力袜；休息时抬高下肢 |
| 磨损信号 | 小腿青筋凸起、沉重酸胀、傍晚足踝肿胀 |
| 常见故障 | 静脉曲张、深静脉血栓（红旗：单侧腿肿痛，**禁忌按摩**，血栓可能脱落致肺栓塞） |
| 高危场景 | 长途飞行/久坐游戏/术后卧床：每小时活动+足量饮水 |

## 5. 毛细血管（037）

- 全身物资交换的最后一公里；糖尿病最伤微血管（视网膜/肾/足——联动02/07/10章），控糖本质是保护微循环。

## 6. 血液（038–041）

### 6.1 零件参数

| 成分 | 寿命/特性 | 职能 |
|---|---|---|
| 红细胞 | 约120天 | 运氧（含铁） |
| 白细胞 | 数小时至数天 | 免疫部队（详见13章） |
| 血小板 | 约7-10天 | 堵漏维修队 |
| 血浆 | 约90%为水 | 运输介质+凝血因子 |

### 6.2 保养

- 营养：铁（女性经期注意补充）、叶酸、B12；足量饮水维持血容量。
- 献血：健康成人定期献血安全（全血间隔≥6个月，按当地规定），献血前后补水。

### 6.3 体检解读速览

| 指标 | 常见含义 |
|---|---|
| 血红蛋白↓ | 贫血（缺铁性最常见；乏力/苍白/活动心慌） |
| 白细胞↑ | 常见感染/应激 |
| 白细胞↓ | 病毒感染可能；显著持续降低需复查 |
| 血小板↓ | 注意出血信号；异常需复查 |
| 便潜血+ | 消化道出血信号（联动06章肠镜） |

- 红旗：不明原因成片瘀斑、反复鼻血+乏力苍白→血液科就诊。
