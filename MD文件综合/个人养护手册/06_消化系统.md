# 06 消化系统 —— 9 米生化长廊

> 覆盖零件：总表 049–059（053 阑尾的免疫职能详见13章；059 胰腺的内分泌部详见12章）
> 消化道的特点：全程约9米管道，零件多、分工细，且与情绪（脑肠轴）深度联动——它是全身最容易被"生活饮食习惯"直接伤害的系统。

## 0. 全线总览

食管（约25cm）→胃（空腹容量约50ml，可扩张至约1.5L）→十二指肠→空肠回肠（共6-7m）→盲肠阑尾→结肠（约1.5m）→直肠→肛门；附属车间：肝、胆囊胆道、胰腺。

## 2. 胃（050）

### 2.1 零件参数与养护

- 胃酸pH约1.5-3.5（强到可腐蚀金属——靠黏液屏障保护自己；屏障失衡=溃疡）。

| 养护项 | 口径 |
|---|---|
| 三餐规律 | 胃酸按点分泌，长时间空转=自我消化 |
| 细嚼慢咽 | 每口约20次 |
| 七分饱 | 暴食撑坏贲门括约肌 |
| 少腌制烟熏烧烤 | 胃癌相关饮食因素 |
| 分餐公筷 | 阻断幽门螺杆菌经口传播 |

### 2.2 专题：幽门螺杆菌（Hp）

- 1类致癌物，感染者胃癌风险显著升高（相对风险数倍级）。
- 建议：成人可筛查一次（碳13/14呼气试验，简便无创）；阳性且符合指征（胃癌家族史/症状）→规范根除（四联方案10-14天，遵医嘱，漏服药=杀不死）。
- 家庭防再感染：分餐或公筷、餐具消毒、不口对口喂孩子。

### 2.3 信号与保养

| 级别 | 信号 | 动作 |
|---|---|---|
| 常规 | 规律性餐前痛/夜间痛（十二指肠溃疡典型）、餐后痛（胃溃疡典型） | 就诊+呼气试验 |
| 红旗 | 黑便（柏油样=上消化道出血）、呕血 | 立即就医 |
| 保养 | 40-45岁建议做1次胃镜基线（结合风险，高危提前；无异常可间隔数年复检） | 胃镜=胃的"全面拆检" |

### 2.4 禁忌

- 空腹酗酒、长期自行服用止痛药（NSAIDs伤胃黏膜）、汤泡饭囫囵吞、带着情绪吃饭（脑肠轴紊乱）。

## 3. 十二指肠（051）

- 胆汁胰液的汇合口+溃疡高发区（"饥饿痛、进食缓解"是它被怀疑的信号）；也是胆石阻塞的必经之路。

## 4. 空肠与回肠（052）

- 吸收主力：6-7米；经环状褶皱+绒毛+微绒毛三级放大，有效吸收面积可达数十至上百平方米（放大口径不同，数据差异大）。
- 保养：吸收不良信号（慢性腹泻+体重下降+贫血）→就诊查因；乳糖不耐者换零乳糖奶或酸奶。

## 5. 盲肠与阑尾（053，免疫详见13）

- 典型故障=阑尾炎：转移性右下腹痛+发热，及时就医（拖延=穿孔风险）。顺口提醒：右下腹痛切勿自行揉按止痛硬扛。

## 6. 结肠（054）

### 6.1 菌群车间

- 约38万亿细菌共生；功能：发酵纤维产短链脂肪酸、合成维生素K与部分B族、训练免疫系统（联动13章）。

### 6.2 保养

| 项 | 口径 |
|---|---|
| 膳食纤维 | 25-30g/天（全谷、豆类、蔬果） |
| 发酵食品 | 酸奶等；抗生素遵医嘱使用（滥用=对菌群无差别轰炸） |
| 排便节律 | 利用晨起/餐后胃结肠反射；如厕≤5-10分钟、不带手机；脚下垫小凳前倾姿势更顺畅 |
| 运动 | 肠蠕动天然泵 |

### 6.3 筛查（性价比最高的防癌操作）

- 腺瘤性息肉→肠癌多经历5-15年窗口：肠镜下顺手切除=把癌症扼杀在萌芽。
- 建议40-45岁起做肠镜（普通风险无异常可5-10年复检，遵医嘱）；不愿直接肠镜者可先年度便潜血/FIT，阳性仍需肠镜。

### 6.4 信号

- 红旗级：排便习惯改变（便秘腹泻交替>1个月）、便血（暗红混匀=上游出血需查）、大便变细、贫血+消瘦。
- 注：鲜血附于便面多为痔，但首次便血建议就医明确，别都归咎"老痔"。

## 7. 直肠与肛门（055–056）

- 痔疮预防套餐：纤维+足量水+不蹲坑玩手机+便后温水清洁+提肛运动（凯格尔，详见07章）。
- 长期依赖泻药（结肠黑变病）与长期憋便都是禁忌。

## 8. 肝脏（057）

### 8.1 零件参数

- 全身化工厂：500余种功能；唯一具备强大再生能力的大器官（切除大部可复原）——但进展到肝硬化则失代偿不可逆。

### 8.2 日常养护

| 项 | 说明 |
|---|---|
| 限酒 | 酒精为1类致癌物；饮酒脸红者乙醛代谢更差；无"安全剂量"，能不喝不喝 |
| 不滥药 | 对乙酰氨基酚过量伤肝（勿叠加多种感冒药）；草药/保健品肝损伤不少见（土三七等） |
| 体重 | 脂肪肝已是最常见肝病；减重5-10%可显著改善，早中期可逆 |
| 疫苗 | 乙肝疫苗；感染者规范抗病毒+定期随访（母婴阻断已成熟） |
| 霉变 | 黄曲霉毒素为1类致癌物——霉变花生玉米整包弃用，警惕土法压榨油 |
| 生食 | 淡水鱼生→肝吸虫风险 |

### 8.3 保养与信号

- 定期保养：每年肝功能+腹部B超；乙肝/脂肪肝者6-12个月随访，按需加甲胎蛋白。
- 信号：眼黄尿浓茶色（黄疸）、肝掌蜘蛛痣、腹胀腿肿。
- 发展链：肝炎→肝硬化→肝癌，每一步都是拦截点，拦截越早代价越小。
