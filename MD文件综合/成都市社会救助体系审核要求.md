# 成都市社会救助体系审核要求

> 政策依据：
> - 《成都市最低生活保障审核确认工作规程》（成民发〔2023〕38号）
> - 《成都市最低生活保障边缘家庭救助办法》（成民发〔2022〕37号）
> - 《成都市刚性支出困难家庭认定办法》（2025年11月1日起施行）

---

## 一、一类：最低生活保障（低保）

### 1.1 认定条件

申请最低生活保障以家庭为单位，应当同时符合以下基本条件：

**（一）户籍条件**
- 本市户籍共同生活的家庭成员
- 夫妻任一方是本市户籍居民组成的家庭
- 申请人可凭居住证向经常居住地提出申请

**（二）收入条件**
- 共同生活的家庭成员人均可支配收入低于本市低保标准
- 申请前6个月平均收入为基础进行核算

**（三）财产条件**
- 家庭财产状况符合相关规定（参照低保边缘家庭财产标准）

### 1.2 共同生活家庭成员范围

**计入人员：**
1. 配偶
2. 未成年子女
3. 已成年但不能独立生活的子女（含在校本科及以下学历教育的成年子女）
4. 其他具有法定赡养、扶养、抚养义务关系并长期共同居住的人员

**不计入人员：**
1. 连续三年以上（含三年）脱离家庭独立生活的宗教教职人员
2. 在监狱内服刑、在戒毒所强制隔离戒毒或者宣告失踪人员
3. 县级民政部门依照有关规定认定的其他人员

### 1.3 不计入家庭收入的项目

1. 国家规定的劳动模范荣誉津贴、优待抚恤金、义务兵津贴、计划生育奖励与扶助金、奖学金、见义勇为等奖励性补助
2. 困难残疾人的生活补助和重度残疾人的护理补贴
3. 80岁以上高龄老人津贴
4. 工伤人员的医疗费、护理费、一次性伤残补助金等特定用途补助资金
5. 社会救助帮扶资金、在校学生奖学金、公益服务津贴
6. 中央确定的城乡居民基本养老保障基础养老金
7. 区（市）县人民政府规定的其他收入

### 1.4 可豁免情形（家庭经济状况核算时）

1. **供养费用豁免**：依靠兄弟姐妹或60周岁及以上老年人供养的成年无业重度残疾人/重病人员/失能失智患者，供养费用可视情按不高于低保月标准的80%予以豁免；70周岁及以上老年人给付的供养费用全部豁免

2. **特殊人员豁免**：申请家庭中有重点优抚对象、满60周岁老年残疾（失智失能）人、70周岁以上老年人、一户多残、计划生育特别扶助家庭人员，按当地低保月标准的10%予以豁免；叠加最高不超过30%

3. **教育阶段豁免**：
   - 学前教育、义务教育阶段学生：按低保月标准的20%豁免
   - 高中（中职）教育阶段学生：按低保月标准的40%豁免
   - 大学教育阶段学生：按低保月标准的80%豁免

4. **务工成本豁免**：外出务工、返岗复工的低保对象，按当地低保月标准的100%扣减务工成本

5. **机动车豁免**：唯一经济型机动车，首次购买或实际折价价值不超过当地年最低生活保障标准8倍（含8倍）

6. **住房豁免**：唯一居住房（包括贷款购买普通商品住房）用于保障家庭成员生活居住

### 1.5 不得纳入低保的辅助指标

1. 申请前后自费安排家庭成员出国留学、自费出国旅游
2. 购买非普通商品房、商铺、高级轿车等支出明显高于周边一般生活消费水平
3. 家庭收入（财产）动态变化与申报情况存在较大差异且无正当理由
4. 上级民政部门规定的其他情形

### 1.6 单人户申请情形

符合下列情形之一的人员，可以单独提出申请：

1. 低收入家庭中或成年无业持有中华人民共和国残疾人证的一级、二级重度残疾人；三级、四级智力残疾人和三级、四级精神残疾人
2. 低收入家庭中重病人员（含21类大病病种及各类罕见病）
3. 符合本市集体户口管理规定且无其他共同生活家庭成员的人员
4. 脱离家庭、在宗教场所居住三年以上（含三年）的生活困难的宗教教职人员
5. 县级民政部门规定的其他特殊困难人员

> **注**：已认定的低保边缘家庭中的重度残疾人、重病人员，经本人申请，可参照"单人户"直接纳入低保范围。

### 1.7 申请材料

1. 如实填写完整并签字确认的《成都市最低生活保障申请表》
2. 申请人身份证或户口簿等身份证明材料
3. 书面承诺及授权调查核对手续
4. 家庭收入（财产）类以及遭遇困难情况等有效证明材料

### 1.8 办理流程

```
申请 → 受理（2个工作日内） → 调查核实（12个工作日内）
 → 初审公示（7天） → 审核确认（县级10个工作日/下放镇街20个工作日）
 → 资金发放（下月10日前）
```

**办理时限：**
- 一般情况：自受理之日起30个工作日内完成
- 权限下放镇（街道）：20个工作日内完成
- 特殊情况：可延长至45个工作日

### 1.9 救助标准

- 按照审核确定的申请家庭人均可支配收入与当地最低生活保障标准的实际差额计算
- 申请家庭符合低保条件的，严格执行全员纳入
- 低保边缘一类"单人户"纳入：按当地低保月标准的80%给予补助
- 低保边缘二类"单人户"纳入：按当地低保月标准的60%给予补助

## 二、二类：低保边缘家庭

### 2.1 分类标准

低保边缘家庭分为两类：

| 类别 | 收入标准 | 说明 |
|------|----------|------|
| 低保边缘1类 | 家庭人均月收入高于当地低保标准50%以内（含50%） | 即低于当地低保标准的1.5倍 |
| 低保边缘2类 | 家庭人均月收入高于当地低保标准100%以内（含100%） | 即低于当地低保标准的2倍 |

### 2.2 认定条件

**（一）基本条件（须同时符合）**
1. 申请人或共同生活家庭成员具有当地户籍
2. 申请之日前6个月内家庭人均月收入符合上述分类标准
3. 家庭财产状况符合相关规定

**（二）因支出过大造成困难的家庭（须同时符合）**
1. 申请人或共同生活家庭成员具有当地户籍
2. 家庭人均年收入低于上年度户籍所在区（市）县居民人均可支配收入
3. 共同生活的家庭成员经认定的医疗、教育、残疾康复或因灾、因意外事故等刚性支出，达到或超过其家庭年收入的60%

### 2.3 家庭财产标准

家庭成员名下财产应当同时符合下列条件：

| 财产类型 | 标准要求 |
|----------|----------|
| 金融资产 | 银行存款、有价证券、债券、理财产品、商业保险、工商注册出资额等总值人均不超过当地年最低生活保障标准10倍（含10倍） |
| 机动车辆 | 家庭共同生活成员名下机动车辆首次购买价值不超过当地年最低生活保障标准8倍（含8倍）；非共同生活成员名下不超过15倍（含15倍） |
| 房产 | 家庭拥有不超过2套商品房，每套面积均不超过100（含）平方米；近1年内无新建、新购住房（拆迁、专项救助除外） |
| 非居住类房屋 | 家庭成员名下不能有中大型商铺、办公楼房、中型以上厂房、多套酒店式公寓等 |

### 2.4 不计入家庭收入的项目

1. 城乡居民基本养老保险基础养老金
2. 社会救助款物、教育资助生活补助、助学金、奖学金
3. 困难残疾人生活补贴、重度残疾人护理补贴
4. 孤儿基本生活费、事实无人抚养儿童基本生活补贴、困境儿童基本生活补贴
5. 老年人高龄津贴、经济困难的高龄和失能等老年人补贴
6. 义务兵优待金、优抚对象的优待抚恤金
7. 计划生育奖励与扶助金、见义勇为奖励金

### 2.5 刚性支出范围（支出型困难）

刚性支出按照申请前6个月的支出总额计算，主要包括：

1. **医疗费用支出**：个人实际支付的医疗费用（扣除医保报销、医疗救助等后），依据票据认定
2. **教育费用支出**：幼儿园到全日制学历教育阶段的保教费/学费、住宿费，按公办学校标准认定
3. **残疾康复费用支出**：基本康复训练、护理、辅助器具适配等个人实际支付费用，依据票据认定
4. **其他刚性支出**：因灾、因意外事故等家庭刚性支出

### 2.6 不得认定情形

有下列情形之一的，不得认定为最低生活保障边缘家庭：

1. 拒绝配合有关部门对申请家庭及其相关人员经济状况进行调查的
2. 拒绝提供经济状况查询核对授权书或提供虚假、不完整授权书的
3. 自费在高收费幼儿园、学校、校外培训机构就读，或自费在境外留学的
4. 人均收入或财产超过规定标准的

### 2.7 申请材料

1. 所有共同生活的家庭成员的户口簿、身份证等证件原件
2. 签署经济状况查询核对授权书
3. 可通过小程序下载家庭经济状况证明一并提交

### 2.8 办理流程

```
申请 → 信息核对（2个工作日） → 受理/不予受理
 → 入户调查（10个工作日内，可选） → 初审公示（7天）
 → 审核确认（县级民政部门10个工作日）
```

**认定有效期：** 1年，期满前1个月主动申请复核；不主动申请复核的，到期自动退出。

### 2.9 救助措施

| 救助类别 | 具体内容 |
|----------|----------|
| 医疗救助 | 住院医疗费用按政策规定予以救助；可享受72小时内急重危伤病应急救助 |
| 教育资助 | 学前教育到高等教育各阶段教育资助（学前资助、义务教育生活补助、高中助学金/免学费、高等教育国家助学金/助学贷款等） |
| 住房救助 | 实物配租、租赁补贴；农村危房改造优先纳入 |
| 就业救助 | 失业登记、就业困难人员认定；确保零就业家庭至少1人就业 |
| 养老服务 | 60岁及以上老年人可享受居家和社区养老补贴或机构养老补贴 |
| 法律援助 | 为符合条件的人员提供免费法律援助 |
| 司法救助 | 对权利受到侵害无法获得有效赔偿的当事人提供一次性辅助救济 |
| 残疾人补贴 | 享受困难残疾人生活补贴、重度残疾人护理补贴 |
| 单人户低保 | 重病患者、一二级残疾人、三四级精神/智力残疾人单独纳入低保 |

## 三、三类：刚性支出困难家庭

### 3.1 认定条件

刚性支出困难家庭应当同时符合下列条件：

1. **收入条件**：共同生活的家庭成员人均收入应低于当地上年度居民人均可支配收入
2. **财产条件**：家庭财产状况限定标准参照低保边缘家庭财产状况规定确定
3. **支出条件**：提出申请前12个月家庭刚性支出总额占家庭总收入比例超过50%
4. **身份条件**：未被审核确认为低保对象、特困人员、低保边缘家庭
5. **其他条件**：县级以上地方人民政府规定的其他条件

### 3.2 刚性支出范围

刚性支出按照申请前12个月的支出总额计算，主要包括：

| 支出类型 | 具体内容 | 认定方式 |
|----------|----------|----------|
| 生活支出 | 维持基本生活的衣、食、住、行、用等费用 | 按当地年低保标准计算 |
| 医疗支出 | 定点医药机构就医的门诊和住院费用（个人负担部分） | 依据有效票据认定 |
| 教育支出 | 幼儿园到全日制普通本科高等学校等学历教育阶段的保教费/学费、住宿费 | 按同类公办学校收费标准认定 |
| 残疾康复支出 | 基本康复训练、辅助器具适配等个人负担费用 | 依据有效票据认定 |
| 其他支出 | 县级民政部门根据实际情况另外认定的支出 | — |

### 3.3 不得认定情形

有下列情形之一的，不得认定为刚性支出困难家庭：

1. 共同生活的家庭成员有"企业法人代表"，并正在从事经营活动，或雇佣他人从事经营性活动的
2. 在法定劳动年龄段内有劳动能力但未就业，无正当理由拒绝接受介绍的与其健康状况、劳动能力等相适应的工作
3. 无正当理由拒不配合家庭经济状况核对和调查
4. 故意隐瞒家庭成员真实收入、家庭财产、家庭人口变动情况，或提供虚假材料
5. 存在与其当前救助期间不相符的消费行为且无法说明正当理由的
6. 县级及以上民政部门规定的其他情形

### 3.4 申请方式

1. **申请主体**：以家庭为单位，由一名共同生活的家庭成员作为申请人
2. **申请地点**：户籍所在地、经常居住地或居住证签发地镇（街道）
3. **委托申请**：村（居）民委员会、其他单位或人员可代为提出申请（需提供授权委托书）
4. **线上申请**：可通过"成都民政通"小程序线上提交申请材料

### 3.5 申请材料

1. 所有共同生活的家庭成员的户口簿、身份证等证件原件
2. 如实书面声明家庭经济状况
3. 履行委托核查家庭及法定赡养、抚（扶）养义务人家庭经济状况的相关程序

### 3.6 办理流程

```
申请 → 信息核对（2个工作日） → 受理/不予受理
 → 入户调查（10个工作日内，可选） → 初审公示（7天）
 → 审核确认（30个工作日内）
```

**办理时限：**
- 一般情况：自正式受理之日起30个工作日内完成
- 特殊情况：可延长至45个工作日
- 资格有效期：12个月

**特殊情况处理：**
- 家庭成员长期失联、核查要件不全、劳动能力或残疾等级无法鉴定等特殊情况，经本人签署承诺书后，可通过"一事一议"方式集体研究处理
- 经审核不符合低保、特困、低保边缘条件但符合刚性支出困难条件的，经本人同意可直接转入认定程序

### 3.7 认定结果运用

1. **临时救助**：按照《成都市临时救助工作规程》有关规定实施救助
2. **专项救助转介**：及时转介教育、人社、住建、医保、卫健等社会救助管理部门
3. **专项救助标准**：参照低保边缘家庭有关规定执行
4. **动态监测**：纳入低收入人口动态监测信息平台常态化监测预警范围

**资格有效期：** 1年，期满前1个月主动申请复核；不主动申请复核的，到期自动退出。

## 四、三类救助对比总览

| 对比项 | 一类：低保 | 二类：低保边缘家庭 | 三类：刚性支出困难家庭 |
|--------|-----------|-------------------|----------------------|
| **收入标准** | 人均收入低于低保标准 | 1类：低于低保标准1.5倍<br>2类：低于低保标准2倍 | 低于上年度居民人均可支配收入 |
| **支出要求** | — | 支出型：刚性支出≥年收入60% | 刚性支出占总收入比例>50% |
| **财产标准** | 符合相关规定 | 详见2.3节 | 参照低保边缘家庭 |
| **户籍要求** | 本市户籍 | 当地户籍 | 本市户籍 |
| **核算周期** | 申请前6个月 | 申请前6个月 | 申请前12个月 |
| **办理时限** | 30个工作日 | 约25个工作日 | 30个工作日 |
| **有效期** | 动态管理 | 1年 | 1年 |
| **政策依据** | 成民发〔2023〕38号 | 成民发〔2022〕37号 | 2025年11月1日起施行 |
| **主要救助** | 低保金（差额补助） | 医疗、教育、住房、就业等专项救助 | 临时救助+专项救助转介 |

## 五、通用审核要求

### 5.1 调查方式

1. **信息化核对**：通过政务信息资源共享平台查询家庭经济状况
2. **入户调查**：至少2名调查人员参加，填写入户调查表并签字
3. **邻里访问**：走访村（居）委会和社区群众了解情况
4. **信函索证**：向相关单位和部门索取证明材料
5. **民主评议**：可选项，由不少于7人（奇数）参加，村民代表不少于三分之二

### 5.2 公示要求

- 初审结果公示期为7天
- 在村（社区）公开栏、镇（街道）公共服务大厅及网络平台公示
- 公示中应保护个人隐私，不得公开与救助申请无关的信息

### 5.3 近亲属备案

共同生活家庭成员与低保经办人员或村（居）民委员会成员有近亲属关系的，应当单独登记备案。近亲属包括：配偶、父母、子女、兄弟姐妹、祖父母和外祖父母、孙子女和外孙子女。

### 5.4 动态管理

1. 家庭经济状况发生明显变化的，应当及时申报
2. 低保边缘家庭和刚性支出困难家庭资格有效期为1年
3. 期满前1个月主动申请复核，程序从简
4. 不主动申请复核的，到期自动退出

### 5.5 容错纠错机制

对秉持公心、履职尽责但因客观原因出现失误偏差且能够及时纠正的，经有关部门调查认定，依法依规予以免责。
