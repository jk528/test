# 鸿蒙（HarmonyOS NEXT）开发全流程环境配置指南

> 适用：一台全新电脑从零搭建鸿蒙开发环境，完成开发、调试、打包、上架全流程。
> 目标系统：HarmonyOS NEXT（API 12+，纯血鸿蒙，ArkTS + ArkUI）
> 文档版本：2026-10

---

## 一、电脑硬件要求

### 1.1 最低配置

| 部件 | 最低要求 |
|------|----------|
| CPU | 8 核及以上，支持 VT-x / AMD-V 硬件虚拟化 |
| 内存 | 16 GB |
| 硬盘 | 100 GB 可用空间（SSD） |
| 显卡 | 集成显卡，支持 OpenGL 3.2+ |
| 显示器 | 1920×1080 分辨率 |
| 网络 | 宽带（需下载 SDK、模拟器镜像） |

### 1.2 推荐配置

| 部件 | 推荐配置 |
|------|----------|
| CPU | Intel i7 / AMD Ryzen 7 及以上，16 核更佳 |
| 内存 | 32 GB（模拟器 + DevEco + 浏览器同时运行） |
| 硬盘 | 256 GB NVMe SSD 可用空间 |
| 显卡 | 独立显卡（NVIDIA / AMD），模拟器硬件加速更流畅 |
| 显示器 | 2K / 4K，支持多屏 |
| 网络 | 千兆宽带 |

### 1.3 BIOS 必须开启的选项

- **VT-x / AMD-V**（虚拟化技术）—— 模拟器必需
- **Hyper-V**（Windows 可选，DevEco 模拟器会用到）
- 关闭 Secure Boot（部分模拟器需要）

> 检查虚拟化是否开启（Windows）：
> ```powershell
> Get-CimInstance -ClassName Win32_Processor | Select-Object VirtualizationFirmwareEnabled
> ```

## 四、全流程步骤

### 阶段 1：环境准备

#### 4.1 开启虚拟化
1. 重启电脑进入 BIOS
2. 找到 `Virtualization` / `VT-x` / `SVM Mode`，设为 `Enabled`
3. 保存重启

#### 4.2 安装 Git
```powershell
winget install --id Git.Git -e
```
配置：
```powershell
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

#### 4.3 下载并安装 DevEco Studio
1. 访问 https://developer.huawei.com/consumer/cn/develostudio/
2. 下载 Windows 版安装包（约 2GB+）
3. 解压并运行 `devecostudio.exe`
4. 安装路径建议：`D:\DevEcoStudio`（避免 C 盘空间不足）
5. 首次启动会进入 **Setup Wizard**

#### 4.4 首次启动配置（Setup Wizard）
1. **SDK 下载**：选择 HarmonyOS NEXT SDK，下载到 `D:\HarmonyOS\Sdk`
2. **Node.js**：使用 DevEco 内置或指定本地 Node.js
3. **OHPM**：自动配置
4. 登录华为开发者账号（必须，否则无法下载模拟器镜像和申请签名）

---

### 阶段 2：SDK 与工具链配置

#### 4.5 通过 SDK Manager 安装组件
路径：`DevEco Studio → File → Settings → HarmonyOS SDK`

必装组件：
- [x] HarmonyOS NEXT SDK（API 12 / 13 / 最新）
- [x] HarmonyOS NEXT SDK System Image（模拟器镜像）
- [x] Toolchains（hvigor、ohpm、hdc、ark_disassembler）
- [x] Command Line Tools

#### 4.6 配置环境变量（Windows）
```powershell
# SDK 路径（按实际安装位置调整）
$env:HOS_SDK_HOME = "D:\HarmonyOS\Sdk"
# hdc 工具
$env:Path += ";D:\HarmonyOS\Sdk\openharmony\toolchains"
# hvigor
$env:Path += ";D:\HarmonyOS\Sdk\openharmony\toolchains\hvigor\bin"
# ohpm
$env:Path += ";D:\HarmonyOS\Sdk\openharmony\toolchains\ohpm\bin"
```

永久写入用户环境变量：
```powershell
[Environment]::SetEnvironmentVariable("HOS_SDK_HOME", "D:\HarmonyOS\Sdk", "User")
```

#### 4.7 验证安装
```powershell
hdc version
ohpm -v
hvigor -v
```

---

### 阶段 3：模拟器与真机配置

#### 4.8 创建本地模拟器
1. `DevEco Studio → Tools → Device Manager`
2. 点击 **New Emulator**
3. 选择设备类型：Phone / Tablet / 2-in-1 / Wearable / TV
4. 选择系统镜像（HarmonyOS NEXT API x）
5. 配置 CPU/内存（建议 4 核 4GB 起）
6. 启动模拟器

#### 4.9 真机调试配置
1. 手机：设置 → 关于 → 连续点击"HarmonyOS 版本"7 次 → 开启开发者模式
2. 设置 → 系统和更新 → 开发者选项 → 开启 **USB 调试**
3. USB 连接电脑，手机弹窗允许调试
4. 验证：
```powershell
hdc list targets
```

---

### 阶段 4：签名配置（调试 + 发布）

#### 4.10 自动签名（调试用，推荐）
1. `DevEco Studio → File → Project Structure → Project → Signing Configs`
2. 勾选 **Automatically generate signature**
3. 登录华为账号后会自动生成调试证书和 Profile

#### 4.11 手动签名（发布用）
1. **生成密钥库（.p12）**：
```powershell
keytool -genkeypair -alias mykey -keyalg RSA -keysize 2048 -validity 9125 -keystore myapp.p12 -storetype PKCS12
```
2. **创建 CSR**：在 AppGallery Connect 上申请证书
3. **创建 Profile**：绑定应用 + 证书
4. 在 `Project Structure → Signing Configs` 中配置 `Store file`、`Store password`、`Key alias`、`Key password`、`Profile`、`Certpath`

> 签名材料申请地址：https://developer.huawei.com/consumer/cn/agconnect/

---

### 阶段 5：项目开发

#### 4.12 创建项目
1. `DevEco Studio → New Project`
2. 选择模板：
   - **Empty Ability**（单页面应用）
   - **Atomic Service**（元服务/原子化服务）
   - **Native C++**（含 C/C++ 模块）
3. 配置：
   - Project Name：`MyApp`
   - Bundle Name：`com.company.myapp`（需与 AGC 一致）
   - Save Location：`D:\HarmonyOS\Projects`
   - Compatible SDK：选择最新 API
4. 点击 **Finish**

#### 4.13 项目结构
```
MyApp/
├── entry/                  # 主模块
│   ├── src/main/ets/       # ArkTS 代码
│   │   ├── pages/          # 页面
│   │   ├── components/      # 自定义组件
│   │   └── entryability/   # Ability 入口
│   ├── src/main/resources/ # 资源（图片、字符串、多媒体）
│   └── build-profile.json5 # 模块构建配置
├── hvigor/                 # 构建脚本
├── oh-package.json5        # 依赖配置
├── build-profile.json5     # 工程构建配置
└── AppScope/               # 应用级配置
```

#### 4.14 安装依赖
```powershell
ohpm install
```

#### 4.15 运行调试
- 选择设备（模拟器 / 真机）
- 点击 **Run**（▶）或 **Debug**（🐛）
- 热重载：修改代码后自动刷新预览

---

### 阶段 6：构建打包

#### 4.16 Debug 包（调试用）
```powershell
hvigorw assembleHap --mode module -p product=default
```
产物：`entry/build/default/outputs/default/entry-default-signed.hap`

#### 4.17 Release 包（发布用）
1. `Project Structure → Signing Configs` 配置 release 签名
2. `Build → Build Hap(s)/APP(s) → Build Hap(s)`
3. 或命令行：
```powershell
hvigorw assembleHap --mode module -p product=release
hvigorw assembleApp --mode project -p product=release
```

#### 4.18 产物说明

| 文件 | 说明 | 用途 |
|------|------|------|
| `.hap` | HAP 安装包 | 单模块安装包，调试/内测 |
| `.app` | APP 包 | 多模块聚合包，上架用 |
| `.so` | 动态库 | Native 模块产物 |

#### 4.19 多模块 / 原子化服务打包
- **HSP**（动态共享包）：`hvigorw assembleHsp`
- **HAR**（静态共享包）：`hvigorw assembleHar`
- **APP**（上架包）：`hvigorw assembleApp`

---

### 阶段 7：上架发布

#### 4.20 创建应用
1. 登录 AppGallery Connect：https://developer.huawei.com/consumer/cn/agconnect/
2. 我的项目 → 选择项目 → 常规 → 应用信息
3. 确认 **包名**、**应用 ID** 与本地一致

#### 4.21 上传包
1. AGC → 分发 → 版本信息 → 准备提交
2. 上传 `.app` 文件
3. 填写版本说明、更新内容

#### 4.22 提交审核
1. 完善应用信息：图标、截图、描述、隐私政策
2. 提交审核（1-3 个工作日）
3. 审核通过后自动上架 / 手动发布

## 五、一键环境检查脚本

将以下脚本保存为 `check-harmony-env.ps1`，在新电脑上一键检查环境：

```powershell
# check-harmony-env.ps1
# 鸿蒙开发环境一键检查脚本

Write-Host "===== 鸿蒙开发环境检查 =====" -ForegroundColor Cyan

# 1. 操作系统
$os = (Get-CimInstance Win32_OperatingSystem).Caption
Write-Host "[OS] $os"

# 2. CPU 虚拟化
$vt = (Get-CimInstance Win32_Processor).VirtualizationFirmwareEnabled
Write-Host "[CPU 虚拟化] $(if($vt){'已开启 ✓'}else{'未开启 ✗，请进 BIOS 开启 VT-x'})"

# 3. 内存
$mem = [math]::Round((Get-CimInstance Win32_ComputerSystem).TotalPhysicalMemory/1GB,1)
Write-Host "[内存] $mem GB $(if($mem -ge 16){'✓'}else{'✗ 建议 16GB+，推荐 32GB'})"

# 4. 硬盘可用空间
$disk = (Get-PSDrive C).Free/1GB
Write-Host "[C 盘可用] $([math]::Round($disk,1)) GB $(if($disk -ge 100){'✓'}else{'✗ 建议 100GB+'})"

# 5. Git
$git = (Get-Command git -ErrorAction SilentlyContinue).Source
Write-Host "[Git] $(if($git){$git + ' ✓'}else{'未安装 ✗'})"

# 6. hdc
$hdc = (Get-Command hdc -ErrorAction SilentlyContinue).Source
Write-Host "[hdc] $(if($hdc){$hdc + ' ✓'}else{'未配置 ✗，需安装 DevEco Studio'})"

# 7. ohpm
$ohpm = (Get-Command ohpm -ErrorAction SilentlyContinue).Source
Write-Host "[ohpm] $(if($ohpm){$ohpm + ' ✓'}else{'未配置 ✗'})"

# 8. hvigor
$hvigor = (Get-Command hvigor -ErrorAction SilentlyContinue).Source
Write-Host "[hvigor] $(if($hvigor){$hvigor + ' ✓'}else{'未配置 ✗'})"

# 9. DevEco Studio
$deveco = Get-ChildItem "C:\Program Files\Huawei\DevEco Studio","D:\DevEcoStudio","D:\Program Files\Huawei\DevEco Studio" -ErrorAction SilentlyContinue | Select-Object -First 1
Write-Host "[DevEco Studio] $(if($deveco){$deveco.FullName + ' ✓'}else{'未找到，需手动确认安装路径'})"

# 10. 已连接设备
if($hdc){
    $devices = hdc list targets 2>&1
    Write-Host "[已连接设备] $devices"
}

Write-Host "===== 检查完成 =====" -ForegroundColor Cyan
```

运行：
```powershell
powershell -ExecutionPolicy Bypass -File .\check-harmony-env.ps1
```

## 六、一键安装脚本（Windows）

将以下脚本保存为 `setup-harmony-env.ps1`，自动安装基础依赖：

```powershell
# setup-harmony-env.ps1
# 鸿蒙开发基础环境一键安装（Windows）

Write-Host "===== 开始安装鸿蒙开发基础环境 =====" -ForegroundColor Cyan

# 1. 安装 Git
if(-not (Get-Command git -ErrorAction SilentlyContinue)){
    Write-Host "安装 Git..."
    winget install --id Git.Git -e --accept-source-agreements --accept-package-agreements
    $env:Path += ";C:\Program Files\Git\cmd"

# 2. 安装 Node.js 18 LTS（可选）

    Write-Host "安装 Node.js 18 LTS..."
    winget install --id OpenJS.NodeJS.LTS -e --accept-source-agreements --accept-package-agreements
}

# 3. 配置 git
git config --global user.name "jk528528"
git config --global user.email "jk528528@gitee.com"
git config --global core.autocrlf false

# 4. 创建工作目录
$workspace = "D:\HarmonyOS\Projects"
if(-not (Test-Path $workspace)){ New-Item -ItemType Directory -Path $workspace -Force }

Write-Host "===== 基础环境安装完成 =====" -ForegroundColor Cyan
Write-Host "下一步：手动下载安装 DevEco Studio：" -ForegroundColor Yellow
Write-Host "  https://developer.huawei.com/consumer/cn/develostudio/" -ForegroundColor Yellow
```

## 八、常见问题

### Q1：模拟器启动失败 / 黑屏
- 检查 BIOS 虚拟化是否开启
- 关闭 Hyper-V 冲突：`bcdedit /set hypervisorlaunchtype off`（需重启）
- 降低模拟器内存配置

### Q2：SDK 下载慢 / 失败
- 切换网络（部分公司网络限制）
- 配置代理：`DevEco → Settings → Appearance → HTTP Proxy`

### Q3：签名错误 `error: signing config is invalid`
- 检查 Bundle Name 是否与 AGC 一致
- 重新生成调试证书（删除 `~/.ohos/config` 后重新自动签名）

### Q4：OHPM install 失败
- 配置 OHPM 私有仓库或官方源：
```json
// oh-package.json5
{
  "registry": "https://ohpm.openharmony.cn/ohpm/"
}
```

### Q5：真机无法识别
- 安装华为 USB 驱动
- 更换 USB 数据线（部分线仅供电）
- `hdc kill` 后 `hdc start`

## 十一、完整流程图

```
新电脑
  │
  ├─ 1. BIOS 开启虚拟化
  ├─ 2. 安装 Git / Node.js
  ├─ 3. 下载安装 DevEco Studio
  ├─ 4. 登录华为开发者账号
  ├─ 5. SDK Manager 安装 SDK + 镜像 + 工具链
  ├─ 6. 配置环境变量
  ├─ 7. 创建/克隆项目
  ├─ 8. 配置签名（自动调试签名 / 手动发布签名）
  ├─ 9. 创建模拟器 或 连接真机
  ├─ 10. ohpm install 安装依赖
  ├─ 11. 开发编码（ArkTS + ArkUI）
  ├─ 12. Run / Debug 调试
  ├─ 13. hvigorw assembleHap 构建 HAP
  ├─ 14. hvigorw assembleApp 构建 APP（发布包）
  ├─ 15. AGC 创建应用 + 上传 APP 包
  └─ 16. 提交审核 → 上架
```
