# 西游记五虫论源流考：一个分类体系的两千年信息溯源

> **溯源对象**：《西游记》第五十八回如来口中的「五虫」——「周天之内有五仙，乃天地神人鬼；有五虫，乃蠃鳞毛羽昆。」
> **核心结论**：五虫论**定型于西汉**（《大戴礼记·曾子天圆》，约公元前 1 世纪编成，内容传述春秋曾子之学），**萌芽于先秦月令系统**（战国《礼记·月令》《吕氏春秋·十二纪》），两千年间经历「物候标签 → 政治等级 → 道教仙阶 → 小说工具」四次变形。《西游记》对古五虫做了**三处外科手术式改编**（介→昆、倮→蠃、摘除圣人），每一处都是为「四猴混世」的叙事服务。
> **溯源方法**：以「名目首次出现」为节点，逐朝代核对名目写法、分类逻辑、「人」在体系中的位置三项指标。凡引文皆注明文献与篇目；存疑处标注「待考」。

## 零、靶文本：《西游记》第58回到底说了什么

第五十八回「二心搅乱大乾坤　一体难修真寂灭」，真假美猴王打上灵山，观音问如来这六耳猕猴的来历，如来的回答是全书唯一一次「宇宙分类学」的完整展示：

> 「周天之内有五仙，乃天地神人鬼；有五虫，乃蠃鳞毛羽昆。这厮非天非地非神非人非鬼，亦非蠃非鳞非毛非羽非昆。又有四猴混世，不入十类之种，不达两间之名。」

随后如来点出四猴：**灵明石猴、赤尻马猴、通臂猿猴、六耳猕猴**——「不入十类之种」。

**这段话里有三个需要溯源的问题：**

1. 「五虫」这个概念是吴承恩发明的吗？——**不是。**它在西汉就有完整定义。
2. 「蠃鳞毛羽昆」这个名目是原装的吗？——**不是。**古本五虫是「毛羽介鳞倮」，《西游记》改了两项。
3. 为什么四猴「不入十类」？——**因为十类里有「人/圣人」这个坑，吴承恩必须先把坑填掉**（详见第十二节）。

## 零之补、前文献时代：甲骨文到底能追溯到什么

**用户之问**：五虫论最早只能追溯到甲骨文吗？

**答案分三层——追溯的层位不同，答案完全不同：**

| 追溯层位 | 最早可到 | 证据 | 能否接到「五虫」 |
|---------|---------|------|----------------|
| **实物层**（对动物的刻画与崇拜） | 新石器时代（约前 5000–3000 年） | 红山文化玉猪龙、仰韶蚌塑龙虎、良渚神徽 | 否——只有单个神兽，无分类 |
| **文字层**（「虫」及相关字的写法） | **甲骨文（商晚期，约前 1250–1046 年）** | 见下表 | 否——只有动物专名，无「五类」框架 |
| **体系层**（五类划分＋名目） | 战国文献（前 5–3 世纪） | 《月令》《吕氏春秋》《管子》 | **是——体系从这里才开始** |

### 甲骨文里的「虫家族」实测

| 字 | 甲骨文形态 | 本义 | 后来归入五虫哪一类 | 备注 |
|----|-----------|------|------------------|------|
| **虫** | 象蝮蛇昂首形（头三角、身卷曲） | **蝮蛇**（毒蛇） | 鳞虫 | 《说文》：「虫，一名蝮」——**「虫」的本义是蛇，不是泛称** |
| **龙** | 巨口有角、长身蜷尾的神兽形 | 神物/方国名 | 鳞虫之精 | 已是超越现实动物的想象物 |
| **凤** | 高冠长尾的鸟形，旁加「凡」声 | 凤鸟，**借作「风」** | 羽虫之精 | 卜辞中多用作「风」，神鸟与风神合一 |
| **龟** | 有正视、侧视两形，甲壳四足俱全 | 龟（占卜主角） | 介虫之精 | 甲骨文本身就是**写在龟甲上**——介虫是这套文字的载体 |
| 鱼／鸟／马／虎／象／鹿／犬／豕／牛羊 | 均为象形 | 现实动物 | 分入鳞、羽、毛 | 商代动物专名已极丰富 |

### 甲骨文的三个「没有」

1. **没有「五虫」合称，也没有任何五分类的痕迹**——甲骨文中动物按专名称呼，占卜按事类（田猎、祭祀、气候）分类，不按体表覆盖物分类。
2. **没有「麟」字**——「麟」字晚出，至西周金文方见（待考：字形出现与概念出现不一定同步）；商代只有「麐」类鹿形字的雏形争议。
3. **没有「倮/介」作为类名**——「介」在甲骨文指「甲衣/副贰」，「倮」字不见于卜辞。

### 金文（西周，前 1046–771 年）的过渡

| 进展 | 说明 |
|------|------|
| 龙、凤字形规范化 | 从图画走向符号 |
| 「麟」字出现 | 四灵名单逐步凑齐 |
| **分类意识仍未见** | 铭文记动物仍是专名罗列，无类别框架 |

### 春秋的关键一步（前 770–476 年）

- 《诗经·周南·麟之趾》：麟进入诗歌，带祥瑞义；
- 《礼记·礼运》首次凑齐「**麟凤龟龙，谓之四灵**」——**四灵先于五虫**。四灵是「祥瑞名单」，五虫是「分类体系」；西汉《大戴礼记》做的事，本质上是**把四灵名单嵌进五类框架，再给「人」补一个第五类的首领位**。

> **所以「最早只能追溯到甲骨文」的准确表述是**：
> **字能追到甲骨文（虫=蛇、龙、凤、龟都有），体系追不到——五虫作为「分类概念」的起点在战国月令，作为「完整定义」的起点在西汉《大戴礼记》。甲骨文提供的是零件，不是图纸。**

## 一、萌芽期：先秦——五虫只是物候标签

### 1.1 《礼记·月令》（战国，内容汇编至秦汉之际编入《礼记》）

月令系统的功能是按月份排布天子的行政与祭祀，其中按月标注「当季活跃的动物类别」：

| 季节 | 原文 | 虫类 | 五行 |
|------|------|------|------|
| 春（孟春、仲春、季春） | 「其虫鳞」 | 鳞（鱼龙属） | 木 |
| 夏 | 「其虫羽」 | 羽（鸟类） | 火 |
| 中央（季夏之末） | 「其虫倮」 | 倮（无毛羽鳞甲者，人在其中） | 土 |
| 秋 | 「其虫毛」 | 毛（兽类） | 金 |
| 冬 | 「其虫介」 | 介（龟鳖甲虫属） | 水 |

**特征**：此时五虫只是**历法配件**——什么季节什么虫「用事」，用来指导天子穿什么衣服、住什么方位的宫殿、行什么政令。没有等级，没有「精者」，人只是倮虫中的一种。

### 1.2 《吕氏春秋·十二纪》（秦，吕不韦门客编，前 239 年）

与《月令》同源同文（《月令》一般认为即取自《十二纪》），名目完全一致：鳞、羽、倮、毛、介。**这是先秦文献中五虫名目最完整的并行证据**——说明战国晚期这套分类已是通行常识，不是某一家私说。

### 1.3 《管子·幼官》等（战国齐国文献）

齐地系统的时令文献中亦有同构的「鳞、羽、倮（臝）、毛、介」配属，与《十二纪》相互印证：**五虫配对在战国时期是跨学派的公共知识**。

### 1.4 萌芽期小结

| 指标 | 状态 |
|------|------|
| 名目 | 鳞、羽、倮、毛、介（五项齐备） |
| 分类逻辑 | **物候/五行配属**（何时何类用事） |
| 有无等级 | 无 |
| 人的位置 | 倮虫之一，无特殊地位 |
| 是否叫「五虫」 | **否**——只逐项列出，未见「五虫」合称 |

> **萌芽期的关键判断**：先秦只有「五类虫的配属」，还没有「五虫」这个**概念名词**。概念的诞生需要等到有人给每一类找一个「首领」——那是西汉的事。

## 二、定型期：西汉——《大戴礼记》首次给出完整定义

### 2.1 首出文献：《大戴礼记·曾子天圆》

**这是五虫论可考的最早完整表述**，也是后世一切引用的源头。戴德（西汉宣帝时人，约前 1 世纪）辑其叔父戴圣所传礼学文献，编成《大戴礼记》；《曾子天圆》篇托名曾子与弟子单居离问答，内容反映战国末至汉初的儒家宇宙论。

原文（据四川大学古籍所整理本）：

> 「毛虫毛而后生，羽虫羽而后生，毛羽之虫，阳气之所生也；介虫介而后生，鳞虫鳞而后生，介鳞之虫，阴气之所生也；唯人为倮匈（胸）而后生也，阴阳之精也。**毛虫之精者曰麟，羽虫之精者曰凤，介虫之精者曰龟，鳞虫之精者曰龙，倮虫之精者曰圣人。**」

### 2.2 这段话做了三件先秦没做的事

| 创新 | 内容 | 后果 |
|------|------|------|
| **① 加等级** | 每类设一个「精者」：麟、凤、龟、龙、圣人 | 分类学变成等级制——「麟凤龟龙」四灵观念由此获得理论框架 |
| **② 提人入圣** | 人不再是倮虫之一，而是「倮虫之精」「阴阳之精」 | 人类中心主义正式写入分类体系 |
| **③ 配阴阳** | 毛羽属阳、介鳞属阴、人为阴阳之精 | 五虫被嵌入阴阳五行大系统，获得「宇宙论身份证」 |

### 2.3 《淮南子·墬形训》（前 139 年，淮南王刘安及其门客）

与《曾子天圆》几乎同时代，《淮南子》做了另一种系统化：**给每一类虫写「生成谱系」**。

| 虫类 | 《淮南子》谱系（各从其类，自神物降凡） |
|------|--------------------------------------|
| 羽 | 羽嘉生飞龙 → 凤凰 → 鸾鸟 → 庶鸟 |
| 毛 | 毛犊生应龙 → 建马 → 麒麟 → 庶兽 |
| 介 | 介潭生先龙 → 玄鼋 → 灵龟 → 庶龟 |
| 鳞 | 介鳞生蛟龙 → 鲲鲠 → 建邪 → 庶鱼 |
| 倮 | （煖湿生海人 → …… → 圣人 → 庶人，谱系文字各本有异文，待考） |

**意义**：《曾子天圆》给的是「横的等级」（每类一个精者），《淮南子》给的是「纵的谱系」（从始祖到凡品）。两套结构并行流传，**后世文献引用时经常混用**——这正是五虫论名目在流传中不断变形的结构性原因。

### 2.4 定型期小结

| 指标 | 状态 |
|------|------|
| 名目 | 毛、羽、介、鳞、倮（《大戴礼记》定本） |
| 分类逻辑 | 阴阳二分＋五行配属＋精者等级 |
| 人的位置 | **倮虫之精＝圣人**（体系的顶点） |
| 「五虫」合称 | 尚未固定出现，但五项定义完整，事实定型 |
| 代表文献 | 《大戴礼记·曾子天圆》《淮南子·墬形训》 |

## 三、扩散期：东汉——文字学与官方经学的双重固化

### 3.1 《说文解字》（许慎，约 100–121 年）

《说文》从**文字构造**层面把五虫钉进了字典：

> 「虫」部字按「鳞、介、毛、羽、倮」分类系联——许慎注「龙」曰「鳞虫之长」，注「凤」、注「麟」、注「龟」均沿用「某虫之长/之精」的框架。

**意义**：五虫从「礼学概念」变成「造字原则」——汉字里凡从虫、从鱼、从鸟、从犬的字，背后都默认这套分类。**一个概念一旦进入字典，就获得了远超任何单篇文献的存活率。**

### 3.2 《白虎通义》（班固等整理，79 年白虎观会议）

官方经学会议记录，将「麟凤龟龙」四灵与五虫框架纳入国家祭祀与符瑞体系——**五虫的「精者」从此有了官方认证**：出现麒麟是祥瑞，祥瑞是政治合法性的证据。分类学彻底政治学化。

### 3.3 《论衡》（王充，约 80 年代）

王充是东汉第一个**质疑者**：他在《龙虚》《讲瑞》等篇中追问「龙是否真为鳞虫之精」「麒麟是否真能验圣」，开了对五虫论的批判传统。**反面的意义同样重要：有人骂，说明它已经是常识。**

### 3.4 郑玄注经（127–200 年）

郑玄遍注三礼，注《月令》「其虫鳞/羽/倮/毛/介」时逐条落实名目，使先秦物候标签与西汉等级定义在注释中合流。**经学注释是概念最耐久的保鲜盒。**

## 四、宗教化：魏晋南北朝——道教的收编

### 4.1 郭璞注（276–324 年）

郭璞注《尔雅》《山海经》《穆天子传》，在注《尔雅·释虫》时沿用五虫框架解释虫鱼鸟兽的古名。**《尔雅·释虫》系统后经孔颖达等梳理，有「虫者，裸毛羽鳞介之总称」的总论性质表述**——五虫至此成为训诂学的默认背景。

### 4.2 《抱朴子》（葛洪，约 317 年前后）

道教首次大规模征用五虫框架：

- 把「成仙」表述为**跳出虫类范畴**——仙人不再是「倮虫之精」，而是超脱五虫之上；
- 讨论龙、龟、鹤等「精者」的寿命与变形能力，为服食修仙提供动物学依据。

**关键转折**：在儒家体系里，「倮虫之精＝圣人」是封顶；在道教体系里，圣人之上还要加一层「仙人」——**五虫的天花板被顶开了**。这个开口，正是八百年后《西游记》「五仙＋五虫」双轨制的远源。

### 4.3 南北朝：符瑞政治的高峰

南北朝各政权争献祥瑞（麟、凤、龟、龙频现于史书符瑞志），五虫的「精者」成为改朝换代的标准道具。概念在此阶段**完全工具化**——没人关心分类是否准确，只关心祥瑞归谁。

## 五、系统化：隋唐——类书与《五行大义》的整理

### 5.1 《五行大义》（萧吉，隋，约 600 年前后）

**五虫论的第一次学术总结。**萧吉把五虫与五行、五方、五色、五脏、五音全部打通，做成一张巨型对应表：

| 五行 | 木 | 火 | 土 | 金 | 水 |
|------|----|----|----|----|----|
| 五虫 | 鳞 | 羽 | 倮 | 毛 | 介 |
| 五方 | 东 | 南 | 中 | 西 | 北 |
| 五色 | 青 | 赤 | 黄 | 白 | 黑 |
| 五脏 | 肝 | 心 | 脾 | 肺 | 肾 |

**意义**：五虫从「礼学概念」「文字学背景」升级为**贯通天地人的知识总线**。后世医书、命书、风水书引用五虫，走的都是萧吉这条总线。

### 5.2 《艺文类聚》（欧阳询，唐，624 年）等类书

类书的编纂逻辑是「天地事物分类汇编」，五虫是现成的分类骨架——麟、凤、龟、龙各自成部，卷帙浩繁。**类书不改变概念，但极大地扩展了概念的检索入口。**

### 5.3 医学与数术的应用

- 《黄帝内经》系统的注家（如杨上善、王冰）在注解「五方之民」时引入五虫配五脏；
- 六壬、遁甲等数术文献以五虫定占卜类象。

## 六、沉淀期：宋元——类书保存与理学消化

| 文献 | 朝代 | 对五虫的处理 |
|------|------|-------------|
| 《太平御览》 | 北宋（977 年） | 大量收《大戴礼记》《淮南子》五虫原文，**成为宋以后文人检索五虫的第一入口** |
| 《册府元龟》 | 北宋（1013 年） | 符瑞部分沿五虫框架编排历代祥瑞记录 |

## 七、改造期：明代——《西游记》的三处手术

### 7.1 明代知识氛围

- 《三才图会》（王圻、王思义，1607 年成书）以**图像**呈现五虫——「裸虫」部赫然画着人，与鸟兽鱼虫同列；
- 《本草纲目》（李时珍，1578 年初刊）按「虫、鳞、介、禽、兽、人」分部，五虫框架直接进入药学；
- 民间宝卷、戏曲大量使用「五虫」作为宇宙秩序的口头禅。

**五虫在明代是「全民常识」级别的概念**——这正是吴承恩敢改它的底气：人人都知道原版，改动才有效。

### 7.2 《西游记》的三处改编（对照表）

| 项 | 古五虫（《大戴礼记》定本） | 《西游记》五虫 | 手术内容 |
|----|--------------------------|---------------|---------|
| 名目一 | **介**（龟鳖甲虫，其精为龟） | **昆**（昆虫/众虫） | **换类**：删介虫，增昆虫 |
| 名目写法 | **倮**（裸，无毛羽鳞甲，其精为圣人） | **蠃**（通假字，音义同「倮/裸」） | **换字**：本字换成通假字 |
| 体系顶点 | 倮虫之精＝**圣人**（人在体系内居顶） | 圣人**消失**；顶点换成「五仙：天地神人鬼」 | **换顶**：人退出虫类，升入仙类 |

### 7.3 每一处手术的原因（详见第十二节，此处先列骨架）

1. **介→昆**：麒麟、凤、龟、龙在明代已是皇室与祥瑞的专属符号，四灵等级森严且「政治敏感」；换成无精者、无等级、泛指众虫的「昆」，类目立刻失去神圣性——**四猴「不入十类」才有腾挪空间**。
2. **倮→蠃**：「倮/裸」的本义是「无遮蔽」，直指「人是裸虫」这个让明代读者尴尬的事实；「蠃」是通假字，字面疏离，**把人从虫类的视觉联想里摘出去**。
3. **删圣人**：古五虫的顶点是圣人——若保留，则「五虫」之内人最大，四猴「不入十类」就必须解释「它们和圣人比谁高」。**吴承恩直接把顶点换成五仙，把人整体搬出虫类，问题消失。**

> **一句话：《西游记》不是在引用五虫论，是在给五虫论做截肢手术——截掉的每一刀，都是为了给孙悟空们腾地方。**

## 七之补、五仙溯源：「天地神人鬼」从何而来

如来的原话是双轨制：「**有五仙，乃天地神人鬼；有五虫，乃蠃鳞毛羽昆**」。前文溯源了五虫，这里补齐五仙——**五仙不是《西游记》的发明，是道教仙阶系统的直接引用**。

### 五仙名目对照表（道教内部诸说）

| 系统 | 时代 | 文献 | 仙阶排序 | 与《西游记》关系 |
|------|------|------|---------|----------------|
| 六等说 | 东汉 | 《太平经》 | 神人→真人→仙人→道人→圣人→贤人 | 远源：以「等差」排仙的思路始于此 |
| 三等说 | 东晋 | 葛洪《抱朴子·论仙》 | **天仙**（举形升虚）→**地仙**（游于名山）→**尸解仙**（先死后蜕） | 天仙/地仙名目首出 |
| **五等说** | **唐末五代** | **《钟吕传道集》**（钟离权、吕洞宾一系） | **鬼仙→人仙→地仙→神仙→天仙** | **直接源头**——名目五项全同，仅排序相反 |
| 五等说定型 | 宋元 | 《云笈七签》、全真诸经 | 天仙→地仙→神仙→人仙→鬼仙 | 与《西游记》顺序一致 |

### 《钟吕传道集》的五仙定义（《西游记》的知识底本）

| 仙阶 | 定义（钟吕系） | 特征 |
|------|---------------|------|
| 鬼仙 | 阴中超脱，神像不明，鬼关无姓，三山无名 | 不悟大道，止于投胎夺舍——**仙中最低，近于不入流** |
| 人仙 | 修真之士得一法、止一病，安乐延年 | 肉体凡胎，仅得小成 |
| 地仙 | 长生住世，不死于人间 | 天地之中，炼形住世 |
| 神仙 | 地仙厌居尘世，功行圆满，身外有身 | 可入蓬莱三山 |
| 天仙 | 神仙传道人间，功行满足，受天书返洞天 | 仙阶顶点，列于天曹 |

**关键判断**：如来的「天地神人鬼」顺序（天仙→地仙→神仙→人仙→鬼仙）正是宋元以后定型的钟吕系排序，只是把名目压缩成单字。**吴承恩没有造五仙，他抄了道教的作业。**

### 双轨制的叙事功能：为什么五仙必须压在五虫上面

| 轨道 | 内容 | 管辖逻辑 |
|------|------|---------|
| 上轨：五仙 | 天地神人鬼 | 已脱生死的「体制内」存在 |
| 下轨：五虫 | 蠃鳞毛羽昆 | 还在生死里的「肉身存在」 |

- 五仙轨收编了道教全部仙阶话语——**等于宣布「你们修炼的终点都在我的分类里」**；
- 五虫轨收编了儒家两千年分类学——**肉身存在也全在网中**；
- 四猴「不入十类」——两轨铺满宇宙之后，唯一的缝隙被如来指出来，而**指出缝隙这个动作本身证明他站在缝隙之外**。

> 这就是[真假美猴王博弈全分析](真假美猴王博弈全分析.md)「定义权高于识别权」的知识考古学版本：如来不是比谛听看得更清，是**比所有人多拥有一层抽屉**。五仙五虫十个抽屉铺满，他说「这厮不在抽屉里」——于是第十一层（他自己）自动成立。

### 五仙五虫合璧总表

| 位次 | 上轨（仙） | 下轨（虫） | 《西游记》实例 |
|------|-----------|-----------|---------------|
| 1 | 天仙 | 蠃（倮） | 天仙：三清四御；蠃：人（已被抽空升入仙轨） |
| 2 | 地仙 | 鳞 | 地仙：镇元子（地仙之祖）；鳞：四海龙王 |
| 3 | 神仙 | 毛 | 神仙：蓬莱福禄寿；毛：青狮白鹿 |
| 4 | 人仙 | 羽 | 人仙：世间得道者；羽：大鹏、昴日星官 |
| 5 | 鬼仙 | 昆 | 鬼仙：山神土地之属；昆：蝎子、蜘蛛、蜈蚣 |
| **外** | **四猴混世** | —— | 灵明石猴、赤尻马猴、通臂猿猴、六耳猕猴 |

> **落点**：注意镇元子是「地仙之祖」却不在天庭编制——五仙轨内部也有「在册/在野」之分。这和五虫轨的「有主/无主」之妖（[全名录](西游记妖怪神仙凡人全名录.md) 的收编率分析）是同一个政治结构的两个投影。

**考据期的意义**：清代学者做的事与本文相同——**溯源**。他们的结论（五虫定型于《大戴礼记》，倮为圣人本字）至今仍是标准答案。

### 页码问题的方法论说明（为什么不直接给页码）

本系列[自我证伪文档](西游系列自我证伪文档.md)的原则是「不伪造精确度」。古籍引用领域有一个基本事实：

1. **页码是版本属性，不是文献属性**——同一篇《曾子天圆》，在汇校集解本、补注本、四库本里的页码完全不同；同一版本的第 1 次与第 3 次印刷页码也可能不同。
2. **古籍引用的稳定坐标是「书名·卷次·篇名」**——这是从《汉书·艺文志》到 GB/T 7714 附录都承认的惯例。本表所有条目已给出卷·篇坐标，任何版本都能据此定位。
3. **逐条页码的可核查路径**：① 中华书局「中华经典古籍库」按书检索原文即显示版本页码；② 中国哲学书电子化计划（ctext.org）可免费核对《礼记》《吕氏春秋》《淮南子》原文段落；③ 读秀/全国图书馆参考咨询联盟可查整理本页码。
4. **待核清单**（诚实标注）：[5] 五虫引文页码、[6] 底本来源、[8] 册数、[9] 节名次第、[10] 分册页码、[12] 章节页码——以上六项标「待核」者，在亲见版本前不应被引用为精确依据。

### 时间线排列逻辑的三条说明

1. **为什么①②在③之前**：字（甲骨文）和名单（四灵）都先于体系——**先有零件，再有名单，最后才有图纸**（与「零之补」的三层追溯结论一致）。
2. **为什么③–⑦挤在战国**：月令系统是「捆绑销售」——五行、五方、五色、五季与五虫名目在**同一份文献里同时出现**，无法分出先后，故并列同段。
3. **为什么⑪横跨汉至隋唐**：五脏配属不是某本书的发明，而是医家、数术家、类书编纂者**几百年逐步对齐**的结果——这类「渐成维度」是溯源中最易误判为单点首出的陷阱，故单独标注置信度「中」。

### 三条横向读数

1. **不动的三格**：鳞、羽、毛——这三类的精者（龙、凤、麟）在明代是皇权符号，动不得。**不动的都是政治的。**
2. **动的两格**：倮（涉及「人是什么」）与介（涉及「龟的灵位」）——动的都是**哲学上和礼制上可以牺牲的**。
3. **讽刺的落点**：被改成「昆」（众虫、杂虫）的那一栏，恰恰是《西游记》里产出妖精最密的类目（蝎子、蜘蛛、蜈蚣）——**类目被降格之日，就是它在小说里泛滥之时**。

## 十一、名目演化链：一字一变的两千年

```
【先秦】  其虫鳞 / 其虫羽 / 其虫倮 / 其虫毛 / 其虫介     ← 物候标签，无等级
              │
【西汉】  毛·羽·介·鳞·倮 ＋ 麟·凤·龟·龙·圣人（五精）     ← 定型：加等级、提圣人
              │
【东汉】  写入《说文》与符瑞体系                          ← 固化：进字典、进国典
              │
【六朝】  道教征用：圣人之上加仙人                        ← 顶开天花板
              │
【隋唐】  《五行大义》全维度打通                          ← 变成知识总线
              │
【宋元】  类书收录，理学消化                              ← 沉淀为背景
              │
【明代】  蠃·鳞·毛·羽·昆（《西游记》58回）                ← 手术：换类、换字、换顶
              │   （介→昆；倮→蠃；删圣人，增五仙）
              │
【清代】  段玉裁等回证「倮」为本字                        ← 考据还原
              │
【现代】  神话学/分类学比较研究                           ← 变成学术对象
```

**两次大变，一次在书外，一次在书内：**

- 西汉那次（加等级、提圣人），是**儒家的政治需要**——要给祥瑞和圣人一个宇宙论位置；
- 明代那次（换类、删圣人），是**小说的叙事需要**——要给四只猴子一个「十类之外」的位置。

## 十二、《西游记》为什么必须改古五虫

这是全篇溯源的落点。回到第五十八回的逻辑现场：

### 12.1 如果吴承恩直接引用古五虫，会出什么 bug

如来要说服观音（和读者）的是一句话：**「六耳猕猴不在任何已知类目里，所以你们都认不出来，只有我认得。」**

但若引用原版「毛羽介鳞倮」：

| 原版类目 | 四猴是否可塞入 | 后果 |
|---------|---------------|------|
| 毛虫（兽类，其精为麟） | **猴子显然属毛虫** | 六耳立刻被归类，「不入十类」不成立 |
| 倮虫（其精为圣人） | 人形猴身，边缘案例 | 引发「猴算不算人」的无穷争论 |
| 圣人居顶点 | 四猴与圣人孰高？ | 叙事焦点被哲学问题劫持 |

### 12.2 三处手术如何逐一拆雷

1. **介→昆**：把「有明确精者（龟）的神圣类目」换成「无精者、无等级、泛指一切小虫的杂类」。昆者，众也——**它是个「其他」筐**。有了这个筐，如来列举五虫时就可以说「四猴连筐都不入」。
2. **倮→蠃**：断绝「人＝裸虫」的字面联想，**避免观音追问「那人形算什么」**。
3. **五仙压五虫**：「天地神人鬼」五仙在上、「蠃鳞毛羽昆」五虫在下，人升入仙类。十类并立，四猴「不入十类」——**如来用两层分类给四猴造了一个「法外之地」，而这个法外之地恰恰是他的终审权的边界**。

### 12.3 与本系列的勾连

这套「改造分类体系以容纳例外」的操作，与[真假美猴王博弈全分析](真假美猴王博弈全分析.md)第九章的结论同构：**如来的权力不在于识别六耳（谛听也能识别），而在于定义「六耳是什么类目」**——定义权高于识别权。五虫论的三处改编，就是这份定义权在**分类学层面**的预演：先用双轨十类把宇宙铺满，再宣布四猴在铺满的宇宙之外，最后宣布「只有我看得见宇宙之外」。
