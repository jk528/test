## 一、衣：穿什么，就是什么

### 1.1 全书最贵的一件衣服

第12回，观音化身老僧在长安卖宝贝，明码标价：

> 「袈裟**五千两**，锡杖**二千两**。」——合计**七千两白银**。

对照第11回：相良夫妇卖水积攒的善钱（约五十两上下）就够盖一座相国寺。**一件袈裟 ≈ 百座寺院的地基钱**。唐王代买赠玄奘——全书的"衣"从第一天起就是权力赠与的记号。

### 1.2 服饰等级表

| 等级 | 穿着者 | 服饰 | 来源 |
|------|--------|------|------|
| 佛门至宝 | 唐僧 | 锦襕袈裟、毗卢帽、白布小衫 | 唐王所赠（观音处流转） |
| 王权 | 各国国王 | 冲天冠、赭黄袍、无忧履 | 各回通例 |
| 官僚 | 丞相/太师/驿丞 | 乌纱、罗襕、角带 | 各国朝廷 |
| 富室 | 员外/地主 | 绫罗绸缎 | 高老庄、陈家庄、寇员外家 |
| 平民 | 农夫/樵夫/渔翁 | 粗布短衣、蒲鞋 | 全书通例 |
| 僧人 | 普通僧众 | 直裰、僧帽（被车迟国没收袈裟） | 各寺院 |
| 异类 | 悟空 | 虎皮裙＋布直裰（第14回自缝） | **兽皮改衣——从妖到人的第一道手续** |
| 异类 | 八戒 | 青缎衫 | 高家定制（招婿时期的"人籍证明"） |
| 妖怪 | 大多数妖王 | 兽皮/树叶或盗来的人间衣冠 | 盘丝洞裸形、玉兔"假公主"凤冠 |

### 1.3 三个关键数据

1. **金池长老藏袈裟七八百件**（第16回），活了270岁，最后为一件不是自己的袈裟烧死自己——**衣服是全书第一张"贪婪试纸"**。
2. **悟空的虎皮裙是他自己动手做的**（第14回剥虎皮、裁裙腰）——取经团里唯一一件"自产服装"，与袈裟（赠予）、青缎衫（定制）形成三种穿衣逻辑。
3. **妖要穿衣才算"人物"**：黑熊精开"佛衣会"、金池长老 obsessed 袈裟、玉兔精必须穿上公主的凤冠霞帔——**妖对人间衣服的执念，就是对人间身份的执念**（与六耳"借位"完全同构）。

|------|------|---------|----------------|

| 蟠桃·六千年熟 | 同上 | 同上 | 「霞举飞升，长生不老」 |
| 蟠桃·九千年熟 | 同上 | 同上 | 「与天地齐寿，日月同庚」 |
| 金丹 | 太上老君 | 看炉童子/有缘者 | 成仙（悟空偷吃一葫芦） |
| 人参果 | 镇元子（地仙之祖） | 万年只结**三十个**，五庄观独有 | 「闻一闻活**三百六十岁**，吃一个活**四万七千年**」 |

> **关键洞察**：所有长生资源都在体制内（天庭、老君、地仙之祖），**唯独唐僧肉是"无主的公共传说"**——这就是为什么妖怪前赴后继：体制内的吃不着，只好吃路过的。

### 2.2 唐僧的餐桌：素斋标准清单

取经十四年，师徒吃的斋饭高度一致（第54、68、96 回筵席菜单可互校）：

```
米面主食：香稻米饭、白面馍馍、卷子、面条
豆制品：豆腐、面筋、豆腐皮
山珍：木耳、蘑菇、香菇、黄花菜
蔬菜：笋干、萝卜、山药、芋头、芹菜、菠菜
油料：香油、椒料
茶果：胡麻、蔓菁、黄精、果品
```

**全书凡人待客的最高规格＝素斋满桌＋跪接＋留宿**——唐僧团队走到哪里，哪里的"民间消费天花板"就被刷新。

### 2.3 食量数据

| 人物 | 食量 | 出处 |
|------|------|------|
| 八戒 | 「一顿要吃三五斗米饭，早间点心也得百十个烧饼」 | 第18回高才报告 |
| 八戒（吃人参果） | 囫囵吞，没尝出味 | 第24回 |
| 悟空 | 铜丸铁汁皆可（八卦炉底子） | 第7回 |

> 八戒的饭量是全职数据——他的"食"从来不是需求，是**身份残留**（天蓬元帅的神胃口＋猪的肉身）。

### 2.4 一个反差

- 车迟国灭佛时期：僧人「沿门乞食，又被人殴打」（第44回）；
- 寇员外家：见僧就斋，「万僧圆满」敲锣打鼓。
**同一个职业，在两个国家的饭桌上，一个是过街老鼠，一个是功德指标**——吃饭这件事，从来由国王的信仰决定。

**洞府和名分一样：你在时是你的，你不在时谁强是谁的**——与"位与权"定律完全一致。

## 四、行：十万八千里，平均每天二十一里

### 4.1 核心数据

| 指标 | 数值 | 计算 |
|------|------|------|
| 全程 | 十万八千里 | 原文定数（恰等于筋斗云一跳） |
| 耗时 | 十四年（贞观十三年→二十七年） | 第100回太宗亲口 |
| **平均速度** | **约 21 里/天** | 108000 ÷ (14×365) |
| 对照：凡人步速 | 约 50–80 里/天 | 唐代行旅常识 |
| 筋斗云 | 一步十万八千里 | 悟空一日可达灵山 |
| **速度差** | **约 5000 倍** | 悟空带飞 vs 骑马 |

> **最重要的行路数据**：取经团的实际行进速度只有凡人步速的 1/3——**十四年里，"在路上"的时间不足三成，其余全在打妖怪、被囚、遭灾、讲经、治病**。
> 「十万八千」与「一筋斗」同数的深意正在这里：**灵山一念即至，走的路是用来消磨你的念的。**

## 五、生老病死：还魂五案，全是关系户

### 5.1 生

| 出生方式 | 案例 | 数据 |

| 正常繁衍 | 凡人 | 通例 |
| **河水怀孕** | 子母河水（女儿国） | 男人也会怀；**解阳山落胎泉可解**——全书唯一的"生育医药学" |
| 修行仍为婴形 | 红孩儿 | 三百年修行，永葆婴儿体 |
| 转世 | 唐僧（金蝉子十世） | **十世修行，前九世都死在流沙河** |

**沙僧项挂九颗骷髅**（第22回）：那九个骷髅「惟有九个取经人的骷髅浮在水面，再不能沉」——**唐僧的前九世，是被沙僧吃掉的**。过流沙河后九骷髅化作九股阴风散去。这是"生"里最黑的一页：**取经人的十世履历里，九世是渡河的学费。**

### 5.2 老

| 存在 | 寿命 | 口径 |
|------|------|------|
| 凡人 | 「人生七十古来稀」 | 崔珏判词「注定贞观一十三年」也可改 |

### 5.3 病

- 全书真正的"病人"只有两个：**朱紫国王**（相思＋惊恐成疾三年，第69回悬丝诊脉）与**乌鸡国王**（已死三年，病灶是"井水寒气"）。
- 唐僧师徒**全程无病**——取经团的"病"全部由妖怪扮演（妖怪就是他们的病原体）。
- 唯一"药"的清单：乌金丹（悟空配的，主料锅灰＋马尿）、九转还魂丹（老君）、落胎泉水、定风丹。

### 5.4 死：还魂五案

| 案例 | 死因 | 还魂方式 | 靠的是什么 |
|------|------|---------|-----------|
| 唐太宗（第11回） | 魂游地府超期 | 崔珏**私改生死簿**（添二十年） | 魏征的**关系**（崔珏是旧交） |
| 李玉莲（第11回） | 顶缸自尽 | 借唐御妹之躯**还魂** | 丈夫刘全**代差进瓜**的公务便利 |
| 陈光蕊（第9回附录） | 被刘洪推江 | 洪江龙王**保尸十八年**并还魂 | 十八年前**放生金鲤**的善缘 |
| 乌鸡国王（第39回） | 落井三年 | 老君**九转还魂丹** | 悟空**讨来的药**＋井龙王保尸 |
| 寇员外（第97回） | 被盗贼踢死 | 地藏王放回＋**加寿一纪（12年）** | 唐僧团队**求情**＋本人「斋僧一万」功德 |

> **规律**：五个还魂案例，**没有一个是走正常程序**——全部依赖：旧交（崔珏）、公务（刘全进瓜）、善缘（放生）、神药（老君）、求情（悟空）。
> **生死簿是给没关系的鬼看的。**

### 5.5 生死簿与幽冥行政

- 十代冥王＋判官＋地藏：地府是全书**行政化最彻底**的部门（排班、簿册、勾魂、超度一条龙）；
- 但从太宗私改、悟空勾销（销了整个猴类户口）、六耳「不入十类之种」到五起还魂——**地府是全书被打招呼次数最多的衙门**。
- 泾河龙王案是反面教材：只**改了一个时辰、克了三寸八点雨**就上剐龙台——**体制内编制的纪律最严，体制外的还魂全是后门**。（泾河龙王：有编制，所以死得最标准。）

## 六、阶级：三界金字塔与跨层压迫

### 6.1 三界阶级金字塔

```
        如来 / 玉帝                     （定义权层：说什么是什么）
      菩萨 / 老君 / 星君 / 天尊          （资源层：坐骑、金丹、长生）
    罗汉 / 揭谛 / 天兵 / 龙王           （执行层：跑腿、下雨、看守）
  —— 天界基层：山神 / 土地 / 城隍 ——    （全书写实的底层公务员）
  —— 妖界：妖王 —— 先锋 —— 小妖 ——     （山寨建制，暴力定级）
  —— 人界：皇帝 — 官僚 — 员外 — 平民 — 仆役 — 强盗 —
```

### 6.2 跨层压迫案例（全书最扎心的数据区）

| 案例 | 压迫方向 | 数据 |
|------|---------|------|
| 红孩儿奴役山神土地（第40回） | 妖 → 神界基层 | 「烧火顶门，黑夜与他巡逻」，土地被剥得「褴褛衣衫」 |
| 车迟国苦役僧（第44回） | 人王＋妖 → 僧 | 五百僧人做苦工，死去大半，「悬梁自尽的也有」 |
| 比丘国药引（第78回） | 人王＋妖 → 儿童 | 一千一百一十一个小儿心肝，民称「小子城」 |
| 凤仙郡连坐（第87回） | 天 → 全郡百姓 | 郡侯推倒斋供喂狗 → 三年不雨，全郡饿殍 |
| 金平府收油（第91回） | 妖(假佛) → 商民 | 三只犀牛假扮佛像，年年元宵收**酥合香油** |
| 泾河龙王案（第9回） | 天条 → 编制龙 | 克扣降雨三寸八点 → 剐龙台问斩 |

> **规律**：压迫的方向几乎全是**向下的跨界压迫**——妖可以奴役神的基层（红孩儿）、人王可以牺牲子民（比丘国）、天可以连坐全郡（凤仙郡）。
> 而反抗几乎不存在：土地山神忍着、僧人自杀、百姓搬家。**底层唯一的对策是熬，直到取经团路过。**

### 6.3 阶级流动的唯一通道：取经编队
