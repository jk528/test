## 二、核心判据：一句话说清"能不能执行"

判断某档最低工资能否强制执行的**唯一标准**是：

> **是否存在一份写明了"施行日期"的正式政府文件。**

- 2330 元：有省政府正式文件（川府规〔2024〕4 号）+ 成都市级落地文件，具备强制执行力。
- 2500 元：仅处于"征求意见"阶段，属于拟定方案，尚未走完法定程序，**不能作为执行依据**。

因此，2500 元"5 月没执行"**不是"该执行而未执行"，而是"法定程序尚未走完"**——它还不具备执行资格。

## 三、完整法定程序总览

依据《重大行政决策程序暂行条例》，重大行政决策须经**五大法定程序**：

```
公众参与 → 专家论证 → 风险评估 → 合法性审查 → 集体讨论决定
```

最低工资调整叠加《最低工资规定》的专属环节后，完整链条为：

```
因素测算 → 拟定方案(三方机制) → 公众参与(公开征求意见)
   → 专家论证 → 风险评估 → 合法性审查(司法行政部门)
   → 集体讨论决定(政府常务会议)★ → 正式印发(载明施行日期)
   → 报人社部备案 → 官方公布 → 成都市级落地通知
   → 执行 / 补足差额

★ = 集体讨论决定；正式印发才是"执行力分水岭"：
    此前为"方案"，此后为"法定依据"
```

**阶段划分**

| 阶段 | 环节 | 产出 |
|---|---|---|
| 0 测算启动 | 因素测算、拟定方案（人社+工会+企联三方） | 调整方案草案 |
| 1 公众参与 | 公开征求意见（约 30 天） | 征求意见汇总 |
| 2 审查风控 | 专家论证、风险评估 | 论证报告、风险评估报告 |
| 3 审查 | 合法性审查（省司法厅） | 合法性审查意见书 |
| 4 决策 | 集体讨论决定（省政府常务会议） | 会议决议 |
| 5 签发 | 正式印发（写明施行日期）、省长签发 | 政府正式文件 |
| 6 备案公布 | 报人社部备案、官方公布 | 备案回执、公告 |
| 7 市级落地 | 成都转发/发布执行通知 | 市级执行通知 |
| 8 执行 | 执行、补差与劳动监察 | 落地执行 |

## 四、法定程序逐项详解

### 4.1 公众参与（公开征求意见）

**定位**：法定五大程序首环，是公众、企业、工会表达意见的窗口期。

**要点**
- 形式：向社会公开《征求意见稿》，公示期通常约 30 天。
- 渠道：政府网站、新闻发布、书面信函、座谈会等。
- 产出：意见汇总与采纳情况说明。
- **此阶段文件名称必带"征求意见"字样，不具备任何执行力。**

**2500 元状态**：✅ 2026-05-09 四川省人社厅发布《最低工资标准调整方案（征求意见稿）》。

---

### 4.2 专家论证

**定位**：法定五大程序的第二环，位于"公开征求意见"之后、"合法性审查"之前；**论证未通过则方案退回修改**，不得进入下一环节。

**1. 组织方式**
- **主体**：由省人社厅组织；可委托第三方机构、科研院所或专业智库执行。
- **形式**：以论证会为主，辅以书面征询、专题研讨。
- **时限**：通常 1–4 周。

**2. 专家构成（典型）**
- 劳动关系 / 劳动经济学者
- 社会保障、统计测算专家
- 法律专家
- 行业代表、企业联合会与工会方（三方机制延伸）
- 通常 7–15 人，需具备相应资质与独立性

**3. 提交论证的材料**
- 2500 元调整方案（含数额、适用范围、拟施行时间）
- 测算报告：最低生活费用、城镇居民人均可支配收入、职工平均工资、社保缴费、就业状况
- 与现行 2330 / 2200 元的对比分析
- 对企业用工成本的初步测算

**4. 论证核心内容**
1. **必要性**：物价、平均工资、生活成本的变动是否支持上调
2. **幅度合理性**：2500 元与经济增长、劳动生产率、企业承受力是否匹配
3. **分档合理性**：区域档次划分（第一档 / 第二档）是否恰当
4. **测算方法科学性**：《最低工资规定》附件的两种方法——
   - *比重法*：以城镇居民人均生活费用支出为基础推算
   - *恩格尔系数法*：最低食物支出 ÷ 恩格尔系数
   - 参考国际通行区间（最低工资约为社会平均工资的 40%–60%）
5. **实施可行性**：企业承受力抽样、对低技能就业的影响

**5. 产出与作用**
- 出具《专家论证意见书 / 论证报告》，含**专家名单、逐条意见、是否通过的结论**。
- **未通过即退回修改**，不得进入合法性审查。
- 属提交政府常务会议审议的必备材料之一。

**6. 2500 元方案当前状态**

| 项目 | 状态 |
|---|---|
| 专家论证 | ⬜ 待进行 |
| 关联影响 | 若论证认为幅度超出企业承受力，可能被要求**下调或分期实施** |

### 4.3 风险评估

**定位**：即"社会稳定风险评估"，与专家论证并列的法定前置程序；**高风险未化解不得提交决策**。

**1. 组织方式**
- **主体**：省人社厅（评估主体），可自行评估或委托第三方专业机构。
- **方式**：问卷调查、企业走访、座谈会、数据分析、舆情监测、历史调整复盘。

**2. 评估维度**

| 维度 | 关注点 |
|---|---|
| 经济风险 | 企业用工成本上升幅度、小微企业压力、裁员风险 |
| 就业风险 | 对低技能劳动岗位需求的影响 |
| 社会风险 | 劳动者诉求、群体性事件触发可能、舆情走向 |
| 政策联动风险 | 加班费基数、社保缴费基数、失业保险金等**与最低工资挂钩**项目的连锁上浮 |
| 财政风险 | 社保支出、财政补贴相应增加 |

**3. 等级判定与处理**
- 分**高 / 中 / 低**三级。
- **高风险**：须调整方案或配套出台缓释措施（过渡期、分年实施、小微企业帮扶）。
- **中低风险**：附加监测与应急预案后继续推进。

**4. 产出与作用**
- 出具《社会稳定风险评估报告》，含**风险等级结论与化解措施清单**。
- 作为政府常务会议审议的前置条件；**缺失或等级过高会直接卡住流程**。

**5. 2500 元方案当前状态**

| 项目 | 状态 |
|---|---|
| 风险评估 | ⬜ 待进行 |
| 关联影响 | 若评为高风险，需先出台配套措施，会**推迟正式印发时间** |

---

### 4.4 合法性审查

**定位**：法定五大程序的第四环，位于"专家论证、风险评估"之后、"集体讨论决定"之前。依《重大行政决策程序暂行条例》第 25–27 条，决策草案未经合法性审查或审查不合法的，**不得提交会议讨论**。

**1. 审查主体**
- 由决策机关（省政府）的司法行政部门承担，即**省司法厅（政府法制机构）**。
- 审查主体独立于起草部门（省人社厅），起"刹车"作用。

**2. 送审材料**
- 决策草案（2500 元方案）及草案说明
- **程序履行情况说明**：公众参与、专家论证、风险评估的完成凭证
- 相关法律、法规、规章及政策依据
- 其他必要材料（测算报告、三方机制意见等）

**3. 审查四项内容**

| 维度 | 审查要点 |
|---|---|
| 权限合法 | 是否属本级政府法定职权——最低工资标准依《劳动法》第 48 条、《最低工资规定》确由**省级人民政府**规定，权限吻合 ✅ |
| 程序合法 | 公众参与、专家论证、风险评估是否已**如实完成**，不得缺项 |
| 内容合法 | 是否与《劳动法》《最低工资规定》及上位法冲突，是否低于国家规定的底线 |
| 协调性 | 与现行地方性法规、规章、其他政策是否协调，有无冲突 |

**4. 产出与效力**
- 出具《合法性审查意见书》，结论为"**合法**"或"需修改"。
- 时限：各地不等，一般数个工作日至两周；材料不全可退回补正（补正期不计入）。
- 结论"不合法 / 需修改"：**退回省人社厅修改后重审**，直至通过。
- 通过后取得"通行证"，方可进入集体讨论。

**5. 2500 元方案当前状态**

| 项目 | 状态 |
|---|---|
| 合法性审查 | ⬜ 待进行 |
| 关联影响 | 若发现程序缺项或内容冲突，**退回重审会明显拖延** |

### 4.5 集体讨论决定

**定位**：法定五大程序的最后一步，决策的**实质决定环节**。依《重大行政决策程序暂行条例》第 28–30 条，决策草案须经决策机关**常务会议或全体会议**讨论，由行政首长在集体讨论基础上作出决定。

**1. 会议形式与人员**
- **形式**：省政府常务会议（省长主持，副省长、秘书长等组成）或省政府全体会议；最低工资调整通常上常务会议。
- **列席汇报**：省人社厅负责人到会说明方案。
- **上会材料包**：决策草案 + 合法性审查意见书 + 专家论证报告 + 风险评估报告 + 三方机制意见。

**2. 审议程序（发言顺序有法定要求）**
1. 省人社厅汇报方案要点与前期程序完成情况
2. **其他与会成员先依次发表意见**（分管副省长、相关部门等）
3. **行政首长（省长）最后发表意见**并作出决定
4. 若首长拟作决定与多数成员意见**不一致**，须**在会上说明理由**
5. 如实记录：会议纪要载明讨论情况与**不同意见**

**3. 表决与结果**

| 结果 | 后续 |
|---|---|
| 通过 | 进入正式印发程序 |
| 要求修改 | 退回人社厅按会议意见修改，必要时重走审查 |
| 否决 / 暂缓 | 方案搁置，维持 2330 / 2200 |

**4. 会后签发与发文**
- 依会议决议形成正式政府文件（如"川府规〔20XX〕X 号"或省政府办公厅文），**由省长签发**。
- 文件必须**写明施行日期**——这是"执行力分水岭"。
- 随后：报人力资源社会保障部备案 → 官方公布 → 成都市级落地通知 → 执行 / 补足差额。

| 集体讨论决定 | ⬜ 待进行 |
| 关联影响 | 若会议"要求修改"，**2500 元幅度本身可能被下调** |

## 七、详细推演（基于 2330 元的历史节奏反推）

> 以下为**推论**，非官方结论。

### 推论 1：时间窗口（反推法）
- 参照样本：2330 元从征求意见（2024-05-22）到正式执行（2025-01-01）约 **7 个月**。
- 2500 元起点：2026-05-09。
- **推算**：约 7 个月后，即 **2026 年 12 月前后**可能正式印发 / 生效。
- 已有讨论提及"拟自 **2026-12-01** 起执行"，与上述推算窗口吻合，但仍属拟议，未获正式文件确证。

### 推论 2：三种情景

| 情景 | 触发条件 | 结果 |
|---|---|---|
| A. 如期落地 | 论证 / 评估 / 审查 / 审议顺利，12 月前完成签发 | 2026-12 前后生效，成都追溯执行 |
| B. 延后落地 | 论证提出新证据、风险评估评为高风险、合法性审查退回、审议要求修改 | 顺延至 2027 年初生效 |
| C. 暂不调整 | 经济下行压力、企业承受力评估不通过 | 维持 2330/2200，方案暂缓 |

### 推论 3：关键卡点环节
"征求意见"与"合法性审查"之间（即专家论证 + 风险评估）是**主要耗时点**，也是 2500 元方案能否如期落地的**最大不确定性来源**：
- 论证不通过 → 幅度可能被要求下调或分期实施；
- 风险评估为高风险 → 需先出台配套措施，直接推迟正式印发。

### 推论 4：市级滞后与补差
若省级文件在 12 月生效、而成都市级通知晚发（如 2330 元的先例），则：
- 执行时点**追溯至省级施行日**；
- 施行日至落地日之间按旧标准支付的工资，需**补足差额**；
- 因此"文件何时生效"比"通知何时到手"更关键。

### 推论 5：能否直接"按 2500 元执行"的判断法则
在任何时点，用下列三问自检：
1. 是否有一份**写明施行日期**的正式（非"征求意见"）文件？—— 无，则不能执行。
2. 该文件的施行日期是否已到？—— 未到，则仍按旧标准。
3. 成都市级通知是否已到？—— 未到但省级已生效，则应按省级标准执行并追补差额。

## 八、核心结论

1. **2500 元没有在 5 月执行，不是"应执行而未执行"，而是法定程序尚未走完。**
2. 判断能否执行的唯一标准：**是否发布了写明"施行日期"的正式政府文件。**
3. 在正式文件发布前，成都仍执行 **2330 元 / 2200 元**（小时标准 23 / 22 元）。
4. 2500 元方案当前处于"公众参与"之后、**专家论证 / 风险评估 / 合法性审查 / 集体讨论决定尚未完成**的状态。
5. 按历史节奏推算，2500 元**可能于 2026 年 12 月前后**生效，但最终以四川省政府正式文件为准。
6. 若省级文件生效后成都市级通知晚发，通常**追溯执行并补发差额**，需关注公示与企业补差义务。
