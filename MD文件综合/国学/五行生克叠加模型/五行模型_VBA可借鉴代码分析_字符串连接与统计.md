## 二、重点一：字符串连接与「连续字符串」

### 2.1 你提到的现象：12345 和 23451 都是连续字符串

用 `Function_连接字符串` 模块的函数解释这个现象：

```vba
连接([1,2,3,4,5], "")  → "12345"     ' Join 拼接
连接([2,3,4,5,1], "")  → "23451"

是否连续序列([1,2,3,4,5])  → True      ' 1..5 无重复、无缺失
是否连续序列([2,3,4,5,1])  → True
```

`是否连续序列` 的判定逻辑（模块里已有）：
> 1-based 下，每个值都在 [1,n] 且 `max-min = n-1`（去重后长度 = n）

所以 **12345 和 23451 都是「1..5 的一个排列」**（连续序列），只是起点不同。这正是五行模型中「同一基序的不同旋转」：

| 字符串 | 五行对应 |
|---|---|
| 01234 | 生链，旋转 c=0 |
| 12340 | 生链，旋转 c=1 |
| 23401 | 生链，旋转 c=2 |
| 34012 | 生链，旋转 c=3 |
| 40123 | 生链，旋转 c=4 |

> 注意：五行用 0..4 编号，所以是 "01234" 而非 "12345"；若用 1..5 编号则对应你说的 12345。

### 2.2 可直接复用的函数

| 函数 | 作用 | 五行中的用途 |
|---|---|---|
| `连接(arr, sep)` | 数组 → 字符串 | 把层排列、差序列签名转成**字符串键**（Dictionary 的 key） |
| `是否连续序列(arr)` | 检测是否为 1..n 排列 | 检测一个候选排列是否是**合法的层**（覆盖所有节点、无重复） |
| `环形相邻计数(arr)` | 环形相邻对计数 | 检测层是否为**单一均匀环**（与生链参考圈的共享边数） |
| `环形相邻判定数组(arr)` | 返回每对是否相邻 | 可视化层的环形结构 |
| `相邻差统计(arr)` | 差值频率统计 | 分析签名的差序列分布 |
| `取重(arr)` / `连续数组(n)` | 去重 / 生成连续序列 | 辅助工具 |

### 2.3 需要扩展的：循环移位归一化（现有代码没有）

**关键发现**：现有代码能把 12345 和 23451 都识别为「连续序列」，但**没有函数能把它们归并为同一个**。而五行模型恰恰需要这个——折叠旋转 c 参数，把 20 层压缩成 4 基序。

**扩展方法**（基于 `连接` + 字符串操作）：取字符串所有循环移位中字典序最小者作为标准型。

```
Canonical("12345") = min("12345","23451","34512","45123","51234") = "12345"
Canonical("23451") = min(...) = "12345"   ← 归并成功
```

脚本验证（n=5）：

```
归一化后基序数: 4  (= φ(n)=4)
  [01234] <- 01234, 12340, 23401, 34012, 40123      ← 生(k=1)的5个旋转
  [02413] <- 02413, 13024, 24130, 30241, 41302      ← 克(k=2)
  [03142] <- 03142, 14203, 20314, 31420, 42031      ← 克逆(k=3)
  [04321] <- 04321, 10432, 21043, 32104, 43210      ← 生逆(k=4)
```

> 这正好把 20 层折叠为 4 基序，与 φ(5)=4 吻合。`连接` 提供了字符串化基础，循环移位归一化是在其上的自然扩展。

## 三、重点二：统计逻辑（STAT_001 是标杆模板）

### 3.1 STAT_001 的标准统计流水线

`STAT_001_全组合环形相邻词频` 建立了一套**可直接套用**的统计模式，分四步：

```
① 生成所有对象  →  ② 对每个对象计算特征  →  ③ Dictionary 计数  →  ④ 排序输出
   (Heap 全排列)      (环形相邻计数)          (词频累加)           (计数/次数/占比)
```

对应代码：

```vba
' ①+②+③：Heap 排列 + 回调累加（边生成边统计，不存全部排列，省内存）
Private Sub 全排列_HeapCallBack(nums, freq, totalCount)
    ...
    Call ProcessOnePerm(nums, freq, totalCount)   ' 每个排列回调一次
    ...
End Sub

Private Sub ProcessOnePerm(arr, freq, totalCount)
    cnt = 环形相邻计数_数组(arr)                   ' ② 计算特征
    If freq.Exists(cnt) Then freq(cnt) = freq(cnt)+1 Else freq.Add cnt, 1  ' ③ 计数
    totalCount = totalCount + 1
End Sub

' ④：字典 → 排序二维数组（计数、次数、占比）
Private Function DictToSortedArray(freq, totalCount, outputCols)
    keys = freq.Keys: 排序 keys
    result(r,1) = keys(i)            ' 特征值
    result(r,2) = freq(keys(i))      ' 出现次数
    result(r,3) = freq(keys(i))/totalCount   ' 占比
End Function
```

### 3.2 这套流水线如何套用到五行

把「对象」和「特征」换成五行的概念，整条流水线直接复用：

| 步骤 | STAT_001（环形词频） | 五行（签名统计） |
|---|---|---|
| ① 生成对象 | Heap 生成 1..N 全排列（N! 个） | 枚举两层组合（20×20=400 个） |
| ② 计算特征 | 环形相邻计数（0..N） | 差序列签名（如 "00000"、"01234"） |
| ③ Dictionary 计数 | freq[cnt]++ | freq[signature]++ |
| ④ 排序输出 | 计数值/次数/占比 | 签名/次数/态分类 |
| 批量对比 | N=1..MaxN 横向对比表 | n=3..11 横向对比表 |

脚本验证五行签名统计（n=5）：

```
两层 400 种 → 去重签名 25 种
签名    次数
00000   20      ← 齐同态（全同）
11111   20      ← 齐同态
22222   20
33333   20
44444   20      ← 齐同态共 5 种，各 20 次
01234   15      ← 齐备态
02413   15
...（共 20 种齐备态，各 15 次）
```

> 这正是思路推导里「400 → 25 签名」的数据来源。`STAT_001` 的 Dictionary 统计模式可以直接产出这张表。

### 3.3 STAT_004 可借鉴的深度统计指标

`STAT_004_数据分析` 在 STAT_001 的频率表之上，又加了一层**统计指标计算**，这些函数也值得搬用：

- 均值 E[k]、方差、标准差
- 众数（出现次数最多的特征值）
- 对称性验证（频率分布是否左右对称）
- 满分 / 零分排列的规律抽取（最大值、最小值的性质）
- TOP 频率特征值
- 期望随 N 的变化趋势

套用到五行：可以分析「签名长度分布」「齐同/齐备/普通态的占比随 n 的变化」「镜像折叠不动点数」等。

### 3.4 公式推导文档的图论视角（值得借鉴的思路）

`STAT_环形相邻词频_公式推导.md` 把统计问题翻译成图论：

> 环形相邻计数 = 排列对应的 Hamilton 圈与固定参考圈 C_N 共享的边数。T(N,k) = 共享 k 条边的有向 Hamilton 圈数。

这个视角对五行很有启发：
- 五行的「一层」也是一个 Hamilton 圈（单一 n-环）
- 可以定义「一层与生链参考圈共享的边数」作为特征
- 例如 n=5 时，生链 01234 与参考圈共享 5 条边（完全重合），克链 02413 共享 0 条边，非仿射排列 01243 共享 3 条边

脚本验证：
```
01234(生,k=1)  环形相邻计数 = 5   ← 满分（与生链完全重合）
02413(克,k=2)  环形相邻计数 = 0   ← 零分（无重合边）
01243(非仿射)  环形相邻计数 = 3   ← 中间值
```

## 六、结论

**最值得借鉴的两个文件**：

1. **`Function_连接字符串.bas`** —— 回答了「12345/23451 都是连续字符串」：用 `连接` 字符串化、用 `是否连续序列` 判定合法排列。但它**缺少循环移位归一化**，这是五行折叠旋转 c 参数的关键缺口，需要在其上扩展（取旋转的字典序最小标准型）。

2. **`STAT_001_全组合环形相邻词频.bas`** —— 提供了「**生成对象 → 计算特征 → Dictionary 计数 → 排序输出**」的标准统计流水线，连批量对比、写表美化都齐了。把对象换成「两层组合」、特征换成「差序列签名」，就能直接产出五行的 400→25 签名统计表。

> 一句话：`连接字符串` 负责「把排列变成可比较的字符串」，`STAT_001` 负责「对字符串特征做词频统计」——两者合起来，正好覆盖五行模型从层生成到签名计数的全流程，中间只差一个「循环移位归一化」的小扩展。
