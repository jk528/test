## 一、PC_002：一个 2×2 的组合模式分类器

### 1.1 四类模式总览

PC_002 把「从 m 个元素里取 n 个」切成四类，沿两个正交维度：

- **维度 A**：组合(combin) vs 排列(permut) —— 是否「去镜像」（顺序是否敏感）
- **维度 B**：不放回 vs 放回 —— 元素能否重复使用

| | 不放回（元素不重复） | 放回（元素可重复） |
|---|---|---|
| **组合**（去镜像，顺序无关） | `combin_arr1` = **C(m,n)** | `combin_arr_repet` = **C(m+n−1,n)** |
| **排列**（不去镜像，顺序敏感） | `permut_no_repet` = **P(m,n)** | `permut_repet` = **mⁿ** |

> 「去镜像」是模块注释里的关键词：组合类通过索引约束让 AB 和 BA 视为同一个；排列类不约束顺序，AB ≠ BA。

举例 m=3（元素 A B C）, n=2：

| 模式 | 结果（部分） | 数量 |
|---|---|---|
| 组合不放回 | AB, AC, BC | C(3,2)=3 |
| 组合放回 | AA, AB, AC, BB, BC, CC | C(4,2)=6 |
| 排列不放回 | AB, BA, AC, CA, BC, CB | P(3,2)=6 |
| 排列放回 | AA, AB, AC, BA, BB, BC, CA, CB, CC | 3²=9 |

### 1.2 四类算法的核心：全在「索引约束」

四类的代码骨架几乎一样（取索引 → 映射元素 → 存结果），唯一区别是**索引怎么生成**。这是整个模块最精妙的设计：

#### ① combin_arr1（不放回组合）— 递归，索引严格递增

```vba
Private Sub GenComb_NoRepet(Arr, m, n, startIdx, depth, res(), result(), outIndex)
    If depth > n Then 记录 res; Exit Sub
    maxI = m - (n - depth)          ' 上界剪枝：保证后面还剩足够元素
    For i = startIdx To maxI
        res(depth) = Arr(i)
        GenComb_NoRepet Arr, m, n, i + 1, depth + 1, ...   ' 下一个从 i+1 开始
    Next i
End Sub
```

- **严格递增** startIdx → i+1 ⟹ 元素不重复
- 递增顺序 ⟹ AB 只出现一次（不会再有 BA）= **去镜像**
- `maxI = m - (n - depth)` 是关键剪枝，避免走到后面不够选

#### ② combin_arr_repet（放回组合）— 迭代，索引非递减

```vba
idx(1..n) = 1
Do:
    记录 Arr(idx(1..n))
    p = n
    Do While p >= 1
        If idx(p) < m Then
            idx(p) = idx(p) + 1
            For i = p+1 To n: idx(i) = idx(p)   ' 进位后右边全部拉平
            Exit Do
        Else: p = p - 1
    Loop
    If p = 0 Then done
Loop
```

- **非递减** idx(p+1..n) = idx(p) ⟹ 元素可重复（AA 合法）
- 仍保持顺序 ⟹ AB 只出现一次 = **去镜像**
- 这是「stars and bars」定理 C(m+n−1,n) 的枚举实现

#### ③ permut_no_repet（不放回排列）— 递归 + used 标记

```vba
Private Sub SolverPermNoRepet(Arr, m, n, used(), res(), depth, result(), R)
    If depth > n Then 记录 res; Exit Sub
    For i = 1 To m
        If Not used(i) Then
            used(i) = True:  res(depth) = Arr(i)
            SolverPermNoRepet ... depth+1 ...
            used(i) = False                          ' 回溯
        End If
    Next i
End Sub
```

- `used` 标记 ⟹ 元素不重复
- **无索引大小约束** ⟹ 顺序敏感，AB 和 BA 都出现 = **不去镜像**

#### ④ permut_repet（放回排列）— 迭代，m 进制计数器（odometer）

```vba
idx(1..n) = 1
Do:
    记录 Arr(idx(1..n))
    i = n
    Do While i >= 1
        If idx(i) < m Then idx(i) = idx(i) + 1: Exit Do
        Else idx(i) = 1: i = i - 1       ' 满 m 进位归 1
    Loop
    If i = 0 Then done
Loop
```

- 每位独立 1..m，满 m 进位 ⟹ 可重复 + 顺序敏感
- 这就是**混合进制计数**，与《四方镜子》备选算法 A（进位计数法）和四方循环的 `源行 = ys(cd(行,步长),行数)` 完全同构（见《通用化框架》文档）。

### 1.3 工程设计亮点

| 设计 | 作用 |
|---|---|
| 统一返回「一维嵌套数组」（每项长度 n、1 基） | 四类函数输出结构一致，下游可统一处理 |
| `TransposeNestedTo2D` | 嵌套数组 → 二维数组，一次性块写表 |
| `CombinationDD` / `PermCount` 用 Double | 安全算 C(n,r)、P(m,n)，避免中间溢出 |
| `Clone1D` 深拷贝 | 避免 VBA 数组别名引用导致结果被覆盖 |
| `自测_组合排列_自动验证` | 期望公式 vs 实际数量 + 边界用例（n=0、n>m、空数组） |

## 二、PC_004：全排列 + 索引映射

### 2.1 核心算法：交换回溯（Solver）

```vba
Private Function Solver(Arr(), m, brr())
    n = UBound(Arr)
    If m < n Then
        Solver Arr, m + 1, brr                    ' ① 当前位不动，递归
        For i = m + 1 To n
            t = Arr(m): Arr(m) = Arr(i): Arr(i) = t   ' ② 交换当前位与第 i 位
            Solver Arr, m + 1, brr                    ' ③ 递归
            t = Arr(m): Arr(m) = Arr(i): Arr(i) = t   ' ④ 换回（回溯）
        Next i
    Else
        k = k + 1: 记录 Arr 到 brr(k)             ' 叶节点 = 一个完整排列
    End If
End Function
```

**原理**：对位置 m，要么不动、要么与后面任意位置交换，两种情况都递归到 m+1。叶节点（m=n）就是一个排列。这是经典的**原地交换全排列**，生成恰好 n! 个，无重复无遗漏。

**比 PC_002 的 `permut_no_repet` 更高效**：PC_002 用 `used()` 布尔数组标记，每次递归要扫描 1..m；PC_004 用原地交换，无需标记数组，空间更省、常数更小。

### 2.2 「映射」的含义：索引映射双输出

`TestPermutations2D` 是理解这个模块的关键。它生成**两张并排的表**：

```
元素排列（左）          索引排列（右）
A B C                  1 2 3
A C B                  1 3 2
B A C                  2 1 3
...                    ...
```

- 左：用户选的实际元素（如 A B C）的全排列
- 右：`[1, 2, 3, ..., n]` 的全排列

两者**逐行同构**：每个元素排列唯一对应一个索引排列。本质是——

> **全排列 = 「位置 → 元素」的双射。把元素换成位置索引，就看清了映射结构本身。**

这就是「映射全排列」命名的由来：不仅给出元素的重排，还给出这个重排对应的**位置置换**。

### 2.3 辅助结构

| 函数 | 作用 |
|---|---|
| `GetArrayDimension` | 探测数组维度（试 UBound 出错即止） |
| `FlattenArrayRowMajor` / `ColumnMajor` | 2D → 1D 扁平化（行/列优先） |
| `Factorial` | 算 n!，预分配结果数组 `ReDim resultArray(1 To n!, 1 To n)` |
| `CalculatePermutations` | 主封装：维度检测 → 扁平化 → 调 Solver → 返回 2D |

## 三、PC_002 与 PC_004 的关系

| 维度 | PC_002 | PC_004 |
|---|---|---|
| 覆盖范围 | 四类（组合/排列 × 放回/不放回），m 选 n | 仅全排列（m=n 的不放回排列） |
| 算法 | `permut_no_repet` 用 used 递归 | 原地交换回溯（更高效） |
| 输出 | 一维嵌套数组 | 二维数组（直接可写表） |
| 特色 | 模式分类 + 自测框架 | **索引映射双输出** + 2D 扁平化输入 |
| 关系 | PC_004 是 PC_002 中 `permut_no_repet(Arr, n)` 的**特例 + 增强** | 反之，PC_004 的全排列是 PC_002 的一个顶点 |

一句话：**PC_002 是「广谱」的组合工具箱，PC_004 是「专深」的全排列 + 映射可视化。**

## 四、打通到五行模型（脚本已验证）

这是两个模块与五行研究的真正连接点。核心验证（n=5）：

```
PC_004 生成全排列: 5! = 120 个（所有「位置→元素」双射）
   │
   ├─ 筛选「仿射置换」: 存在 k(与5互质), c 使 p[i] = (k·i + c) mod 5
   │     → 命中 20 个  ← 这就是五行的层（4 基序 × 5 旋转）
   │
   └─ 舍弃 100 个非仿射排列（如 0 1 2 4 3，不是均匀单一 5-环）
```

### 4.1 计数对照表

| PC_002 / PC_004 的对象 | 公式 / 数量 | 五行模型对应 |
|---|---|---|
| PC_004 全排列 | 5! = **120** | 5 节点所有「位置→元素」双射 |
| 筛选仿射子集 | φ(5)×5 = **20** | 五行的层空间（生/克/克逆/生逆 × 5 旋转） |
| `permut_repet`(20层, 2) | 20² = **400** | 两层有序组合 |
| `combin_arr1`(20层, 2) | C(20,2) = **190** | 两层无序组合 |
| `permut_no_repet`(20层, 2) | P(20,2) = **380** | 两层有序不重复 |
| `permut_repet`(20层, m) | 20ᵐ | m 层有序选法（可重复） |
| 差序列归一化 | **25** | 独特签名 |
| 反转等价类 | **13** | 镜像折叠后 |
| 并集闭包（非 PC_002 直接对应） | 8 层收敛 / **52,521** | m 层独特画面 |

### 4.2 索引映射视角对五行的启示

PC_004「元素排列 vs 索引排列」的双输出，恰好揭示了五行的数学本质：

- **一层 L = 一个映射**：位置 i → 元素 L(i)。全排列 120 = 所有可能的双射；五行只取其中的仿射双射（k·i+c），因为只有仿射双射才是「均匀的单一 5-环」（生链、克链都能一笔画走完所有节点）。
- **两层的签名 = 两个映射的差**：d(i) = L_b(i) − L_a(i) = A·i + B mod 5，仍是一个仿射映射（见思路推导 §7）。
- **舍弃 100 个排列的原因**：如 `0 1 2 4 3`，检查是否存在 k,c：p[0]=0 → c=0；p[1]=1 → k=1；但 p[3] 应为 3 却等于 4，不满足 k·i+c。它是一个置换，但不是均匀环——无法作为「一层」叠加（会出现局部交换，破坏环形结构）。

### 4.3 PC_002 四类模式如何「覆盖」五行的各层次

如果要把五行模型完全用 PC_002 的语言重述：

```
1. 生成层空间: 先 permut_no_repet(5元素, 5) 得 120 全排列
              → 再筛选仿射 → 20 层   [这一步 PC_002 没有，需自定义筛选]
2. 两层有序组合: permut_repet(20层, 2) = 400
3. 两层去重签名: 对 400 个差序列做归一化（自定义，非 PC_002）
4. 镜像折叠: 对签名做反转等价类（自定义，非 PC_002）
5. m 层选法: permut_repet(20层, m) = 20^m
6. m 层画面: 对选法做并集 + 去重 + 闭包（自定义，非 PC_002）
```

**结论**：PC_002 提供了「选哪些层、选多少层」的组合枚举（步骤 2、5），但**筛选仿射层、签名归一化、反转折叠、并集闭包**这四步是五行模型特有的，需要在 PC_002 之上自定义扩展——这正是《五行叠加 n 演示范例》要做的事。

## 五、总结

| 模块 | 核心价值 | 对五行的作用 |
|---|---|---|
| **PC_002** | 四类组合模式的完整分类 + 索引约束统一实现 | 提供两层/m 层「选层组合」的计数与枚举工具 |
| **PC_004** | 高效全排列 + 索引映射双输出 | 揭示「一层 = 位置→元素的双射」，五行取其中仿射子群（120 → 20） |
| **两者合起来** | 从 120 个双射到 20 个仿射层，再到 400/190/20ᵐ 组合 | 五行模型的组合计数骨架全部能在这两个模块里找到对应 |

> **一句话**：PC_004 生成全部 120 种「位置→元素」映射，五行从中挑出 20 个均匀的仿射环作为「层」；PC_002 的四类模式则负责回答「从这 20 层里选 2 层 / m 层有多少种选法」。两个 VBA 模块合起来，构成了五行生克叠加模型的组合数学底座。
