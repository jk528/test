## 一、从 VBA 代码提炼的三种基本组合模式

四方镜子 v12 虽然功能很多（四方循环、双边循环、四象限、备选算法 A–G），但剥掉 UI 外壳，底层只有**三种正交的组合模式**。理解这三种，就理解了所有排列组合 / 循环组合问题的骨架。

### 1.1 模式一：笛卡尔积（全组合，混合进制计数）

**VBA 出处**：`四方循环_执行`（scct），备选算法 A 进位计数、B 回溯法、E 逐列扩展——这四种算法输出完全相同，都是笛卡尔积。

**核心公式**（四方循环）：
```vba
步长(1) = 1
步长(列) = 步长(列-1) * 每列行数(列-1)          ' 正向：左快右慢
源行 = ys( cd(行, 步长(列)), 每列行数(列) )      ' 混合进制解码
```
其中：
- `cd(c,d) = RoundUp(c/d)` = **商**（向上取整）
- `ys(n,Y) = ((n+Y-1) Mod Y)+1` = **1-based 安全模**（环形索引，恒正）

**本质**：每列是一个「数字位」，进制 = 该列行数。把线性行号 `行` 按混合进制**解码**成各列的索引。总组合数 = `数组乘积(每列行数)` = ∏ 各维度大小。

```
行号 →  商 cd(行,步长)  →  模 ys(商,进制)  →  该列取第几个元素
        (是第几个"块")      (块内位置)
```

**特点**：覆盖所有组合，无遗漏无重复；各维度**完全独立**。

### 1.2 模式二：LCM 独立循环（环形组合）

**VBA 出处**：`双边循环_执行`（zxgbs），备选算法 C 自定义周期。

**核心公式**：
```vba
最小公倍数 = WorksheetFunction.Lcm(每列行数)
源行 = ys(行, 每列行数(列))        ' 每列独立取模，互不干扰
```

**本质**：每列按自己的周期独立循环，行数 = LCM(所有周期)。当各列周期两两互质时，LCM = 乘积 = 完整覆盖（四方镜子标记为「完整」）；否则 LCM < 乘积，部分组合不出现（标记为「残缺」）。

**与模式一的区别**：
| | 笛卡尔积 | LCM 循环 |
|---|---|---|
| 总数 | ∏ 各维度大小 | LCM(各维度) |
| 列间关系 | 完全独立（嵌套） | 各自独立并行 |
| 互质时 | = LCM | = ∏（两者相等） |
| 不互质时 | 全覆盖 | 残缺（部分组合缺失） |

### 1.3 模式三：镜像反转（对称生成）

**VBA 出处**：`四象限_执行`，变换表 `[identity, R, E, RE]`。

**核心**：在已生成的组合矩阵上做三种反转：
- **R**（Row 反转）：组合顺序颠倒 → 上下镜像
- **E**（Element 反转）：每组合内元素顺序颠倒 → 左右镜像
- **RE**：双反转 → 中心镜像

**本质**：不产生新组合，只对已有结果做**对称变换**，生成等价类的代表。这正是「折叠 / 归一化」的前置操作。

## 二、把五行模型映射到这三种模式

五行模型看起来是另一个领域（生克、叠加、签名），但它的每一个构件都能精确对应到上述三种模式。这就是「通用化」的关键——**五行不是特例，而是这套组合框架的一个参数实例**。

### 2.1 一层 = 模式一（笛卡尔积）：k 维度 × c 维度

五行中「一层」是一个排列 `L(i) = (k·i + c) mod n`，由两个参数决定：
- **k**（步长 / 基序方向）：必须与 n 互质，共 **φ(n)** 个 → 对应「生 / 克 / 克逆 / 生逆」
- **c**（旋转偏移）：0..n−1，共 **n** 个 → 对应 5 个旋转

**层的生成就是 k 维度 × c 维度的笛卡尔积**：

```
每层排法 = φ(n) × n        ← 四方镜子的 数组乘积(每列行数)
```

| n | φ(n)（k 维度大小） | n（c 维度大小） | 每层排法 = φ(n)×n |
|---|---|---|---|
| 3 | 2 | 3 | 6 |
| 4 | 2 | 4 | 8 |
| **5** | **4** | **5** | **20** |
| 6 | 2 | 6 | 12 |
| 7 | 6 | 7 | 42 |

**与四方镜子的同构验证**：把层按线性序号 idx 编号，用四方镜子的混合进制解码：

```
k = ks[ cd(idx, n) ]     ← 商 → 第几个 k（基序方向）
c = ys(idx, n)           ← 余 → 旋转偏移
```

脚本实测 n=5（见下），idx 0–4 → k=1（生），5–9 → k=2（克），10–14 → k=3（克逆），15–19 → k=4（生逆），与 `源行 = ys(cd(行,步长), 行数)` 完全同构：

```
idx | k | c | 层排列 L(i)=(k·i+c) mod 5
 0  | 1 | 0 | 0 1 2 3 4   ← 生正
 5  | 2 | 0 | 0 2 4 1 3   ← 克正
10  | 3 | 0 | 0 3 1 4 2   ← 克逆
15  | 4 | 0 | 0 4 3 2 1   ← 生逆
```

> **结论**：五行的「4 基序 × 5 旋转 = 20 层」不是什么神秘结构，就是笛卡尔积在 n=5 时的取值。换成任意 n，把 φ(n) 代进去即可。

### 2.2 一层的内部结构 = 模式二（LCM 循环）

层排列 `L(i) = (k·i + c) mod n` 本身就是**两个循环的复合**：

- 位置 i 从 0 循环到 n−1（周期 n）
- 值按步长 k 跳跃：L(i+1) = L(i) + k (mod n)

这正是四方镜子 `双边循环` 的逻辑——`源行 = ys(行, 周期)`。当 k 与 n 互质时，这个循环恰好走完所有 n 个节点（单一 n-环）；当 gcd(k,n) > 1 时，循环分裂成多个小环（对应四方镜子的「残缺」）。

| gcd(k,n) | 循环行为 | 四方镜子对应 |
|---|---|---|
| = 1 | 单一 n-环，走完所有节点 | 「完整」（LCM = 乘积） |
| > 1 | 分裂成 gcd 个环 | 「残缺」（LCM < 乘积） |

**这就是为什么层要求 k 与 n 互质**——只有互质才能保证一层是「一条首尾相接走完所有节点的链」，否则链断成几截（见思路推导 §3.5）。

### 2.3 两层签名 = 仿射循环序列

固定上层 (kₐ, cₐ)、下层 (k_b, c_b)，每个位置 i 的关系差：

```
d_i = (L_b(i) − L_a(i)) mod n
    = ((k_b − k_a)·i + (c_b − c_a)) mod n
    = A·i + B  mod n        ← 关于 i 的仿射函数
```

其中 A = k_b − k_a，B = c_b − c_a。**签名序列 (d₀, d₁, …, d_{n-1}) 就是一个步长为 A 的循环序列**——又回到模式二的 `ys(i, n)` 结构。

- 当 A 与 n 互质（⟺ n 为奇数时可能成立）：d_i 遍历 0..n−1 各一次 → **齐备态**
- 当 A = 0：d_i 恒为 B → **齐同态**
- 其余：部分重复 → **普通态**

### 2.4 多层叠加 = 并集闭包（模式三的推广）

m 层叠加的画面 = m 个层的边集的**并集**（按位或）。这不再是笛卡尔积或循环，而是集合的并运算：

```
画面 = 层₁ ∪ 层₂ ∪ … ∪ 层ₘ       （边集按位或）
```

由于或运算的交换律、幂等律，选层顺序和重复都不影响画面 → 大量选法坍缩。用四方镜子的语言，这是对层集合做「并集闭包」：

```
S₀ = {∅}
S_m = { s ∪ 层 : s ∈ S_{m-1} }     ← 增量闭包（见思路推导 §3.6.6）
```

n=5 时到 m=8 闭包收敛，共 52,521 种独特画面。

### 2.5 镜像折叠 = 模式三（R/E 反转）

思路推导里的「镜像折叠」（交换上下层 → 生↔被生、克↔被克），本质就是四方镜子的 **R 反转**：把组合序列倒过来。Burnside 引理计算不动点，就是在数「反转后等于自身」的签名数。

| 四方镜子 | 五行模型 |
|---|---|
| R 反转（组合顺序颠倒） | 交换上下层（生↔被生、克↔被克） |
| identity / R / E / RE 四象限 | 同 / 生 / 克及其逆的对称分类 |
| 折叠后等价类数 | 25 签名 → 13 类（100 模型 → 8 类） |

## 三、通用 n 的完整逻辑链

把上面的映射串起来，得到一条从「参数 n」到「全部结论」的完整流水线，每一步都对应一个 VBA 组合模式：

```
给定 n
  │
  ├─ [模式一·笛卡尔积]  层空间 = φ(n) × n = n·φ(n) 种层
  │                       └─ 解码: idx → (k=ks[cd(idx,n)], c=ys(idx,n))
  │
  ├─ [模式二·LCM循环]  每层 L(i)=(k·i+c) mod n 是单一 n-环 ⟺ gcd(k,n)=1
  │                       └─ k 取与 n 互质的数（φ(n) 个）→ 保证环完整
  │
  ├─ [两层组合]  两层有序组合 = (n·φ(n))² 种
  │     │
  │     └─ [模式二·循环序列]  签名 d_i = A·i+B mod n
  │            ├─ A 与 n 互质 → 齐备态（n 奇时存在）
  │            ├─ A = 0 → 齐同态（恒 n 种）
  │            └─ 其余 → 普通态
  │
  ├─ [模式三·反转]  镜像折叠（交换上下层）→ 等价类（Burnside）
  │
  └─ [多层叠加]  并集闭包 S_m = {s ∪ 层} → 收敛于某层，穷尽所有画面
```

### 3.1 n 的取值如何影响每一步

| 步骤 | 质数 n | 奇合数 n | 偶合数 n |
|---|---|---|---|
| 层空间 n·φ(n) | n(n−1) 最大 | n·φ(n) | n·φ(n)（φ 缩水） |
| 每层是否单环 | k=1..n−1 全单环 | 部分 k 分裂 | 部分 k 分裂 |
| 齐备态（A 与 n 互质） | ✅ 存在 | ✅ 存在 | ❌ A 恒偶，永不存在 |
| 关系类型折叠类 | (n+1)/2 | (n+1)/2 | n/2+1（多 1 自逆类） |
| n=5 的特殊性 | — | 关系类恰好 3 = 同+生+克 | — |

### 3.2 一句话通用化

> 任意 n 的五行式模型 = **φ(n) 个基序方向 × n 个旋转**的笛卡尔积生成层，每层是步长互质的单一 n-环（LCM 循环），两层差为仿射循环序列（决定齐同/齐备），多层做并集闭包穷尽画面，镜像用反转折叠等价类。**n=5 是这条流水线上「关系类型恰好 3 类、结构恰好饱满」的参数点。**

## 四、VBA 代码对照：哪些函数可直接复用

如果要把《五行叠加 n 演示范例》改造成更通用的引擎，四方镜子里这些函数可以直接搬用：

| 四方镜子函数 | 作用 | 五行模型中的对应 |
|---|---|---|
| `ys(n,Y)` = 1-based 安全模 | 环形索引 | `ModN(x,n)`（已在 WX 里实现，0-based 版） |
| `cd(c,d)` = RoundUp 商 | 混合进制解码的商位 | `idx \ n` 取 k 的索引 |
| `数组乘积(arr)` | ∏ 各维度大小 | 每层排法 `φ(n) * n`、组合数 `(nφ)²` |
| `WorksheetFunction.Lcm` | LCM | 判断层是否单环（gcd=1 ⟺ 环完整） |
| `生成scct结果` | 笛卡尔积生成 | `BuildLayers` 生成所有层 |
| 备选算法 A 进位计数 | 混合进制枚举 | 枚举所有 (k,c) 层组合 |
| 备选算法 B 回溯 DFS | 递归生成组合 | 枚举多层叠加组合 |
| 四象限 `变换表[R/E/RE]` | 反转生成对称 | 镜像折叠、签名归一化 |

**两个模块的函数其实是同一套数学**：
- 四方镜子 `ys(n,Y) = ((n+Y-1) Mod Y)+1`
- 五行 `ModN(x,n) = ((x Mod n)+n) Mod n`

两者都是「安全模运算（结果恒在合法范围）」，只是 1-based 与 0-based 的区别。这说明**两个看似无关的 VBA 项目，底层是同一套组合数学引擎**。

## 五、总结

| 抽象层次 | 四方镜子 VBA | 五行模型 | 通用 n |
|---|---|---|---|
| 元素空间生成 | 笛卡尔积 ∏ | 4 基序 × 5 旋转 = 20 | φ(n) × n |
| 单元素内部结构 | LCM 循环 | 单一 5-环（生/克链） | 单一 n-环（gcd=1） |
| 两元素关系 | — | 差序列 → 签名 | 仿射循环 A·i+B |
| 对称归一化 | R/E/RE 反转 | 镜像折叠 | 反转等价类 |
| 多元素聚合 | — | 并集叠加 → 画面 | 并集闭包收敛 |

**五行模型不是孤立的玄学构造，而是「笛卡尔积生成层 + 循环保证单环 + 差序列签名 + 并集闭包穷尽画面 + 反转折叠对称」这套通用组合框架的 n=5 实例。** 把 n 换成 3、7、9……同一套流水线自动产出对应结论，这正是「五行延伸到通用」的逻辑本质。
