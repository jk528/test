## 二、HarmonyOS 应用开发文档

文档中心（https://developer.huawei.com/consumer/cn/doc/）下的核心板块：

- **应用开发导读**：通过 HarmonyOS SDK 开放能力完成应用开发的指引
- **版本说明**：HarmonyOS 各版本变更与特性
- **API 参考**：ArkTS / 系统能力 API 文档
- **应用框架 / 系统 / 媒体 / 图形 / 应用服务 / AI**：按能力域分类的开发指南
- **元服务**：元服务（原子化服务）开发专题
- **应用测试**：单元测试、集成测试与专项测试
- **最佳实践 / 行业实践**：场景化方案与行业解决方案
- **FAQ**：常见问题
