## 九、从零开始学鸿蒙：完整学习路径

适用人群：无编程经验或转方向开发者。鸿蒙应用主力开发语言是 **ArkTS**（在 TypeScript 基础上扩展声明式 UI、状态管理等能力），UI 框架为 **ArkUI**。整体路径：

```text
阶段0 编程语言基础 → 阶段1 入门课程 → 阶段2 ArkUI 声明式开发
→ 阶段3 应用开发核心能力 → 阶段4 实战 → 阶段5 认证与上架
```

### 阶段 0：编程语言基础（判断、循环、函数等）

ArkTS 的基础语法与 TypeScript 几乎一致，先补齐 TS 通用语法即可平滑过渡：

- **必学清单**：变量声明（let / const）、数据类型（number / string / boolean / 数组 / 对象）、运算符、
  **条件判断（if / else if / else、switch）**、**循环（for、while、for...of、forEach）**、
  函数（声明、参数、返回值、箭头函数）、类与接口（class / interface / extends / implements）、
  模块化（import / export）、空值处理（? / !）、异步编程（Promise、async / await）
- 学习资源：
  - [鸿蒙应用开发零基础入门：从工具到语言](https://developer.huawei.com/consumer/cn/blog/topic/03199500520473102)（官方博客，含语法示例）
  - [学习 ArkTS 语言（官方教程）](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/learning-arkts)
  - [TypeScript 官方手册](https://www.typescriptlang.org/docs/)（英文，查语法用）

### 阶段 1：官方入门课程（免费）

- [HarmonyOS 第一课](https://developer.huawei.com/consumer/cn/training/study-path/101667550095504391)：5阶段 33课 约53小时，覆盖 ArkTS 语法 → 简单页面 → 应用构建
- [华为云学堂 · 鸿蒙应用开发学习路径](https://edu.huaweicloud.cn/programs/hongmeng.html)：3阶段 10门课，含在线实验
- 同步准备：[注册开发者账号](https://developer.huawei.com/consumer/cn/) + [安装 DevEco Studio](https://developer.huawei.com/consumer/cn/deveco-studio/)，跟随"快速入门"跑通第一个 Hello World

### 阶段 2：ArkUI 声明式开发（核心基本功）

- **页面开发四要素**：@Entry、@Component、struct、build()
- **基础组件**：Text、Button、Image、TextInput 等；**容器**：Column、Row、Stack、List、Grid、Tabs
- **状态管理装饰器**：@State、@Prop、@Link、@Provide / @Consume、@Observed、@Watch
- **渲染控制**（语法层面的"判断与循环"在 UI 中的体现）：
  - 条件渲染：if / else
  - 循环渲染：ForEach、LazyForEach（长列表）
- **页面跳转**：Navigation、Router
- 文档入口：[ArkUI 开发框架概述](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-ui-development-overview)
- 配套课程：[鸿蒙应用开发实战课](https://developer.huawei.com/consumer/cn/training/study-path/201770621937867778)（ArkUI 语法 + 预览器实操）

### 阶段 3：应用开发核心能力

- **应用模型**：Stage 模型、UIAbility 生命周期、应用上下文 Context
- **数据**：用户首选项、关系型数据库（RelationalStore）、应用沙箱文件读写
- **网络**：HTTP 请求、Web 组件
- **系统能力**：权限申请、通知、后台任务、媒体（音视频/相机）、位置
- **元服务**：轻量级原子化服务开发（可选方向）
- 以上均在[文档中心](https://developer.huawei.com/consumer/cn/doc/)"应用框架 / 系统 / 媒体 / 应用服务"等板块有对应开发指南与 API 参考

### 阶段 4：动手实战

- [Codelabs 官方实验](https://developer.huawei.com/consumer/cn/codelabsPortal/)（按场景分步实操）
- [官方示例代码工程](https://developer.huawei.com/consumer/cn/samples/)
- 练手建议：待办清单 App（练 ForEach + 状态管理 + 数据持久化）→ 新闻客户端（练网络请求 + 列表 + 路由）→ 综合项目

### 阶段 5：测试、认证与上架

- 应用测试（单元/集成/专项）：[文档中心](https://developer.huawei.com/consumer/cn/doc/)"应用测试"板块
- 考取 [HarmonyOS 应用开发者基础认证](https://developer.huawei.com/consumer/cn/training/dev-cert-detail/101666948302721398) → 高级认证
- 通过 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/marketplace/index.html) 上架分发

### 节奏建议

| 阶段 | 内容 | 建议投入 |
|---|---|---|
| 0 | TS/ArkTS 语法（判断、循环、函数、类、异步） | 1–2 周 |
| 1–2 | 官方入门课 + ArkUI 组件与状态管理 | 2–4 周 |
| 3 | 应用模型、数据、网络等核心能力 | 2–3 周 |
| 4 | Codelabs + 自主小项目 | 持续进行 |
| 5 | 认证考试 + 上架流程 | 按需 |
