# 小说切入点全类型枚举

> 覆盖范围：7 大类、37 个细分类型，每个类型给出 4~6 个可执行的切入点选项。
> 用法：先看第 1 节确定切入点的五种基本型，再看第 2 节的四条硬标准，然后到第 3 节找你的类型，最后用第 6 节排错。
> 说明：文中所有示例均为演示用原创桥段，可直接改写使用，不涉及任何已有作品的具体情节。

---

## 0. 什么叫"切入点"

切入点不是"开头写什么"，而是**读者进入这个故事的第一道门**。它必须同时回答三件事：

1. **谁的故事**——视角人物是谁，他此刻是什么处境。
2. **从哪一刻开始**——不是从出生开始，是从"不能再晚"的那一刻开始。
3. **为什么是现在**——为什么不能早一天，也不能晚一天。

判断一个切入点是否成立，只需问一句：**如果晚三天开始讲，故事会有什么损失？** 如果没有损失，说明你选错了时刻。

**最常见的误解**：把"世界观介绍"当成切入点。世界观是背景，切入点是**一个人在一个具体时刻遇到的麻烦**。

---

## 1. 切入点的五种基本型（所有类型通用）

任何类型的开篇，本质上都是这五种之一，或者它们的组合。

| 基本型 | 定义 | 优势 | 风险 | 通用开场示例 |
|---|---|---|---|---|
| **时间切入** | 从一个特殊时刻开始 | 天然有紧迫感 | 时刻不够特殊就显得刻意 | "婚礼进行到交换戒指时，教堂的门被推开了。" |
| **身份切入** | 从一个反常身份开始 | 一句话建立差异 | 身份太猎奇会盖过人物 | "我是这间殡仪馆唯一的入殓师，也是唯一能听见死者说话的人。" |
| **冲突切入** | 从一场正在发生的冲突开始 | 最快建立张力 | 容易写成无意义的打架 | "刀架在脖子上的时候，他还在想刚才那碗面没吃完。" |
| **信息切入** | 从一条异常信息开始 | 制造悬念成本最低 | 信息太抽象会显得故弄玄虚 | "体检报告最后一页写着：预计剩余寿命，三天。" |
| **情绪切入** | 从一种强烈情绪开始 | 代入感最强 | 情绪没有事件支撑会显得矫情 | "我这辈子只后悔过一件事，就是那天没有回头。" |

**组合用法**：成熟的开篇通常是"两种型叠加"。例如"身份 + 冲突"（我是卧底，此刻正在被自己人审问）、"时间 + 信息"（婚礼当天，我收到一封举报自己的信）。

**选择建议**：新人优先用**冲突切入**或**信息切入**，因为它们最不依赖文笔；文笔强的作者可以用**情绪切入**，但必须尽快补上事件。

## 2. 切入点的四条硬标准

不管什么类型，一个合格的切入点必须过这四关。

| 标准 | 具体要求 | 不合格的样子 |
|---|---|---|
| **三行内建立"谁 + 困境"** | 读者看完前三行，知道这人是谁、他遇到什么麻烦 | 前三行在写天气、写山川、写家族历史 |
| **第一屏有"必须现在解决"的问题** | 有一个带时限的麻烦 | 主角在思考人生，没有具体的事在逼他 |
| **主角有一个可理解的欲望** | 读者能懂他想要什么，哪怕不认同 | 主角只是"被剧情推着走" |
| **结尾埋一个"想知道答案"的问题** | 一个具体的疑问，不是抽象的"命运将如何" | 结尾是"故事，才刚刚开始" |

**四种最该避免的开场：**

1. **世界观开场**：先讲三千年历史、五大陆、九大种族。读者还没认识人，不会关心世界。
2. **天气/风景开场**：除非风景本身是威胁（暴风雪、毒雾），否则就是拖延。
3. **回忆开场**：从十年前讲起，读者会以为主线在十年前。
4. **自我介绍开场**：我叫XX，今年十八岁，是XX家族第三子。这是简历，不是小说。

## 3. 全类型切入点枚举

### 3.1 幻想类

#### 1）玄幻（东方玄幻 / 异世大陆）

**类型承诺**：一个普通人靠着某种独特路径，在一个力量至上的世界里往上爬。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 废柴觉醒 | 宗门测灵根，他当众测出"无灵根"，全场哄笑 | 最稳的商业开法；风险是同质化严重，必须在"觉醒方式"上做出差异 |
| 天才坠落 | 全族最强的少年，在继承大典上被最信任的兄长废去修为 | 落差感强；风险是读者对"曾经的天才"没有感情，要先给三行高光 |
| 灭门之夜 | 家族被灭那晚，他躲在枯井里，听见上面的人在数人头 | 情绪最重；风险是开篇太压抑，需要尽快给一个"活下来的理由" |
| 反派转世 | 大魔头兵解转世，睁眼发现自己成了最讨厌的正道圣子 | 反差爽；风险是容易写成段子，缺少真实困境 |
| 必败守城 | 他被任命为一座注定守不住的城的守将，粮只够七天 | 天然有时限和赌注；适合写战争向玄幻 |
| 系统到期 | 系统提示：宿主剩余寿命三天，请尽快完成任务 | 信息切入的典型；风险是系统文容易被读者预判套路 |

**最忌**：开篇先讲大陆格局和境界体系。

#### 2）仙侠（修真 / 古典仙侠）

**类型承诺**：在一条求长生的路上，人如何面对"要舍弃什么"。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 杂役十年 | 外门第十年，他还在扫同一片落叶，直到那天扫出一枚带血的玉简 | 底层视角，代入感强；节奏要快，别真写十年 |
| 师父飞升 | 师父飞升前只说半句话，剩下的被天雷劈断了 | 悬念天然；适合写"追寻答案"型主线 |
| 偷吃禁果 | 他偷吃了师门禁地的果子，发现那不是灵果，是毒 | 冲突切入；能快速建立"犯错—代价"的循环 |
| 魔头重生 | 魔道祖师被围剿，睁眼成了正道首席弟子 | 身份反差；风险是正邪对立容易脸谱化 |
| 无情道心动 | 她修无情道三百年，第一次心跳加速是在杀他的时候 | 情绪切入；适合女频仙侠，情感张力强 |
| 飞升即囚 | 他修到飞升，发现上界是牢笼，飞升者都是养料 | 反套路；风险是前期必须埋够暗示，否则像硬转 |

**最忌**：开篇大段引用道经、堆砌仙气描写。

#### 3）奇幻（西幻）

**类型承诺**：在剑与魔法的世界里，一个小人物被卷进远超他身份的局。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 屠龙学徒 | 他是屠龙小队里负责牵马的，龙来的那晚，队里只剩他活着 | 身份反差 + 危机；适合写成长 |
| 错误预言 | 预言说会毁灭王国的孩子出生了，而他是负责去杀那个孩子的人 | 道德困境；冲突高级 |
| 魔法失效 | 全大陆的魔法在同一刻失灵，只有他的还能用 | 信息切入；风险是"唯一"设定容易变无敌 |
| 亡灵归来 | 他死后第七天醒在自己的葬礼上，没人看得见他 | 身份切入；适合悬疑向西幻 |
| 最后守夜人 | 边境哨塔只剩他一个人，而墙外的号角今晚响了 | 时间 + 危机；氛围强 |

**最忌**：开篇扔一堆自造名词（种族名、地名、神名）。

#### 4）都市异能

**类型承诺**：在熟悉的城市里，一个普通人突然拥有了不该有的能力。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 能力初现 | 地铁上，他突然能听见整节车厢所有人的心声 | 熟悉场景 + 异常；代入最快 |
| 死亡倒计时 | 他看见每个人头顶都有数字，而自己的只剩七天 | 信息切入；悬念强，但需要尽快解释规则 |
| 失业当天 | 被裁员的那天下午，他在天台上接到了第一个"客户" | 现实痛点 + 转折；情绪真实 |
| 误入现场 | 他走错房间，看见有人在处理一具不该存在的尸体 | 冲突切入；适合悬疑向 |
| 老宅继承 | 他继承了素未谋面的叔叔的老宅，地下室锁着三十七个箱子 | 探索欲；适合慢热型 |

**最忌**：开篇就写"这个世界分为明暗两层"。

#### 5）灵气复苏

**类型承诺**：世界正在改变，先适应的人获得优势。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 第一株草 | 小区花坛里长出一株会动的草，只有他注意到了 | 微观切入，恐怖感强 |
| 全网直播 | 一只怪物出现在早高峰的地铁口，全网直播 | 宏大开场；风险是主角容易被淹没在场面里 |
| 退伍归来 | 他退伍回家，发现家乡的山变了形状 | 个人视角切入宏大变化；适合写"守护" |
| 旧规则失效 | 枪打不穿那东西了，军队封锁了整个街区 | 军事向；适合硬核设定 |

**最忌**：开篇就报"灵气浓度达到XX"这种数据。

#### 6）克苏鲁 / 规则怪谈

**类型承诺**：世界有一套你不知道的规则，违反就会出事。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 一张纸条 | 他搬进新租的房子，冰箱上贴着一张纸条：晚上十点后不要开窗 | 规则切入，成本极低，效果极好 |
| 少了一个人 | 合影里少了一个人，但所有人都记得他存在过 | 信息切入；悬念高级 |
| 值夜班 | 他第一天上夜班，交接的人说：如果听见敲门，不要问是谁 | 场景 + 规则；适合短篇集 |
| 错误的常识 | 他发现所有人都认为"1+1=3"，只有他记得是2 | 认知恐怖；风险是容易写崩逻辑 |

**最忌**：直接描写"不可名状的恐怖"，读者无法想象。

#### 7）无限流

**类型承诺**：被强制投入副本，完成任务才能活。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 第一站 | 他睁开眼，站在一节陌生的车厢里，车门上贴着三条规则 | 规则 + 场景，最快建立机制 |
| 死亡预告 | 手机收到一条消息：你已被选中，倒计时 10 分钟 | 信息切入；适合都市背景 |
| 老兵带新人 | 他是老乘客，这次要带三个新人活过第一站 | 老手视角；风险是缺少"第一次的恐惧" |
| 名单少一人 | 他发现自己不在乘客名单上 | 身份切入；悬念强，适合长线 |

**最忌**：开篇花大篇幅解释"主神空间是什么"。

#### 8）诸天流

**类型承诺**：进入一个个已知世界，拿走资源，变强。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 第一页 | 他翻开一本缺页的旧书，第一页上写着他的名字 | 机制 + 悬念；不依赖 IP 认知 |
| 任务降临 | 系统提示：请前往《XX》世界，完成任务可获奖励 | 直接；风险是像游戏公告 |
| 错误进入 | 他本来只想穿一次，结果回不去了 | 冲突切入；能快速建立紧迫感 |
| 前辈痕迹 | 他进入第一个世界，发现墙上有人刻了一行现代字 | 悬念切入；适合长线主线 |

**最忌**：开篇先介绍"诸天万界"的概念。

#### 9）快穿

**类型承诺**：一个任务者不断进入不同身份，完成委托。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 第一个身份 | 她睁眼成了即将被休弃的侯府夫人，系统提示：请改写结局 | 身份 + 任务，最快入戏 |
| 任务失败 | 上个世界失败了，她被扣了积分，这次只剩一次机会 | 压力切入；适合老手型主角 |
| 委托反转 | 委托人说"帮我活下去"，可她查到的真相是委托人早已死了 | 悬念切入；质量高 |

**最忌**：开篇用旁白介绍"快穿局"的组织架构。

#### 10）末世 / 废土

**类型承诺**：文明崩塌之后，人怎么活，以及活成什么。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 第一天 | 早上八点，超市里所有人开始抢水，广播说"请市民不要恐慌" | 日常崩塌，代入极强 |
| 醒来之后 | 他从避难所的冷冻舱醒来，外面已经过去三十年 | 时间切入；适合探索型 |
| 最后一个 | 他是这座城市最后一个活人，直到他看见另一盏灯 | 情绪 + 悬念 |
| 墙外 | 他在安全区的墙内长大，第一次被派到墙外 | 世界观自然展开 |

**最忌**：开篇就写"丧尸病毒源于XX实验室"。

### 3.2 现实类

#### 11）都市生活

**类型承诺**：在真实的城市里，把一个普通人的日子过出滋味或翻盘。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 交不起房租 | 房东在门外敲门，他躲在屋里不敢出声 | 痛点真实，代入快 |
| 同学会 | 十年同学会，他是唯一没混出来的那个 | 情绪切入；适合写逆袭 |
| 继承小店 | 他继承了父亲的小饭馆，账本上全是欠条 | 生活流；适合慢热 |
| 意外之财 | 他捡到一个包，里面是三十万现金和一张身份证 | 道德困境；能快速制造选择 |

**最忌**：开篇就写"他其实是隐藏的豪门继承人"。

#### 12）职场商战

**类型承诺**：在利益场里，人怎么赢，以及赢了之后变成什么。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 背锅 | 项目出事了，全组都知道不是他的错，但没人说话 | 冲突 + 共鸣，最稳 |
| 空降 | 他被空降到亏损部门当负责人，下属集体递了辞职信 | 权力困境；适合写管理 |
| 竞标前夜 | 标书做好了，对手拿到了他们的底价 | 时间 + 危机 |
| 第一笔单 | 他是新人，第一笔单子的客户是他前女友的丈夫 | 关系张力；适合都市情感向 |

**最忌**：开篇用大段专业术语建立"我很专业"。

#### 13）校园

#### 16）行业文（医疗 / 刑侦 / 律政 / 教育）

**类型承诺**：在一个专业系统里，用专业能力解决具体问题。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 第一天上岗 | 他第一天上班，带教老师说"今天可能会死人" | 时间 + 压力 |
| 一例误诊 | 一份报告摆在他面前，他知道这意味着什么 | 道德困境；专业感强 |
| 值班夜 | 凌晨三点，急诊送来一个没有家属的病人 | 场景切入 |
| 旧案重启 | 十年前的案子被翻出来，卷宗上有他的签名 | 悬念切入；适合刑侦 |

**最忌**：开篇用病例/案卷格式炫技。

### 3.3 历史与军事类

#### 17）历史穿越

**类型承诺**：一个现代人带着知识落差，进入一个真实的困局。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 睁眼即死局 | 他醒来发现自己躺在刑场上，还有一炷香行刑 | 时间 + 危机，最抓人 |
| 灾年 | 他穿成一个县令，县里已经断粮七天 | 困境切入；适合种田/治理 |
| 边关 | 他成了守城小兵，敌军明天到 | 军事向 |
| 身份错位 | 他穿成了历史上注定要死的那个人 | 信息切入；读者知道结局，张力强 |

**最忌**：开篇先背一遍历史大势。

#### 18）历史架空

**类型承诺**：在一个"像历史但不是历史"的世界里，重演权力与人性的戏。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 登基前夜 | 老皇帝死了，遗诏还没找到 | 时间 + 权力真空 |
| 和亲路上 | 送亲队伍被截杀，只剩她一个 | 冲突切入 |
| 科举放榜 | 榜上没有他的名字，尽管他答得最好 | 不公 + 悬念 |
| 兵变 | 城外的军队换了旗号 | 宏大开场；需快速落到个人 |

**最忌**：开篇画一张势力关系图。

#### 19）军事战争

**类型承诺**：在极端环境里，看人如何承担、如何崩溃、如何守住。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 战前十分钟 | 战壕里，他在写一封可能寄不出去的信 | 时间 + 情绪，最有力量 |
| 新兵报到 | 他到连队第一天，班长说"记住你旁边人的名字" | 人物切入 |
| 撤退 | 命令下来了：断后的是他们连 | 冲突 + 牺牲 |
| 战后 | 仗打完了，他一个人在数空床位 | 情绪切入；适合反战主题 |

**最忌**：开篇用战报体报番号和兵力。

#### 20）谍战

**类型承诺**：在不能信任任何人的环境里，完成一件不能说的任务。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 上线失联 | 他和上线约定的接头时间过了三天，人没来 | 悬念 + 孤立，最标准 |
| 被怀疑 | 审讯室里，对面的人只说了一句"我们都知道" | 冲突切入；张力极强 |
| 双重身份 | 他同时为两边做事，今天两边都给了他任务 | 困境切入 |
| 叛徒 | 组织里出了叛徒，而名单在他手里 | 信息切入 |

**最忌**：开篇解释"我方""敌方"的组织架构。

### 3.4 悬疑探险类

#### 21）本格推理

**类型承诺**：给读者所有线索，和读者公平地比一场。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 尸体出现 | 密室的门被撞开，里面只有一具尸体和一台停摆的钟 | 经典；必须在第一屏给一个"不可能" |
| 死亡预告 | 他收到一封信：明天下午三点，你会死 | 时间 + 悬念 |
| 凶手视角 | 第一章就是凶手在布置现场，但没说是谁 | 视角切入；高级但难写 |
| 无尸命案 | 所有人都说人死了，但找不到尸体 | 悬念切入 |

**最忌**：开篇就写侦探的怪癖和履历。

#### 22）社会派悬疑

**类型承诺**：案子只是入口，真正要查的是这个社会为什么会产生这样的案子。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 一个普通人失踪 | 外卖员三天没接单，没人报警 | 底层视角，力量感强 |
| 判决之后 | 案子判了，受害者家属在法院门口跪着 | 情绪切入 |
| 旧闻重提 | 十年前的新闻被翻出来，评论区和当年不一样了 | 信息切入 |
| 加害者家属 | 他去找凶手的孩子，想问一句为什么 | 道德困境 |

**最忌**：开篇就下结论、给立场。

#### 23）盗墓 / 探险

**类型承诺**：进入一个不该进的地方，拿走不该拿的东西。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 一封遗书 | 爷爷留下半张地图和一句话：别去 | 悬念 + 禁令，最有效 |
| 下墓第一夜 | 绳子放下去三十米，还没到底 | 场景切入 |
| 队伍少人 | 出发时五个人，进洞时只剩四个 | 冲突切入 |
| 文物上的字 | 出土的青铜器上刻着他们队伍的名字 | 信息切入；悬念高级 |

**最忌**：开篇大段讲风水门派和盗墓规矩。

### 3.5 科幻类

#### 24）硬科幻

**类型承诺**：用一个经得起推敲的科学设定，推演出一个完整的世界。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 一个异常数据 | 监测站收到一段不该存在的信号 | 信息切入；克制有力 |
| 实验事故 | 实验室的警报响了，屏幕上只有一个数字在跳 | 危机切入 |
| 第一次接触 | 探测器传回一张照片，上面有建筑 | 悬念切入 |
| 规则失效 | 物理常数发生了偏移，一切都在慢慢改变 | 概念切入；难度高 |

**最忌**：开篇用论文腔解释设定。

#### 25）赛博朋克

**类型承诺**：在高科技低生活的世界里，人如何保住自己那点"人"的部分。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 义体到期 | 他的义体贷款逾期，回收公司今天上门 | 现实痛点 + 未来感，最有效 |
| 记忆买卖 | 他靠卖记忆还债，今天要卖掉最后一段 | 概念 + 情绪 |
| 公司区 | 他住在下城区，第一次进公司区送快递 | 阶级对比 |
| 系统升级 | 全城的义体在同一秒强制更新 | 事件切入 |

**最忌**：开篇堆霓虹、雨夜、全息广告的描写。

#### 26）星际 / 太空歌剧

**类型承诺**：在极大的尺度上，讲人的野心与忠诚。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 舰毁之后 | 主舰爆炸，逃生舱里只剩他和一个敌方士兵 | 冲突 + 孤立，张力最强 |
| 殖民第一年 | 殖民地第一年，补给船没来 | 生存切入 |
| 叛变 | 舰长宣布脱离联邦，问全舰谁反对 | 权力冲突 |
| 信号 | 他们收到一段来自人类故乡的信号，而故乡已经消失两百年 | 悬念切入 |

**最忌**：开篇报星区编号和舰队编制。

#### 27）时间循环 / 时间旅行

**类型承诺**：时间一旦可以被重来，人的选择就失去了重量——直到他找到不能重来的东西。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 第二次醒来 | 他再次睁开眼，是同一个早晨，同一条新闻 | 概念切入，最快建立规则 |
| 倒计时 | 他每穿越一次，寿命就少一年 | 代价切入；解决"无限重来"的乏味 |
| 遇见自己 | 他在街上看见了自己，对方也看见了他 | 悬念切入 |
| 无法改变 | 他试了十七次，那个人还是会死 | 情绪切入；悲剧感强 |

**最忌**：开篇用旁白解释时间线理论。

### 3.6 情感类

#### 28）现代言情

**类型承诺**：两个人在现实条件下，如何靠近、如何错过、如何选择。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 婚礼变故 | 交换戒指时，他的手机响了，他看了一眼就走了 | 时间 + 冲突，最抓人 |
| 重逢 | 她去医院做检查，主治医生是五年前不告而别的人 | 关系张力 |
| 相亲错位 | 她替姐姐去相亲，坐下才发现对方是他 | 轻喜剧；适合甜宠 |
| 离婚当天 | 离婚协议签完，她发现自己怀孕了 | 情绪切入；虐恋常用 |
| 合租 | 她租的房子，房东是她的顶头上司 | 日常张力 |

**最忌**：开篇用大段外貌描写介绍男主"身高一米八七，眉眼深邃"。

#### 29）古代言情（宫斗 / 宅斗）

**类型承诺**：在规矩森严的深宅或深宫里，用规矩本身当武器。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 重生归来 | 她睁开眼，回到被赐死的前一夜 | 信息差 + 复仇，最稳 |
| 嫡女回府 | 她在庄子上住了十年，今天被接回府，院子已经住了人 | 冲突切入 |
| 选秀当天 | 她故意在御前失仪，还是被留了牌子 | 反套路 |
| 和亲路上 | 送亲队伍遇到劫杀，护卫全死了 | 危机切入 |
| 冲喜 | 她被抬进王府冲喜，新郎已经昏迷三个月 | 设定切入；张力强 |

**最忌**：开篇用旁白介绍"她是丞相府嫡女，琴棋书画样样精通"。

#### 30）甜宠

**类型承诺**：低冲突、高浓度的心动体验。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 意外同居 | 她家的水管爆了，物业派来的维修工是他 | 日常 + 接触 |
| 契约关系 | 他们签了一份"假装情侣"的协议，第一条是不能动心 | 设定切入；读者已知会破戒 |
| 一见钟情 | 她在人群里多看了他一眼，他正好也在看 | 情绪切入；风险是缺少后续动力 |
| 冤家开局 | 他们因为一只猫在小区门口吵了半小时 | 冲突切入；反差萌 |

**最忌**：开篇就写"他宠她入骨"——宠要写出来，不能说出来。

#### 31）虐恋

**类型承诺**：把两个人放在"爱但不可以"的结构里，反复拉扯。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 误会已成 | 她站在病房外，听见他说"我从来没爱过她" | 情绪切入；信息差是核心 |
| 身份对立 | 她是他的仇人之女，他今天来提亲 | 结构切入；张力天然 |
| 替身 | 她知道自己是个替身，今天正主回来了 | 身份切入 |
| 生死 | 医生说她只剩半年，她决定不告诉他 | 时间切入 |

**最忌**：靠"不长嘴"制造误会，读者会反感。

#### 32）婚恋家庭

**类型承诺**：把婚姻与家庭里的真实难题摊开写。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 一张账单 | 她在丈夫的手机里看到一笔转账，收款人她不认识 | 信息切入；生活感强 |
| 婆媳同住 | 婆婆搬进来的第一天，把她的东西全挪了位置 | 冲突切入 |
| 二胎 | 全家都在劝她生二胎，没人问她愿不愿意 | 议题切入 |
| 中年失业 | 他四十岁被裁，回家路上在车里坐了两小时 | 情绪切入 |

**最忌**：开篇就把所有家庭成员列一遍。

#### 33）BL / 百合

**类型承诺**：在同性与社会目光之间，两个人如何确认彼此。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 秘密暴露 | 他的手机被室友捡到，屏保是另一个男生的照片 | 冲突 + 悬念 |
| 搭档 | 他们被分到同一个项目组，工位挨着 | 日常张力 |
| 多年后重逢 | 同学会上，他们隔着一张桌子，谁都没先开口 | 情绪切入 |
| 假装情侣 | 为了应付家里，他们决定假扮一对 | 设定切入；轻喜剧 |

**最忌**：开篇用旁白强调"这个社会不接受他们"，说教感重。

### 3.7 特殊结构类

#### 34）群像

**类型承诺**：不是一个人的成长，是一群人在同一件事里的不同选择。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 一个共同事件 | 大楼停电，电梯里困了七个人 | 事件切入；天然聚人 |
| 一个人的死 | 班长死了，全班都收到了他的遗书 | 悬念切入 |
| 同一件事的多个视角 | 第一章从保安的视角写同一场火灾 | 结构切入；需要读者耐心 |

**最忌**：开篇连续介绍五个人物的姓名职业。

#### 35）单元剧

**类型承诺**：每一集独立成立，串起来是一条长线。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 第一单 | 他接到第一个委托：帮她找回失踪的猫 | 轻入口；适合长篇 |
| 老规矩 | 店里有个规矩：不问客人来历 | 设定切入 |
| 常客 | 每周三同一个时间来同一个人，点同样的东西 | 细节切入；氛围好 |

**最忌**：第一个单元就上最大最复杂的案子。

#### 36）双线 / 多线

**类型承诺**：两条时间线或两条人物线互相解释、互相颠覆。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 现在与过去 | 现在：他在整理遗物；过去：她在写日记 | 对照切入 |
| 两个陌生人 | 两条线各写一个人，读者猜他们什么关系 | 悬念切入 |
| 同一案两端 | 一条线是警察，一条线是凶手 | 结构切入；张力强 |

**最忌**：两条线在开篇没有任何关联暗示，读者会以为读了两本书。

#### 37）反套路 / 元叙事

**类型承诺**：读者以为要看A，你给他B，而且B更有意思。

| 切入点 | 从哪一刻开始 | 适合 / 风险 |
|---|---|---|
| ★ 角色知道自己是角色 | 他对着天空说："作者，我知道你在看" | 概念切入；风险是玩梗过度 |
| 套路失效 | 他按系统提示做了，结果系统说"你被骗了" | 反转切入 |
| 反派视角 | 第一章从"反派"的视角写他怎么被主角欺负 | 视角切入；新鲜感强 |
| 开局即结局 | 第一章就是大结局，然后倒着讲 | 结构切入；难度高 |

**最忌**：只有梗，没有故事。反套路的底子必须是一个扎实的套路。

## 5. 第一句话的十二种写法

切入点定下来之后，第一句怎么写，决定读者会不会看第二句。

| 写法 | 结构 | 示例 |
|---|---|---|
| **异常陈述** | 说一句不合常理的话 | "我们家死人的规矩是：头七那天，不能哭。" |
| **倒计时** | 给出剩余时间 | "距离他被枪毙，还有四十分钟。" |
| **动作中途** | 从动作中间切入 | "刀劈下来的时候，他还在想那碗面没吃完。" |
| **身份自陈** | 一句话说清我是谁 | "我是这条街上唯一一个不给活人理发的理发师。" |
| **否定式** | 先否掉读者的预期 | "我不是英雄。我只是那天刚好没跑。" |
| **物件特写** | 用一个物件承载信息 | "遗书只有三行，第三行被血糊住了。" |
| **对话开场** | 直接甩一句台词 | ""你确定要打开这扇门？"" |
| **场景反差** | 把两件不搭的事放一起 | "婚礼进行到一半，殡仪馆的车到了。" |
| **规则宣告** | 直接给一条规则 | "晚上十点以后，不要照镜子。" |
| **数字开场** | 用具体数字建立真实感 | "三十七个人进了那栋楼，出来的是三十六个。" |
| **回忆钩** | 用一句"后来我才知道" | "后来我才知道，那天他本来不该来。" |
| **疑问开场** | 用主角的疑问起手 | "如果一个人被所有人忘了，他还算活着吗？" |

**纪律**：第一句只承担一个任务——让读者想知道第二句。不要在第一句里塞世界观。

## 6. 切入点常见错误对照表

| 错误 | 表现 | 修法 |
|---|---|---|
| **世界观开场** | 前三段在讲大陆、种族、历史 | 删掉，从一个人遇到麻烦的那一刻开始 |
| **主角简历** | 姓名、年龄、家世、外貌连着写 | 拆散到动作和对话里 |
| **无效日常** | 起床、刷牙、吃饭写了两千字 | 只保留能展示人物或埋线索的日常 |
| **假悬念** | "他不知道，这一去将改变一生" | 换成具体信息或具体威胁 |
| **群像式开头** | 一口气出现五个人名 | 先只让一个人有名字 |
| **设定倾泻** | 用旁白解释金手指规则 | 让主角用一次，读者自然懂 |
| **情绪先行** | 开篇大段内心独白 | 给情绪配一个事件 |
| **切入太晚** | 第三章才进入主线 | 把第三章的内容提到第一章 |
| **切入太早** | 从主角小时候写起 | 直接从"不能再晚"的那一刻开始 |
| **类型错位** | 标着甜宠，开篇在写凶杀 | 前三百字必须兑现类型承诺 |
| **模仿痕迹** | 开篇结构与某本名作高度相似 | 换时刻、换视角、换第一个麻烦 |
| **信息过载** | 一段里出现八个专有名词 | 一段最多一个新名词 |

## 7. 交付前自检清单

- [ ] 切入点能回答"谁、从哪一刻、为什么是现在"三个问题。
- [ ] 晚三天开始讲，故事会有明显损失。
- [ ] 前三行建立了"谁 + 困境"。
- [ ] 第一屏有一个带时限的麻烦。
- [ ] 主角有一个读者能理解的欲望。
- [ ] 结尾有一个具体的、可回答的疑问。
- [ ] 前三百字兑现了类型承诺（甜宠要甜，悬疑要悬）。
- [ ] 没有世界观倾泻、没有主角简历、没有无效日常。
- [ ] 第一句只做一件事：让读者想看第二句。
- [ ] 一段之内不超过一个新专有名词。
- [ ] 开篇没有与名作高度相似的结构。
