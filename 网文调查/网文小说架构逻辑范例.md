# 网文小说架构逻辑范例

> 用途：把"我想写个爽文"翻译成一套可执行、可审计的结构。
> 读法：第 1 节看逻辑，第 2 节看一部完整范例，第 3 节抄模板，第 4 节对照排错。
> 说明：范例《拾骨人》为演示用原创设定，人物、地名、桥段均为本文虚构，可直接替换成你自己的故事。

---

## 1. 架构到底是什么：六层结构

网文架构不是"设定集 + 大纲"，而是一条**承诺 → 兑现**的传导链。上一层没立住，下一层写得再热闹都是空转。

| 层级 | 回答的问题 | 产出物 | 这一层崩了会怎样 |
|---|---|---|---|
| L1 承诺层 | 读者点进来，是来反复获得什么体验？ | 一句话题材承诺 + 书名/简介/标签 | 点进来就退，开篇留存高但涨不动 |
| L2 人物层 | 谁在要什么，为什么非他不可？ | 主角卡、对手卡、关系债务 | 章章打脸，但没人关心主角 |
| L3 规则层 | 世界用什么方式阻止他、收他多少代价？ | 3~5 条硬规则 + 压力测试 | 高潮靠临时加规则救场，读者失去信任 |
| L4 骨架层 | 全书到卷，有哪些不可逆的变化？ | 三幕/卷纲 + 因果链 | 中段换地图、数值通胀、重复塌陷 |
| L5 场景层 | 这一章谁想干什么，卡在哪，做了什么选择？ | 单章场景卡、爽点五问 | 情节在动，人物没动；水 |
| L6 结算层 | 读者拿到了什么，又欠下什么新问题？ | 章末钩子、卷末结算 | 靠断章硬吊，追更变成消耗 |

**传导关系一句话**：承诺决定人物要什么，人物要什么决定规则该拦什么，规则决定大纲的升级方式，大纲决定每一章的选择，每一章的选择决定读者要不要看下一章。

## 2. 完整范例：《拾骨人》

### 2.1 立项卡（先答"为什么是你写"，再谈赛道）

| 项目 | 内容 |
|---|---|
| 目标平台 | 男频悬疑向长篇（示例，实际以目标平台当期频道为准） |
| 创作目标 | 商业连载为主，兼顾改编潜力 |
| 核心体验 | 每破一案，主角就少一段自己——读者一边追真相，一边看着他消失 |
| 读者画像 | 喜欢推理与规则怪谈、能接受主角付出真实代价的读者 |
| 作者优势 | 擅长写冷硬对白与案件结构；对"记忆/身份"题材有长期素材积累 |
| 产能与存稿 | 日更 4000 字，开书存稿 12 万字（示例，按真实产能填） |
| 合规风险 | 涉及尸骨、死亡场景，需控制在悬疑尺度内，不做血腥细节 |

> 关键动作：**先写清"为什么是这个作者来写"，再决定写什么赛道。** 热赛道可能需求强，也可能供给拥挤；作者适配度决定你能不能写到 80 万字不塌。

### 2.2 题材承诺（一句话，且必须可验证）

> **在一个记忆会凝成骨珠的世界，一个靠"读骨"破案的拾骨人，每读一次就要拿自己的一段记忆付账——他要找回师父的骨珠，代价是逐渐忘记自己是谁。**

这句话里有五个可验证项，缺一项承诺就是空的：

| 承诺项 | 具体内容 | 在正文哪里被验证 |
|---|---|---|
| 为哪类读者 | 悬疑 + 规则怪谈 + 代价流 | 第 1 章就演示规则与代价 |
| 跟随谁 | 拾骨人沈砚 | 第 1 章第一视角代入 |
| 世界约束 | 骨珠七日散、读骨付记忆 | 第 1 章、第 3 章各演示一次 |
| 核心行动循环 | 接案 → 读骨 → 破案 → 付代价 | 每个案件单元重复一次 |
| 持续体验 | 真相推进 + 自我流失的双重张力 | 每卷末结算一次"他忘了什么" |

**反面例子**（标签堆砌，不可验证）："玄幻+系统+无敌+爽文+杀伐果断"——读者无法据此判断自己会读到什么，正文也无法验收。

### 2.3 主角卡（欲望系统，不是能力清单）

**沈砚｜拾骨人｜二十三岁**

- **外部目标**：取回师父陆九的骨珠，查明他真正的死因。
- **内部缺口**：他已经在丢失自己的记忆，却不敢承认自己害怕变成空壳。
- **脆弱点**：他记不住妹妹沈萤的脸，只能靠一枚糖糕的味道去确认"我还记得她"。
- **价值底线**：不读活人的骨。这是他和同行、和司骨监的分界线。
- **关系债务**：三年前欠守骨人阿箬一条命，代价是"她要他做一件事，他不能问是什么"。
- **选择模式**：每次都在"读骨拿到真相"和"保住自己"之间选前者——**这是他反复付出代价的机制，也是他人物的钩子。**

> 主角卡的作用不是让读者觉得他强，而是让读者能预测他在压力下会怎么选，并且为这个选择心疼。

### 2.4 对手卡（有独立目标，会学习）

**裴无咎｜司骨监少监｜三十四岁**

- **独立目标**：把所有骨珠收归官库。他真心认为私人记忆是动乱之源——他不是来送人头的，他是来推行自己那套秩序的。
- **手段**：制度、合法身份、信息垄断，而不是"我要杀了你"。
- **学习能力**：第 7 章被沈砚当众揭穿后，第 22 章他就学会用"空骨"设局反钓，并且改用沈砚的底线（不读活人骨）来逼他。
- **与主角的镜像关系**：沈砚想留住记忆，裴无咎想消灭记忆。两种"为你好"，都要求别人付出代价。

### 2.5 金手指五问（答不全就是无代价外挂）

| 问题 | 《拾骨人》的答案 |
|---|---|
| 多出什么行动 | 能读死者最后七日的记忆碎片，获得常人拿不到的现场信息 |
| 何时不能用 | 骨珠离尸三日即自毁；七日前的记忆已散；活人没有骨珠 |
| 代价是什么 | 读多少付多少自身记忆，且会被死者的习性"染色"（口癖、口味、恐惧） |
| 对手如何反制 | 洗骨伪造、空骨陷阱、往骨珠里塞别人的记忆当"记忆锚"，让他分不清自己 |
| 升级带来什么新难题 | 读得越多越强，也越不像沈砚——第三卷他必须面对"我还是我吗" |

### 2.6 世界规则与压力测试

**三条硬规则：**

1. 人死后七日内，记忆凝为骨珠；七日后散尽，不可复原。
2. 读骨须以自身等量记忆为薪；被读者会染上死者的习性。
3. 洗骨可伪造骨珠，但伪造品缺一段"气味"——童年的气味记忆无法伪造。

**每条规则都要过四道压力测试：**

| 测试 | 规则 3 的答案 |
|---|---|
| 谁受益 | 司骨监垄断验骨权；富户靠伪造遗嘱骨珠夺产 |
| 怎样规避 | 提前"养骨"、雇人代读、黑市买"净骨" |
| 极端情况会怎样 | 读到至亲的骨珠——规则没有例外，他必须照付。这正是全书高潮的合法性来源 |
| 在剧情中何处首次被看见 | 第 1 章乞儿的骨珠"没有气味"，第 3 章揭晓这是伪造 |

> **底线纪律**：高潮不许临时加例外救主角。所有"主角能赢"的路径，必须在前面章节已经展示过规则允许。

### 2.7 三本账（架构的可审计部分）

**承诺账**——向读者许过什么，什么时候还：

| 承诺 | 兑现位置 | 状态 |
|---|---|---|
| 每读一次就少一段自己 | 第 1、7、15、28 章各结算一次具体遗忘 | 进行中 |
| 师父之死不是意外 | 第一卷卷末 | 已兑现 |
| "我会找回妹妹" | 全书终局 | 未兑现 |

**因果账**——相邻重要事件必须能连成"因为…所以…"，不能是"然后…然后…"：

> 因为师父的骨珠被司骨监取走 → 所以沈砚必须进档案库 → 因为进档案库需要合法身份 → 所以他接下裴无咎的招安任务 → 因为任务中他读了关键证人的骨 → 所以他拿到线索，同时失去了妹妹的一段记忆 → 因为失去这段记忆，他判断失误 → 所以卷末他错认了师父骨珠的真伪。

**伏笔账**——每埋一个必须登记，不登记的伏笔就是未来的债：

| 埋设章 | 伏笔内容 | 预期回收章 | 状态 |
|---|---|---|---|
| 第 1 章 | 乞儿的骨珠没有气味 | 第 28 章（空骨案源头） | 未收 |
| 第 1 章 | 他忘了糖糕的味道 | 第 15 章（妹妹墓前） | 未收 |
| 第 3 章 | 阿箬说"第十三具无名骨不入册" | 第 40 章 | 未收 |
| 第 7 章 | 裴无咎袖口沾着洗骨粉 | 第 22 章 | 未收 |
| 第 12 章 | 陆九临终只说三个字："别读我" | 第 30 章（大伏笔） | 未收 |

> 纪律：连续 3 章有新埋无回收，触发预警；卷末盘点一次"本卷埋了几笔、收了几笔"。

### 2.8 全书骨架（先定终局，再拆单元）

**终局**：沈砚读到自己的骨珠——他早已在第一次读骨时死过一次，现在的他是被"染色"出来的另一个人。他选择把真相留给自己，把师父的清白还给世界。

**三幕与卷级不可逆变化：**

| 幕/卷 | 主角想要 | 卷末不可逆变化 |
|---|---|---|
| 第一幕·第一卷 | 取回师父骨珠 | 从"想找回记忆的人"变成"知道自己正被取代的人" |
| 第二幕·第二至四卷 | 查清谁先读过师父的骨 | 从民间拾骨人变成体制内的人，再变成体制的敌人 |
| 第三幕·第五卷 | 决定"我是谁" | 身份彻底不可逆：他放弃了唯一能证明自己的东西 |

> **卷级不可逆变化的检验标准**：这一卷结束后，主角还能回到卷首的状态吗？如果能，这一卷就是白写的。

### 2.9 第一卷卷纲（因果链写法）

```
第 1 章  师父死讯 → 骨珠被司骨监取走（欲望点火）
第 2 章  裴无咎招安 → 沈砚拒绝 → 被断财路（代价升级）
第 3 章  第一具空骨出现 → 他被迫接案（进入主线）
第 4-6 章 查案：三个嫌疑人，各有不在场证明 → 骨珠是唯一突破口
第 7 章  当众读骨破案 → 得到档案库通行令（短回路兑现）
第 8-11 章 档案库：发现师父的骨珠登记被人涂改
第 12 章 回忆：陆九临终"别读我"（伏笔，此时读者不懂）
第 13-15 章 代价结算：他忘了糖糕的味道，妹妹的墓前他站了很久
第 16-21 章 空骨案扩大 → 线索指向司骨监内部
第 22 章 裴无咎反钓：用空骨设局，沈砚第一次输
第 23-27 章 反查：他用自己的一段记忆换关键证人的骨
第 28 章 揭晓：空骨来自官库，乞儿的骨珠是第一具
第 29-30 章 拿到师父骨珠 → 发现缺"气味" → 是伪造的
```

**为什么这样排**：每一段都能用"因为…所以…"接上；每 6~8 章有一次短回路兑现；每 10 章左右结算一次代价，让"失去"变成可数的进度条，而不是抽象设定。

### 2.10 黄金三章功能验收表

不套"退婚重生系统觉醒"，只看功能是否到位：

| 功能 | 第 1 章《一颗没有气味的骨》 | 是否达成 |
|---|---|---|
| 定位 | 开篇三行内出现"拾骨""骨珠""读骨" | ✅ |
| 欲望 | 他要攒钱赎回妹妹的骨珠 | ✅ |
| 扰动 | 师父死讯 + 骨珠被抢 | ✅ |
| 差异 | 别人破案靠人证，他靠消耗自己 | ✅ |
| 规则演示 | 读乞儿的骨 → 破案拿赏钱 → 忘了糖糕的味道 | ✅ |
| 短回路兑现 | 当场指认左撇子凶手，拿到钱 | ✅ |
| 长问题建立 | 师父的骨珠被谁取走？为什么没有气味？ | ✅ |

**第 2 章**：反派登场，招安被拒，主角被断财路——把"拒绝"变成"付不起拒绝的代价"。
**第 3 章**：第一具空骨，规则升级（洗骨存在），主角被迫入局，同时给一个小胜。

### 2.11 单章场景卡（第 7 章：当众验骨）

> 场景卡格式：目标 → 阻碍 → 选择 → 结果 → 新问题。一章至少一个完整的五拍。

- **场景**：白露城祠堂，富商周氏要凭亡父骨珠独吞家产，族人告其伪造。
- **目标**：沈砚要证明骨珠是假的，拿到档案库通行令。
- **阻碍**：骨珠已由司骨监验过"为真"；他若当众推翻，就是打司骨监的脸，按律可判诬告。
- **选择（不可替代的一步）**：他不说"这是假的"，而是当场读骨，并**故意让富商看见自己被"染色"**——他开始模仿亡父的咳嗦和口癖。
- **结果**：族人认出那是老爷子的习惯，富商当场崩了；骨珠被验为洗骨伪造。
- **新问题（责任）**：他染上了亡父的咳嗦，且开始记不清自己的字迹；裴无咎在人群里看着他，记下了这一手。

> 检验：这个爽点能不能换成别人来做？如果不能，它才是主角的爽点。

### 2.12 爽点五问（每个爽点都过一遍）

以第 7 章为例：

1. **读者此前期待什么？** 前三章反复强调"遗嘱骨珠决定家产"，读者已经站在族人一边。
2. **什么阻碍让结果不廉价？** 骨珠官方验真，推翻它要担罪。
3. **主角做了哪步不可替代的选择？** 用自己的记忆当赌注，并主动暴露"被染色"。
4. **结果改变了什么？** 家产归族人，他拿到通行令，裴无咎注意到他。
5. **带来什么新责任？** 身体与记忆的双重损耗；被反派盯上。

### 2.13 章末钩子：靠后果，不靠截断

| 类型 | 写法 | 示例 |
|---|---|---|
| 后果钩 | 这一章的选择产生了新麻烦 | 他赢了官司，却开始咳嗦——那是死人的病 |
| 选择钩 | 下一章他必须二选一 | 阿箬要他兑现"那件事"，而这件事会让他违背底线 |
| 信息钩（限量） | 给半条信息，不给答案 | 师父骨珠的登记页上，涂改的笔迹是他自己的 |
| 危机钩 | 直接威胁 | 档案库起火，唯一能证明师父清白的册子在里面 |

> **反面做法**：把一句"他推开门"拆成两章结尾。强钩子提高的是唤起，不是继续读的意愿；长期这么干，读者会用弃书投票。

## 4. 架构故障对照表

| 症状 | 大概率不是"节奏慢" | 真正要修的地方 |
|---|---|---|
| 开篇留存高，十万字后崩 | 不是读者变挑剔 | 第一次大兑现之后没有新目标（L2 断了） |
| 章章打脸，但没人关心主角 | 不是爽点不够多 | 爽点没有前置期待与代价，主角没有选择（L2/L5） |
| 反派像送人头的 | 不是反派不够狠 | 反派没有独立目标与学习能力（L2） |
| 高潮靠"突然觉醒"过关 | 不是读者不懂欣赏 | 世界规则没做压力测试，临时加例外（L3） |
| 中段换地图、数值通胀 | 不是地图不够大 | 升级只有数值没有结构变化（L4） |
| 越写越水，更新透支 | 不是灵感枯竭 | 产能与存稿方案不匹配，节律失控（L6） |
| 追更靠恶意断章撑着 | 不是钩子不够狠 | 章末没有后果与新问题，只有截断（L6） |
| 数据一跌就说"节奏慢" | 不是单一原因 | 没做漏斗分层：包装 / 首章 / 前三章 / 首次兑现后 |

**数据诊断的正确顺序**（先固定口径：平台、入口、推荐阶段、分母、观察窗口、章节版本）：

1. 曝光高、进入低 → 查包装（书名/简介/标签与正文是否一致）。
2. 进入高、首章读完低 → 查前两千字的理解成本与代入速度。
3. 前三章好、后续跌 → 查第一次兑现之后有没有给出新目标。
4. 中段掉、评论骂 → 把评论按"理解障碍 / 期待未兑 / 设定矛盾 / 纯偏好"编码，当诊断线索，不当投票改剧情。

## 5. 交付前自检清单

- [ ] 题材承诺能用一句话说完，且五个承诺项都能在正文找到验证位置。
- [ ] 主角在压力下的选择可预测，且这个选择会让他付出代价。
- [ ] 反派有自己的目标，并且会因为输过一次而变强。
- [ ] 金手指五问全部有答案，没有"什么都能解决"的能力。
- [ ] 每条世界规则都过了四道压力测试，高潮没有临时加例外。
- [ ] 每一卷结束都有不可逆变化，主角回不到卷首状态。
- [ ] 相邻重要事件能用"因为…所以…"连起来，而不是"然后…然后…"。
- [ ] 三本账都在更新，伏笔有回收章号，连续 3 章未回收已预警。
- [ ] 每个爽点都过了五问，且换个人来做就不成立。
- [ ] 章末钩子来自后果与选择，不是把一句话拆成两章。
- [ ] 更新计划匹配真实产能，存稿是缓冲，不是透支的遮羞布。
- [ ] 没有复刻他人作品的具体人物组合、桥段序列与台词；引用与改编有授权依据。
