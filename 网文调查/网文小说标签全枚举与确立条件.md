# 网文小说标签全枚举与确立条件验证

> 覆盖：9 组、384 个现行标签，每个标签给出"正文必须出现什么才算成立"的兑现条件。
> 方法：先看第 1 节的标签层级，再看第 3 节的六维验证模型，然后到第 2 节查标签，最后用第 4 节的打分卡判定。
> 口径说明：标签体系各平台不同且会调整，本文按主流平台通行分类整理；具体平台的可选标签、层级与入口，以开书当期该平台分类页为准。

---

## 0. 标签的本质：一份三方契约

很多作者把标签当装饰，打完就不管了。实际上标签同时约束三方：

| 主体 | 标签对它的作用 | 它反过来要求标签 |
|---|---|---|
| **平台** | 分发依据。算法靠标签做内容匹配与人群匹配 | 标签必须是平台可识别的、层级正确的 |
| **读者** | 筛选工具。读者用标签在几秒内决定要不要点 | 标签必须是读者语言，不是作者语言 |
| **作者** | 承诺书。打了这个标签，就要交出对应体验 | 正文必须可兑现，且能指出兑现位置 |

**核心结论**：一个标签"成立"，等于**平台能识别、读者能检索、正文能兑现**三件事同时成立。缺一件，这个标签就是负资产——它会带来错误的点击，然后用低留存把这本书的推荐权重拖下去。

**标签的三种常见虚挂：**

- **装饰型**：打了 8 个标签，正文只兑现 1 个。读者点进来发现不是想看的，三章内流失。
- **追热型**：蹭当期热标签，但正文没有对应内容。短期有曝光，长期伤账号。
- **自嗨型**：用作者自己的概括词（"史诗级群像""深度人性"），平台没有这个标签，读者也不会搜。

## 1. 标签的五层结构

理解层级，才能理解为什么有的标签决定生死、有的只是修饰。

| 层级 | 名称 | 作用 | 例子 | 数量级 |
|---|---|---|---|---|
| **L0** | 频道 | 决定进入哪个大盘子 | 男频 / 女频 | 2~3 |
| **L1** | 题材 | 决定流量池归属，是第一道筛选 | 玄幻、都市、仙侠、现言、古言 | 20~40 |
| **L2** | 流派/设定 | 决定长尾匹配与同类竞品 | 无限流、诸天流、系统、规则怪谈、种田 | 100+ |
| **L3** | 情节/关系/人设 | 决定精准人群与预期管理 | 追妻火葬场、双洁、扮猪吃虎、群像 | 150+ |
| **L4** | 情绪/风格 | 决定阅读体验的质地 | 爽、虐、甜、轻松、杀伐果断、慢热 | 50+ |

**平台的真实做法（以两个主流体系为例）：**

- 起点把标签做成了一个大池子，公开标签页显示约 300 个标签，且每个标签带作品数量——穿越、系统流、轻松、杀伐果断、无敌流、热血、快节奏、智商在线、重生这些排在最前，说明它们是高频入口；同时"斗罗大陆"这类 IP 名也在标签里，说明标签体系里还混着圈层入口[1]。
- 番茄的逻辑是"一级标签决定大盘流量池归属（如都市、玄幻、现言），二级标签描述设定或情节特征，用来提升长尾匹配度"，并且明确建议核心标签 1~2 个最精准、辅助标签 2~3 个、热点标签适度加[2]。

**这两个体系给作者的启示是一致的**：L1 决定你能不能进池子，L2/L3 决定你被推给谁，L4 决定读者读起来"像不像那么回事"。

**一个作品的标准标签结构**：

```
1 个 L1（题材） + 2~3 个 L2/L3（流派、设定、关系） + 1~2 个 L4（情绪风格）
```

超过 5 个标签，通常意味着定位不清；超过 8 个，等于没有定位。

## 2. 标签全枚举（含兑现条件）

> "兑现条件"一栏写的是：正文出现什么，这个标签才算成立。这一栏是本文的核心——它让标签从形容词变成可验收的标准。
> 层级缩写：L1 题材 / L2 流派设定 / L3 情节关系人设 / L4 情绪风格。

## 3. 标签确立的六维验证模型

这是本文的方法核心。一个标签要不要打、能不能打，用六个维度依次验证，**任一维度不过关，就不该打**。

### 维度一：平台维度（可打性）

**要验证的**：这个标签在目标平台是否存在、在哪个层级、入口在哪。

| 检查项 | 取证方法 | 判定标准 |
|---|---|---|
| 标签是否存在 | 到平台分类页/标签页实测搜索 | 能搜到且能选 = 通过 |
| 层级是否正确 | 看它出现在一级筛选还是二级筛选 | 打错层级会导致进错池子 |
| 是否可自定义 | 平台是否允许作者自填标签 | 自填标签权重通常低于官方标签 |
| 同义标签是否并存 | 搜"无限流"和"无限游戏"看是否都有 | 并存时选作品数更多的那个 |

**常见失败**：用 A 平台的标签去打 B 平台的书。同名标签在不同平台的含义可能完全不同。

**判定红线**：平台没有的标签，一律不打。自造标签不产生分发，只产生混乱。

### 维度二：读者维度（可检索性）

**要验证的**：读者会不会用这个词找书。

| 检查项 | 取证方法 | 判定标准 |
|---|---|---|
| 是否是读者语言 | 看读者评论区、书单、推文里怎么称呼这类书 | 读者口语里出现 = 通过 |
| 搜索下拉是否有 | 在平台搜索框输入前两个字，看联想词 | 有联想 = 高价值 |
| 理解成本 | 给一个非本书读者看这个词，能否 3 秒内理解 | 需要解释 = 不合格 |
| 是否有歧义 | 同一个词是否指向两种内容 | 有歧义 = 慎用 |

**读者语言 vs 作者语言**：

| 读者语言（有效） | 作者语言（无效） |
|---|---|
| 追妻火葬场 | 情感反转叙事 |
| 扮猪吃虎 | 隐藏实力型主角 |
| 苟道流 | 风险规避型生存策略 |
| 群像 | 多主角并行结构 |

**判定红线**：需要一句话解释才能懂的标签，读者不会用它搜索。

### 维度三：文本维度（可兑现性）

**要验证的**：正文能不能兑现，兑现得多强、多密、多早。

| 检查项 | 取证方法 | 判定标准 |
|---|---|---|
| 兑现强度 | 全文兑现 / 局部兑现 / 仅开局兑现 | 局部兑现的标签不能放主位 |
| 兑现频次 | 抽样 10 章，数兑现点 | 主标签每 3~5 章至少一次 |
| 兑现位置 | 前 3 章是否出现 | 主标签必须在前 3 章出现 |
| 兑现可指认 | 能否指出具体章节 | 指不出 = 虚挂 |

**三级兑现强度：**

- **A 级（全篇兑现）**：标签是这本书的结构，去掉它书就不成立。可以放主标签。
- **B 级（阶段兑现）**：标签只在某一卷/某一段成立。只能放辅助标签。
- **C 级（点缀兑现）**：只有个别桥段沾边。不该打。

**判定红线**：C 级标签一律删掉，它只会带来错误点击。

### 维度四：竞争维度（供需）

**要验证的**：这个标签下的供给密度和需求强度。

| 检查项 | 取证方法 | 判定标准 |
|---|---|---|
| 供给密度 | 按标签筛选，看作品总数 | 数量极大 = 红海，需要差异化 |
| 头部数据 | 看该标签前 20 名的数据分布 | 头部高、腰部空 = 赢家通吃 |
| 新旧程度 | 看近 12 个月新书占比 | 新书多 = 标签仍活跃 |
| 是否有标杆作品 | 该标签下是否有公认代表作 | 有标杆 = 读者预期明确，也意味着比较更严 |

**起点的公开标签页会直接显示每个标签下的作品数量**（如穿越、系统流、无敌流、诸天流、无限流各自的数量级差异很大），这是判断供给密度最直接的入口[1]。

**判定逻辑**：

- 供给极大 + 有标杆 → 红海，除非你有明确差异化，否则不要用主标签。
- 供给中等 + 增长中 → 最佳切入区。
- 供给极小 + 无标杆 → 可能是需求未被验证，也可能是需求不存在，需要用读者维度交叉验证。

### 维度五：商业维度（分发价值）

**要验证的**：这个标签能不能带来实际分发。

| 检查项 | 取证方法 | 判定标准 |
|---|---|---|
| 是否进入流量池 | 平台是否用它做一级/二级筛选 | 进入筛选 = 有分发价值 |
| 是否影响冷启动 | 新书期标签是否参与推荐匹配 | 参与 = 重要 |
| 是否影响转化 | 同书不同标签组合的点击/留存对比 | 有显著差异 = 有效 |

**平台机制的现实**：推荐系统会依据内容的类型与标签做匹配，标签是内容侧最主要的可计算特征之一；平台还会用互动率、完读率、订阅率等指标决定流量倾斜[3]。这意味着**标签决定你被推给谁，数据决定你还能不能被继续推**——标签错，第一批人就不对，数据一定难看。

**番茄的实操建议值得直接借用**：核心标签 1~2 个最精准（决定主推人群），辅助标签 2~3 个相关但稍宽（扩大曝光面），热点标签适度加[2]。

### 维度六：合规维度（安全性）

**要验证的**：这个标签是否敏感、是否需要弱化表述。

| 检查项 | 取证方法 | 判定标准 |
|---|---|---|
| 是否在平台禁限清单 | 查平台社区规范/审核规则 | 在清单 = 不打 |
| 是否需要弱化 | 同类作品如何表述 | 有更温和的同义词 = 换词 |
| 是否涉及真实人物/事件 | 标签是否指向现实对象 | 涉及 = 谨慎 |
| 是否涉及未成年人 | 标签是否暗示未成年恋爱等 | 涉及 = 不打 |

**判定红线**：合规是一票否决项，不参与打分。

### 横轴：时间维度（标签生命周期）

同一标签在不同时期的价值完全不同，必须放在时间轴上判断。

| 阶段 | 特征 | 策略 |
|---|---|---|
| **新兴期** | 新书少、读者好奇、无标杆 | 红利期，可作主标签，但要确认需求真实存在 |
| **主流期** | 供给大、有标杆、读者预期明确 | 需要差异化，标签作辅助，靠内容取胜 |
| **衰退期** | 新书减少、存量读者为主 | 可作辅助标签触达存量，不宜作主标签 |
| **回流期** | 因影视/短剧/新作带动重新升温 | 短期可用，注意别追在最高点 |

**判断方法**：看该标签下近 12 个月新书数量与前 20 名数据的变化趋势，而不是看单本爆款。

**近年的实例**：规则怪谈、第四天灾、迪化流这些标签已经进入主流平台的标签体系（晋江作品页可直接看到这些内容标签），说明它们已从圈层用语变成平台可识别的正式标签[4]。这类标签处在主流期，供给在增长，需要用差异化切入。

## 4. 标签成立的判定打分卡

把六个维度量化，每个 0~5 分，总分 30 分。合规维度作为否决项单独判定。

| 维度 | 0 分 | 3 分 | 5 分 |
|---|---|---|---|
| 平台可打性 | 平台无此标签 | 有，但在二级 | 一级筛选可见 |
| 读者可检索 | 读者不用这个词 | 部分读者用 | 搜索有联想词 |
| 文本可兑现 | 指不出兑现章节 | 阶段兑现 | 全篇结构级兑现 |
| 竞争健康度 | 红海且无差异 | 有竞争但有空间 | 供给中等且在增长 |
| 商业分发力 | 不参与推荐 | 参与长尾匹配 | 决定流量池归属 |
| 时间适配度 | 衰退期 | 主流期 | 新兴期且有真实需求 |

**判定规则：**

- **25 分以上**：可作主标签，放在最前。
- **18~24 分**：可作辅助标签。
- **18 分以下**：不打，或只作为描述性文字写在简介里。
- **合规不通过**：无论多少分，一律不打。

## 5. 标签组合规则

### 5.1 标准结构：1 + 3 + 2

```
1 个 L1（题材）      → 决定进哪个池子
3 个 L2/L3（设定/关系）→ 决定推给谁
2 个 L4（情绪风格）   → 决定阅读预期
```

**为什么是这个比例**：L1 太少会进错池子，L2/L3 太多会稀释精准度，L4 缺失会让读者无法判断"读起来是什么感觉"。

### 5.2 互斥标签表（同打会自相矛盾）

| 标签 A | 标签 B | 冲突原因 |
|---|---|---|
| 无CP | 甜宠 / 追妻火葬场 | 一个说没有感情线，一个说感情线是核心 |
| 1v1 | 后宫 / 多女主 | 关系结构互斥 |
| 双洁 | 带球跑（若涉及他人） | 需看具体设定，容易冲突 |
| 爽文 | 致郁 / 虐文 | 核心体验相反 |
| 慢热 | 快节奏 | 节奏承诺相反 |
| 无敌流 | 升级流 | 一个说开局最强，一个说持续变强 |
| 无CP | 万人迷（若为情感向） | 需明确万人迷是否含恋爱指向 |
| HE | BE / OE | 结局承诺互斥 |

**处理原则**：互斥标签不是绝对不能共存，但**必须有一个是"反套路"用法**，且要在简介里明确说明。否则读者会认为你挂羊头。

### 5.3 冗余标签表（同义只留一个）

| 冗余组 | 保留建议 |
|---|---|
| 无限流 / 无限游戏 / 副本流 | 保留平台作品数最多的那个 |
| 系统 / 系统流 | 同上 |
| 重生 / 重生之 | 保留"重生" |
| 穿越 / 穿越流 | 保留"穿越" |
| 甜宠 / 甜文 / 小甜饼 | 按平台可选范围保留一个 |
| 群像 / 群像剧 | 保留"群像" |
| 苟道流 / 苟住 / 稳健流 | 三者语义有差异，按正文实际选一个 |

### 5.4 堆砌阈值

| 标签数 | 判断 |
|---|---|
| 3~5 个 | 健康 |
| 6~7 个 | 偏多，检查是否有一个是 C 级兑现 |
| 8 个以上 | 定位不清，必须删到 5 个以内 |

## 6. 标签与正文不符的四种后果

标签虚挂不是"没什么影响"，它会以具体的数据形态反噬。

| 后果 | 数据表现 | 机制 |
|---|---|---|
| **错人群** | 点击率不低，但首章读完率低 | 标签把人推给了错误读者 |
| **错预期** | 前三章留存尚可，第一次大转折后暴跌 | 读者发现不是自己想看的那类 |
| **差评集中** | 评论区出现"挂羊头""被骗了" | 预期与内容落差 |
| **权重下滑** | 后续推荐量递减 | 低完读率拉低推荐权重 |

**这四种后果的共同点**：短期数据可能还行，长期一定伤书。因为平台最终看的是完读与追读，不是点击。

## 7. 实操流程：五步定标签

### 第一步：列候选（10~15 个）

从三个来源列：自己想打的、同类头部作品在用的、读者评论区高频出现的。

### 第二步：平台实测

逐个到目标平台搜索，记录：是否存在、在哪个层级、该标签下作品数量。

### 第三步：竞品抽样

每个候选标签，取前 20 名作品，记录：数据分布、是否有标杆、近 12 个月新书占比。

### 第四步：正文对照

抽样自己的 10 章，标注每个候选标签的兑现点。指不出兑现点的，直接删。

### 第五步：组合与 A/B

按 1+3+2 组合出两套方案，观察新书期的点击率、首章读完率、追读率。**以追读率为主要判据，不以点击率为准**。

## 8. 常见错误 20 条

| # | 错误 | 修法 |
|---|---|---|
| 1 | 标签堆到 8 个以上 | 删到 5 个以内 |
| 2 | 打了平台没有的标签 | 只用平台可选标签 |
| 3 | 用作者语言当标签 | 换成读者口语 |
| 4 | 主标签只在开局兑现 | 降为辅助标签 |
| 5 | 互斥标签同打且不解释 | 删一个，或在简介说明反套路 |
| 6 | 同义标签重复打 | 只留作品数最多的 |
| 7 | 只打 L1 不打 L2/L3 | 补 2~3 个精准标签 |
| 8 | 只打设定不打情绪 | 补 1~2 个 L4 |
| 9 | 追热点标签但正文没有 | 删，或补内容 |
| 10 | 照搬同类头部作品的标签 | 头部标签未必适合新书 |
| 11 | 忽略平台差异 | 每个平台单独定标签 |
| 12 | 标签与书名简介不一致 | 三者必须互相印证 |
| 13 | 打了"爽文"但前 10 章没有爽点 | 要么改内容，要么改标签 |
| 14 | 打了"群像"但只有主角有戏 | 降为"配角出彩"类描述 |
| 15 | 打了"双洁"但正文有前任亲密描写 | 删标签或改内容 |
| 16 | 打了"HE"但结局留白 | 改 OE |
| 17 | 打了"慢热"却在简介承诺快节奏 | 统一口径 |
| 18 | 标签半年不更新 | 每卷复盘一次 |
| 19 | 只在新书期定标签，后期不管 | 剧情转向时同步调整 |
| 20 | 用标签掩盖内容问题 | 标签只能精准分发，不能提升质量 |
