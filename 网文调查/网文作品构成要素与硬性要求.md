# 网文作品构成要素与硬性要求

> 对象：一本书在读者面前呈现的全部外部要素——书名、简介、标签、封面、开篇、章节标题、字数节奏、分卷、笔名、作者的话等。
> 逻辑：每个要素都对应一个转化环节，都有可验收的硬要求，不是"写好一点"这种模糊标准。
> 说明：文中范例均为演示用原创内容；平台的具体字数限制、封面尺寸、字段要求以开书当期规则为准。

---

## 0. 先看清一件事：读者是怎么一步步流失的

一本书从被看见到被追读，要过五道关，每一关由一个或几个要素负责。**要素写不好，不是"不够美"，是某一关的转化被卡住了。**

```
曝光 → 点击 → 首章读完 → 追读 → 付费/收藏
 │       │        │         │        │
封面    书名      开篇      章末钩子  整体质量
标签    简介      第一章    章节标题  更新稳定
分类    封面      前300字   分卷节奏
```

| 环节 | 负责要素 | 这一关失败的表现 | 这一关的判定指标 |
|---|---|---|---|
| 曝光→点击 | 封面、书名、标签 | 有曝光没点击 | 点击率 |
| 点击→首章读完 | 简介、第一章前 300 字 | 点了但三屏内退出 | 首章读完率 |
| 首章→追读 | 章末钩子、章节标题、更新节奏 | 读完第一章不再来 | 追读率 |
| 追读→付费 | 分卷结构、卷末高潮、整体质量 | 看到收费章就走 | 付费转化率 |
| 长期留存 | 更新稳定、作者的话、完本承诺 | 养书、弃书 | 留存曲线 |

**核心判断**：先定位是哪一关出了问题，再改对应要素。点击率低却去改简介，是典型的改错地方——简介影响的是"点了之后读不读"，不是"点不点"。

## 2. 书名：0.5 秒的判断题

### 2.1 三条硬标准

| 标准 | 具体要求 | 不合格的样子 |
|---|---|---|
| **可读性** | 一眼读顺，无生僻字，12 字以内 | 《玄天九幽万古至尊帝尊》——读不完也记不住 |
| **信息性** | 至少包含"身份/处境"或"冲突/金手指"之一 | 《岁月静好》——不知道写什么 |
| **差异性** | 同题材下不与头部作品撞结构 | 同类已有《我在XX当XX》，再写一个同结构就淹没 |

**12 字这条不是死规定，是移动端显示的现实**：列表页标题区通常只显示一行到两行，超出会被截断成"……"，读者看到的是残缺信息。

### 2.2 八种可复用的命名结构

| 结构 | 公式 | 范例 |
|---|---|---|
| **身份 + 行为** | 我在【地点】做【职业】 | 《我在殡仪馆值夜班》 |
| **处境 + 反差** | 【倒霉事】后，我【意外收获】 | 《被裁员那天，我继承了殡仪馆》 |
| **前提 + 后果** | 【穿越/重生】后我【做了某件不该做的事】 | 《重生后我嫁给了杀父仇人》 |
| **疑问式** | 谁/为什么/是不是 + 一个反常事实 | 《谁在替我活着》 |
| **数字式** | 【数字】+ 名词 | 《第十三个乘客》 |
| **规则式** | 【时间/条件】+ 禁令 | 《末班车最后一站不要下车》 |
| **称谓式** | 我的【某人】是【反常属性】 | 《我的房东是妖怪》 |
| **概念式** | 【抽象物】+ 职业化后缀 | 《记忆修补师》 |

### 2.3 平台差异

| 平台类型 | 偏好 | 原因 |
|---|---|---|
| 免费阅读平台 | 长、直白、冲突前置，常见"身份+事件"结构 | 读者在信息流里快速划过，需要一眼看懂 |
| 付费阅读平台 | 可略含蓄，允许意境与悬念 | 读者有主动搜索意图，愿意多花一秒理解 |
| 女频 | 关系与情绪词更有效（"嫁""宠""弃""归"） | 读者按情感结构筛选 |
| 男频 | 身份与能力词更有效（"我在""最强""签到"） | 读者按成长结构筛选 |

### 2.4 书名的五个禁忌

1. **生僻字**：读者念不出来，就不会向别人推荐。
2. **纯意境无信息**：《浮生若梦》——美，但不知道写什么。
3. **与热门作品高度相似**：会被当成跟风，也会被平台判定为混淆。
4. **含敏感词**：审核风险，也可能被限流。
5. **与内容不符**：书名承诺 A，正文写 B，是最快的差评来源。

### 2.5 检验方法（三秒钟能做完）

**念给一个人听，让他复述。** 如果他能说出"这是讲一个 XX 在 XX 的故事"，书名合格；如果他只记住几个字但说不出内容，重写。

## 3. 简介：把点击变成阅读

简介是全书性价比最高的 200 字。它要在 5 秒内完成三件事：让人知道这是什么书、让人想知道后面发生了什么、让人相信这本书能兑现。

### 3.1 四段式结构

| 段 | 作用 | 长度 | 写法 |
|---|---|---|---|
| **第一段：钩子** | 制造疑问或反差，决定读者是否继续看 | 1~2 句 | 反常识陈述、时间限定、对话、数字 |
| **第二段：设定** | 交代世界/身份/金手指 | 1~2 句 | 只给必要信息，不给体系 |
| **第三段：冲突** | 主角要面对什么，代价是什么 | 2~3 句 | 具体事件，不写抽象命运 |
| **第四段：承诺** | 读者能获得什么体验 | 1 句 | 一句有余味的话，不喊口号 |

### 3.2 完整范例

**合格版：**

> 在我们这儿，死人会留下一颗骨珠。
> 骨珠里是死者最后七天的记忆。
> 我是拾骨人，靠读骨破案为生。
> 但每读一次，我就要拿自己的一段记忆付账。
>
> 上个月我忘了我妈的名字。
> 昨天我忘了我妹妹爱吃什么。
> 今天有人送来一颗骨珠，里面是我自己的声音。
>
> 他说：别读我。

**为什么合格：**

- 第一行反常识，立刻建立"这个世界不一样"。
- 第二、三行给设定和身份，没有一句世界观解释。
- 第四行给出代价，这是全书的核心机制。
- 后面三行用递进的具体损失制造压迫感（妈的名字→妹妹爱吃什么→自己的声音）。
- 最后一句是钩子，也是一个具体的悬念。

**失败版（对照）：**

> 这是一个灵气复苏的世界，分为九大境界，主角林某，二十三岁，性格坚韧，身世成谜。他将在这个世界一步步成长，最终成为一代强者，谱写属于自己的传奇。

**为什么失败：**

- 第一句是世界观倾泻。
- 第二句是人物简历。
- 第三句是空洞承诺（"一步步成长""谱写传奇"）。
- 读完不知道这本书具体讲什么事，也不知道有什么不一样的。

### 3.3 五种高转化的开头句式

| 句式 | 结构 | 范例 |
|---|---|---|
| **反常识陈述** | 说一句与常识相反的话 | "在我们这儿，死人会留下一颗骨珠。" |
| **时间限定** | 给一个具体时刻 | "距离我被枪毙，还有四十分钟。" |
| **对话开场** | 直接甩一句台词 | ""你确定要打开这扇门？"" |
| **数字开场** | 用具体数字建立真实感 | "三十七个人进了那栋楼，出来的是三十六个。" |
| **疑问开场** | 用主角的疑问起手 | "如果一个人被所有人忘了，他还算活着吗？" |

### 3.4 简介的六个禁忌

| 禁忌 | 为什么不行 | 改法 |
|---|---|---|
| 世界观倾泻 | 读者还不关心世界 | 删到只剩"这个世界和我们的区别" |
| 人物履历 | 简历不是故事 | 拆到动作和对话里 |
| 形容词堆砌 | "惊天动地""绝世无双"没有信息 | 换成具体事件 |
| 剧透结局 | 知道结局就没有追读动力 | 只给前提和冲突 |
| 承诺不兑现 | 简介写甜宠，正文写虐 | 简介必须与正文同类型 |
| 照搬他人结构 | 会被认成跟风，也失去差异 | 换钩子、换第一行 |

### 3.5 三个版本都要准备

| 版本 | 用在哪 | 长度 | 要求 |
|---|---|---|---|
| **长版** | 详情页 | 150~300 字 | 四段式完整 |
| **短版** | 列表页摘要、推荐位 | 40~80 字 | 只保留钩子 + 核心冲突 |
| **一句话版** | 榜单、分享、书单 | 20 字内 | 一句话说清"谁+要什么+阻碍" |

**一句话版的公式**：`一个【身份】为了【目标】，必须【行动】，但【代价】。`

范例："一个靠读骨破案的拾骨人，每读一次就要拿自己的记忆付账，直到他读到自己的骨珠。"

## 4. 标签：精准分发的开关

标签的完整方法（384 个标签枚举、六维验证、组合规则）见《网文小说标签全枚举与确立条件》，这里只给必守的四条：

1. **3~5 个**：1 个题材 + 2~3 个设定关系 + 1~2 个情绪风格。
2. **只用平台可选的**：自造标签不产生分发。
3. **每个都能指出兑现章节**：指不出的删掉。
4. **与书名、简介、正文一致**：四者指向同一个承诺。

---

## 5. 封面：缩略图里的一秒钟

封面不是艺术品，是**缩略图**。它在列表页可能只有指甲盖大小。

### 5.1 三条硬要求

| 要求 | 检验方法 | 不合格的表现 |
|---|---|---|
| **主体清晰** | 缩到 100 像素宽还能看出是什么 | 元素太多，缩略后成一团 |
| **书名可读** | 缩略后仍能认出书名 | 字体过细、艺术字过度变形 |
| **风格匹配** | 与类型一致（悬疑要冷、甜宠要暖） | 甜宠用暗黑风，读者预期错位 |

### 5.2 五个禁忌

1. 盗用他人图片或素材（版权风险，平台会下架）。
2. 使用明星/真人肖像（肖像权风险）。
3. 血腥、惊悚过度（审核风险）。
4. 与内容完全不符（点击高、留存低）。
5. 文字过多（缩略后全糊）。

## 6. 开篇：前 300 字决定首章读完率

开篇的切入方法（五种基本型、37 个类型的具体切入点）见《小说切入点全类型枚举》，这里给三条转化要求：

| 要求 | 具体标准 | 检验方法 |
|---|---|---|
| **第一句有事** | 第一句就有一个动作、异常或问题 | 删掉第一句，看是否影响理解——影响就说明它有用 |
| **第一屏有麻烦** | 手机第一屏（约 300 字）内出现具体困境 | 数第一屏里有几件事在发生 |
| **前 300 字给类型信号** | 读者能判断这是甜宠/悬疑/玄幻 | 让一个没看过的人读 300 字，问他"这是什么类型" |

**一个反常识的判断**：开篇不需要"交代清楚"，需要"让人想往下看"。交代是后面几十章的事，开篇只负责建立"这个人遇到了麻烦，我想知道他怎么办"。

## 7. 章节标题：目录页的点击单位

很多作者忽略章节标题，但它出现在目录页，是读者决定"点哪一章"的直接依据，也是老读者回看的检索工具。

### 7.1 三种写法

| 写法 | 结构 | 范例 |
|---|---|---|
| **事件式** | 这一章发生了什么 | 《灵堂里的第二口棺材》 |
| **悬念式** | 抛出一个问题 | 《谁动了那碗饭》 |
| **结果式** | 直接给结果，制造反差 | 《我把他埋了》 |

### 7.2 四条要求

1. **8~15 字**：太短没信息，太长被截断。
2. **有具体名词**：具体名词比抽象词有效（"棺材"优于"危机"）。
3. **不剧透关键反转**：标题可以给结果，但不能给"是谁"。
4. **与内容一致**：标题承诺的事件必须在本章发生。

### 7.3 三个禁忌

- **无信息标题**：《第三章》《第三章 冲突》——浪费一次点击机会。
- **标题党**：标题写"她死了"，正文没死，读者会觉得被骗。
- **连续同构**：每章都是《第X章 XXX的XXX》，目录会失去辨识度。

## 8. 单章字数与更新节奏

### 8.1 字数

| 平台类型 | 常见单章字数 | 原因 |
|---|---|---|
| 免费阅读平台 | 1500~2500 字 | 信息流阅读，短章更容易读完 |
| 付费阅读平台 | 2500~3500 字 | 按章订阅，需要单章价值感 |
| 女频 | 2000~3000 字 | 情绪段落需要空间 |

**硬要求不是字数，是"一章一个完整场景"**：目标 → 阻碍 → 选择 → 结果 → 新问题。字数可以浮动，场景不能残缺。

### 8.2 更新节奏

| 项目 | 要求 | 原因 |
|---|---|---|
| 频率 | 稳定高于高频 | 读者会形成阅读习惯，断更一次就流失一批 |
| 时间 | 固定时段 | 培养追更生物钟 |
| 存稿 | 至少 10~15 天 | 应对突发，避免断更 |
| 爆更 | 关键节点（上架、卷末、推荐位） | 冲榜与转化 |

**一句实话**：稳定日更 4000 字写一年，比爆更十天然后断更一个月强得多。平台看的是持续供给能力。

## 9. 分卷与卷名

| 要求 | 标准 |
|---|---|
| 每卷章数 | 30~60 章（约 8~20 万字） |
| 卷名 | 有信息量，能看出这一卷的核心事件或地点 |
| 卷末 | 必须有不可逆变化（主角回不到卷首状态） |
| 卷首 | 用 1~2 章重新建立目标，不要让读者"忘了在追什么" |

**卷名的三种写法：**

- 地点式：《白露城》《归墟》
- 事件式：《空骨案》《第十三具无名骨》
- 状态式：《我忘了她的名字》

**禁忌**：卷名用"第一卷""第二卷"这种无信息命名，等于放弃一次向读者传达"这一卷有什么好看"的机会。

## 10. 其他必要要素

### 10.1 笔名

| 要求 | 说明 |
|---|---|
| 易记 | 2~4 个字最佳 |
| 易搜 | 不与知名作者高度相似，避免混淆 |
| 无歧义 | 不含生僻字、不含敏感词 |
| 可延续 | 想清楚能不能用五年 |

### 10.2 分类/频道

分类决定进哪个流量池，是**最高优先级**的要素。选错分类，后面所有优化都是在错误的池子里挣扎。

**判断方法**：看该分类下前 20 名作品，你的书是否与它们"放在一起不违和"。违和就说明选错了。

### 10.3 一句话简介 / 立意

部分平台把这两个作为必填字段，它们会进入审核与推荐系统，也会出现在某些展示位。

- **一句话简介**：20 字内说清"谁 + 要什么 + 阻碍"。
- **立意**：一句话说明这本书想表达什么，不要写成口号。

### 10.4 作者的话

| 该做 | 不该做 |
|---|---|
| 简短（3 行内） | 长篇大论讲创作理念 |
| 与本章有关的小互动 | 剧透后续剧情 |
| 感谢、求收藏（适度） | 反复诉苦、抱怨数据 |
| 固定位置 | 打断阅读节奏 |

### 10.5 作品相关 / 设定集

- 作用：给硬核读者查设定，也是世界观展示窗口。
- 要求：**不剧透**、条目不冗长、随剧情更新。
- 禁忌：把设定集当正文写，或者把关键反转写在设定里。

### 10.6 番外

- 作用：完本后留住读者、给下一本导流。
- 要求：独立可读，不依赖正文细节；长度 1~3 万字为宜。
- 常见类型：配角视角、平行结局、日常番外、前传。

### 10.7 完本感言

- 作用：把老读者转成下一本的读者。
- 三个必须：感谢具体的人、说清这本书想写什么、给出下一本的钩子。
- 禁忌：抱怨平台、抱怨读者、长篇总结剧情。

## 11. 五要素一致性检查（最容易被忽略，也最致命）

书名、封面、标签、简介、开篇，这五个要素必须指向**同一个承诺**。任何一个偏离，都会造成"高点击、低留存"。

| 检查项 | 问题 | 后果 |
|---|---|---|
| 书名 vs 简介 | 书名说悬疑，简介写甜宠 | 读者预期混乱 |
| 封面 vs 类型 | 封面是暗黑风，正文是轻松日常 | 点击的人不是目标读者 |
| 标签 vs 正文 | 打了"爽文"，前 10 章在铺垫 | 三章流失 |
| 简介 vs 第一章 | 简介写"开局即死局"，第一章在写起床 | 首章读完率崩 |
| 开篇 vs 类型承诺 | 标甜宠，开篇写凶杀 | 类型读者直接退出 |

**一致性检验方法（五分钟）**：把书名、封面、标签、简介、第一章前 300 字分别给一个没看过的人看，问他"这是什么类型的书，讲什么事"。五个人的回答如果一致，说明一致性合格；如果有分歧，找出分歧最大的那一项改。

## 12. 要素验收打分表

每个要素 0~5 分，低于 3 分必须重做。

| 要素 | 5 分标准 | 3 分标准 | 0 分标准 |
|---|---|---|---|
| 书名 | 12 字内、有信息、可复述 | 有信息但偏长 | 无信息或生僻 |
| 简介 | 首行有钩、四段完整、承诺具体 | 信息完整但无钩子 | 世界观倾泻或简历 |
| 标签 | 3~5 个、全可兑现、平台可选 | 有冗余或个别虚挂 | 堆砌或无标签 |
| 封面 | 缩略可辨、风格匹配 | 清晰但风格一般 | 糊、盗图、不符 |
| 开篇 | 第一句有事、300 字给类型信号 | 有事件但进入慢 | 世界观开场 |
| 章节标题 | 有具体名词、有信息 | 有信息但平淡 | 无信息 |
| 更新 | 稳定固定、有存稿 | 稳定但不固定 | 断更 |
| 分卷 | 卷名有信息、卷末有变化 | 有分卷但卷名平淡 | 无分卷或无变化 |

## 13. 常见错误 20 条

| # | 错误 | 修法 |
|---|---|---|
| 1 | 书名超过 15 字 | 砍到 12 字内，只留最有信息的部分 |
| 2 | 书名纯意境无信息 | 加"身份"或"事件" |
| 3 | 简介第一行写世界观 | 换成反常识陈述或对话 |
| 4 | 简介写成人物简历 | 拆到动作里 |
| 5 | 简介剧透结局 | 只给前提与冲突 |
| 6 | 简介与正文类型不符 | 改简介或改正文，二者必须统一 |
| 7 | 标签打 8 个 | 删到 5 个内 |
| 8 | 标签虚挂 | 指不出兑现章节就删 |
| 9 | 封面元素过多 | 缩略后能看清主体即可 |
| 10 | 封面盗图 | 换正版素材，避免下架 |
| 11 | 开篇先讲设定 | 从一个人遇到麻烦开始 |
| 12 | 第一句是天气 | 换成动作、异常或问题 |
| 13 | 章节标题无信息 | 用事件式或悬念式 |
| 14 | 章节标题剧透 | 给结果不给"是谁" |
| 15 | 单章没有完整场景 | 补齐目标-阻碍-选择-结果 |
| 16 | 更新不稳定 | 先存稿再开书 |
| 17 | 卷名用"第一卷" | 换成地点/事件/状态式 |
| 18 | 卷末没有变化 | 设计一个不可逆事件 |
| 19 | 作者的话剧透 | 只写与本章有关的互动 |
| 20 | 五要素各说各话 | 做一致性检查，统一到一个承诺 |

## 14. 交付前自检清单

- [ ] 书名 12 字内，念给别人能复述出"讲什么"。
- [ ] 书名与正文类型一致，没有挂羊头。
- [ ] 简介第一行有钩子，不是世界观。
- [ ] 简介四段完整：钩子、设定、冲突、承诺。
- [ ] 简介没有人物履历、形容词堆砌、结局剧透。
- [ ] 长版、短版、一句话版三个简介都写了。
- [ ] 标签 3~5 个，每个都能指出兑现章节。
- [ ] 封面缩略后主体与书名都清晰。
- [ ] 封面素材有版权，无真人肖像。
- [ ] 开篇第一句有事，前 300 字给类型信号。
- [ ] 章节标题 8~15 字，有具体名词，不剧透。
- [ ] 每章一个完整场景，字数在平台常见区间。
- [ ] 更新频率稳定、时间固定、有 10 天以上存稿。
- [ ] 分卷 30~60 章，卷名有信息，卷末有不可逆变化。
- [ ] 笔名易记易搜、无歧义。
- [ ] 分类选对，与同类前 20 名放在一起不违和。
- [ ] 一句话简介 20 字内说清"谁+要什么+阻碍"。
- [ ] 作者的话简短、不剧透、不诉苦。
- [ ] 书名、封面、标签、简介、开篇指向同一个承诺。
- [ ] 做过一致性检验：五个人对"这是什么书"的回答一致。
