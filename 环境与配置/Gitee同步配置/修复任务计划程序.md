#### 3.1 仓库路径改为绝对路径

**解决方法**：用 `[System.Text.Encoding]::UTF8` 重新保存脚本（带 BOM）。

## 自动同步机制（实时监控 + 定时兜底）

在修复原有任务的基础上，新增了自动同步机制：检测到仓库中有新增/修改的文件时，自动触发 git 同步。采用"实时监控 + 定时兜底"双重保障。

### 工作原理

```
文件变更 → [watch_and_sync.ps1 实时监控] → 立即同步（15秒检测间隔）
                                              ↓
                              [XinWenLianBo_Sync_30min 兜底] → 每30分钟同步
                                              ↓
                              [XinWenLianBo_Sync_0600 日终] → 每天6:00同步
```

### watch_and_sync.ps1 工作流程

1. 每 15 秒执行 `git status --porcelain` 检测是否有未提交的变更
2. 检测到变更后，等待 5 秒（debounce，等文件写入完成）
3. 执行 `git add -A` → `git commit` → `git pull` → `git push`
4. 同步完成后写入日志 `watch_sync.log`
5. 日志超过 1MB 自动轮转为 `.old.log`

### watch_and_sync.ps1 关键特性

- **锁文件防重复**：通过 `.watch_lock` 文件记录 PID，防止多实例同时运行
- **日志轮转**：日志超过 1MB 自动归档，防止无限增长
- **debounce 机制**：检测到变更后等 5 秒再同步，避免大量文件同时写入时频繁触发
- **UTF-8 BOM 编码**：兼容中文路径 `这是什么`

## 备用方案：FileSystemWatcher 监控（未启用）

脚本 `watch_and_sync_fsm.ps1` 已生成但**未创建任务计划程序**，作为备用方案存档。当 `git status` 轮询方案出现问题时，可切换到此方案。

### 两种方案对比

| 特性 | watch_and_sync.ps1（当前使用） | watch_and_sync_fsm.ps1（备用） |
|---|---|---|
| 检测方式 | `git status --porcelain` 轮询 | .NET FileSystemWatcher 事件驱动 |
| 检测延迟 | 最多 15 秒 | 几乎实时（事件触发） |
| 资源占用 | 每 15 秒执行一次 git 命令 | 事件回调，空闲时几乎零占用 |
| 可靠性 | 高（不依赖文件系统事件） | 中（网络驱动/某些场景可能丢失事件） |
| 文件类型过滤 | 检测所有变更（git 管理的所有文件） | 按扩展名过滤（.md/.py/.js/.json 等） |
| debounce | 5 秒 | 5 秒 |
| 日志文件 | watch_sync.log | watch_sync_fsm.log |
| 锁文件 | .watch_lock | .watch_fsm_lock |

### FileSystemWatcher 方案工作原理

```
文件创建/修改/删除/重命名
  → FileSystemWatcher 触发事件
  → 检查扩展名是否在监控列表中
  → 设置 syncPending = true，记录最后变更时间
  → 主循环每 2 秒检查一次
  → 距最后变更 ≥ 5 秒（debounce）→ 执行 git add/commit/pull/push
```

### 监控的文件扩展名

`.md` `.py` `.js` `.json` `.csv` `.txt` `.html` `.css` `.ps1` `.cmd` `.bat` `.vbs` `.yaml` `.yml` `.xml`

## 注意事项

1. **不要移动桌面文件夹中的脚本**：任务计划程序通过绝对路径引用，移动脚本会导致任务再次失败
2. **修改 .ps1 脚本时注意编码**：必须使用 UTF-8 BOM 编码保存，否则中文路径会乱码
3. **run_checkin.cmd 中的 `%~dp0`**：自动解析为脚本所在目录，无需修改
4. **Git remote**：仓库 `origin` 指向 `git@gitee.com:jk528528/test.git`，使用 SSH 协议
5. **XinWenLianBo_Watch 在登录时自动启动**：重启电脑后需登录一次才会启动监控进程
6. **watch_sync.log 会自动轮转**：超过 1MB 自动重命名为 `.old.log`，无需手动清理
7. **三层同步保障**：实时监控（15秒）→ 30分钟兜底 → 6:00日终，确保不漏同步
8. **备用方案未启用**：`watch_and_sync_fsm.ps1` 已生成但未绑定任务，需手动切换
