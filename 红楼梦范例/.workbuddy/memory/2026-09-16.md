- **WebView2 用 `downloadBootstrapper`**：切勿用 `embedBootstrapper` / `offlineInstaller`，否则安装包被塞进 100+ MB 运行时。
- **前端 `base: './'`**：WebView2 以 file:// 载入时资源路径必须相对。
- **jieba 瘦身不可逆的代价**：删 `analyse/` 后不得再调 `extract_tags` / `textrank`。
