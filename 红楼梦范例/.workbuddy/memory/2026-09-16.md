## 打包体积测算（单安装包能装多大）

**实测数据（非估算）**
- 工程本体合计 **27.88 MB**：分析结果 10.05 / skill 4.16 / 分词结果 3.05 / 红楼梦.txt 2.45 / 拆分 2.45 / 基础 1.82 / 分词结果_txt 1.53 / V3.3存档.zip 1.05 / 情感分析结果 0.79 / 脚本工具 0.25
- **jieba 安装后 40.97 MB**（本机默认 venv 实测）。大头：`lac_small/model_baseline/word_emb` 10.23 MB（可删）、`analyse/idf.txt` 5.91 MB（仅 TF-IDF 用）、`dict.txt` 4.84 MB（必需）、posseg/finalseg 概率表约 12 MB、各 `__pycache__` 约 4.2 MB（可删）。**精简后可压到约 20 MB。**
- Python 运行时：托管 3.13.12 整体 48.34 MB；裁剪后可到约 20 MB。
- wheel 实测：numpy 12.6 MB / pillow 7.2 MB（**仅词云需要**）、lxml 4.0 MB（python-docx 依赖）、networkx 2.1 MB、pydantic-core 2.1 MB、jieba 仅发 sdist 19.2 MB（无 wheel）。

**结论区间（安装包）**
| 形态 | 安装后 | 安装包 |
|---|---|---|
| A 精简离线版（S1–S3 + 网页界面 + Tauri 壳） | 88 MB | 约 37 MB（33–42） |
| B 推荐全功能（+LLM 调度+导出+关系图，Tauri） | 132 MB | 约 55 MB（50–63） |
| C B + 离线词云 | 158 MB | 约 66 MB |
| D 换 Electron 壳 | 326 MB | 约 137 MB |
| E B + 120 章全量示例数据 | 148 MB | 约 62 MB |
B 版若同步精简 jieba（-21 MB）→ 安装包约 47 MB。含本地大模型则另加 4–9 GB。

**省体积的三个杠杆（按收益排序）**
1. 用 ECharts 的 wordcloud 扩展替代 Python `wordcloud` → 省约 70 MB（去掉 numpy + pillow）
2. 精简 jieba（删 lac_small、idf.txt、__pycache__）→ 省约 21 MB
3. 壳用 Tauri 而非 Electron → 省约 194 MB（前提：目标机有 WebView2；Windows 10/11 通常自带）
