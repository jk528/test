## 四、分析硬性要求（务必从原文出发）

1. **事件接入清单(§二)**：按原文段落顺序拆分事件。一个事件 = 一个完整行动单元（起因→行动→结果），不同行动单元必须拆分为独立事件。事件总数 ≥ 章字数÷500（取整）；★核心事件 ≥ 5 个；◆关键事件 ≥ 4 个。段落索引精确到"第X段前/中/末"（同一段内多事件需区分位置）；判词/诗词/曲子按册/组独立编号。事件ID格式 `E{章号两位}-{序号两位}`（如第1章 E01-01）。附"段落索引规范"和"拆分排查机制"清单（勾选 [x]）。
2. **新闻六要素 A轨(§三)**：所有★核心事件必须逐条提取5W1H（时间/地点/新闻主体/事件/原因/方式），严格10列表。A轨条数 ≥ ★核心事件数 + 判词/曲子分组数。
3. **叙事六要素 B轨(§四)**：时空背景（时间层→空间层）、人物角色（标注★主角/◆重要配角/◇次要角色，保留全名）、核心情节（[主线] 20-40字概括）、冲突动机（人vs人/人vs社会/人vs自我/命运冲突/身份冲突）、叙事手法（叙事视角/叙事节奏/对比手法/修辞手法/寓言嵌套/章节定位六维度）、章节定位（起/承/转/合/伏笔/呼应/高潮）。
4. **人物基准六要素表(§4.2)**：每个出场人物一行，记录层级、出场次数、出场段落、核心行为、情感变化、对话占比、关系对象、行为动机、本章作用、状态标记（活跃/离世/缺席/初登场/出走）。
5. **冲突动机分析(§4.3)**：逐条拆解本章冲突（≥3重）。
6. **叙事手法六维度(§4.4)**：逐维度分析。

## 五、情感数据使用（禁止臆造，直接从 JSON 取数）

情感数据已由程序生成在 `情感分析结果/{章号}_emotion.json`，请直接取用：

- **§5.7 七类情绪分布(DUTIR)**：用 JSON 的 `dutir_好/乐/哀/怒/惧/恶/惊` 各字段的 count（词数）、pct（占比）、words（代表词汇），以及 `dutir_total/pos/neg/neu`；交叉验证用 `hownet_pos/neg/pos_pct/neg_pct`。情绪丰富度=7类中有词的类别数/7。主导情绪=词数最多的类别。正负情绪比=正面词数/负面词数（保留2位）。
- **§5.5 高频词汇TOP10**：用 JSON 的 `top_words` 数组前10条（word 词汇、count 频次）；"类型"列按词义判断：人名标"中性（人名）"，其余按情感倾向标"正面/负面/中性"。
- **§1.2 字数统计**：从文本文件名第2段数字读取（如 `001_06928_第1章...` → 6928字）。
