# 空白模板更新日志

---

## V3.3（2026-08-26）

**版本号**：V3.3 / 流程v1.9
**变更范围**：空白模板全面对齐实际报告结构，新增2个分析模块，删除3个可选章节

### 新增

| 变更项 | 说明 |
|--------|------|
| §4.4 叙事手法与章节定位 | 新增6维度叙事分析表（叙事视角/叙事节奏/对比手法/修辞手法/寓言嵌套/章节定位），每维度含分析列和说明列 |
| §5.3 情感趋势分析 | 新增段落区间情感曲线表（段落区间/情感状态/情感基调/关键事件），填补情感分析的时序维度空白 |
| §9.1 章节衔接建议 | 新增结构化衔接建议（悬念追踪/行为后续验证/感情线发展） |
| §9.2 伏笔追踪 | 新增伏笔追踪表（伏笔内容/类型/预计回收章节范围） |
| §9.3 跨章线索 | 新增跨章线索分析（承接关系/呼应关系/埋伏关系） |
| §8.3 情绪分析检测项 | 新增4项完整性检测（情绪分析完整度/冲突动机分析/叙事结构分析/情感趋势分析） |

### 修改

| 变更项 | 优化前 | 优化后 |
|---------|--------|--------|
| §4.3 | 冲突类型参考（2列简单参考表） | 冲突动机分析（5列详细分析表：序号/冲突类型/冲突描述/驱动角色/解决状态） |
| §4.4+§4.5 | 叙事手法详解 + 章节定位参考（2节分离） | 合并为"叙事手法与章节定位"（1节6维度） |
| §5.5 | 高频词汇TOP10（含虚词TOP10子节） | 高频词汇TOP10（实词）（删除虚词子节） |
| §5子节编号 | 5.1~5.6（6节） | 5.1~5.7（7节，5.3~5.6顺延为5.4~5.7） |
| §5.7子子节编号 | 5.6.1~5.6.3 | 5.7.1~5.7.3 |
| §8.3标题 | 完整性检测（三重指标） | 完整性检测（三重指标 + 情绪分析） |
| §8.5编号 | 两个§8.5（复测状态 + 检测日志，重复编号） | 仅保留§8.5 检测日志（删除复测状态） |
| §9结构 | 单一4列表格 | 3个子节结构（9.1+9.2+9.3） |
| 版本号 | V3.1 / v1.7 | V3.3 / v1.9 |

### 删除

| 变更项 | 说明 |
|---------|------|
| §十 可视化数据（可选） | 全章均为占位符，无实际数据，待图表工具支持后可重新添加 |
| §十一 版本差异记录（可选） | 全章均为占位符，绝大多数章节无显著版本差异 |
| 附录 CSV数据导出 | 全章均为占位符，无实际导出数据 |
| §5.5 虚词TOP10子节 | 实际报告中未使用，简化为仅实词TOP10 |
| §8.5 复测状态 | 实际报告中未使用，且与§8.5检测日志重复编号 |
