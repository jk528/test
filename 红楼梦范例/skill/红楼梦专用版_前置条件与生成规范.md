| `top_words` | array | 高频词`[{word,count}]` | §5.5 TOP10 |

#### 数据换算公式

| 报告字段 | 公式 | 示例 |
|---------|------|------|
| §5.1 正面占比 | `round(dutir_pos/dutir_total*100)` → `~整数%` | 134/238 → `~56%` |
| §5.1 负面占比 | `round(dutir_neg/dutir_total*100)` → `~整数%` | 97/238 → `~41%` |
| §5.7.2 正面词数 | `dutir_好.count + dutir_乐.count` | 105+29=134 |
| §5.7.2 负面词数 | `dutir_哀+n怒+惧+恶` 各count之和 | 28+2+2+65=97 |
| §5.7.2 正负比 | `正面/负面` 保留2位小数 | 134/97=1.38 |
| §5.7.2 主导情绪 | 词数最多类别 `情绪字(占比%)` | `好(44.1%)` |
| §5.7.2 丰富度 | `有词类别数/7` | `7/7` |
| §5.7.3 正面·极性 | `hownet_pos_pct` | `53.6%` |
| §5.7.3 正面·情绪 | `round(dutir_pos/dutir_total*100,1)` | `56.3%` |
| §5.7.3 负面·极性 | `hownet_neg_pct` | `46.4%` |
| §5.7.3 负面·情绪 | `round(dutir_neg/dutir_total*100,1)` | `40.8%` |

### 2.3 words 字段处理

JSON words 为 Python repr 字符串（`"'词1', '词2'"`），处理：去引号 → 逗号分隔 → 去单引号 → 取前5 → 中文逗号 `、` 连接。示例：`功德、亲友、洞悉、动人、雄壮`

### §五 情感词三维统计

#### §5.1 情感词分布总览

正面=`dutir_pos`（好+乐），负面=`dutir_neg`（哀+怒+惧+恶），中性=`dutir_neu`（惊），合计=`dutir_total`。占比 `~整数%`。代表词汇取 words 前5。

#### §5.2 情感基调判定

正面>40% → ✅正面主导；负面>40% → ✅负面主导；中性>60% → 中性主导

#### §5.3 情感趋势

按段落区间拆解3-6段情感曲线

#### §5.4 与前章对比

第N章列"第N-1章（基准）+第N章"，占比 `~整数%`。第1章用"—"占位。第N-1章数据从上一章 emotion.json 取。

#### §5.5 高频词汇TOP10

取 `top_words` 前10条。人名标"中性（人名）"。

#### §5.6 情感词处理记录

否定翻转/递进加权/一词多义/虚词排除均填"—"说明

#### §5.7 七类情绪分布（DUTIR）

**§5.7.1** 7类×(count/pct/words)，占比精确 `X.X%`（不加~）。代表词汇取 words 前5。

| 情绪 | 极性 | 词数 | 占比 | 代表词汇 |
|------|------|------|------|---------|
| 好（正面褒奖） | 正面 | dutir_好.count | dutir_好.pct% | words前5 |
| 乐（愉悦快乐） | 正面 | dutir_乐.count | dutir_乐.pct% | words前5 |
| 哀（悲伤痛苦） | 负面 | dutir_哀.count | dutir_哀.pct% | words前5 |
| 怒（愤怒憎恶） | 负面 | dutir_怒.count | dutir_怒.pct% | words前5 |
| 惧（恐惧害怕） | 负面 | dutir_惧.count | dutir_惧.pct% | words前5 |
| 恶（厌恶鄙视） | 负面 | dutir_恶.count | dutir_恶.pct% | words前5 |
| 惊（惊讶惊奇） | 中性 | dutir_惊.count | dutir_惊.pct% | words前5 |
| 合计 | — | dutir_total | 100% | — |

**§5.7.2** 正面=好+乐，负面=哀+怒+惧+恶，中性=惊；正负比保留2位小数；主导情绪 `情绪字(占比%)` 半角括号1位小数；丰富度=`有词类别数/7`

**§5.7.3** 极性(Hownet pos%/neg%) vs 情绪(DUTIR 好+乐%/哀+怒+惧+恶%)，差异≤15%一致，≤25%基本一致

### 12.1 分词脚本

```python
import os, json, jieba

SPLIT_DIR = r"红楼梦_拆分"
TOKENIZED_DIR = r"红楼梦_分词结果"
SEG_DICT_FILE = r"基础\红楼梦分词词典.txt"

jieba.load_userdict(SEG_DICT_FILE)
os.makedirs(TOKENIZED_DIR, exist_ok=True)

for fname in sorted(os.listdir(SPLIT_DIR)):
    if not fname.endswith('.txt'): continue
    chapter_num = fname[:3]
    with open(os.path.join(SPLIT_DIR, fname), 'r', encoding='utf-8') as f:
        text = f.read()
    words = list(jieba.cut(text, cut_all=False))
    with open(os.path.join(TOKENIZED_DIR, f"{chapter_num}.json"), 'w', encoding='utf-8') as f:
        json.dump(words, f, ensure_ascii=False)
```

### 12.2 情绪分析脚本

```python
import os, json, sys
from collections import Counter

sys.path.insert(0, r"基础")
from emotion_analysis import EmotionAnalyzer, SentimentAnalyzer

TOKENIZED_DIR = r"红楼梦_分词结果"
EMOTION_DIR = r"情感分析结果"
DICT_DIR = r"基础"

os.makedirs(EMOTION_DIR, exist_ok=True)
ea = EmotionAnalyzer(dict_dir=os.path.join(DICT_DIR, "情感词典_DUTIR"))
sa = SentimentAnalyzer(
    dict_dir=os.path.join(DICT_DIR, "情感词典_Hownet"),
    negation_file=os.path.join(DICT_DIR, "否定词.txt"),
    degree_file=os.path.join(DICT_DIR, "递进词.txt"))

stopwords = set()
with open(os.path.join(DICT_DIR, "停用词.txt"), 'r', encoding='utf-8') as f:
    stopwords = set(l.strip() for l in f if l.strip())
sw_dir = os.path.join(DICT_DIR, "停用词库")
if os.path.isdir(sw_dir):
    for swf in os.listdir(sw_dir):
        with open(os.path.join(sw_dir, swf), 'r', encoding='utf-8') as f:
            stopwords.update(l.strip() for l in f if l.strip())

for fname in sorted(os.listdir(TOKENIZED_DIR)):
    if not fname.endswith('.json') or 'emotion' in fname: continue
    chapter_num = fname[:3]
    with open(os.path.join(TOKENIZED_DIR, fname), 'r', encoding='utf-8') as f:
        data = json.load(f)
    words = [w for w in data if w and w not in stopwords]
    emo_result = ea.analyze_words(words)
    sent_result = sa.analyze_words(words)
    word_counts = Counter(w for w in words if w)
    top_words = [{"word": w, "count": c} for w, c in word_counts.most_common(30)]
    total = emo_result['total_emotion_words']
    output = {"chapter": chapter_num}
    for emo in ['好','乐','哀','怒','惧','恶','惊']:
        cnt = emo_result['emotion_counts'].get(emo, 0)
        output[f"dutir_{emo}"] = {
            "count": cnt,
            "pct": round(cnt / total * 100, 1) if total else 0,
            "words": str(emo_result['emotion_words'].get(emo, [])[:15])[1:-1]}
    output.update({
        "dutir_total": total,
        "dutir_pos": emo_result['positive_emotion_count'],
        "dutir_neg": emo_result['negative_emotion_count'],
        "dutir_neu": emo_result['neutral_emotion_count'],
        "hownet_pos": sent_result['pos_count'],
        "hownet_neg": sent_result['neg_count'],
        "hownet_pos_pct": sent_result['pos_percentage'],
        "hownet_neg_pct": sent_result['neg_percentage'],
        "hownet_total": sent_result['total_sentiment_words'],
        "hownet_pos_words": str(sent_result['pos_words'][:30])[1:-1],
        "hownet_neg_words": str(sent_result['neg_words'][:30])[1:-1],
        "top_words": top_words})
    with open(os.path.join(EMOTION_DIR, f"{chapter_num}_emotion.json"), 'w', encoding='utf-8') as f:
        json.dump(output, f, ensure_ascii=False, indent=2)
```

```python
import os, re, json, glob

OUTPUT_DIR = r"分析结果\V3.4存档_1-80章新建"

def validate_all_reports():
    """批量校验1-80章报告"""
    pass_count = 0
    fail_count = 0

    for ch in range(1, 81):
        ch_str = f"{ch:03d}"
        pattern = os.path.join(OUTPUT_DIR, f"{ch_str}_*_V34_分析报告.md")
        reports = glob.glob(pattern)

        if not reports:
            print(f"❌ 第{ch}章: 报告文件不存在")
            fail_count += 1
            continue

        report_path = reports[0]
        with open(report_path, 'r', encoding='utf-8') as f:
            report = f.read()

        issues = []

        # 1. 九大模块齐全
        for s in ['§一','§二','§三','§四','§五','§六','§七','§八','§九']:
            if s not in report:
                issues.append(f"缺{s}")

        # 2. 事件数量
        star = report.count('★')
        diamond = report.count('◆')
        if star < 5: issues.append(f"★={star}<5")
        if diamond < 4: issues.append(f"◆={diamond}<4")

        # 3. 情感数据一致性
        emo_path = os.path.join(EMOTION_DIR, f"{ch_str}_emotion.json")
        if os.path.exists(emo_path):
            with open(emo_path, 'r', encoding='utf-8') as f:
                emo = json.load(f)
            if str(emo['dutir_total']) not in report:
                issues.append(f"dutir_total={emo['dutir_total']}未出现")
        else:
            issues.append("emotion.json不存在")

        # 4. 格式检查
        if '~' not in report:
            issues.append("缺~约数格式(§5.1)")
        if not re.search(r'\d+\.\d%', report):
            issues.append("缺X.X%精确格式(§5.7)")

        # 5. 报告底部
        if '报告版本' not in report:
            issues.append("缺报告底部版本声明")

        if issues:
            print(f"⚠️ 第{ch}章: {'; '.join(issues)}")
            fail_count += 1
        else:
            print(f"✅ 第{ch}章: ★{star} ◆{diamond} 通过")
            pass_count += 1

    print(f"\n=== 汇总 ===")
```

```python
import os, re

SPLIT_DIR = r"红楼梦_拆分"

def extract_abbreviations():
    """从原文文件名自动提取章节简称（回目前半句）"""
    abbreviations = {}
    for fname in sorted(os.listdir(SPLIT_DIR)):
        if not fname.endswith('.txt'): continue
        ch_num = fname[:3]
        # 文件名格式: 001_6928_第1章　甄士隐梦幻识通灵　贾雨村风尘怀闺秀.txt
        # 提取标题部分
        parts = fname.replace('.txt', '').split('_')
        if len(parts) >= 3:
            title = parts[2]  # 第1章　甄士隐梦幻识通灵　贾雨村风尘怀闺秀
            # 去掉"第X章"前缀
            title = re.sub(r'^第\d+章\s*', '', title)
            # 按全角空格分两半，取前半
            halves = title.split('　')
            abbrev = halves[0].strip() if halves else title.strip()
            abbreviations[ch_num] = abbrev

    # 输出对照表
    print("| 章号 | 简称 |")
    print("|------|------|")
    for ch, abbrev in sorted(abbreviations.items()):
        print(f"| {ch} | {abbrev} |")

    return abbreviations
```

```python
"""

运行前提：红楼梦_拆分/ 目录已存在按章txt文件

from collections import Counter

PROJECT_ROOT = r"c:\Users\Administrator\Documents\这是什么\JK-temp\红楼梦范例"

print("步骤1：jieba 分词")
print("=" * 50)

import jieba
jieba.load_userdict(SEG_DICT)
os.makedirs(TOKENIZED_DIR, exist_ok=True)

for fname in sorted(os.listdir(SPLIT_DIR)):
    if not fname.endswith('.txt'): continue
    ch = fname[:3]
    with open(os.path.join(SPLIT_DIR, fname), 'r', encoding='utf-8') as f:
        text = f.read()
    words = list(jieba.cut(text, cut_all=False))
    with open(os.path.join(TOKENIZED_DIR, f"{ch}.json"), 'w', encoding='utf-8') as f:
        json.dump(words, f, ensure_ascii=False)
    print(f"  {ch}: {len(words)}词")

# ============ 步骤2：情绪分析 ============
print("\n" + "=" * 50)
print("步骤2：情绪分析（DUTIR + Hownet）")
print("=" * 50)

sys.path.insert(0, DICT_DIR)
from emotion_analysis import EmotionAnalyzer, SentimentAnalyzer

ea = EmotionAnalyzer(dict_dir=os.path.join(DICT_DIR, "情感词典_DUTIR"))
sa = SentimentAnalyzer(
    dict_dir=os.path.join(DICT_DIR, "情感词典_Hownet"),
    negation_file=os.path.join(DICT_DIR, "否定词.txt"),
    degree_file=os.path.join(DICT_DIR, "递进词.txt"))

# 停用词

with open(os.path.join(DICT_DIR, "停用词.txt"), 'r', encoding='utf-8') as f:
    stopwords = set(l.strip() for l in f if l.strip())
sw_dir = os.path.join(DICT_DIR, "停用词库")
if os.path.isdir(sw_dir):
    for swf in os.listdir(sw_dir):
        with open(os.path.join(sw_dir, swf), 'r', encoding='utf-8') as f:
            stopwords.update(l.strip() for l in f if l.strip())

os.makedirs(EMOTION_DIR, exist_ok=True)

for fname in sorted(os.listdir(TOKENIZED_DIR)):
    if not fname.endswith('.json') or 'emotion' in fname: continue
    ch = fname[:3]
    with open(os.path.join(TOKENIZED_DIR, fname), 'r', encoding='utf-8') as f:
        words = [w for w in json.load(f) if w and w not in stopwords]

    emo = ea.analyze_words(words)
    sent = sa.analyze_words(words)
    wc = Counter(w for w in words if w)
    total = emo['total_emotion_words']

    output = {"chapter": ch}
    for e in ['好','乐','哀','怒','惧','恶','惊']:

    with open(os.path.join(EMOTION_DIR, f"{ch}_emotion.json"), 'w', encoding='utf-8') as f:

    print(f"  {ch}: total={total} pos={emo['positive_emotion_count']} neg={emo['negative_emotion_count']}")

print(f"  情绪JSON: {EMOTION_DIR}")
print(f"\n下一步：用模型调用前置条件文档生成分析报告")
```

### 15.5 注册表更新脚本

```python
import json, re, os

REGISTRY_PATH = r"分析结果\V3.4存档_1-80章新建\foreshadow_registry.json"
OUTPUT_DIR = r"分析结果\V3.4存档_1-80章新建"

def update_registry_from_report(chapter_num):
    """从第N章报告中提取伏笔信息并更新注册表"""
    ch_str = f"{chapter_num:03d}"

    # 1. 读取当前注册表
    if os.path.exists(REGISTRY_PATH):
        with open(REGISTRY_PATH, 'r', encoding='utf-8') as f:
            registry = json.load(f)
    else:
        registry = {"last_updated_chapter": "", "total_foreshadowing": 0, "items": []}

    # 2. 定位报告文件
    import glob
    pattern = os.path.join(OUTPUT_DIR, f"{ch_str}_*_V34_分析报告.md")
    reports = glob.glob(pattern)
    if not reports:
        print(f"第{chapter_num}章报告不存在")
        return registry

    with open(reports[0], 'r', encoding='utf-8') as f:
        report = f.read()

    # 3. 提取§6.2伏笔追踪表
    # 匹配表格行格式：| F01-01 | ... |
    foreshadow_pattern = r'\|F(\d{2})-(\d{2})\|([^|]+)\|([^|]+)\|([^|]+)\|([^|]+)\|'
    matches = re.findall(foreshadow_pattern, report)

    new_count = 0
    updated_count = 0

    for match in matches:
        f_ch, f_seq, content, f_type, characters, echo = match
        f_id = f"F{f_ch}-{f_seq}"
        content = content.strip()
        f_type = f_type.strip()
        characters = [c.strip() for c in characters.split('/')]
        echo = echo.strip()

        # 判断状态
        if echo == '—' or echo == '':
            status = '未呼应'
            echoed_chapters = []
        elif '部分' in echo:
            status = '部分'
            echoed_chapters = [echo]
        else:
            status = '已呼应'
            echoed_chapters = [echo]

        # 查找是否已存在
        existing = None
        for item in registry["items"]:
            if item["id"] == f_id:
                existing = item
                break

        if existing:
            # 更新已有条目
            existing["echoed_chapters"] = echoed_chapters
            existing["status"] = status
            updated_count += 1
        else:
            # 新增条目
            registry["items"].append({
                "id": f_id,
                "first_chapter": f"第{int(f_ch)}章",
                "content": content,
                "type": f_type,
                "characters": characters,
                "echoed_chapters": echoed_chapters,
                "status": status
            })
            new_count += 1

    registry["last_updated_chapter"] = f"第{chapter_num}章"
    registry["total_foreshadowing"] = len(registry["items"])

    # 4. 写回注册表
    with open(REGISTRY_PATH, 'w', encoding='utf-8') as f:
        json.dump(registry, f, ensure_ascii=False, indent=2)

    print(f"第{chapter_num}章: 新增{new_count}条伏笔, 更新{updated_count}条")
    return registry

# 批量更新（按章顺序执行）
for ch in range(1, 81):
    update_registry_from_report(ch)

print(f"\n✅ 伏笔注册表更新完成")
print(f"  总伏笔数: {registry['total_foreshadowing']}")
print(f"  最后更新: {registry['last_updated_chapter']}")
```

```python
# 场景：第6章报告已生成，需更新注册表
# 假设第6章报告中§6.2写入了以下伏笔：
```

### 15.10 注册表查询与筛选函数

```python
import json

REGISTRY_PATH = r"分析结果\V3.4存档_1-80章新建\foreshadow_registry.json"

def load_registry():
    with open(REGISTRY_PATH, 'r', encoding='utf-8') as f:
        return json.load(f)

def get_by_status(status="未呼应"):
    """按状态筛选伏笔"""
    reg = load_registry()
    return [i for i in reg["items"] if i["status"] == status]

def get_by_chapter(chapter_num):
    """筛选涉及指定章节的伏笔（首现或呼应）"""
    ch_str = f"第{chapter_num}章"
    reg = load_registry()
    results = []
    for item in reg["items"]:
        if item["first_chapter"] == ch_str:
            results.append(("首现", item))
        if ch_str in item.get("echoed_chapters", []):
            results.append(("呼应", item))
    return results

def get_by_character(name):
    """按人物筛选伏笔"""
    reg = load_registry()
    return [i for i in reg["items"] if name in i["characters"]]

def get_pending_for_chapter(chapter_num):
    """获取第N章需要追踪的伏笔（未呼应+部分状态的）"""
    reg = load_registry()
    return [i for i in reg["items"] if i["status"] in ("未呼应", "部分")]

def format_for_prompt(chapter_num):
    """格式化为模型Prompt可用的文本"""
    pending = get_pending_for_chapter(chapter_num)
    relevant = get_by_chapter(chapter_num)

    lines = [f"## 伏笔追踪输入（第{chapter_num}章）"]
    lines.append(f"注册表最后更新: {load_registry()['last_updated_chapter']}")
    lines.append(f"待追踪伏笔: {len(pending)}条\n")

    if relevant:
        lines.append("### 本章相关伏笔")
        for role, item in relevant:
            lines.append(f"- [{role}] {item['id']} {item['content']} ({item['status']})")

    if pending:
        lines.append(f"\n### 待追踪（未呼应+部分，共{len(pending)}条）")
        for item in pending[:20]:  # 最多注入20条避免Prompt过长
            lines.append(f"- {item['id']} | {item['first_chapter']} | {item['content']} | {item['status']}")

    return '\n'.join(lines)
```

### 15.11 批处理管线集成（完整流程）

```python
"""
红楼梦80章伏笔追踪完整管线
运行顺序：生成报告 → 更新注册表 → 注入下一章
"""

import json, re, os, glob

REGISTRY_PATH = r"分析结果\V3.4存档_1-80章新建\foreshadow_registry.json"
OUTPUT_DIR = r"分析结果\V3.4存档_1-80章新建"

def full_pipeline(start=1, end=80):
    """完整管线：按章顺序更新注册表"""

    # 步骤0：确保注册表存在
    if not os.path.exists(REGISTRY_PATH):
        init_registry()  # 调用15.8的初始化函数

    stats = {"chapters_processed": 0, "new_foreshadowing": 0, "updated_foreshadowing": 0, "skipped": 0}

    for ch in range(start, end + 1):
        ch_str = f"{ch:03d}"
        pattern = os.path.join(OUTPUT_DIR, f"{ch_str}_*_V34_分析报告.md")
        reports = glob.glob(pattern)

        if not reports:
            print(f"⏭️ 第{ch}章: 报告未生成，跳过")
            stats["skipped"] += 1
            continue

        if os.path.getsize(reports[0]) < 1000:
            print(f"⏭️ 第{ch}章: 报告不完整，跳过")
            stats["skipped"] += 1
            continue

        # 读取注册表
        with open(REGISTRY_PATH, 'r', encoding='utf-8') as f:
            registry = json.load(f)

        # 读取报告
        with open(reports[0], 'r', encoding='utf-8') as f:
            report = f.read()

        # 提取伏笔
        foreshadow_pattern = r'\|(F\d{2}-\d{2})\|([^|]*)\|([^|]*)\|([^|]*)\|([^|]*)\|([^|]*)\|'
        matches = re.findall(foreshadow_pattern, report)

        new_count = 0
        update_count = 0

        for fid, first_ch, content, ftype, chars, echo in matches:
            content = content.strip()
            ftype = ftype.strip()
            chars = [c.strip() for c in chars.split('、')]
            echo = echo.strip()

            status = '未呼应' if (echo == '—' or not echo) else ('部分' if '部分' in echo else '已呼应')
            echoed = [] if status == '未呼应' else [echo]

            existing = next((i for i in registry["items"] if i["id"] == fid), None)
            if existing:
                if existing["status"] != status:
                    old = existing["status"]
                    existing["status"] = status
                    existing["echoed_chapters"] = echoed
                    update_count += 1
            else:
                registry["items"].append({
                    "id": fid, "first_chapter": first_ch.strip() or f"第{ch}章",
                    "content": content, "type": ftype, "characters": chars,
                    "echoed_chapters": echoed, "status": status})
                new_count += 1

        registry["last_updated_chapter"] = f"第{ch}章"
        registry["total_foreshadowing"] = len(registry["items"])

        with open(REGISTRY_PATH, 'w', encoding='utf-8') as f:
            json.dump(registry, f, ensure_ascii=False, indent=2)

        stats["chapters_processed"] += 1
        stats["new_foreshadowing"] += new_count
        stats["updated_foreshadowing"] += update_count
        print(f"✅ 第{ch}章: +{new_count}新 ~{update_count}更 (总{registry['total_foreshadowing']}条)")

    # 汇总
    print(f"\n{'='*50}")
    print(f"伏笔追踪管线完成")
    print(f"  处理章节: {stats['chapters_processed']}")
    print(f"  跳过: {stats['skipped']}")
    print(f"  新增伏笔: {stats['new_foreshadowing']}")
    print(f"  更新伏笔: {stats['updated_foreshadowing']}")

    # 状态分布
    reg = json.load(open(REGISTRY_PATH, 'r', encoding='utf-8'))
    status_dist = {}
    for item in reg["items"]:
        status_dist[item["status"]] = status_dist.get(item["status"], 0) + 1
    print(f"  伏笔状态分布: {status_dist}")

full_pipeline(1, 80)
```
