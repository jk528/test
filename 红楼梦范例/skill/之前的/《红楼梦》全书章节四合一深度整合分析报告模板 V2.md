## 2. 标准化词汇库与判定标准

### 2.1 情感词汇判定标准

| 类别                | 定义                        | 示例词汇                          |
| :---------------- | :------------------------ | :---------------------------- |
| **正意词（Positive）** | 美好、善良、愉悦、赞赏、和谐等积极情感或状态    | 聪明、灵慧、贤淑、荣耀、富贵、繁华、妙极、可贺、安稳、团圆 |
| **反意词（Negative）** | 恐惧、邪恶、愤怒、欺骗、冲突、悲伤等消极情感或状态 | 悲哀、凄凉、恐惧、欺骗、冲突、妒忌、冷笑、欺瞒、不轨、持戈 |
| **中性词（Neutral）**  | 无明显情感色彩或需结合语境判断的词汇        | 行走、说话、看见、听见、房屋、衣服、饮食、日常动作描述   |

### 2.2 中性词二次分类（V2.0 新增）

|     子类别    | 说明           | 示例        |
| :--------: | :----------- | :-------- |
| **偏正性中性词** | 语境中倾向积极的中性描述 | 精心、细致、隆重  |
| **偏反性中性词** | 语境中倾向消极的中性描述 | 匆忙、勉强、不得已 |
|  **纯中性词**  | 完全无情感色彩的客观描述 | 是、有、在、了、的 |
