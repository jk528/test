# 小说章节六要素分析器

## 功能概述

从小说章节文本中提取叙事六要素，输出结构化 Markdown 表格。支持单章分析、多章批量对比，内置人物关系梳理、冲突识别、章节结构定位等小说专项分析。

## 六要素定义

| 要素 | 新闻对应 | 说明 | 提取要点 |
|------|---------|------|---------|
| 时空背景 | 时间+地点 | 故事发生的时间与空间 | 时代、季节、时段；具体场景及其氛围 |
| 人物角色 | 新闻主体 | 本章出场角色及身份 | 保留原名；标注主角/配角/路人；注明角色关系 |
| 核心情节 | 事件 | 本章主要事件 | 一句话概括；区分主线/支线 |
| 冲突动机 | 原因 | 矛盾冲突与角色动机 | 冲突类型；驱动角色行动的内在/外在原因 |
| 叙事手法 | 方式 | 叙事视角与表现技巧 | 人称、视角、节奏、修辞手法 |
| 章节定位 | — | 本章在全书结构中的作用 | 起/承/转/合；伏笔/呼应/高潮/过渡 |

## 使用流程

### 步骤一：识别章节信息

1. 读取输入文本
2. 提取章节标题/编号（如"第12回"、"Chapter 5"）
3. 若文本含多个章节，逐章识别并编号
4. 若为单章，直接进入提取流程

### 步骤二：逐章提取六要素

#### 时空背景

- **时间层**：时代背景（如"清末"、"未来纪元"）→ 季节 → 具体日期/时段（如"深秋黄昏"）
- **空间层**：大场景（如"京城"）→ 具体场所（如"贾府正堂"）→ 空间氛围（如"肃穆"、"喧闹"）
- 多场景用箭头串联（如"贾府正堂 → 大观园 → 怡红院"）
- 虚构世界观需标注设定名称（如"中土世界"、"修仙界"）

#### 人物角色

- **保留人物全名**，不做脱敏（小说人物为虚构角色）
- 标注角色层级：

| 标记 | 含义 | 说明 |
|------|------|------|
| ★ | 主角 | 本章核心视角或行动角色 |
| ◆ | 重要配角 | 有台词或关键行为的角色 |
| ◇ | 次要角色 | 提及但无实质互动的角色 |

- 角色格式：`★ 角色名（身份/关系）`
- 多角色用分号分隔
- 新出场角色标注"[初登场]"
- 示例：`★ 林黛玉（贾母外孙女）[初登场]；◆ 贾宝玉（衔玉公子）`

#### 核心情节

- 一句话概括本章核心事件（20-40字）
- 区分主线/支线：`[主线] xxx` 或 `[支线] xxx`
- 多事件用序号列出（最多3条）
- 概括格式：`谁 + 在哪里 + 做了什么 + 结果如何`

#### 冲突动机

- **冲突类型**：

| 类型 | 说明 | 示例 |
|------|------|------|
| 人vs人 | 角色间对立 | 两个家族的世仇 |
| 人vs社会 | 个人与体制/规则冲突 | 叛逆者对抗礼教 |
| 人vs自然 | 与自然环境抗争 | 荒野求生 |
| 人vs自我 | 内心矛盾 | 道德抉择、情感挣扎 |
| 命运冲突 | 与宿命对抗 | 挣脱预言的束缚 |

- **动机**：驱动角色行动的内在欲望或外在压力
- 格式：`[冲突类型] 冲突描述；动机：xxx`

#### 叙事手法

- **叙事视角**：

| 视角 | 标记 | 说明 |
|------|------|------|
| 第一人称 | 第一人称 | "我"视角，限知 |
| 第三人称限知 | 第三人称·限知 | 跟随单一角色视角 |
| 第三人称全知 | 第三人称·全知 | 上帝视角，可窥探所有角色内心 |
| 多视角切换 | 多视角 | 章内切换不同角色视角 |

- **节奏**：快（密集事件）/ 中（匀速推进）/ 慢（铺垫/描写）
- **修辞手法**：列出本章突出的修辞（如"象征"、"伏笔"、"倒叙"、"白描"）
- 格式：`视角 | 节奏 | 修辞手法`

#### 章节定位

- **结构功能**：

| 功能 | 标记 | 说明 |
|------|------|------|
| 起 | 开篇 | 引入新人物/新设定/新环境 |
| 承 | 发展 | 推进已有情节，深化关系 |
| 转 | 转折 | 剧情反转、冲突激化、真相揭露 |
| 合 | 收束 | 解决冲突、阶段性总结 |
| 伏笔 | 埋线 | 为后续情节埋下线索 |
| 呼应 | 照应 | 回应前文伏笔 |
| 高潮 | 爆发 | 全书或本卷情感/冲突最高点 |

- 格式：`[功能标记] 一句话说明本章在全书中的作用`

### 步骤三：人物关系梳理

提取本章中角色间的关系，输出关系表：

```markdown
### 人物关系

| 角色A | 关系 | 角色B | 本章互动 |
|-------|------|-------|---------|
| 林黛玉 | 祖孙 | 贾母 | 黛玉初进贾府，贾母搂入怀中泣 |
| 林黛玉 | 表姐弟 | 贾宝玉 | 初次见面，似曾相识 |
```

### 步骤四：输出表格

#### 单章分析输出格式

```markdown
## 第X章 六要素分析

### 六要素总表

| 要素 | 内容 |
|------|------|
| 时空背景 | "时间层 → 空间层" |
| 人物角色 | "★ 主角（身份）；◆ 配角（身份）" |
| 核心情节 | "[主线] 一句话概括" |
| 冲突动机 | "[冲突类型] 描述；动机：xxx" |
| 叙事手法 | "视角 | 节奏 | 修辞" |
| 章节定位 | "[功能标记] 结构作用说明" |

### 人物关系

| 角色A | 关系 | 角色B | 本章互动 |
|-------|------|-------|---------|
| ... | ... | ... | ... |
```

#### 多章对比输出格式

```markdown
## 多章六要素对比

| 章 | 时空背景 | 人物角色 | 核心情节 | 冲突动机 | 叙事手法 | 章节定位 |
|----|---------|---------|---------|---------|---------|---------|
| 第1回 | "..." | "..." | "..." | "..." | "..." | "[起] ..." |
| 第2回 | "..." | "..." | "..." | "..." | "..." | "[承] ..." |
| ... | ... | ... | ... | ... | ... | ... |
```

#### 线索追踪表（可选，多章分析时附加）

```markdown
### 伏笔与线索追踪

| 章回 | 线索内容 | 类型 | 状态 |
|------|---------|------|------|
| 第1回 | 甄士隐梦中见通灵宝玉 | 伏笔 | 第3回呼应 |
| 第5回 | 贾宝玉梦游太虚幻境 | 伏笔 | 未呼应 |
```

类型：伏笔 / 呼应 / 悬念 / 暗线
状态：已呼应 / 未呼应 / 部分呼应

### 步骤五：章节简评（可选）

在表格下方附加50-100字的章节简评，涵盖：
- 本章叙事亮点
- 人物塑造特点
- 结构编排评价
- 与前后章的衔接

## 特殊情况处理

### 章节信息不完整
- 文本截断或内容缺失时，已提取的要素正常输出，缺失要素填"—"
- 在表格下方标注"⚠ 本章文本可能不完整，部分要素未能提取"

### 纯描写/抒情章节
- 无明确情节推进的章节（如环境描写、心理独白）：
  - 核心情节填"[铺垫] 场景描写/心理刻画"
  - 冲突动机填"—"或"[人vs自我] 内心感悟"
  - 章节定位通常为[承]或[伏笔]

### 多线叙事章节
- 章内含多条故事线时，核心情节分行列出：
  ```
  [主线·A线] xxx
  [支线·B线] xxx
  ```
- 人物角色按故事线分组标注

### 群像章节
- 出场角色超过5人时，仅列出★和◆角色，其余归为"◇ 若干次要角色"
- 人物关系表聚焦关键互动

## 使用示例

**输入文本**（节选自《红楼梦》第三回）：
```
林黛玉初进贾府，拜见外祖母贾母。众人见黛玉年貌虽小，其举止言谈不俗，身体面庞虽怯弱不胜，却有一段自然的风流态度。贾母搂黛玉入怀，心肝儿肉叫着大哭起来。随后黛玉依次拜见大舅母邢夫人、二舅母王夫人、李纨等人。最后王熙凤出场，未见其人先闻其声...
```

**输出**：

### 六要素总表

| 要素 | 内容 |
|------|------|
| 时空背景 | "清末 → 京城贾府；当日 → 贾母正堂，气氛由悲转喜" |
| 人物角色 | "★ 林黛玉（贾母外孙女）[初登场]；◆ 贾母（史太君）；◆ 王熙凤（琏二奶奶）[初登场]；◆ 邢夫人（大舅母）；◆ 王夫人（二舅母）；◆ 李纨（珠大嫂子）；◇ 贾宝玉（衔玉公子）" |
| 核心情节 | "[主线] 林黛玉初进贾府，拜见贾母及众女眷，王熙凤高调出场" |
| 冲突动机 | "[人vs社会] 孤女寄人篱下的谨慎与不安；动机：黛玉寻求庇护，贾母怜惜亡女之女" |
| 叙事手法 | "第三人称·限知（黛玉视角）| 中速 | 白描、未见其人先闻其声" |
| 章节定位 | "[起] 核心角色集结，奠定贾府人际关系基本格局" |

### 人物关系

| 角色A | 关系 | 角色B | 本章互动 |
|-------|------|-------|---------|
| 林黛玉 | 祖孙 | 贾母 | 黛玉拜见，贾母搂怀泣 |
| 林黛玉 | 表姐弟 | 贾宝玉 | 末尾初见，似曾相识 |
| 林黛玉 | 嫂侄 | 王熙凤 | 凤姐高调出场，寒暄招待 |

## 注意事项

1. **保留原名**：小说人物为虚构角色，保留全名，不做脱敏处理
2. **不臆造**：仅从文本中提取明确存在的信息，缺失要素填"—"
3. **视角敏感**：注意区分叙述者视角和角色视角，叙事手法中标注的是叙述视角
4. **结构意识**：章节定位需考虑全书结构，单章分析时可注明"需结合上下文确认"
5. **简洁准确**：表格单元格内容控制在50字以内，过长内容拆分或精简
6. **语言一致**：输出语言与输入文本语言保持一致
7. **批量处理**：多章分析时按章节顺序编号，独立提取每章六要素后输出对比表
