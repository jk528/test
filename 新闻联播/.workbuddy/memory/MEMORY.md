# 项目长期记忆 —— 新闻联播总结报告

## 现行生成流程（唯一入口）
```
python 流程/一键生成/xwlb_report.py [YYYYMMDD]     # 默认昨天
    --force      强制覆盖已存在报告
    --dry-run    抓数据+渲染+自检，不落盘
    --preview P  渲染结果写到 P（调试）
    --check      只对已存在报告跑自检
退出码：0=通过  1=自检有 ERROR  2=自检有 CRITICAL
```
- 输出：`归档/YYYY年M月/新闻联播总结_YYYYMMDD.md`（自动建月目录，命名与旧流程一致）
- 已有报告 >10KB 时跳过重生成，但仍跑自检并返回同样退出码（避免定时任务重试掩盖质量失败）
- 格式契约来自 `流程/旧版本/新闻联播总结_去敏感词模板.md`，运行时读取骨架
- 定时任务（2026-09-16 起）：任务名 `新闻联播每日总结`，**每天 05:00**，
  动作**直接调用 `xwlb_report.py`**（不带日期 = 昨天），不经 `run_daily_task.ps1` 外壳。
  注册/改时间：`register_task.ps1 -NonInteractive`（**改 config 后必须重新注册**）；
  注册时自动探测解释器（实际绑定 Python312，需 requests 可导入）；
  归档同步到 Gitee 默认不在任务里，需 `-WithSync` 才追加。
  手动验证 `run_now.ps1`（与任务动作一致）→ `check_status.ps1` 看「目标报告检查」。
- 依赖：仅 Python 标准库 + requests（解释器由 PS 端自动探测，需 requests 可导入）

## 写 .ps1 的坑（本机中文 locale）
**用 Write 工具产出的 .ps1 没有 BOM**，Windows PowerShell 5.1 会按 GBK 解读，
中文字节错位吃掉引号/大括号，报"语句块中缺少右 }"之类语法错（实测 register_task.ps1）。
每次写完必须补 BOM：
`[System.IO.File]::WriteAllText($p, $c, (New-Object System.Text.UTF8Encoding($true)))`
另：`config.paths.*` 相对路径**以「自动化任务」目录为基准**（不是 `流程`）。

## 硬约束（用户明确要求）
- 七部分结构 + 第六部分 10 列表头**不得变更**
- **不增加外部依赖与成本**（不得引入 LLM API 做六要素填充）
- 按日期落对应月目录，优先以空白模板为骨架

## 数据源纪律
- 分段/完整版一律走 **CNTV 栏目接口**，不要用央视网日页做主源（日页会漂移指向次日空页）
- 齐鲁网只提供"子条目标题清单 + 独立链接"，**没有正文**
- 快讯子条目用交叉对账：「齐鲁网名录 − 央视网常规新闻」

## 已知取舍
- 原因/方式两列：正则只在正文有显式目的/方式小句时填充，否则「—」。
  历史归档里这两列是 AI 填充的，语义更丰富但违反"不加外部依赖"约束。
- 快讯六要素依赖正文；日页漂移时正文会丢，脚本会记 WARNING。

## 格式契约细则（复核于 2026-09-16，勿"顺手改"）
- 第七部分子节编号是 **7.1 / 7.3 / 7.4 / 7.5 / 7.6（没有 7.2）**：模板如此，归档 79 份如此
  （仅 9 份旧产物漂成 7.1/7.2/7.3/7.4）。**不要补 7.2、不要重排。**
- 报告头部**不含**模板的「版本/变更日志」块（那是模板自身元数据）。
- 第三部分只输出"有内容的子节"（空分类不输出 `### 3.x`）。
- 模板文件本身在附录 A.5 的 JSON 处被截断（历史遗留），契约解析不受影响。
- Markdown 铁律：`---` 前必须留空行，否则上一行被渲染成 setext 二级标题（已入自检）。
- 说明/语境类文本一律以**句读边界**起收，禁止按字数硬裁（否则出现"子电池…""造业…"断字残片）。

## 内容策略（2026-09-16 用户要求）
**"抓取网页链接的内容可以不用省略"** —— 已抓到的正文不得二次截断：
- 第四部分快讯正文原样输出（官方定稿 93–177 字），不再 clip 到 80 字
- 抽取层正文窗口全部放开（分类/原因/方式/数据来源不再截 300–800 字）
- 7.5 每条取 6 个数值、全表上限 30 行；第三部分「核心数据」按模板
  呈现为「数据点：数值」而非裸数值
- 代价：报告 30KB → 38KB（流程文档写的"正常 18–35KB"上沿已被突破，50KB 才是异常线）
