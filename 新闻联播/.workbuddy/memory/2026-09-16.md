### 关键数据源发现（重要，勿再踩坑）
1. **央视网日页会漂移**：`tv.cctv.com/lm/xwlb/day/YYYYMMDD.shtml` 在播后会被更新，
   实测 20260915 日页把「国内联播快讯」「完整版」都指向 09/16 路径，而 09/16 页面
   `content_area` 是空的 → 快讯 9 条正文全丢。真正的正文在 09/15 路径下。
2. **CNTV 栏目接口才是稳定源**（已接入 `fetch_videos` 前置）：
   - `api.cntv.cn/NewVideo/getVideoListByColumn?id=TOPC1451528971114112&n=60&sort=desc&p=1&mode=0&serviceId=tvcctv`
     → 完整版列表（含 `brief`「本期节目主要内容」，即当天全部分条标题）
   - 同接口 `mode=1` → 分段列表（含每条独立 URL、`length` 时长、`focus_date` 发布时序）
   - 竞态证据：mode=1 对 09/15 同时列出 09/15 与 09/16 两条「国内联播快讯」，
     按 URL 路径日期过滤即可取到带正文的那条
   - mode=1 返回倒序，`reverse()` 后即播出顺序；完整版优先取「路径日期==目标日期 且 19:00」那条
3. 齐鲁网详情页**无正文**（只有 title/description），不要指望它补快讯正文
4. 页面互不链接、CCTV 搜索接口不可用；`getVideoRelated`/`getVideoListByGuid` 返回"拒绝访问"

- **分隔线前缺空行**：`render_report` 用 `"\n---\n\n"` 拼接 → 8 处 `---` 紧贴上一行，

### 关键坑（复用价值高）
1. **Write 工具产出的 .ps1 没有 BOM** → Windows PowerShell 5.1 按本地代码页(GBK)解读，
   中文字节错位会吃掉引号/大括号，报"语句块中缺少右 }"这类诡异语法错。
   修法：`[System.IO.File]::WriteAllText($p, $c, (New-Object System.Text.UTF8Encoding($true)))`。
   本次 register_task / run_now / check_status / unregister_task 四个脚本都已补 BOM。
2. `config.paths.*` 的相对路径**以「自动化任务」目录为基准**（不是 `流程`）；
   Join-Path 后要 `GetFullPath` 再判存在性，否则 `流程\../一键生成` 会落到错目录。
3. 注册脚本原版用 `Read-Host` + 末尾 `pause` 交互，自动化调用必然挂住 →
   必须提供 `-NonInteractive`（= `-Force -NoPause`），且该模式**不尝试提权**。
4. Register-ScheduledTask 的触发时间在注册时写入任务库，**改 config 不会自动生效**，
   必须重跑注册脚本。
5. 同步到 Gitee 不应默认塞进 05:00 任务（属无人确认的外发动作）→ 改成显式 `-WithSync` 才追加。
