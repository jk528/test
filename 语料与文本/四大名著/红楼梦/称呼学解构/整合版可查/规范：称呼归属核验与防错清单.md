# 规范：称呼归属核验与防错清单

> 用途：防止把"谁称谁、谁对谁说"写反或写错。2026-11-25 对 001–080 全量复核，确认 65 处同类错误（涉及 46 篇），本清单据实归纳，供此后每一回生成、每一次汇总时逐条对照。
> 适用：本目录全部回目稿（`NNN_*.md`）与本线路汇总稿（`总结：*.md`、`README：*.md`）。
> 与 `方法论：整合版生成与质检调用.md` §1.4「归属核查」配套使用；质检脚本只管引文是否命中底本，**管不了引文安在谁头上**，这一层必须人工核。

---

## 0. 一条总原则

**引文命中底本，不等于归属正确。** 「」只证明"这句话存在"，不证明"这句话是这个人说的、对这个人说的"。锚定通过之后，仍须单独核一次**发送方—接收方**。

---

## 1. 五类必须消灭的错误

| 代号 | 错误类型 | 表现 | 判定 |
| :---: | :--- | :--- | :--- |
| A | 主客倒置 | 把"甲称乙为 X"写成"乙称甲为 X" | 施称者与受称者互换 |
| B | 施受倒置 | 把"甲认乙作 X""甲把乙叫作 X"写成"乙认甲作 X" | 认亲、命名的方向反了 |
| C | 张冠李戴 | 把底本中 A 说的话安到 B 头上 | 说话人错 |
| D | 关系／身份错标 | 婆婆↔母亲、嫂子↔姐姐、丫头↔小姐、外祖母↔祖母、母子↔母女 | 亲属格错 |
| E | 引文不存在 | 「」内 ≥10 字，本回底本检索不到 | 多为跨回引文或改写 |

三条硬规则：

1. **跨回引文不得用「」**。第 37 回的话不能当第 38 回的本回证据（038 曾把 037 回湘云语放进本回定律表）。
2. **引用谁的话，就必须写出"谁对谁说"**，不能只写"某人说"。
3. **底本没写说话人时，不得代拟**；宁可写"某语"不写"某道"。

## 2. 高危位置（按出错频次排序）

| 位置 | 为什么容易错 | 本轮实例 |
| :--- | :--- | :--- |
| §4／§3「同一个人，好几副舌头」 | 一人多档并列，复制句式时最容易把对象张冠李戴 | 043「丢了我不管」实对尤氏；052 晴雯「我是老虎」实对坠儿 |
| §0「一句话」 | 概括句压缩了主语，写顺了就丢 | 025 把凤姐的话写成"贾环一句"；038 把平儿误撞写成"鸳鸯抹" |
| §1 事件标题 | 标题先定性后引文，标题里的主语常没人复核 | 024 把贾芸自报写成"小红回话"；056 把平儿的话写成"探春又道" |
| §4 定律命中表"代表事件" | 只抄引文不抄说话人，事后无法追溯 | 019 把宝玉劝晴雯写成"对闯祸小厮"；025 把王夫人写成"邢夫人" |
| 汇总稿人物线／分幕 | 二次转写，最易脱离底本 | 039「老寿星」、057「认娘」两处均错在汇总稿而非原篇 |

**结论**：这五处必须逐条回底本，不能凭前文记忆续写。

## 3. 核验四步法（每条归属陈述都走一遍）

1. **取串**：从稿件「」内取 8–20 字连续片段，去掉标点。
2. **定位**：Grep 该串到本回底本 `红楼梦_拆分\NNN_*.txt`；无命中换 2–3 个片段再试，仍无命中记 E 类。
3. **读上下文**：Read 命中处前后各 20–40 行（底本一段一行，必要时截取前后 200 字）。
4. **填三格**：施称者＝？受称者＝？引语是否是此人此语？三格与稿件一致才算通过。

> 只核"这句话有没有"是质检脚本的活；只核"这句话谁说的"才是本清单的活。

---

## 4. 判定三格模板

对每条归属陈述，先在草稿上填：

```
施称者（谁说）：______
受称者（对谁说／说谁）：______
引语原文（底本核对后）：______
稿件表述：______  一致？ 是 / 否
```

三格任一为空，就说明这条还没核实，不能落盘。

---

## 5. 写作时的六个自检问句

1. 这句话的**主语**在底本里是不是这个人？
2. 宾语／受称者是不是这个人？有没有把"被称者"写成"称呼者"？
3. 亲属格对不对（婆婆≠母亲、外祖母≠母亲、母子≠母女）？
4. 这条引文是不是**本回**的？跨回的一律改引号、标回次。
5. 一人多档并列时，每一档的**对象**是否各自核对过，而不是沿用上一档？
6. 概括句（§0、标题、代表事件）压缩后，主语还在不在？

## 7. 汇总稿的二次校验（单独一道）

汇总稿（总览、README、分幕、人物线）是对 80 篇的**再压缩**，错误率高于原篇。做法：

1. 汇总稿里每一句"某称某为某"，都回**原篇**找对应事件，再回**底本**核一次；原篇与底本不一致时以底本为准，并同时改原篇。
2. 人物线表格逐人核：施称／受称列不能混（如"刘老老：她称贾母为老寿星；贾母称她为老亲家"）。
3. 分幕概述里的"谁对谁"，不得只写一方。

- [ ] 质检脚本退出码 0，未锚定 0。

- [ ] 跨回引文已改引号并注明回次，未混入本回。
- [ ] §0、§1 标题、§4 代表事件三处的归属，均已回底本复核。
- [ ] 一人多档并列（"几副舌头"）逐档核过对象。
- [ ] 汇总稿若有改动，已回原篇＋底本双向复核。
