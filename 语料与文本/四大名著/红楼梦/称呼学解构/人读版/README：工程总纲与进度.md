## 0. 工程总纲（先读此节）

**一句话**：《红楼梦》是汉语**称呼密度最高、层位最全、动力学最复杂**的长篇语料——贾府这个"钟鸣鼎食之家"把亲缘网（L1）跑到极限（四百余人一张族谱）、把立场调制（L2）精细到一字千钧（姐妹互称与姨娘称谓的两个世界）、把通信协议（L3）演成日常（一句话说错即挨骂）、把治理层（L4）写满悲喜剧（骂与夸的攻防全书）。**逐回解构即逐回取证：每一回都是四层十二件的活体实验室。**

**三句工程纲领**：

1. **不猎奇**：只解构文本实际发生的称呼事件，不做索隐；每条分析必须落在原文节选上（引文锚自名词列锦章节文件）。
2. **不重复**：体系概念（黑盒、路由、三色等）不在本工程重复展开——一律以"件号＋定律号"回指总架构，本工程只产出**红楼梦的事件与发现**。
3. **计数守恒**：每回文档载明该回解构的称呼事件数；工程总量逐批累计（§5 进度表）。

## 3. 红楼称呼学的预判四题（工程期间验证）

开工前置四个"全书级"问题——逐回取证，进度表中滚动回答：

1. **黛玉的称谓漂移轨迹**：从第 3 回"步步留心"的规范称呼（外祖母／大舅母／二舅母），到中段的自嘲"草木之人"，到与宝钗互称"姐姐/妹妹"的转变——称呼轨迹即心理轨迹（黑盒状态机的历次转写）。
2. **"宝二爷／宝兄弟／宝玉／混世魔王／凤凰蛋"的多名并存**：同一人多入口（路由表 g 的活体展示），谁叫哪个名，即谁站在哪个位置。
3. **詈骂语的亲密化光谱**："小蹄子／凤丫头／猴儿／老货"在贾母口中是爱称、在王夫人某些语境是怒词——同一词跨极性档（L2 极性随 L3 信道与 L4 意图浮动）的边界在哪。
4. **称谓即命运**：从"姑娘"到"宝二奶奶"的协议升级与破产（96–97 回"调包"即一次恶意 BCC 帧）；尤二姐"姐姐"称呼链的甜毒；赵姨娘的称谓天花板（永远是"姨娘"，进不去"太太"格）——称谓系统如何参与人物命运。
