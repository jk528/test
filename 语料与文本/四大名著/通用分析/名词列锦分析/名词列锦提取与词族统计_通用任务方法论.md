# 名词列锦提取与词族统计 · 通用任务方法论（v2）

> **性质**：本文是「对已拆分长文本做名词列锦逐章提取 + 同类词族纵向统计」的完整口径与生成逻辑。**v2 以《西游记》100 回全书实战为唯一标准重写**——判定、两类产物、目录、流程、模板、校验、防错、基准数据全部来自一次完整跑通并交付的实战（见 §9），未经验证的环节不写入。v1 备份在同目录 `..._v1备份.md`。
> **通用性约定**：全文不绑定任何具体书名、章数与绝对路径。凡随项目变化的量一律用占位符（见 §0.2）；§9 的实测值仅作规模参照，不是硬约束。
> **总原则**：**宁可多不要少**。多了可删，少了不好找。凡有疑义一律先收并标注，不擅自剔除；只有"零新增"底线不放宽。
> **与白描方法论的关系**：同系列姊妹任务。白描拆**写作手法**，本任务拆**名词列锦与同类词族**；共用"只提取、不改写、逐字引证"底层约束，可并行跑、交叉引用。

## 0. 阅读约定

### 0.1 任务一句话定义

输入「一部已按章拆分的文本 + 名词列锦判定与词族口径」，输出「**{总章数} 个逐章独立 MD**（每章一个文件，含该章逐回条目 + 本回词族表）」＋「**1 份全书总结报告 MD**」。全程由主控调度、子代理逐章阅读与提取并**逐章独立落盘**，主控负责机器校验、词族大类归并、统计与总结报告；**同类词无论出现几次、是否已在别的条目里出现，一律在词族表中逐处单列**。

> **v2 与 v1 的根本差别**：v1 的终产物是「一份 head+batches+tail 拼接的统合 md」，中间产物进 `.temp`；v2 的终产物是「每章一个面向用户的独立 MD + 一份总结报告」，**没有 .temp、没有 batch 文件、没有拼接步骤**。每章 MD 本身就是交付物，可读、可单独删改、可单独复核。

## 1. 名词列锦判定（宜宽不宜严）

### 1.1 定义

白描 25 手法中，名词列锦原义为"同处境名词排列成景"（信号：原文已有几个同属一处境的名词；撤掉：名词无共同关系、只像清单）。本任务**反向使用**：不改写、只提取，用它作识别框架拆解成熟文本。

### 1.2 三条判定（满足任意一条即先收）

| 条件 | 含义 |
|---|---|
| **同境** | 成员属同一处境／体系：时辰、方位、器物、果品、禽兽、草木、职分、辈分、气象、景物、处所…… |
| **成列** | 原文以并列、对仗、铺陈、枚举呈现，或虽散落但同类关系明确，或可经剔除修饰语归组 |
| **成景** | 排列后能读出画面、秩序或层级结构 |

对偶句、韵文、偈语、长尊号、动宾短语中的名词、数字＋名词组合，**只要能成组，一律先收**，存疑的按 §3 标注体系处理。

### 1.3 三类界定

| 类 | 名称 | 判定 | 处理口径 |
|---|---|---|---|
| **①** | 原文完备 | 原文成组写全、顺序边界清楚 | 原样提取；依据栏写"原文完备" |
| **②** | 缺失补全 | 成员被**压缩**（四字格并俩）、**散落**（藏于叙述）、**截尾**（以"等／般般件件"收束） | 还原或展开；补全字必须全部出自原文 |
| **③** | 跨章节 | 成员不集中单回、散见全书、靠体系关系维系 | 单回记线索并标"待全书校验"；全书汇集后在总结报告单列 |

**合条**：一句含多组时可合为一条，但成员清单必须分组写清。

### 1.4 纳入清单（从宽，优先收）

1. 完整枚举的名物组：地支、部洲、四象、五形、三才、辈分字等；
2. 铺陈式对偶／排比中的同类名词：果品、器物、禽兽、草木、穿戴、气象、山水；
3. 层级／序列词：帝王世系、名色品类、职分、亲属称谓、身体部位；
4. 散落但可归组的同类名词（如时辰散在叙述里、瑞兽分置四句）；
5. 数字＋名词咬合的秩序组合；
6. 长尊号、成串职名、地名叠称等"名词连缀成景"者；
7. **韵文、偈语、歌词、诗赋中的名物**（照收，标注 `[韵文]`）；
8. **动宾短语中的名词**（剔除动词后成组，按②类收）；
9. **原文只给总数未列成员的组**：照收，标 `[待考·外部补全]`；
10. 同一章内重复出现的组：逐回条目首次详列、复现回指；**但词族表仍按出现次数逐处单列**；
11. **同一语义类的词族**：无论是否已在逐回条目中出现，均须在词族表中全部列出。

### 1.5 排除清单（从窄，仅这三种）

1. 完全不成组的孤立的词——某名词仅此一处、无任何同类可归并；
2. 纯抽象概念连缀、无画面也无秩序者；
3. 原文残缺到无法辨认成员的字（保留原字"□"，**不据此编造成员**）。

> 拿不准的一律不进排除清单，改走 §3 标注体系收进正文。

## 2. 词族纵向统计（本方法的核心维度）

### 2.1 为什么必须有这一维度

逐回条目按"当场成组的名词"提取，会天然漏掉三类东西：
- **别名/近义**：同一集团的多种称谓（如"三等名色／三等人／三者／佛仙神圣"）分散在不同句；
- **同词复现**：同一词出现多次，逐回条目里只记一次或被合条覆盖；
- **跨章呼应**：某类词贯穿全书，单章看不出规模。

词族统计按"同一语义类的全部词"纵向归并，**与逐回条目并行、互不替代**。

### 2.2 六条执行细则

> **核心规则**：一个词即使已在某条逐回条目中出现过，仍须在所属词族表中**单列一次**，不得因"已经算进某组"而折叠、省略。

1. **覆盖对象**：同一语义类的所有词与别称——同义、近义、俗称、雅称、动词化表述，全收；
2. **跨位置归并**：同章多处、跨章、韵文与散体中的同类词，一律归入同一族；
3. **逐处标注**：每个词标出**全部出处**（章号＋原文片段），并注明"已见逐回条目"以便双向核对；
4. **单列不合并**：同族内别名分行单列，不合并计数；同一词出现 N 处，记 N 条；
5. **异形各自成词**：词序不同（如"不老长生／长生不老"）、连称与分称（如"三者／佛仙神圣"）各自单列；
6. **独立成篇**：每章词族表附在该章 MD 末尾；全书另在总结报告做**大类归并统表**（§6 步骤 5），与逐章表互不覆盖、互不扣减。

### 2.3 种子族清单（先定后补）

先列种子族，全书提取中发现的新类随时并入：

| 组 | 种子族示例 |
|---|---|
| 时空秩序 | 地支时辰、方位部洲、节令四时、纪年数字 |
| 生命观 | 长生不死、冥界死亡、轮回果报、仙凡品类 |
| 品类序列 | 名色品类、辈分字、职分官阶、亲属称谓 |
| 物象铺陈 | 器物、果品、禽兽、草木、穿戴、建筑、山水 |
| 数量秩序 | 数字＋名词的组合（尺寸／历数／卦数／里程） |

> **实战扩展**：西游记 100 回跑完后，实际高频族远超种子表——神佛尊号、身体部位、饮食席面、丹道佛理、情态形容、法术变化、经卷名目、譬喻列锦等均成大类。种子表只作起步锚点，**不设上限、不阻止新增**。

### 2.4 逐章词族表格式

```markdown
### 词族名（共 N 词次）
| 词形 | 出处 | 原文片段 | 已见逐回条目 |
|---|---|---|---|
| 词A | 第N章·段落 | 「……」 | Cxx |
| 词A | 第M章·段落 | 「……」 | — |
```

### 2.5 词族命名的分散性（v2 新增，必须预期）

分批并行的本质是多个判定者，**词族表名**不会被强制统一：实战 100 回产出 **548 个原始词族名**，其中"器物"一义就有 `器物／器物族／器物·兵器族／器物用度／器物兵器` 等 45 个别名。这不是错误，是"宁可多收"的自然结果。处理方式：
1. 逐章 MD 内**保留原始表名**，不强行改名（避免破坏"已见逐回条目"的双向对应）；
2. 总结报告用**关键词映射归并到 17 个标准大类**（见 §6 步骤 5），别名数本身作为一项统计指标；
3. 若后续需要机器聚合，可另做一轮"词族名标准化"，但那是独立的可选步骤，**不在本流程内**。

## 3. 标注体系（"多收可删"的实现）

每条逐回条目必须带一个标记，方便后续批量删减：

| 标记 | 含义 | 默认 |
|---|---|---|
| `[核心]` | 三类判定毫无争议 | 保留 |
| `[韵文]` | 出自诗、偈、词、歌、赋，名物成立但文体存疑 | 保留，可删 |
| `[动作]` | 从对偶动作短语中剔除动词取名词 | 保留，可删 |
| `[尊号]` | 长称号连缀，是并列名物还是单一专名存疑 | 保留，可删 |
| `[待考]` | 成员靠外部文化知识补全，非原文所有 | 保留，但**不计入统计** |
| `[复现]` | 同章或跨章重复出现，回指首见条目 | 保留，逐回条目层不重复计数（词族表仍逐处单列） |

**删减梯度**：先删 `[待考]`，再删 `[尊号]`／`[韵文]`，最后视需要精简 `[动作]`；`[核心]` 是全集骨干。
**注意**：删减只作用于逐回条目层；**词族表不受删减影响，始终全列**。
**全书标记分布**是总结报告 §二 的必备统计项（实战：核心 2788／韵文 1593／复现 648／动作 622／尊号 436／待考 168，占比合计 >100% 因一条可带多标记）。

### 3.1 三条铁律

1. **逐字引证**：引文直接来自所读章，禁止凭记忆改写、缩写、拼接不相连的原句（节选须标明）；
2. **零新增**：`[待考]` 类之外，补全字必须全部出自原文，仅做剔除修饰语、拆分并列、还原顺序；
3. **不改写原文**：说明文字指向"原文怎么写（信号）—排成了什么景（效果）"，不写"淋漓尽致"类空评。

> **OCR 讹字处理（v2 新增）**：部分拆分文本含明显扫描讹字（如"天恩祖德"作"天思祖德"、"青埂峰"作"青埂蜂"、"尚未"作"尚末"）。**引文一律照抄原字，不纠正、不标注、不替换**——本任务是提取而非校勘；擅自改动会破坏引文可核率的机器回查。

## 4. 输入要求与前置勘察

### 4.1 输入硬性要求

1. **文本已拆分**：每 {章单位} 一个独立 txt，位于同一 {拆分目录}；
2. **文件名含序号**：序号在文件名前缀且可机械提取（如 `001_xxx.txt`），这是分批与排序唯一依据；
3. **文件内首行为标题**，供逐章 MD 标题引用；
4. **无缺号**：序号从起点到终点连续；缺号先补拆或把实际清单作为事实源；
5. **口径先定**：判定与词族口径（§1–§3）先于读文本确定，防止各代理自行发挥造成漂移。

### 4.2 勘察步骤（主控执行）

| 勘察项 | 方法 | 用途 |
|---|---|---|
| 文件总数与序号连续性 | 列目录 + `for i in $(seq -w 1 N)` 逐号查缺 | 确定 {总章数}，缺号即报 |
| 单文件字节数区间 | `du -b` 取 min/max | 决定 {批次大小}（读入侧）；**单章 >30KB 时下调到 8 章/批** |
| 首行标题格式 | 抽读首尾各 1 文件 | 确定 MD 标题写法与 {章单位} |
| 正文特征 | 抽读 1 文件前 20 行 | 判断韵文密度、缩进、OCR 讹字、编码乱码 |
| 文件名特殊字符 | 检查全角空格等 | 决定代理用 glob 还是明确列表 |
| **单章列锦密度**（抽样） | 抽 3–5 章试跑，数条目数 | 估输出量，定 {批次大小}（输出侧） |
| **种子族适配性**（抽样） | 对照 §2.3 看哪些族在本文本高频 | 增删种子族 |

> 实测提示：中文拆分文件名常含**全角空格**，不手工拼路径。

## 5. 产物与目录结构（v2 重写）

```
{作品}/
├── {作品}_拆分/                      # 输入（只读）
│   └── NNN_*.txt × {总章数}
├── 名词列锦章节/                     # ★ 逐章交付物（本流程新建）
│   ├── 001_第1章.md                  # 每章一个独立 MD
│   ├── 002_第2章.md
│   └── ...
│   └── NNN_第N章.md
└── {作品}分析/
    └── 名词列锦提取_全书总结报告（{总章数}{章单位}）.md   # ★ 全书总结报告
```

**没有 .temp、没有 batch、没有 head/tail、没有拼接脚本。** 每个逐章 MD 就是最终交付物本身。

### 5.1 逐章 MD 文件头（所有章统一，机器校验前提）

```markdown
# 《{书名}》第X{章单位}　完整章目　名词列锦分析

> 语料：`{拆分目录}/原文件名.txt`
> 原则：宁可多不要少，疑义先收并标注。标记：`[核心]`/`[韵文]`/`[动作]`/`[尊号]`/`[待考]`/`[复现]`
> 本{章单位}：条目 N 条 ＋ 词族表 M 张

---
```

> **头部声明数必须等于正文实际数**（§6 步骤 4 机器校验）。这是 v2 新增的硬约束：实战中多批子代理曾出现头部写 62、正文实为 70 的情况，靠这一校验卡口发现并修正。

### 5.2 逐回条目格式（所有章统一）

```markdown
### C编号　①/②/③　组名　[标记]
- **原文**：「逐字引文；长列锦节选须标明」
- **成员**：……（N 个；多组分行写清）
- **依据**：①写"原文完备"；②写还原方式与依据；③写"待全书校验"；待考写外部来源
- **说明**：信号与效果，一两句，克制具体。
```

**C 编号在本章内从 C01 连续递增**（不跨章连续）。跨章定位靠文件名 `NNN_` 前缀。

### 5.3 逐章词族表格式

见 §2.4，固定放在该章 MD 末尾 `## 本回词族表` 之下。

### 5.4 全书总结报告结构（六节，固定）

1. **任务与口径回顾**：方法来源、逐章成果路径、原则与标记、三条判定与三类界定的压缩复述、词族口径；
2. **全书统计总览**：章节覆盖、逐回条目总数、词族表总数、词次总数、原始词族名数、归并大类数、引文可核率；单章条目密度（最丰沛/次丰沛/最精简/平均）；标记分布表；
3. **全书词族大类统表**：按词次降序的大类表（大类／总词次／覆盖章数／别名数／高频别名），附"其他杂类"说明；
4. **统合观察**：4–6 条，落在支柱族、跨章呼应、文体差异、命名分散度等具体发现，不写空评；
5. **校验结论**：逐项 ✅ 表（章齐全、编号连续、头部计数一致、引文可核、不可核处置、词族双向一致、编码）＋一句结论；
6. **产物清单与使用说明**：目录树、按章查阅、批量删减、全书检索、复用提示。

> **三条格式约定（中途不可变更）**：① 条目标记与类别写法固定；② 逐章 C 编号自 C01 连续；③ 词族表"出处＋已见条目"列固定。机器校验全部依赖这三条。

## 6. 完整生成流程（v2 七步）

流程总览：**勘察 → 分批 → 逐章并行提取（每章独立落盘）→ 机器校验 → 词族大类归并 → 总结报告 →（仅异常时）补漏/统一轮**。

### 步骤 1：文本勘察
按 §4.2 执行，产出：{总章数}、{批次大小}、{总批数}、{单章列锦密度}、文件名清单、编码与特殊字符结论、适配后的种子族。
**验收**：序号集合 = 1..N 无缺口；种子族已定稿。

### 步骤 2：批次规划

```
{批次大小} ≤ floor(100KB ÷ max{单章字节区间})        # 读入侧
{批次大小} ≤ floor(60KB ÷ 单章输出预算)               # 输出侧，实测约 2–4KB/章
{批次大小} = min(两者)，落在 [6, 10]
{总批数}   = ceil({总章数} ÷ {批次大小})
```

**并行调度**：一次消息内并发 {并行波次}=5 个子代理（实测稳定），批次按序号连续切块、不交错。100 章 → 10 批 × 10 章 → 2 波。
**验收**：批次表已建（批号 → 章号区间 → 输出文件名清单）。

### 步骤 3：逐章并行提取（首轮即全集）
派发模板 A（§7.1）。核心约束：
1. **按序号逐个读文件，读完一章立即用 Write 写完该章独立 MD，再读下一章**——这是 v2 与 v1 最关键的操作差别，一次写入一章，天然规避写盘失败；
2. **全集口径**：命中即写，不挑典型、不设上限；
3. 引文逐字摘自所读文本，禁止凭记忆改写；OCR 讹字照抄；
4. **词族表按出现次数逐处单列**，同词多次分列、别名分行；
5. **头部声明数写完前必须数准**；
6. 返回只给两行：完成状态 + 各章条目数/词族表数汇总，不粘贴全文。

**验收**：每章 MD 存在、章标题数 = {总章数}、每章有条目、有词族表。

### 步骤 4：机器校验（v2 新增，主控执行，脚本见 §7.3）
1. **章齐全**：逐章 MD 数 = {总章数}，`seq -w 1 N` 逐号查缺；
2. **编号连续**：每章 `^### C\d+` 提取编号，校验 = 1..n；
3. **头部计数一致**：正则取"本回：条目 N 条"，与实际条目数比对，异常清单输出；
4. **引文可核率**：抽取每章全部 `**原文**：「…」`，规范化（去标点空白）后回查对应章 txt 原文；长引文按 `…` 切段，任一段 ≥4 字命中即算可核；
5. **不可核诊断**：对未命中引文做 4 字滑动窗口命中率——命中率 >75% 判为"跨句节选/异体字/缺字/个别字出入"（内容真实，可保留），<30% 判为"疑似编造"，中间区间人工核原文；**1 字出入直接 Edit 修正并同步词族表里的同一引文**；
6. **词族双向一致**：逐章词族表均含"已见逐回条目"列，可回溯。

**验收**：缺漏 = 0；头部异常 = 0；可核率给出具体百分比；疑似编造项全部处置。

### 步骤 5：词族大类归并（v2 新增）
按 §2.5 用关键词映射把全部原始词族名归到标准大类，统计每类：总词次、覆盖章数、别名数、高频别名 Top5。输出按词次降序的统表。同时汇总：逐回条目总数、词族表总数、词次总数、标记分布、单章条目密度。
**验收**：全部词族表都有归属大类；总词次可复算。

### 步骤 6：总结报告撰写（主控）
按 §5.4 六节结构写入 `{总结报告路径}`，数字全部来自步骤 4/5 的脚本输出，不手写估算。
**验收**：报告统计数字与脚本输出一致；六节齐全。

### 步骤 7：补漏/统一轮（异常专用）
仅在以下情形启用：批次空返回/中断、校验发现缺章或缺项、某章格式与其余不一致（如由旧范例迁入的章）、引文疑似编造需重做。做法：算差集 → 派发模板 B（§7.2）→ 覆写该章 MD → **重跑步骤 4–6**（统计数字会变，必须同步更新报告）。
**验收**：全覆盖 + 报告数字重算一致。

```text
【六、返回】只返回：①完成状态一行；②各{章单位}"条目数/词族表数"汇总。不粘贴全文。
```

```text
【角色】修复《{书名}》第{起}—{止}{章单位}的名词列锦 MD。研究+文件编辑任务，不写代码。

【输入】
1. 待修章 MD：{逐章目录}/NNN_*.md

【硬性要求】
```

### 7.3 机器校验与归并脚本规格（v2 新增，替代 v1 的拼接脚本）

主控用 Python 3 写三个临时脚本（用完即删，不留项目文件）：

**（a）校验脚本** `.temp_verify.py`
```
读全部 {拆分目录}/*.txt 到 dict[序号]=原文（utf-8, errors=replace）
遍历 {逐章目录}/*.md：
  items = re.findall(r'(?m)^### C(\d+)', text)          # 编号连续
  declared = re.search(r'本回：条目\s*(\d+)\s*条', text)  # 头部计数
  quotes = re.findall(r'\*\*原文\*\*：\s*「(.+?)」', text) # 引文
  norm(s) = 只保留汉字/数字/字母
  可核判据：引文按 … 切段，任一段 norm 后 ≥4 字且 in norm(本章原文) 即算命中
输出：逐章表（序号/条目/声明/连续/引文数/可核/不可核）+ 汇总可核率 + 不可核样例
```

**（b）诊断脚本** `.temp_diag.py`
```
对每条不可核引文：4 字窗口、步长 2 滑动，统计窗口在 norm(原文) 中的命中率
  >75%  → 跨句节选/异体字/缺字/个别字出入（内容真实）
  30–75% → 部分出入，人工核原文
  <30%  → 疑似编造，必须回原文核对并 Edit 修正
```

**（c）词族归并脚本** `.temp_fam.py`
```
对每章 MD：取 '## 本回词族表' 之后的所有
  re.findall(r'(?m)^###\s+(.+?)（共\s*(\d+)\s*词次）', tail)
按关键词表把原始族名映射到标准大类（§5.4 第 3 节的 17 类），
累计：每类总词次 / 覆盖章集合 / 别名集合 / 高频别名。
同时统计：条目总数、词族表总数、词次总数、标记 re.findall(r'\[(核心|韵文|动作|尊号|待考|复现)\]')。
输出：按词次降序的大类表 + 汇总数字。
```

> **注意**：脚本是临时工具，不属于交付物；跑完立刻删除，且**不写任何项目目录**。统计数字必须由脚本给出，禁止手写估算——实战中曾因手写估算导致头部计数与正文不符。

### 9.4 关键教训（写进 v2 的防错）

1. **"数字＋名词"是全书骨架**（覆盖 95/100 回），但种子表里没有预置——种子族必须允许随时扩展；
2. **韵文占逐回条目 31.1%**，是列锦富矿也是可删大头，靠 `[韵文]` 标记成批管理；
3. **词族命名必然分散**（548 名 / 45 个"器物"别名），不要在提取阶段强行改名，归并留给总结报告；
4. **扩/改条目后必须重跑机器校验**：实战中"三等名色"曾在扩条时整条丢失，头部计数也曾与正文不符；
