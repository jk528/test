## 0. 结论（先行）

> **确诂一句话**："奋六世之余烈"＝**（秦始皇）腾身而起，把六位先君〔孝公、惠文王、武王、昭襄王、孝文王、庄襄王〕遗留下来的功业一并施展挥发**。"奋"训振起、施展（本义鸟振翅高飞，非今语"奋斗"），"六世"非虚数——原文上文已逐一列名六君（含"延及孝文王、庄襄王"），**数字由文内枚举自注**；"余烈"之义为遗留之功业，"烈"本义火猛（火之余焰），与"泽"（水之余润）恰成水火一对。语篇上本句是始皇登顶铺陈动词链（奋—振—吞—履—执—鞭笞—威振）的**首环定调**：字面极写其盛，实为《过秦论》"过秦"批判主旨的欲抑先扬——写得越烈，后文"一夫作难而七庙隳"跌得越重。

| 项目 | 判定 |
| :--- | :--- |
| 句子性质 | 赋体铺陈句群首句（动宾结构：奋＋六世之余烈） |
| 关键训诂 | 奋＝振起、施展；六世＝六位先君（实指）；余烈＝遗业、余势 |
| 数字确证路径 | **文内枚举自注**——原文明列六君（对比上例"五世"的文外制度锚定） |
| 结构机制 | "奋"领起七动作链，动作烈度递增（腾跃→扬鞭→吞并→登位→执杖→鞭笞→威振），登顶过程即暴虐升级链 |
| 必留语义 | ① 六世实指的接力积累感；② "烈"的火性辉煌（烈焰而非残烬）；③ "奋"的主动挥霍感（非静守而是一次性总取）；④ 欲抑先扬的语篇功能 |

**证据链一句话**：《过秦论》原文自注六君（孝公→庄襄王逐一列名）→ "六世"实指铁证＋通行注"烈，功业"＋《说文》"烈，火猛也""奋（奮），翚也"定本义 → 反例一票否决"虚数说""含始皇说""励志颂扬说" → 确诂成立。

## 3. 六步解析实操（古语句子版·铺陈型）

### ① 读语境（定场＋语篇功能定位）

- 语境：《过秦论》上篇始皇段总起句。三问：**谁说**——贾谊，西汉政论家，借秦亡论政；**对谁**——汉廷君主与士林（"过秦"实为警汉）；**什么场合**——政论史论，全文结论是"仁义不施而攻守之势异也"。
- **语篇功能问（句子型第四问）**：这句在章内干什么？——它是**赋体铺陈的造势首环**：领起"奋—振—吞—履—执—鞭笞—威振"七个动作，一路堆高始皇之势，堆到"威振四海"的顶点；而全文的论证策略恰是**欲抑先扬**——势写得越足，结尾"一夫作难而七庙隳"的落差越大，"攻守之势异也"的论断越重。本句与结尾不是顺承而是**互相成全的反差结构**。
- **产出**：凡把本句读出颂扬基调（秦真伟大）的解释，均与"过秦"（数落秦的过失）主旨冲突——第 1 步就把"励志读法"押上审判台。

### ② 拆关键词群（句子版：逐训点扫描＋结构分析）

| 训点 | 本义 → 句中义 | 依据 |
| :--- | :--- | :--- |
| 奋 | 奮，翚也（鸟振翅高飞，《说文》引《诗》"不能奋飞"）→ **振起、施展** | 腾跃起势的动作感保留：如自六世高台纵身一跃；无"愤怒"义，非今语"奋斗"的中性努力义 |
| 六世 | **六位先君**（孝公、惠文、武王、昭襄、孝文、庄襄） | 原文逐一列名自注（见第 2 节）；**世**承朱熹口径"父子相继为一世"，君位序列按"一君一世"计（昭襄王以弟继武王，虽同辈仍各为一世） |
| 余烈 | **遗留之功业、余势** | 烈本义火猛 → 功业义（《立政》"以扬武王之大烈"）；"余"＝遗留下未用尽的——火候已足、只待总取 |
| 及至始皇 | 隐含主语始皇，"及至"为承接六君后的时间接续词 | 结构上"六世"必不含始皇自己（否则"奋己在内之功"语义不通） |

**结构分析**：动宾结构，宾语为偏正短语"六世之余烈"。**动词链观察（铺陈型新增）**：本句是七动作链首环——奋（纵身）→ 振（扬鞭）→ 吞（吞并）→ 履（登上）→ 执（握杖）→ 鞭笞（抽打）→ 威振（震慑），动作从"腾跃"一路升级为"暴力施于天下"——**铺陈句的义有一半在链上**：首环"奋"定下"主动、总取、挥霍"的调性，后链沿此惯性奔向顶点。

- **产出**：骨架为"（始皇）纵身而起，总取六世积蓄一股脑儿挥洒出去"——重点在"总取＋挥发"，不在"安静继承"。

### ③ 追声音（追通假与防讹防今义）

- 奋、烈两字在本句历代注疏**未见通假异读**，标"未见通假说"——若后见王氏父子或清儒异训，按元规则 2 全局重审。
- 本步实际收益有二：
  1. **防今义滥用**：检索实见"奋"被读作"奋斗""发愤图强"乃至"愤怒"——"奋"的古义是振翅腾身，句中义是施展挥霍，带"猛一把"的爆发感而非持续努力感；"奋斗六世"式翻译是今义倒灌。
  2. **防清单讹混**：备考题库实见把**秦穆公**混入"六世"的错误选项——穆公在春秋，与战国变法线隔两百余年，望"秦"生义的典型错。
- **产出**：无通假可立；两条例外陷阱入第 ⑤⑥ 步。

### ④ 查书证（文内枚举自注——本步新用法）

- 书证总表见第 2 节。本步针对句中数字的新动作：**文内枚举自注**——上一个"五世"案例需借《礼记·大传》从文外做制度锚定；本句更省事：**《过秦论》原文自己把六位国君全部列了名**（孝公开篇主角，"惠文、武、昭襄蒙故业"三名，"延及孝文王、庄襄王"再两名），"六世"之"六"由文本内部枚举直接坐实，无需外证。
- **算术跨验**：孝公即位（前 361）至始皇统一（前 221）约一百四十年，六君均分每君位约二十三年（内含昭襄王五十六年长君与孝文王三日之君的极端方差）——年表量级与"六世"吻合，虚数说的最后退路（"约举成数"）也走不通，因为枚举名单是公开的六个人。
- **对照上例的知识底色**（观察层）：《礼记·大传》"六世，亲属竭矣"——六世恰是宗法亲缘的竭点；本句的六世却恰是功业的沸点。同在"六"这个数字位上，自然衰减律（亲亲之泽）与制度积累律（耕战之烈）背道而驰——贾谊与孟子在同一个坐标系里给出了两支曲线（详见第 5 节双联对照）。
- **产出**："六世"实指闭环。第 4 步在本案与上案用法不同而同为主力：**数字确证的两条路径——文外制度锚定与文内枚举自注**。

### ⑥ 防陷阱（定稿）

- **以今律古三大高发点（本例实测俱在）**：其一，奋→奋斗（努力感倒灌，句义实为挥霍感）；其二，六世→虚数或讹混清单（穆公项活标本）；其三，句式→励志语（立场反转——把批判文的铺垫读成颂词，为三坑之最）。
- **词义漂移绑定时代**：贾谊批判性铺陈（西汉政论）→ 中性史述（历代选本作史实引）→ 励志化引用（现代语用）。第三层最远——今人引此句夸企业接力、夸家族传承时，句子已被剥离原文的"斩"意，恰如上例"泽→家产"的漂移，只是方向相反：上例把余韵读成了财，本例把贬抑读成了夸。
