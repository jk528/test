## 0. 结论（先行）

> **确诂一句话**："君子之泽，五世而斩；小人之泽，五世而斩"＝**君子的流风余韵（德业对后世的余波影响），传五代人便告断绝；小人同样如此**——对举两端，泛说无人例外：任何人遗留的影响，都以"五世"为极限存量期。"泽"训**流风余韵**（非家产），"斩"训**断绝**，"五世"非虚数，锚定周礼丧服"五世袒免、杀同姓"的亲族衰减律。语篇上此句为下文张本：依此律，孔子之泽垂断在即（孔子之卒至孟子之世正约五世之数），孟子自陈"未得亲传、私淑诸人"，恰在断线前接续道统。

| 项目 | 判定 |
| :--- | :--- |
| 句子性质 | 对偶格言（经文断片，章内承担论证前提功能） |
| 关键词确诂 | 泽＝流风余韵；斩＝断绝；五世＝五世（丧服制度实指）；私淑＝未及亲受而间接取善 |
| 结构机制 | "君子／小人"极举两端＋同尾对举（"……而斩"）→ 泛化为无例外全称律 |
| 隐含论证链 | 立律（五世而斩）→ 推论（孔子之泽垂断）→ 自认（我以私淑接续） |

## 3. 六步解析实操（古语句子版改造）

### ① 读语境（定场＋语篇功能定位）

- 语境：孟子自述章。三问：**谁说**——孟子；**对谁**——门徒与后世读者；**什么场合**——自道学术渊源、申明师承。
- **语篇功能问（句子型新增第四问）**：这句在整章里干什么？——四句一体：首二句**立律**（影响皆五世而斩），第三句**自陈**（未得亲为孔子徒），末句**自认**（私淑诸人接续）。格言句不是独立感慨，是**为下文张本的论证前提**：先立"五世而斩"之律，再暗示"孔子之泽行将斩绝于我之世"，然后自己站出来接。
- **产出**：确诂必须同时兼容下文——凡解释不通"予私淑诸人也"的义项，一律存疑。这一问直接把"家产说"押上了审判台（家产传承与"私淑"毫无关涉）。

### ② 拆关键词群（句子版改造：无中心词，逐训点扫描＋结构分析）

句子不能像单词那样找中心词（第 2 步原生动作失效），改造为**关键训点扫描**——四个训点各跑一遍单词流程，再看结构：

| 训点 | 本义 → 句中义 | 依据 |
| :--- | :--- | :--- |
| 泽 | 光润 → 水泽 → 恩泽 → **流风余韵**（身后影响的余波） | 《说文》起步；《玉藻》"手泽"坐实"遗润"义；朱熹注定谳 |
| 斩 | 截（砍断） → **断绝、终止** | 《说文》"截也"；本句主语是抽象余绪，动作是衰减至无 |
| 五世 | **五世**（父子相继为一世，约一百五十年） | 非虚数——制度锚定见第 ④ 步 |
| 君子／小人 | 有位者／德行层位的两极举隅 → **泛指所有人**（分野在"人"的类属，不在"影响"的性质——好／坏二分说排除，见反例五） | 孔子时代"君子"主要指有位者（杨伯峻），此处德位两读皆通，功能同为举两端 |

**结构分析（句子型新增）**：两分句完全平行同尾（"……之泽，五世而斩"），对举不表对立而表**穷举**——如同"东西南北"以正方位括尽四方，这里以"君子／小人"括尽贤愚贵贱。句义重心不在"君子如何、小人如何"，而在**"而斩"对两端的同一判决：无例外**。

- **产出**：四个训点各自收敛＋对举泛化机制成立，全句骨架即出：**任一端点的余绪存量期都是五世**。

### ③ 追声音（追通假与防讹字）

- 泽、斩两字在本句无可靠通假义项（历代注疏未见通假异读），标"未见通假说"——若后见王念孙王引之一系或清儒异训，按元规则 2 全局重审。
- 本步在句子型的实际收益转为**防讹字**：检索实见将"私淑"讹作"私**塾**"——"私塾"为后起词，望文生义的活标本。正诂："淑"训善（《诗》"淑人君子"）："私淑诸人"＝**私下从他人那里取善（求取孔子之道）**，"私"言非亲承，"淑"言所取为善，"诸人"言所自为旁支门人。
- **产出**：无通假可立；防讹一条（淑≠塾），入第 ⑤⑥ 步反例与陷阱栏。

### ④ 查书证（制度锚定——本步新用法）

- 书证总表见第 2 节。本步针对句中**数字**有一新动作：**数字制度锚定**——句中数字往往是制度实指而非虚言。
- "五"的锚点：《礼记·大传》"四世而缌，服之穷也；五世袒免，杀同姓也；六世，亲属竭矣"——五世正是同姓服層断绝的临界值。孟子说"五世"，是拿当时人人皆知的丧服递减律（亲恩随世数衰减的"礼制半衰期"）作度量衡：**血缘温情尚且五世而竭，何况德业余绪**。
- **算术跨验**：孔子之卒（前 479 年）至孟子论学盛年，相距约百一十年至百六十年（孟子生年通说约前 372），恰落在"五世"（5 × 30 年）量级区间。孟子选"五"不选"三"不选"六"，是**制度＋算术双锚定**——他算的就是自己与孔子的距离。
- **产出**："五世"由虚读坐实为"恰好指孔子到孟子这一段"。第 4 步在句子型中升为主力：数字的义项由制度与年表共同给出。

### ⑤ 正反验证（核心环节）

| 检验 | 内容 | 结论 |
| :--- | :--- | :--- |
| 正例一 | 朱熹注"泽，犹言流风余韵也""斩，绝也"，历代沿用；当代词典同训 | 存在性坐实 |
| 正例二 | 语篇自洽：训"余韵"则末句"私淑诸人"顺理成章（余韵堪接，故私淑可成） | 存在性坐实 |
| 正例三 | 《史记》"受业子思之门人"——隔代受业正是"未得亲传而私淑"的史影 | 旁证坐实 |
| 反例一（一票否决） | **家产财富说**（"君子留下的家业五代败光"）若成立，"小人之泽"空转——匹夫本无世袭之常可言；且与"私淑诸人"完全接不上 | **排除**（确认为后世语用引申义，非本义） |
| 反例二 | **宿命命定说**（富贵天定、五世必衰的宿命论）若成立，孟子自任接续即成废话——他恰是要做"斩而不斩"的那个人；且孔孟心性之学不作此等断言 | **排除** |
| 反例三 | **水泽字面说**（自然惠泽如水土）——"泽"若为实物水泽，不能配"世"计年、不能配"斩"作终态 | **排除** |
| 反例四 | **讹字陷阱**："私淑"≠"私塾"——检索实见讹例，"塾"义后起且句位不通 | 排除误字路径 |
| 反例五（一票决） | **道德二分说**（君子之泽＝好影响、小人之泽＝坏影响）——先秦坏影响自有专词（《易·坤·文言》"积不善之家，必有余殃"），同一"泽"字（光润余润，古今无贬义）统摄两句必是同一性质余绪；同式复沓"X之泽，五世而斩"表同判推广，若一惋惜一庆幸则文气断裂；且"坏影响断绝"于私淑接续论证毫无贡献，反成赘文 | **排除**（确认为现代"小人"道德义的以今律古） |

- **产出**：四条反例全过，唯一确诂即第 0 节表述。

### ⑥ 防陷阱（定稿）

- **以今律古四大高发点（本例实测俱在）**：其一，泽→财产（"富不过三代"式倒灌，现代引用最普遍的漂移）；其二，五世→泛泛"几代人"或误为"五代十国"（检索实见备考干扰项）；其三，私淑→私塾（讹字活例）；其四，小人→坏人（"好影响／坏影响"道德二分——现代"小人"已道德化，先秦君子／小人首先是身份位分对〔在位者／平民〕兼德义对〔贤者／细民〕，孟子两义并用如《告子上》"从其小体为小人"；此章德位两读皆通而穷举功能不变，唯"好／坏影响"二分为"泽"字义与语篇功能双重排除，分野在人不在影响的性质）。
- **词义漂移绑定时代**：先秦本义层（流风余韵）→ 中古引申层（福泽荫庇，重荫袭）→ 现代俗谚层（家产财富）。三层各自有效，不得混装——引经据典谈"义理传承"用第一层，谈"家族兴衰"是第三层，已是两个不同的命题。
- **诚实边界**：汉赵岐注、清焦循《孟子正义》原书未及亲核，本篇未引；"小人"确指（无位者／德薄者两读）注家或有异说，标**待考**附异说。未见反例的部分（"泽"无通假说）仅作暂定。
