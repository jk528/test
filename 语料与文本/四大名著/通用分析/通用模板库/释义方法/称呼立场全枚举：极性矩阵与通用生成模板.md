# 称呼立场全枚举：极性矩阵与通用生成模板

> 文档性质：称呼系统**立场维度全枚举工程文档**——称呼三部曲之三（《亲缘称谓全枚举》血缘网络、《社会称呼全枚举》场景网络之后）。
> 分工：亲缘篇管"你是谁"，场景篇管"我们在哪"，本篇管"**我以什么身份叫你**"——同一对象、同一场景，说话人立场一换，称呼即换。本篇同时交付**称呼生成通用模板**（第 6 节，可操作的构词公式与称呼卡）。
> 生成日期：2026-11-25　|　六个重点维度：**面称／背称／自谦／敬语／自贬／蔑视**（用户点名），外加自大、亲密两条负补轴
> 计数：主表 **43**＋专表 **76**＝**119** 个枚举单位，守恒见第 7 节。

## 0. 结论（先行）

> **一句话**：称呼不是名词，是**立场的函数**——f（对象位 × 通道 × 极性 × 内外 × 场景 × 时代）→ 具体称呼。极性谱远不止敬与谦两极：**敬—平—亲密—贬—蔑**构成对彼五档，**谦—平—自大**构成对己三档，八档在三个通道（面称/背称/他称）里展开成完整矩阵。极性的三条硬规律：①**让渡分界律**（谦向对方让渡地位，贬向对方让渡人格——"家父"得体、"奴才"制度化的分界线）；②**蔑称构词律**（蔑称九成产自"职业＋等第"：或加贬缀〔臭＋老九〕、或降身份场〔大夫→戏子〕、或借贱籍〔皂隶〕——元代"九儒十丐"十等序列是其制度的完成形态）；③**蔑称挪用律**（蔑称被指称群体自己认领后攻击性归零转同盟——"牛马""码农"自称即是；与《社会称呼篇》"语用腐蚀律"恰好反向）。

**总判定表**：

| 项目 | 判定 |
| :--- | :--- |
| 系统性质 | 立场网络——对象与场景皆不变时，立场（谁叫／怎么叫／当不当面叫）仍使称呼变化 |
| 对彼极性五档 | 敬（君）→平（汝，挚友）→亲密（你小子）→贬（匹夫）→蔑（竖子） |
| 对己极性三档 | 谦（在下）→平（我）→自大（乃公——对己的"负谦称"） |
| 三通道 | 面称（当面叫）／背称（对人提）／书称（书面）——亲缘篇两栏制扩为三通道 |
| 内外维 | 家父／令尊之别：己方亲属于外人称"家"，对方亲属于己称"令"——内外就是立场 |
| 蔑称主产地 | 职业＋等第（元"九儒十丐"，谢枋得／郑思肖双源，版本异文见 C6） |
| 通用模板 | 第 6 节：三步生成器＋构词公式九式＋称呼卡 |
| 最大陷阱 | ①谦贬不分（自贬过度即失格）；②通道错配（背称词当面用／面称词书面用）；③蔑称不识史（"戏子""臭老九"的等第背景）；④极性旧档残留（"同志"在部分语境仍是敬语） |

**证据链一句话**：《礼记·曲礼》"自卑而尊人"立总纲 →《史记》"乃公"（自大自称）＋"竖儒"（蔑称）双出 →《孟子》"公输子"＋《庄子》"运斤成风"（斧正典）定敬语动词 → 谢枋得《叠山集》／郑思肖《心史》双源证"九儒十丐" → 清代奴才制（满汉臣工分途）证自贬制度化 → 现代语用（码农／牛马）证蔑称挪用律 → 矩阵与模板成。

## 1. 立场坐标系（六维）

| 维度 | 取值 | 决定什么 |
| :--- | :--- | :--- |
| D1 对象位 | 自称／对称／他称（提第三方） | 入主表哪一区（§2） |
| D2 极性 | 对彼：敬／平／亲密／贬／蔑；对己：谦／平／自大 | 入哪一带 |
| D3 通道 | 面称／背称／书称 | 面上可昵、背后须描述、书面可抬格 |
| D4 内外 | 自己人／外人 | 己方亲属于外人前称"家Ｘ"，于家中直呼 |
| D5 场景 | 承《社会称呼篇》B1–B8 | 通行词库与腐蚀状态 |
| D6 时代 | 古／今／退场中 | 极性档位随时代整体平移（"同志"从通货到戏称） |

**核心思想转变**（与前两篇的分野）：亲缘篇与场景篇都把称呼当**名词表**查；本篇把称呼当**谓词**算——先答四个问题（我以什么身份、对谁、当不当面、内外），再查词。**立场定了，词几乎是唯一的**。

**概念辨析（释义）**：

| 概念 | 定义 | 分界 |
| :--- | :--- | :--- |
| 自谦 | 礼制内自愿、得体地自降一档 | 让渡**地位**（在下、晚生） |
| 自贬 | 让渡人格或制度强制的过度自低 | 让渡**人格**（奴才、草民）；或非自愿（清代旗制） |
| 敬语 | 礼制内抬对方一档 | 有制度边界（令尊、阁下） |
| 谀语 | 越界的敬（抬到失格） | 敬语过极限即谀（"老板英明"式滥用） |
| 贬称 | 压低对方一档的对称 | 有愤怒语境（匹夫！） |
| 蔑称 | 否定对方身份资格的称呼 | 连愤怒都省了（竖子——不屑之轻） |
| 昵称 | 亲密者间的低位互称（你小子） | 贬的形式、爱的内容——**负极性正使用** |

## 8. 钩连：称呼三部曲总收

- **亲缘篇**（血缘网络）答"你是谁"：格可穷举，一人立原点全表出。
- **场景篇**（场景网络）答"我们在哪"：通货更替、语用腐蚀、拟亲借用。
- **本篇**（立场网络）答"**我以什么身份叫你**"：极性八档×三通道×内外——立场一变词变。
- 三网咬合处：拟亲属称谓是亲缘网向两网的借货口；场景通货是本篇 D5 维的词库池；而本篇的极性轴给前两篇每格加了"档位标签"——**前两篇是名词表，本篇是动词表**：拿到任何称呼，先算立场函数，再查名词表。
- 一句总收：**称呼的完整地址 = 场景（哪）＋对位（谁）＋立场（哪个我）**——三部曲即三层门牌；本篇交付的生成模板，就是把三层门牌的计算压成一张卡片的操作化。
