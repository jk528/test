## 0. 结论（先行）

> **确诂一句话**：诚实信号＝**因发送者承担了无法伪造的成本而获得可靠性的信号**——"诚实"不是发送者的品格，是**机制的结构属性**：造假成本＞造假收益，使"如实"成为唯一划算的策略（进化博弈的稳定均衡，Grafen 1990 数学证明）。孔雀的尾巴不是孔雀想诚实，是**尾巴太贵、装不起**；瞪羚弹跳不是谦虚，是**把体力余额演给狮子看**。汉译的"诚实"二字带入道德色彩而原文 honest 在技术语境已"去道德化"（an honest indicator＝如实映射的统计学用法）——**译入语的道德漂移大过源语**，中文读者读到"善良的信号"的风险远高于英文读者。信号博弈全谱三分：**诚实信号**（因贵而真）／**欺骗信号**（cheap 伪装：拟态、空谈 cheap talk）／**廉价言语**（零成本的口头声明——人类语言的默认形态，故最易通胀）。

| 项目 | 判定 |
| :--- | :--- |
| 术语归属 | 行为生态学（Zahavi handicap）＋信号经济学（Spence）＋进化博弈（Grafen）三源汇流 |
| 确诂核心 | **可靠性来自成本结构，不来自品格**——"骗不起"而非"不想骗" |
| 信号博弈三分 | 诚实信号（成本绑定）／欺骗信号（拟态伪装）／廉价言语（cheap talk，无成本约束） |
| 诚实三定律 | ①成本律：可靠性＝造假成本/造假收益＞1　②均衡律：诚实是博弈稳定均衡（单方作弊者被识破淘汰）　③军备律：诚实永被破解压力追赶（拟态军备竞赛）——可靠性是动态维持的战争，非一劳永逸 |
| 汉译色彩漂移 | honest 技术语→"诚实"道德义：**译入语日常义越强，漂移越大**（本例新增观察律，见 §6.2） |
| 判别要点 | 看信号是否与质量**成本绑定**（有真代价）＋是否**难以为低质量者模仿**（无作弊空间）——两条齐备方为诚实信号；只有"说得对"没有"付不起"的，是言语真话，不是诚实信号 |
| 最大陷阱 | ①道德倒灌（以为信号有品格——拟人化误读）；②绝对化（以为诚实信号永恒可靠——忽略军备竞赛）；③把"真话"当诚实信号（内容为真≠机制为真——无心智者说真话靠运气，诚实信号说真话靠结构） |

### 2.2 汉典书证层（机制的先秦版）

| 书证 | 原文 | 要点 |
| :--- | :--- | :--- |
| 千金买骨（《战国策·燕策一》） | "古之君人，有以**千金求千里马**者，三年不能得。……三月得千里马，**马已死，买其首五百金**，反以报君。君大怒曰：'所求者生马，安事死马而捐五百金？'涓人对曰：'**死马且买之五百金，况生马乎？天下必以王为能市马，马今至矣！**'于是不能期年，千里之马至者三" | 【A 原文多源核实】**买死马首=招募承诺的诚实信号**：燕昭王要向天下证明"我真心求贤"，空口千金悬赏是 cheap talk；**五百金实付死马首**——为不可用之物真金白银，才让"求才"贵到无法作假（成本使承诺可信——handicap 的政治学版）；郭隗之谋的下一步"今王诚欲致士，先从隗始"＝同构：**先礼遇我这个中等人才，天下人就知道你怎么对待顶级人才**——以可观察的对待行为作信号载体 |

**名恒值变巧合一枚**（系列律的又一笑点）：原文"有以**千金**求千里马"（预算额）→"买其首**五百金**"（实付额）→ 流传成语作"**千金买骨**（市骨）"——**成语把预算记成了成交**：后人转述时数值发生通胀（五百→一千），而机制未变（贵买死骨以示诚）——"名恒值变律"在成语层的又一活标本（与度量衡篇 1 斤 250g→500g 同构：名目不变，数值翻倍）。

### 2.3 生物学对照系（欺骗信号——诚实信号的反面教材）

- **贝氏拟态**（Batesian mimicry）：食蚜蝇无刺无毒，却演化出蜜蜂的黄黑警戒色——**无成本的伪装信号**（借 真 信号的外壳）；其存在证明"诚实"须以成本维系：拟态者的比例一旦过高，警戒色整体贬值（信号通胀的生物学版——**拟态频率与警戒色的可靠性成反比，恰好复刻"通货贬值于超发"**）。
- **杜鹃巢寄生**：蛋拟态宿主鸟蛋（信号欺骗）、雏鸟"超级刺激"乞食（信号操纵）——自然界不缺信号战争。
- **瞪羚弹跳**（stotting，前篇已引）：见狮不逃反跳——**纯耗能的炫耀**，正因纯耗能才是真实的存活余力证明。

### 2.4 机制的社会版本（人类学）

- **Potlatch 夸富宴**（北美西北岸原住民）：毁弃／焚烧财富以赢取地位——**毁灭性成本作为地位信号**（烧得起，才是真酋长）——诚实信号的人类学极限版（成本高到以灭示真）。
- **宗教祭品的昂贵仪式**（人类学通论【D】）：献祭贵重之物以示信仰之诚——献祭机制=信仰的 handicap（信众"舍得"即绑定；"舍不得"则暴露低成本信仰）。

## 3. 六步解析实操（专业技术版·译词改造）

### ① 读语境（定场——C 场景配置）

- 三问：**谁说**——行为生态学家、信号经济学家、博弈论者（以及被科普的大众）；**对谁**——同行评审与受训读者；**什么场合**——机制分析：解释"为什么有些信号能被信任"。
- **语篇功能**：这个词不描写信号内容（说什么），而给一类信号**命名其可靠性的来源**（为什么可信）——凡是出现"诚实信号"的论文段落，都在回答"接收方为何不担心被骗"。
- **产出**：确诂必须锁在**机制可靠性**上，不可滑向内容真实（信号说什么）或品格真诚（发送者想不想骗）——场定错，两反例即涌入。

### ② 拆词（道德词×机制词的复合结构）

| 训点 | 日常义 | 术语中的用法 |
| :--- | :--- | :--- |
| 诚实 | 品格：言行一致、不撒谎（道德条目） | **如实的均衡态：因骗不起而事实上不骗**——非意愿属性 |
| 信号 | 信号灯、暗号（信息载体） | 携带发送者不可直接观察之质量的可观察指标（学术定义链） |

- **复合张力**：日常"诚实"的主语必须是人（且是有意志的道德主体），术语"诚实"的主语却是**信号/机制本身**——"诚实的信号"在语言搭配上已属拟人句式（信号无品格），恰是术语翻译的**借喻定格**：把"结果上不可骗"压缩成"诚实"，**道德词征用作机制词**——拆词即见陷阱之源。
- **产出**：确诂必须保留"机制非品格"限定，防日常义倒灌。

### ③ 追声音（跨语追源——译词的新追踪法）

- 传统通假排查（本词无古语通假层）。
- **译词回查**（C+F 复合场景新动作）：回查源词 honest 在英文技术语境的语义衰变史——honest 在统计/测量语境的 "honest estimate"（如实估计）已**非道德义**（估准，不关操守）；生物学 honest signal 承此"如实映射"义并加机制化（**因成本结构而如实**）。
- **漂移观察律候选（本例新发现）**：**译入语的日常义越强，译词的色彩漂移越大**——英文 honest 在技术语境去道德化程度高（技术读者少误解）；中文"诚实"至今仍是道德语汇的常青词（"诚实守信"为社会主义核心价值观条目），日常义密度更高——故**中文读者对同一术语的道德化误读风险系统性高于英文读者**。术语翻译的**漂移不对称律**：翻译不是无损管道，是密度过滤器——**源语里已消散的联想，译入语可以复活**（"诚实"复活了 honest 早已卸下的道德联想）。
- **产出**：确诂附"译词漂移注"——读"诚实信号"时先把道德系数手动清零。

### ④ 查书证（原始论文锚定——C 场景的主力步）

- 权重阶梯实测：原始论文（Zahavi/Grafen/Spence：机制发生学与数学定型）＞ 教科书（博弈框架标准化）＞ 科普（MIT 媒体实验室测量学外延）——与 A 场景"多书证互勘"不同，**C 场景靠定义链定版**：一个术语的确诂锚在**首次数学化定义**（Grafen：成本结构使如实成为 ESS）——此后一切用例（孔雀、文凭、夸富宴）都是**机制的应用例证**，不参与义项建构。
- **机制核验三问（本步新工具）**：判定一个行为/信号是否诚实信号：①**有无真实成本**（有代价吗）？②**成本与质量绑定吗**（强者/诚者付出更低成本或获得更高回报吗——Spence 不对称）？③**作弊空间封死了吗**（低质量者模仿成本＞模仿收益吗——Grafen 均衡）——三问全过方为诚实信号。
- **产出**：确诂＋判别三问。

| 反例三 | **绝对可靠说**（"凡诚实信号永久可信"）——贝氏拟态证明：警戒色（典型诚实信号）可被无刺蝇寄生模仿；军备竞赛不息，诚实只是**均衡态+动态维持的战争**（信号者继续付成本升级信号；拟态者被识破则退潮）——可靠性有程度、有期限 | **排除**（绝对化） |
| 正例四（外延） | MIT 媒体实验室《Honest Signals》：把"难以伪装的无意识通道"(声调、姿态、停顿) 当作测量对象——术语外延至人际测量 | 外延义附列（承继"难伪装=诚实"机制核） |
