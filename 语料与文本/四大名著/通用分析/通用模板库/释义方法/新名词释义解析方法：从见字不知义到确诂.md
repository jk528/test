# 新名词释义解析方法：从"见字不知义"到"确诂"

> 用途：解决"每个字都认识，合在一起不知道什么意思"的问题——尤其针对古籍、专业术语、方言旧词中的陌生名词。
> 目标：把零散的猜词经验，变成一套可复现、可自检的释义操作流程。

## 纲领（全文统摄）

> 一句话：**把"猜词"变成"证词"——从"讲得通"推进到"非它不可"。**

**内核三句：**

1. **方法**：前四步（读语境、拆形构、追音源、查书证）挖出全部候选义项，后两步（正例立可通、反例定必然）收敛到唯一。反例优先于正例——一万个正例证明不了，一个反例足以推翻。
2. **场景**：六步是工具箱不是流水线。场景不改写方法，只决定三件事——哪步当主力、证据信谁、换哪份陷阱清单。古语词与新闻词不是两套方法，是两种配置。
3. **立论**：语言要稳定、现实一直在变，新词是这对矛盾的泄压阀；它把描述成本从说话人转给听话人，所以新词越多、释义需求越大。

第十四例开两个新方向（详见 9.14/9.15）：**C 场景专业技术完整实测**——权威阶梯（原始论文＞教科书＞科普）与定义链定版落位：确诂锚在首次严格化的定义（Grafen 数学证明），此后一切用例只是机制的应用例证不参与义项建构，机制核验三问（成本／绑定／无作弊空间，诚实信号篇实测定型）为 C 场景贡献判别工具，A/C 两场景证据法以"是否同构"互认（千金买骨＝handicap 汉典版）；**译词漂移入册**——源语已卸下的联想可被译入语日常义复活（honest 技术语去道德化 vs "诚实"道德语汇常青），漂移量与译入语日常义密度成正比，与回灌词构成跨语陷阱两支（概念入侵 vs 色彩沾染），定为元规则 15。**总结论：六步骨架十四例未破；C 场景自本例由一格矩阵升为全流程配置。**

> **系列计数勘误**：早期测试版自计编号互有出入（亲族四概念与君子之泽五世而斩均自计"第七"）。按真实创建序统一重排：亲族四概念＝第七、君子之泽＝第八、奋六世＝第九、度量衡＝第十、不负如来＝第十一、诸子百家＝第十二、儒释道＝第十三、诚实信号＝第十四（C 场景首例完整实测＋跨语译词层）；《亲缘称谓全枚举》《余绪语义场全枚举》两篇为枚举工程文档，不入实测序列。

## 0. 问题界定

### 0.1 三种典型困境

| 困境 | 表现 | 例子 |
| :--- | :--- | :--- |
| 字面认识，义项不明 | 字都认得，合起来不知指什么 | "考终命""攸好德" |
| 古今义错位 | 拿现代常用义套古文，越套越错 | 以"考试"解"考"，以"妻子"解"妻财" |
| 专业术语误用 | 同一个词在日常与专业语境含义不同 | 八字里的"妻财"是一个术语，非两件事 |

### 0.2 两个境界：可通 vs 确诂

- **可通**：某个义项放进句子里讲得通——这是最低门槛，不是终点。
- **确诂**：不止此义可通，而且**非此义不可**——这才是释义的终极目标。

本方法全部围绕一件事：如何把"讲得通"推进到"非它不可"。

### 0.3 为什么新词层出不穷：立论根源

- **根本矛盾**：语言要稳定才能交流，现实却一直在变。新词是这对矛盾的泄压阀——旧词指称不了新现象（有物无名）、完整描述太长（繁 vs 简）、旧词边界太宽（粗 vs 细）、表述需要带态度（中性 vs 态度），都要靠造词化解。
- **矛盾的转嫁**：新造词并未消灭矛盾，而是把"描述成本"从说话人转给听话人——说的人省一句解释，听的人得先学会这个词。**新词越多，释义需求越大，这正是本方法的用武之地**。
- **一个边界**：新造词 ≠ 旧词新义。前者解决"无名"，后者解决"旧词不够用但造新词太贵"——后者正是第 8、9 章"旧词新义混淆"陷阱的来源。

## 1. 核心原则：三句口诀

> **字形定本源，声音定通假，语境定实义，书证定时代。**
> **正例立其可通，反例定其必然。**
> **未见反例只是暂定，遇一反例全局重审。**

- 第一句管"找候选义项"——从形、音、境、证四个方向把可能的义项都挖出来。
- 第二句管"定唯一义项"——用正反两股力量把候选义项收敛到一个。
- 第三句管"诚实边界"——永远为反例保留推翻权。

## 2. 六步解析法

### 第一步：读上下文（定场）

- **不猜**，先把整句、整段读完，圈出这个词和哪些词搭配。
- 判断语境三问：**谁说的？对谁说？什么场合？**
- 语境决定义项的选择范围。"五服"在《仪礼·丧服》里是丧服制度，在春节口彩里是"五福"，在命理书里又是另一套——脱离语境无法释义。
- 句子型对象（整句格言／诗句）在此步加**第四问：这句在章内干什么？**（语篇功能问）——句子的义约六成不在字内而在章位功能（立律／造势／张本／认输，详见 9.8.5）。

### 第二步：拆字形（以形索义）

- 看偏旁，形声字的**形旁点出意义类属**。
  - 例："福""禄"皆从"示"（祭祀），本义都与祭神祈福相关。
- 注意边界：形旁表**类属**不表**具体义**，不可过度推断。"从示"只能说明与祭祀相关，不能直接推出具体是哪个福。

### 第三步：追声音（因声求义）

- 古书大量同音通假与谐音，望文生义必踩坑。
  - 例："考"通"老"（考妣＝已故父母）；"蝠"谐音"福"（五福捧寿图案）。
- 古今音不同，需借工具书（见第六步）确认通假关系，不能凭今音硬配。

### 第四步：查书证（列候选义项）

- 分两层用工具书：
  - **探本义**：《说文解字》《尔雅》《释名》
  - **查流变**：《汉语大词典》《汉语大字典》、汉典网、"中国哲学书电子化计划"
- **关键动作**：看每个义项下**第一个书证出自哪本书、哪个年代**——这决定该义项是古义还是后起义。
- **制度词先找定义句、句中数字先走确证路径**——制度词多自带定义句直接命中义项；数字（五世、六世）多为制度或史实实指，先锚定（文外制度／文内枚举／定义句＋实物三路径）再谈虚数（详见 9.10）。
- 此时**只列不选**：把所有候选义项摊开，暂不判定。

### 第五步：正反验证（定确诂）——核心环节

详见第 3 章。这一步是把"候选义项"收敛到"唯一确诂"的关键。

### 第六步：防陷阱（定稿）

- **以今律古**：拿现代常用义套古文。"考试"是后起义，《洪范》成书时无此义。
- **词义漂移**：扩大、缩小、转移。同一个词跨朝代含义会变，必须绑定时代谈义。
- 定稿前对照第 6 章自检清单过一遍。

## 3. 正例与反例：确证机制

### 3.1 可通与确诂的矛盾

一个词往往有多个义项，套进句子可能三四个都"讲得通"。此时正例与反例干的是两种不同的活：

| | 解决什么 | 作用 |
| :--- | :--- | :--- |
| **正例** | 存在性 | 证明这个义项在此类语境里真有人这么用，不是臆造 |
| **反例** | 排他性 | 证明其他竞争性义项在这个语境里讲不通 |

只有正例没有反例，就停在"可通"层面——找到三个支持义项A的例子，但也许支持义项B的例子有十个，只是没去看。这是**确认偏误**。只有把竞争性义项用反例一个个打掉，才能从"可通"升到"确诂"。

### 3.2 反例优先原则

这是有限证据与全称结论的矛盾：一万个正例也证明不了第 10001 个不推翻它（休谟问题），但**一个反例就能掀翻整个解释**。

> 考据中的不对称法则：**反例优先于正例**。正例给可信度，反例给确定性。

### 3.3 对立词定位法

用反义词反推本义，是最省事的定位招。

- 知道"凶短折"是"寿"的反面，"考"字就不可能训为"考试"。
- 文档实践中：五福的"反义"列本质就是反证器——六极逐项打在五福背面，把每一福钉死在它该在的位置上。

### 3.4 证据权重分级

正例反例不等价，按下表定权重：

| 权重 | 证据类型 | 说明 |
| :--- | :--- | :--- |
| 高 | 同时代、同体裁、直接语境 | 三个同时代用例顶十个后世转述 |
| 中 | 同时代、异体裁 | 可作旁证 |
| 低 | 异代、异体、后世注疏转引 | 仅作参考，需回溯原典 |

### 3.5 诚实边界

- 找不到反例，只能说"**未见反例**"，不能说"没有反例"。
- 这是考据的底线：为未来可能出现的反例保留推翻权。

## 5. 完整案例演示：以"考终命"为例

现场把六步走一遍：

**① 读上下文**：《尚书·洪范》："五福：一曰寿，二曰富，三曰康宁，四曰攸好德，五曰考终命。"——与寿、富、康宁并列，都是人生的好状态，故"考终命"必是**吉语**，不是中性或凶义。

**② 拆字形**："考"从老省、丂声，本义与"老"相关——锁定了"年长/寿"的方向，排除了"考试"的字面联想。

**③ 追声音**："考＝老"（考妣＝已故父母），"终"与"考"义近复用，"考终"即"老终"。

**④ 查书证**：《说文》："考，老也。"郑玄注："考终命者，老而终其天命。"首见先秦两汉，与《洪范》时代匹配。

**⑤ 正反验证**：
- 正例：先秦两汉多处以"考"训"老"，存在性坐实。
- 反例：若训为"考试"，则与"寿""富""康宁"并列不通；且《洪范》成书时科举未兴，"考试"义尚未产生——排他性坐实。

**⑥ 防陷阱**：识别"以今律古"陷阱——"考试"是后起义，不能倒灌进先秦文本。

**确诂**：考终命＝寿数尽时安稳离世，善终，不遭横祸病痛折磨。

## 8. 新闻新词适配版（含实测案例）

> 前述六步法原为古语词设计。实测新闻新词后发现第 2、3 步失灵，需改造；其余四步通用。本章给出适配版与完整实测案例。

### 8.1 为什么要适配

- 古语词多有**字形与通假**问题，故"拆字形""追声音"是主力。
- 新闻新词多为**合成词与外来借词**，字形不含古义、也无通假，硬套前两步会落空。
- 但"语境定场、书证定年代、正反验证、对立词定位"四步对新闻词**完全通用**，且反例优先的威力更大——新词常被媒体滥用扩大范围，没有反例一票否决，极易把特指误解为泛指。

### 8.2 六步改造对照

| 步骤 | 古语词版 | 新闻新词版 | 改造理由 |
| :--- | :--- | :--- | :--- |
| 1 读上下文 | 读整句整段 | 不变 | 语境定场通用 |
| 2 拆字形 | 以形索义，看偏旁本义 | **拆构词法**：偏正/动宾/缩略，看中心词比喻 | 新词是合成词，义在构词不在字形 |
| 3 追声音 | 因声求义，查通假 | **追词源**：外来语/旧词新义/方言借入 | 新词多借词，义在来源不在通假 |
| 4 查书证 | 看首见书证年代 | 不变，但**首见年代更关键** | 新词寿命短，年代直接定义项 |
| 5 正反验证 | 正例立义，反例破义 | 不变，**反例优先更用力** | 媒体滥用需一票否决划边界 |
| 6 防陷阱 | 以今律古、词义漂移 | 改为**防滥用扩大化、防旧词新义混淆** | 新词陷阱在传播中变形，非古今错位 |

**新闻新词口诀**（在前三句基础上替换前两句）：

> 构词定中心，词源定借入，语境定实义，书证定年代。
> 正例立其可通，反例定其必然。
> 未见反例只是暂定，遇一反例全局重审。

### 8.3 新闻新词的证据权重

| 权重 | 证据类型 | 例子 |
| :--- | :--- | :--- |
| 高 | 官方通报、权威文件、词典收录 | 中央网信办"清朗"通报、《韦氏词典》年度词 |
| 中 | 权威媒体报道、机构评论 | 人民论坛、潮新闻评论 |
| 低 | 百科词条、自媒体解读、热词盘点 | 百度百科、头条热词文 |

判断义项以高权重证据为准；低权重只作线索，不作定论。

**补充规则（据"电子布洛芬"实测回写）**：网络情感词往往无权威词典收录，高权重证据缺位。此时以**三源以上共识**坐实义项——百科、机构报告、主流媒体解读若指向一致，可替代单一权威书证；但须在结论中标注"无权威收录，依多源共识"。

### 8.4 实测案例：数字泔水

**① 读上下文**：出现在网信办通报与人民论坛评论中，语境全是"整治、毒害、污染"——先锁定为**贬义**的某类内容，非中性技术词。

**② 拆构词法**（改造版）：偏正结构，"泔水"是中心词。泔水本义为淘米洗菜后的废弃水、潲水，引申为**无营养的废弃残余**——这个比喻是理解全词的钥匙。

**③ 追词源**（改造版）：对应英文 **slop**，被《韦氏词典》列为 2025 年度词汇；中文为**意译**（取"泔水"的比喻）而非音译。

**④ 查书证**：首见 2025（韦氏 slop）→ 2026.3 网信办通报进入官方话语 → 4 月"清朗"行动第二阶段列为整治对象 → 媒体（人民论坛、潮新闻）跟进。义项稳定为"AI 批量生成的低质数字内容"。

**⑤ 正反验证**：
- 正例：AI 魔改名著、毒动画、低俗换脸、虚假信息——存在性坐实
- 反例（一票否决）：不是餐厨泔水；不是泛指一切烂片；也不等于"AI 洗稿"（后者是盗取骨架，前者是量产垃圾）——排他性坐实

**⑥ 防滥用扩大化**：人民论坛原文以"活水来源"对举普通创作者，"泔水 vs 活水"把边界钉死。

**确诂**：用 AI 低成本批量炮制、逻辑荒诞价值空洞、污染网络生态与公众认知的低质数字内容。

### 8.5 两版适用判别

| 判别信号 | 用古语词版 | 用新闻新词版 |
| :--- | :--- | :--- |
| 单字成词、有形旁 | ✓ | |
| 存在通假/古今音变 | ✓ | |
| 合成词、缩略词 | | ✓ |
| 外来借词、旧词新义 | | ✓ |
| 首见年代在近五年 | | ✓ |
| 语义在传播中漂移 | | ✓ |

两版可混用：先按判别信号选主版本，另一版的相关步骤作补充验证。

## 9. 使用场景全谱：不止古语词与新闻词

> 前述两版只是六个场景中的两个。六步法本质是一个**工具箱**：场景不改写方法，只决定"哪几步当主力、证据权重怎么排、换哪份陷阱清单"。本章把使用场景补全。

### 9.1 场景的两种切法

- **按词的来源/领域切**（本章主线）：典籍文献、新闻传播、专业技术、官方话语、民间生活、跨域外来——六类。
- **按使用目的切**（见 9.4）：读懂一段话、精准表达、考据溯源、辨伪防骗、学习积累——五种目的可叠加在任一领域上。

两套切法正交：先按领域选主力步骤，再按目的定详略深度。

### 9.2 六大领域适配矩阵

| 场景 | 代表词 | 主力步骤 | 首选证据 | 特有陷阱 |
| :--- | :--- | :--- | :--- | :--- |
| **A 典籍文献** | 考终命、攸好德、成语典故 | 2 拆字形 + 3 追声音 | 原典注疏（说文/尔雅/郑玄注） | 以今律古、通假误判 |
| **B 新闻传播** | 数字泔水、已读乱回、配得感 | 2 拆构词 + 3 追词源 + 5 反例 | 官方通报、权威媒体、词典收录 | 滥用扩大化、旧词新义混淆 |
| **C 专业技术** | 善意取得、对冲、诚实信号 | 1 定场 + 4 查权威定义 + 5 反例 | 原始论文、学科辞典、国标、教材（权威阶梯见 9.15） | 日常义套专业义（"善意"≠好意）、定理绝对化、译词漂移（9.14/9.15） |

| 辨伪防骗（识别话术/谣言） | 重第 1、4、5 步 | 锁定权威出处，反例一票否决 |
| 学习积累（词汇/语言） | 2、3、6 步为主 | 记构词理据与陷阱，形成长期记忆 |

### 9.5 跨场景补充案例

**案例一：专业技术类——"善意取得"**（法律术语）

- ① 定场：出现在物权法语境，非日常对话——"善意"是法律术语
- ④ 查权威定义：指受让人不知且无重大过失地取得物权，法律予以保护
- ⑤ 反例一票否决：日常"善意＝好意" Peterson 套不进法律定义；明知转让人无权处分者不构成善意
- **确诂**：无重大过失、支付合理对价、依法完成登记或交付而取得物权

**案例二：民间生活类——"埋单"**（粤语借入）

- ③ 追词源：来自粤语，源自茶楼"埋数"（结账、"埋"有聚合结算义）
- ① 语境三问：餐馆场景、顾客对服务员说——确认是结账义
- ⑥ 防字面硬解：不是"埋葬单据"
- **确诂**：在餐馆等消费场所结账付款（粤语借词，已入普通话）

**案例三：官方话语类——"新质生产力"**（政策术语）

- ① 定场：出自政策文件与领导讲话，非general概念讨论
- ④ 原文为准：以文件原文定义为准（创新主导、高科技、高效能、高质量）
- ⑥ 防望文生义：不等于"新的生产力"字面，也不能随个人理解伸缩
- **确诂**：由技术革命性突破、生产要素创新性配置等形成的先进生产力

### 9.6 场景判别速查

| 你拿到一个词，先问 | 归属场景 |
| :--- | :--- |
| 出自古籍、有通假、字形含古义？ | A 典籍文献 |
| 近五年冒出、媒体刷屏、官方在整治/推广？ | B 新闻传播 |
| 某行业专用、外行看不懂、有教科书定义？ | C 专业技术 |
| 出自红头文件、领导人讲话、官方发布？ | D 官方话语 |
| 方言口语、街巷俗语、圈层昵称？ | E 民间生活 |
| 有外文原形、音译/意译、年度词榜可见？ | F 跨域外来 |

一词可跨场景（如"泔水"既是日常词又被新闻借用）：**按当前文本语境定场景**，不按词的"出身"定。

### 9.7 全场景通用底线

无论哪个场景，三条不变：

1. **反面检验不可省**——凡义项有争议，必须走反例；无反例可检验时标"暂定"
2. **证据分权重**——权威原文 > 二手解读 > 自媒体；同时代 > 后世转述
3. **诚实标注**——争议处"待考"附异说；找不到反例写"未见反例"而非"没有反例"

**第 4 条（据"电子布洛芬"实测回写）**：**喻体属性须完整带入**——对"药物/食品/玩具"类比喻新词，定场时多问一句"喻体的哪个属性被带入了？"。布洛芬的"治标不治本"正是词义组成部分，漏掉即释义失真。这条把第 1 步（定场）与第 5 步（反例）之间原本隐含的动作显式化。

## 9.8 第三个维度：单词 vs 词组（据"开门七件事"实测回写）

前三个实测词暴露：除了"领域"（第 9 章六大领域）与"目的"（9.4 定深度），还有一个独立维度决定步骤配置——**单位是单词还是词组**。前两例（数字泔水、电子布洛芬）都是偏正单词，第三例（柴米油盐酱醋茶）是七项并列词组，第 2、3、4 步全部改造。

### 9.8.1 单词 vs 词组：步骤配置对照

| 步骤 | 单词（偏正，有中心词） | 词组（并列，无中心词） |
| :--- | :--- | :--- |
| 第 2 步 拆形构 | 找中心词，比喻即钥匙（布洛芬＝止痛） | 无中心词，改**分类列举**（柴/米/油/盐/酱/醋/茶＝燃料/主食/烹调/调味/饮品） |
| 第 3 步 追音源 | 追通假（古）或词源（新） | 纯名词词组无通假、无借入→改**追源流演变**（宋八件→元七件→明定型） |
| 第 4 步 书证 | 定首见年代（辅助证据） | **年代差本身构成义项**——意义分层由书证锚定，升为主力步骤 |
| 第 5 步 反例 | 排字面义／防扩大化 | 新增两种用法：**以年代排误**（排"自古七件"）＋**以集合属性确立底色**（茶非生理刚需却入选→"必需"是社会建构） |
| 主力配置 | 2/3/5 | **3/4/5** |

### 9.8.2 第 4 步的第二种用法：年代差即义项

此前案例中，书证只负责"定首见年代"，属辅助证据。词组案例显示第 4 步还有第二种用法：**当一个集合的构成随年代变化时，年代差本身就是意义分层**。

以"开门七件事"为例：

- 宋《梦粱录》作八件（含酒）→ 早期"必需"含社交／礼俗性饮品
- 元代去"酒"成七件 → "必需"标准收窄为日常刚性
- 明清入诗（唐伯虎、张璨）→ 衍生清贫自嘲与雅俗落差义

三个年代三层意义，全部由书证差异锚定。此时第 4 步不再是"查完年代交给第 5 步"，而是**直接参与义项建构**。

### 9.8.3 判别规则

拿到词先加一问：**这是单词还是词组？**

- 有中心词、可拆偏正/动宾 → 走单词配置（2/3/5）
- 多项并列、无中心词 → 走词组配置（3/4/5），第 2 步改分类、第 3 步改追源流、第 4 步升主力

与"领域×目的"两维正交，形成**三维定位**：领域（哪步主力）＋目的（做多深）＋单位（怎么拆）。三词实测命中的是三个不同格子：B/单词/考据、B/单词/考据、E/词组/考据。

### 9.8.4 词组的三种结构型（据"东南西北 vs 东西南北"实测回写）

词组内部此前只分两型，第六案例暴露第三型——**意义可能不在"是哪几项"，而在"按什么顺序排"**：

| 结构型 | 意义所在 | 第 2 步拆法 | 代表词 |
| :--- | :--- | :--- | :--- |
| 实体集合型 | 项目的集合与必需性 | **分类列举**（柴/米/油/盐/酱/醋/茶＝燃料/主食/烹调/调味/饮品） | 柴米油盐酱醋茶 |
| 关系坐标型 | 项与项的空间／逻辑关系 | **拆关系结构**（东西横轴／南北纵轴，隐含"中"） | 东南西北 |
| **序构型** | **排列顺序本身** | **拆排列结构**（环行顺次 vs 两两对举） | 东南西北／东西南北 |

**序构型的判别**：词素完全相同、仅语序不同的两个词若义项随之改变（且非同义换说），即为序构型。此时语序是义项载体——东南西北（环行顺次，配四时五行相生，表秩序顺天）与东西南北（两两对举，泛举"到处"，带凄惶意）不可互换。

**配置影响**：第 2 步从"拆构成"扩到"拆排列"，第 5 步新增"反例排同义说"——用"24 种排列汉语仅通行两序""典籍严守次序"等证据一票否决"两序可互换"的浅解。与"年代差即义项"（9.8.2）并列，同属第 4、5 步在词组场景下的深化用法。

**口诀补充（并列序构词专用）**：偏正词"构词定中心"，并列词则**"排列定义项"**——先看是环行顺次还是两两对举，再定其时空含义。

### 9.8.5 单位第三档：句子（据"君子之泽""奋六世""不负如来不负卿"实测回写）

句子没有中心词可拆、不止集合与排列——其义分布在**关键词群＋句法结构＋语篇功能**三层，任一层缺失即不收敛。三例（论断／铺陈／反诘）检验后，句子档配置定型：

| 配置点 | 句子型做法 | 依据案例 |
| :--- | :--- | :--- |
| 第 1 步＋**第四问**（语篇功能） | "这句在章内干什么？"——立律（为全称断言铺底）／造势（欲抑先扬首环）／张本（为下文接续预设）／认输（自陈绝境） | 五世而斩（张本）、奋六世（造势）、安得句（认输） |
| 第 2 步＝**关键词群逐训＋结构分析** | 训点各跑一遍单词流程，再做句法结构分析：对举分两亚型（**穷举型**——两端并立括尽一切→全称律；**冲突型**——两端互斥→必负其一）；铺陈句抓**动词链**（首环定调、链条升级） | 君子／小人（穷举）、如来／卿（冲突）、奋—振—吞—履—执—鞭笞（七动作链） |
| 第 4 步＝**数字专名锚定** | 经句数字多为制度或史实实指，先锚定再谈虚数 | 五世（《礼记·大传》丧服律）、六世（原文列名自注） |
| 第 5 步＝**言说者立场检验**（常备反例位） | 站说话人而非读者立场——宿命说／励志说／承诺说三连命中同一病灶：读者立场覆盖作者立场 | 三例反例表 |

**句子型内部分三文类**：论断句（立律）、铺陈句（造势＋动词链）、反诘抒情句（判定词＋极性）。骨架配置同（主力 1/2/4/5），第四问答案与结构动作随文类切换。

**摘句极性反转（判定词效应）**：反诘句判定词（如"安得"）被摘去后句子仍语法自足而极性全反（绝望变誓约）——**判定词的位置决定语用漂移的难易**；引用名句先补全判定框架。

### 9.8.6 单位第四档：词群（据"亲族四概念"实测回写）

近义词组同场（祖宗十八代／九族／五服／六亲）：确诂目标从"唯一含义"扩为"**边界划分＋异说分层**"。

| 配置点 | 词群型做法 |
| :--- | :--- |
| 第 1 步 | 定诸词共同场，逐词过三问 |
| 第 2 步 | 分类列举＋**切轴比较**——各词各切什么轴（辈分／族界／亲疏／核心），轴不同即边界 |
| 第 4 步 | 改**择异说分层**：异说并存不硬择一，按证据权重＋制度实证分"通行说＋别说"，写"通行说 X，另有 Y 说（出处）" |
| 第 5 步 | 主战场改**划边界**——反例专打"混同"（四词同义？九族＝五服？），边界钉死即完成 |

**产出形态**：词群的成果是"边界总表"而非"确诂一句话"——四把刀各切一轴，合为一张网络。

## 9.9 第四个维度：单场 vs 多场（据"东南西北风"实测回写）

前四词各有一个确诂，第五词（东南西北风）第一次出现**同一串字、多个确诂并存且无法归并**的情况——麻将牌／气象农谚／文学意象／八风典故，四义各有充分书证，彼此排斥。这暴露了第四个维度：**一个词是单场（一义）还是多场（多义并列）**。

### 9.9.1 单场 vs 多场：流程结构对照

| 方面 | 单场词（前四例） | 多场词（东南西北风） |
| :--- | :--- | :--- |
| 确诂数 | 1 个 | 多个并列，无法归并 |
| 第 1 步 定场 | 辅助——定范围、定褒贬 | **总开关**——决定走哪一场，场错则全错 |
| 第 2—6 步 | 对整词跑一遍 | 对**每个场各跑一遍** |
| 第 4 步 书证作用 | 定年代／年代差即义项 | **划分义场边界**——证明每场确诂成立且互斥 |
| 第 5 步 反例功能 | 排字面义／防扩大化／缺项破题 | **跨场排误**——防把 A 场义套进 B 场 |
| 决策表 | 收敛唯一解 | 改为**分场判定表**——场—义一一对应 |
| 输出结构 | 线性六步 | **树状：先分场，再分跑六步** |

### 9.9.2 判别规则：什么时候是多场词

拿到词，做完定场后加一问：**这些义项能不能归到一个上位义？**

- 能归并（如"五服"在丧服/五福/口彩各有义，但都与"五×"相关，可视为引申链）→ 单场词，按引申链处理
- **不能归并**（如"东南西北风"，牌/雨/外力/八卦风无共同上位义）→ 多场词，走树状流程

补充信号：多个场各有**独立且充分**的书证、场间互斥（牌桌无晴雨、竹石无牌桌）、且无历时引申关系——三条同时满足即判定多场。

### 9.9.3 多场词的操作步骤

1. **列出所有场**——先不释义，只问"这词会在哪些场合出现"，穷举场（麻将/气象/文学/八风）。
2. **逐场定场**——对每个场回答三问（谁说/对谁说/什么场合），锁定该场语境。
3. **逐场跑六步**——每个场内独立走第 2—6 步，得出该场确诂。
4. **跨场反例**——专门检查场间串味：把 A 场义套进 B 场是否讲不通，讲不通则场边界成立。
5. **分场输出**——按场列确诂，标明判别信号，不强行归并、不给"统一义"。

### 9.9.4 四维定位总表

至此方法定位由四个正交维度构成：

| 维度 | 问什么 | 决定什么 |
| :--- | :--- | :--- |
| 领域（第 9 章六大领域） | 什么场合的文本 | 证据信谁、换哪份陷阱清单 |
| 目的（9.4） | 为什么释义 | 做多深（读懂/表达/考据/辨伪/学习） |
| 单位（9.8） | 单词还是词组 | 第 2、3 步怎么拆 |
| 单/多场（9.9） | 一义还是多义并列 | 流程是线性还是树状 |

六案例实测命中：数字泔水 B/单词/单场、电子布洛芬 B/单词/单场、柴米油盐酱醋茶 E/词组/单场、东南西北 E/词组/单场、东南西北风 跨场/单词/多场、东南西北／东西南北 A/词组序构型/单场。第七至第十三例续检：亲族四概念 A/词群/单场、君子之泽五世而斩 A/句子（论断）/单场、奋六世之余烈 A/句子（铺陈）/单场、度量衡 A/词组（制度枚举）/单场、不负如来不负卿 A/句子（反诘抒情）＋译文层/单场、诸子百家 A/词组（双层）/单场、儒释道 A/词组（异源并称）/单场、诚实信号 C/单词（专业技术）＋译词层/单场。

## 9.10 数字与量值判据（据"亲族四概念""奋六世""度量衡""诸子百家"实测回写）

集合总称里的数字与数值，四例合并出三条通则：

**其一，数恒项变（计数层判据）**：总称数字多为文化刻度而非计数。判定动作——**问数字先问计数层**：同一词的数字可在不同层级各对实数（成员级／等级级／流派级／著作级），层不同则实数不同而刻度恒定。"百家"三层实测无一为百：先秦二显学（《韩非子》）、汉十家（刘歆班固）、《艺文志》著录著作百余种。

**其二，名恒值变（朝代判据）**：制度词词形恒定而量值逐代漂移（汉 1 斤约 250g→唐大制约 661g→清库平约 596.8g→今市制 500g）。判定动作——**数值绑定朝代＋实物书证**：历代文献互相抄旧值，唯出土器不撒谎，考古实测与文献互校。与"数恒项变"成对偶：一边数字恒定成员流动，一边名目恒定数值流动。

**其三，数字确证三路径**：①**文外制度锚定**（五世→《礼记·大传》丧服律）；②**文内枚举自注**（六世→原文列名六君）；③**定义句＋实物锚定**（衡制进制→《律历志》定义句＋出土权量实测）。遇数字先跑三路径，跑不通再考虑虚数——"约举说"是懒解。

## 9.11 并称集合分类学与语序四档制（据"度量衡""诸子百家""儒释道"实测回写）

**结构四型**：

| 型 | 成员关系 | 代表 |
| :--- | :--- | :--- |
| 平列型 | 同类互补 | 柴米油盐酱醋茶 |
| 门类型 | 分域并举 | 度量衡（制度门类）、儒释道（教化门类） |
| 双层型 | 生成链（产出者×产出物） | 诸子百家（人×派，子先家后） |
| 异源型 | 命名来源不同构 | 儒释道（职业名＋祖姓＋义理名——两土生＋一外来） |

**语序四档＋三问判据**（元规则 10 完整版）：

| 档 | 表现 | 代表 |
| :--- | :--- | :--- |
| 强敏感 | 异序异义 | 东南西北／东西南北 |
| 弱敏感 | 倒序偶见而正序含生成链 | 诸子百家 |
| 首固尾浮 | 首位恒定（政治正统）、后位浮动（教争） | 儒释道（儒恒首，道释可换） |
| 不敏感 | 纯引用惯例，变序同义 | 度量衡（三序并存） |

三问判据：换序是否改变 **（a）义项、（b）生成时序、（c）成员地位**——依次为"是"则强／弱／首固尾浮，皆"否"则不敏感。**语序敏感是例外，不敏感是通则**。另附**定型四机理**（词形如何长出）：生活筛选（柴米）／立法钦定（度量衡）／簿记收纳（诸子百家——目录学定型）／论衡政治（儒释道——排序即政治）。

**对举两亚型**（句法层，与并称表互补）：穷举型（两端并立括尽一切→全称律）vs 冲突型（两端互斥→必负其一）。混读两型是高发误源——"君子／小人"读成对立冲突、"如来／卿"读成并列兼容，皆错。

## 9.12 翻译文学与托名：译文层配准（据"不负如来不负卿"实测回写）

翻译文学（及一切转译名句）释义前，先做**文本层分字**——确诂必须绑在正确的层上：

| 层 | 归属 | 动作 |
| :--- | :--- | :--- |
| 原作层 | 原作者 | 依首译直译重述诗境，勿拿译语充原作亲笔 |
| 译语层 | 译者 | 译笔造语的著作权属译者，署原作者即错层 |
| 传播层 | 大众 | 托名、摘句、改写各归档为引申层，不与本义争 |

**托名池现象**：诸子书（古托先师——道统背书）与仓央嘉措（今托名人——流量背书）为署名经济学的古今两代，引用文本前先验署名层真伪。**摘句效应**同判定词效应（9.8.5）：反诘句去判定词即极性反转，摘句引用前先补全判定框架。

## 9.13 第三层陷阱：回灌词（据"儒释道"实测回写）

陷阱清单原有两层——以今律古（古今义错位）、望文生义（字面硬解）。第三层为**翻译时代回灌**：近代以日译西学术语重构汉语古词（"教""经济""封建"同一病灶家族），古词被悄悄注入新概念框架。判定动作：**先分层再今解**——"儒释道"之"教"在原文语境＝"上所施，下所效"的教化，非宗教义；"儒教是不是宗教"之争的一半是回灌层错，而非学术问题。

## 9.14 第四层陷阱：译词漂移（据"诚实信号"实测回写）

陷阱清单第三层（回灌词）是"概念倒错"——外来概念框架重解本土古词；第四层方向相反：**译入语日常义给源语术语言重新染色**。以"诚实信号"（honest signal）为例：honest 在英文统计／测量语境已"去道德化"（an honest estimate＝如实估计，不关操守），汉译"诚实"至今仍是道德语汇常青词——**源语早已卸下的联想，译入语把它复活了**（中文读者系统性地把机制词读成品格词，风险高于英文读者）。

**译词漂移不对称律**（元规则 15）：翻译不是无损管道，是密度过滤器——源语与译入语对同一词的日常义密度不对等，**漂移量与译入语日常义密度成正比**；源语已消散的联想译入语可复活，反向（译入语比源语更"素"）罕见。同为跨语陷阱，回灌词**搬概念**（拿外来框架解本土古词），译词漂移**染色彩**（源语已卸的联想被译入语日常义重新着色）——两支方向相反，判定口诀：**碰到"译词不像它母语"或"古词不像它时代"，先问是漂移还是回灌。**

**判定动作——译词回查（第 3 步跨语扩展）**："追声音"对译词不追通假、追**源词语义衰变史**——该词在源语中是否经历过专业语境的语义收窄或去色彩化？译入语对应字是否仍在日常义高频区？两者一旦错位，确诂须附**"漂移注"**：读术语前先把译入语日常义的色彩手动清零（读"诚实信号"先请"良知"离场）。

## 9.15 C 场景完整配置：权威阶梯、定义链定版与机制核验三问（据"诚实信号"实测回写）

此前 C 专业技术场景（9.2）只有一行矩阵配置＋"善意取得"简例（9.5 案例一）。"诚实信号"一例（第十四例）完成 C 场景首个全流程实测，四件配置定型：

**其一，权威阶梯（第 4 步专业化）**：原始论文（机制发生学与数学定型）＞教科书（框架标准化）＞科普（当代扩散）。与 A 场景"多书证互勘"相对，**C 场景靠定义链定版**：确诂锚在**首次严格化的定义**（Grafen 1990 证明 handicap 为进化稳定均衡），此后一切用例（孔雀尾、文凭、夸富宴）只是机制的应用例证，**不参与义项建构**。

**其二，机制核验三问（第 5 步专业化）**：判定某对象是否属于术语所指——①**有无真实成本**（有代价吗）？②**成本与所指质量绑定吗**（强者付出更低成本或获得更高回报吗——Spence 不对称）？③**作弊空间封死了吗**（低质量者模仿成本＞模仿收益吗）？三问全过方为正例，任一不过即排除或降为"形似物"。

**其三，防定理绝对化（第 6 步 C 场景新陷阱）**：科学术语常被读成铁律（"诚实信号永不可骗"）。反例检验须专设**边界条件位**：术语多描述**动态均衡**而非永恒定律，适用条件、失效场景、反例模型（贝氏拟态之于警戒色——军备竞赛不息，可靠性动态维持）须一并写入确诂；C 场景的"未见反例"还应追加一问**"已知失效条件是什么"**。

**其四，A/C 证据法互通**：专业术语的释义也能用古籍书证——当本土案例与机制**严格同构**时照用：千金买骨＝招募承诺的 handicap（五百金买死马首，使"求贤"贵到无法作假）。判别不在场景而在"是否同构"；且古籍核实照样触发既有律条（原文"千金求马"为预算、"五百金"为实付，成语记成千金——名恒值变律的成语层活标本）——两场景证据法并非壁垒。

## 10. 通用配置系统：四维定位与一键适配（统摄全法）

> 第 8、9 章是**归纳式累积**——每遇一个新词型就加一条补丁。本章反其道而行：从实测案例中迭代抽象出一套**演绎式配置系统**（初版六例，后扩至十四例）。任何新词进来，先定位四维、再叠配置、最后套元规则，即得专属流程；不必重读全文，也不必再打新补丁。

### 10.1 四维定位卡（统一入口）

把散落在 9.2（领域）、9.4（目的）、9.8（单位）、9.9（单/多场）的四个维度收拢到一张卡上。**四问必答，顺序固定**：

| 序 | 维度 | 问什么 | 取值 | 决定什么 |
| :---: | :--- | :--- | :--- | :--- |
| ① | **场** | 一义还是多义并列？ | 单场 / 多场 | 流程是线性还是树状（总开关） |
| ② | **单位** | 什么量级的释义对象？ | 单词 / 词组 / 句子 / 词群 | 第 2、3、4 步怎么拆 |
| ③ | **领域** | 出自哪类文本？ | A 典籍 / B 新闻 / C 专业 / D 官方 / E 民间 / F 外来 | 证据信谁、换哪份陷阱清单 |
| ④ | **目的** | 为什么释义？ | 读懂 / 表达 / 考据 / 辨伪 / 学习 | 做多深、裁到哪一步 |

**为什么这个顺序**：场决定流程骨架（错则为全错），单位决定拆法，领域定证据，目的定深度——先定骨架再定细节，避免"用单场流程硬套多场词"这类结构性错误。

四维组合有数十种，不穷举；改为**叠加式配置**——每一维贡献一部分设置，四者叠加得到唯一流程。

| 维度 | 取值 | 配置贡献 |

### 10.3 标准操作流程（拿到词后的五步）

把前九章压成一条可照做的主线：

1. **定位**——填四维定位卡（10.1），四问必答，顺序固定。
2. **配置**——按一键配置表（10.2）叠加出该词的主力步骤、证据清单、裁剪深度与输出结构。
3. **执行**——跑六步；若定位为多场，先分场再逐场跑（9.9.3）；执行中随时查 7.1 工具书与 7.2 陷阱表。
4. **校验**——第 5 步的正反验证不可省；定稿前用 10.4 元规则层逐条过一遍。
5. **成文**——结论先行：第 0 节先亮确诂 + 判定表，中间放论证，末节回扣（见"释义模板测试版"系列）。

> 一句话：**定位 → 配置 → 执行 → 校验 → 成文**。前九章都是这五步的展开或补丁。

**常见疑问：拿到一个词，是"直接调用第 10 章配置系统"，还是"走六步法"？**

> **不是二选一——两者是一条路的两段。** 第 10 章是**配置层**（决定跑哪种六步、跑几步、线性还是树状、查哪些证据），六步法是**执行层**（唯一产生释义的动作）。第 10 章本身不产出释义；跳过六步直接套配置，等于只有地图没有行走。
>
> 二者的差别只是配置动作**显性还是隐性**：新手显式填四维卡、查配置表；熟手几秒内把四维判断内化，看似"直接走六步"，但走的已是**配置后的改造版六步**，不是第 2 章的原始通用六步。所以答案是——**六步永远要跑，配置永远在做**。

以"东南西北"为例，看配置如何驱动执行：

| 阶段 | 动作 | 东南西北 |
| :--- | :--- | :--- |
| 配置层 | 四维定位 | 单场 / 词组（**关系坐标型**）/ A 典籍 / 考据 |
| 配置层 | 叠加配置 | 词组配置：第 2 步改拆正交关系（东西横轴／南北纵轴，区别于柴米油盐的"分类列举"）、第 3 步改追源流、第 4 步升主力；触发元规则 7「缺项即线索」 |
| 执行层 | 改造版六步 | ①定场＝方位框架非物资 ②拆结构＝四正两两正交 ③追源流＝《尧典》四方→《洪范》五方 ④书证＝年代差即义 ⑤反例＝非四面八方、非中性坐标 ⑥防陷阱＝以今律古 → 确诂 |
| 校验层 | 元规则过一遍 | 缺项即线索：四方补"中"；四隅未见用例，标"未见反例" |
| 成文 | 结论先行 | 确诂一句话 + 判定表 + 论证 + 回扣 |

> 补注：词组内部此前已分出"实体集合型"（柴米油盐）与"关系坐标型"（东南西北），二者第 2 步拆法不同——前者分类列举、后者拆关系结构。此细分随本例一并落到配置层。

### 10.4 元规则层（跨场景不变的底层约束）

各章铁律原本散落，此处收拢成一层"常量"——**配置随词变，元规则不变**。凡释义，无论何词，十五条恒定（1–10 为原十条，11–14 据第七至第十三例实测回写，15 据第十四例"诚实信号"实测回写）：

| 元规则 | 内容 | 依据 |
| :--- | :--- | :--- |
| 1 反例优先 | 反例一票否决；一万个正例证明不了，一个反例足以推翻 | 3.2 |
| 2 诚实边界 | 找不到反例写"未见反例"，不写"没有反例"；争议标"待考"附异说 | 3.5 |
| 3 证据权重 | 权威原文 > 二手解读 > 自媒体；同时代 > 后世转述 | 3.4 / 8.3 |
| 4 场定于境 | 按当前文本语境定场，不按词的"出身"定；一词可跨场 | 9.6 |
| 5 喻体完整 | 比喻型词须完整带入喻体被借用的属性（布洛芬"治标不治本"） | 9.7-4 |
| 6 年代即义 | 集合构成随年代变化时，年代差本身构成意义分层 | 9.8.2 |
| 7 缺项即线索 | 异常缺项或隐含项是破题口（七件事删"酒"、四方补"中"） | 9.8 / 东南西北实测 |
| 8 多场不并 | 多场词各场确诂并列，无共同上位义时不可强行归并 | 9.9.2 |
| 9 结论先行 | 成文先亮确诂再论证，首尾回扣而非循环论证 | 纲领 / 样板文档 |
| 10 语序四档 | 语序负载义分四档：强敏感（异序异义）／弱敏感（正序含生成链）／首固尾浮（首位恒定后位浮动）／不敏感（纯惯例）；三问判据＝换序是否改变义项、时序、成员地位；语序敏感是例外，不敏感是通则 | 9.8.4 / 9.11 |
| 11 数恒项变 | 总称数字多为文化刻度；遇数字先问计数层——同一词可在成员/等级/流派/著作各层对应不同实数 | 9.10 |
| 12 名恒值变 | 制度词名恒而值漂；数值须绑定朝代与实物书证（考古实测与文献互校），勿以今值套古词 | 9.10 |
| 13 言说者立场 | 释义站说话人立场而非读者直觉：欲抑先扬、摘句反转、宿命误读同源，皆读者立场覆盖作者立场之病 | 9.8.5 / 9.12 |
| 14 防回灌词 | 近代日译西学回灌古词（教/经济/封建）为第三层陷阱；先分清词在原文语境的本义层再作今解 | 9.13 |
| 15 防译词漂移 | 翻译不是无损管道，是密度过滤器——源语已卸下的联想译入语可复活，漂移量∝译入语日常义密度；外来术语先回查源词语义衰变史，确诂附"漂移注"清零译入语色彩 | 9.14 |

**用法**：第 6 章自检清单查"做没做"，本层查"守没守"——前者是动作核对，后者是原则兜底。

### 10.5 适配程序：遇到未见词型如何自我扩展

历次升级（新闻词、词组、坐标词组、多场词、句子与词群、数字量值判据、并称分类与语序四档、译文层与回灌词、C 场景配置与译词漂移）看似各加一章，实则遵循同一套动作。把它显式化，以后遇新词型照此扩展，**无需再打新补丁**：

| 步 | 动作 | 判据与产出 |
| :---: | :--- | :--- |
| 1 | **识别异常** | 现有配置讲不通——某步落空、义项无法收敛、出现无法解释的必留语义 |
| 2 | **抽象新维度** | 问"失效差异是什么？"；判据：差异必须改变步骤配置或流程结构，否则只是同配置下的新例子，不构成新维度 |
| 3 | **最小改动配置** | 只改受影响的步骤档位，其余沿用；产出一张"旧配置 vs 新配置"对照表 |
| 4 | **双词验证** | 一个已测词作阴性对照（确认不破坏旧配置）＋一个新词作阳性检验（确认解决新缺口），两者都过才算成立 |
| 5 | **回写固化** | 三处回写：定位卡增补维度、纲领实测表补词、对应章节落一条"据 XX 实测回写"元规则 |

### 10.6 通用性边界（诚实声明）

- **本方法管的是"释义流程"**——如何从语境与书证把词义收敛到确诂；它不管"领域知识"本身。不懂法律要件、不通方言背景时，需补的是专业知识，不是改方法维度。
- **取值范围有经验性**——四维取值来自十四个实测案例的归纳，未覆盖的词型（如纯符号、图像命名、跨语种混合词）按 10.5 适配，但新增维度须经双词验证，不得凭空添加。
