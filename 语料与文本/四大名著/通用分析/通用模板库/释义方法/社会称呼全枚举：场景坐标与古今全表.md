# 社会称呼全枚举：场景坐标与古今全表

> 文档性质：**社会称呼（社交称谓）全枚举工程文档**——《亲缘称谓全枚举：八维坐标与古今全表》的姊妹篇。
> 分工：亲缘篇管**血缘网络**（有穷尽的格，一人立原点全表可得）；本篇管**场景网络**（称呼随场景增生，永不闭合，只能做代际快照）——两篇合观，即汉语称呼全域。两网之间以"拟亲属称谓"为人行桥（C4 专表）。
> 生成日期：2026-11-25　|　枚举轴：场景×时代×敬谦×专通（六维坐标见第 1 节）
> 计数：主表 **60**（B1–B8 八场景）＋横向专表 **31**＝**91** 个枚举单位，计数守恒见第 4 节。

## 0. 结论（先行）

> **一句话**：汉语社会称呼是"陌生人之间如何安全开口"的词汇防火墙，其运行受三条定律支配——**万能通货更替律**（每个时代都有一个安全万能称呼：老爷→同志→师傅→老师／美女→亲→宝，约二三十年一轮换）、**语用腐蚀律**（称呼泛化越广变味越快，安全存量与使用广度成反比：小姐→大姐→阿姨→同志→师傅→美女，无一幸免）、**拟亲属储备律**（社会称呼的半壁江山从亲缘词库借来——大哥、大姐、叔叔阿姨、大爷、家人们：血缘的温度可以借，血缘的义务不能借）。称呼之"礼"的总纲古今未变：**自卑而尊人**（《礼记·曲礼》上）。

**总判定表**：

| 项目 | 判定 |
| :--- | :--- |
| 系统性质 | 场景网络（vs 亲缘的血缘网络）——格随场景增生，本表为代际快照非穷举 |
| 六维坐标 | 场景×时代×敬谦×专通×性别年龄暗示×正式度（第 1 节） |
| 万能通货更替律 | 老爷（明清官绅）→先生/小姐（民国）→同志（1949–70s）→师傅（70s–90s）→先生/小姐复归（90s）→美女/帅哥（2000s–10s）→老师（10s 万金油）→亲（电商）→宝/家人们（2020s）——周期约 20–40 年 |
| 语用腐蚀律 | 三阶段：溢价期（安全＋礼貌）→透支期（泛化滥用）→崩盘期（敬义剥离，仅余场景义）【E 级模型】 |
| 拟亲属储备律 | 亲缘词库是社会称呼的蓄水池；借出的词自带"年龄暗示"风险区（阿姨、大姐的变味即踩线） |
| 统一总纲 | 卑己而尊人（谦称在己、敬称在人——与亲缘篇 C3 谦敬双轨同源） |
| 最大差异 | 亲缘表可穷举（血緣格有限）；称呼表不可穷举（场景无限增生）——两姊妹篇的本质分野 |
| 最大陷阱 | ①拿昨天的通货称呼今天的人（叫年轻女顾客"大姐"）；②不知称呼变味史（"小姐"古今两度反转）；③职务词抗腐蚀性强误当永恒（X总／老师也会老） |

**证据链一句话**：《礼记·曲礼》"自卑而尊人"立总纲 →《论语》《孟子》《诗经》定先生、女士、大夫古义 → 蔡邕《独断》解陛下一系"不敢指斥"机制 → 钱惟演、洪迈、赵翼证"小姐"宋卑尊反转 → 北宋医官阶名证"大夫""郎中"职业借官名 → 现代语用观察（D 级）定通货更替序列 → 三定律成。

## 5. 与姊妹篇的钩连（结论回扣）

- **分工与本质差异**：亲缘篇＝血缘网络，格有限而全表可穷举；本篇＝场景网络，格随场景增生而**永不闭合**——本表永远只是代际快照。"可穷举 vs 不可穷举"是两姊妹篇的分水岭，也是称呼系统最重要的结构事实：**血缘不会新增辈分，社会永远新增场景**。
- **三座桥**：①**拟亲属桥**（C4）——亲缘词库不断向场景网输出（大哥→家人们）；②**谦敬同源桥**——两篇共用"自卑而尊人"总纲（亲缘 C3 家/令双轨＝本篇 B8 在下/足下镜像）；③**官职渗民桥**（C6 大夫／郎中）——与度量衡篇"以律起度"、亲缘篇"命妇平民化"（夫人条）同一历史语法：**制度词不断跌落民间，跌落即漂移之始**。
- **方法论回扣**：本篇场景即"场"（方法文档第 1 步定场）的最宏观展演——大叔／阿姨／大姐同词在亲缘场是敬意、在陌生场是冒犯，**场不同则礼与冒犯互换**；而"小姐"两度反转与"同志"三段史，则是"名恒义变律"（元规则 12 家族）在称呼系统的双标本。
- **一句总收**：亲缘篇收的是"你是谁"（血缘分格），本篇收的是"我们在哪"（场景定名）——一个人被怎么称呼，一半由出生决定，一半由场合决定；两半合起来，才是称呼这门称呼学的全貌。
