## 0. 结论（先行）

> **一句话**：情绪词不是感情的标签，是**生存信号的词典化**——每种基本情绪都是一个古老的警报系统（恐惧避害、愤怒护界、厌恶防污、悲伤止损、欢喜强化、惊愕定向），汉语用两千余年把这个信号系统打磨出了世界罕见的三层粒度：**文言同义字谱**（愠＜恚＜忿＜愤＜怒——一词一级，先秦的情绪分辨率藏于训诂）、**复合词谱**（悲喜交加、啼笑皆非、爱恨交织——两极同存的精细命名）、**不可直译词**（委屈、尴尬、怅然、意难平——复合到目的语无对应格）。三大传统系统各执一份清单：**儒家七情**（喜怒哀惧爱恶欲——"弗学而能"的人情全谱，含动机）、**中医七情五志**（喜怒忧思悲恐惊＋五志配五脏——**只收能内伤致病的**，故剔"欲"、纳"思"）、**心理学基本情绪**（Ekman 六种跨文化表情——只收有专属神经／表情回路的）。三份清单的出入处正是三系统的分野：**枚举范围由系统目的决定**（伦理教化／医学治病／实证研究），这一条与释义方法"目的定深度"同构。

**总判定表**：

| 项目 | 判定 |
| :--- | :--- |
| 情绪本质（功能主义） | 生存信号系统——每情绪回答一个生存问题（§3） |
| 颗粒度三轴 | **强度轴**（轻微→剧烈＝唤醒度梯度）；**复杂度轴**（基本→复合）；**分辨率轴**（Barrett 粒度：词汇量=体验分辨率） |
| 三大系统 | 儒家七情（礼运）／中医七情五志（素问＋陈无择）／心理学基本情绪（Ekman）——对齐见 §1 |
| 最大发现一 | **中医不收"欲"**：欲是动机非情绪、不内伤——医学清单剔除伦理全谱；儒家"七者弗学而能"含欲——伦理清单收人情全部 |
| 最大发现二 | **中医独收"思"**：思伤脾——认知负荷（反刍思维 rumination）作为情绪源入医，比现代心理学早两千年 |
| 最大发现三 | **文言单字粒度**：怒谱愠怏恼恚忿愤怒怼、哀谱戚忧悲怆恸——先秦情绪分辨率高于现代双字词系统 |
| 汉语之最 | 复合情绪词：对冲型（悲喜交加）、邻近型（怅然若失）、社会型（尴尬内疚羞耻）三谱 26 词 |
| 中医工程学 | 情志相胜环（悲胜怒、恐胜喜、怒胜思、喜胜忧、思胜恐）——古代情绪调节技术，五路闭环 |
| 最大陷阱 | ①以今律古（"七情"今日俗义≠礼运／陈无择清单）；②跨系统混表（拿中医五志套 Ekman）；③粒度错觉（把"不开心"当精确描述——低粒度失察） |

**证据链一句话**：《礼记·礼运》"何谓人情？喜、怒、哀、惧、爱、恶、欲七者，弗学而能"立儒家清单 →《素问·阴阳应象大论》五志配五脏＋情志相胜立医学清单 → 宋陈无择《三因极一病证方论》定中医七情（剔欲）→ Ekman 跨文化六种基本表情立实证清单 → Barrett 情绪粒度（granularity）：高粒度者情绪调节更佳 → 文言字谱（《论语》"人不知而不愠"《大学》"身有所忿懥"）证单字分级 → 复合词谱与不可直译词证汉语高粒度 → 总表成。

## 1. 三大系统源对齐表（谁收谁，收了干什么）

### 1.1 三份七情清单（＋心理学清单）

| 序 | 儒家（《礼记·礼运》） | 中医（陈无择《三因极一病证方论》七情） | 心理学（Ekman 基本情绪） |
| :---: | :--- | :--- | :--- |
| 1 | 喜 | 喜 | 快乐（enjoyment） |
| 2 | 怒 | 怒 | 愤怒（anger） |
| 3 | 哀 | 忧 | 悲伤（sadness） |
| 4 | 惧 | 思 | 恐惧（fear） |
| 5 | 爱 | 悲 | 厌恶（disgust） |
| 6 | 恶 | 恐 | 惊讶（surprise） |
| 7 | 欲 | 惊 | —（爱、欲不入基本情绪） |

### 1.2 出入处的系统诊断（本节核心产出）

| 出入 | 诊断 |
| :--- | :--- |
| 儒收"欲"，中医剔"欲" | 儒家编"人情全谱"（"饮食男女，人之大欲存焉；死亡贫苦，人之大恶存焉"【A】——欲恶是心之大端，故欲必入）；中医编"致病清单"——欲是持续动机非情志波动，不作"内伤"病因，剔——**清单范围由系统目的决定** |
| 心理学不收"爱""欲" | 爱归依恋系统（attachment）、欲归动机系统（motivation）——实证心理学按**专属神经／表情回路**划界，爱欲无专属惊跳式回路，不入基本情绪 |
| 中医独收"思" | 思伤脾【A 素问五志】——认知负荷（想太多）致病入医：**反刍思维（rumination）致病的古代版本**，先于现代心理学两千年 |
| 中医"惊""恐"分立 | 惊＝突发外袭（事件性质），恐＝内发持续（状态性质）——惊恐之辨即现代"急性应激 vs 焦虑"的雏形 |
| "悲""忧"两家合并 | 肺在志为忧，悲亦属肺【A】——损伤同脏则归并，医学按脏腑归堆不按体验细分——与儒家"哀"的伦理位、心理学"sadness"的实证位三分 |
| 儒家无"思""忧"位 | 礼运七情收"情"不收"虑"——思是认知活动，忧是思与惧的复合（复合词不入基本清单）——儒家分得也细 |

> **枚举学通则**（通向释义方法的"目的定深度"）：同一现象域，伦理学、医学、实证心理学各画各的网格——**没有中立的清单，只有宣告了目的的清单**。释义遇系统清单（七情／五志／基本情绪），先问"这张单要干什么"，再对号。

### 1.3 五志配五脏全表（中医情绪解剖学）

| 志 | 脏 | 造病 | 相胜（治法） |
| :---: | :---: | :--- | :--- |
| 怒 | 肝 | 怒伤肝 | 悲胜怒（悲则气消，泄其上亢） |
| 喜 | 心 | 喜伤心 | 恐胜喜（恐则气下，镇其涣散） |
| 思 | 脾 | 思伤脾 | 怒胜思（怒则气上，破其纠结） |
| 忧 | 肺 | 忧伤肺 | 喜胜忧（喜则气缓，解其郁结） |
| 恐 | 肾 | 恐伤肾 | 思胜恐（思则气定，胜其无措） |

> **情志相胜环**【A《素问·阴阳应象大论》系统】是中医的独门工程：以情治情、五路闭环，方向沿五行克伐——比现代"情绪调节"（Gross 过程模型，1980s 起）早约两千年，且思路相反：现代以认知驭情绪（自上而下），中医以情绪克情绪（以毒攻毒、同级对抗）。

## 2. 情绪颗粒度三轴（用户点名维度一）

Barrett 的**情绪粒度**（emotional granularity）：个体分辨自身情绪的分辨率——高粒度者能区分"恼怒／烦躁／愤懑／不忿"，低粒度者只有"不爽"。粒度不是修辞奢侈品：**粒度高者情绪调节更佳、身心症状更少**（Barrett 学派系列研究【D】，效应量以元分析为准）——词汇即工具箱，工具越多，修理越精。

### 2.1 强度轴：轻微 → 剧烈（唤醒度梯度）

每条基本情绪在文言单字里各有一个梯度谱——先秦的情绪分辨率直接编码在训诂字群中：

**怒谱（8 级）**：不悦 → **愠**（微怒——《论语·学而》"人不知而不愠"【A】）→ 怏怏（不平）→ 恼 → **恚**（恨怒）→ **忿**（《大学》"身有所忿懥，则不得其正"【A】）→ **愤**（懑盈欲发）→ 怒 → 雷霆之怒／目眦欲裂（极）

**喜谱（7 级）**：**怡**（和悦不形）→ **悦**（内心里许——《论语》"学而时习之，不亦说乎"【A】）→ **欣／忻** → **怿**（悦怿）→ 喜 → 乐 → 大喜若狂／喜不自胜（极）——剧烈档有"喜极而泣""喜极而疯"（范进中举【C】）两种失稳形态

**哀谱（7 级）**：惆怅 → **怅**（怅然若失）→ **戚**（戚戚——《论语》"小人长戚戚"【A】）→ 忧 → **悲** → **怆**（悲怆／怆然涕下）→ **恸**（哀之至——《论语》"哭之恸"【A】）→ 悲恸欲绝／泣血（极）

**惧谱（7 级）**：不安 → **忐忑**（心悬不定，拟声构词）→ **惴**（惴惴——临渊惴栗）→ **怵**（怵惕）→ 慌 → **惧** → **恐**（恐则气下，深且久）→ 魂飞魄散／毛骨悚然（极）

**厌谱（5 级）**：不对付 → 看不上 → **嫌**（嫌弃）→ **恶**（wù，可恶）→ **憎／恶心**（极）——厌恶谱最短：厌是判官不是火药，少有升级链

**惊谱（4 级）**：**愕**（错愕）→ **惊** → 震惊 → 骇然／大惊失色——惊是瞬态信号，无持续档（持续即转惧）

> **梯度四观察**：①怒谱最长（社会性情绪需精细调档——对谁发、发到几分，都是政治）；②厌谱最短（否决性情绪不讨价还价）；③惊无持续态（转瞬即化为惧或怒——新异信号一判定即交接）；④"喜极而泣／怒极而笑"证明剧烈档两极相通（倒错反应是系统过载的显影）。

### 2.2 复杂度轴：基本 → 复合（详见 §5 词谱）

复合原则初判：两极同存（对冲型）、相邻渐变（邻近型）、自我涉入（社会型）——三型各成词谱。

### 2.3 分辨率轴：粒度的语言化石

汉语粒度进化三阶段：**文言单字高粒度**（愠／恚／忿分级——一字一档）→ **双字词粒度折半**（不高兴／生气／愤怒三级——古字的细分被折叠）→ **网络词再精细化**（"内耗""破防""意难平""emo"——复合情绪被重新单字化）——粒度不是直线进化，**词汇系统每次换代都重新分配分辨率**，网络时代正在自发补课。

## 3. 生存信号表（心理学：情绪背后的生存问题——用户点名维度二）

功能主义视角：每种情绪是一套古老的报警与调度系统，**情绪是进化打包的决策捷径**——

| 情绪 | 生存问题 | 信号与调度 | 生理指纹（标志性） |
| :--- | :--- | :--- | :--- |
| 恐惧 | 前方有致命危险？ | 战斗／逃跑／僵死三择一，注意收窄全程锁敌 | 心跳骤升、杏仁核捷径（先反应后认知的神经道路） |
| 愤怒 | 边界／规则被侵犯？ | 调资源强制修正——示威力先于动手 | 心率血压升、面赤（怒发冲冠＝竖毛肌动员【C】） |
| 厌恶 | 此物有污染／病原风险？ | 排出、远离、封锁（恶心＝呕吐预备） | 上唇提肌微动、恶心貌（跨文化共通表情之一） |
| 悲伤 | 不可挽回的损失发生了？ | 减速、省能、认知重整、求助广播（哭＝最高音量的社会求援） | 哭、乏力、社交缩窄——悲伤的"低唤"是节能模式 |
| 快乐 | 奖励到位、此路可走？ | 强化行为、亲和连接（笑＝"无害广播"） | 达谢基（Duchenne）真笑：眼轮匝肌无法伪装的参与 |
| 惊讶 | 新异事件，重新定标？ | 定向反应：全通道注意重置 | 瞬时睁眼扬眉，为重采样视野扩容 |
| 爱／依恋 | 长期同盟如何维系？ | 承诺、共育、催产素回路 | 与应激反向：心安、低警觉 |
| 嫉妒 | 排他资源受威胁？ | 守护、监控、驱逐对手 | 妒火中烧（高唤醒） |
| 内疚 | 我违规了？ | 修复：道歉补偿动机 | 低唤醒、回避目光 |
| 羞耻 | 我整个人不合格？ | 隐藏／顺从（整体自我贬抑——比内疚的"对事"更"对人"） | 缩小体态、低头 |
| 尴尬 | 自我呈现当场失败？ | 缓和广播："我不是故意的"（给在场者的维修信号） | 面红（唯一专属脸红档） |
| 委屈（汉语高粒度） | 不公加身而无力申辩 | 召唤第三方同情的信号（哭的委屈版） | 眼眶热、哽——"求抱"姿态 |

> **三规律（本表格的通则层）**：①**负性情绪占多数**——生存中危险大于机会，警报器多于奖赏器（与三色评价层的"褒贬不对称律"同构：贬词多、骂词多、负情绪多，一脉）；②**每个信号有专属生理指纹**——测谎仪原理即在此（但指纹可被伪装与倒错——"喜极而泣"即通道串线）；③**复合情绪＝信号叠加**——尴尬＝惊（事发）＋惧（在场）＋耻（自认）＋缓和动机（修），信号叠加才需复合词。

## 5. 主表二｜复合情绪词谱（汉语高粒度的实力区，26 词）

### 5.1 对冲型（两极同存）

悲喜交加｜悲喜交集｜啼笑皆非（哭笑不得）｜又惊又喜（惊喜交集）｜爱恨交织｜酸甜苦辣（全谱杂陈）｜百感交集｜悲欣交集（弘一法师临终偈"悲欣交集"【C】——四字压尽一生）

### 5.2 邻近型（相邻渐变，无对立而有余韵）

怅然若失（失＋茫然）｜黯然神伤｜意难平（憾＋不甘＋时过境迁不消解——文言腔网络复活词）｜怅惘（怅＋惘）｜若有所失｜五味杂陈｜怅然低回｜依依不舍（恋＋别痛）

### 5.3 社会型（自我涉入＋道德／呈现维度）

尴尬（呈现失败）｜羞耻（整体自我）｜内疚（具体行为）｜惭愧（惭于己、愧于人——对内对外一双）【B 楚辞王逸注系统，待核】｜悔（后之自责）｜愧疚｜妒羡（妒是怕失所有、羡是盼得所有，合一成酸）｜酸了（妒羡的网络单字化——**复合情绪被民间词库压缩成单字**，粒度自发进化标本）｜敬畏（畏＋仰——崇敬与恐惧的官方复合）
