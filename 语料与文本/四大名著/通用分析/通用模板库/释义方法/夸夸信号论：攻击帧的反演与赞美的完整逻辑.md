## 0. 结论（先行）

> **一句话**：夸人是攻击帧的**镜像帧**——同一张靶心谱，骂人往下打，夸人往上供；燃料由**分别心**换成**共鸣心**（我认同一件事珍贵，才夸得出它）；杀伤公式反转为增益公式：**夸的收益＝靶心命中×共鸣厚度×可信度**。三条镜像是本篇骨架：①骂破防＝破防公式反转→夸"起防"——**夸错靶的代价与骂错靶同样惨烈**（对不看重的人夸其容貌＝把对方最不自信的地方放在聚光灯上，等价于骂）；②虚构骂不可反驳→**虚构夸（夸其没有的品质）不可接收**（对方无法 ACK 一帧不存在的东西，只能疑惑或警觉——"我配吗"的猜疑链启动）；③实际骂以真为毒→**实际夸以真为药**（夸真实成就，一句话顶一万句）。骂与夸共享同一张靶心谱、同构的通信信道，甚至同一套防御动作——**夸人和骂人本质上是同一门手艺，只是方向相反**：骂是把对方拉下他站的台阶，夸是把对方送上他自己想站却不敢站的那级台阶。

## 2. 燃料反演：分别心 → 共鸣心

### 2.1 共鸣心（夸人的燃料）

骂人烧的是对方的分别心，夸人烧的是**自己的共鸣心**——

**定义**：共鸣心＝真心认同某价值轴珍贵（自己也被该轴感动）的程度。

**夸效公式的燃料位**：

```
夸的收益 = 信号强度 × 接收方靶心命中率 × 发送方共鸣心厚度
```

**三对镜像**：

| 骂 | 夸 |
| :--- | :--- |
| 燃料在被骂者（分别心） | 燃料在夸人者（共鸣心） |
| 弱者无靶可骂（分别心为零则不痛） | 冷者无话可夸（共鸣为零则虚夸——拍马） |
| 高明的骂读对方看重谱 | 高明的夸也读对方看重谱 |

### 2.2 拍马与赞美的分界

共鸣心＝0 时的夸＝**拍马**——技术上调制完美（用词、时机、信道全对），但因为发送方不信，帧里缺温度调制，接收方的黑盒检出"温度校验位不匹配"（情绪篇 7.3：信温度，不信词）——**拍马之所以被识破，不是词错，是温度错**。邹忌讽齐王纳谏的深层机制正在此：妻妾客美我，皆"私我""畏我""有求于我"——**共鸣为零的夸，帧的可信度校验不过**【A：《战国策·邹忌修八尺有余》】。齐王最后能听邹忌，恰因邹忌以自己"不如徐公美"的自省开帧——**共鸣先自证，再夸天下**。

## 3. 真值类型学反演：虚构夸／实际夸／策略夸

| 型 | 定义 | 机制 | 接收方反应 |
| :--- | :--- | :--- | :--- |
| **实际夸**（以真为药） | 夸**真实存在**的品质或成就——"你这篇文章写得真好"（它真的好） | 药力来自事实的不可否认性——实际夸不可驳倒，且越具体越有力（细节＝事实校验位） | 安心接收：可信度满格，帧入档 |
| **虚构夸**（夸没有的） | 夸**不存在**的品质——对内向者夸其口才、对普通学生夸其天才 | 不可接收：对方无法 ACK 一个自己认不出来的自己——**夸与自我认知的差距 = 帧的失配度**；轻度失配→疑惑（"我配吗"），重度失配→警觉（"他要卖我保险"） | 疑惑／警觉／讨好判定——**糖衣里没糖** |
| **策略夸**（夸未来可能成的） | 夸**未发生但有潜势**的品质——"你将来必成大器""这孩子是当科学家的料" | 属虚构夸的战略子型：**以未来做杠杆**，撬动当下行为（皮格马利翁效应：期待改变行为【D，Rosenthal 实验系】） | 悬浮帧：无法验证也无法反驳，挂在半空——**教育者以自己的信誉做担保发出此帧** |

**三型对照骂制**：虚构骂的"小畜生"骂出生（不可反驳——罪不存在所以无法辩护）｜虚构夸的"你真大方"夸不是大方的人（不可接收——德不存在所以无法领）——**对不存在之物说话，骂则无处辩，夸则无处领**：同一机制的正反两面。

**实际夸深剖**（以真为药的三层）：

- 药力第一层：**具体性**——"好"不如"好在哪里"（"你这段转折处理得干净"＞"你写得真好"）——细节是事实校验位，防"客套帧"判定；
- 药力第二层：**他人侧证**——"连张老都说你这篇好"（三方篇背书帧的正用：用第三方的靶谱给帧加密）；
- 药力第三层：**低频高分**——夸的边际效用随频率递减（通胀），偶发的精准夸顶重复的泛夸（通货逻辑：滥发即贬值，与"美女"贬值为同一律——夸人也守语用腐蚀律）。

**策略夸的杠杆与风险**：夸"未然"以撬"将然"，是教育的核心技术（皮格马利翁效应），但**策略夸是期货**——若未来不兑现，"你早说我是天才"会反转为怨气（"伤仲永"的通信学：帧透支了，账户被未来清算【C】）。老师夸学生"是这块料"，实际是**用自己的信用给学生的未来做担保**——担保额度须量力而行。

## 5. 夸的三重滑坡链（过量风险——骂"破防"的镜像："起防"之外的系统性故障）

骂的失败形态是"破防"（对方崩溃）或"无感"（靶偏了）；夸的失败形态是一条**滑坡链**——

| 阶段 | 形态 | 机制 | 案例 |
| :--- | :--- | :--- | 邹忌的妻妾："君美甚，徐公何能及君也"——滤镜夸的始态【A】 |
| ①**滤镜夸** | 发送端失真：夸的是自己脑补的形象（偏爱／敬仰的投影），不是对方本人 | 共鸣心过强、靶心误读：把"我想象的你"夸给"实际的你"——接收方收到一帧"描述了别人"的夸，失配感启动 |  |
| ②**通货膨胀** | 频率失真：天天夸、事事夸 | 边际效用递减（通货逻辑）：夸的币值随发行量贬——到真值得大夸时，词已不值钱（"狼来了"的夸奖版） | 滥赏式管理："每件小事都夸" → 员工对重要夸脱敏 |
| ③**捧杀** | 战略反用：故意放大夸帧，使对方在幻觉中自毁 | 帧的真实目的是攻击（攻击帧伪装成增益帧）——《吕氏春秋》"将欲败之，必须姑辅之；将欲取之，必姑与之"【B】逻辑；捧得越高，摔得越深 | "某某是天才"捧至目中无人（骄傲使然败落）——**骂人的最高形式是夸人**（毒糖帧） |
| ④**捧杀防线**（附） | 识别与抵御捧杀 | 受方检测：夸帧是否与自身事实存在明显失配＋发送方是否与我有竞争关系（竞争者的高夸＝红色警报——**对手突然猛夸你，等价于对手突然对你笑**） | 曾子三省的夸奖扩展版："传不习乎"的自检日常化——**把每次被夸都过一遍自省过滤**【A】 |

## 7. 夸人指南（操作链六步 + 防御五法）——释义

### 7.1 增益流程六步（攻击流程五步的反演＋一步）

1. **侦查读靶**（与骂人同款）：读出对方看重谱——他自夸什么、掩饰什么、为什么失眠。**看重的点＝靶心，自夸的点＝他希望你聚焦的靶心**——两者未必相同（希望被夸的地方有时恰是不敢自夸的地方）；
2. **选帧**（真值类型+档位）：实际夸（最稳）＞策略夸（有杠杆）＞虚构夸（避免——除非明示为玩笑帧）；档位从轻到重：具体小夸（"这步棋好"）→当面中夸（"你这事办得漂亮"）→公开大夸（在 CC 域点名称赞——**公开夸的增益倍数随信道公开度上升**，但靶心错配的代价也随之倍增——信道选择是夸的策略核）；
3. **选信道**：私下夸（L3/L4：亲密充值）vs 当众夸（L1/L2：社会身份充值——"在人前给我面子"）；**当众夸是双刃帧**：靶准时是最大的礼，靶偏时是最大的刑（把对方最不自信处公告全网）；
4. **发射**：调制要真（共鸣心不足时宁可不发）；**夸细节不夸方向，夸行为不夸身份**（"这篇写得好"＞"你是作家"，行为夸可验证、身份夸定终身）；
5. **接收验证**（夸人独有的步骤）：观察对方反馈帧——安然受之（真接上了）／摆手否认（谦辞帧，中国礼节标准响应）／"哪有哪有"但眼里有光（嘴上推心里收——中餐菜单式的表面拒绝）／表情失配（帧没接好，立刻补具体化："特别是那个结尾的处理"）；
