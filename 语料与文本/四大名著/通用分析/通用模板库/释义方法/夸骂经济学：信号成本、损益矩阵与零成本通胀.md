# 夸骂经济学：信号成本、损益矩阵与零成本通胀

> 文档性质：夸骂系列的**底层经济学补篇**——《骂人指南》（统合总纲）给了攻击帧的通信学结构，《夸夸信号论》给了反演逻辑，本篇下探一层：**发出任何信息都有成本，夸与骂皆不例外**——它们不是情感的自然流露，而是**投出去的社交资本**：每帧都付出（能量＋风险＋机会）三重成本，预期（获利或避损）两种回报（用户命题）。本篇回答：这笔账怎么算的、为什么大多数人算错、以及零成本信号的宿命。
> 生成日期：2026-11-25　|　理论工具：信号成本理论（Spence 2001 诺奖）／ handicap 原理（Zahavi）／损失厌恶（Kahneman & Tversky）／言语梳毛（Dunbar）
> 计数：成本科目 **3**＋handicap 案例 **4**＋损益四格 **4**＋夸策略 **6**＋骂策略 **6**＋不对称定律 **3**＋经典映射 **7**＋灵长类账本 **3**＝**36** 个枚举单位，守恒见第 9 节。

## 0. 结论（先行）

> **一句话**：夸与骂是**社交市场的两种交易品**——夸买**未来的资源**（结盟预期、好感期权），骂买**即时的边界**（威慑资产、止损保护）。每帧发账都要付三重成本（能量微不足道，**风险才是大头**：关系烧桥、报复升级、名声损耗），所以开口前人脑运行成本收益核算（多数时候是无意识的）。两条铁律决定这个市场的秩序：**其一，成本决定可信度（handicap 原理）**——零成本的信号必然通胀至无意义（"美女"的贬值、"亲"的油腻、夸夸群的空转——**凡是不花本钱的夸，最终都不值钱**），而真实成本的信号才被市场相信（雪中送炭＞锦上添花＝患难真情贵在"患难"两字本身就是成本：搭上时间、站队风险、甚至身家）；**其二，损失厌恶不对称（Kahneman）**——损失之痛约两倍于收益之乐，导致**避损型骂的预算永远高于获利型夸**：人类在防御边界上愿意投入的攻击成本，远超在讨好结盟上的投入——骂 比 夸 激烈得多的终极原因不是愤怒更强，是**账本不对称**。

**总判定表**：

| 项目 | 判定 |
| :--- | :--- |
| 夸骂的本质 | 社交投资行为：为获利或避损而发帧，帧有真实成本 |
| 成本三科目 | 能量成本（微）＋**风险成本（主项：关系／报复／名声）**＋机会成本（此帧占用的信道与时间） |
| 收益两方向 | **获利**（资源、结盟、地位）／**避损**（防线、止损、威慑）——用户二分 |
| 可信度铁律 | handicap：信号价值＝成本可见性——花多少钱的话，就值多少钱的信 |
| 零成本通胀律 | 无成本信号必然超发→贬值→需加成本重建（通货史全套搬进语言市场） |
| 损失厌恶不对称 | 避损权重大于获利——骂的心理预算高于夸的结构性原因 |
| 市场的终极裁决 | 发帧者的长期净收益＝Σ（预期收益×兑现率）−Σ成本——**只发不收（只夸不真予、只骂不真战）者终被市场出清** |
| 最大陷阱 | ①以为夸不要钱（通胀税）；②以为骂最贵（威慑骂是资产不是消耗）；③用获利框架算避损账（两种账算法不同） |

**证据链一句话**：《史记·货殖列传》"天下熙熙，皆为利来；天下攘攘，皆为利往"立总纲【A】 →《老子》"将欲取之，必固与之"立战略预付【A】 →《论语》"巧言令色，鲜矣仁"立零成本夸的识破标记【A】 →《礼记》"口惠而实不至，怨菑及其身"立空头承诺的清算条款【A】 →《诗·大雅》"投桃投李"立互惠账本的诗歌版【A】 → 季布"一诺千金"立信号的市场定价【B】 → Spence 信号模型＋Zahavi handicap＋Dunbar 言语梳毛立三个现代学科支点【D】 → 账本模型成。

## 1. 发帧的账本：成本三科目

发言不是免费的——成本记在三个科目上：

| 科目 | 内容 | 量级 |
| :--- | :--- | :--- |
| **能量成本** | 发声、组织语言的生理消耗 | 微不足道（几乎可忽略——**这正是问题所在**：成本太低导致超发） |
| **风险成本**（主项） | ①关系烧桥（骂断交情）②报复升级（对方反击的预期损失）③名声损耗（围观者 CC 域的差评）④地位暴露（夸错边站错队） | 主项，且**随信道公开度指数上升**：私下一句骂＝损失一段关系；当众一句骂＝损失社会身份 |
| **机会成本** | 此帧占用的时机与信道：对着 A 夸的精力本可用来结交 B；骂战的时间本可生产 | 隐性但真实 |

**真话的定价**（为什么真话最贵）：说真话的成本结构特殊——真话常损害听者利益（触发对方反击）或损害说者安全（皇帝新衣里说真话的孩子冒的是生存风险），**谎言的内容成本为零，真话的成本是真实后果**——所以市场上谎多真少不是道德问题，是价格问题：**真话是奢侈品，多数场景买不起**。皇帝的新衣之所以是寓言经典，因为它是真话成本的极限情境（对权力说真话＝押上性命）；而"指鹿为马"是其镜像（说假话的成本为零、收益是生存——**谎市在威权下的极端繁荣**）。

## 2. handicap 原理：贵的话才值钱（可信度的成本基础）

**理论内核**【D 生物学通识】：Zahavi 的 handicap 原理（自残原理）——**诚实的信号必须昂贵**：孔雀的尾巴巨大累赘，正因累赘才可信（只有真健康的孔雀扛得起）；瞪羚见狮子不逃反而**弹跳**（stotting），纯浪费能量——但正因浪费才可信（我有多余体力，追不上，你换目标吧）。信号的成本不是缺陷，是**防伪机制**。

**语言市场的 handicap 四案例**：

| # | 案例 | 成本在哪 | 为什么因此可信 |
| :---: | :--- | :--- | :--- |
| 1 | **雪中送炭＞锦上添花** | 雪中送炭付真实资源（炭＋时间＋立场），锦上添花只付嘴 | 患难时期的支持帧自带防伪标签——**"患难"本身过滤了投机者**（搭便车者不来了），信号免检 |
| 2 | **一诺千金（季布）** | 古代无契约 enforcement，承诺的抵押品是**说者全部声誉**（赖账＝社会性死亡） | 高押金信号才有一级市场价——"得黄金百斤，不如得季布一诺"【B】＝声誉市场的市盈率 |
| 3 | **歃血为盟／纳投名状** | 盟约不满足于言语——要流血、要杀人、要烧掉退路 | 极高成本承诺：让背叛变得昂贵（毁约成本提前内化）——**承诺的可信度与毁约的代价成正比** |
| 4 | **骂帝**（闻诛一夫纣矣／海瑞骂嘉靖） | 指着权力者的鼻子骂，押上的是命 | 天下最贵的骂因此有天下最高的可信度——**骂的成本使骂者的话成为孤证真话**（没人会为撒谎付出生命级的成本——除反间计） |

**通胀律的镜像表述**：成本消失则信号死亡——**"美女""亲""爱你"的通胀史，就是这些词的成本清零史**：当"美女"只花嘴皮、当"亲"只是客服模板、当"爱你"只是表情包，语言的物价局自动把它们清出硬通货名单。**重建信用的唯一途径是重新注入成本**（对滥发过"爱你"的人，有效的表达必须付出新的、可见的代价——时间、行动、资源）。

## 3. 损益四格矩阵（用户二分的形式化：获利×避损×夸×骂）

| | **获利型**（投资未来收益） | **避损型**（防御未来损失） |
| :--- | :--- | :--- |
| **夸** | **谄媚／结盟**：讨好上位、维系同盟、下好感期权——"君美甚"（邹忌的妻妾客【A】） | **安抚夸／止损夸**：先夸后转折（"你底子很好，但是……"——铺垫软化，避免关系破裂）；安抚盛怒者（对怒谱拉满者的降温帧） |
| **骂** | **压制型骂／泄愤收益**：攻击竞争者抬高自己；道德围猎（占领高地收割）；愤怒的生理收益（战斗动员的爽感） | **威慑骂／边界骂**：警告越界者（领土宣言——"你再动她试试"）；群体防御（鸣枪示警式——借骂一个吓退一批） |

**四格的隐藏秩序**：

- **获利型夸的主成本是尊严折价与通胀税**（夸得越违心，尊严损耗越大、预期兑现越虚）；**避损型夸的主收益是止损精度**（一句及时的安抚救下一段关系的账面价值）；
- **获利型骂的主风险是升级失控**（骑虎难下：为压制而骂，骂出真仇）；**避损型骂的主收益是一次性威慑的资产化**——**边界骂只需打赢一次就长期生效**（"不好惹"的名声是耐用品，一次立起来，此后免费威慑所有人——骂作为投资，属"一锤子买卖的终身年金"）；这就是"软柿子定律"的背面：**软柿子被捏是因为它免费，硬茬没人碰是因为有人早付过一次威慑成本**；
- 四格里**最被低估的是避损型夸**（中国式"给台阶"的艺术：给对方递台阶的成本是自己咽下对错之争——**台阶是用人格付账的**）；**最被滥用的是获利型骂**（用骂代替实力竞争——低成本攻击的过度投资，最终靠骂获利者被市场识别为噪音源而出清）。

## 4. 夸的投资学（夸的六个盈利模式与两个死穴）

| # | 模式 | 投入 | 预期回报 | 死穴 |
| :---: | :--- | :--- | :--- | :--- |
| 1 | **结盟夸**（对等者互夸） | 互捧的时间成本 | 关系保险（未来互抬） | 互吹过热则双双掉价（娱乐圈式互吹的反噬） |
| 2 | **谄媚夸**（对上位者） | 尊严折价 | 资源、提携预期 | 被识破（"巧言令色"标记）＋贬值（上位者对夸通胀免疫） |
| 3 | **交易夸**（对服务者） | 微小（"谢谢阿姨"） | 更好服务的即时回报 | 空转（对方知道你是套路，礼貌进入互不亏欠态） |
| 4 | **止损夸**（冲突后修复） | 咽下分歧的人格成本 | 关系保住 | "夸完再犯"则信用破产 |
| 5 | **杠杆夸**（对孩子/下属的策略夸） | 说话者的信用担保 | 皮格马利翁式行为改变 | 期货不兑现即反噬（伤仲永清算） |
| 6 | **交易外夸**（无目的真夸） | 零——但有真实共鸣成本（要真的看见） | 关系币的信誉积累（长期最值钱） | 需要读靶能力（前置技能门槛） |

**夸的两个死穴**：①**通胀死穴**——夸的发行量超过自己的实力储备（滥发夸奖者最终像滥发货币的央行：币值崩，信用死）；②**杠杆死穴**——策略夸（期货）超过自己担保能力（夸得越重、承诺越深、期货违约时的反噬越大）。

## 5. 骂的投资学（骂的六个盈利模式与两个死穴）

| # | 模式 | 投入 | 预期回报 | 死穴 |
| :---: | :--- | :--- | :--- | :--- |
| 1 | **威慑骂**（边界宣言） | 一次冲突的全部风险 | **终身威慑年金**（"不好惹"标签） | 对手真的更强（成本归零、面子破产） |
| 2 | **压制骂**（打击竞争者） | 名声损耗 | 对手出局、资源归我 | 围观者反转（"欺负人"标签贴回自己） |
| 3 | **泄愤骂**（情绪释放） | 关系＋可能的物理冲突报 | 生理收益（愤怒的战斗动员回路的满足） | **纯粹消费型投资**：最快乐、回报最薄（泄愤后的空洞＋烂摊子） |
| 4 | **正义骂**（道德围猎） | 站队风险 | 道德高地＋群众借势 | 猎物翻案（冤案骂者被反噬最狠） |
| 5 | **止损骂**（断绝预期） | 一段关系 | 拒绝未来索取（"提前骂走吸血者"） | 断错了（错杀真朋友） |
| 6 | **艺术骂**（文骂/玩梗） | 智力成本 | 圈内声望（鲁迅式"乏走狗"【C】） | 出圈即失灵：圈内懂梗者笑，圈外只见脏（信道的知识门槛） |

**骂的两个死穴**：①**升级死穴**——骂的成本不是线性是**指数的**：私骂损失五分关系、回骂损失二十分、动手损失一切——为五分情绪付全部身家的骂者，是这市场最差的交易员；②**通胀死穴**——骂骂咧咧者天天骂，则威慑力清零（国骂使用者互不生威——**骂的通胀比夸更快**，因为骂的信用基础本就薄）。

## 6. 损失厌恶的不对称定律（为什么人类的骂比夸重）

三条不对称贯穿整个夸骂市场【D 行为经济学通识】：

| # | 定律 | 内容 |
| :---: | :--- | :--- |
| 1 | **权重不对称** | 同额损失之痛 ≈ 2×同额收益之乐（Kahneman & Tversky 前景理论）——**避损型发帧的心理授权天然大于获利型**："忍无可忍"的骂比"锦上添花"的夸拿到更多心理预算 |
| 2 | **折现不对称** | 夸的收益是**远期期权**（好感何时兑现未知，心理折现沉重）；骂的收益是**即时现货**（威慑立刻生效、爽感立刻到账）——短视的市场天然偏爱现货交易：**这是骂的另一重结构性受欢迎** |
| 3 | **沉没不对称** | 被骂的损失已经发生（人格受伤在先），骂回去是"追回损失"的心理账户（人愿意为追损付出超额成本，尽管追不回）——**骂战比夸战持续的深层动力：两边都在追损，都停不下来** |

**合流结论**：骂与夸不是对称市场——**骂的即时兑现＋避损高权重＋追损账户**三重机制，使人类语言交易的短期交易量天然偏向骂；而夸是长线价值投资（复利在关系账本上慢慢滚）。**急性子倾家荡产骂短线，真正的赢家用夸熬长线**。

## 7. 经典映射（七条）

| # | 经典 | 经济学解 |
| :---: | :--- | :--- |
| 1 | 《史记·货殖列传》"天下熙熙，皆为利来；天下攘攘，皆为利往"【A】 | **本篇总纲的祖版**——太史公给天下（含语言市场）立的流动性法则：凡有往来，皆有算盘 |
| 2 | "将欲取之，必固与之"《老子》三十六章｜"将欲败之，必姑辅之"《吕氏春秋》【A/B】 | **战略预付**：先给后取的先手投资——捧杀的战略本质（投资的终点是收割：先付夸的期权费，收骂的执行价） |
| 3 | "巧言令色，鲜矣仁"《论语·学而》【A】 | **零成本夸的市场识别标记**——儒家在两千五百年前就给空头信号贴了警示标签 |
| 4 | "口惠而实不至，怨菑及其身"《礼记·表记》【A】 | **空头承诺的清算条款**：送嘴不送礼者的结局是双倍索赔（预期违约的愤怒＋机会白白浪费） |
| 5 | "投我以桃，报之以李"《诗·大雅·抑》【A】 | **互惠账本的诗歌版**——中国最早的"礼尚往来"记账准则（往来之"账"从桃李起算） |
| 6 | 季布"一诺千金"（《史记·季布栾布列传》）【B】 | **信号的市场定价**——声誉定价机制：百斤黄金 < 一次真实承诺，因为承诺背后押着违约风险金 |
| 7 | 触龙说赵太后（"父母之爱子，则为之计深远"）【A，前序已核】 | **说服的收益核算示范**：不直接要账（长安君质齐），而给赵太后算长期账（"不及今令有功于国，一旦山陵崩……"）——绕开当下损失框架，启用长期收益框架——**换一个账本，同一笔交易就谈成了**：框架效应的战国实战 |

## 8. 灵长类账本：从梳毛到 gossip（成本的进化史）

| # | 阶段 | 内容 |
| :---: | :--- | :--- |
| 1 | **梳毛经济**（灵长类原市） | 猴群用互相梳毛购买同盟与保护——梳毛是**时间本位的硬通货**（一小时的梳毛＝一小时的真实成本，无法通胀——handicap 完美状态） |
| 2 | **言语梳毛**（语言的发明） | Dunbar 理论【D】：语言的进化动机之一＝**廉价梳毛**——说话代替抓虱子，一次可"梳"数人、可远程、可异步。**成本革命带来规模扩张**（梳毛上限约 50 只，语言上限邓巴数 150）——但成本降低的代价：**言语梳毛天然趋向通胀**（gossip 的廉价使它必须靠频率与细节维持币值） |
