## 0. 结论（先行）

> **确诂一句话**："名不正，则言不顺"＝**名分不正，那么政令言语便不能顺理成章、无从成立推行**——"名"指名分、名位（本事中即卫国君位与父子之名），"正"是使动（使名实相符），"言"指可施于政的号令与承诺（非日常闲谈），"顺"训**理**（《说文》"顺，理也"），即言之成理、推得动（非"顺从"、非"顺口"）。两句是**因果**不是并列，且不在句内闭合——它是六环链的第二环：
> **名正 → 言顺 → 事成 → 礼乐兴 → 刑罚中 → 民措手足**（起点是"名"，终点是"民"）。

| 项目 | 判定 |
| :--- | :--- |
| 句子性质 | 连锁推演句（因果链第二环，带"则"算子） |
| 关键训诂 | 名＝名分名位；正＝使正（使动）；言＝政令、可执行之言；顺＝理（成理、说得通） |
| 篇章结构 | 六环链：名→言→事→礼乐→刑罚→民；本句只占前两环，义在链上 |
| 文内自注 | 章末"**名之必可言也，言之必可行也**"——孔子自定"名—言—行"的可执行标准，是本句的释义锁定句 |
| 篇内反驳 | 子路"有是哉，子之迂也！奚其正？"——反对意见写在同一章里，反证本句是**答辩**而非训诫 |
| 必留语义 | ① 名实相符（正的对象是名与实的关系）；② 言依名而立（授权链断裂则号令失效）；③ 链条不可跳环（跳第一环，后五环空转） |
| 情感色彩 | 答辩的峻切（"野哉，由也"）——先斥其失，再陈其理 |
| 引申链（语用流变） | 春秋卫国政事（名实错位）→ 汉唐"名教"纲纪 → 现代个人化（"说话没底气""师出无名"）——由治理链降格为处境语 |

**证据链一句话**：原文六环链（同章连下）＋章末文内自注（"名之必可言，言之必可行"）＋《说文》"**顺，理也**"＋《论语·颜渊》"君君、臣臣、父父、子子"（正名的正面公式）＋《荀子·正名》"名定而实辨"、《韩非子》"循名责实"（名实命题的跨学派平行）＋卫国父子争国本事 → 反例否决"名字说""名声说""顺从说""口才说""形容词正说" → 确诂成立。

## 3. 六步解析实操（古语句子版·连锁型）

### ① 读语境（定场＋语篇功能定位）

- 三问：**谁说**——孔子；**对谁**——子路（弟子，直率敢驳，故有"迂"之讥）；**什么场合**——师徒论为政之先务，实指卫出公欲用孔子之事。
- **本事复原**：卫灵公太子蒯聩出奔，灵公卒，卫人立其子辄（出公）。辄以子拒父而居君位，父子之名与君臣之位同时错位。孔子至卫，出公有意任用，"卫君待子而为政"即指此。故"正名"绝非泛论，直指"辄之位"。
- **语篇功能问（第四问）**：本句在章内干什么？——整章是**三回合答辩**：
  ```
  ① 子路设问：将奚先？           → 探孔子施政次序
  ② 孔子作答：必也正名乎！        → 立主张
  ③ 子路反驳：子之迂也！奚其正？   → 篇内反例（时人视角）
  ④ 孔子驳斥：野哉由也……名不正则言不顺…… → 本句所在：以链条证"不迂"
  ⑤ 章末自注：名之必可言，言之必可行 → 给出可执行标准
  ```
  本句的位置是**答辩的第二回合**：不是陈述教义，是**回应"迂阔"的指控**。这一问决定了释义方向——凡解释成"泛泛的道德格言"的，都答不了子路那一问；只有把它读成"治理链条的第一环失效将导致全链失效"，才构成"不迂"的证明。
- **产出**：确诂必须能回答"为什么正名是施政之先"；凡不能承接"奚先"之问的义项，一律出局。

### ② 拆关键词群（句子版：逐训点扫描＋结构分析）

| 训点 | 本义 → 句中义 | 依据 |
| :--- | :--- | :--- |
| 名 | 自命（夜间以口自名，起于辨识）→ **名分、名位**（名实相符的身份秩序） | 《说文》"自命也"；皇侃"名，名分也"（待核）；本事指父子君臣之名 |
| 正 | 不偏（是也）→ **使……正、匡正**（使动用法） | 《说文》"正，是也"；"必也正名乎"之"正"带宾语，必为动词 |
| 言 | 言语 → **政令、号令、可执行之言** | 章末"言之必可行也"自注其可执行性 |
| 不顺→顺 | 理（纹理条理）→ **顺理、成理、推得动** | 《说文》"**顺，理也**"——本义即"理"，非"顺从" |
| 则 | 就、那么（因果连词） | 六环全用"则"承接，是**链条算子**，非修辞衬字 |

**结构分析（句子型）**：

1. **句式＝因果链的一节，不是自足的判断**。全章五个"则"连缀成一条单向推导，本句居首二环。故其主语虽只"名""言"二字，语义负载却必须容下后四环——**释一句而须顾全链**，这是连锁型与前三型的根本差别。
2. **"则"是算子不是衬字**。通行引用多作"名不正，言不顺"（脱"则"），两句由**因果**降为**并列**：原句是"因不正故不顺"，脱字后易读成"既不正又不顺"的两项并列。此一字之脱，正是本句流传中最普遍的误读入口。
3. **两组对举构成闭环**：句内"名—言"，章末"名—言—行"。孔子用"必可言""必可行"两级检验，把"名"钉在可执行性上：**一个名若说不出所以然、说不出的话又做不成，这个名就是空的**。这与"觚不觚"的叹息同源——名不副实，器物与制度同时失语。
4. **主体的单一性**：句中"言"的主语是**在位者**（君子、为政者），不是任何人。若读作"人人说话不顺"，则链条后四环（礼乐、刑罚）无所归依。

- **产出**：五个训点收敛＋三处结构判定成立，本句骨架即出：**为政者之名若不副实，则其号令不成理、不可行，进而全链失效。**

### ③ 追声音（通假、异文与防讹）

- **无通假可立**。名、正、言、顺四字在句中皆用本义或近本义引申，历代注疏未见通假异读。若后见清儒（如刘宝楠《论语正义》）别训，按元规则 2 重审。
- **异文一：脱"则"字**。原文"名不正，则言不顺"，通行引用作"名不正，言不顺"。此为简省，非异文——但**语义后果严重**（因果→并列），引用时宜还原。
- **异文二："必也正名乎"**。或引作"必也正名乎"，"也"为句中停顿助词，非"也是"之"也"，不可译作判断词。
- **防讹一条："措手足"**。章末"民无所措手足"，"措"训安置（《说文》"措，置也"），非"措辞"之措；通作"错"（"无所错手足"），"错"亦置也，非"错误"。
- **防讹二："刑罚不中"之"中"**。读 zhòng，训得当，非"中间"。今人误读为 zhōng，则"不中"成"不在中间"，句意全失。
- **防讹三："顺"非"顺口"**。今语"顺"以"顺畅、流利"为常，字书的本义"理"反被遗忘。此处一旦训"流利"，下文"事不成"便接不上——**口才与政事之间没有因果**。

- **产出**：无通假；异文一组（脱"则"）＋防讹三条（措／中／顺），均入第 ⑥ 步。

### ④ 查书证（链条锚定——本例核心动作）

- **动作升级**：前三例的第 4 步分别做数字制度锚定（五世＝丧服分界）、文内枚举自注（六世＝六君列名）、实物等级锚定（曲县＝诸侯三面）。本例做第四种——**链条锚定**：句义由"它在链条中的位置"给出，须找出同构链条对读，才能确定每一环的强度。
- **锚点一：同章链条（内证）**。名→言→事→礼乐→刑罚→民。注意各环的**递进逻辑**：言是"说得出"，事是"做得到"，礼乐是"秩序成"，刑罚是"裁量当"，民是"行为有据"。这是一条**从符号到行为**的降维链，每环都是前一环的落地形态。
- **锚点二：《左传》链条（同代外证）**。师服"名以制义，义以出礼，礼以体政，政以正民"——同样是"名"起、"民"结，中间环目不同（义、礼、政 vs 言、事、礼乐、刑罚），说明**"名→……→民"是春秋政治思维的公共语法**，孔子只是把中段换成了自己的关切。
- **锚点三：《荀子》《韩非子》（跨学派外证）**。荀子"名定而实辨"，韩非"循名而责实"——儒法两家对"名"的用法不同（荀子正名以明道，韩非循名以课能），但都承认**名是可操作的政治接口**。这直接驳倒"迂阔"之讥：同时代最务实的两派都在处理名实问题。
- **锚点四：《颜渊》正面公式（内证互补）**。"君君，臣臣，父父，子子"——四个"名"字叠用，前为名词后为动词，句式本身即是"正名"的定义：**使君像君、臣像臣**。与本句一反一正，互为注脚。
- **锚点五：字书锚**。《说文》"顺，理也"，是全句训释的定谳；"事，职也"坐实"事"为政事而非泛事。
- **产出**：本句由"一句格言"坐实为"一条公共政治语法的头两环"；"顺"由"顺口"坐实为"成理"。

## 6. 方法自检

**管用的地方：**

1. **篇内反驳是语篇功能的定位器**。子路一句"子之迂也"，把本句的功能从"训诫"锁定为"答辩"，随之给出硬验收条件：解释必须能证明"正名是施政之先"。这比任何注疏都直接——**原文自带的反对意见，是最好用的释义基准线**。
2. **"则"字识别为链条算子**。一个虚字的存废，决定因果或并列。此前三例的算子分别是"而"（转折判决）、"奋"（动词链首）、"不可以"（禁令模态）；本例补上"则"（因果递推）。**虚字在句子型释义中的权重被系统性低估了。**
3. **字书本义可防今义降格**。《说文》"顺，理也"一句，抵得上千言辨析：今义"顺口"与本义"成理"之间，正是本句由政治命题滑向口才问题的分水岭。
4. **跨学派平行可用作"不迂"的证明**。荀子、韩非都在处理名实，说明这是时代的技术问题，不是一家空谈——**外证在此不只证明词义，还证明命题的现实性**。

**暴露的边界（本次新发现）：**

1. **连锁型句子的释义单位是"链"**。单句抽出来训，只能得到"名不正→言不顺"这一节的字面；要确定"顺"的强度（成理到什么程度）、"言"的范围（政令还是泛指），必须看后四环的落点。**第 1 步应增设"链条边界问"：这条链从哪起、到哪止、我在第几环。**
2. **虚字须单列训点**。此前训点只列实词，本例"则"若不列，脱字之误无从发现。建议句子型第 2 步固定增列"算子"一项（而／则／唯／不可以／必）。
3. **引用层的简省会造成语义级损伤**。前例的"引者回灌"是义项污染，本例的脱"则"是**结构污染**——前者改义，后者改逻辑关系。两者应分列两条元规则。
4. **典故型句子的"实指—通义"双读需明确分层**。本事提供语境，通义提供适用面；释义时若只给通义，句子会飘；只给实指，句子会死。**双读并存而实指优先，是可推广的处理法**。
