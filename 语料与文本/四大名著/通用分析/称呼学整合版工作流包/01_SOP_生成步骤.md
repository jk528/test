# 称呼学整合版 · 01 生成步骤（SOP）

> 本文件描述"一回整合版"从零到交付的完整逻辑与操作步骤。所有步骤以 055 整合版为规格锚。
> 总体逻辑：**先取证，再命名；先分层，再成文；先自检，再交付。**

---

## 阶段 A　备料：把"可引用的东西"备齐

| 步 | 动作 | 要点 |
| :---: | :--- | :--- |
| A1 | 定位底本 | `红楼梦_拆分\NNN_*\第N章　*.txt`；记下完整文件名，写进头标 |
| A2 | 通读底本全文 | 不做抽样。必须读到回末"且听下回分解"，避免漏掉末段的关键事件 |
| A3 | 读旧稿（若有） | 只取**事件清单与已知错漏**作对照，不沿用其结论与措辞；旧稿错误须逐条核实 |
| A4 | 打开框架件 | 十问、四层十二件①–⑫、双公式、26 条定律编号，确认本回可用件号 |

产出：底本全文 + 旧稿事件表 + 可用件号清单。

---

## 阶段 B　定调：先写"一眼能记住的判断"

| 步 | 动作 | 要点 |
| :---: | :--- | :--- |
| B1 | 写一句话 | 格式：**本回是"××"的××**——指出核心矛盾 + 两个相反动作。必须能覆盖全回，不写成情节复述 |
| B2 | 十问速查表 | 10 行固定；只填"本回答况"与"落点事件编号"，未命中的问写"未正面涉及" |
| B3 | 四层十二件分布 | 固定 12 行；③拟亲属桥等可标"未命中"；"代表事件"填 §1 的编号 |
| B4 | 判定表 | 五行：回目情境／称呼事件数／命中定律／特色。事件数须与 §1 行数一致 |

---

## 阶段 C　切事件：把一回拆成 10–12 件

| 步 | 动作 | 要点 |
| :---: | :--- | :--- |
| C1 | 定切分单位 | 以"一次称谓变更／一次立场冲突／一次授权或拒绝"为单位，不以段落为单位 |
| C2 | 写五列表 | `# ｜ 事件（原文锚） ｜ 四维定位 ｜ 层位/件 ｜ 命中` |
| C3 | 四维定位 | 场（B8 古典家闱等）／单位（亲缘、职分、位格、出身）／极性（对谁·褒贬平）／通道（面称、背称、书称、叙述） |
| C4 | 标层位/件 | **只写理论件号**（①亲缘网、②场景网、④立场调制……），不写 L1–L4 当层名 |
| C5 | 写命中 | 每件 4–6 点，格式为"**①「原文」的判词**（解释）——**规律句**：一句可迁移的话" |
| C6 | 事件链读法 | 表后另起一段，把 11 件并成 4 条链，并点出四链共用的母题 |

事件数建议 10–12；每个事件的原文锚不少于 2 处「」，且必须逐字取自本回底本。

---

## 阶段 D　三段重点：每回固定三刀

### D1 生成公式复盘（立场×见识×智慧×对话者）
选一件"改变称呼格局"的事件，四因子各写一段，再叠一帧**通信公式**（WHO×STANCE×MOOD×CHANNEL×LEXEME），补"黑盒一侧"与"密级对照"两小条。

### D2 攻击帧复盘（燃料／靶心／真值／破防）
选一件对抗性事件，逐柱验四支柱；给出"帧序列复盘"（发现→定性→取证→施压→反转→撤帧）与"成本对照"。

### D3 成本核算（三址＋密级＋handicap＋账本）
选一件说服性事件，写 To/CC/BCC、密级混用、25 handicap（先付什么成本）、26 账本不对称（谁得利、谁出名义），最后列"成本三问"（能量／风险／机会）。

三段均以 `判语：` 收束，判语必须给出一个可迁移的结论，不复述前文。

---

## 阶段 E　四层观察（L1–L4）

- **L1 词库层**：本回被重铸、被禁用、被借用的词（3–5 条）
- **L2 生成层**：同一人几副舌头、自称的变化（3–5 条）
- **L3 执行层**：传话、上报、信道、仪注（3–5 条）
- **L4 治理层**：三笔账、一次改制、一条禁令（3–5 条）

每条格式：**现象**——一句解释——**规律句**。

---

## 阶段 F　定律表（55–60 行）

- 列：`| 定律 / 命中（编号） | 本回证据 |`
- 排序：①→②→…→⑫，再排跨层编号（15／17／18／19／21／22／23／25／26）
- 证据列必须是本回底本原文「」，同一句尽量不重复使用
- 每行标题写成"编号＋短名＋本回形态"，便于检索

---

## 阶段 G　钩连

五类各 1–3 条：对前回／对后文（标回次区间）／对体系（四层联动标本）／对预判四题／可选跨著。

---

## 阶段 H　自检与交付

| 步 | 动作 |
| :---: | :--- |
| H1 | 跑 `03_质检脚本_参数化.ps1`，须退出码 0、未锚定 0 |
| H2 | 跑 `04_审计扫描脚本.ps1`，处置候选（误报记入进度） |
| H3 | 核对密度：字符 16–18k、定律行 55–60、「」185–200 |
| H4 | 按标准名命名：`NNN_第N回_上句标题.md`；旧稿移入 `_旧稿归档\`，不并存 |
| H5 | 未经用户明确说"同步"，不 commit、不 push |

---

## 返工场景的额外步骤

1. **只重做指定回**：读底本＋旧稿→按本 SOP 全流程重写，不沿用旧稿段落。
2. **加厚**：优先补 §3 四层条目与 §5 钩连，不靠拉长 §1 事件描述。
3. **纠错**：先列错点清单（主语、归因、异文、引号用途），逐条在文中定位修正，再跑质检。
4. **命名统一**：整合版内容以标准名落盘，原稿归档；避免同回双文件导致计数偏高。
