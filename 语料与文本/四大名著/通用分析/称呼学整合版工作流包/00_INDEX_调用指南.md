# 称呼学整合版工作流包 · 00 调用指南

> 适用对象：《红楼梦》称呼学解构 **055 回及以后**的"整合版"回目文档（以 055 为规格锚）。
> 与旧包关系：本包是 `通用分析\称呼学工作流包`（00–06）的**升级补充包**，不替代旧包。旧包负责全局批次、审计与进度；本包只负责"单回整合版"的生成逻辑、步骤与硬性限制。
> 规格锚文件：`红楼梦\称呼学解构\055_第55回_辱亲女愚妾争闲气.md`（内容为整合版，文件名已回归标准）。

## 一、这套工作流解决什么问题

旧版回目文档存在四类问题：层位混用工程简写（L1–L4 当层名）、事件表缺四维定位、定律表稀疏、引文与分析性短语混用引号。整合版用**双公式为纲、四层十二件为目、十问为检核**重排，把"读感"换成"可核对的证据链"。

## 二、文件清单与阅读顺序

| 顺序 | 文件 | 用途 |
| :---: | :--- | :--- |
| 1 | `00_INDEX_调用指南.md` | 本文件：定位与阅读顺序 |
| 2 | `01_SOP_生成步骤.md` | 从备料到交付的完整逻辑与八阶段步骤 |
| 3 | `02_硬性限制与质检清单.md` | 命名、结构、引文、计数、禁止项 |
| 4 | `03_模板骨架.md` | 可直接套用的章节骨架 |

配套脚本（沿用旧包，不复制）：
- `通用分析\称呼学工作流包\03_质检脚本_参数化.ps1`（结构／计数／引文锚定）
- `通用分析\称呼学工作流包\04_审计扫描脚本.ps1`（批量审计）

## 三、一句话流程

**读底本 → 切事件 → 双公式复盘 → 四层观察 → 定律表 → 钩连 → 跑质检 → 按标准名归档。**

## 四、适用与不适用

- 适用：单回称呼学解构的撰写、返工、加厚、旧稿纠错。
- 不适用：跨回专题研究、全书统计（走旧包 01_SOP 与 04 审计）、其他名著（本包术语按《红楼梦》底本锚定）。
