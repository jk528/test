# 称呼学整合版 · 02 硬性限制与质检清单

> 本文件是可执行的"红线清单"。写作时逐条对照，交付前逐条打勾。

## 一、命名与目录

| 项 | 规定 |
| :--- | :--- |
| 文档名 | `NNN_第N回_上句标题.md`（三位序号＋回次＋底本回目上半句），写入 `整合版可查\` |
| 例 | `整合版可查\056_第56回_敏探春兴利除宿弊.md` |
| 禁止后缀 | 不再使用 `_整合版` 后缀；整合版内容直接以标准名落盘 |
| 旧稿 | 放 `称呼学解构\人读版\`，**不与标准名并存**（并存会使质检"声明事件总数"偏高） |
| 底本 | 不改名、不移动；路径写进头标 |
| 提交 | 未明确说"同步／提交"，不 commit、不 push |

## 二、结构与计数（质检脚本硬校验）

| 校验项 | 要求 |
| :--- | :--- |
| 六节齐全 | `## 0.` 至 `## 5.` 一节不缺 |
| 事件计数守恒 | §1 表行数 ＝ 判定表"本回解构 N 件" ＝ 尾注"本回称呼事件 N 件" |
| 重点段数 | `###` 数量 ＝ 尾注"重点解构 N 段"，固定 **3** |
| 尾注 | 含"部分内容可能由 AI 生成"，末行恰为 `> AI生成` |
| 头标 | 含系列进度（NN/120）、底本路径、框架回指、整合说明 |

## 三、引文锚定（最易出错）

1. **所有 ≥12 字（去标点归一化后）的「」内容，必须逐字出现在本回底本**；脚本按"本回底本＋本回名词列锦"校验。
2. **「」只用于底本原文**。分析性短语、概括词、自造术语一律不得用「」——可用加粗、"引号"或直接行文。
3. **跨回引文不得用「」**。引用前回／后文的句子只能转述（例：不写「我但凡是个男人」，改写为"探春曾叹女孩儿不能出去立事业"）。
4. **不得虚构异文**。尾注列"底本异形字"时，只列该回底本真实出现的字（如 058 的"针黹""阿物儿""挑么挑六"）。
5. 引文含底本内层引号（“ ”）时，整段照抄，不改写、不转简体异体。

## 四、术语与层位

| 禁止 | 应写作 |
| :--- | :--- |
| 用 `L1–L4` 作层位名 | ①亲缘网／②场景网／③拟亲属桥／④立场调制／⑤评价调制／⑥情绪调制／⑦点对点协议／⑧网络协议／⑨信道密级／⑩攻击帧／⑪增益帧／⑫成本底账 |

| 事件层位只标一个件 | 一件可标 2 个件，用"；"分隔 |

## 六、内容质量红线

- **不写情节复述**：每个事件必须落到"称谓／立场／成本"的变化上。
- **不空转形容词**：每条命中要有"原文锚＋机理解释＋可迁移规律句"三段式。
- **判语不重复正文**：判语给结论，不给摘要。
- **旧稿错误必须核实**：主语（谁送的）、归因（因穷／因无能）、异文、引号用途四类重点查。
- **四维不空填**：场、单位、极性、通道四项都要具体，不写"人际关系"这类空词。
