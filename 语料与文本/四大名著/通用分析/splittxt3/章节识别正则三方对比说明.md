# 章节识别正则三方对比说明（A 彩读目录 / B standard / C 第三方）

## 一、总纲

### 1.1 三条正则原文

**A. 彩读目录正则**（彩读阅读 ColorTxt 内置目录识别规则，下游阅读器侧）

```
^[ \t　]*(第[0-9０-９一二三四五六七八九十百千万亿億零〇○两兩壹貳贰叁參肆伍陸陆柒捌玖拾佰仟廿卅卌皕萬]{1,12}[章回卷节集部篇])(?:[ \t　：:]+(.*))?$
```

**B. standard 正则**（本工具章节级第 1 优先级规则，见 split_txt_v3.py / split_txt_v3.bas）

```
^[ \t　]*第([0-9０-９一二三四五六七八九十百千万亿億零〇○两兩壹貳贰叁參肆伍陸陆柒捌玖拾佰仟廿卅卌皕萬]+)(章|回|节|卷)(?:[ \t　：:]+(.*))?$
```

**C. 第三方章节正则**（新增对比对象）

```
^\s*(第[零一二三四五六七八九十百千万两〇壹贰叁肆伍陆柒捌玖拾廿卅卌佰皕仟萬0-9０-９]{1,12}[章回卷节集部篇])\s*(.{0,40})\s*$
```

### 1.2 一句话结论

- **A 与 B**：字符集、空白、分隔符完全相同，差在**捕获组结构、单位字覆盖、数字长度**三点（详见上一版结论）。
- **C 是 A 的"近亲变体"**：同样 2 组整体捕获、同样 7 个单位字、同样 12 字上限；但**数字字符集少了 7 个字（亿億兩貳參陸○）、标题不要求分隔符、标题限 40 字、空白类更宽（\s）**。
- 三条正则**两两互不包含**，呈三方交叉关系；存在明确的安全交集格式。

### 1.3 三方差异速览表

| 维度 | A. 彩读目录 | B. standard（本工具） | C. 第三方 |
|------|------------|----------------------|-----------|
| 捕获组 | 2 组：`("第N章")`、`(标题)` | 3 组：`(N)`、`(单位)`、`(标题)` | 2 组：`("第N章")`、`(标题)` |
| 单位字 | 7 个：章回卷节集部篇 | 4 个：章回节卷 | 7 个：章回卷节集部篇 |
| 数字字符集 | 60 字全集（含亿億繁体大写） | 同 A | **53 字，缺 亿億兩貳參陸○** |
| 数字长度上限 | `{1,12}` | `+` 无上限 | `{1,12}` |
| 行首空白 | `[ \t　]*` | `[ \t　]*` | `\s*`（更宽，含 NBSP 等） |
| **标题分隔符** | 必须有（空白/冒号）或行尾 | 同 A | **无需分隔符** |
| **标题长度** | 不限 | 不限 | **≤40 字** |
| 冒号归属 | 冒号在标题捕获之外 | 同 A | 冒号被吃进标题捕获 |
| 误报风险 | 低 | 低 | **较高**（无分隔要求，易吞正文句） |
| 用途定位 | 阅读器目录展示 | 拆分/去重/排序解析 | 目录识别（宽松通吃型） |

## 二、逐项差异详解

### 2.1 差异①：捕获组结构（C 同 A）

- **A、C**：`(第N[单位])` 整体捕获 + 标题组，共 2 组。只用于"拿出来展示"。
- **B**：`第(N)(章|回|节|卷)` 拆成数字组、单位组、标题组，共 3 组。本工具要拿独立数字串做中文数字→阿拉伯转换、排序、去重、跨卷判定，必须拆组。

### 2.2 差异②：单位字覆盖（C 同 A）

- **A、C** 认 7 个单位（含集/部/篇），"第三集""第一部""第二篇"都能进目录。
- **B** 只认 4 个，卷/部/册/篇/集/季由工具内的卷级正则（VOLUME_PATTERNS）在更高层级接管，属分层设计而非遗漏。

### 2.3 差异③：数字长度上限（C 同 A）

- **A、C** 限制 `{1,12}`，数字超过 12 个字符即放弃识别（防御异常长行）。
- **B** 用 `+` 无上限，处理极端脏文本宁可多认。

### 2.4 差异④：数字字符集宽度（C 独有短板）

C 的字符类比 A/B **少 7 个字**：

| 缺失字 | 类型 | 受影响示例（C 漏认，A/B 能认） |
|--------|------|-------------------------------|
| 亿、億 | 大数单位 | `第一亿零三回`、`第壹億回` |
| 兩 | 繁体"两" | `第兩百回`（C 只认简体"两"） |
| 貳 | 繁体大写"二" | `第貳拾回`（C 只认"贰"） |
| 參 | 繁体大写"三" | `第參拾回`（C 只认"叁"） |
| 陸 | 繁体大写"六" | `第陸拾回`（C 只认"陆"） |
| ○ | 圆圈号 U+25CB | `第○三回`（罕见写法） |

> C 保留了简体大写全套（壹贰叁肆伍陆柒捌玖拾佰仟）和廿卅卌皕萬，日常简体文本够用；**遇到繁体/大写/含"亿"的章号就会漏**。

### 2.5 差异⑤：标题分隔符要求（C 最宽松，误报最高）

- **A、B**：`(章|回|…)` 之后必须是 `[ \t　：]+` 分隔符或行尾，否则整行不匹配。
- **C**：单位字之后 `\s*(.{0,40})` —— **任何字符都可直接当标题**，无需分隔：
  - `第十二章标题紧跟` → A、B 拒绝；**C 匹配**（标题="标题紧跟"）。
  - 副作用：正文里"第三回长安城落了雪……"这类**无分隔的叙述句首**会被 C 误判为章节（误报风险）。
  - 副作用：`第十二回：标题` 中，A/B 捕获的标题是干净的"标题"；**C 捕获的是"：标题"，冒号残留在标题里**（目录显示需再清洗）。

### 2.6 差异⑥：标题长度上限（C 独有）

- **C** 的 `(.{0,40})` 把标题**硬限 40 字**：单位字之后剩余非空白内容超过 40 字 → 整行不匹配，该章节从目录消失（漏报）。
- **A、B** 的 `(.*)` 不限长度。

### 2.7 差异⑦：空白字符类（C 略宽）

- **A、B** 的 `[ \t　]` 只认半角空格、Tab、全角空格。
- **C** 的 `\s` 还认不间断空格（\xa0）、换页符等 Unicode 空白；逐行匹配时主要体现为 **NBSP 分隔的标题行 C 能认、A/B 不能认**（整文多行模式下 \s 还可能吞换行，需注意）。

## 四、对本项目的实际影响（兼容性结论）

1. **三方安全交集格式**（最稳输出）：
   `第N章|回|节|卷 + 空格或冒号分隔 + 标题≤40字`，数字用阿拉伯数字或常见中文数字（一二三四五六七八九十百千万零〇两），**不含亿/繁体大写、数字≤12字**。满足此格式的章节三方正则全部可识别。
2. **工具 → A**：standard 认出的章节 A 全认，完全兼容（上一版结论不变）。
3. **工具 → C**：本工具的"章号归一化"（中文数字→阿拉伯数字）恰好同时解决 C 的两个短板——**数字压短到 12 字以内、规避亿/繁体大写缺字**。归一化是打通三方的关键环节。
4. **残余风险点**：归一化后若**标题仍超 40 字**，C 类规则会漏认该章；拆分输出时建议关注超长标题（可由归一化/截断策略兜底）。
5. **方向性差异**：B 是"修得准"（解析严、结构化），A 是"看得全"（单位宽、展示向），C 是"吞得多"（无分隔要求、误报最高）。工具位于上游只负责产出规范文本，下游阅读器各自的识别宽窄不影响工具输出的正确性。

## 五、总结

| | A. 彩读目录 | B. standard（本工具） | C. 第三方 |
|---|---|---|---|
| 本质 | 目录**展示**正则 | 章节**解析**正则 | 目录**通吃**正则 |
| 关键特征 | 整体捕获 / 7 单位 / 限 12 字 / 全字符集 | 拆解捕获 / 4 单位 / 不限长 / 全字符集 | 整体捕获 / 7 单位 / 限 12 字 / **缺 7 字** / **标题≤40** / **无需分隔** |
| 三者关系 | 两两互不包含，三方交叉 | 同左 | 同左 |
| 安全交集 | 第N章/回/节/卷 + 分隔符 + 常规数字≤12字 + 标题≤40字 | — | — |

**记法**：彩读"认得宽、取得整"；工具"认得准、拆得开"；C "吞得多、挑数字"（对数字字集和标题长度更挑剔，对分隔符却最放纵）。
