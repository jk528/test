# 整合版规格与写作规程

> 每回生成前必读。骨架原文见 `assets/skeleton.md`；理论件号与定律编号见 `references/methodology.md`。
> 本文件由《红楼梦》称呼学解构工程（整合版工作流包 01／02／03／05）浓缩而成，去除书目专属路径，跨书通用。

## 1. 六节骨架与固定行数

写作顺序：先 §0 一句话与三张表 → §1 定稿 → §2 → §3 → §4（从正文回捞证据）→ §5。

## 2. 引文红线（返工率最高）

1. 「」内**只能是本回底本连续逐字原文**；分析性短语、概括词、自造术语一律改用加粗或行文引号。
2. **不得漏中间短句**：底本「甲：『X。』Y：『Z。』」不可只引后者。
3. **动作词／语气词与底本完全一致**：底本「宝玉推他道」不可写成「宝玉道」。
4. **严禁把并列／节选词塞进同一个「」**。错误示范：`「成仙了道／霞举飞升／与天地齐寿」`；正确写法：各自成「」且各自在底本中连续命中。
5. 引文末尾标点与底本一致；底本内层引号（弯引号）原样保留，不改写、不转简体异体。
6. 跨句号长引文可分段用「」＋「」并以「＋」连接，**每段内部必须连续**。
7. 引文在文中出现的顺序与底本顺序一致。
8. **跨回内容一律转述**，不加「」。
9. 不得虚构异文；尾注所列异形字只列该回底本真实出现的字。

> 自检脚本按 `……｜＋｜——｜—` 切片段，归一化后长度 <12 的跳过，≥12 的必须在本回底本或本回列锦中连续命中。归一化剥离标点／空白／零宽字符，故标点差异无妨，**但字不能改、不能跳、不能并**。
> 事件小标题里至少 2 处「」，且来自底本不同位置。

## 3. 归属门（锚定之外的独立一层）

**总原则：引文命中底本，不等于归属正确。** 「」只证明「这句话存在」，不证明「这句话是这个人说的、对这个人说的」。

五类必消灭的错误：主客倒置（施称者与受称者互换）／施受倒置（认亲、命名方向反）／张冠李戴（说话人错）／关系身份错标（亲属格错）／引文不存在（多为跨回或改写）。

核验四步法：
1. **取串**：从「」内取 8–20 字连续片段，去标点。
2. **定位**：在本回底本 `NNN_*.txt` 检索；无命中换 2–3 个片段再试。
3. **读上下文**：命中处前后各 20–40 行，确认说话人与对象。
4. **填三格**：施称者＝？受称者＝？引语是否此人此语？三格任一为空即未核实，不能落盘。

高危位置（按出错频次）：§3「同一个人，好几副舌头」／§0 一句话／§1 事件标题／§4 代表事件／README 与汇总稿的二次转写。概括句压缩主语后最易丢归属。

六个自检问句：主语是否此人？受称者是否此人、有无把被称者写成称呼者？亲属格对不对？引文是否本回？一人多档时每档对象是否各自核过？概括句压缩后主语还在不在？

## 4. A→H 写作流程

| 阶段 | 动作 | 要点 |
| :--- | :--- | :--- |
| A 备料 | 定位底本 → **通读全文至回末** → 读本回列锦 → 打开框架件号 → **A5 引文预截** | 先取证再命名；预截是防未锚定的根，先拷出全部计划引文再写任何分析 |
| B 定调 | 一句话 + 十问速查 + 十二件分布 + 判定表 | 一句话＝核心矛盾＋两个相反动作，覆盖全回，不写情节复述 |
| C 切事件 | 以「一次称谓变更／一次立场冲突／一次授权或拒绝」为单位，不以段落为单位 | 五列表；四维定位（场／单位／极性／通道）具体不空；每件 4–6 条命中，格式「**①「原文」的判词**（解释）——**规律句**」 |
| D 三段重点 | 生成公式（立场×见识×智慧×对话者）／攻击帧（燃料 21・靶心 22・真值 23・破防）／成本核算（To/CC/BCC・密级・handicap 25・账本 26） | 三段均以「判语：」收束，判语给可迁移结论，不复述正文 |
| E 四层观察 | L1 被重铸的词／L2 几副舌头／L3 传递与密级反转／L4 立法・退场・烂账 | 每条格式：**现象**——解释——**规律句** |
| F 定律表 | ①→⑫ 再跨层编号，证据列为本回原文「」 | 每行标题写「编号＋短名＋本回形态」，便于检索 |
| G 钩连 | 对前回／对后文〔NNN–NNN〕／对体系／对预判四题 | 末回须对四题作全书总收束并呼应首回 |
| H 自检交付 | 全文搜「」逐条核 → 跑 `check` → 核密度 → 标准名落盘 | 旧稿不与标准名并存；未经明确要求不 commit／push |

## 5. 密度与质量红线

| 指标 | 目标 |
| :--- | :--- |
| 正文字符 | ≥ 15,700，目标 15,700–17,000 |
| §4 定律行 | 55–72 |
| 「」总数 | 185–215 |
| §1 事件 | 10–12 件（下限 10、上限 12；宁少一件不空转，不得为凑上限把一件事拆成两件） |
| §3 每层观察 | 3–5 条 |

内容质量红线：不写情节复述（每个事件须落到称谓／立场／成本的变化）；不空转形容词（每条命中含「原文锚＋机理解释＋可迁移规律句」三段式）；判语不重复正文；四维不空填；层位一律用①–⑫件号，不用 L1–L4 当层位名（L1–L4 只作 §3 观察分层标题）。
