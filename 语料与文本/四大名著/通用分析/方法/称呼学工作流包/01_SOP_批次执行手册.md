## §2 单回生成（精读六步）

### 2.1 输入与权威分级

| 级 | 来源 | 用途 | 权威性 |
| :--- | :--- | :--- | :--- |
| 底本 | `红楼梦_拆分\NNN_*.txt`（约 5000–9000 字） | **唯一引文权威**——所有「」引文逐字复制 | 100% |
| 坐标 | `名词列锦章节\NNN_第N章.md` | 参考坐标（C 编号可引〔C〕）；**不得作引文源** | 参考 |
| 常识 | 通行本回目/情节/脂批 | 【B】级背景、钩连后文（显式标注） | 辅证 |
| 解读 | 本工程展开 | 【E】级 | 产出层 |

### 2.2 六步流程

1. **通读全文**一次读完，不在中途动笔——先建全局事件图再取舍；
2. **选事件 5–12 件**，三轴取舍：密度（本回收束观察值得单列）× 新颖性（新定律/新称谓现象优先）× 钩连性（能接前后回或预判四题优先）。高价值事件型：命名、骂称、自称、排行、避讳、戏言谶语、转述链、位格裁定、绰号流通、婚配称谓；
3. **录引文**：从底本复制粘贴，任何改动＝违规；
4. **定位映射**：每件三标注——四维定位（场/单位/极性档/通道）→ 层位/件（L1–L4）→ 命中定律（回指总架构 §7.2 的 26 条编号）或工程新命题；
5. **填模板**（见 `02_回目文档模板.md`）：§0 速览→§1 事件清单→§2 重点解构 2–3 段→§3 回内系统观察→§4 定律命中表→§5 钩连→尾注块＋「> AI生成」；
6. **声明计数**：三处一致（§0 声明＝§1 表行数含 Nb＝尾注计数）。

### 2.3 引文纪律（红线）

- 引文不加内嵌 `**` 星号强调；不插括注；异文照录底本＋注记放引号外；
- 任何跳句显式标 `……`；
- 底本讹字/异形字**照录不校**（"睛雯""虎视眈耽""烧糊了的子"等），尾注集中存档；
- 关键引文写前核对说话人归属（读前后 50–100 字确认——高危：多人对白密集段、咕哝、转述嵌套）；逐条按 `……\通用分析\方法\称呼学整合版工作流包\05_称呼归属核验与防错清单.md` 的"施称者／受称者／引语"三格过一遍。

### 2.4 写作体例要点

- 命名：`NNN_第N回_回目缩名.md`（NNN 三位零填充）；
- 头标：系列行含 `（N/120）` 与底本引用声明；
- §5 钩连**固定四向**：对前回（编号回指）/ 对后文（【B】标回号区间）/ 对预判四题 / 对体系或跨著；
- 尾注块必含：证据分级说明＋异文存档＋计数＋「部分内容可能由 AI 生成」＋「> AI生成」。

## §3 单回质检（写完必跑）

```powershell

```

**验收**：退出码 0，输出"质检通过"。

**QMISS 修复类型学**（7–12 批实测汇总，按频次排序）：

| 类型 | 实测案例 | 修法 |
| :--- | :--- | :--- |
| 凭记忆复述差异 | "心不顺了"〔底本"心不顺"〕、"又干这"〔底本"又于"〕 | 查底本原句逐字照录 |
| 异文未照录 | "虎视眈眈"→底本"眈耽"；"烧糊了的卷子"→底本"烧糊了的子"；"竟无肠"→底本"竞无肠" | 照录底本＋尾注存档 |
| 引文内嵌星号 | `**那起坏人的嘴**` | 去星号（强调移到引号外） |
| 衍字/脱字 | "弄弄腌了床"〔衍"弄"〕 | 对照底本删/补 |
| 工具静默跳过 | multiedit 的 oldString 直/弯引号不匹配→部分编辑不生效无报错 | **每次编辑后重跑质检**；复杂替换用 PowerShell 行级操作兜底（见 §8） |

## §4 批次收敛（README 更新）

批内 4–6 回全部质检通过后：

1. **批次表**追加一行（格式照旧）：
   `| 第 N 批（yyyy-MM-dd） | 第 a–b 回 | **已完成（精读全文模式）** | **+X**（n1+n2+…）＝**累计** |`
   审计补全过则状态列注明"审计补全 XX b 两件"；
2. **要点存档**追加：每回一条（核心命题＋关键引文＋新定律命名），加一行审计记录；
3. 跑质检确认"声明事件总数"与批次表累计一致。

## §5 审计补全（密度扫描法）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "语料与文本\四大名著\通用分析\方法\称呼学工作流包\04_审计扫描脚本.ps1" -ProjectDir "语料与文本\四大名著\红楼梦\称呼学解构" -Chapters "043,044,045,046"
```

流程：扫描得未覆盖候选句 → 逐条读底本语境过滤（剔场景句/已收事件引文层）→ 真事件按 **Nb 规则**插入：

- Nb 行插在原编号事件行后（如 6b 紧跟事件 6），**不重排原编号**（§2–§5 与后续回钩连按原编号引用）；
- 表行计数含 b 行；三处声明改为"本回解构 N 件（见 §1，含 Xb）"；
- 补全后**必须**重跑质检至全绿；
- README 批次表累计数同步修正（如 432→434）。

> 经验：扫描法检出率高但**不能替代精读**——纯叙事中的称谓关系变化它找不到。审计的定位是兜底，不是主工序。

## §8 异常处置

| 症状 | 处置 |
| :--- | :--- |
| 质检 FAIL·QMISS 带 `[N→回号]` | 引文混入了别回文本——查底本该回原句重录 |
| 质检 FAIL·计数不符 | 对齐三处计数（Nb 行计入表行数） |
| pre-commit 拒绝 | 同质检 FAIL 流程修复后重新 commit |
| multiedit "oldString not found" 或改完仍报错 | 引号直/弯两套不一致——用 PowerShell 行级 `.Replace()`（码点 `[char]34` 构造直引号）兜底，改后必重跑质检 |
| 候选句大量"未覆盖"但实为已收 | 属引文层覆盖（文档以转述/缩写形式收录）——逐条人工过滤，勿机械补全 |
| 单会话已做 6 回 | 强制收束：报告完成状态，下一批新会话继续 |
