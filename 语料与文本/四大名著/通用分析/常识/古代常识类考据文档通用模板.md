# 古代常识类考据文档通用模板

> 用途：为任意「古代文化常识」主题（制度、礼俗、名物、观念、职官、器物等）生成结构统一、考据严谨的 Markdown 文档。
> 来源：从《五福五服朝代演变与反义考据表》的 10 轮迭代中抽象而成——只保留可复用的骨架与模块，剥离五福主题专属内容。

## 0. 模板定位与使用说明

### 0.1 适用范围

- **适用**：需要按朝代/时期纵向铺开、兼顾官方与民间两种口径、并寻求演变规律的古代常识主题。
- **适用样例**：五福、六极、祭祀礼制、服饰色制、科举、丧服、节气、称谓、职官、货币、婚姻礼俗等。
- **不适用**：单一时点的静态名词解释、纯文学赏析、无史料可征的传说汇编。

### 0.2 章节地图（必填 / 可选）

| 序号 | 章节 | 性质 | 何时保留 |
| :-- | :--- | :--- | :--- |
| 1 | 标题与副标题 | 必填 |  always |
| 2 | 凡例 | 必填 | 凡涉及术语歧义、数据性质差异、争议考据 |
| 3 | 核心考据表 | 必填 | 主题可分期且有双口径 |
| 4 | 项目依次对照 | 必填 | 主题为「N 项集合」（五福、六艺、五常等） |
| 5 | 分期考据说明 | 必填 | 凡核心表需解释成因 |
| 6 | 演化规律总结 | 必填 | 跨度 ≥3 个时期 |
| 7 | 相关内容信息 | 必填 | 任何主题均可补人物/典籍/辨析 |
| 8 | 可选：并维度分析 | 可选 | 需要做定性→定量投影时 |
| 9 | 可选：宏观数据面板 | 可选 | 需要气候/技术/人口/制度背景时 |
| 10 | 演变小结 | 必填 | always |
| 11 | 史料出处与参考 | 必填 | always |
| 12 | 使用指南 | 模板自带 | 套用时删除本章 |

### 0.3 三条贯穿全文的约定

1. **史观与史料分开**：每期考据先列可征文献（史料），再列解释框架（史观），二者分段书写，不混在一起。
2. **数据性质分级**：凡数字与判断，标注来源等级——`史`（有学术依据）/ `评`（综合判断）/ `理`（理论构建，无实测）。
3. **争议不臆断**：有异说处标「一说」「待考」并加脚注，不强行统一。

## 1. 标题与副标题

```markdown
# \[主题名称]（用户术语写作"\[别名]"）的\[演变维度]：\[口径A]、\[口径B]及其\[对照面]——\[学科视角]考据
```

- 标题内嵌三要素：**主题 + 演变维度 + 双口径**，一眼看出文档覆盖范围。
- 副标题点明学科方法（礼制史、民俗史、制度史、考据学等）。
- 若有用户习惯用语与规范术语不一致，在标题内括注，并在凡例中展开。

## 2. 凡例

> 凡例是全篇的"契约"，放在最前。以下六条按需取用。

- **术语界定**：说明\[别名]与正名的关系，防止与同名概念混淆。
  > 示例：本文「五服」系用户沿用的栏目名，实指五福体系；与丧服制度的五服（斩衰、齐衰、大功、小功、缌麻）无关，凡例后文均写「五福」。
- **口径定义**：界定官方口径与民间口径的判别标准。
  > 示例：官方口径＝典籍、礼制、官方认可的表述；民间口径＝年画春联、命理术数、口头俗语中的流传形态。
- **对照面定义**：说明「反义/对立面」指什么。
  > 示例：反义指与\[主题]相对的凶祸不幸观念，官方层面如灾异谴告，民间层面如\[具体表述]。
- **数据性质标注**：声明 `史 / 评 / 理` 三级标注的含义与使用范围。
- **争议标注约定**：声明「一说」「待考」的使用规则。
- **分析视角声明**（可选）：若采用特殊二分视角，在此声明。
  > 示例：全文严格区分「风向＝制度（应然）」与「数据＝实际（实然）」，二者分列，不混用。

## 3. 核心考据表

> 全篇的骨架。行＝朝代分期，列＝上位维度统领双口径。

### 3.1 分期轴（标准 10 期）

`先秦 → 秦汉 → 魏晋南北朝 → 隋唐 → 宋 → 元 → 明 → 清 → 近现代 → 当代`

- 主题涉及特定制度时，可替换分期（如「夏商周 / 春秋战国 / 秦汉…」），但需保持时间连续、不重叠。
- 每行可细化到起讫年份与国祚（见可选模块 9）。

### 3.2 列结构设计

- 双上位维度统领双口径时，采用表头合并式：

```markdown
| 朝代/时期 | 维度甲 | | 维度乙 | |
|:---:|:---:|:---:|:---:|:---:|
| | 官方口径 | 民间口径 | 官方口径 | 民间口径 |
| \[先秦] | \[...] | \[...] | \[...] | \[...] |
```

- 单维度双口径时，简化为三列：`朝代 | 官方口径 | 民间口径`。
- 每个单元格须注明典籍或出处名称，不写孤立结论。

### 3.3 填写规则

- 一格一史实，多说并存时用 `<br>` 分行并标「一说」。
- 反义列与正面列保持镜像对应，便于观察同构/背离。

## 4. 项目依次对照（N 项集合主题专用）

> 当主题为「N 项集合」时，把每项拆开逐次释义。

### 4.1 体系逐项对照表

```markdown
| 体系 | 第1项 | 第2项 | 第3项 | 第4项 | 第5项 |
|:---|:---|:---|:---|:---|:---|
| \[体系A·出处] | \[项名＝释义] | ... | | | |
| \[体系B·出处] | \[项名＝释义] | ... | | | |
```

- 每项格式统一为「项名＝简明释义」，释义控制在 8–20 字。
- 体系数量按实际，至少覆盖原典、改制本、宗教本、民间本、专业术数本、当代本六类。

### 4.2 分期归属对照

一张表覆盖全部分期，标注每期采用哪套体系，形成「体系—朝代」映射。

### 4.3 对立面逐项释义

对「反义」集合同样逐项拆解，并注明与正面集合的镜像关系（几对几、是否有缺项）。

## 5. 分期考据说明

> 每期一段，固定两段式，**史料在前、史观在后**。

```markdown
### 一、\[朝代]：\[阶段定性]

**史料**：\[可征文献与出处，如《书名·篇名》载「原文」]。\[版本号/篇名有异者标「一说」]。

**史观**：\[解释本期变化的原因——政治避讳、宗教渗透、市民文化、技术革新、制度变迁等]。\[点评：本期在长时段中的意义]。
```

- 阶段定性用 4–8 字概括（如「经典定型期」「避讳改易期」「宗教化转型期」）。
- 史观部分须点出**变化动因**，不复述表格内容。

## 6. 演化规律总结

> 从考据表中提炼跨期结构性规律，每条三段式。

```markdown
### 规律一：\[规律名]律

**表述**：\[一句话概括规律]。

**史实支撑**：\[列举 2–3 个朝代的具体事实]。

**点评**：\[一句话点出规律背后的机制]。
```

**常用规律清单（按主题挑用，不必全列）**：

| 规律名 | 内核 | 适用主题 |
| :--- | :--- | :--- |
| 载体下沉律 | 典籍→礼制→宗教→民俗器物→术数→数字 | 观念类 |
| 口径双轨律 | 官方稳定 vs 民间流变的张力 | 有双口径者 |
| 避讳驱动律 | 皇权/礼法避讳改造表述 | 涉及帝王名讳 |
| 宗教渗透律 | 佛道观念改写原有框架 | 生死、福祸类 |
| 数理化/命定化律 | 从修德致福到术数推算 | 命理相关 |
| 反义同构律 | 对立面随正面同步世俗化 | 有反义列者 |
| 数恒项变律 | 容器恒定、填充内容置换 | N 项集合类 |
| 雅俗分合律 | 精英与民间表述的分合循环 | 跨阶层主题 |

## 7. 相关内容信息

> 五个固定子栏目，按需增减。

### 7.1 关键人物小传

每人 1–2 句，说明其与主题演变的关系。

```markdown
- **\[人物]（\[朝代]）**：\[身份与贡献]，与主题的关系是\[...]。
```

### 7.2 民俗/物质载体

图案、器物、建筑、节俗等实物载体，说明其如何承载主题。

### 7.3 典籍索引

列出与主题相关的典籍要点，注明作者、篇名、核心观点。

### 7.4 易混概念辨析

成对辨析易混概念，重点区分同名异物。

```markdown
- **\[概念A] vs \[概念B]**：\[A 的定义]；\[B 的定义]。区别在于\[...]。
```

### 7.5 相关成语俗语

列出相关成语、俗语、禁忌语，各附一句释义。

## 8. 可选模块 A：并维度分析（定性 → 定量）

> 把主题投影到生活维度上做百分比量化。**必须先定义归类规则，再计算，保证可复算。**

### 8.1 维度设定与归类规则

- 定义维度代码（如 A 衣食住行 / B 柴米油盐 / C 生老病死 / D 超维度）。
- 逐项给出落点规则：「\[项目]→\[维度代码]，理由\[...]」。
- 声明这是**后设分析框架**，作趋势看，不宜当精确测量。

### 8.2 逐项落点明细

一张表列出每一项及其落点，末尾附计数。

### 8.3 百分比对照

按双口径（风向/数据，或制度/实际）分列百分比，并核对各项计数自洽。

### 8.4 关键差异解读

聚焦占比差异最大的维度，一句话点破制度与实际的张力。

## 9. 可选模块 B：跨朝代宏观数据面板

> 为背景层数据，与主题正文相对独立，可整块插入或整块删除。

### 9.1 凡例：数据性质与曲线定义

声明每条曲线的性质等级（`史/评/理`）与含义，如：

- 技术 → 生产力（`评`）
- 制度 → 分配效率（`评`）
- 气候 → 冷暖相位（`史`）
- 人口 → 基本盘（`史`）
- 经济 → GDP 与人均（`史`）
- 智商差 → 阶层固化代理指标（`理`，无实测数据，须醒目标注）

### 9.2 朝代进程总表

每朝一行，列：起讫年份、国祚、气候相位、技术标志、人口基本盘、制度分配、代理指标。

### 9.3 权威年份点数据表

采用公认数据源（如麦迪森项目 1990 国际元口径），注明来源与口径，不自行估算。

### 9.4 曲线咬合关系

说明各曲线如何共同作用，解释主题定型的历史条件。

### 9.5 与正文的接口

写明本面板如何回填到主题（如「解释某口径为何定型于某期」）。

## 10. 演变小结

- 用一段话收束，给出**一条主线 + 一句定性**。
- 示例：五个字的容器一直没变，每个时代都往里装进自己最想要的东西——所谓「不同含义」，本质就是一部用\[主题]写成的\[X]史。

## 11. 史料出处与参考

- 逐条列出典籍、论文、数据源，注明作者/版本/年份。
- 与正文脚注一一对应。

```markdown
1. 《\[书名]·\[篇名]》：\[与主题相关的要点]。
2. \[作者].《\[论文/报告名]》. \[出版信息], \[年份].
```

## 12. 使用指南（套用时删除本章）

### 12.1 套用步骤

1. 复制本模板，改标题。
2. 填凡例：先定术语、口径、数据标注。
3. 填核心表：定分期轴与列结构，逐格填史实+出处。
4. 填项目对照（若为 N 项集合主题）。
5. 填分期说明：每期两段式，史料/史观分开。
6. 提炼规律：从表中选 5–8 条，三段式写。
7. 补相关内容：人物、载体、典籍、辨析、俗语。
8. 按需插入可选模块 A/B。
9. 写小结与史料出处。
10. 对照 12.3 清单自检，删除本章。

### 12.2 模块裁减建议

| 主题类型 | 必留 | 可删 |
| :--- | :--- | :--- |
| N 项集合类（五福、六艺） | 全部 | 无 |
| 单一制度演变（职官、科举） | 1/2/3/5/6/7/10/11 | 4 |
| 名物器用类（服饰、货币） | 1/2/3/5/7/10/11 | 4/6/8/9 |
| 观念俗信类（禁忌、吉语） | 1/2/3/4/5/6/7/8/10/11 | 9 |

### 12.3 质量检查清单

- [ ] 标题含主题+维度+双口径
- [ ] 凡例界定清楚术语、口径、反义、数据分级
- [ ] 核心表每格有出处，分期连续不重叠
- [ ] 项目对照每项有释义，反义有镜像说明
- [ ] 每期说明史料与史观分段
- [ ] 规律为三段式，且有史实支撑
- [ ] 数据标注 `史/评/理`，无实测数据处已声明
- [ ] 争议处标「一说/待考」并有脚注
- [ ] 百分比数字与落点计数自洽
- [ ] 小结有主线与定性
- [ ] 史料出处与正文脚注对应
- [ ] 已删除本使用指南章节
