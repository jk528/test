# 中国古代度量衡体系详解

## 1. 度量衡概述

度量衡是中国古代对长度、容积、重量三种计量的统称。

| 类别 | 含义 | 代表单位 |
|------|------|----------|
| **度** | 长度计量 | 寸、尺、丈、引 |
| **量** | 容积计量 | 升、斗、斛、石 |
| **衡** | 重量计量 | 铢、两、斤、钧、石 |

> 「度量衡」之名最早见于《尚书·舜典》：「协时月正日，同律度量衡。」

## 2. 度（长度）

### 2.1 基本单位体系

| 单位 | 换算关系 | 说明 |
|------|----------|------|
| 分 | 1分 = 0.1寸 | 最小常用单位 |
| 寸 | 1寸 = 10分 | 中指中节长度 |
| 尺 | 1尺 = 10寸 | 成年男子手掌到肘部长度（一拃） |
| 丈 | 1丈 = 10尺 | 成年男子身高（一丈=丈夫） |
| 引 | 1引 = 10丈 | 最长的官定长度单位 |

## 4. 衡（重量）

### 4.1 基本单位体系

| 单位 | 换算关系 | 说明 |
|------|----------|------|
| 铢 | 1铢 = 1/24两 | 最小常用单位 |
| 两 | 1两 = 24铢 | 基本单位 |
| 斤 | 1斤 = 16两 | 半斤八两 = 彼此相当 |
| 钧 | 1钧 = 30斤 | 千钧一发 |
| 石（dàn） | 1石 = 4钧 = 120斤 | 读作「担」 |

### 4.2 各朝代一斤的实际重量

| 清 | 596.8 g | 库平两37.3克 |

### 4.3 特殊重量单位

| 单位 | 含义 | 换算 |
|------|------|------|
| 絫（lěi） | 十黍为絫 | 极小单位 |
| 黍 | 一粒黍的重量 | 基准单位，约0.06~0.08克 |
| 圭 | 六十四黍为圭 | |
| 锱（zī） | 六铢为锱 | 锱铢必较 = 斤斤计较 |
| 镒（yì） | 二十两或二十四两 | 黄金单位，以镒称铢 |
| 斤 | 十六两 | 半斤八两（旧制） |

### 4.4 「斤两」的文化含义

- **半斤八两**：旧制一斤十六两，半斤就是八两，比喻彼此不相上下
- **掂量**：用手估量重量，引申为斟酌、考虑
- **斤斤计较**：形容过分计较小事
- **缺斤短两**：指商品重量不够

## 5. 度量衡的演变规律

### 5.1 总体趋势

| 时期 | 变化趋势 | 原因 |
|------|----------|------|
| 先秦 | 各国不一 | 诸侯割据，度量衡不统一 |
| 秦汉 | 统一制度 | 秦始皇统一度量衡，汉承秦制 |
| 魏晋南北朝 | 逐渐增大 | 战乱频繁，制度混乱，剥削加重 |
| 隋唐 | 大幅增长 | 隋代大增大，唐代趋于稳定 |
| 宋元明清 | 缓慢增长 | 商品经济发展，逐步调整 |

### 5.2 为什么度量衡会越来越大？

1. **赋税剥削**：官府征收赋税时，用大斗大秤可以多收粮食布帛
2. **经济发展**：商品交换规模扩大，需要更大的单位
3. **制度变迁**：改朝换代时往往重新制定度量衡
4. **技术进步**：测量精度提高，可以更准确地定义单位

## 7. 现代与古代换算参考

### 7.1 常见文学作品中的数字理解

| 原文 | 古代含义 | 现代约值 |
|------|----------|----------|
| 「身长八尺」（三国） | 汉代八尺 | 约185 cm |
| 「千里走单骑」 | 汉制千里 | 约415 km |
| 「斗酒诗百篇」 | 唐制一斗 | 约6000 ml（6升） |
| 「半斤八两」 | 旧制 | 旧制半斤=八两=约186克 |
| 「万钟之禄」 | 六斛四斗为钟 | 约640石粮食 |

### 7.2 中药计量沿用

中药计量至今仍沿用古制（汉代制）：
- 1两 ≈ 15.625克（据考证）
- 1斤 = 16两 ≈ 250克
- 实际临床多按「1两≈3克」简化换算（李时珍「古之一两，今用一钱」）

> 注意：古代药方中的剂量换算存在争议，实际使用请遵医嘱。
