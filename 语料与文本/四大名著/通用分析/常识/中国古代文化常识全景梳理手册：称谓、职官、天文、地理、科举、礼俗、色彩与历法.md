## 1. 名号与称谓体系

古代称谓讲究尊卑有序，涵盖姓名、字号、谥号及各类谦敬称。

### 1.1 姓名字号

* **姓与氏**：先秦时期“姓”别婚姻，“氏”别贵贱；秦汉以后姓氏合二为一。

* **名**：出生三个月由父亲命名，供长辈呼唤或自称。

* **字**：男子二十岁冠礼、女子十五岁笄礼时取字，供平辈或晚辈尊称。名与字意义通常相关（如诸葛亮，字孔明）。

* **号**：个人自取或他人赠予，显示志趣或居所（如陶渊明号五柳先生，苏轼号东坡居士）。

### 1.2 特殊称号

* **谥号**：死后朝廷依生平给予的评价性称号。

  * *美谥*：文（经天纬地）、武（威强睿德）、昭（圣闻周达）。

  * *恶谥*：灵（乱而不损）、厉（杀戮无辜）、炀（好内远礼）。

  * *同情谥*：哀（恭仁短折）、怀（慈仁短折）。

* **庙号**：皇帝死后在太庙立室供奉的名号，如太祖、太宗。

* **年号**：帝王纪年的名号，明清多一帝一号（如乾隆），此前多一帝多号。

### 1.3 年龄称谓

| 年龄段         | 称谓         | 出处/备注          |
| :---------- | :--------- | :------------- |
| 未满周岁        | **襁褓**     | 包裹婴儿的被子和带子     |
| 2-3 岁       | **孩提**     | 初知发笑，尚在怀抱      |
| 7-8 岁       | **始龀/龆龀**  | 换牙之年           |
| 幼年          | **垂髫/总角**  | 头发下垂或扎成两角      |
| 13-14 岁 (女) | **豆蔻年华**   | 杜牧诗“豆蔻梢头二月初”   |
| 15 岁 (女)    | **及笄**     | 成年，可许嫁         |
| 15 岁 (男)    | **束发/志学**  | 成童，开始专心求学      |
| 20 岁 (男)    | **弱冠**     | 行冠礼，体犹未壮       |
| 30 岁        | **而立**     | 立于礼，有所成就       |

### 1.4 谦称与敬称

* **谦称**：

  * *帝王*：朕（秦后专用）、寡人、孤、不谷。

  * *臣子/一般人*：臣、仆、愚、鄙人、不才、小人、窃。

  * *女子*：妾、贱妾、奴家。

  * *称己方亲属*：家严/家君（父）、家慈（母）、舍弟（弟）、拙荆/内人（妻）、犬子/贱息（儿）、小女（女）。

* **敬称**：

  * *帝王*：陛下、万岁、圣上。

  * *对方*：足下、阁下、执事、左右、君、公、子。

  * *对方亲属*：令尊（父）、令堂（母）、令郎（儿）、令爱/千金（女）、贤弟、尊驾。

  * *师长*：夫子、先生、席前。

## 2. 古代职官制度

### 2.1 中央官制演变

* **三公九卿（秦汉）**：

  * *三公*：丞相（行政）、太尉（军事）、御史大夫（监察）。

  * *九卿*：奉常、郎中令、卫尉等分管具体事务。

* **三省六部（隋唐至宋）**：

  * *三省*：中书省（决策）、门下省（审议）、尚书省（执行）。

  * *六部*：吏（人事）、户（财政）、礼（礼仪教育）、兵（军事）、刑（司法）、工（工程）。长官为尚书，副职为侍郎。

* **内阁与军机处（明清）**：

  * *明代*：废丞相，设内阁大学士协助皇帝处理政务。

  * *清代*：设军机处，军机大臣跪受笔录，君主专制达到顶峰。

### 2.2 地方官制

* **郡县制**：郡守（太守）、县令/长。

* **州道制**：刺史（监察官演变为行政长官）、节度使（唐，掌军政大权）。

* **行省制（元明清）**：行省平章政事、布政使、按察使、巡抚、总督。

### 2.3 官职变动术语

* **授予/提升**：拜、除、授、封、征、辟、荐、举、擢、升、迁（一般指升，左迁为降）。

* **调动/代理**：调、徙、转、改、出（京官外放）、入（地方官进京）、权（暂代）、摄（兼理）、守（试任）。

* **罢免/贬谪**：罢、免、黜、夺、削、左迁、谪、放逐。

* **辞官/退休**：乞骸骨（请求退休）、致仕（退休）、挂冠、归隐。

## 3. 天文星象与地理区划

### 3.1 天文星象

* **二十八宿**：古人观测日月五星运行的坐标系统，分东、南、西、北四宫。

  * *东方青龙*：角、亢、氐、房、心、尾、箕。

  * *南方朱雀*：井、鬼、柳、星、张、翼、轸。

  * *西方白虎*：奎、娄、胃、昴、毕、觜、参。

  * *北方玄武*：斗、牛、女、虚、危、室、壁。

* **常见意象**：

  * **北斗**：斗柄指东天下皆春，指南皆夏，指西皆秋，指北皆冬。

  * **参商**：参星与商星此出彼没，喻亲友分离或对立。

  * **流火**：大火星西沉，天气转凉（农历七月）。

  * **银河**：又称天河、银汉、星河。

### 3.2 地理区划与别称

* **中国/中华**：原指中原地区，后泛指全国。

* **九州**：冀、兖、青、徐、扬、荆、豫、梁、雍，代指中国。

* **海内/四海**：国境之内。

* **江河**：专指长江、黄河。

* **山东/山西**：崤山以东/以西（战国秦汉语境）；太行山以东/以西（后世语境）。

* **江东/江左**：长江下游以南地区（今苏南浙北），因长江在此段呈西南 - 东北流向，南岸在东/左。

* **关东/关西**：函谷关以东/以西。

* **阴阳**：山南水北为阳，山北水南为阴（如衡阳在衡山之南，江阴在长江之南）。

## 4. 科举制度与教育体系

### 4.1 选官制度演变

* **先秦**：世卿世禄制。

* **汉代**：察举制（孝廉）、征辟制。

* **魏晋南北朝**：九品中正制（重门第）。

* **隋唐至清**：科举制（重才学）。

## 5. 风俗礼仪与宗法伦理

### 5.1 宗法制度

* **九族**：高祖至玄孙的直系亲属，或包含父族、母族、妻族的广泛亲属网。

* **嫡庶**：正妻之子为嫡，妾之子为庶。嫡长子继承制是核心。

* **昭穆**：宗庙排列次序，左为昭，右为穆，以此区分辈分。

* **五服**：斩衰、齐衰、大功、小功、缌麻，表示亲属关系远近及丧服等级。

### 5.2 礼仪习俗

* **五礼**：吉礼（祭祀）、嘉礼（婚冠）、宾礼（宾客）、军礼（军旅）、凶礼（丧葬）。

* **座次**：

  * *室内*：东向为尊（项羽坐东向），其次南向，再次北向，最末西向。

  * *朝堂*：南向为尊（面南背北）。

  * *车骑*：虚左（左边位置最尊）。

* **婚俗**：六礼（纳采、问名、纳吉、纳征、请期、亲迎）。

* **丧俗**：丁忧（遭父母丧，官员需停职守制三年）、服阕（守丧期满）。

## 6. 色彩体系与文化意象

古代色彩不仅是视觉描述，更蕴含等级与哲学意义（五行学说）。

### 6.1 五色（正色）

对应五行，象征尊贵与正统：

* **青**（木，东）：苍、碧、翠。

* **赤**（火，南）：朱、丹、红。

* **黄**（土，中）：帝王专用色，象征皇权。

* **白**（金，西）：素、皓。

* **黑**（水，北）：玄、墨、乌。

### 6.2 间色（杂色）

由正色混合而成，地位较低，常用于平民服饰或特定场合：

* **绿**（青 + 黄）：唐代低阶官服颜色（“江州司马青衫湿”实为青色，八品九品着绿）。

* **紫**（赤 + 黑）：虽为间色，但因染料难得，后世逐渐成为高官显贵之色（“满朝朱紫贵”）。

* **橙、褐、骝**等。

### 6.3 特殊色彩词汇

* **玄**：黑中带红，天色，深奥之意。

* **纁**（xūn）：浅红色，黄昏之色，常用于婚礼服饰。

* **黛**：青黑色，女子画眉之用（“六宫粉黛无颜色”）。

* **赭**（zhě）：红褐色，囚犯所穿衣物颜色（“赭衣塞路”）。

* **缁**（zī）：黑色，僧侣服饰（“缁流”）。

## 8. 高频词汇速查与应用示例

### 8.1 高频实词速查

* **诣**：到，去（特指到尊长处）。例：“由是先主遂诣亮。”

* **劝**：鼓励，勉励。例：“果行以劝之。”

* **课**：考核，督促，征收赋税。例：“课农桑。”

* **按**：巡视，考察。例：“按诛五人。”

* **白**：告诉，禀告（下对上）。例：“阿母白媒人。”

* **短**：说坏话，诋毁。例：“短屈原于顷襄王。”

* **让**：责备。例：“平原君让魏公子曰...”

* **坐**：因...犯罪；定罪。例：“坐法去官。”

* **适**：女子出嫁；恰好；往。例：“始适还家门。”

* **归**：女子出嫁；返回。例：“之子于归。”

### 8.2 应用示例解析

> **例句**：“永元中，举孝廉不行，连辟公府不就。”（《张衡传》）
>
> * **解析**：
>
>   * **永元**：年号纪年。
>
>   * **举孝廉**：汉代察举制科目，由地方推举孝顺廉洁之人。
>
>   * **辟**：官府征召。
>
>   * **就**：就职。
>
>   * **译文**：永元年间，（张衡）被推举为孝廉没有去应荐，屡次被公府征召也没有去就职。

> **例句**：“予左迁九江郡司马。”（《琵琶行》）
>
> * **解析**：
>
>   * **左迁**：贬官降职（汉代以右为尊，故左迁为降）。
>
>   * **九江郡**：地名。
>
>   * **司马**：官职，唐代多为闲职或贬官安置之所。
>
>   * **译文**：我被贬官担任九江郡的司马。
