## 0. 结论（先行）

> **确诂一句话**：
> **"东南西北"**＝环行顺次，从东起顺时针（东→南→西→北），仿太阳右旋，配春夏秋冬与五行相生（东木→南火→中土→西金→北水），是承载**秩序、循环、顺天**观念的方位次序，用于讲方位顺序、明堂制度、招魂、四声配伍。
> **"东西南北"**＝两两对举，东‖西、南‖北交叉并列，是**泛举四方**，"到处、各方"义，古籍中常带人生凄惶之意，不表严格方位次序（日语习惯用此序）。
> **异序即异义，不可互换**——语序本身就是义项载体。

| 判定 | 东南西北 | 东西南北 |
| :--- | :--- | :--- |
| 结构 | 环行顺次（相邻首尾相接，可循环） | 两两对举（东西一组／南北一组，交叉） |
| 时序 | 春→夏→秋→冬，顺天、有方向 | 无时序，纯空间泛举 |
| 五行 | 木火（土）金水，相生序 | 木金对、火水对，仅示四方 |
| 核心义 | 次序／循环／秩序 | 到处／各方／凄惶流离 |
| 视角 | 立于中央环视一周（环状地域观） | 两极对举，横向铺开 |
| 时间轴 | 自带（配四时） | 无 |

**证据链一句话**：四种方位有 24 种排列，汉语仅通行两序 → 东南西北序配四时五行相生、为"顺天"正序，东西南北序为泛举、带凄惶意 → 语序差异承载义项差异 → 第 2 步改拆"排列结构"、第 5 步反例排除"两序同义" → 异序异义确诂。

## 4. 六步实操

**① 定场**——场＝语言学与民俗的"同词素异序"对比。三问：谁说？典籍、术士、日常口语。什么场合？讲方位**次序** vs 泛指**到处**。场不定则两序被当成同一词的两种写法——那正是要排除的误读。

**② 拆排列结构**（改造版第 2 步，序构型专属）——四字全同，变的是排列：
- 东南西北：环列，东→南→西→北→（回东）首尾相接，可循环
- 东西南北：对举，东‖西、南‖北两两相对，打断环行
- 产出：确认差异在"序"不在"素"，为第 5 步埋反例线索

**③ 追源流**（改造版第 3 步）——两序各追其源：
- 东南西北：观象授时＋太阳视运动（顺时针右旋）→ 四时 → 五行相生 → 邹衍明堂制度、河图左旋、《楚辞·招魂》
- 东西南北：两两对举的泛举传统；日语习惯此序（跨文化对照）

**④ 查书证**——见第 2 章。作用有二：定首见与典籍出处；**年代差与书证类型本身构成义项**（顺天正序 vs 泛举口语）。

**⑤ 正反验证**（核心）：

| 候选义项 | 正例（存在性） | 反例检验（排他性） | 结论 |
| :--- | :--- | :--- | :--- |
| 两序同义，可互换 | 两序皆指四方 | 若可互换，无法解释招魂、明堂、四声为何严格守东南西北序；亦无法解释东西南北的凄惶色彩 | **排除** |
| 东南西北＝顺次环行序 | 《楚辞》《周礼》《吕氏春秋》《易原》环列用例 | 若只是"到处"，上述典籍严守次序不可解；环行序含四隅之外（不含东南等隅），≠四面八方 | **确诂** |
| 东西南北＝两两对举泛举 | 古籍泛指用例、日语习惯序 | 若表次序，则打断四时相生（东→西跳、南→北跳），与顺天观念冲突 | **确诂** |

最有价值的反例：**24 种排列汉语仅通行两序**——若为任意罗列，不该如此整齐。这个"排列受限"现象本身证明语序受文化规则约束，不是随意的。

**⑥ 防陷阱**——
- **以今度古**：今人看地图"上北下南、左西右东"，觉得东西南北更顺；古人"面南背北、顺天右旋"，东南西北才是正序。
- **跨文化混淆**：日语用东西南北，中文用东南西北；按文本语境定序，不按"普世方位"定。
- **诚实边界**：未见"东南西北"表凄惶流离的固定用例，标"未见反例"。
