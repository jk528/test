## 0. 结论（先行）

> **确诂一句话**：
> **南北半球**＝以赤道为界划分地球的两半（北半球／南半球），是纯地理坐标词；但它携带一组**随半球反转的隐含前提**——太阳方位、季节、五行寒热配属、建筑最佳朝向，全都以半球为转移。
> **坐北朝南**＝房屋/座位背北面南；在**北半球**因太阳常在南侧、冬避西北寒风夏纳东南凉风，成为采光最优朝向，并由《易》"圣人南面而听天下"升格为**尊位**，是"向阳＝尊"的礼制化。
> **坐南朝北**＝背南面北，在北半球是背阴次位（"北面称臣"）；但在**南半球**太阳常居北侧，坐南朝北才是向阳最优——**两词的确诂由所在半球决定，脱离半球则无法定其尊卑**。

| 判定 | 南北半球 | 坐北朝南 | 坐南朝北 |
| :--- | :--- | :--- | :--- |
| 词性 | 地理坐标词（二分） | 建筑/礼制方位俗语 | 建筑/礼制方位俗语（反向） |
| 结构 | 偏正：南/北＋半球 | 动宾并列：坐北＋朝南 | 动宾并列：坐南＋朝北 |
| 核心机制 | 赤道分界＋太阳直射点移动 | 向阳（北半球）→尊 | 背阴（北半球）→卑；向阳（南半球）→尊 |
| 隐含前提 | **半球位置**（决定太阳在何方） | 北半球 | 北半球（若南半球则反转） |
| 必留语义 | 南北是坐标，寒热与方位绑定是条件 | 采光避风＋尊卑双重义 | 尊卑义完全依赖半球 |
| 反义/对举 | 南半球↔北半球 | 坐南朝北 | 坐北朝南 |

**证据链一句话**：地球公转使太阳直射点在南北回归线间移动 → 北半球太阳常在南、南半球太阳常在北 → "坐北朝南"在北半球向阳为尊（《易·说卦》《春秋繁露》《礼记》，考古房屋多朝南）；在南半球须坐南朝北才向阳（澳房产以朝北为卖点）→ 前驻斐济大使记"方向观念完全颠倒""五行冷热方向颠倒" → **同一方位词的确诂由半球这个物理场变量决定** → 第 1 步定场须纳入"地理半球"，确诂分半球陈述。

## 3. 六步实操

### ① 定场——本组决定性步骤（场＝物理半球）

三问在这里必须加一问：谁说的？对谁说？什么场合？——**还有第四问：脚下是哪个半球？**

- 典籍（《易》《春秋繁露》《礼记》）说的"南面为尊"，默认语境是**北半球中纬度**（黄河流域）；
- 澳洲地产说的"朝北为佳"，默认语境是**南半球**；
- 两者不矛盾，是同一条物理规律（向阳为尊）在不同半球的不同投影。

**产出**：这三个词的确诂必须**绑定半球**陈述，否则"坐北朝南为尊"与"坐南朝北为尊"会看似冲突。场从"文化场"扩展到"地理场"——这是本组对方法最大的贡献。

### ② 拆构词

- 南北半球：偏正结构，"南/北"修饰"半球"，二分地理坐标。
- 坐北朝南／坐南朝北：动宾并列，"坐X"表背靠、"朝Y"表面向，两词仅方位词对调，是最小对立对。

**产出**：两坐向词词素全同、只换南北，属"同词素异序/异置"——但差异不在语序而在**取值替换**（南↔北），与前一案例"东西南北"的序构型不同，需单独识别。

### ③ 追源流（无通假可追，改追物理机制＋词义升格）

两源合追：
- **物理源**：地轴倾角 66.5° → 太阳直射点在南北回归线间移动 → 北半球太阳常在南侧、南半球常在北侧 → 向阳朝向相反。
- **文化升格源**：北半球"面南向阳"（实用）→ 阳贵阴贱（《春秋繁露》）→ 南面＝君位（《易》《庄子》）→ 南尊北卑礼制化 → 延伸到建筑、拜师、朝臣。

**产出**：一条"物理规律→实用朝向→礼制尊卑"的升格链，解释为何一个采光选择会变成尊卑符号。

### ④ 查书证

已如第 2 节所列。关键发现：**书证本身带半球标记**——《易》《礼记》出自北半球，澳洲资料出自南半球；书证年代与地域共同构成义项边界。这与"开门七件事"的"年代差即义项"同类，但本组是"**地域差即义项**"。

### ⑤ 正反验证（核心）

| 检验 | 内容 | 结论 |
| :--- | :--- | :--- |
| 正例 | 北半球典籍+考古证南向为尊；南半球地产+教材证北向为佳 | 两半球各自确诂成立 |
| 反例一（一票否决） | "坐北朝南为普世最尊" → 澳洲朝北才是卖点，南半球南向背阴 | 排除普世化，尊卑必须绑半球 |
| 反例二 | "坐向只有采光义、无尊卑义" → 《易》《春秋繁露》《礼记》明文南面＝君位 | 排除纯实用义，必留礼制义 |
| 反例三 | "南北半球只是坐标、不携带其他义" → 五行寒热、季节、朝向全随半球反转 | 排除纯坐标义，必留条件绑定 |
| 反例四（划边界） | 北半球也有坐南朝北（永祚寺）——反常个例不推翻常则，反而反证南向为正 | 个例归入"特殊原因"，不改主流确诂 |

**最有价值的一条反例**：反例一。它一票否决了"南面为尊是放之四海皆准的文化真理"这一直觉——那其实只是**北半球太阳几何的礼制投影**。漏掉这层，"坐北朝南"就被讲成了无条件的普世尊位，这是以偏概全。

### ⑥ 防陷阱

- **以今律古**：今人默认"上北下南"看地图，但古代海图多"上南下北"（《郑和航海图》以指南定位），南北尊卑不可按现代地图直觉定。
- **文化普世化陷阱**（本组新增）：把北半球的"南尊北卑"当成人类通用观念——南半球恰好相反。这是"以我一域度天下"的空间版以今律古。
- **个例误推翻**：永祚寺坐南朝北是特殊选址，不足以推翻北半球南向为正的常则；未见其代表普遍尊卑倒转的用例，标"未见反例"。

## 4. 反转关系总表（本组核心）

同一个"向阳为尊"原理，在两个半球给出相反答案：

| 维度 | 北半球（中国） | 南半球（澳洲） | 是否反转 |
| :--- | :--- | :--- | :--- |
| 太阳常年方位 | 南 | 北 | ✅ 反转 |
| 最佳朝向 | 坐北朝南 | 坐南朝北 | ✅ 反转 |
| 尊位 | 南面（君位） | 北面（向阳） | ✅ 反转（若按向阳逻辑） |
| 卑位 | 北面（臣位） | 南面（背阴） | ✅ 反转 |
| 五行寒热 | 南火（暖）北水（寒） | 南寒北暖（大使亲历） | ✅ 反转 |
| 季节 | 南风暖、北风寒 | 南风带南极寒流 | ✅ 反转 |
| 恒定项 | 向阳为尊、背阴为卑 | 向阳为尊、背阴为卑 | ❌ 不变 |

**一句话**：变的是"哪个方位向阳"，不变的是"向阳为尊"——**方位取值随半球反转，尊卑原理恒定**。这正是元规则"配置随词变、元规则不变"的地理版。

### 5.1 管用之处
1. **第 1 步定场再次证明是总开关**——这次的"场"是物理半球，不定场则两半球确诂直接打架。
2. **反例一票否决威力显著**——"普世南尊"的直觉被澳洲反例当场推翻。

### 5.2 暴露的新边界
1. **"场"的外延需扩展**：方法文档 9.9/10.1 的"场"指语言/文化场（典籍/新闻/麻将），本组出现**物理环境场**（半球）。建议在"场"的分类下补注：场含"文化场"与"物理场"两类，后者如地理半球、气候带，会改变词的取值而非仅改变用法。

## 6. 结论回扣

回到开篇确诂：

> **南北半球**＝赤道二分地理坐标，携带一组随半球反转的隐含前提；**坐北朝南**在北半球向阳为尊（《易》"南面而听天下"），**坐南朝北**在南半球向阳为尊（澳洲以朝北为卖点）。**尊卑由半球定，向阳原理恒定。**

首尾不是循环：第 0 节先给答案，第 1—5 节用可复现的六步与书证证明"非它不可"，第 4 节反转总表把两半球答案统一到同一条原理下。

**本组对方法的净贡献**：把"场"从文化场扩展到**物理场**，并识别出"隐含前提"这一新线索类型——词的确诂不仅取决于语境，还取决于它默认站在哪个地球坐标上。
