## 0. 结论（先行）

> **确诂一句话**："唯器与名，不可以假人"＝**只有礼制器物与爵位名号，不能借给（授予）不当得的人**——"器"指车服旌旗钟磬之属（本事中即**曲县、繁缨**），"名"指与器配套的**爵号名位**，"假"训**借与**（非今义"虚假"，亦非官制的"暂摄"），"人"指**非其分者**（本事中即以大夫之身请用诸侯之服的新筑人仲叔于奚）。禁令的根据不是名器值钱，而是"**君之所司**"——归属权；故让渡符号即让渡政权，下文自注："若以假人，与人政也。政亡，则国家从之。"

| 项目 | 判定 |
| :--- | :--- |
| 句子性质 | 禁令式论断句（"唯……不可以……"）＋因果链自注（六环推演） |
| 关键训诂 | 器＝礼制器物；名＝爵号名位；假＝借与；人＝非其分者（非"民"）；司＝职掌 |
| 文内自注 | 以"**与**"释"假"（"若以假人，与人政也"）；以"**名—器**"互训（"名以出信，信以守器"） |
| 结构机制 | 禁令（本句）→ 权属理由（君之所司）→ 六环机制链（名→信→器→礼→义→利→民）→ 反证（与人政）→ 后果（政亡国从，弗可止） |

**证据链一句话**：原文本事（辞邑而请曲县、繁缨，许之）＋文内自注（"与人政也"以"与"释"假"）＋同书平行句《左传·庄公十八年》"名位不同，礼亦异数，**不以礼假人**"＋《周礼·春官·小胥》乐县四级制（王四面／诸侯三面／卿大夫两面／士一面）实物锚定＋《资治通鉴》卷一臣光曰经典化引作"惟器与名" → 反例一票否决"虚假说""人偶说""兵器说""民说""摄官说" → 确诂成立。

## 3. 六步解析实操（古语句子版·禁令型）

### ① 读语境（定场＋语篇功能定位）

- 三问：**谁说**——孔子，事后评论（"仲尼闻之曰"，非当廷谏诤，是对既成事实的追评）；**对谁**——门人及后世读史者（评论被记入史，说话对象已泛化）；**什么场合**——史评，评论一次具体的名器让渡。
- **本事复原**：卫齐新筑之战，卫师败，新筑人仲叔于奚救孙桓子得免。卫人赏他城邑，他辞邑不要，改请"曲县、繁缨以朝"——即请求在朝见场合使用诸侯级别的乐悬与马饰，卫君答应了。孔子所惜者，正在"许之"二字。
- **语篇功能问（第四问）**：本句在整段里干什么？——整段是完整论证，五段式：
  ```
  ① 总评：惜也
  ② 比较：不如多与之邑        ← 定"可与／不可与"的分界
  ③ 立禁：唯器与名，不可以假人，君之所司也   ← 本句
  ④ 推演：名以出信……政之大节也
  ⑤ 反证＋后果：若以假人，与人政也。政亡，则国家从之
  ```
  本句是**禁令与根据的合体**（"不可以假人"＋"君之所司也"），既下判断又给依据，是全段的枢纽：前有比较（邑可与、名器不可与），后有推演（为何不可与）。
- **产出**：确诂必须同时满足三条——(a) 能解释"为什么赏邑可以、赏名器不可以"；(b) 能接上六环链（名→信→器→礼→义→利→民）；(c) 能支撑"假名器＝与政"的等价判断。凡不能同时过三关的义项，一律出局。

### ② 拆关键词群（句子版：逐训点扫描＋结构分析）

句子无中心词，改跑**关键训点扫描**——四个训点各走一遍单词流程：

| 训点 | 本义 → 句中义 | 依据 |
| :--- | :--- | :--- |
| 唯 | 只有、唯独（限定副词，提前强调唯一性） | 与"唯……是……"同族的排他句式；此处非"虽然"（"唯"作"虽"多见于"唯毋""唯然"，句位不合） |
| 器 | 皿（器具）→ **礼制器物**：车服、旌旗、乐悬、马饰之属 | 《说文》"皿也"是起点；本句自注"器以藏礼"直接定其礼制属性；本事实指曲县（乐悬）、繁缨（马饰） |
| 名 | 自道其名（夜间以口自名，起于辨识）→ 名号 → **爵号名位** | 《说文》字形义；《左传·庄公十八年》"名位不同"同书互证；与"器"配套（有诸侯之器则有诸侯之名） |
| 假 | 非真 → **借与、给与** | 《说文》"非真也"为本义，"借"为引申；**文内自注**最硬：下文"若以假人，与人政也"以"与"释"假" |
| 人 | 人（与"己""我"相对的他者）→ **非其分者**（不当得之人） | 同段"人"三见（"假人""假人"）而"民"一见（"利以平民"），分用不混——"人"非"民"；本事中"人"实指仲叔于奚 |

**结构分析（句子型）**：

1. **句式＝禁令**。"唯 X，不可以 Y"是把 X 单独提出、加限定词、再下绝对禁止的格式——不是陈述"X 很难得"，而是宣告"X 属禁区"。禁令句的释义必须回答两件事：禁的是哪个动作（假），禁到什么程度（不可以＝绝对禁止，非"不宜"）。
2. **"器与名"＝一体两面，非两件并列物**。证据在下一句："名以出信，信以守器"——名与器互为表里（名是器的称号，器是名的形体）。故"与"是**配套连词**（器与名这一套），不是**选择连词**（器或名）。这决定释义不能把二者拆成"物质利益＋精神荣誉"两笔账——古人算的是一笔账：符号系统。
3. **列举次序与推演次序相反**：禁令说"器与名"（先器，从眼前所争之物说起，由显入隐）；推演说"名→信→器"（先名，从生成之序说起，由本及末）。一倒一顺不是笔误，是两种叙述逻辑：**列举就事论事，推演就理说理**。
4. **理由句"君之所司也"是禁令的承重墙**。"司"训职掌（《说文》"司，臣司事于外者"）。这一句把"不可假"的依据落在**归属**上：因为名器是君主职掌之物，所以无权转借——不是"舍不得"，是"不归你给"。**据此可知本句不是道德劝谕，是权限声明。**

- **产出**：四训点各自收敛＋三处结构判定成立，全句骨架即出：**一套由君主职掌的符号系统（器＋名），其授予权不得让渡给不当得者。**

### ③ 追声音（通假、异文与防讹）

- **繁缨＝樊缨＝鞶缨**：本字当作"樊"（马大带），《周礼·春官·巾车》"锡樊缨十有再就"，郑玄注"樊读如鞶带之鞶，谓今马大带也"；《左传》作"繁"，为通行写法。"繁"在此**非"繁多"义**——望文生义作"繁多的缨络"即错。此为本篇最实的一条音义线索（郑注待核，理据可靠）。
- **曲县＝曲悬**："县"为"悬"的古字（《说文》"縣，系也"，古悬挂字多作"县"），"乐县"即"乐悬"。若按今义读"县"为行政区划，全句立刻不通——这是纯字形陷阱。
- **唯／惟**：《资治通鉴》引作"惟器与名"，"唯""惟"古通用，不构成异解，仅记异文。
- **假**无通假问题，但有两义竞争：借与（本句）／暂摄（官制"假相""假王"）。此非通假而是**同字多义**，入第 ⑤ 步反例处置，本步只标出。
- **防讹一条**：网络流传常将本句写作"唯器与名，不可以假于人"，增"于"字。增字后"假于人"仍通（借给别人），但原句"假人"是"假（之）人"的省略双宾结构，增字属改写而非异文，引用时应依原文。

- **产出**：无影响义项的通假；实得异文两组（繁／樊、唯／惟）与字形陷阱一组（县≠行政区），入第 ⑥ 步。

### ④ 查书证（实物等级锚定——本例核心动作）

- **动作升级**：前两例的第 4 步分别做"数字制度锚定"（五世＝丧服分界）与"文内枚举自注"（六世＝六君列名）。本例做第三种——**实物等级锚定**：句中的"器"是可指称的具体物件，其等级值由礼制文本直接给出，不必推测。
- **锚点一：乐悬四级制**。《周礼·春官·小胥》："正乐县之位：王宫县，诸侯轩县，卿大夫判县，士特县。"依郑注体系：宫县四面、轩县三面（去一面）、判县两面、特县一面（细节待核）。**"曲县"即轩县＝诸侯之制（三面）**。仲叔于奚以大夫之身请三面之悬，正是**越两级取用**（大夫本应判县两面）。
- **锚点二：繁缨**。马大带之饰，杜预注"皆诸侯之服"（待核）——与曲县同级配套。两件器物同指一个等级：**诸侯**。

## 6. 方法自检

**管用的地方：**

1. **文内自注成为第 4 步的硬内证**——"若以假人，与人政也"用"与"释"假"，一句话把"虚假说""摄官说"同时判死。这提示：句子型对象应优先搜"同段释义句"（作者自己换词重说的地方），其权重高于任何后世注疏。
2. **同段人称分用可作排他判据**——"人"三见、"民"一见，是纯语言内证，比"人本指他者"的词典义更有杀伤力。此法可推广：**同一段内的近义字若分用不混，即构成作者的分档意图**。
3. **禁令句的"两问释义法"**——禁什么（假）＋凭什么禁（君之所司）。第二问常被忽略，而它恰恰是本句的承重墙：不讲归属，禁令就退化为道德说教。

**暴露的边界（本次新发现）：**

1. **禁令句不是"陈述句加否定"**。其义项结构中必有一项是"根据"（权限、归属、后果），漏掉这一项，释义就只剩训诫。第 2 步拆训点之外，应固定增问"禁令的根据句在哪"。
2. **实物等级锚定是第四种数字／量值锚定**。前三例分别用了丧服世数、文内枚举、定义句＋基准链；本例的"器"自带礼制等级值（面数、饰等），须查礼书制度表而非词书。**凡句中含具体器物名，第 4 步应先问"此物在礼制中属几等"**。
3. **"同字多义"与"通假"须分开处置**——"假"的借与／暂摄是同一字的两义（历史同源、并行使用），不是通假；若误判为通假，会去找音近字，反而绕远。第 3 步应设一条分流：**音同义通者查通假，音同义异者查多义**。
4. **经典化引用层会反向污染释义**——司马光的读法极权威，但他是"用"这句（借以论礼分），不是"训"这句。把引用者的引申当原义，是 C 场景"回灌"陷阱在 A 场景的变体（引者回灌），须单列。
