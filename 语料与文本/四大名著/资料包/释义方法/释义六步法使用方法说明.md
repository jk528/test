# 释义六步法使用方法说明

> 用途：把《新名词释义解析方法》从"是什么"讲成"怎么用"——拿到一个看不懂的词，照着做就能得出确诂并写成规范文档。
> 定位：操作手册。理论依据见 `新名词释义解析方法：从见字不知义到确诂.md`，写成样板见 `释义模板测试版：电子布洛芬（结论先行）.md`。

---

## 0. 一句话用法（结论先行）

> **前四步挖出所有候选义项，后两步收敛到唯一确诂；反例优先于正例，成文时结论先行于论证。**

整套方法只干一件事：把"猜词"变成"证词"——从"讲得通"推进到"非它不可"。

**操作总览：**

```
拿到看不懂的词
   ↓
[判断场景] 古语词 / 新闻新词 → 决定第2、3步怎么做
   ↓
[前四步·挖候选] ①读语境 → ②拆形构 → ③追音源 → ④查书证
   ↓
[后两步·收敛]   ⑤正反验证（正例立可通+反例定必然）→ ⑥防陷阱定稿
   ↓
[成文] 结论先行：第0节先亮确诂 → 展开论证 → 末尾回扣
```

## 1. 第零步：判断场景（30 秒）

拿到词先问：这是**古语词**还是**新闻新词**？答案决定第 2、3 步的动作：

| 步骤 | 古语词版 | 新闻新词版 |
| :--- | :--- | :--- |
| 第 2 步 | 拆**字形**——看偏旁本义 | 拆**构词法**——找中心词、定偏正/动宾 |
| 第 3 步 | 追**声音**——查通假谐音 | 追**词源**——外来语？旧词新用？词族？ |

其余四步两版通用。三条原则：

- **六步是工具箱不是流水线**——场景只决定哪步当主力、证据信谁、防哪个坑，方法本身不变。
- **一词可跨场景**——"泔水"既是日常词又被新闻借用，按当前文本语境定场景，不按词的出身定。
- **拿不准就两边都跑**——先用古语词版探本义，再用新闻词版定现义，取语境契合的那个。

## 2. 六步怎么用

### ① 读语境（定场）

- 不猜。把整句、整段读完，圈出这个词和哪些词搭配。
- 问三句：**谁说的？对谁说？什么场合？**
- 语境决定义项的选择范围。同一个词形在不同场合含义全变，脱离语境无法释义。
- 新闻词版多问一句：**喻体的哪个属性被带入了？**（如"电子布洛芬"带入"止痛＋治标不治本"，"治标不治本"是词义组成，不可漏。）

**产出**：义项的大致范围与褒贬色彩。

### ② 拆字形 / 拆构词

- **古语词**：形声字形旁点出意义类属（"福""禄"从"示"，与祭祀相关）。注意——形旁表类属不表具体义，不可过度推断。
- **新闻词**：偏正结构找中心词（"电子布洛芬"中心＝布洛芬，修饰语＝电子）。中心词的比喻是全词钥匙，比字面猜词高效得多。

**产出**：本义方向 / 比喻核心。

### ③ 追声音 / 追词源

- **古语词**：查同音通假与谐音。例："考"通"老"（考妣＝已故父母）；"蝠"谐音"福"。古今音不同，须借工具书确认，不能凭今音硬配。
- **新闻词**：判断有无外语借入、是否旧词新用、属于哪个能产词族（"电子 X""XX 化"），定位家族归属。

**产出**：通假关系 / 词族定位。

### ④ 查书证（列候选义项）

- 分两层用工具书：**探本义**——《说文解字》《尔雅》《释名》；**查流变**——《汉语大词典》《汉语大字典》、汉典网、"中国哲学书电子化计划"。
- **关键动作**：看每个义项的**第一个书证出自哪本书、哪一年**——这决定该义项是古义还是后起义。
- **只列不选**：把所有候选义项摊开，暂不判定。
- 新闻词无权威词典收录时，以**三源以上共识**坐实义项，并标注"无权威收录，依多源共识"。

**产出**：候选义项清单（含首见年代）。

### ⑤ 正反验证（核心环节）

把候选义项摊进决策表逐项过：

| 候选义项 | 正例支持（存在性） | 反例检验（排他性） | 语境契合 | 书证年代 | 结论 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| \[义项A] | \[几个同时代用例] | \[有无讲不通处] | \[契合/不契合] | \[首见何时] | \[确诂/排除/待考] |

- **正例**证明存在性——这个义项真有人这么用，不是臆造。
- **反例**证明排他性——其他竞争性义项在这里讲不通。
- **反例一票否决，优先于正例**：一万个正例证明不了第 10001 个不推翻它，一个反例就足以掀翻解释。
- **证据权重**：同时代同体裁直接语境 > 同时代异体裁 > 异代后世转述。三个同时代用例顶十个后世注疏。
- **判定规则**：反例不通过者直接排除；剩余者取语境契合最高、书证年代匹配者确诂；证据不足者标"待考"附异说。

**产出**：唯一确诂（或"待考"）。

### ⑥ 防陷阱（定稿）

- **以今律古**：拿现代常用义套古文。如以"考试"解《洪范》的"考"——"考试"是后起义，成书时无此义。
- **词义漂移**：扩大、缩小、转移。同一词跨朝代含义会变，必须绑定时代谈义。
- **诚实边界**：找不到反例只能写"**未见反例**"，不能写"没有反例"——为未来反例保留推翻权。

**产出**：定稿确诂。

## 3. 成文格式：结论先行

文档结构按下列顺序，读者 10 秒拿到答案：

| 节 | 内容 | 作用 |
| :--- | :--- | :--- |
| 第 0 节 | **确诂一句话** + 判定表 + 证据链 | 先给答案 |
| 第 1 节 | 纲领对齐（口诀、总纲图） | 亮方法论 |
| 中间节 | 书证采集 → 六步实操 → 义项竞争决策表 → 对照案例 | 展开论证 |
| 末节 | 结论回扣 | 首尾呼应，不是循环论证 |

**判定表建议字段**：词性 / 构词 / 比喻机制 / 情感极性 / 词族归属 / 必留语义。

## 4. 三句口诀（随身带）

> **字形定本源，声音定通假，语境定实义，书证定时代。**
> **正例立其可通，反例定其必然。**
> **未见反例只是暂定，遇一反例全局重审。**

## 5. 速查表

| 你遇到的情况 | 怎么办 |
| :--- | :--- |
| 古文里一个词讲不通 | 先怀疑通假与古今义错位，走古语词版 |
| 新闻里冒出新词 | 走新闻词版，重点拆构词＋追词源＋划词族边界 |
| 几个义项都讲得通 | 上决策表，找反例逐个打掉，反例优先 |
| 是比喻型新词 | 定场时追问"喻体哪个属性被带入了"，完整带入 |
| 没有权威词典收录 | 三源以上共识坐实，标注"依多源共识" |
| 找不到反例 | 写"未见反例"，不要写"没有反例" |
| 争议未决 | 标"待考"，附异说，不臆断 |

## 6. 三步上手清单

1. **拿到词** → 判断场景（古语词 / 新闻新词），定第 2、3 步做法。
2. **跑六步** → 前四步列候选，后两步收敛，填决策表得出确诂。
3. **写文档** → 第 0 节先亮确诂，中间展开论证，末节回扣。
