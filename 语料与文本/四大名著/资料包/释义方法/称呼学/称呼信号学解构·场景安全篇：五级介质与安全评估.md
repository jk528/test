# 称呼信号学解构·场景安全篇：五级介质与安全评估

> 文档性质：称呼信号学解构**第三篇**——双篇管点对点协议（你我），三方篇管网络拓扑（你我他），本篇管**介质的安全分级**（这话能在哪说）。用户命题："场景（介质）延伸，本质是**安全评估**"——本篇论证：场合不是地点清单，而是一套分级保密系统；每次开口前，人脑都在运行一个安全评估函数。
> 生成日期：2026-11-25　|　五级设定（用户点名）：**国礼 → 公共场合 → 私密场合 → 安全屋 → 潜意识**｜理论工具：保密分级体制＋威胁模型
> 计数：评估四问 **4**＋五级信道 **5**＋失密事故 **4**＋降级规则 **5**＋经典映射 **6**＝**24** 个枚举单位，守恒见第 7 节。

## 0. 结论（先行）

> **一句话**：场合即密级——**每个说话场所都是一台带安全等级的信道**，从国礼（最高仪式化公开：全控制、全记录、零真情）经公共（半匿名噪声场：墙有耳）、私密（凭证准入：关系本位）、安全屋（合约保密：枚举尽在场者）到潜意识（终极自管仓：连自己都要经过译码才能取件）。称呼的全部规律在此坐标系上重写一遍：**公开度越高，帧越模板化**（国礼的"总统阁下"是格式化信封）；**密级越深，帧越裸**（安全屋里的小名是明文）。安全评估是每次发帧的前置函数：**这句话的密级，配不配这个信道的等级**——错配即事故（酒后失言＝L4 内容发进 L2 信道）。悖论一枚：最公开的信道反而最安全（国礼之言滴水不漏），最私己的信道反而最危险（潜意识会从口误里自己越狱）——**信道的物理距离与安全等级无关**。

**总判定表**：

| 项目 | 判定 |
| :--- | :--- |
| 介质安全五级 | L1 国礼（仪式公开）→ L2 公共（噪声场）→ L3 私密（凭证准入）→ L4 安全屋（合约保密）→ L5 潜意识（终极自管） |
| 安全评估函数 | 发帧前四问：在场盘点→密级评估→后果评估→撤回评估（§1） |
| 通道与密级的正反律 | 公开度↑＝帧模板化↑＝信息量↓（国礼的"废话"是安全设计）；密级↑＝帧裸露度↑（安全屋说什么都是明文） |
| 最大威胁分布 | L1 威胁在全球直播；L2 威胁在墙有耳（潜在窃听）；L3 威胁在自己人外传；L4 威胁在时效（密友会过期）；L5 威胁在自己（口误越狱） |
| 与双篇/三方篇的关系 | 双篇的三信道（声波/书面/中继）是**物理分类**，本篇是**密级分类**——同一物理信道可处于不同密级（同一句话在客厅＝L3、被录音后＝L2） |
| 与称呼系统的接口 | 三方篇路由表＋本篇密级＝**路由表上再加一栏"这入口在当前信道开放吗"**：小名在 L3/L4 开放，L1/L2 强制切官方称谓 |
| 最大陷阱 | ①以为场合只是背景（漏看场合即密级）；②把"私密"当"安全"（私密≠保密，客厅会漏，卧室会被录音）；③高估安全屋时效（今天的枕边人≠明天的保密人） |

**证据链一句话**：《管子·君臣下》"墙有耳，伏寇在侧……墙有耳者，微谋外泄之谓也"立信道泄露祖训 →《左传》外交赋诗言志＋"外交辞令"传统立 L1 模板化协议 →《礼记》朝仪班位、"入境问禁"立 L1 程序法 → 忏悔室封印（seal of confession）立 L4 制度化保密 → 弗洛伊德《日常生活精神病理学》口误论立 L5 越狱机制 →"酒后吐真言""隔墙有耳""家丑不可外扬"三谚构成民间安全守则群 → 模型成。

## 1. 安全评估函数（发帧前四问——用户命题的形式化）

"本质是安全评估"——把这句话写成函数。每个社会人开口前（无论自觉与否）执行四问：

| 序 | 问 | 评什么 | 事故源 |
| :---: | :--- | :--- | :--- |
| ① | **在场盘点** | 信道成员显式枚举：谁在听？谁可能在听（墙外、门外、录音端）？ | 漏盘点潜伏收件人（孩子在装睡、手机在录、邻桌在听） |
| ② | **密级评估** | 这帧泄露了我什么：状态（我的真实情绪）／关系（我们的真实版本）／意图（我接下来要做什么）？ | 高估帧的无害性（"就随口一说"——帧密级由接收方定义不由发送方） |
| ③ | **后果评估** | 若此帧经此信道泄露至最大范围，损害可承受吗？ | 用最好情形代替最坏情形做安全决策 |
| ④ | **撤回评估** | 帧的不可逆度：声波（当场不可撤回但会衰减）＜文字（永久）＜档案（存证）。信道有录音设备吗？ | 把声波当文字的场合误判（"说完就过去了"——过去了但被存了） |

**四问的耗时特征**：熟练者 300 毫秒完成（社交直觉即安全直觉的自动化）；不熟练者在 L1/L2 帧上卡顿（书呆子在国宴说真话）；而**跳过四问直接发帧的冲动**（心直口快），是儿童与醉酒者的共同状态——所谓"童言无忌"，实为**安全评估模块未安装（儿童）或被强制下线（醉酒）**。

## 2. 五级信道全谱（本篇主表）

### L1｜国礼级（最高仪式公开：全控制信道）

| 属性 | 判定 |
| :--- | :--- |
| 场所 | 国宴、朝仪、签约仪式、觐见、公开照会、国事访问 |
| 威胁模型 | 全球直播：任何失帧即国际事件；但威胁**已知且冻结**（收件人、镜头、协议全程预定） |
| 帧规范 | **最高模板化**：称谓全格式化（"主席阁下""尊敬的大使"）、语句全程序化（欢迎辞、答谢辞）、**信息量最小化——废话是安全设计**：外交辞令"双方进行了坦率交谈"＝谈崩了、"充分交换了意见"＝吵翻了——L1 的话语把信息压缩到只剩善意框架 |
| 称呼特征 | 职衔全称＋敬格顶配；**路由表锁死**：任何私人入口（小名、昵称）在 L1 强制关闭——"私下是老友，国宴是阁下" |
| 安全悖论 | 最公开＝最安全：因为**全程无明文**——零真实信息可泄露 |
| 古典版 | 《左传》外交"赋诗言志"：不直说立场，借《诗》篇代理（**代理服务器**：他国使节以引诗代立场，解读权留给对方——L1 的先秦实现）；《礼记》朝仪班位（"天子南面"的物理协议）——《仪礼》整本就是 L1 信道的操作手册 |

### L2｜公共级（半匿名噪声场：不可控信道）

| 属性 | 判定 |
| :--- | :--- |
| 场所 | 电梯、办公室、饭局、车厢、微信群、微博、街市 |
| 威胁模型 | **墙有耳**：《管子·君臣下》"古者有二言：'墙有耳，伏寇在侧。'墙有耳者，微谋外泄之谓也"【A 核实】——潜在窃听者不可枚举（邻桌、装睡的孩子、录音的手机）；威胁未知且不冻结 |
| 帧规范 | 称呼自动升半档（前台化——双篇已立）；亲密路由关闭；**内容降级规则**："会议室可拍桌，走廊只说天气"——越公开，帧含金量越低 |
| 称呼特征 | 通货区（场景篇八大场景全在 L2）：X总、老师、美女——**通货即 L2 的安全称谓**（不暴露关系版本，因为无版本可言） |
| 现代变体 | 群聊：伪装成私交的 L2 信道（"以为在客厅说话，其实在广场"）——**线上场景的默认密级是 L2**，一切的"私密群"都是可转发的 L2 |
| 民间守则 | "病从口入，祸从口出""隔墙有耳""路上说话，草里有人"——L2 安全教育三谚 |

### L3｜私密级（凭证准入：关系本位信道）

| 属性 | 判定 |
| :--- | :--- |
| 场所 | 家中客厅、密友饭局、二人散步 |
| 威胁模型 | **威胁收窄为"自己人外传"**：信道成员可信（凭证＝多年关系），但**记忆是全息的**——你说的每句都在为未来的泄露存档 |
| 帧规范 | 亲密路由开放（小名、外号、方言称呼解禁）；内容可降密（可抱怨、可议人——但议第三方时帧密级仍随转述链回弹，见三方篇乱序到达） |
| 称呼特征 | 昵称主场（"老王""哎"）；**屋内还有梯度**：客厅（孩子可听的 L3.5）与卧室（夫妻 L4 前厅）——家的安全等级是分间的 |
| 典型事故 | **家丑外扬**＝L3/L4 帧进入 L2 信道的家族事故——"家丑不可外扬"不是遮丑，是**家族信道的密级管理条例** |
| 边界 | 私密≠保密：客厅的墙隔不走录音笔——**L3 的安全感常是错觉**（威胁模型估计过时——录音时代，客厅的默等于广场的默） |

### L4｜安全屋级（合约保密：枚举尽在场者）

| 属性 | 判定 |
| :--- | :--- |
| 场所 | 忏悔室、心理咨询室、深夜卧谈、临终床前、结拜、告解 |
| 威胁模型 | **合约式可控**：信道成员显式枚举（"这话天知地知你知我知"——枚举协议），并附保密承诺（忏悔室封印：神父泄密即逐出教门——L4 的制度化版本；心理咨询保密协议：法律化的 L4） |
| 帧规范 | 全明文许可——**安全屋的存在意义就是允许说 L5 内容**：忏悔（把潜意识罪感转为语言帧）、倾诉（把情绪梯度全档释放）、托付（临终遗言＝人生最后一组 L4 帧） |
| 称呼特征 | 最裸帧：乳名、直名、甚至"你"（敬语全卸）；**称呼的卸装仪式即安全屋的门禁**——"叫我名字就好"（一句话把信道从 L2 拉到 L4） |
| 建屋仪式 | 关门、递烟、碰杯、对暗号（"咱俩谁跟谁"）——**物理动作在做信道握手**：确认合约生效才开始明文传输 |
| 最大威胁 | **时效**：L4 的安全依赖在场者承诺，而承诺会过期——密友变路人、夫妻变对手后，当年安全屋的帧全部转密级为"可公开罪证"（婚变后的枕边话大战）。**安全屋没有永恒的，只有尚未到期的** |
| 认证失效 | 醉后真言＝**入口控制被酒精破解**（"酒后吐真言"的机制学表述：L4/L5 帧绕过评估函数直接上 L2/声波信道） |

### L5｜潜意识级（终极自管仓：连自己都要译码取件）

| 属性 | 判定 |
| :--- | :--- |
| 场所 | 梦、自我对话、无意识冲动——**唯一的单用户信道**（理论上只有自己能收） |
| 威胁模型 | **内部威胁**：压抑机制的可靠性——潜意识是最大安全屋（不可告人的欲望、创伤、真实评价全部存在此仓），但有三条越狱通道：**梦**（弗洛伊德"通往潜意识的皇家大道"：L5 内容以伪装帧上浮意识层——审查官打瞌睡时的合规外泄）；**口误**（"日常生活精神病理学"：最高密级帧的意外上链——嘴快过脑，明文脱口）；**身体泄露**（微表情、语气——情绪篇已证"声调先于语义被解码"：L5 的加密在调制层就有破口） |
| 帧规范 | 不归评估函数管（你自己都不知道你存了什么）——**L5 的安全评估由防御机制代行**（压抑、否认、投射＝一整套自动加密网关） |
| 称呼特征（本篇奇观） | **自我对话中的自我称呼分裂**："你怎么这么笨！"——用第二人称骂自己：自我分裂成两台状态机（发送机的我与接收机的我），**人对自己说话也要选称呼**（"我要振作"〔动员帧〕vs"你能行的"〔安慰帧——发送方伪装成外部支持者〕）——双篇模型的终点彩蛋：即使只剩一个人，通信结构仍在（自言自语＝内部双机对话的外化） |
| 受权接入 | 心理咨询师、精神分析师＝**持证访问 L5 的第三方**（保密协议的 L4 信道＋专业译码权）——咨询室是 L4 壳、L5 通道的复合建筑 |

## 3. 失密事故类型学（四型——密级错配的全谱）

| # | 事故型 | 机制 | 实例 |
| :---: | :--- | :--- | :--- |
| 1 | **密级误判** | L4/L5 内容发进 L2 信道（评估函数的②③环节失准） | 酒后失言、情绪失控时的真话（情绪篇：盛怒时评估函数被劫持——"怒失智"的通信学） |
| 2 | **信道误判** | 以为是 L3 实为 L2（在场盘点环节失准——①出了错） | 床边深谈被装睡的孩子全收；饭局"包间"隔墙就是熟人 |
| 3 | **通道误投** | 帧发错信道——技术性错配（四问全过，发送端口错了） | **发错群**——数字时代最高频事故：对甲的吐槽发进有乙的群（L1/L2 信道瞬间广播 L4 帧）——撤回功能是数字信道唯一的悔棋，但**撤回提示本身也是 帧**（"你撤回了一条消息"＝广播"我发了不该发的"） |
| 4 | **时效失密** | 帧在当时信道合法，**信道的密级随时间崩塌** | 日记被子女读到；录音在十年后流出；聊天记录成为呈堂证供——**L4 帧的有效期＝信道成员关系的有效期**：写下来的一切都在等一个未来的 L1 |

> 四型的责任分布不同：①是判断事故（脑子）、②是侦测事故（眼睛）、③是操作事故（手）、④是**时间事故（无人可责，只能怪当初不该存明文）**——四型递进恰好对应**评估四问**的单点失效：每一问失守，诞生一种事故型。

## 4. 信道动态降级规则（密级不是常数）

| # | 规则 | 机制 |
| :---: | :--- | :--- |
| 1 | **生人入场** | L3 聚会来了新客人→信道瞬时降为 L2（话题自动切天气）——密级随在场集合实时重估 |
| 2 | **手机上桌** | 现代硬件规则：智能设备在桌面，任何信道默认降一档（潜在的录音端）——"把手机拿开"＝**信道升密仪式** |
| 3 | **录音存证** | 录音笔＝信道外挂存储，不可撤回性拉满；L4 谈判被录音→帧转永久档案（时效失密的主动制造） |
| 4 | **酒精破解** | 乙醇＝入口控制破解剂：L5 越狱＋评估函数下线——酒局的规则性失密**尽人皆知**，故谈判不赴宴（"宴无好宴"的通信学） |
| 5 | **升密仪式** | 反向操作也存在：关门（物理屏障）、屏退左右（成员裁剪）、换到书房（空间切换）、递烟倒酒（关系握手）——**升密靠仪式，降密靠事件**：升密要双方配合，降密瞬间完成 |
