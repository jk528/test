## 0. 结论（先行）

> **一句话**：称呼是**关系状态同步协议的握手包**——每一次称呼，都是说话人向对方发送的一帧"关系状态声明"：A 编码发出（"X 老师"＝我声明我们是敬距关系）→ 经信道（声波／文字／第三方转述）→ 进入 B 的黑盒（解码器＋私有状态机）→ B 按自身历史与当下情绪完成状态转移（受用／无感／被冒犯）→ B 回发反馈帧（回称／微笑／沉默／纠正）→ A 的黑盒接收解码、更新 A 的关系状态——**一条完整的通信回路**。关系本身，就是两台状态机在此回路中试图维持的"会话状态"；社会，就是靠亿万次称呼交换来保持**最终一致性**的分布式系统。"名不正则言不顺"是这一模型的两千五百年前的精确表述：**握手帧失败，则整条会话报废**。

**总判定表**：

| 项目 | 判定 |
| :--- | :--- |
| 通信模型 | 五段回路：信号源（编码器）→介质Ⅰ→接收方（黑盒）→介质Ⅱ→被接收方（原信号源作信宿闭环） |
| 称呼的信号学定义 | **会话建立包（握手帧）**：定义本次会话的全部参数——亲密等级、极性档位、通道正式度 |
| 编码内容 | 不只是"指称对象"，而是**说话人对双边关系状态的瞬时声明**（我叫你什么＝我认为我们是什么） |
| 接收方黑盒 | 解码器（公共语言协议）＋状态寄存器（关系历史／当前情绪／身份认知／期待值）＋转移函数（私有） |
| 反馈语义 | 回称＝ACK（确认）；纠正＝NACK（拒绝并请求重传）；白眼＝校验失败；沉默＝丢包 |
| 关系的本质 | 两台状态机经协议交互维持的**共识状态**——非强一致（每次称呼都可能被拒），而是最终一致 |
| 称呼系统全部已知规律 | 均可重写为协议现象：语用腐蚀律＝字段通胀；通货更替＝协议版本迭代；避讳＝禁用信号位；改口＝重传机制 |
| 最大陷阱 | ①把称呼当单向的信息传递（漏看反馈回路与前向声明性）；②把黑盒当透明（漏看同一信号的不同转移）；③把词库当静态（漏看协议的版本生命周期） |

**证据链一句话**：《论语·子路》"名不正，则言不顺；言不顺，则事不成"立协议有效性祖训（握手失败→会话报废→协作失败）→《荀子·正名》"名无固宜，约之以命，约定俗成谓之宜"立协议标准化原理（信号-意义绑定由群体约定）→ 香农《通信的数学理论》（1948）立信源-信道-信宿-噪声的数学结构 → 戈夫曼拟剧论立"信号发送的自我管理"【D】→ 系列文档全部实证数据（腐蚀律、更替律、极性八档、死亡词谱）作为模型的数据集 → 模型成。

## 1. 通信链模型：五段回路的展开

用户给出的结构图，逐段展开：

```
【A 信号源】        【信道Ⅰ】          【B 接收方·黑盒】      【信道Ⅱ】        【A 被接收方】
┌──────────┐   声波/文字/转述   ┌──────────────┐   反馈信号帧    ┌──────────┐
│ 编码器：   │  ═══════════▶   │ 解码器（公共协议）│  ═══════════▶  │ 解码器   │
│ 词选·档位· │                  │ 状态寄存器（私有） │                │ 状态更新  │
│ 语调·时机· │  ＋信道噪声       │ 转移函数（私有）   │  ＋信道噪声     │ 关系状态  │
│ 伴随信号   │ ◀═══════════   │ 输出：反馈帧      │ ◀═══════════  │ 修正     │
└──────────┘                  └──────────────┘                └──────────┘
        ▲                                                              │
        └──────────────── A 的下一帧称呼由更新后的状态决定 ──────────────┘
```

**回路三要点**：

1. **称呼帧的本质是"状态声明"而非"信息查询"**——A 喊"李教授"，不是在问"你是谁"，而是在声明"**我认为我们是什么关系**"（敬距＋学界）。称呼先于全句发出，等于给整句话打了个关系头部（信封）。
2. **黑盒的输入输出不对称**——A 能控制发出的帧，不能控制 B 内部的转移函数：同一帧"美女"，张三的黑盒转移为"友善"（输出微笑 ACK），李四的黑盒转移为"冒犯"（输出冷脸 NACK）。**信道相同，转移不同**——这就是"叫错人"事故的通信学原理。
3. **回路闭合才算通信完成**——只发不收（宣布完就走）是半途通信；B 的反馈帧经信道Ⅱ回到 A，A 的内部状态随之更新（"以后不这样叫他了"），一次完整的称呼交互才闭合。**社会关系这张大网，就是无数条这样的闭合回路编织的**。

## 2. 信号源：编码器（五要素）

| 要素 | 信号学角色 | 系列文档对应 |
| :--- | :--- | :--- |
| **词选** | 协议字典选词——从词库取一个词条（"师傅"还是"老师"） | 场景篇八大场景词库；立场篇极性八档——**选词即选帧格式** |
| **档位** | 帧的优先级／极性位（敬／平／亲／贬／蔑）；一帧只标一档 | 立场篇极性谱——档位错标＝头部校验错，后文全崩 |
| **语调音量** | 信道调制：同一词（"哎"）四种调（唤／急／怨／凶）四种帧 | 情绪篇梯度谱——**语调是情绪对信道的一次调制** |
| **时机** | 时隙选择：何时发帧（当面／背后／久别初见）——时机错则帧义变 | 面称／背称／书称三通道——时隙＝通道选择 |
| **伴随信号** | 冗余校验位：表情、手势、姿态与称呼帧并行发送，供接收方交叉校验 | 生存信号表的生理指纹（脸红＝尴尬帧的校验位） |

**编码层两定律**：①**声调先于语义被解码**——B 先听出 A 语气里的情绪档（情绪篇梯度），再解词义：同一句"亲爱的"，调制不同则是爱称或阴阳怪气（**同一帧格式、不同调制、完全不同的帧义**）；②**信号从不单独出行**——称呼帧总伴随情绪帧与体态帧打包发出，接收方按整包解码（只模仿词选不模仿温度＝只抄帧格式不抄调制方式，必然失真——"敬语说得很假"的机理）。

**有意编码与无意泄漏**：A 的编码器并非全受控——情绪篇已证"情绪是发动机，称呼是方向盘"，**无意识的档位滑动（疲惫时称呼变简慢）是不加密的明文状态广播**。高手读人，读的正是帧缝里的未加密字段。

## 3. 传递介质：三种信道

| 信道 | 传输特性 | 协议含义 |
| :--- | :--- | :--- |
| **声波信道**（面称） | 即时、不可撤回（泼出去的水）、自带语调冗余（调制信息全保留）、无重传缓冲 | 最高带宽信道：语调／音量／停顿全部在线传输——但**无撤回机制**，说错即已错，只能补发修正帧（"哦不好意思叫错了"） |
| **书面信道**（书称／文书） | 延迟、可斟酌修改后发出、无语调（调制信息归零，需靠敬语字面恢复正式度）、可存档 | 帧发出前有编辑缓冲区——所以书面称呼允许最高档敬语（"尊鉴""钧览"）：**无调制的信道必须靠词选补足温度**；且帧永久留档（白纸黑字不可抵赖） |
| **第三方中继信道**（背称的传播） | 多跳路由：A→C→B；每跳一次经过一个中继黑盒，**帧可能被篡改、截取、加注** | 最危险的信道：A 背后称 B"老顽固"，经 C 转述至 B 时可能已被篡改为"骂你是老顽固"——**背称是签名转发，且转发者常改包** |

**信道噪声四源**：①同音歧义（声波信道的物理噪声：称"shi fu"不知师傅还是师父）；②场域噪声（嘈杂公开场合，称呼被环境吞掉半截——所以公共场合喊人要提档喊全名）；③时间漂移（书信往来期间双方关系已变，帧到达时状态机已转移——**信里还叫"贤弟"，收信人已翻脸**）；④中继篡改（见第三方信道）。噪声不改变 A 的编码，只改变 B 的解码输入——**通信事故的一半责任在信道**。

## 4. 接收方：黑盒（四部件）

接收方之所以是**黑盒**：A 永远无法直接观测 B 的内部状态，只能通过反馈帧反推。黑盒内部四部件（全部为系列文档的整合）：

| 部件 | 功能 | 私有程度 | 数据来源 |
| :--- | :--- | :--- | :--- |
| **解码器** | 语言知识：把信号还原为词条义（"令尊"＝对方父亲） | 公共协议（全语言社区共享） | 释义方法全系列——词库即协议字典 |
| **状态寄存器Ⅰ：关系历史** | 与 A 的全部交互记录（他上次怎么叫我） | 完全私有 | 亲缘篇＋场景篇——每对关系一本台账 |
| **状态寄存器Ⅱ：当下状态** | 此刻情绪（情绪篇梯度位）、身份认知（我今天是客是主）、期待值（我以为他会叫我X） | 完全私有且**实时变动** | 情绪篇——**同一称呼对同一些人，早中晚转移不同**（情绪污染解码） |
| **转移函数** | 综合解码结果＋两个寄存器→输出内部状态转移＋反馈帧 | 完全私有（人格即函数） | 立场篇＋三色评价层——**人是自带极性判断的状态机** |

**黑盒三定律**：

1. **不可观测律**——A 只见反馈帧不见内部转移：当面笑纳（ACK 帧）不等于内部接受（状态已记恨）——**ACK 可能是伪造的**，这是"客气话"存在的通信学根源。
2. **路径依赖律**——转移函数吃全部历史：十年前一声"胖子"对今日之 B 仍有权重。关系的账本是全量记账、永不滚存清零的（钩连《余绪语义场》："余绪"即**状态寄存器中的历史残留值**——手泽／遗恨皆是寄存器里未清除的旧数据）。
3. **情绪污染律**——当下情绪作为噪声直接进入转移函数：欢喜时"死鬼"是糖，盛怒时"宝贝"是刀——**解码器正常而寄存器Ⅱ异常，帧义照样反转**。

## 5. 状态机互动：协议现象全表（十项）

两台状态机的互动，构成一整套可枚举的协议行为：

| # | 协议现象 | 描述 | 系列对应 |
| :---: | :--- | :--- | :--- |
| 1 | **握手**（Handshake） | 会话建立：每句人话的第一帧是称呼帧，为后续通信定义参数（你是谁、我是谁、我们什么关系） | 称呼三问（对象位／极性／通道）＝握手参数三元组 |
| 2 | **ACK 确认** | 回称呼应（A 喊"王老师"，B 应"哎，小李啊"）——B 用"小李"签发了**反向状态声明**（我们是师生但可口语） | 面称系统 |
| 3 | **NACK 拒绝** | 纠正帧："别叫姐，叫名字"——B 拒收 A 的状态声明并请求重传 | 改口机制（"阿姨"→"姐姐"＝请求帧降级重传） |
| 4 | **丢包沉默** | 不回应＝信号到了黑盒但无反馈帧发出（可能：未收到／收到拒绝回应／正在处理）——沉默本身是信息量极高的帧 | 系列新增：**零帧也是帧** |
| 5 | **超时重传** | 改口：NACK 或无响应后，A 调整词选档位重发（"大姐"不通换"美女"再试） | 场景篇防腐蚀三策略的"更替"——**重传机制是通货更替的微观机理** |
| 6 | **协议升降级** | 关系变化后的首次改称（升职后同事改口"X 总"＝双方协商升级；分手后改回全名＝会话降级） | 立场篇职称词抗腐蚀——**制度词是协议的稳定版本号** |
| 7 | **乱序到达** | 背称帧经中继信道延迟到达本人（A 上月背后称 B"老抠"，本周经 C 传到 B)——**帧比关系状态晚到，按旧状态编码的帧在新状态机上解码** | 背称系统——是非的通信学起源 |
| 8 | **中间人攻击** | 中继篡改：挑拨者改包转发（去掉语气、换掉原词、添加毒注释——"他背后说你老顽固"） | 第三方信道——**谗言的协议学定义：篡改后的帧转发** |
| 9 | **版本迭代失效** | 时代变迁使旧协议词被全网降级：70 年代"同志"帧畅通，今日部分黑盒将其转移至戏谑档 | 场景篇通货更替律＝**协议版本的生命周期**（贬值即版本下线） |
| 10 | **禁用信号位** | 避讳制度：某些词位对某些对象永久禁用（帝讳、亲长名讳）——协议层硬编码的保留字段 | 亲缘篇名讳制——**避讳是带强制力的协议规范**，乱用即帧被丢弃（甚至封号：文字狱） |

**状态机的完整互动图景**：两台机器各自持有一份"关系状态副本"，谁也不能强制读写对方的寄存器，只能互发称呼帧试探和声明，靠反馈帧修正自己的副本——**关系的"真相"并不存在于任何一方，只存在于两台机器副本的收敛过程中**。所谓"心照不宣"，是副本高度同步；所谓"自作多情"，是 A 的副本与 B 的副本严重不一致而 A 未察觉 NACK。

## 6. 状态转移全表：十个典型通信场景

| # | 场景 | 通信学诊断 | 处置 |
| :---: | :--- | :--- | :--- |
| 1 | 旧识重逢叫错名字 | **缓存失效**：A 的地址簿过期，旧映射已更新 | 立即 NACK 道歉＋重传（"记岔了"）；B 的反馈决定重传成本 |
| 2 | 升职后仍被旧称 | **状态不同步**：B 的副本未更新（角色已变） | 宽容重传（笑答"现在叫 X 总啦"）；反复拒更新者＝拒绝状态同步 |
| 3 | 对平辈用高敬语 | **过度握手**：帧档位高于关系状态，B 黑盒判"生分"或"讽刺" | 敬语帧的档位须匹配关系副本：**握手过强比过弱更易失败**（敬而生分） |
| 4 | 初见即用昵称 | **越级握手**：跳过协商阶段直接声明高亲密态，B 若未同步则触发防诈骗警觉 | 亲昵需要双方副本都到档（升温须逐帧爬升） |
| 5 | 用贬称骂人（"竖子"） | **攻击帧**：A 主动发送降档声明，B 状态机转入敌对态 | 攻击帧广播后双方副本同降至敌对——**骂人是对关系的公开烧桥**（春秋笔法＝加密攻击帧：明文明明是"郑伯"） |
| 6 | 当面全名称唤（连名带姓） | **告警位拉满**：全名是默认帧（中性），但**亲密态中的全名帧＝异常信号**（母亲全名称子＝训斥帧） | 全名的极性随关系副本反向变化：越亲则越凶 |
| 7 | 敬语配冷笑 | **校验位冲突**：词选帧（敬）与伴随信号帧（冷）不一致，B 按校验规则取伴随帧（**阴阳怪气的解码原理**） | 接收方遇冲突帧的默认策略：**信温度，不信词** |
| 8 | "亲"进公文 | **协议错配**：电商域协议帧闯入正式域（域间防火墙拦截） | 场景篇场景线——**每个场景是一个协议域**，跨域帧需网关转换 |
| 9 | 群发节日称呼群发错了（"王总"发给已是老友的老同事） | **批量帧未按地址分版本**：群发引擎用统一帧格式发异构黑盒 | 关系副本本来各异——**群发是对状态机的抹平操作**，事故源 |
| 10 | 网抑云深夜发"宝" | **帧与时刻错配**（时隙维）：同一帧在营业时段＝促销态、在深夜＝情感态，B 按时隙解帧 | 时机要素的显影：**时隙本身携带解帧密钥** |

## 7. 系统论：分布式关系一致性

把这层模型拉远看整个社会：

| # | 系统论观察 | 展开 |
| :---: | :--- | :--- |
