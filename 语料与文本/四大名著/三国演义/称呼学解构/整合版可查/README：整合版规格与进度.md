## 3. 预判四题（全书级，滚动登记）

1. **正统与名分**：汉室宗亲／皇叔／丞相／魏王／吴王——名分是政权合法性的外衣；第 80 回"曹丕废帝／汉王正位"双帝对峙，第 120 回"三分归一统"收束名分循环。
2. **尊号与自称的落差**：温侯／卧龙／凤雏／武侯／关公——他称尊号与自称（某、备、操）之间的位格差，名号即位格。
3. **名字与命运（谶纬命名）**：字、号、改名、童谣谶语——名字预示命运，第 1 回"治世之能臣，乱世之奸雄也"八字定曹操终身。
4. **命名权与收编**：天子封拜／诸侯自封／赐姓赐名——谁有权命名，谁就拥有收编合法性；第 119 回"再受禅依样画葫芦"是命名权循环的最高反讽。
