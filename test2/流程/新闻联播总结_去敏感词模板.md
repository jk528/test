# 附录：去敏感词处理规范

## A.1 概述

### 目的
规范央视网《新闻联播》视频标题和内容的去敏感词处理流程，确保输出内容符合相关规定。

### 适用范围
- 视频标题处理
- 视频描述处理
- 生成文档内容处理
- 分享和传播内容处理

## A.2 敏感词分类

### 政治敏感词

#### 国家领导人相关

| 领导人姓名 | 需使用规范称谓 | 保留官方称谓 |
| 职务称谓 | 主席、总理等 | 保留规范称谓 |
| 活动描述 | 视察、讲话等 | 保留官方表述 |

#### 政治事件相关
| 类型 | 示例 | 处理方式 |
|------|------|----------|
| 历史事件 | 使用规范表述 | 保留官方表述 |
| 政策名称 | 使用全称 | 保留全称 |
| 会议名称 | 使用规范简称 | 保留规范简称 |

### 社会敏感词

| 舆情事件 | 使用官方定性 | 保留官方定性 |

| 司法程序 | 使用法定术语 | 保留法定术语 |

#### 国际关系

#### 涉外事件

|------|------|----------|

| 涉外纠纷 | 使用官方表述 | 保留官方表述 |

## A.3 处理规则

### 保留规则

以下情况**保留原词**：
- 官方发布的规范表述
- 法律法规明确术语
- 外交辞令标准表述
- 历史事件规范名称
- 政策文件标准名称

### 替换规则

以下情况**替换处理**：
- 非规范表述 → 规范表述
- 口语化表达 → 书面语表达
- 情绪化词汇 → 中性词汇
- 歧义性表述 → 明确表述

### 删除规则

以下情况**删除处理**：
- 与内容无关的敏感词
- 过度渲染的形容词
- 未经证实的信息
- 涉及个人隐私的内容

## A.4 处理流程

### 流程图

```
开始
  │
  ▼
获取原始文本
  │
  ▼
分词处理
  │
  ▼
敏感词检测
  │
  ├── 是 → 判断敏感词类型
  │           │
  │           ├── 政治敏感 → 应用保留规则
  │           │
  │           ├── 社会敏感 → 应用替换规则
  │           │
  │           └── 国际敏感 → 应用删除规则
  │
  └── 否 → 保留原文
  │
  ▼
重组文本
  │
  ▼
质量检查
  │
  ▼
输出结果
  │
  ▼
结束
```

### 详细步骤

1. **获取原始文本**：从央视网标题、搜索结果等来源获取原始新闻文本
2. **分词处理**：将文本拆分为可逐词匹配的单元（实际操作中可直接字符串匹配，无需分词库）
3. **敏感词检测**：遍历A.5敏感词库，检测原始文本中是否包含敏感词，记录敏感词类型和位置
4. **应用处理规则**：按A.3规则分类处理：
   - 政治敏感 → 保留官方称谓，替换具体人名为占位符（如"国家领导人"）
   - 社会敏感 → 替换为中性表述（如"[相关内容]"）
   - 国际敏感 → 保留或删除（视语境）
5. **质量检查**：验证处理后文本的核心意义是否保留、格式是否有效、是否产生新的敏感词

> **注**：以上步骤在实际操作中由AI助手在生成报告时自动执行（步骤10质量检查），无需独立运行代码。代码实现参考 `fetch_xwlb.py` 及流程文件附录C。

## A.5 敏感词库

> **使用说明**：
> - **保留词**：指在央视网原始标题中可能出现且不应被删除的官方称谓。但在最终报告中，具体人名（如"习近平""李克强"）必须替换为占位符（如"国家领导人"），保留的仅为"国务院总理""全国人民代表大会"等职务/机构称谓。
> - **替换词**：需在最终报告中替换为占位符的内容。
> - **删除词**：完全从报告中移除的内容。
