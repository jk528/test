## A.3 处理规则

### 保留规则

以下情况**保留原词**：
- 官方发布的规范表述
- 法律法规明确术语
- 外交辞令标准表述
- 历史事件规范名称
- 政策文件标准名称

### 替换规则

以下情况**替换处理**：
- 非规范表述 → 规范表述
- 口语化表达 → 书面语表达
- 情绪化词汇 → 中性词汇
- 歧义性表述 → 明确表述

### 删除规则

以下情况**删除处理**：
- 与内容无关的敏感词
- 过度渲染的形容词
- 未经证实的信息
- 涉及个人隐私的内容

#### 步骤 3：敏感词检测
```python
class SensitiveWordDetector:
    def __init__(self, word_lists):
        """
        初始化敏感词检测器
        
        :param word_lists: 敏感词列表字典
        """
        self.political_words = word_lists.get('political', [])
        self.social_words = word_lists.get('social', [])
        self.international_words = word_lists.get('international', [])
    
    def detect(self, text):
        """
        检测敏感词
        
        :param text: 待检测文本
        :return: 检测结果列表
        """
        results = []
        
        for word in self.political_words:
            if word in text:
                results.append({
                    'word': word,
                    'type': 'political',
                    'position': text.index(word)
                })
        
        for word in self.social_words:
            if word in text:
                results.append({
                    'word': word,
                    'type': 'social',
                    'position': text.index(word)
                })
        
        for word in self.international_words:
            if word in text:
                results.append({
                    'word': word,
                    'type': 'international',
                    'position': text.index(word)
                })
        
        return results
```

#### 步骤 4：应用处理规则
```python
class TextProcessor:
    def __init__(self, rules):
        """
        初始化文本处理器
        
        :param rules: 处理规则字典
        """
        self.rules = rules
    
    def process(self, text, detections):
        """
        处理文本
        
        :param text: 原始文本
        :param detections: 敏感词检测结果
        :return: 处理后的文本
        """
        processed_text = text
        
        for detection in detections:
            word = detection['word']
            word_type = detection['type']
            
            if word_type == 'political':
                # 政治敏感词：保留或替换为规范表述
                replacement = self.rules['political'].get(word, word)
                processed_text = processed_text.replace(word, replacement)
            
            elif word_type == 'social':
                # 社会敏感词：替换为中性表述
                replacement = self.rules['social'].get(word, '[相关内容]')
                processed_text = processed_text.replace(word, replacement)
            
            elif word_type == 'international':
                # 国际敏感词：根据情况保留或删除
                replacement = self.rules['international'].get(word, word)
                processed_text = processed_text.replace(word, replacement)
        
        return processed_text
```
