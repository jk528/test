# 新闻联播总结报告生成流程

---

## 第一步：确定日期

1. 默认取"昨晚"的新闻联播（当前日期的前一天）
2. 若当前时间在当天19:00之前，则取前一天的
3. 用户指定日期时以用户为准

**排查机制**：
- 检查日期是否为未来日期（不应超过当前日期）
- 检查日期格式是否正确（YYYY年M月D日）

---

## 第二步：访问央视网

1. 打开 `http://tv.cctv.com/lm/xwlb/`
2. 找到对应日期的《新闻联播》页面
3. 提取完整标题列表和每条视频的时长

**超时与重试机制**：
- 页面加载超时设置为 **30秒**
- 若首次加载失败，等待5秒后重试1次
- 若重试后仍失败，标记为"数据异常"，暂停执行并记录错误

**排查机制**：
- 检查页面是否加载成功（HTTP状态码200）
- 检查是否找到对应日期的内容
- 检查提取的标题数量是否 >= 10条（通常12-18条）
- 若标题数量 < 10条，标记为"数据异常"，尝试刷新页面或检查日期

---

## 第三步：提取视频信息

从央视网页面提取：

| 信息项 | 说明 |
|--------|------|
| 新闻标题 | 每条视频的完整标题（含[视频]前缀） |
| 视频时长 | 格式为 HH:MM:SS |
| 总时长 | 完整版视频的总时长 |

**排查机制**：
- 检查每条视频时长是否为有效时间格式（HH:MM:SS）
- 检查总时长是否在 **25-35分钟** 范围内
- 检查是否有重复标题（去重处理）
- 若总时长 < 25分钟或 > 35分钟，标记为"时长异常"

---

## 第四步：计算播放时间

1. 第一条开始时间固定为 **19:00:00**
2. 每条结束时间 = 上一条结束时间 + 本条时长
3. 最后一条结束后到19:30:00为片尾时段
4. 验证总时长是否在 **25-35分钟** 范围内

**排查机制**：
- 检查播放时间是否连续无断裂（每条结束时间 = 下一条开始时间）
- 检查最后一条结束时间是否接近19:30:00（允许±2分钟误差）
- 检查片尾时长是否在1-3分钟范围内
- 若时间断裂，标记断裂位置并排查原因

---

## 第五步：识别快讯目录

从视频分条中识别目录条目（仅标记哪些是目录，子条目数量在第六步搜索后确定）：

- **"国内联播快讯"** → 记录为目录，非独立新闻
- **"国际联播快讯"** → 记录为目录，非独立新闻

**排查机制**：
- 检查是否识别到"国内联播快讯"目录（通常有，偶尔无）
- 检查是否识别到"国际联播快讯"目录（通常有，偶尔无）
- 检查快讯目录的时长是否合理（2-4分钟）
- 若未识别到快讯目录，标记为"快讯缺失"，需手动检查页面
- **注意**：此步骤仅识别目录条目本身，目录内含多少条子快讯需在第六步搜索后确定

---

## 第六步：搜索新闻详情

对每条标题进行网络搜索，获取文字内容：

**搜索优先级（兜底策略）**：
1. **优先搜索**：`新闻联播 YYYY年M月D日 要闻N条 整理` — 一次性获取全部新闻摘要和快讯子条目
2. **补充搜索**：`新闻联播 YYYY年M月D日 标题 主要内容` — 对重点新闻获取更详细内容
3. **专项搜索**：`国内联播快讯 YYYY年M月D日 具体内容` 和 `国际联播快讯 YYYY年M月D日 具体内容` — 展开快讯子条目

**排查机制**：
- 检查每条新闻是否搜索到至少1个有效来源
- 检查快讯子条目是否全部展开（国内通常5-8条，国际通常3-5条）
- **快讯子条目数量异常验证**：
  - 若国内快讯子条目 < 3条或 > 10条，标记为"快讯数量异常"
  - 若国际快讯子条目 < 2条或 > 7条，标记为"快讯数量异常"
  - 异常时需手动核对搜索结果，确认是否遗漏
- 检查是否有新闻完全无搜索结果（标记为"信息缺失"）
- 若信息缺失 > 3条，标记为"搜索异常"，尝试更换搜索关键词

---

## 第七步：分类与标注

### 7.1 重要性标注

| 标注 | 条件 |
|------|------|
| 🔴 必标重点 | "最高层"活动、"国务院"重大政策、国际热点冲突、重大突发事件 |
| 🟡 选标重点 | "副国家级"活动、部委政策、经济数据、科技/文化事件 |
| 一般 | 常规报道、快讯 |

### 7.2 子分类

| 分类 | 收录内容 |
|------|----------|
| 政策/会议 | 国务院政策、部委文件、重要会议 |
| 国际新闻 | 外交活动、国际冲突、国际关系 |
| 经济要闻 | 经济数据、产业政策、金融动态、科技成就 |
| 社会/文化 | 社会事件、文化活动、民生热点 |

**排查机制**：
- 检查是否有新闻未被标注重要性（所有新闻必须有标注）
- 检查🔴必标重点数量是否合理（通常3-6条）
- 检查是否有新闻未被分类（所有新闻必须有分类）
- 检查分类是否合理（是否有明显错分类的新闻）

---

## 第八步：统计条数

**前提**：此步骤需要第五步识别的目录数（D）和第六步搜索得到的子条目数（M、K）。

| 统计项 | 计算方式 |
|--------|----------|
| 央视网视频分条 | N条 |
| 减：快讯目录数 | -D条（国内+国际联播快讯目录，第五步识别） |
| 加：国内快讯子条目 | +M条（第六步搜索后确定） |
| 加：国际快讯子条目 | +K条（第六步搜索后确定） |
| **实际独立新闻总数** | **N - D + M + K = X** |

**排查机制**：
- 检查公式计算是否正确（N - D + M + K = X）
- 检查实际独立新闻总数是否在 **15-30条** 范围内
- 检查国内快讯子条目数是否合理（通常5-8条）
- 检查国际快讯子条目数是否合理（通常3-5条）
- 若总数 < 15条或 > 30条，标记为"条数异常"，排查是否有遗漏或重复

---

## 第九步：填写报告

按模板结构填写：

| 部分 | 内容 | 排查项 |
|------|------|--------|
| 一、基调概述 | 核心主题、整体基调、重点领域、当日亮点 | 检查是否填写完整，字数是否在100-200字 |
| 二、新闻速览 | 按播放顺序列出所有新闻，标注重要性 | 检查是否包含所有新闻，快讯目录是否正确标注 |
| 三、重点新闻详解 | 仅收录🔴和🟡，按子分类归档，注明播放顺序 | 检查是否遗漏🔴或🟡新闻，播放顺序是否正确 |
| 四、联播快讯详解 | 列出国内/国际快讯子条目 | 检查子条目是否完整，是否有遗漏 |
| 五、完整性检测 | 播放时间、时长匹配、条数统计、检测结论 | 检查表格数据是否准确，结论是否合理 |
| 六、新闻六要素索引 | 序号、标题、类别、时间、地点、人物、事件、原因、方式 | 检查是否包含所有新闻，类别是否正确 |
| 七、占位符统合 | 汇总人物、机构、时间、地点、数据、内容占位符 | 检查是否汇总完整，是否有遗漏 |

**排查机制**：
- 检查每个部分是否都有内容（不允许空部分）
- 检查是否有新闻在多个部分重复出现（除索引外）
- 检查是否有新闻完全未出现在报告中
- 检查占位符是否统一使用双引号标注

---

## 第十步：质量检查

1. 每条新闻是否有实质性内容（不只是标题）
2. 播放时间节点是否连续无断裂
3. 条数统计是否正确（N - D + M + K = X）
4. 分类是否合理
5. 所有占位符是否使用双引号标注
6. 是否含具体人名（应使用"国家领导人"等通用称谓）

**排查机制**：
- 检查是否有"信息缺失"标记的新闻
- 检查是否有"时长异常"标记的新闻
- 检查是否有"条数异常"标记的情况
- 检查是否有"搜索异常"标记的情况
- 若存在任何异常标记，需返回对应步骤重新处理
- 若所有检查通过，标记为"质量合格"

# 附录A：视频获取处理流程

## A.1 问题背景

### 遇到的问题
- 使用搜索引擎无法直接获取央视网《新闻联播》完整视频分条信息
- 央视网视频页面使用 JavaScript 动态加载，视频地址通过 GUID 动态生成
- 搜索返回结果有限，仅能获取到第三方转载链接（如齐鲁网）

### 问题原因分析
1. **搜索策略局限**：WebSearch 工具搜索央视网视频列表时，搜索引擎返回结果非常有限
2. **页面动态加载**：央视网视频页面使用 JavaScript 动态渲染内容，静态抓取无法获取完整信息
3. **地址动态生成**：视频 URL 格式为 `https://tv.cctv.com/2026/06/20/VIDE{随机字符}{日期}.shtml`，其中 VIDE 后面的字符是动态生成的 GUID
4. **视频流加密**：视频播放使用 `blob:` 协议，实际视频流地址需要通过 API 接口获取

## A.2 解决方案

### 方案一：浏览器自动化获取（推荐）

**适用场景**：
- 需要获取完整的视频分条信息（时长、标题、URL）
- 需要定期更新视频列表
- 需要处理动态加载的页面内容

**实现步骤**：

**步骤 1：访问央视网《新闻联播》列表页**
```
URL: https://tv.cctv.com/lm/xwlb/
```

**步骤 2：等待页面 JavaScript 加载完成**
- 页面使用 AJAX 加载视频列表
- 需要等待列表渲染完成

**步骤 3：提取视频信息**
```javascript
// 获取所有视频分条信息
const listItems = document.querySelectorAll('li');
const videoList = [];

listItems.forEach((item) => {
    const text = item.textContent || '';
    const durationMatch = text.match(/(\d{2}:\d{2}:\d{2})/);
    const link = item.querySelector('a');
    
    if (durationMatch && link) {
        videoList.push({
            duration: durationMatch[0],  // 视频时长
            title: text.replace(durationMatch[0], '').trim(),  // 视频标题
            href: link.href  // 视频页面URL
        });
    }
});
```

**步骤 4：获取视频详情（可选）**

**技术工具推荐**：

- **Playwright**：Microsoft 开源的跨浏览器自动化工具
- **Selenium**：经典的浏览器自动化测试工具

### 方案二：API 接口获取

**适用场景**：
- 已知视频 GUID，需要获取视频详细信息
- 需要获取视频的真实播放地址

**API 接口说明**：

**视频信息接口**
```
接口地址：//api.cntv.cn/video/videoinfoByGuid
请求参数：
  - guid: 视频GUID（从页面URL中提取）
  - serviceId: 服务ID

示例：
//api.cntv.cn/video/videoinfoByGuid?guid=2flMySL99j9yksI4qlbc&serviceId={serviceId}
```

**GUID 提取方法**
```javascript
// 从视频页面URL中提取GUID
const url = 'https://tv.cctv.com/2026/06/20/VIDE2flMySL99j9yksI4qlbc260620.shtml';
const guidMatch = url.match(/VIDE([^\.]+)/);
const guid = guidMatch ? guidMatch[1].replace(/\d{6}$/, '') : null;
// 结果：2flMySL99j9yksI4qlbc
```

### 方案三：混合方案（最佳实践）

**流程图**：

**实现代码框架（Python + Playwright）**：
```python
from playwright.sync_api import sync_playwright
import json

def get_xwlb_videos():
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)
        page = browser.new_page()
        
        # 访问列表页
        page.goto('https://tv.cctv.com/lm/xwlb/')
        page.wait_for_load_state('networkidle')
        
        # 等待视频列表加载
        page.wait_for_selector('li:has-text(":")')
        
        # 提取视频信息
        videos = page.evaluate('''() => {
            const listItems = document.querySelectorAll('li');
            const videoList = [];
            
            listItems.forEach((item) => {
                const text = item.textContent || '';
                const durationMatch = text.match(/(\d{2}:\d{2}:\d{2})/);
                const link = item.querySelector('a');
                
                if (durationMatch && link) {
                    videoList.push({
                        duration: durationMatch[0],
                        title: text.replace(durationMatch[0], '').trim(),
                        href: link.href
                    });
                }
            });
            
            return videoList;
        }''')
        
        browser.close()
        return videos

# 使用示例
videos = get_xwlb_videos()
print(json.dumps(videos, ensure_ascii=False, indent=2))
```

## A.3 注意事项

### 反爬虫策略
- 央视网可能有反爬虫机制，建议：
  - 设置合理的请求间隔（2-5秒）
  - 使用真实的 User-Agent
  - 必要时使用代理IP

### 页面结构变化
- 央视网页面结构可能会更新，需要：
  - 定期检查页面结构
  - 使用稳定的 CSS 选择器
  - 添加异常处理机制

### 视频地址有效期
- 视频播放地址可能有有效期限制
- 建议获取后及时使用或存储视频信息而非直接地址

### 版权说明
- 央视网视频内容受版权保护
- 获取的视频信息仅用于个人学习研究
- 禁止大规模爬取和商用

## A.4 常见问题

**Q1：为什么直接搜索获取不到视频列表？**
A：央视网视频列表通过 JavaScript 动态加载，搜索引擎爬虫无法执行 JavaScript，因此搜索结果显示不完整。

**Q2：视频 blob: 地址如何转换为真实地址？**
A：blob: 地址是浏览器本地生成的，需要通过央视网 API 接口获取真实的视频流地址。

**Q3：GUID 会变化吗？**
A：每个视频的 GUID 是固定的，但新发布的视频会生成新的 GUID。

**Q4：如何获取历史日期的视频？**
A：央视网《新闻联播》列表页默认显示最新一期，历史视频需要通过日期参数或搜索功能访问。

```python
from playwright.sync_api import sync_playwright

def get_video_urls():
```

## C.1 完整自动化脚本（Python）

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
央视网《新闻联播》视频生成脚本
"""

import os
import json
import time
from datetime import datetime, timedelta
from playwright.sync_api import sync_playwright

class XWLBGenerator:
    def __init__(self, output_dir='./output'):
        self.output_dir = output_dir
        self.base_url = 'https://tv.cctv.com/lm/xwlb/'
        os.makedirs(output_dir, exist_ok=True)
    
    def fetch_video_list(self, target_date=None):
        """
        获取视频列表
        
        :param target_date: 目标日期，None表示最新一期
        :return: 视频列表
        """
        with sync_playwright() as p:
            browser = p.chromium.launch(headless=True)
            page = browser.new_page()
            
            try:
                # 访问列表页
                page.goto(self.base_url)
                page.wait_for_load_state('networkidle')
                
                # 等待视频列表加载
                page.wait_for_selector('li:has-text(":")', timeout=10000)
                
                # 提取视频信息
                videos = page.evaluate('''() => {
                    const items = document.querySelectorAll('li');
                    const videoList = [];
                    
                    items.forEach((item) => {
                        const text = item.textContent || '';
                        const durationMatch = text.match(/(\d{2}:\d{2}:\d{2})/);
                        const link = item.querySelector('a');
                        
                        if (durationMatch && link) {
                            const href = link.href;
                            const guidMatch = href.match(/VIDE([^\.]+)/);
                            const guid = guidMatch ? guidMatch[1].replace(/\d{6}$/, '') : null;
                            
                            videoList.push({
                                duration: durationMatch[0],
                                title: text.replace(durationMatch[0], '').trim(),
                                href: href,
                                guid: guid
                            });
                        }
                    });
                    
                    return videoList;
                }''')
                
                return videos
                
            except Exception as e:
                print(f"获取视频列表失败: {e}")
                return []
            finally:
                browser.close()
    
    def process_data(self, videos, target_date):
        """处理视频数据"""
        total_seconds = sum(
            int(d.split(':')[0]) * 3600 + int(d.split(':')[1]) * 60 + int(d.split(':')[2])
            for d in [v['duration'] for v in videos]
        )
        
        hours = total_seconds // 3600
        minutes = (total_seconds % 3600) // 60
        seconds = total_seconds % 60
        
        return {
            "date": target_date,
            "total_videos": len(videos),
            "total_duration": f"{hours:02d}:{minutes:02d}:{seconds:02d}",
            "videos": [
                {
                    "index": i + 1,
                    **video
                }
                for i, video in enumerate(videos)
            ]
        }
    
    def generate_document(self, data):
        """生成Markdown文档"""
        document = f"""# 央视网《新闻联播》视频列表 - {data['date']}

## 基本信息

| 项目 | 内容 |
|------|------|
| 日期 | {data['date']} |
| 视频数量 | {data['total_videos']} |
| 总时长 | {data['total_duration']} |

## 视频列表

| 序号 | 时长 | 标题 | 视频地址 | GUID |
|------|------|------|----------|------|
"""
        
        for video in data['videos']:
            document += f"| {video['index']} | {video['duration']} | {video['title']} | {video['href']} | {video['guid']} |\n"
        
        document += f"""

## 生成信息

- 生成时间：{datetime.now().strftime('%Y-%m-%d %H:%M:%S')}
- 数据来源：央视网 (tv.cctv.com)
- 生成工具：XWLBGenerator

---

*本文档由自动生成工具创建*
"""
        return document
    
    def save_document(self, document, filename):
        """保存文档"""
        filepath = os.path.join(self.output_dir, filename)
        with open(filepath, 'w', encoding='utf-8') as f:
            f.write(document)
        return filepath
    
    def run(self, target_date=None):
        """
        运行生成流程
        
        :param target_date: 目标日期，None表示最新一期
        """
        if target_date is None:
            target_date = datetime.now().strftime('%Y-%m-%d')
        
        print(f"开始获取 {target_date} 的视频列表...")
        
        # 获取视频列表
        videos = self.fetch_video_list(target_date)
        if not videos:
            print("未获取到视频列表")
            return None
        
        print(f"获取到 {len(videos)} 个视频")
        
        # 处理数据
        data = self.process_data(videos, target_date)
        
        # 生成文档
        document = self.generate_document(data)
        
        # 保存文档
        filename = f"xwlb_{target_date.replace('-', '')}.md"
        filepath = self.save_document(document, filename)
        
        print(f"文档已保存到: {filepath}")
        return filepath

# 使用示例
if __name__ == '__main__':
    generator = XWLBGenerator(output_dir='./流程')
    generator.run()
```
