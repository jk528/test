# 新闻联播总结报告生成流程

---

## 第一步：确定日期

1. 默认取"昨晚"的新闻联播（当前日期的前一天）
2. 若当前时间在当天19:00之前，则取前一天的
3. 用户指定日期时以用户为准

---

## 第二步：访问央视网

1. 打开 `http://tv.cctv.com/lm/xwlb/`
2. 找到对应日期的《新闻联播》页面
3. 提取完整标题列表和每条视频的时长

---

## 第三步：提取视频信息

从央视网页面提取：

| 信息项 | 说明 |
|--------|------|
| 新闻标题 | 每条视频的完整标题（含[视频]前缀） |
| 视频时长 | 格式为 HH:MM:SS |
| 总时长 | 完整版视频的总时长 |

---

## 第四步：计算播放时间

1. 第一条开始时间固定为 **19:00:00**
2. 每条结束时间 = 上一条结束时间 + 本条时长
3. 最后一条结束后到19:30:00为片尾时段
4. 验证总时长是否在 **25-35分钟** 范围内

---

## 第五步：识别快讯目录

从视频分条中识别：

- **"国内联播快讯"** → 记录为目录，非独立新闻
- **"国际联播快讯"** → 记录为目录，非独立新闻

---

## 第六步：搜索新闻详情

对每条标题进行网络搜索，获取文字内容：

| 搜索内容 | 目的 |
|----------|------|
| 新闻联播 YYYY年M月D日 标题 主要内容 | 获取新闻详情 |
| 要闻N条 整理文章 | 获取补充信息 |
| 快讯子条目详情 | 展开国内/国际联播快讯 |

---

## 第七步：分类与标注

### 7.1 重要性标注

| 标注 | 条件 |
|------|------|
| 🔴 必标重点 | 领导人活动、国务院重大政策、国际热点冲突、重大突发事件 |
| 🟡 选标重点 | 副国级活动、部委政策、经济数据、科技/文化事件 |
| 一般 | 常规报道、快讯 |

### 7.2 子分类

| 分类 | 收录内容 |
|------|----------|
| 政策/会议 | 国务院政策、部委文件、重要会议 |
| 国际新闻 | 外交活动、国际冲突、国际关系 |
| 经济要闻 | 经济数据、产业政策、金融动态、科技成就 |
| 社会/文化 | 社会事件、文化活动、民生热点 |

---

## 第八步：统计条数

| 统计项 | 计算方式 |
|--------|----------|
| 央视网视频分条 | N条 |
| 减：快讯目录数 | -D条（国内+国际联播快讯目录） |
| 加：国内快讯子条目 | +M条 |
| 加：国际快讯子条目 | +K条 |
| **实际独立新闻总数** | **N - D + M + K = X** |

---

## 第九步：填写报告

按模板结构填写：

| 部分 | 内容 |
|------|------|
| 一、基调概述 | 核心主题、整体基调、重点领域、当日亮点 |
| 二、新闻速览 | 按播放顺序列出所有新闻，标注重要性 |
| 三、重点新闻详解 | 仅收录🔴和🟡，按子分类归档，注明播放顺序 |
| 四、联播快讯详解 | 列出国内/国际快讯子条目 |
| 五、完整性检测 | 播放时间、时长匹配、条数统计、检测结论 |
| 六、新闻六要素索引 | 序号、标题、类别、时间、地点、人物、事件、原因、方式 |
| 七、占位符统合 | 汇总人物、机构、时间、地点、数据、内容占位符 |

---

## 第十步：质量检查

1. 每条新闻是否有实质性内容（不只是标题）
2. 播放时间节点是否连续无断裂
3. 条数统计是否正确（N - D + M + K = X）
4. 分类是否合理
5. 所有占位符是否使用双引号标注
6. 是否含具体人名（应使用"国家领导人"等通用称谓）

---

## 第十一步：保存文件

文件名格式：`新闻联播总结_YYYYMMDD.md`

保存路径：用户工作文件夹
