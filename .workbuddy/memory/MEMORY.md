## 四大名著「白描手法逐回分析」目录规范

每部书结构完全一致：

```
语料与文本\四大名著\<书名>\<书名>分析\
├─ 《书名》白描手法逐回解析：<N>回叙事技巧统合分析.md   ← 汇总产物
└─ 白描批次\                                            ← 上游中间产物
    ├─ batch_01.md ~ batch_10.md   逐回分析批次
    ├─ head.md / tail.md           全书首/尾片段
    └─ hits.txt                    逐回命中手法清单
```

- **`hits.txt` 格式已冻结**：UTF-8 **无 BOM**、**LF** 换行，每行 `章号|手法A,手法B,…`。
- 规范出处：`四大名著\通用分析\拆分文本白描逐回分析_通用任务方法论.md` 第 149 / 224 行。
- 行数 = 该书回数（红楼梦/三国/水浒 120，西游记 100）。
- **禁止**中文式 `第N回：手法、手法` 写法；**禁止** BOM / CRLF / `xyj_` 之类书名前缀。
