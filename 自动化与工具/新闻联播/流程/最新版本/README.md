# 新闻联播总结报告生成系统 — 最新版本

> **版本**：v1.0.0（2026-10-07）
> **性质**：自包含发布包，复制到任意 Windows 电脑即可复现

---

## 一、这是什么

每天 05:00 自动生成前一天《新闻联播》总结报告的系统。报告含七部分：基调概述、新闻速览、重点新闻详解、联播快讯详解、完整性检测、新闻六要素索引、占位符统合信息。

**核心特点**：
- **不脱敏版**：保留新闻原始人名，人物以"职务+姓名"呈现（如"联合国秘书长古特雷斯"）
- **AI 精读六要素**：脚本抓取数据 + AI 精读正文填写地点/主体/事件/原因/方式
- **质检闭环**：12 项自动检测，0 问题才算完成
- **快讯完整不截断**：第四部分用完整正文，禁止 `...` 省略号
- **快讯父目录行不出现**：第六部分只列子条目行，更干净

## 三、两套方案对比

本发布包含两套自动化方案，共用同一份代码，按需选择：

| 维度 | 用积分方案 | 不用积分方案 |
|------|----------|------------|
| **配置文档** | `定时任务配置.md` | `不用积分\README.md` |
| **执行方式** | TeleAgent 定时任务（AI 执行） | Windows 任务计划程序（纯脚本） |
| **积分消耗** | 每天 1 次 TeleAgent 会话 | 零 |
| **六要素质量** | 高（AI 精读正文，>95%） | 一般（正则提取，~70%） |
| **生成耗时** | ~2-5 分钟 | ~15 秒 |
| **外部依赖** | TeleAgent 桌面端运行中 | 仅 Python + requests |
| **可选升级** | — | ai_api 模式（外部 API，~0.01元/天） |

## 四、快速复现

### 4.1 通用准备（两套方案都需要）

### 步骤 1：复制文件夹

把整个 `最新版本\` 文件夹复制到目标电脑，建议路径 `<任意目录>\新闻联播\流程\最新版本\`。

同时创建空的 `归档\` 目录用于存放报告输出：

```
<任意目录>\新闻联播\
  ├── 归档\           ← 报告输出（首次运行自动创建月份子目录）
  └── 流程\
       └── 最新版本\  ← 复制到这里
```

### 步骤 2：安装 Python + requests

### 步骤 3：选择方案

根据需求选择一套方案配置（可共存，但建议只用一套）：

**方案 A：用积分（高质量，推荐）** → 按 `定时任务配置.md` 操作
- 需要 TeleAgent 桌面端运行
- AI 精读六要素，质量高
- 每天 05:00 由 TeleAgent 自动执行

**方案 B：不用积分（零成本）** → 按 `不用积分\README.md` 操作
- 仅需 Python + requests
- 正则提取六要素，质量一般
- 每天 05:00 由 Windows 任务计划程序自动执行
- 可选升级到 ai_api 模式（外部 API，~0.01元/天）

### 步骤 4：手动验证

选好方案后，先手动跑一次确认环境正常：

**用积分方案**：详见 `定时任务配置.md` 第二章

**不用积分方案**：
```powershell
cd "<你的路径>\最新版本\不用积分\scripts"
powershell -ExecutionPolicy Bypass -File .\run_now.ps1
```

### 步骤 5：配置定时任务

**用积分方案**：详见 `定时任务配置.md` 第三章（`teleai-agent-schedule add`）

**不用积分方案**：以管理员身份运行
```powershell
cd "<你的路径>\最新版本\不用积分\scripts"
powershell -ExecutionPolicy Bypass -File .\register_task.ps1 -NonInteractive
```

**运行命令**（Phase 1 抓取）：

```powershell
$env:XWLB_NO_DESENSITIZE='1'
& "<PYTHON_EXE>" gen_report_final.py YYYYMMDD
# 工作目录：代码\
```

**质检命令**：

```powershell
& "<PYTHON_EXE>" check_md_quality.py "<报告路径>"
# 工作目录：代码\；此时 XWLB_NO_DESENSITIZE=1 应已设
```
