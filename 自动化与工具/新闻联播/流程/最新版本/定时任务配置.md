# TeleAgent 定时任务配置步骤

> **版本**：v1.0.0（2026-10-07）
> **用途**：在新电脑上从零配置"每天 05:00 自动生成高质量不脱敏版新闻联播总结报告"的定时任务
> **前置条件**：已安装 TeleAgent 桌面端并登录

---

## 一、前置环境准备

### 1.1 软件依赖

| 组件 | 版本要求 | 验证命令 |
|------|---------|---------|
| Python | 3.10+（开发用 3.12） | `python --version` |
| requests 库 | 任意版本 | `python -c "import requests; print(requests.__version__)"` |
| TeleAgent 桌面端 | 当前发行版 | 任务计划程序库可见 `teleai-agent-schedule` |

若 Python 缺 requests：

```powershell
python -m pip install requests -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 1.2 文件部署

将本文件夹（`最新版本\`）复制到目标电脑的任意路径，例如 `D:\projects\新闻联播\`。最终结构：

```
新闻联播\
  ├── 归档\                      # 报告输出目录（首次运行自动创建月份子目录）
  └── 流程\
       └── 最新版本\
            ├── 生成过程控制.md
            ├── 生成结果模板.md
            ├── 中间代码逻辑说明.md
            ├── 定时任务配置.md    ← 本文档
            ├── README.md
            └── 代码\
                 ├── gen_report_final.py
                 ├── gen_report_v2.py
                 ├── fetch_xwlb.py
                 ├── fetch_iqilu.py
                 ├── fill_elements_api.py
                 └── check_md_quality.py
```

### 1.3 路径变量

后续命令中需要替换的路径（记下你的实际值）：

| 变量名 | 含义 | 示例值 |
|--------|------|--------|
| `<PROJECT_ROOT>` | 新闻联播项目根目录 | `D:\projects\新闻联播` |
| `<CODE_DIR>` | 代码目录 | `<PROJECT_ROOT>\流程\最新版本\代码` |
| `<PYTHON_EXE>` | Python 解释器完整路径 | `C:\Users\用户名\AppData\Local\Programs\Python\Python312\python.exe` |

**获取 Python 路径**：

```powershell
(Get-Command python).Source
# 或显式查找
Get-ChildItem "$env:LOCALAPPDATA\Programs\Python\Python*\python.exe" -ErrorAction SilentlyContinue | Select-Object FullName
```

### 1.4 环境变量

定时任务运行时需要设置一个临时环境变量：

| 变量名 | 值 | 作用 | 何时设/取消 |
|--------|----|------|-----------|
| `XWLB_NO_DESENSITIZE` | `1` | 不脱敏：保留新闻原始人名，质检跳过敏感词检查 | AI 执行流程开始时设；任务结束前取消 |

## 二、手动验证（配置定时任务前必做）

在新电脑首次部署后，先手动跑一次确认环境正常：

### 2.1 验证脚本可运行

```powershell
# 切到代码目录
cd "<CODE_DIR>"

# 用昨天的日期测试（不带参数默认昨天）
& "<PYTHON_EXE>" gen_report_final.py
```

**预期输出**：
- 控制台显示 `[1/4] 获取央视网视频列表...` 到 `[4/4] 生成报告1-5部分 + 六要素数据源...`
- 生成两个文件：
  - `<PROJECT_ROOT>\归档\YYYY年M月\新闻联播总结_YYYYMMDD.md`（1-5 部分）
  - `<PROJECT_ROOT>\归档\YYYY年M月\六要素数据源_YYYYMMDD.json`

### 2.2 验证不脱敏开关

```powershell
$env:XWLB_NO_DESENSITIZE='1'
& "<PYTHON_EXE>" -c "import sys; sys.path.insert(0, '.'); from fetch_xwlb import desensitize; print(desensitize('习近平总书记强调'))"
# 预期输出：习近平总书记强调（不脱敏）
Remove-Item Env:\XWLB_NO_DESENSITIZE
& "<PYTHON_EXE>" -c "import sys; sys.path.insert(0, '.'); from fetch_xwlb import desensitize; print(desensitize('习近平总书记强调'))"
# 预期输出：<u>国家主席</u>总书记强调（默认脱敏）
```

### 2.3 验证质检脚本

```powershell
& "<PYTHON_EXE>" check_md_quality.py "<PROJECT_ROOT>\归档\YYYY年M月\新闻联播总结_YYYYMMDD.md"
# 预期：All checks passed（或列出问题）
```

**如果以上三步均通过，环境就绪，可以配置定时任务。**

## 三、配置 TeleAgent 定时任务

### 3.1 确认 scheduler 命令可用

```powershell
teleai-agent-schedule list
# 预期：📋 任务列表（可能为空）
```

若命令不存在：确认 TeleAgent 桌面端已安装且在运行；scheduler 命令通常位于 `C:\Program Files\TeleAgent\resources\scheduler\bin\`。

### 3.2 创建定时任务

**核心命令**（在新电脑上执行一次即可）：

```powershell
$prompt = @'
生成昨天日期的高质量、不脱敏版《新闻联播》总结报告（分阶段精读+一键生成模板融合版），工作目录为新闻联播项目根目录。不脱敏说明：全报告保留新闻原始人名，人物以"职务+姓名"形式呈现（如"联合国秘书长古特雷斯"、"中共中央总书记、国家主席、中央军委主席习近平"），不加<u>占位符标签。流程：1.目标日期为昨天YYYYMMDD，输出归档\YYYY年M月\新闻联播总结_YYYYMMDD.md；2.若报告已存在先备份到.temp\备份_新闻联播总结_YYYYMMDD_旧版.md；3.先设环境变量XWLB_NO_DESENSITIZE=1（抓取、渲染、质检三步共用，任务结束前取消），再在流程\最新版本\代码目录运行 <PYTHON_EXE> gen_report_final.py YYYYMMDD 生成1-5部分与六要素数据源JSON临时文件；4.读JSON逐条精读title/summary/full_text填写六要素(地点/主体/事件/原因/方式)，禁止大量填—须依据正文实质提炼，人物主体直接写职务+姓名不加<u>标签，机构名与事件核心对象写明文，修正脚本分类错误(假期文旅归社会/文化要闻、经济调研归经济要闻、联合国决议归国际新闻等)，机构用全称地点精确到城市，完整版行固定填location=全国/subject=—/event=当日全部新闻汇总/cause=—/method=完整播报；5.参考流程\最新版本\生成结果模板.md与流程\一键生成\示例输出\新闻联播总结_20260915.md格式渲染第六七部分：第六部分为10列六要素索引表(序号/标题含链接/类别/时间/地点/新闻主体/事件/原因/方式/详细信息源链接)，完整版首行+常规新闻+快讯子条目N-M，快讯父目录行(纯"国内/国际联播快讯"的序号8、12等)不出现只列子条目行，加编号规则说明；第七部分占位符统合(7.1.1人物类直接列姓名职务不加u标签、7.1.2机构类含全称、7.1.3事件核心对象类、7.2时间、7.3地点、7.4数据占位符从正文全部提取不设上限、7.5内容占位符)，不再把"国内/国际联播快讯"目录名作为主体归类，末尾数据来源区块加声明行；6.第四部分快讯排版：每条快讯之间空>行分隔，正文用full_text完整呈现禁止用截断summary禁止...省略号结尾；7.拼接1-5部分+第六七部分写回归档报告UTF-8无BOM，删除多余AI生成标记行以声明行结尾；8.在流程\最新版本\代码目录运行 <PYTHON_EXE> check_md_quality.py 报告路径（此时XWLB_NO_DESENSITIZE=1已设，质检会跳过敏感人名检查）必须0问题(CRITICAL/ERROR/WARNING全0)不通过则修复重检；9.取消环境变量XWLB_NO_DESENSITIZE；10.删除归档目录六要素数据源_*.json与六要素结果_*.json中间文件只保留md报告；11.汇报报告路径、行数大小、质检结果、新闻条数与六要素填写数。
'@

teleai-agent-schedule add `
  --name "新闻联播日报" `
  --type cron `
  --expr "0 5 * * *" `
  --prompt $prompt `
  --project-path "<PROJECT_ROOT>"
```

**执行前替换**：
- `<PYTHON_EXE>` → 你的 Python 完整路径（如 `C:\Users\用户名\AppData\Local\Programs\Python\Python312\python.exe`）
- `<PROJECT_ROOT>` → 你的项目根目录（如 `D:\projects\新闻联播`）

### 3.3 验证任务创建成功

```powershell
teleai-agent-schedule list
# 预期输出包含：
# ID                      名称              类型      状态
# job_xxx                 新闻联播日报      cron      ✅
```

### 3.4 （可选）立即手动触发一次

不想等到明天 05:00，可立即触发验证：

```powershell
teleai-agent-schedule run <task-id>
# task-id 从 list 命令获取
```

或在 TeleAgent 桌面端对话中直接说"立即运行新闻联播日报任务"。

## 四、Prompt 关键词与规则速查

> 以下是写入定时任务的完整 prompt 关键内容，供复现/调试/改版时参考。

### 4.1 prompt 关键词清单

| 关键词 | 规则要求 |
|--------|---------|
| **不脱敏** | 保留原始人名，人物"职务+姓名"呈现，不加 `<u>` 标签 |
| **XWLB_NO_DESENSITIZE=1** | 抓取/渲染/质检三步共用，任务结束前取消 |
| **full_text 完整** | 第四部分快讯用 full_text，禁止截断 summary，禁止 `...` 省略号 |
| **空 > 行分隔** | 第四部分每条快讯之间空 `>` 行 |
| **快讯父目录行不出现** | 第六部分不列序号8、12等纯目录行，只列子条目行 N-M |
| **禁止大量填—** | 六要素每条依据正文实质提炼，"—"占比 ≤ 30% |
| **分类修正** | 假期文旅→社会/文化要闻；经济调研→经济要闻；联合国决议→国际新闻 |
| **机构全称** | 如"国务院安委会办公室"而非"国务院安委办" |
| **7.4 不设上限** | 数据占位符从正文全部提取，不限数量 |
| **UTF-8 无 BOM** | 报告编码 |
| **以声明行结尾** | 删除多余 `> AI生成` 标记行 |
| **质检 0 问题** | CRITICAL/ERROR/WARNING 全 0 |
| **清理 JSON** | 删除六要素数据源/结果 JSON，归档只留 md |

### 4.2 prompt 模板（带占位符，复用时替换）

将下方 `<尖括号>` 内容替换为你的实际值后即可用于 `teleai-agent-schedule add --prompt`：

### 4.3 cron 表达式说明

| 表达式 | 含义 |
|--------|------|
| `0 5 * * *` | 每天 05:00（默认） |
| `30 6 * * *` | 每天 06:30 |
| `0 5 * * 1-5` | 工作日 05:00 |
| `0 5,17 * * *` | 每天 05:00 和 17:00 各一次 |

## 五、常见问题

### 5.1 任务到点没触发

| 检查项 | 方法 |
|--------|------|
| TeleAgent 是否运行 | 桌面端是否在线；`teleai-agent-schedule list` 是否能响应 |
| 任务状态 | `teleai-agent-schedule list` 状态列为 ✅ |
| cron 表达式 | 确认 `0 5 * * *`（5点）非 `5 0 * * *`（0点5分） |
| 系统时区 | 中国时区应为 China Standard Time |

### 5.2 任务触发但报告没生成

| 检查项 | 方法 |
|--------|------|
| Python 路径 | prompt 中的 `<PYTHON_EXE>` 是否指向实际存在的解释器 |
| 代码目录 | `<PROJECT_ROOT>\流程\最新版本\代码\` 是否含 6 个脚本 |
| 网络访问 | 央视网 `tv.cctv.com` 是否可访问 |
| 权限 | 当前用户对项目目录有读写权限 |

### 5.3 报告生成但质检不通过

| 报错 | 原因 | 解决 |
|------|------|------|
| sensitive_name_found | 没设 `XWLB_NO_DESENSITIZE=1` | 确认 prompt 含设环境变量步骤 |
| missing_section | 七部分有缺失 | AI 渲染时漏部分，检查第六七部分渲染 |
| section6_column_count | 表头列数不对 | 严格按模板 10 列 |
| file_size < 10KB | 生成中断 | 检查央视网是否返回正常数据 |

### 5.4 修改定时任务

```powershell
# 查看任务 ID
teleai-agent-schedule list

# 更新 prompt（如改 Python 路径）
teleai-agent-schedule update <task-id> --prompt "新prompt内容"

# 更新执行时间
teleai-agent-schedule update <task-id> --expr "30 6 * * *"

# 启用/停用
teleai-agent-schedule enable <task-id>
teleai-agent-schedule disable <task-id>

# 删除任务
teleai-agent-schedule delete <task-id>
```
