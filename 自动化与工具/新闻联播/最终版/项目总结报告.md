## 二、问题与解决方案

### 2.1 核心问题：联播快讯 B=0

| 项 | 内容 |
|----|------|
| **现象** | 10月13日"联播快讯"合集B=0，遗漏7条子快讯 |
| **根因** | `build_dataset` 只识别"国内/国际联播快讯"分开形式，不识别单条"联播快讯"合集；`fetch_kuaixun_details` 未被调用 |
| **解决方案** | ①`build_dataset` 增单条"联播快讯"识别 ②调用`fetch_kuaixun_details`解析子条目 ③按`_looks_international`分国内/国际 ④合集行进第六部分 ⑤子条目"父序号-子序号"编号 ⑥条数公式 N+M+K |
| **验证** | B=7（国内5+国际2），条数公式 11+5+2=18 闭合 |

### 2.2 CNTV 接口漂移

| 项 | 内容 |
|----|------|
| **现象** | CNTV栏目接口对历史日期（20261013）只返回2条分段 |
| **根因** | CNTV接口对历史日期数据漂移，非完整11条 |
| **解决方案** | `fetch_videos` 在CNTV返回<5条时回退央视网日页 `fetch_xwlb_list` 补全 |
| **验证** | 回退后取到12条 |

### 2.3 第七部分编号跳 7.2

| 项 | 内容 |
|----|------|
| **现象** | 旧版 part7 跳过7.2（7.3时间/7.4地点/7.5数据/7.6内容） |
| **根因** | 旧模板历史BUG，子节编号不连续 |
| **解决方案** | contract.json 修正为 7.2时间/7.3地点/7.4数据/7.5内容；渲染代码同步修正 |
| **验证** | 质检不再报"第七部分缺少子节" |

### 2.4 敏感词误报（不脱敏版）

| 项 | 内容 |
|----|------|
| **现象** | 质检报 CRITICAL"敏感词泄露：习近平、拜登" |
| **根因** | 最终版不脱敏，但质检仍按旧版检查敏感人名 |
| **解决方案** | ①xwlb_report.py 删除两处敏感词检查 ②check_md_quality.py 默认跳过，加`--check-dedesensitize`可选开启 |
| **验证** | 质检 CRITICAL=0 |

### 2.5 🔴必标重点判断缺失

| 项 | 内容 |
|----|------|
| **现象** | 🔴仅基于标题含领导人职务词，遗漏会议型/政策型重点 |
| **根因** | `_RED_KEYWORDS` 只有9个职务词，且只查 title_clean 不查正文 |
| **解决方案** | ①扩充会议型词（政治局会议/常委会/中央委员会）②扩充政策型词（中共中央关于/国务院关于）③增 `_RED_BODY_KEYWORDS` 查正文 |
| **验证** | 6条习近平活动全标红 |

### 2.6 🟡选标重点逻辑不完善

| 项 | 内容 |
|----|------|
| **现象** | "印发/发布/规划/论坛"过宽导致误标；缺副国级活动；裸国名误标 |
| **根因** | `_YELLOW_KEYWORDS` 关键词过于宽泛且缺失spec要求的副国级 |
| **解决方案** | ①移除过宽词 ②增副国级（副委员长/副主席/最高法/最高检/国务委员）③裸国名改为"美国总统/俄罗斯总统"限定 |
| **验证** | 🟡=2，不再泛滥 |

### 2.7 排序仅二值不显性

| 项 | 内容 |
|----|------|
| **现象** | 排序键 `0 if 🔴 else 1` 仅二值，同级按播出顺序；引言笼统 |
| **根因** | 无重要性细分；引言未显式说明排序规则 |
| **解决方案** | ①排序简化为 `(level, idx)` ②contract.json 引言显式说明"子分类内先🔴后🟡，同级按播出顺序" |
| **验证** | 🔴排🟡前，同级按播出序，引言透明 |

### 2.8 分类偏差（外交活动误入经济要闻）

| 项 | 内容 |
|----|------|
| **现象** | "习近平同博茨瓦纳总统会谈"被分到"经济要闻"，"习近平致电祝贺爱沙尼亚总统"分到"其他" |
| **根因** | 博茨瓦纳/多哥/爱沙尼亚不在国际新闻关键词，加权打分误入经济类 |
| **解决方案** | `_FORCE_RULES` 增外交活动强制规则（访华/会谈/会见/致电祝贺→国际新闻） |
| **验证** | 4条外交活动归入3.2国际新闻 |

### 2.9 首次产物不全

| 项 | 内容 |
|----|------|
| **现象** | 央视网/齐鲁网首次未同步全→条目少/正文缺 |
| **根因** | 数据源更新有延迟 |
| **解决方案** | `auto_complete.py`：首次运行→检测完整性（条目≥8/大小≥15KB/exit=0）→不全则等待30分钟--force重跑，最多2次 |
| **验证** | 10月13日首次即完整，补全机制就绪 |

### 2.10 引言不更新（contract优先级）

| 项 | 内容 |
|----|------|
| **现象** | 改 `_render_part3` 的 fallback 引言不生效 |
| **根因** | `_intro` 优先读 contract.json 的 intros，fallback 被忽略 |
| **解决方案** | 直接改 contract.json 的 `intros["三"]` |
| **验证** | 引言显式显示排序规则 |

## 五、关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 脱敏策略 | 不脱敏（恒等） | 用户明确要求保留原始人名 |
| 排序基准 | 央视网播出顺序 | 唯一权威基准，齐鲁网仅补链接 |
| 联播快讯 | 合集条目（非目录行） | 与国内/国外新闻同级，子条目计入统计 |
| 子条目编号 | 父序号-子序号（11-1, 11-2） | 避免重号，国际接续国内 |
| 质检退出码 | 三级（0/1/2） | 定时任务可据退出码判定成败 |
| 敏感词检查 | 默认跳过 | 最终版定位不脱敏 |
| 排序键 | (level, idx) | 显性简单，先🔴后🟡同级按播出序 |
| 定时时间 | 11:10 | 用户指定，新闻联播次日上午处理 |
| 补全机制 | 等待30分钟重跑最多2次 | 应对数据源同步延迟 |
