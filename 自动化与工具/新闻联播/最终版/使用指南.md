# 新闻联播日报生成系统 — 使用指南

> **版本**：1.0.0  
> **适用对象**：零基础使用者  
> **运行环境**：Windows + Python 3.10+

---

## 一、环境准备

### 1.1 Python 环境

需安装 Python 3.10 及以上版本。确认安装：

```powershell
python --version
```

若未安装，从 [python.org](https://www.python.org/downloads/) 下载安装，安装时勾选 "Add Python to PATH"。

### 1.2 安装依赖

仅需 `requests` 库：

```powershell
pip install requests
```

### 1.3 目录结构确认

最终版目录应完整存在：

```
自动化与工具\新闻联播\最终版\
├── 代码\           ← 脚本目录
├── 不用积分\       ← 定时自动化配置
├── 最终版方案.md
└── 使用指南.md     ← 本文档
```

## 二、快速开始

### 2.1 生成昨日报告（最常用）

```powershell
cd 自动化与工具\新闻联播\最终版\代码
python xwlb_report.py
```

不指定日期时默认生成**昨天**的报告。

### 2.2 生成指定日期报告

```powershell
python xwlb_report.py 20261013
```

### 2.3 强制重新生成

```powershell
python xwlb_report.py 20261013 --force
```

`--force` 会先备份旧报告到 `.temp/` 再重新生成。

### 2.4 预览不落盘

```powershell
python xwlb_report.py 20261013 --dry-run
```

执行采集与渲染校验但不写入归档，用于部署前验证。

---

## 三、命令参数

| 参数 | 说明 |
|------|------|
| `date` | 目标日期 YYYYMMDD（缺省为昨天） |
| `--mode {oneshot,ai_api,staged}` | 运行模式（默认 oneshot） |
| `--force` | 强制覆盖已有报告（先备份） |
| `--dry-run` | 渲染并自检但不写正式文件 |
| `--preview PATH` | 把渲染结果写到指定路径 |
| `--check` | 仅对已存在报告跑自检 |

## 四、质量检测

### 4.1 生成时自动质检

`xwlb_report.py` 生成报告后自动运行自检，输出退出码：

| 退出码 | 含义 |
|--------|------|
| 0 | 全部通过 |
| 1 | 有 ERROR（结构缺陷） |
| 2 | 有 CRITICAL（致命问题） |

### 4.2 独立质检工具

```powershell
python check_md_quality.py "归档\2026年10月\新闻联播总结_20261013.md"
```

批量检查某目录：

```powershell
python check_md_quality.py --dir "归档\2026年10月"
```

最终版默认不检查敏感人名（不脱敏）。如需检查，加 `--check-dedesensitize`。

### 4.3 仅自检已有报告

```powershell
python xwlb_report.py 20261013 --check
```

## 五、定时自动化（不用积分方案）

### 5.1 配置

编辑 `不用积分\config\config.json`：

```json
{
  "python_exe": "C:\\路径\\python.exe",
  "schedule": {
    "trigger_time": "05:00"
  }
}
```

**关键项**：
- `python_exe`：Python 解释器完整绝对路径
- `trigger_time`：每日触发时间（24小时制）

### 5.2 注册定时任务

```powershell
powershell -ExecutionPolicy Bypass -File 不用积分\scripts\register_task.ps1
```

注册后每日 05:00 自动生成昨日报告。

### 5.3 手动运行

```powershell
powershell -ExecutionPolicy Bypass -File 不用积分\scripts\run_now.ps1
```

指定日期：

```powershell
powershell -ExecutionPolicy Bypass -File 不用积分\scripts\run_now.ps1 -TargetDate 20261013 -Force
```

### 5.4 状态查询

```powershell
powershell -ExecutionPolicy Bypass -File 不用积分\scripts\check_status.ps1
```

显示定时任务状态与目标日期报告是否就位。

### 5.5 卸载定时任务

```powershell
powershell -ExecutionPolicy Bypass -File 不用积分\scripts\unregister_task.ps1
```

> **重要**：修改执行时间后必须重新运行 `register_task.ps1` 注册任务。

## 六、运行模式说明

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| `oneshot` | 正则一键生成（默认） | 日常使用，零成本 |
| `ai_api` | AI API 增强六要素 | 有 AI API 凭据时 |
| `staged` | 分阶段生成 | 需要中间产物调试时 |

三种模式核心生成流程统一，质量一致。

## 七、输出说明

报告归档路径：

```
归档\{年}年{月}月\新闻联播总结_{YYYYMMDD}.md
```

报告结构（七部分）：
1. 基调概述
2. 新闻速览（含联播快讯合集标注）
3. 重点新闻详解
4. 联播快讯详解（展开子条目）
5. 完整性检测与播放时间
6. 新闻六要素索引（含合集行+子条目）
7. 占位符统合信息

## 八、常见问题与排障

### 8.1 编码乱码

PowerShell 控制台显示乱码是编码问题，不影响报告内容。设置环境变量：

```powershell
$env:PYTHONIOENCODING = "utf-8"
```

### 8.2 Python 解释器路径错误

确认 `config.json` 中 `python_exe` 为完整绝对路径，且文件存在。

### 8.3 报告已存在跳过生成

报告 >10KB 时自动跳过重生成。如需重建，加 `--force`。

### 8.4 联播快讯子条目为空

若第四部分显示"暂无快讯数据"，可能是央视网页面结构变化。检查 `fetch_xwlb.py` 的 `fetch_kuaixun_details` 解析逻辑。

### 8.5 CNTV 接口返回条数不足

CNTV 栏目接口对历史日期可能只返回2条。系统会自动回退央视网日页补全，无需手动处理。

### 8.6 质检退出码非零

- 退出码 1（ERROR）：结构缺陷，检查报告第七部分子节是否齐全
- 退出码 2（CRITICAL）：致命问题，检查章节完整性与表头

## 九、部署避坑清单

1. **Python 版本**：需 3.10+，低版本可能不支持某些语法
2. **requests 库**：必须安装，否则无法抓取
3. **目录路径**：含中文路径需确保系统编码支持 UTF-8
4. **定时任务**：需管理员权限注册 schtasks
5. **网络环境**：需能访问 tv.cctv.com 和 v.iqilu.com
6. **归档目录**：月份目录不存在时自动创建，无需手动建
7. **双方案共存**：智能体精读方案与纯脚本方案共用归档路径，通过已有报告保护机制避免互相破坏
