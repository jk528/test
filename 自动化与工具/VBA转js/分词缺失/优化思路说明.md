# 分词缺失 VBA 代码分析与优化说明

## 一、项目概述

本项目包含两个 VBA 模块，用于 Excel 中的组合数学分析：

| 文件 | 功能 | 核心算法 |
|------|------|----------|
| PC_005_分词和缺失.bas | 文本分词 / 组合缺失分析 | 二进制枚举所有切分/保留方案 |
| PC_006_分拆示意图.bas | 整数分拆统计（干/支） | 递归生成无序/有序分拆 + 频率匹配 |

---

## 二、PC_005 逻辑分析

### 2.1 核心思路

**单格模式（文本分词）**：
- 对长度为 n 的文本，有 n-1 个可切分位置
- 用二进制数枚举所有 2^(n-1) 种切分方案
- `1` = 在该位置插入分隔符 `|`（表示"缺失"）
- `0` = 不切分
- 输出：二进制组合 | 分词结果 | 缺失位置数

**多格模式（组合缺失）**：
- 对 m 个数据项，用二进制枚举所有 2^m 种保留/缺失方案
- `0` = 保留该项，`1` = 缺失该项
- 输出：二进制组合 | 保留项 | 缺失项 | 缺失数量

### 2.2 发现的问题

| # | 问题 | 严重度 | 说明 |
|---|------|--------|------|
| 1 | 变量在循环内 Dim | 低 | VBA 不支持块级作用域，全部 hoist 到函数级，循环内 Dim 易误导阅读者 |
| 2 | Application.Index 提取列 | 中 | 对大数组有隐式计算开销，直接循环赋值更快 |
| 3 | GetFlattenedArray 维度检测 | 高 | 用 `On Error` 检测 `rng.Value2(1,2)` 判断二维，逻辑脆弱不可靠 |
| 4 | 字符串循环拼接 | 中 | `tokenResult = tokenResult & ...` 在循环中是 O(n²) 操作 |
| 5 | LogExecutionTime 空行定位 | 高 | `UsedRange.Rows.Count` 在有格式无数据时偏移错误 |
| 6 | 缺少空文本/单字符校验 | 低 | 边界情况未处理 |

### 2.3 优化措施

1. **变量声明集中到顶部**：所有 Dim 移至过程开头，符合 VBA 最佳实践
2. **新增 ExtractColumn 函数**：直接循环提取二维数组的指定列，替代 `Application.Index`
3. **重写 GetFlattenedArray**：用 `Rows.Count` / `Columns.Count` 显式判断一维/二维，不再依赖错误捕获
4. **单格分词用 数组+Join**：先写入 `strParts()` 数组，最后 `Join(strParts, "")` 一次拼接，从 O(n²) 降到 O(n)
5. **修正 LogExecutionTime**：用 `Cells(Rows.Count, 1).End(xlUp).Row + 1` 定位空行，标准且可靠
6. **增加边界校验**：空文本提示退出、单字符提示退出

## 三、PC_006 逻辑分析

### 3.1 核心思路

**数学概念**：
- 无序分拆（"干"）：n 的分拆中不区分顺序，如 3+2 和 2+3 视为相同
- 有序分拆（"支"）：n 的分拆中区分顺序，如 3+2 和 2+3 视为不同
- 频率键：分拆中各数字出现次数的规范化表示，如 "1+2+2" → "1:1,2:2"

**算法流程**：
1. 递归生成 n 的所有无序分拆（保证非递增顺序，避免重复）
2. 递归生成 n 的所有有序分拆（每项从 1 到剩余值遍历）
3. 对有序分拆按"频率键+项数"分组存入字典
4. 遍历每个无序分拆，用相同的频率键+项数查找匹配的有序分拆集合
5. 输出：干 | 项数 | 词频(匹配数) | 支(所有匹配的有序分拆)

### 3.2 发现的问题

| # | 问题 | 严重度 | 说明 |
|---|------|--------|------|
| 1 | **Sort2DArray 函数缺失** | **致命** | 代码调用了 `Sort2DArray` 但从未定义，运行必报错 |
| 2 | 变量在循环内 Dim | 低 | 同 PC_005 |
| 3 | 输入校验不完整 | 中 | 提示"不能大于15"但未实际校验上限 |
| 4 | 错误处理几乎为空 | 中 | RunDemo 的 ErrorHandler 为空体，DemoPartition 无错误处理 |
| 5 | partition 函数未使用 | 低 | 五边形数定理函数定义了但从未调用 |

### 3.3 优化措施

1. **补充 Sort2DArray 函数**：实现选择排序，按指定列升/降序排列二维数组，修复致命缺陷
2. **变量声明集中到顶部**：所有 Dim 移至过程开头
3. **完善输入校验**：检查 `n >= 1 And n <= 15`，非法输入给出明确提示
4. **完善错误处理**：两个 Sub 均添加 `On Error GoTo ErrorHandler` 和错误提示
5. **移除未使用的 partition 函数**：精简代码，如需可单独保留为工具模块
6. **数值转字符串显式化**：`CStr(i)` 替代隐式转换，避免类型歧义

## 四、优化前后对比

### PC_005

| 方面 | 优化前 | 优化后 |
|------|--------|--------|
| 列提取方式 | `Application.Index(arr, 0, col)` | `ExtractColumn` 直接循环 |
| 字符串构建 | 循环内 `&` 拼接 (O(n²)) | 数组 + `Join` (O(n)) |
| 维度检测 | `On Error` 捕获异常 | `Rows.Count` / `Columns.Count` 显式判断 |
| 空行定位 | `UsedRange.Rows.Count` (不可靠) | `End(xlUp).Row` (标准可靠) |
| 边界校验 | 仅长度上限 | 空文本 + 单字符 + 长度上限 |

### PC_006

| 方面 | 优化前 | 优化后 |
|------|--------|--------|
| Sort2DArray | **缺失（运行必崩）** | 选择排序实现 |
| 输入校验 | 仅提示不校验 | 完整范围校验 (1~15) |
| 错误处理 | 空体 / 无 | 完整 ErrorHandler |
| 未使用代码 | partition 函数残留 | 已移除 |
| 类型转换 | 隐式 | 显式 `CStr()` |

## 六、使用方式

1. 在 Excel VBA 编辑器中，通过 `文件 > 导入文件` 导入 `_optimized.bas` 文件
2. PC_005：选中单元格后运行 `分词和缺失分析`，单格触发分词模式，多格触发组合模式
3. PC_006：运行 `RunDemoWithCount`，输入 1~15 的整数生成分拆统计表
