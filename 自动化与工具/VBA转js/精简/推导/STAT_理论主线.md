## 一、核心思想

> 来源：`STAT_基分解思想总结.md` §一

### 1.1 直觉描述

人眼看到一张杂乱无章的图，会认为"无规律"。但这可能只是因为**信息过载**——大脑无法同时处理多个有规律的图层叠加。就像三束不同频率的光叠加成白光，看似无色，实际上包含了所有频率。

**关键问题**：给定一个看似无规律的叠加结果，能否找到一组"基础图元"，使得叠加结果恰好是这些图元的组合？

**答案是肯定的**——前提是找到正确的"基"和对应的"分解工具"。

### 1.2 数学本质（概念定义唯一处）

```
看似无规律的叠加态 f(x)  =  Σ_y g(y) · K(x,y)
                               ↓ 反演
有规律的基础层   g(y)  =  Σ_x f(x) · K⁻¹(x,y)
```

- f(x)：可观测的"叠加态"（看似无规律）
- g(y)：分解出的"基础层"（有规律）
- K(x,y)：叠加核（将基础层叠加成观测态的规则）
- K⁻¹(x,y)：反演核（从观测态分解出基础层的工具）

**不同领域有不同的 K 和 K⁻¹，但思想完全同构。**

## 二、各领域的"基础图元"

> 来源：`STAT_基分解思想总结.md` §二、§三

| 领域 | 基础图元（基） | 叠加操作 | 叠加出的东西 | 分解工具（反演） |
|------|--------------|---------|------------|----------------|
| 线性代数 | 基向量 e₁,e₂,...,eₙ | 线性组合 Σ cᵢeᵢ | 任意向量 | 矩阵求逆 |
| 傅里叶分析 | 正弦/余弦波 e^(iωt) | 积分叠加 | 任意周期信号 | 傅里叶逆变换 |
| 小波分析 | 母小波平移伸缩 | 离散叠加 | 任意信号（含局部特征） | 小波逆变换 |
| 图论-圈空间 | 基本圈 basis cycles | XOR（对称差） | 任意偶子图 | 生成树分解 |
| 图论-割空间 | 基本割 basic cuts | XOR | 任意割集 | 割空间基分解 |
| 组合-排列 | 逆序对 / 循环 | 乘积叠加 | 任意排列 | 逆序表 / 循环分解 |
| 组合-子集 | 单元素集 {i} | 并集 | 任意子集 | 容斥原理 |
| **本文 T(N,k)** | **恰好 k 条共享边的排列** | **加权求和** | **E(N,j) 至少 j 条** | **二项式反演** |

### 图论中的基础图元清单（7 大类）

| 编号 | 基础图元 | 计数公式 | 生成什么 | 维数/大小 |
|------|---------|---------|---------|----------|
| 1 | **生成树** (Spanning Trees) | Cayley: n^(n-2) | 连接所有顶点的极小子图 | n-1 条边 |
| 2 | **完美匹配** (Perfect Matchings) | — | 2-正则偶子图 | n/2 条边 |
| 3 | **Hamilton 圈** | n!/2 (无向) | 经过所有顶点的圈 | n 条边 |
| 4 | **k-匹配** (k-matchings) | C_n 的 k-matchings = A034807 | k 条互不相邻边 | k 条边 |
| 5 | **k-因子** (k-factors) | — | k-正则生成子图 | kn/2 条边 |
| 6 | **圈空间基** (Cycle Basis) | m-n+1 个基本圈 | 所有偶子图 (GF(2) 向量空间) | m-n+1 维 |
| 7 | **独立集 / 团** | — | 互不相邻顶点 / 两两相邻顶点 | 变化 |

### 圈空间的基分解（最直接的图论实例）

```
任意图 G 的圈空间 = GF(2) 上的向量空间
  维数 = m - n + 1  (m=边数, n=顶点数)
  基 = 基本圈组 (由生成树 + 每条非树边生成)

分解算法：
  1. 取一棵生成树 T
  2. 对每条非树边 e，T+e 形成唯一基本圈 C_e
  3. 所有 C_e 构成圈空间的一组基
  4. 图中任何圈 = 某些基本圈的 XOR 叠加
```

## 三、容斥原理 = 组合学中的"傅里叶变换"

> 来源：`STAT_基分解思想总结.md` §四

### 3.1 叠加-反演结构

```
【叠加态】E(N,j) = Σ_{k≥j} C(k,j) · T(N,k)     ← "至少 j 条边"的总和
                     ↓ 二项式反演 (Möbius 反演的特例)
【基础层】T(N,k) = Σ_{j≥k} (-1)^{j-k} · C(j,k) · E(N,j)  ← "恰好 k 条边"
```

### 3.2 类比傅里叶变换

| 傅里叶变换 | 容斥原理 |
|-----------|---------|
| 时域信号 f(t) | 叠加统计量 E(N,j) |
| 频域频谱 F(ω) | 基础分布 T(N,k) |
| 正变换：f(t) = Σ F(ω)·e^(iωt) | 叠加：E(N,j) = Σ C(k,j)·T(N,k) |
| 逆变换：F(ω) = Σ f(t)·e^(-iωt) | 反演：T(N,k) = Σ (-1)^(j-k)·C(j,k)·E(N,j) |
| 正弦波 e^(iωt) | 二项式系数 C(k,j) |
| 频率 ω | 共享边数 k |
| 频谱强度 F(ω) | 排列数 T(N,k) |
| Parseval 恒等式 | 行和恒等式 Σ T(N,k) = N! |

### 3.3 为什么"看似无规律"？

E(N,j) 是一个单调递减序列（j 越大，至少含 j 条边的排列越少），看起来没有特别的结构。但反演后的 T(N,k) 却有丰富的规律：

- T(N,N) = 2N（满分排列恰好 2N 个）
- T(N,N-1) = 0（缺一条边不可能）
- T(N,0) 有闭式（C_N 补图的 Hamilton 圈数）
- 峰值稳定在 k=2

**"无规律"只是叠加态的表象，反演后的基础层才是真正的规律所在。**

## 四、基分解 vs 容斥原理：完整对比

> 来源：`STAT_基分解vs容斥原理对比.md` §一~§八

### 4.1 核心定义对比

| 维度 | 基分解 (Basis Decomposition) | 容斥原理 (Inclusion-Exclusion) |
|------|----------------------------|-------------------------------|
| **一句话定义** | 将复杂对象表示为"基元素"的线性组合 | 通过"至少满足"的计数反演出"恰好满足"的计数 |
| **数学本质** | 线性代数：在向量空间中选一组基 | 组合反演：在偏序集上做 Möbius 变换 |
| **解决的问题** | "这个复杂结构由哪些简单结构组成？" | "恰好满足某条件的对象有多少个？" |
| **方向** | 基元素 → 叠加 → 复杂对象（正向） | 叠加统计 → 反演 → 精确计数（逆向） |
| **理论框架** | 线性空间 / 模 / 格 | Möbius 反演（偏序集上的反演） |
| **对偶关系** | 基 ↔ 对偶基 | 叠加核 K ↔ 反演核 K⁻¹ |

### 4.2 公式对比

| 公式维度 | 基分解 | 容斥原理 |
|---------|-------|---------|
| **叠加公式** | f = Σᵢ cᵢ · bᵢ （bᵢ=基, cᵢ=系数） | E(j) = Σ_{k≥j} C(k,j) · T(k) |
| **反演公式** | cᵢ = ⟨f, bᵢ⟩ / ⟨bᵢ, bᵢ⟩（投影） | T(k) = Σ_{j≥k} (-1)^{j-k} · C(j,k) · E(j) |
| **叠加核 K** | 基矩阵 B 的列向量 | 二项式系数 C(k,j) |
| **反演核 K⁻¹** | B⁻¹（逆矩阵） | (-1)^{j-k} · C(j,k) |
| **恒等验证** | B · B⁻¹ = I | Σ_j (-1)^{j-k}·C(j,k)·C(k,j') = δ(k,j') |
| **Parseval 类比** | ‖f‖² = Σ ‖cᵢ‖²（正交基） | Σ_k T(N,k) = N!（行和恒等式） |

### 4.3 构成要素对比

| 要素 | 基分解 | 容斥原理 |
|------|-------|---------|
| **基础图元** | 基向量 / 基本圈 / 正弦波 | T(N,k)（恰好 k 条边的排列数） |
| **叠加态** | 任意向量 / 任意偶子图 / 任意信号 | E(N,j)（至少 j 条边的排列数） |
| **叠加操作** | 线性组合 Σ cᵢbᵢ / XOR 对称差 | 加权求和 Σ C(k,j)·T(k) |
| **分解工具** | 矩阵求逆 / Gram-Schmidt / 生成树 | 二项式反演 / Möbius 反演 |
| **基的维数** | dim(V) = 基元素个数 | N+1（k=0,1,...,N 共 N+1 层） |
| **基的正交性** | ⟨bᵢ,bⱼ⟩ = 0 (i≠j) | Σ_j (-1)^{j-k}C(j,k)C(k,j') = [k=j'] |
| **系数含义** | cᵢ = f 在 bᵢ 方向的投影 | T(N,k) = E 在"恰好 k 层"的投影 |

### 4.4 应用场景对比

| 应用 | 基分解 | 容斥原理 |
|------|-------|---------|
| **图论-圈空间** | 圈空间分解（m-n+1 个基本圈生成所有偶子图） | 共享边数分布 T(N,k) |
| **图论-着色** | 色多项式的基展开 | 色多项式 P(G,q) = Σ(-1)^j·a_j·q^{n-j} |
| **计数** | 生成函数系数分解 | 错位排列 D(n) = n!·Σ(-1)^k/k! |
| **概率** | 概率空间的正交分解 | 恰好 k 次成功 = Σ(-1)^{j-k}C(j,k)P(≥j) |
| **数论** | 整数环的基分解 | φ(n) = Σ_{d\|n} d·μ(n/d) |
| **线性代数** | 任意向量 = 基向量线性组合 | — |
| **信号处理** | 任意信号 = 正弦波叠加 | — |
| **组合设计** | 区组设计的基分解 | 恰好覆盖计数 |

### 4.5 计算复杂度对比

| 维度 | 基分解 | 容斥原理 |
|------|-------|---------|
| **正向（叠加）** | O(n²)（矩阵-向量乘法） | O(N²)（E(N,j) 求和） |
| **逆向（反演）** | O(n³)（矩阵求逆）或 O(n²)（已知逆） | O(N²)（二项式反演） |
| **存储** | O(n²)（基矩阵） | O(N²)（E 和 T 数组） |
| **瓶颈** | 基的构造（如最小圈基 NP-hard） | E(N,j) 的闭式推导（需组合洞察） |
| **本文 T(N,k)** | DP 枚举 O(2^N·N³) | 闭式公式 O(N²) |
| **精度** | 浮点误差可能累积 | 交替符号导致大数相消 |

### 4.6 局限性对比

| 局限 | 基分解 | 容斥原理 |
|------|-------|---------|
| **存在性** | 需要线性空间结构，非所有对象都有基 | 需要偏序集结构，非所有问题都有自然偏序 |
| **基的选择** | 基不唯一，不同基效率不同 | 偏序集固定时反演核唯一 |
| **数值稳定性** | 病态矩阵导致不稳定 | 交替符号可能导致大数相消 |
| **精度问题** | 浮点误差累积 | 大 N 时中间项远大于结果（如 N! vs T(N,0)） |
| **构造难度** | 最小权圈基 NP-hard | E(N,j) 闭式推导需要组合洞察 |
| **可扩展性** | 维度高时存储爆炸 | N 大时精度溢出 |

## 五、统一理论框架：Möbius 反演

> 来源：`STAT_基分解思想总结.md` §六 + `STAT_基分解vs容斥原理对比.md` §九 + `STAT_Möbius反演文献综述.md` §1.2

### 5.1 一般表述

在任意局部有限偏序集 (P, ≤) 上：

```
叠加：g(x) = Σ_{y≤x} f(y)          ← 对所有 y ≤ x 求和
反演：f(x) = Σ_{y≤x} μ(y,x)·g(y)   ← Möbius 函数 μ 加权求和
```

其中 μ 是偏序集的 Möbius 函数，满足：
- μ(x,x) = 1
- Σ_{x≤z≤y} μ(x,z) = 0 (if x < y)

### 5.2 不同偏序集下的特例（概念定义唯一处）

| 偏序集 P | 叠加核 K(x,y) | 反演核 K⁻¹(x,y) | 名称 | 图论应用 |
|---------|-------------|----------------|------|---------|
| 子集格 2^S (A⊆B) | 1 (恒等) | (-1)^(|B|-|A|) | **容斥原理** | 子图计数 |
| 整数 divisibility (d|n) | 1 | μ(n/d) (经典 Möbius 函数) | **数论 Möbius 反演** | 因子计数 |
| 区间 [k] ⊆ [j] | C(k,j) | (-1)^(j-k)·C(j,k) | **二项式反演** | **本文 T(N,k)** |
| 分拆格 Π_n | 1 | μ(π,σ) (分拆 Möbius 函数) | **分拆反演** | 连通分量 |
| Bond lattice L(G) | 1 | μ(H,G) | **图反演** | 色多项式 |
| 子图格 | 1 | μ(H,H') | **子图反演** | Tutte 多项式 |
| 向量空间 | 基矩阵 B | B⁻¹ | **线性代数** | 圈空间分解 |

### 5.3 统一公式

```
所有分解/反演都遵循同一模式：

  叠加：f(x) = Σ_y g(y) · K(x,y)        ← 从基础层到叠加态
  反演：g(y) = Σ_x f(x) · K⁻¹(x,y)      ← 从叠加态恢复基础层

  其中 K · K⁻¹ = I（恒等）

不同领域的 K 和 K⁻¹：
  线性代数：  K = B (基矩阵),         K⁻¹ = B⁻¹ (逆矩阵)
  傅里叶：    K = e^(iωt),           K⁻¹ = e^(-iωt) / N
  容斥：      K = 1,                 K⁻¹ = (-1)^(j-k)
  二项式：    K = C(k,j),            K⁻¹ = (-1)^(j-k) · C(j,k)
  数论：      K = 1,                 K⁻¹ = μ(n/d)
  图格：      K = 1,                 K⁻¹ = μ(H,G)
```

### 5.4 三层应用框架

> 来源：`STAT_Möbius反演文献综述.md` §1.1

| 层次 | 数学结构 | 核心问题 | 基分解 vs 反演 | 代表文献 |
|------|---------|---------|---------------|---------|
| **圈空间层** | GF(2) 向量空间 | 任意偶子图 = 哪些基本圈的 XOR？ | 纯线性基分解（无需反演） | Radcliffe, Kavitha 综述 |
| **格论层** | Bond lattice / 子图偏序集 | 从"至少含 H"反演"恰好含 H" | Möbius 函数 μ(G,H) 加权反演 | Tutte, Whitney, Rota |

## 六、本文 T(N,k) 的定位

> 来源：`STAT_基分解思想总结.md` §五 + `STAT_Möbius反演文献综述.md` §6.3

### 6.1 T(N,k) 就是一次完整的"谱分解"

```
基础图元族 = 所有 n!/2 条无向 Hamilton 圈（K_n 中的"基"）
参考图      = C_N（一条固定的 n 圈）
叠加统计量  = E(N,j)（至少含 j 条 C_N 边的 Hamilton 圈数）
反演结果    = T(N,k)（恰好含 k 条 C_N 边的 Hamilton 圈数）

→ T(N,k) 就是 Hamilton 圈族在 C_N 上的"频谱分布"
```

### 6.2 闭式公式 = "解析频谱"

```
f(N,j,b) = N/b · C(j-1,b-1) · C(N-j-1,b-1)    ← Kaplansky 环上组合

E(N,j) = N · (N-j-1)! · Σ_b f(N,j,b) · 2^b    ← 叠加态闭式

T(N,k) = Σ_{j=k}^{N} (-1)^{j-k} · C(j,k) · E(N,j)   ← 反演频谱
```

### 6.3 算法演进 = "计算方法的升级"

```
全排列枚举  O(N!)       → 逐个采样"波形"    (STAT_001)
位掩码 DP   O(2^N·N³)  → 离散采样"频谱"    (STAT_006)
闭式公式    O(N²)       → 解析计算"频谱"    (STAT_008)
```

### 6.4 学术定位

| 定位维度 | 描述 |
|---------|------|
| **数学结构** | 二项式反演在 Hamilton 圈族上的应用 |
| **偏序集** | 自然数链 {0,1,...,N}（最简单的偏序集） |
| **叠加核** | C(k,j)（二项式系数） |
| **反演核** | (-1)^{j-k}·C(j,k) |
| **基元素** | T(N,k)（恰好 k 条共享边的排列数） |
| **参考圈** | C_N（固定的 n 圈） |
| **图论联系** | Bond lattice 上 Möbius 函数的投影 |
| **算法价值** | O(N²) 闭式 vs O(2^N·N³) DP |
| **新意** | 首次给出共享边数分布的完整闭式 |

## 八、核心公式速查

> 来源：`STAT_基分解vs容斥原理对比.md` §十

### 8.1 基分解公式

```
线性代数：
  f = Σᵢ cᵢ · bᵢ                    ← 向量 = 基的线性组合
  cᵢ = ⟨f, bᵢ⟩ / ⟨bᵢ, bᵢ⟩         ← 系数 = 投影

图论圈空间：
  任意偶子图 = XOR(某些基本圈)        ← GF(2) 叠加
  基本圈 C_e = e + path_T(e)         ← 非树边 + 树路径
  dim(C(G)) = m - n + c              ← 圈空间维数

傅里叶：
  f(t) = Σ F(ω) · e^(iωt)           ← 信号 = 正弦波叠加
  F(ω) = (1/N) Σ f(t) · e^(-iωt)   ← 频谱 = 逆变换
```

### 8.2 容斥原理公式

```
基本容斥：
  |A₁∩A₂| = |A₁| + |A₂| - |A₁∪A₂|
  |A₁∩A₂∩A₃| = |A₁|+|A₂|+|A₃| - |A₁∪A₂|-|A₁∪A₃|-|A₂∪A₃| + |A₁∪A₂∪A₃|

一般容斥：
  |恰好 0 性质| = Σ_{k=0}^{n} (-1)^k · (至少 k 性质)

二项式反演：
  E(j) = Σ_{k≥j} C(k,j) · T(k)                    ← 至少 j = Σ 恰好 k 的加权
  T(k) = Σ_{j≥k} (-1)^{j-k} · C(j,k) · E(j)      ← 恰好 k = Σ 至少 j 的交替和

本文 T(N,k)：
  E(N,j) = N · (N-j-1)! · Σ_b f(N,j,b) · 2^b      ← 至少 j 条 C_N 边
  T(N,k) = Σ_{j=k}^{N} (-1)^{j-k} · C(j,k) · E(N,j)  ← 恰好 k 条 C_N 边
  f(N,j,b) = N/b · C(j-1,b-1) · C(N-j-1,b-1)      ← Kaplansky 环上组合
```

### 8.3 Möbius 反演公式

```
一般偏序集 (P, ≤)：
  g(x) = Σ_{y≤x} f(y)                    ← 叠加
  f(x) = Σ_{y≤x} μ(y,x) · g(y)          ← 反演

  μ(x,x) = 1
  Σ_{x≤z≤y} μ(x,z) = 0   (if x < y)

数论特例：
  g(d) = Σ_{d|e|n} f(e)                  ← 叠加
  f(d) = Σ_{d|e|n} μ(n/e) · g(e)        ← 反演

图格特例：
  N_≥(H) = Σ_{G'⊇H} N_=(G')             ← 叠加
  N_=(G) = Σ_{G'⊇H} μ(H,G') · N_≥(G')  ← 反演
```

## 九、哲学总结

> 来源：`STAT_基分解思想总结.md` §七

### 9.1 "无规律"的本质

```
无规律 = 多个有规律信号的叠加，超出认知处理能力
```

- 白光 = 所有频率可见光叠加 → 看似"无色"
- 噪声 = 所有频率声波叠加 → 听似"无音"
- E(N,j) 递减序列 = 多个 T(N,k) 层加权叠加 → 看似"无结构"

### 9.2 "找出基础图"的含义

```
找出基础图 = 找到一组基 (basis)，使得分解可行
```

- 傅里叶：找正弦波基 → 分解出频率谱
- 图论：找生成树 → 分解出基本圈
- 组合：找恰好层 T(N,k) → 分解出精确分布

### 9.3 "分解工具"的统一性

```
所有分解工具都是 Möbius 反演的特例：
  傅里叶逆变换  ↔  容斥原理  ↔  二项式反演  ↔  生成树分解
```

它们在数学上是**完全同构**的——都是"从叠加态恢复基础层"的操作。

### 9.4 核心公式总结

```
┌──────────────────────────────────────────────────────┐
│                                                      │
│   叠加态 f(x) = Σ_y g(y) · K(x,y)                   │
│                                                      │
│   基础层 g(y) = Σ_x f(x) · K⁻¹(x,y)                 │
│                                                      │
│   其中 K · K⁻¹ = I (恒等)                            │
│                                                      │
│   容斥：K = 1,          K⁻¹ = (-1)^(j-k)            │
│   二项式：K = C(k,j),    K⁻¹ = (-1)^(j-k)·C(j,k)    │
│   傅里叶：K = e^(iωt),   K⁻¹ = e^(-iωt) / N         │
│                                                      │
└──────────────────────────────────────────────────────┘
```

## 十二、一句话总结

> **容斥原理就是组合学中的傅里叶变换——它把"看似无规律的叠加统计量"分解成"有规律的基础分布层"，正如傅里叶变换把白光分解成彩虹。**

```
基分解（空间视角）  ←→  容斥原理（计数视角）
         ↕
    Möbius 反演（统一框架）
         ↕
  叠加: f = Σ g·K    反演: g = Σ f·K⁻¹
```
