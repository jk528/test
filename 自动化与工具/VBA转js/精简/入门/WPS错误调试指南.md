# WPS VBA 错误日志与调试指南

> 在 WPS 中运行修复后的代码，如何定位报错模块
> 日期：2026-08-12

---

## 一、快速定位报错模块

### 方法 1：使用测试模块（推荐）

1. 在 WPS VBA 编辑器中导入 `STAT_000_测试数据生成.bas`
2. 运行 `演示_一键测试`
3. 查看「测试报告」工作表：

```
模块                    状态    耗时(秒)   备注
STAT_008 闭式公式       PASS    0.015     T(N,N)=2N 验证通过
STAT_006 总表特点分析   FAIL              错误: 变量未定义 (错误号 91)
STAT_005 公式验证       PASS    0.008
STAT_001 全组合环形相邻 PASS    2.341
```

FAIL 行的「备注」列会显示具体错误号和错误描述。

### 方法 2：使用安全调用包装器

在 VBA 编辑器的「立即窗口」中输入：

```
Call 安全调用("STAT_008", "演示_闭式公式")
```

如果报错，会自动：
1. 弹窗显示错误号 + 描述
2. 在「错误日志」工作表记录详细信息

### 方法 3：逐模块手动运行

在 VBA 编辑器中，按 F5 运行各模块的 `演示_xxx` 入口，记录哪个模块报错。

## 二、WPS VBA 调试技巧

### 2.1 开启「遇到错误中断」

1. VBA 编辑器 → 工具 → 选项 → 通用
2. 勾选「在所有错误处中断」（Break on All Errors）
3. 运行代码，出错时自动停在报错行

### 2.2 使用「立即窗口」查看变量

1. 视图 → 立即窗口（或 Ctrl+G）
2. 出错暂停时，在立即窗口输入：

```
? N          ' 查看当前 N 值
? k          ' 查看当前 k 值
? Err.Number ' 查看错误号
? Err.Description ' 查看错误描述
```

### 2.3 使用「监视窗口」跟踪变量

1. 调试 → 添加监视
2. 输入要监视的变量名（如 `N`、`freq`）
3. 运行时实时查看变量值变化

### 2.4 使用「本地窗口」查看所有局部变量

1. 视图 → 本地窗口
2. 出错暂停时，展开本地窗口中的变量树

## 三、常见错误号对照表

| 错误号 | 含义 | 可能原因 | 修复方法 |
|--------|------|---------|---------|
| 5 | 过程调用或参数无效 | 参数越界 | 检查 N 值范围 |
| 9 | 下标越界 | 数组索引超出范围 | 检查 ReDim 和访问索引 |
| 11 | 除以零 | fVal 计算中 c=0 | 检查循环起始值 |
| 13 | 类型不匹配 | Variant 混合类型运算 | 用 CDec() 显式转换 |
| 91 | 对象变量未设置 | Set 语句缺失或失败 | 检查 CreateObject |
| 35 | 子程序或函数未定义 | 缺少依赖模块 | 导入所有 9 个 .bas 文件 |
| 458 | 变量使用了 VB 不支持的类型 | Decimal 在某些 WPS 版本限制 | 改用 Double |
| 1004 | 应用程序定义或对象定义错误 | 工作表操作失败 | 检查工作表是否存在 |
| vbObjectError+1~6 | 自定义测试错误 | 测试函数主动抛出 | 查看错误描述中的 N 值 |

## 四、错误日志工作表

### 4.1 自动记录

运行 `安全调用` 或 `演示_一键测试` 时，所有错误自动写入「错误日志」工作表：

| 时间 | 模块 | 错误号 | 错误描述 | 附加信息 |
|------|------|--------|---------|---------|
| 2026-08-12 20:15:33 | STAT_008 | 91 | 对象变量未设置 | 过程: 演示_闭式公式 |

### 4.2 手动记录

在任意 VBA 代码中插入：

```vba
On Error GoTo MyHandler
' ... 你的代码 ...
Exit Sub

MyHandler:
    Call 写入错误日志("我的模块", Err.Number, Err.Description, "当前 N=" & N)
    Resume Next
```

## 五、分模块排查清单

如果 `演示_一键测试` 报告某模块 FAIL，按以下步骤排查：

### STAT_001 失败

```
检查项：
□ STAT_001 模块是否已导入
□ 工作表「测试数据」是否存在
□ N 值是否 ≤ 8（大 N 会很慢）
□ 是否有其他模块的同名函数冲突
```

### STAT_005/STAT_006 失败

```
检查项：
□ STAT_008 是否已导入（STAT_005/006 依赖 getT_closed）
□ STAT_001 是否已导入（STAT_006 依赖统计环形相邻词频）
□ getT_dp 函数是否存在（STAT_006 的 DP 函数）
```

### STAT_007 失败

```
检查项：
□ Dictionary 对象是否可创建（CreateObject("Scripting.Dictionary")）
□ N 值是否 ≤ 15（大 N 内存不足）
□ 是否有 64 位/32 位兼容性问题
```

### STAT_008 失败

```
检查项：
□ N 值是否 ≤ 27（Decimal 精度上限）
□ CDec() 函数是否可用（某些 WPS 版本限制）
□ 组合数表 C(n,k) 是否溢出 Long（N > 12 时 C(N, N/2) 可能超限）
```

### 函数名冲突

如果多个模块有同名函数（如 `环形相邻计数_arr`），WPS 会报"二义性名称"。

```
解决方法：
1. VBA 编辑器 → 搜索同名函数
2. 保留一个版本，删除其余
3. 或在函数名前加模块前缀（如 STAT001_环形相邻计数_arr）
```

## 六、完整测试流程

```
步骤 1：导入所有 .bas 文件
  VBA 编辑器 → 文件 → 导入文件
  依次导入 9 个 .bas 文件

步骤 2：生成测试数据
  运行 → 生成测试数据
  确认「测试数据」工作表生成

步骤 3：一键测试
  运行 → 演示_一键测试
  查看「测试报告」工作表

步骤 4：如有 FAIL
  查看「错误日志」工作表
  对照本指南第三章排查
  或在立即窗口用 ? Err.Description 查看详情

步骤 5：逐模块深入测试
  Call 安全调用("STAT_008", "演示_闭式公式")
  Call 安全调用("STAT_006", "演示_总表特点分析")
  ...
```

## 七、导出错误日志

如果需要把错误日志分享或保存：

```vba
Sub 导出错误日志()
    Dim ws As Worksheet
    Set ws = Worksheets("错误日志")
    ws.Copy    ' 复制到新工作簿
    ActiveWorkbook.SaveAs "C:\错误日志_" & Format(Now, "yyyymmdd_hhnnss") & ".xlsx"
    MsgBox "错误日志已导出", vbInformation
End Sub
```
