## 2. 四象限：排列 × 组合、放回 × 不放回

排列组合的核心问题是：从 **n 个元素** 中取出 **k 个**，有几种取法。区别由两个维度决定：

- **顺序是否计入**：排列（顺序相关） vs 组合（顺序无关）
- **元素能否重复**：放回（可重复） vs 不放回（不可重复）

由此构成「四象限」：

| 类型 | 名称 | 公式 | 顺序 | 重复 | 镜像说法 |
| --- | --- | --- | --- | --- | --- |
| Type 1 | 组合不放回 | `C(n,k) = n! / (k!(n-k)!)` | 不计 | 不重复 | 去镜像 |
| Type 2 | 组合放回 | `C(n+k-1,k)` | 不计 | 可重复 | 去镜像 |
| Type 3 | 排列不放回 | `A(n,k) = n! / (n-k)!` | 计 | 不重复 | 镜像 |
| Type 4 | 排列放回 | `n^k` | 计 | 可重复 | 镜像 |

### «镜像 / 去镜像» 的直观含义

沿用 PC_001 的通俗说法：

- **去镜像（组合）**：`{A,B}` 与 `{B,A}` 视为同一种选择，不重复计数。
- **镜像（排列）**：`A→B` 与 `B→A` 视为两种，顺序被保留。

> 组合就是「去掉镜像后的排列」：`A(n,k) = C(n,k) × k!`，即先挑出 k 个（去镜像），再对 k 个做全排列（k!）。

### 放回与不放回的依据

- **不放回**：每个元素最多取一次，`k` 不能超过 `n`。
- **放回**：每次取后放回，元素可反复出现，数学上 `k` 可任意大；但为了矩阵规整与一致约定，PC_008 也限定 `k ≤ n` 才有意义（见下文约定）。

## 3. 「0 = 不可选择」统一约定

所有计数 / 枚举函数遵循同一约定：**任何类型，只要 `k > n`，数值为 0（不可选择）**；放回类型在 `n = 0` 且 `k > 0` 时同样返回 0。

| 情形 | 结果 |
| --- | --- |
| `k > n`（四种类型统一） | 计数 = 0；枚举 = 空 |
| `k = 0`（空选择） | 计数 = 1（恒有一种「什么都不选」） |
| `k < 0` 或参数非法 | 计数 = 0；枚举 = 空 |
| 放回类型 `n = 0` 且 `k > 0` | 计数 = 0；枚举 = 空 |

矩阵中 `k > n` 的格子填 `0`（不再留空，与三角矩阵的空白区分）。

## 4. 计数公式的底层实现

| 函数 | 算法 | 说明 |
| --- | --- | --- |
| `C(n,k)` | 乘法递推 `Π (n-k+i)/i` | 用 `Double`/`Math.round` 修正浮点，避免阶乘溢出；对称性 `C(n,k)=C(n,n-k)` 减少步数 |
| `A(n,k)` | 连乘 `n×(n-1)×…×(n-k+1)` | 直接乘积，避免 `n!/(n-k)!` 的中间溢出 |
| 组合放回计数 | 转化为 `C(n+k-1,k)` | 「n 类元素可重复取 k 个」等价于「n+k-1 取 k」的隔板法 |
| 排列放回计数 | `n^k` | 每位 n 种选法，共 k 位 |

> 隔板法直观解释（组合放回）：把 k 个球分配给 n 个盒子（可空），等价于在 `k + (n-1)` 个位置中选 `n-1` 个隔板，即 `C(k+n-1, n-1) = C(k+n-1, k)`。

## 5. 四大枚举算法的底层逻辑

枚举统一基于 **索引 `1..m`** 生成（不直接操作元素值），最后再把索引映射回真实元素。这样可天然输出「元素 + 映射」双列（映射 = 原位置索引）。

| 类型 | 算法 | 状态推进方式 | 复杂度 |
| --- | --- | --- | --- |
| 组合不放回 | 回溯法，索引严格递增 | `rec(start, depth)`，下一层从 `start+1` 开始，带上界 `m-(k-depth)` 剪枝 | O(C(n,k)·k) |
| 组合放回 | 非递减索引迭代 | 维护 `idx[1..k]`（初值全 1），末位 `<m` 则 +1 并让后续位跟随；否则向前进位 | O(C(n+k-1,k)·k) |
| 排列不放回 | 回溯 + `used` 标记 | 每层遍历 `1..m`，跳过已用，选后置 `used=true`，回溯置 `false` | O(A(n,k)·k) |
| 排列放回 | m 进制进位法 | 维护 `idx[1..k]`（初值全 1），末位 `<m` 则 +1，否则回 1 向前进位 | O(n^k · k) |

### 放回 vs 不放回 在枚举上的本质区别

- **不放回**：索引必须**互不相同**（组合是不降且严格递增；排列是不重复任意顺序）。
- **放回**：索引**允许重复**（组合是「非递减」即允许相等；排列是「每位独立」即完全自由）。

## 6. 范围输入的扁平化与去空

`RangeTo1DArrayOpt` / `flattenRange` 负责把用户选择的单元格范围变成一维元素数组：

1. **取 Value**：单格 → 标量；一行 / 一列 → 一维数组；矩形 → 二维数组。
2. **行 / 列优先**：二维区域询问用户
   - 行优先：逐行从左到右读取（先行后列）
   - 列优先：逐列从上到下读取（先列后行）
3. **去空选项**：`skipEmpty = true` 时，`Empty / Null / 空白字符串` 一律剔除；否则空字符串也视为一个元素。

扁平化得到元素数组 `arr[1..m]`，`m = 有效元素数`，后面枚举与映射都以此 `m` 为基准。

## 7. 元素与映射的双列输出（映射关系）

PC_004 的核心思想：**元素排列与索引排列一一对应**。

- 枚举函数只产出 **索引序列**，如 `[2, 1, 3]`。
- 输出时：
  - **元素列** = `arr[索引]`（把索引换回真实值）
  - **映射列** = 索引本身（`2, 1, 3`）

于是每一行结果同时展示「具体内容」和「它来自原数组的第几个位置」，便于追溯与复用。

> 例：`arr = [A, B, C]`，取 `k=2` 排列不放回，某行索引 `[2, 3]` →
> 元素列 `[B, C]`，映射列 `[2, 3]`。

## 8. 达式统一：矩阵

矩阵行 `n = 0..nMax`，列 `k = 0..nMax`，格子 = `count(n, k, type)`。

| 列 | 含义 |
| --- | --- |
| 第 1 列 | 总和 = Σ count(n,k)（该行的合计） |
| 第 2 列 | 总数 n |
| 第 3 列起 | 「选 k 个」对应的计数 |

由于「任何类型 `k > n → 0`」，矩阵中 `k > n` 区自动填 0，四种类型的行总和分别为：

- 组合不放回：Σ_k C(n,k) = **2^n**
- 组合放回：Σ_k C(n+k-1,k)（到 k=n 为止）
- 排列不放回：Σ_k A(n,k)
- 排列放回：Σ_k n^k

## 10. 安全防护（三层上限）

| 常量 | 值 | 作用 |
| --- | --- | --- |
| `MAX_ENUM` | 10,000,000 | 内存保护：枚举结果数量超过则拒绝生成 |
| `MAX_ROWS` | 1,048,576 | 写入保护：数据块最后一行超过工作表最大行数则跳过 |
| `MAX_COLS` | 16,384 | 写入保护：输出列数 `2k+1` 超过工作表最大列数则跳过 |

枚举入口还带 **溢出保护**：`n^k` 等超大值用 `isFinite / Err` 兜底，视为「超过上限」，不会中断运行。

## 11. 边界情况一览

| 输入 | 组合不放回 | 组合放回 | 排列不放回 | 排列放回 |
| --- | --- | --- | --- | --- |
| `n=0, k=0` | 1 | 0 | 1 | 1 |
| `n=0, k>0` | 0 | 0 | 0 | 0 |
| `n=5, k=0` | 1 | 1 | 1 | 1 |
| `n=5, k=5` | 1 | C(9,5) | 120 | 3125 |
| `n=3, k=5`（k>n） | 0 | 0 | 0 | 0 |

> 说明：组合放回 `n=0, k=0` 按统一约定（`n<1` 即不可选择）返回 0；矩阵中 `k=0` 列单独固定填 1，不受影响。
