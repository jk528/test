## 一、解决的问题

### 1.1 核心数学问题

计算一个新三角表 T(N,k)：N 个元素 {1,...,N} 的所有排列中，环形相邻对满足 `|a-b|=1 或 |a-b|=N-1`（即 C_N 圈图的边）恰好有 k 对的排列数。

**图论等价**：K_N 中随机 Hamilton 圈与参考圈 C_N 共享恰好 k 条边的排列数。

**应用背景**：对全排列进行环形相邻计数，统计词频分布，寻找数学规律，最终推导闭式公式。

## 二、遇见的困难

### 2.1 全排列枚举的阶乘爆炸

| 困难 | 说明 |
|------|------|
| **N! 增长极快** | N=10 → 3,628,800 次排列；N=15 → 1.3 万亿次，枚举不可行 |
| **VBA Heap 算法慢** | VBA 解释执行，N=10 需约 40 秒，N=15 预估 15 天 |
| **字典计数写入慢** | 逐排列计数后写入工作表，N=8 以上明显卡顿 |

### 2.2 DP 算法的内存爆炸

| 困难 | 说明 |
|------|------|
| **3D 数组太大** | `dp(2^N, N, N+1)` 在 N=15 时需 60MB，N=18 需 684MB |
| **VBA Long 限制** | 32 位有符号整数，bitmask 上限 N=30（但内存先爆炸） |
| **Double 精度限制** | IEEE 754 双精度只能精确到 2^53 ≈ 9×10^15，19! 超出 |
| **N=19 精度失效** | 19! = 1.22×10^17 超过 Double 精确上限，行和差 30 |

### 2.3 数学公式推导

| 困难 | 说明 |
|------|------|
| **无现成 OEIS 对应** | 与 A180188（升序环形继承数）有关联但非简单倍数 |
| **加法递推不成立** | T(N,k) ≠ α·T(N-1,k) + β·T(N-1,k-1)，无法像帕斯卡三角那样递推 |
| **容斥公式复杂** | E(N,j) 的计算需要环上路径组合计数，推导难度大 |
| **无标准学术名字** | 检索 OEIS + arXiv + 数学文献，未找到精确匹配的已有命名 |

### 2.4 VBA 环境限制

| 困难 | 说明 |
|------|------|
| **无 BigInt 类型** | VBA 最大数值类型 Decimal 上限 7.9×10^28，仅支持 N≤27 |
| **Dictionary 开销大** | 每个 Dictionary 条目约 100-150 字节开销，稀疏存储效率不如 JS |
| **32 位地址空间** | 32 位 WPS/Excel 地址空间约 2GB，大数组易溢出 |

### 2.5 学术定位困难

| 困难 | 说明 |
|------|------|
| **相关文献分散** | 涉及 Kaplansky 1943、Tutte 1954、Rota 1964、Barghi 2018、Yaqubi 2026 等跨年代跨领域 |
| **Möbius 反演门槛高** | 偏序集理论对非数学专业读者不友好，需要建立直观类比 |

## 三、再次解决的方法

### 3.1 阶段一：枚举 → DP（STAT_001 → STAT_006）

```
全排列枚举 O(N!)  →  位掩码 DP O(2^N · N³)
```

**方法**：固定起点 first=1（利用环形旋转对称性减少 N 倍），用 `dp[mask][last][c]` 记录已放置 mask、末元素 last、路径中 c 条满足条件相邻对的排列数。转移时枚举下一个未放置的元素 j，更新计数。

**效果**：N=10 从 3.6M 次枚举降到 127K 次 DP 转移，提速 28 倍。

### 3.2 阶段二：3D 数组 → 稀疏分层 DP（STAT_006 → STAT_007）

```
3D 数组 O(2^N · N²) 内存  →  分层 Dictionary O(C(N,N/2) · N) 内存
```

**方法**：按 popcount（已放置元素个数）分层推进，每层只保留当前层和下一层的非零状态。用 `Dictionary` 稀疏存储，key = `mask·(N+1)+last`，value = `Double(N+1)` 数组。

**效果**：

| N | 原始 DP 内存 | 稀疏 DP 内存 | 节省 |
|---|---|---|---|
| 15 | 60 MB | 10 MB | 6x |
| 18 | 684 MB | 100 MB | 7x |

### 3.3 阶段三：DP → 闭式公式（STAT_007 → STAT_008）

```
DP 枚举 O(2^N · N³)  →  闭式公式 O(N²)
```

**方法**：推导出环上选边组合数的闭式公式：

```
f(N,j,b) = N/b · C(j-1,b-1) · C(N-j-1,b-1)       ← Kaplansky 环上组合引理

E(N,j) = N · (N-j-1)! · Σ_b f(N,j,b) · 2^b        ← 至少 j 条边的排列数

T(N,k) = Σ_{j=k}^{N} (-1)^{j-k} · C(j,k) · E(N,j) ← 二项式反演：恰好 k 条边
```

关键洞察：选 j 条边形成 b 条路径段，每段有 2 个方向，排列数为 `N · 2^b · (N-j-1)!`。环上组合数公式 `f(N,j,b)` 将求和化为封闭形式。

**效果**：

| N | DP 耗时 | 闭式公式耗时 | 加速比 |
|---|---|---|---|
| 15 | 594ms | <0.1ms | ~6000x |
| 18 | 3.5s | 0.1ms | ~35000x |
| 100 | 不可行 | 2.3ms | ∞ |
| 500 | 不可行 | 248ms | ∞ |

### 3.4 精度问题的解决

| 范围 | 方案 | 精度 |
|------|------|------|
| N ≤ 18 | Double (64-bit IEEE 754) | 精确（18! < 2^53） |
| N ≤ 27 | VBA Decimal (96-bit) | 精确（27! < 7.9×10^28） |
| N 任意 | JS BigInt | 精确（无上限） |

### 3.5 学术定位的解决

通过系统检索 OEIS、arXiv、数学文献，确定：
- **最接近工作**：Yaqubi & Mirzavaziri, arXiv:2602.02046 (2026) — C_n 图型 r-Stirling 数
- **基础引理**：Kaplansky 1944 — 圆周选边分段
- **理论框架**：Rota 1964 — Möbius 反演
- **统一视角**：基分解 ↔ 容斥原理 ↔ Möbius 反演三者同构

### 3.6 理论深度拓展

从 T(N,k) 的具体计算延伸到数学哲学层面：
- **基分解思想**：看似无规律的整体 = 多个有规律的基础图元叠加
- **容斥 = 傅里叶变换**：E(N,j) 是"频域"，T(N,k) 是"频谱"，二项式反演是"逆变换"
- **Möbius 反演统一框架**：容斥/数论反演/二项式反演/图格反演都是偏序集上的特例
- **Python 可视化**：圈空间基分解的 XOR 叠加与还原演示

### 4.3 已证明的闭式公式

| 定理 | 公式 | 条件 |
|------|------|------|
| 满分定理 | T(N,N) = 2N | N ≥ 3 |
| 空缺定理 | T(N,N-1) = 0 | N ≥ 3 |
| 行和恒等式 | Σ_k T(N,k) = N! | 所有 N |
| Kaplansky 引理 | f(N,j,b) = N/b · C(j-1,b-1) · C(N-j-1,b-1) | 1 ≤ b ≤ min(j, N-j) |
| E(N,j) 闭式 | E(N,j) = N · (N-j-1)! · Σ_b f(N,j,b) · 2^b | 0 ≤ j ≤ N |
| 通用闭式 | T(N,k) = Σ_{j=k}^{N} (-1)^{j-k}·C(j,k)·E(N,j) | 所有 N, k |

### 4.6 关键结论

1. **T(N,N) = 2N**：满分排列只有 2 个方向 × N 个起点
2. **T(N,N-1) = 0**：N-1 条边覆盖所有 N 个点，闭合边唯一且恰是缺失边
3. **N=5 是唯一完美对称点**：T(5,k) 关于 k=N/2 对称
4. **峰值稳定在 k=2**：占比趋近 29%
5. **无加法递推**：与帕斯卡三角不同，本三角表不存在简单的 T(N,k) = f(T(N-1,*)) 递推关系
6. **与 OEIS A180188 的关系**：满分列 = 2 × A180188 满分值，但其他 k 无简单倍数关系
7. **容斥 = 傅里叶变换**：E(N,j) 是"频域叠加态"，T(N,k) 是"频谱基础层"，二项式反演是"逆变换"
8. **三层统一**：圈空间基分解（GF(2)）→ 图格 Möbius 反演 → 本文二项式反演，三者同源
