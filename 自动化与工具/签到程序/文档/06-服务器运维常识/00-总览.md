## 二、最重要的一页：端口三层模型

任何"网站打不开"的问题，都在这三层里，**按顺序查，不要跳**：

```
┌─────────────────────────────────────────────┐
│ 第 1 层  安全组（华为云控制台）              │  ← 云厂商的虚拟防火墙
│          实例级、与镜像无关、换系统也不会变   │
└───────────────────┬─────────────────────────┘
                    ↓ 放行了吗？
┌───────────────────▼─────────────────────────┐
│ 第 2 层  本机防火墙（ufw / firewalld）        │  ← 装在系统里的软件防火墙
│          由镜像/预装软件决定默认策略           │
└───────────────────┬─────────────────────────┘
                    ↓ 放行了吗？
┌───────────────────▼─────────────────────────┐
│ 第 3 层  进程监听（谁在占用这个端口）          │  ← 服务有没有真的跑起来
│          还分 0.0.0.0（对外）/ 127.0.0.1（仅本机）│
└─────────────────────────────────────────────┘
```

**口诀：安全组 → 本机防火墙 → 监听 → 绑定地址。**
四步都过，才可能从外网访问到。

## 五、十条最值钱的常识（先记住，细节查各篇）

1. **端口不是"开启/关闭"的开关**，而是"有没有进程监听 + 有没有被拦住"两件事。
2. 端口总数固定 **65536 个（0–65535）**，不是想加就加。
3. **安全组和镜像无关**。换系统镜像，安全组规则一条都不会变。
4. 云上"防火墙"有两道：安全组（云厂商）+ 本机防火墙（系统里）。**两道都要过**。
5. `0.0.0.0` 表示监听所有网卡（外网可能通），`127.0.0.1` 表示只听本机（外网永远不通）。
6. **同协议同端口只能一个进程占用**，第二个启动会报 `Address already in use`。
7. 1024 以下端口要 root 才能监听，所以 Web 服务常用 80/443，开发常用 8080/8000。
8. Linux 一切皆文件，改动前先 `cp xxx xxx.bak`，比任何"回滚方案"都可靠。
9. 排障顺序永远是 **状态 → 日志 → 端口 → 资源 → 网络**，不要凭猜。
10. **最小权限**：能只开自己 IP 就不要开 `0.0.0.0/0`，能只开一个端口就不要开一段。
