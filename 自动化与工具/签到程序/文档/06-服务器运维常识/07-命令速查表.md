# 07 · 命令速查表

> 一页装下日常 95% 的命令。不用背，用时翻。

---

## 一、连服务器

```powershell
ssh root@121.36.27.69                    # 登录（已配免密）
ssh -p 2222 root@IP                      # 非默认端口
exit                                     # 退出
ssh -V                                   # 查看本地是否有 ssh
ssh-keygen -t ed25519                    # 生成密钥
```

## 二、文件传输

```powershell
scp .\file.txt root@IP:/opt/             # 上传文件
scp -r .\folder root@IP:/opt/            # 上传目录
scp root@IP:/opt/log.txt .\              # 下载文件
```

## 三、目录与文件

```bash
pwd                      # 当前路径
ls -la                   # 详细列表（含隐藏）
cd /opt/game2048         # 进目录
cd ..                    # 上一级
mkdir -p /opt/app        # 建目录（含父级）
cp a b                   # 复制
cp a a.bak               # ★ 改文件前先备份
mv a b                   # 移动/改名
rm -f file               # 删文件
rm -rf dir               # 删目录（无回收站，慎用）
cat file                 # 看全文
less file                # 分页看（q 退出）
head -20 file            # 前 20 行
tail -f file             # ★ 实时跟日志
grep -n "关键词" file     # 按行查找
find /opt -name "*.js"   # 找文件
```

## 四、权限

```bash
chmod 755 script.js      # rwxr-xr-x
chmod 600 notify.conf    # rw------- （凭证专用）
chmod 644 index.html     # rw-r--r--
chown root:root file     # 改归属
ls -l                    # 看权限
```

## 五、进程与资源

```bash
ps aux | grep node                 # 找进程
ps aux --sort=-%mem | head         # 内存 TOP
kill PID                           # 优雅停止
kill -9 PID                        # 强制杀
top                                # 实时资源（q 退出）
uptime                             # 运行时长 + 负载
free -m                            # 内存（MB）
df -h                              # 磁盘
du -sh /opt/game2048               # 目录大小
```

## 六、服务（systemd）

```bash
systemctl status game2048          # 状态
systemctl start game2048           # 启动
systemctl stop game2048            # 停止
systemctl restart game2048         # 重启
systemctl enable --now game2048    # 开机自启 + 启动
systemctl disable game2048         # 取消自启
systemctl daemon-reload            # ★ 改 unit 后必执行
systemctl list-units --type=service --state=running
```

## 七、日志

```bash
journalctl -u game2048 -n 50        # 最近 50 行
journalctl -u game2048 -f           # 实时跟
journalctl -u game2048 --since today
journalctl -p err -n 50             # 只看错误
journalctl --disk-usage             # 日志占用
tail -f /opt/trae-checkin/checkin.log
```

## 八、端口与网络

```bash
ss -lntp                        # ★ 监听中的 TCP 端口 + 进程
ss -lnup                        # UDP
ss -lntp | grep :80             # 只看 80
lsof -i :8080                   # 按端口反查
curl -I http://127.0.0.1/       # 测 HTTP 响应头
curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1/
ping -c 3 baidu.com             # 通不通
nc -zv IP 8080                  # 测端口（需 netcat）
```

```powershell
Test-NetConnection 121.36.27.69 -Port 80     # ★ 外网连通性
tnc 121.36.27.69 -Port 80                    # 简写
Invoke-WebRequest http://IP/ -UseBasicParsing | Select StatusCode
```

## 九、防火墙

```bash
# Ubuntu / Debian（ufw）
ufw status                          # 看规则
ufw status numbered                 # 带编号
ufw allow 8080/tcp                  # 放行
ufw delete allow 8080/tcp           # 删除
ufw enable / disable                # 启用/停用

# CentOS / EulerOS（firewalld）
firewall-cmd --list-all
firewall-cmd --add-port=8080/tcp --permanent
firewall-cmd --reload

# 底层（宝塔/Docker 会改）
iptables -L -n
```

> 安全组不在系统里，只能去华为云控制台。

## 十七、十个"一秒钟定位"组合

| 我想知道 | 命令 |
|---|---|
| 网站为啥打不开 | `curl -I http://127.0.0.1/` |
| 谁占了 80 | `ss -lntp \| grep :80` |
| 外网到底通不通 | `Test-NetConnection IP -Port 80` |
| 服务为啥挂了 | `journalctl -u xxx -n 50` |
| 内存够不够 | `free -m` |
| 磁盘满了吗 | `df -h` |
| 谁最吃内存 | `ps aux --sort=-%mem \| head` |
| 定时任务在不在 | `crontab -l` |
| 文件权限对不对 | `ls -l 文件` |
| 端口是安全组挡的吗 | 本机 curl 通 + ufw 放行 + 外网不通 = 安全组 |

## 十八、危险命令（执行前先想三秒）

| 命令 | 后果 |
|---|---|
| `rm -rf /` 或 `rm -rf /*` | 系统报废 |
| `rm -rf 目录` | 无回收站，不可恢复 |
| `crontab -r` | 删光所有定时任务 |
| `systemctl disable --now ssh` | 断掉自己的 SSH 入口 |
| `chmod -R 777 /` | 权限体系崩坏 |
| `iptables -F` | 清空防火墙规则（可能被攻击） |
| `git reset --hard` | 丢弃未提交修改 |
| `> 文件` | 清空文件内容 |

**通用防护**：执行前先 `pwd` 确认位置、`cp` 备份、别在 `/` 下跑通配符。
