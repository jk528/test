# 01 · 云服务器基础常识

> 目标：搞清"我租的到底是什么东西"。看完能独立开通、登录、判断规格够不够、不踩计费坑。

---

## 一、云服务器到底是什么

一台**放在云厂商机房里、由你独占使用的虚拟电脑**。你在本地敲键盘，实际执行发生在机房那台机器上（通过 SSH 远程登录）。

| 对比项 | 物理服务器 | 云服务器（ECS） |
|---|---|---|
| 硬件 | 你买整台机器 | 虚拟化切出来的一份 |
| 开通 | 采购、上架、装系统，几天 | 控制台点几下，1–3 分钟 |
| 扩容 | 加内存条、换 CPU | 控制台改规格，重启生效 |
| 故障 | 自己修 | 提工单换机器 |
| 计费 | 一次性买断 | 按需（按小时）/ 包年包月 |

## 二、必懂的 9 个名词

| 名词 | 一句话解释 | 你要关心什么 |
|---|---|---|
| **实例** | 一台具体的云服务器 | 就是"这台机器"本身 |
| **镜像** | 装机用的系统模板（含预装软件） | 决定初始环境：纯净 or 带面板 |
| **规格** | CPU/内存组合，如 2vCPU/4GiB | 内存是新手最容易不够的 |
| **系统盘** | 装系统的盘，通常 40G | 不够就扩，别删系统文件 |
| **数据盘** | 额外挂的盘，需自己分区挂载 | 大数据才需要 |
| **VPC** | 虚拟私有网络（你专属的内网） | 一般默认建好，不用动 |
| **子网** | VPC 里划分的网段 | 一般默认，不用动 |
| **安全组** | 云厂商的虚拟防火墙 | **开端口必来这里**（见 04 篇） |
| **弹性公网 IP（EIP）** | 对外可访问的 IP，可绑定/解绑 | 不释放会继续计费 |

## 三、镜像怎么选（新手最容易选错的一步）

| 类型 | 说明 | 适合谁 |
|---|---|---|
| **公共镜像（纯净）** | 官方系统，什么都不装：Ubuntu / Debian / CentOS / EulerOS / Windows Server | **推荐**。干净、可控、教程通用 |
| **市场镜像（预装）** | 第三方打包，如"宝塔面板镜像""LAMP 镜像""WordPress 镜像" | 想 5 分钟建站、不介意预装一堆东西 |
| **私有镜像** | 你自己做的快照模板 | 批量部署同一环境 |
| **共享镜像** | 别人共享给你的 | 团队协作 |

**新手建议：选纯净 Ubuntu LTS 或 Huawei Cloud EulerOS。** 理由：
- 教程最多，出问题搜得到
- 没有预装软件抢端口（市场镜像常自动占 80/8888/3306）
- 出了问题知道是自己装的，好排查

> 本文这台就是**纯净 Ubuntu 24.04**，宝塔是我们后来手动装的（它自己改写了 ufw 规则，这就是为什么 ufw 里有一堆 FTP 端口）。

## 四、规格怎么选

命名规律：`2vCPU | 4GiB` = 2 个虚拟核 + 4G 内存。

| 类型 | 特点 | 典型用途 |
|---|---|---|
| 通用型 | CPU 与内存均衡 | 建站、跑脚本、**你这种场景** |
| 计算型 | CPU 强、内存少 | 编译、计算密集 |
| 内存型 | 内存大 | 数据库、缓存 |
| 突发型 | 平时低配、可短时爆发 | 个人测试（便宜，但持续高负载会限速） |

**够不够的判断方法**：

| 用途 | 建议配置 |
|---|---|
| 纯脚本 / 定时任务 / 单页网站 | 1 核 1G 起，2 核 2G 很稳 |
| 带面板（宝塔）+ 网站 | 2 核 2G 起，**2 核 4G 更舒服** |
| 数据库 + 应用 + 面板 | 2 核 4G 起 |
| Electron 客户端常驻 | 至少 4G，8G 稳妥 |

> 你这台 1.7G 内存跑"Node 脚本 + 宝塔 + 2048"，可用 1.36G，完全够。再加重型服务（Docker、MySQL）就会吃紧。

## 五、计费：别让钱悄悄流走

| 方式 | 特点 | 适合 |
|---|---|---|
| **按需计费** | 用多久算多久，可随时释放 | 练习、临时项目 |
| **包年包月** | 一次付，便宜 | 长期跑的服务 |
| **竞价/抢占** | 最便宜，但可能被回收 | 可中断的计算任务 |

**三个必须知道的扣费点**：
1. 实例不关机 ≠ 不花钱，**关机也可能收"保留资源"费**；
2. **弹性公网 IP 不释放会继续计费**（哪怕机器已停）；
3. 练习结束要 **释放实例 + 解绑并释放 EIP**，只留 VPC/子网免费。

## 六、第一次登录服务器

**两种凭证方式**：

| 方式 | 安全性 | 说明 |
|---|---|---|
| 密码登录 | 中 | 会被暴力破解扫描，务必改默认端口或加 fail2ban |
| **密钥对登录（推荐）** | 高 | 私钥本地保存，服务器只存公钥，扫不到密码 |

```powershell
# 密码 / 已配免密，都统一用这条
ssh root@121.36.27.69
```

首次连接会提示指纹确认（`yes` 即可），之后写入 `known_hosts` 不再提示。

**免密原理**：本地 `~/.ssh/id_ed25519`（私钥）↔ 服务器 `~/.ssh/authorized_keys`（公钥）。私钥泄露 = 服务器失守，权限必须 600。

## 七、Linux 目录结构（只需记 8 个）

| 目录 | 放什么 | 你的项目落在哪 |
|---|---|---|
| `/etc` | 所有配置文件（nginx.conf、systemd unit、ssh 配置） | `game2048.service` 在这 |
| `/opt` | **第三方/自建软件**，约定俗成的安装位置 | `/opt/game2048`、`/opt/trae-checkin` ✅ |
| `/var/log` | 系统和服务的日志 | 系统日志在这 |
| `/usr/bin` | 可执行程序（node、nginx、curl 都在这） | `/usr/bin/node` |
| `/home` | 普通用户家目录 | 不用 |
| `/root` | root 的家目录 | 免密配置在 `/root/.ssh` |
| `/tmp` | 临时文件，**重启可能被清理** | 别放重要东西 |
| `/www` | 宝塔专用目录（网站源码、面板程序） | 宝塔装的东西都在这 |

> 你的两个服务都放 `/opt`，这是最稳妥的选择：不污染系统目录、不跟宝塔的 `/www` 混在一起。

## 八、权限体系（看不懂权限 = 改坏系统）

**三类人**：`u`（所有者）/ `g`（所属组）/ `o`（其他人）
**三种权**：`r` 读 / `w` 写 / `x` 执行

```
-rwxr-xr-x   root root   trae_checkin.js
 ↑↑↑ ↑↑↑ ↑↑↑
 所有 组  其他
```

| 数值 | 组合 | 常见用途 |
|---|---|---|
| **755** | rwx-r-xr-x | 可执行脚本、目录 |
| **644** | rw-r--r-- | 普通文件、网页文件 |
| **600** | rw------- | **凭证类文件**（token、key、notify.conf） |
| **700** | rwx------ | 私钥目录 `~/.ssh` |

```bash
chmod 600 /opt/trae-checkin/trae_cred.json   # 只有 root 能读
chmod 755 /opt/game2048/server.js            # 所有人可执行
chown root:root /opt/game2048                # 归属 root
```

**铁律**：任何含 token / Cookie / 密码的文件，一律 `600`，且不进 git。

## 九、必会的 30 条命令

```bash
# --- 我在哪 / 有什么 ---
pwd                          # 当前目录
ls -la                       # 详细列出（含隐藏文件）
cd /opt                      # 进目录
df -h                        # 磁盘用了多少
free -m                      # 内存（MB）
du -sh /opt/game2048         # 某目录占多大

# --- 文件操作（改前先备份！）---
cp a a.bak                   # 备份
mv a b                       # 改名/移动
rm -rf 目录                  # 慎用，没有回收站
cat file                     # 看全文
less file                    # 分页看（q 退出）
tail -f logs/checkin.log     # 实时跟日志（最常用）
grep -n "关键词" file         # 按行找

# --- 进程 ---
ps aux | grep node           # 找进程
top                          # 实时资源（q 退出）
kill -9 PID                  # 强杀（先试普通 kill）

# --- 服务（systemd）---
systemctl status game2048    # 状态
systemctl start/stop/restart game2048
systemctl enable game2048    # 开机自启
journalctl -u game2048 -n 50 # 看最近 50 行日志

# --- 网络 ---
ss -lntp                     # 谁在监听
curl -I http://127.0.0.1/    # 本机测 HTTP
ping -c 3 baidu.com          # 通不通
```

## 十、包管理：装软件的两种世界

| 系统 | 命令 | 说明 |
|---|---|---|
| Ubuntu / Debian | `apt update && apt install -y 软件` | 本文这台用的 |
| CentOS / EulerOS / Rocky | `dnf install -y 软件`（旧版 `yum`） | 更常见于国内云 |

**国内加速**（可选）：把源换成华为云/阿里云镜像，`apt update` 会快很多。

**Node 项目例外**：不需要 `apt install nodejs` 装包，直接用官方二进制或已装好的 v22 即可（系统源的 Node 通常太旧）。

## 十一、文件传输三招

| 方式 | 命令 | 适用 |
|---|---|---|
| **scp（最直观）** | `scp .\file root@121.36.27.69:/opt/` | 小文件、目录 `-r` |
| **base64（防火墙友好）** | 本地转码 → ssh 解码 | 只要 SSH 通就能传，适合脚本化 |
| **宝塔面板** | 网页上传 | 有面板时最省事 |

```powershell
# scp 上传整个目录
scp -r .\game2048 root@121.36.27.69:/opt/
```

## 十二、这一篇的 5 个"早知道就好了"

1. 练习一定选**按需计费**，用完释放，别心疼那几分钟。
2. 选**纯净镜像**，别一上来就市场镜像，省得跟预装软件抢端口。
3. **密钥登录**比密码安全一个数量级，配一次终身受益。
4. 项目放 `/opt`，别散落在 `/root` 或 `/tmp`（`/tmp` 重启就没了）。
5. 内存不够先看 `free -m` 和 `ps aux --sort=-%mem | head`，别急着升级配置。
