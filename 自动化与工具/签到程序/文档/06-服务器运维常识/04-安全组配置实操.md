# 04 · 安全组配置实操（华为云）

> 目标：能独立放行端口、能按最小权限配规则、能在不通时快速定位是不是安全组的问题。

---

## 一、安全组是什么

**云厂商在虚拟网络层给你的实例套的一层防火墙**，独立于操作系统：

| 特点 | 说明 |
|---|---|
| 生效位置 | 在云平台侧，**系统里看不到**（`ufw` 里查不到） |
| 粒度 | 实例 / 网卡级，一台机器可绑多个安全组 |
| 方向 | **入方向**（别人访问你）+ **出方向**（你访问外网） |
| 有状态 | 允许入站的连接，回包自动放行，不用单独配出方向 |
| 默认 | 新建实例通常只放 22（部分模板放 22/3389） |
| 优先级 | 规则序号**越小越优先**，匹配即停 |

> 它和 `ufw` 是**串联**关系：**两道门都开，才进得来**。所以你 ufw 放行了 8080，外网仍然不通，就是安全组没开。

## 二、华为云控制台操作路径（文字版）

1. 浏览器打开 `https://console.huaweicloud.com`，登录
2. 顶部搜索框输入 **ECS** → 进入"弹性云服务器"
3. 左侧 → **实例** → 找到你的机器（`121.36.27.69` 对应那台）
4. 点实例名进入详情 → 找到 **安全组** 标签（或在实例列表的"安全组"列点击）
5. 点 **配置规则**（或"更改安全组"旁的"管理规则"）
6. 切到 **入方向** 标签 → **添加规则**
7. 按下表填写 → 确定

## 三、添加一条规则的字段含义

| 字段 | 填什么 | 说明 |
|---|---|---|
| **优先级** | 1–100，数字小的先匹配 | 普通放行填 `1` 即可 |
| **协议端口** | `TCP` + `8080`；或 `TCP:80`；或 `TCP:39000-40000` | 网页/数据库/SSH 都是 TCP |
| **类型** | IPv4 / IPv6 | 一般选 IPv4 |
| **源地址** | `0.0.0.0/0`（所有人）/ `192.168.1.0/24` / 指定 IP | **能精确就别用 0.0.0.0/0** |
| **动作** | 允许 / 拒绝 | 默认允许 |
| **描述** | 写清楚用途和日期 | 三个月后你会感谢自己 |

---

## 四、四种常用规则模板

| 用途 | 协议端口 | 源地址 | 备注 |
|---|---|---|---|
| SSH 管理 | `TCP 22` | **你自己的公网 IP**（如 `1.2.3.4/32`） | 别对全网开，爆破太多 |
| 网站 HTTP | `TCP 80` | `0.0.0.0/0` | 公开站点必须全网 |
| 网站 HTTPS | `TCP 443` | `0.0.0.0/0` | 同上 |
| 临时调试 | `TCP 8080` | **仅自己 IP** | 用完就删 |
| 面板（宝塔） | `TCP 8888` | 仅自己 IP | 面板绝不对公网 |
| 数据库 | — | — | **不建议开任何端口**，用 SSH 隧道 |

**CIDR 小知识**：

| 写法 | 含义 |
|---|---|
| `0.0.0.0/0` | 所有 IPv4 地址（全网） |
| `1.2.3.4/32` | 只有这一个 IP |
| `1.2.3.0/24` | 1.2.3.0 到 1.2.3.255 这一整段 |
| `192.168.0.0/16` | 一个大内网段 |

## 五、完整排障流程（照抄即可）

```powershell
# ===== 在本地 Windows 上 =====
Test-NetConnection 121.36.27.69 -Port 80
# TcpTestSucceeded : True  → 安全组通了
# TcpTestSucceeded : False → 继续往下查
```

```bash
# ===== 在服务器上（SSH 进去）=====
curl -I http://127.0.0.1/            # ① 服务本身活没活
ss -lntp | grep :80                  # ② 监听了吗、绑定哪个地址
ufw status | grep 80                 # ③ 本机防火墙放行了吗
```

**判定表**：

| ① 本机 curl | ② ss 有监听 | ③ ufw 放行 | ④ 外网通 | 问题在哪 |
|---|---|---|---|---|
| ✅ | ✅ | ✅ | ❌ | **安全组** |
| ✅ | ✅ | ❌ | ❌ | 本机防火墙 |
| ✅ | ❌ | — | ❌ | 服务没起来 / 端口写错 |
| ❌ | — | — | ❌ | 服务崩溃，先看日志 |

## 六、这次实战的真实案例

| 步骤 | 操作 | 结果 |
|---|---|---|
| 1 | 2048 部署到 8080，`ufw allow 8080/tcp` | 本机 `127.0.0.1:8080` 返回 200 ✅ |
| 2 | 本地 `Test-NetConnection -Port 8080` | **超时** ❌ |
| 3 | 查 `ufw status` | 8080 已 ALLOW → 不是本机防火墙 |
| 4 | 判断 | **安全组未放行 8080** |
| 5 | 验证替代方案：把服务改到 **80**（安全组本来就开着 80/22） | 本地访问 **200** ✅ |
| 6 | 结论 | 不必让用户去控制台，**换到 80 端口即可** |

**经验沉淀**：遇到"ufw 放了还不通"，先别急着让人开控制台——**先看有没有一个安全组已放行的端口可用**（常见 80/443/22）。

## 七、出方向要不要配

| 场景 | 建议 |
|---|---|
| 默认（能访问外网、能调 API） | 保持默认"允许全部"即可 |
| 高安全要求 | 只放行目标域名/IP + 端口 |

你的签到脚本要访问 `api.trae.cn`、`sctapi.ftqq.com`，**出方向必须通**。目前默认全通，所以推送和签到正常。

## 八、安全组 vs 本机防火墙（速记）

| | 安全组 | 本机 ufw / firewalld |
|---|---|---|
| 所在层 | 云平台虚拟网络 | 操作系统内 |
| 谁能改 | 控制台（需要账号权限） | SSH 进去就能改 |
| 换镜像 | **不变** | 重置 |
| 日志 | 控制台可查拦截记录（部分规格） | 一般无 |
| 建议 | 只开必要端口，源地址尽量精确 | 作为第二道保险，规则可以更宽松 |

**结论：安全组是主防线，ufw 是副防线，两道都别裸奔。**

## 九、常见疑问

| 疑问 | 答案 |
|---|---|
| 改了安全组要重启服务器吗？ | 不需要，**立即生效** |
| 安全组能改成"拒绝所有"吗？ | 能，但会把自己也锁在外面（连 SSH 也断），慎用 |
| 一台机器能绑多个安全组吗？ | 能，规则取并集（更宽松的生效） |
| 出方向关掉会怎样？ | 服务器无法访问外网，签到、推送、apt 全挂 |
| 安全组规则有数量上限吗？ | 有（通常几十条），不要堆一堆重复规则 |
| 怎么知道是安全组挡的？ | 本机 curl 通 + ss 在监听 + 外网不通 = 基本就是它 |

## 十、五条硬规则

1. **控制台操作前先记下原规则**，改错了能还原。
2. **SSH 只开自己的 IP**，不用 `0.0.0.0/0`。
3. **数据库/缓存/面板端口一律不对公网**。
4. 临时开的端口（如 8080）**用完就删**，别留后门。
5. 每条规则写**描述 + 日期**，否则半年后没人知道它干嘛的。
