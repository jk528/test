# 签到程序使用说明

多平台积分每日自动签到，**API 直连**，无需打开客户端窗口。`run_checkin.cmd`（唯一入口，自动探测 Node）调用 `checkin_all.js`（自包含 6 平台逻辑与公共工具，纯 Node 零依赖）。

## 一、目录结构

```
签到程序/
├── run_checkin.cmd        # 唯一入口（自动探测 Node 运行时，不带参数）
├── checkin_all.js         # 唯一脚本：6 平台签到 + 公共工具
├── sync_gitee.ps1         # Gitee 仓库定时同步（可选，与签到无关）
└── 文档/                  # 使用说明、排障手册、果办逆向记录
```

## 二、平台与执行时间

| 平台 | 说明 |
|---|---|
| Trae | 原 TraeWork/TraeCN 已合并为单平台，数据目录自动遍历新旧名 |
| TeleAgent | 经 current-owner.json 定位 token |
| WorkBuddy | 密钥自动获取（binding → 缓存 → WorkBuddy.exe 自取），无需客户端运行 |
| CodeArts | DPAPI + node:sqlite + AES-GCM 解密，需 Node 22.13+ |
| Qoder | **活动每日 10:00 刷新，必须 10:30 之后运行** |
| OfficeAce（果办） | **需果办客户端处于运行状态**，本地 API 调用 |

**建议每天 10:35 之后执行，只注册一个任务。**各平台顺序执行，签到前随机等 30~300 秒；单平台失败记录日志并继续，不影响其它平台。退出码：`0` = 全部成功/已签，`1` = 至少一个平台失败。

## 三、运行依赖

- **Node 18+**（CodeArts 需 22.13+）。`run_checkin.cmd` 按序探测：PATH 的 `node` → `C:\Program Files\nodejs` → TeleAgent 自带 Node → Trae EXE（`ELECTRON_RUN_AS_NODE=1`）
- **各平台已登录**产生的本地凭证（脚本只复用，不存账号密码）：

| 平台 | 凭证位置 |
|---|---|
| Trae | `%APPDATA%\Trae CN\User\globalStorage\storage.json`（旧名 `TRAE SOLO CN`） |
| TeleAgent | `%USERPROFILE%\.local\share\TeleAgent\users\<owner>\app-auth\token.json` |
| WorkBuddy | `%LOCALAPPDATA%\CodeBuddyExtension\Data\Public\auth\workbuddy-desktop.info` |
| Qoder | `%APPDATA%\com.qodercn.app.stable\auth.v1.dat`（国际版 `com.qoder.app.stable`） |
| CodeArts | `%APPDATA%\codearts-agent\User\globalStorage\state.vscdb` |
| OfficeAce | `%USERPROFILE%\.office-claw\session.cookie` |

## 四、手动运行

```powershell
cd "<签到程序目录>"
.\run_checkin.cmd               # 全部平台（含随机延迟，最坏约半小时）
.\run_checkin.cmd --no-delay    # 跳过延迟快速测试
node checkin_all.js --no-delay  # 直接调用脚本
```

## 五、注册计划任务（PowerShell）

```powershell
$dir = $PSScriptRoot   # 粘贴执行时改为：$dir = (Get-Location).Path
$cmdArg   = '/s /c ""' + $dir + '\run_checkin.cmd" >> "' + $dir + '\checkin_all.log" 2>&1"'
$action   = New-ScheduledTaskAction -Execute "cmd.exe" -Argument $cmdArg
$trigger  = New-ScheduledTaskTrigger -Daily -At "10:35"
$settings = New-ScheduledTaskSettingsSet -StartWhenAvailable -ExecutionTimeLimit (New-TimeSpan -Minutes 90)
Register-ScheduledTask -TaskName "统一签到" -Action $action -Trigger $trigger -Settings $settings -Force
```

要点：用 `Register-ScheduledTask` 而非 `schtasks`（中文任务名无乱码）；`cmd /c` 含 `>>`、`&` 必须加 `/s`；触发时间 ≥ 10:35（Qoder 限制）；`-StartWhenAvailable` 关机错过后开机补跑；限时 90 分钟（随机延时最坏约 30 分钟）。目录迁移后的改绑流程与历史教训见 [任务计划配置记录.md](任务计划配置记录.md)。

常用管理：

```powershell
Get-ScheduledTaskInfo -TaskName "统一签到"        # 状态与下次运行时间
Start-ScheduledTask -TaskName "统一签到"          # 手动触发
Unregister-ScheduledTask -TaskName "统一签到" -Confirm:$false
```

## 六、日志与常见问题

日志在同目录 `checkin_all.log`（UTF-8，由计划任务重定向写入）。客户端升级跑挂了看 [排障手册.md](排障手册.md)。

| 报错 | 原因 |
|---|---|
| `未检测到数据目录` | 客户端未安装或未登录 |
| `登录态已过期` | 打开客户端重新登录 |
| `未找到 Node.js 运行时` | 安装 Node 18+ |
| `缺少内置 node:sqlite` | CodeArts 需 Node 22.13+ |
| Qoder 领不到 | 任务时间早于 10:30，改到 10:35 后 |

## 七、自动探测机制

所有路径无硬编码，客户端更名/迁移/卸载自动适配：

| 探测项 | 方式 |
|---|---|
| Trae 数据目录 | 遍历 `%APPDATA%` 下新→旧目录名，选含 `storage.json` 的 |
| 客户端安装目录 | 注册表 `Uninstall` → 常见安装路径 |
| WorkBuddy EXE / 各版本号 | 注册表 / 常见路径；`resources\app\package.json` |
| OfficeAce 本地 API | 运行态快照 → `.env` 端口 → 默认端口 → 回环端口扫描 |
| Node / Git 运行时 | PATH → 常见路径 → TeleAgent 自带 → Trae EXE 兜底 |

公共工具（`regQueryInstallLocation`、`detectAppVersion`、`dpapiUnprotect`、`aesGcmDecryptV10` 等）集中在 `checkin_all.js` 顶部，`module.exports` 导出便于单独测试；入口由 `require.main === module` 守卫。
