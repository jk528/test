# 第 4 步 · 配置定时任务

> 目标：让服务器每天凌晨自动跑签到脚本，不用人工干预。
> 用 Linux 自带的 **cron** 服务，简单稳定。

---

## §4.1 先确认 cron 服务活着

远程 SSH 里：

```bash
systemctl is-active cron
```

看到 `active` 就好。如果不是，试试：

```bash
systemctl start cron && systemctl enable cron
```

---

## §4.2 写入定时任务

远程 SSH 里，**完整复制下面整段**粘贴回车：

```bash
NODE_BIN=$(command -v node)
crontab -l 2>/dev/null | grep -vE 'trae[-_]checkin' > /tmp/ct.new
printf '\n10 0 * * * cd /opt/trae-checkin && %s trae_checkin.js >> /opt/trae-checkin/checkin.log 2>&1\n' "$NODE_BIN" >> /tmp/ct.new
crontab /tmp/ct.new && rm -f /tmp/ct.new
```

这段做了三件事：
1. 查出 node 的完整路径（cron 执行时 PATH 很短，写死路径最稳）
2. 删掉旧的 Trae 签到任务（防止重复），追加新的
3. 写回 crontab 文件

---

## §4.3 验证写对了

远程 SSH 里：

```bash
crontab -l
```

应该看到类似：

```
LANG=en_US.UTF-8
LC_ALL=en_US.UTF-8

44 13 * * *  /www/server/cron/...（这是宝塔的原有任务，别动它）

10 0 * * * cd /opt/trae-checkin && /usr/bin/node trae_checkin.js >> /opt/trae-checkin/checkin.log 2>&1
```

重点看**最后那一行**：
- `10 0 * * *` = 每天北京时间 00:10
- `cd /opt/trae-checkin &&` = 先进入脚本所在目录
- `/usr/bin/node` = node 的完整路径（和 `which node` 输出一致）
- `trae_checkin.js` = 脚本名
- `>> /opt/trae-checkin/checkin.log 2>&1` = 输出（包括错误）全部追加到日志文件

> ⚠️ 服务器上装了**宝塔面板**，它管理的 cron 条目和我们共存。上面 `grep -vE 'trae[-_]checkin'` 就是为了只删自己的、不碰宝塔的。**别手动删宝塔那行**。

---

## §4.4 立刻触发一次验证

不想等到明天，想马上看 cron 能不能真跑起来？远程 SSH 里：

```bash
cd /opt/trae-checkin && node trae_checkin.js
```

然后看日志：

```bash
tail -5 /opt/trae-checkin/checkin.log
```

应该能看到签到结果的那一行。

---

## §4.5 想改签到时间？

改 crontab 里那行的时间字段就行，用 `crontab -e` 编辑（或重跑 §4.2 的命令、把 `10 0` 改成你想要的时间）。常用写法：

| 想在几点 | cron 写法 |
|---|---|
| 每天 00:10 | `10 0 * * *` |
| 每天 00:05 | `5 0 * * *` |
| 每天 23:30 | `30 23 * * *` |
| 每小时的第 5 分钟（调试用） | `5 * * * *` |

> cron 的时间顺序是：**分 时 日 月 星期**，不是 时分！
