# 05-服务器部署 · 总览

> 这是一份**从零开始的保姆级教程**，面向完全不懂 Linux / SSH / Node 的新手。
> 目标：把 Trae 签到搬到一台华为云 Ubuntu 服务器上，让它每天自动跑。
> 你只需要照抄命令、看懂意思，不需要理解原理。

---

## 一、先看这一页：你要做什么？

整个流程**5 步**，按顺序走就行：

| 第几步 | 做什么 | 你需要准备 | 用时 |
|---|---|---|---|
| **1** | 连服务器 | 服务器 IP、root 密码（你手里那两个） | 5 分钟 |
| **2** | 本地解出 Trae token | 电脑上 Trae 客户端已登录 | 2 分钟（跑现成脚本） |
| **3** | 把脚本和 token 传到服务器 | —— | 3 分钟（复制粘贴命令） |
| **4** | 让它每天自动跑 | —— | 2 分钟 |
| **5** | 日常维护（token 失效怎么办） | —— | 5 分钟（备用） |

走完 1–4，**之后什么都不用管**，服务器每天凌晨自己签到。

## 二、这次用的服务器参数

> 记下来，后面每一步命令都要填这几个值。**第一次部署的同学直接抄。**

| 项目 | 值 | 怎么看 |
|---|---|---|
| IP 地址 | `121.36.27.69` | 华为云控制台 → ECS → 公网 IP |
| 登录用户 | `root` | 默认值，别改 |
| 密码 | `******` | 你自己那串，别写进文件别外传 |
| 系统 | Ubuntu 24.04 | 不用管，服务器自带 |
| Node 版本 | v22.22.1 | 不用管，服务器已装好 |
| 服务器上签到目录 | `/opt/trae-checkin/` | 固定值，别改 |
| 签到时间 | 每天北京时间 00:10 | 可改，见第 4 步 |

## 四、一句话原理（可选阅读）

Trae 签到其实就是一条 HTTP 请求 + 一个令牌。令牌从本地 Trae 客户端文件里解出来（AES 算法，不绑电脑），然后服务器上 Node 脚本拿着令牌每天发一次请求就行。其他 5 个平台（TeleAgent、WorkBuddy、CodeArts、Qoder、OfficeAce）解令牌时强绑 Windows 本机，所以这次只能迁 Trae；要一起迁得换 **Windows 服务器**。

详细原理见 [六平台凭证获取与华为云服务器部署.md](../03-逆向后-落地接入/六平台凭证获取与华为云服务器部署.md)。
