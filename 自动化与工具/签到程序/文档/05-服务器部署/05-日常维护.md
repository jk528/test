# 第 5 步 · 日常维护

> 签到脚本上线之后，**99% 的时间你不用管它**。
> 但 Trae token 不是永久的，会有两种情况需要刷新：

| 失效触发 | 大概多久一次 | 征兆 |
|---|---|---|
| Trae 客户端升级 | 几个月一次 | 服务器日志里 `签到失败：xxx` 或报 401/403 |
| 在本地 Trae 里手动重新登录 | 你自己决定 | 同上 |

---

## 刷新 token（最常见的维护）

只需要跑第 2 步和第 3 步的 §3.3：

**① 本地 PowerShell**（先本地重新解 token）：

```powershell
cd "C:\Users\Administrator\Desktop\JK-temp\自动化与工具\签到程序"
node ".temp\extract_trae_cred.js"
```

看到 `OK token_len=xxx` 就好。

**② 上传到服务器**（覆盖旧的 token 文件）：

```powershell
$b64 = [Convert]::ToBase64String([IO.File]::ReadAllBytes("$PWD\.temp\trae_cred.json"))
ssh root@121.36.27.69 "echo $b64 | base64 -d > /opt/trae-checkin/trae_cred.json && chmod 600 /opt/trae-checkin/trae_cred.json"
```

**③ 试跑确认**（远程 SSH）：

```bash
node /opt/trae-checkin/trae_checkin.js --no-delay
```

成功就行。**脚本本身不用动**。

---

## 怎么知道它今天跑了没？

远程 SSH 里看日志：

```bash
tail -10 /opt/trae-checkin/checkin.log
```

最后一行应该是今天日期开头的签到结果。

---

## 怎么知道 cron 触发了没？

```bash
grep CRON /var/log/syslog | tail -5
```

看到类似 `(root) CMD (cd /opt/trae-checkin && ...)` 就触发过。

如果什么都没看到，可能服务器没按 cron 时间启动（比如关机了），cron 启动后会补跑错过的任务，不用担心。

---

## 日志太大了怎么办？

脚本自带 5MB 自动轮转（`checkin.log` → `checkin.log.old`），一般不用管。想手动清：

```bash
> /opt/trae-checkin/checkin.log
```

见 [04-配置定时任务.md](04-配置定时任务.md) §4.5。

## 想关掉自动签到？

远程 SSH 里：

```bash
crontab -l | grep -v trae | crontab -
```

就这一条，宝塔的任务保留，只删 Trae 的。想重新启用就重跑 §4.2。

## 服务器密码安全建议

你手里的 root 密码**在本次部署对话里明文出现过**，建议去华为云控制台重置一次。改完之后：

- 如果已经配了 SSH 公钥免密 → 改密码不影响，继续免密登录
- 还没配免密 → 记得本地重连一次让你输新密码

> SSH 公钥免密是更安全的做法，下次部署自动装好了，直接 `ssh root@121.36.27.69` 就能进。
