# 第 3 步 · 部署签到脚本到服务器

> 目标：把 token 和签到脚本传到服务器上，试跑一次确认能签到。
> **第一次部署全做；平时 token 失效只做 §3.3。**

---

## §3.1 先在服务器上建目录

打开 **SSH 远程终端**（连上 `root@121.36.27.69` 之后那个）：

```bash
mkdir -p /opt/trae-checkin
```

---

## §3.2 上传脚本和 token

回到**本地 PowerShell**，执行下面两条 scp 命令（把服务器目录里的内容传到本地，方向反过来就是上传；这里换一种更稳的 base64 方式，绕开引号问题）。

**① 上传脚本**（先在本地算出脚本的 base64，再让服务器解出来）：

本地 PowerShell：

```powershell
$b64 = [Convert]::ToBase64String([IO.File]::ReadAllBytes("$PWD\.temp\trae_checkin_server.js"))
ssh root@121.36.27.69 "echo $b64 | base64 -d > /opt/trae-checkin/trae_checkin.js"
```

**② 上传 token**（同样 base64）：

本地 PowerShell：

```powershell
$b64 = [Convert]::ToBase64String([IO.File]::ReadAllBytes("$PWD\.temp\trae_cred.json"))
ssh root@121.36.27.69 "echo $b64 | base64 -d > /opt/trae-checkin/trae_cred.json && chmod 600 /opt/trae-checkin/trae_cred.json"
```

> `chmod 600` 是 Linux 权限命令，意思是"只有 root 本人能读"，防止别人偷窥 token。

**③ 给脚本加执行权限**：

本地 PowerShell：

```powershell
ssh root@121.36.27.69 "chmod 755 /opt/trae-checkin/trae_checkin.js"
```

---

## §3.3 如果以后 token 失效了，只做这一小步

上面第 2 步重新跑 `extract_trae_cred.js` 之后，只需要重新上传 token 文件，脚本本身不用动：

```powershell
$b64 = [Convert]::ToBase64String([IO.File]::ReadAllBytes("$PWD\.temp\trae_cred.json"))
ssh root@121.36.27.69 "echo $b64 | base64 -d > /opt/trae-checkin/trae_cred.json && chmod 600 /opt/trae-checkin/trae_cred.json"
```

---

## §3.4 试跑一次

回到**远程 SSH 终端**，执行：

```bash
cd /opt/trae-checkin && node trae_checkin.js --no-delay
```

成功输出有两种，都是正常：

- `今日已签到。积分：100（含额外 100）` — 今天已经签过了
- `签到成功！积分：100` — 刚刚签到成功

失败会看到 `签到失败：xxx` 或 `错误：xxx`，去 [99-故障排查.md](99-故障排查.md) 查。

---

## §3.5 确认服务器上文件就位

远程 SSH 里执行：

```bash
ls -la /opt/trae-checkin/
```

应该看到三行（第一次部署时 checkin.log 还不存在，有或没有都正常）：

```
-rwxr-xr-x 1 root root 3308 ... trae_checkin.js      ← 签到脚本
-rw------- 1 root root 1174 ... trae_cred.json       ← token 凭证（只有 root 能读）
-rw-r--r-- 1 root root  726 ... checkin.log           ← 日志（试跑之后才会有）
```

权限位重点看：`trae_cred.json` 是 `rw-------`，不是就 `chmod 600 /opt/trae-checkin/trae_cred.json`。

---

## 这一阶段完成了什么？

- ✅ 服务器有了签到脚本 `/opt/trae-checkin/trae_checkin.js`
- ✅ 服务器有了 token `/opt/trae-checkin/trae_cred.json`
- ✅ 手动跑了一次，确认 token 服务器端有效
