# 第 6 步 · 微信消息推送（方糖 / Server酱）

> 方糖（Server酱）是签到结果推送到微信的渠道。签到跑完自动推一条，成功/失败/今日已签都有消息，不用自己去服务器看日志。
> **历史名：Server酱**，官网 `sct.ftqq.com`，现已更名为"方糖"，域名和 SendKey 格式没变，老用户不用换 key。

---

## 一、现状一览

| 项目 | 值 |
|---|---|
| 推送渠道 | 方糖 / Server酱 |
| SendKey | `SCT****8TESp****WuoPe************f`（**等同账号密码，勿外传，实际值存服务器 /opt/trae-checkin/notify.conf**） |
| 推送接口 | `https://sctapi.ftqq.com/<SendKey>.send?title=...&desp=...` |
| 服务器配置文件 | `/opt/trae-checkin/notify.conf`（chmod 600） |
| 服务器脚本 | `/opt/trae-checkin/trae_checkin.js` 里的 `pushWechat()` 函数 |
| 推送触发 | 签到脚本末尾，成功/已签/失败 三种结果各推一条 |
| 免费额度 | 每天 5 条（签到一天 1 条，绰绰有余） |
| 配额刷新 | 偶尔登录 `sct.ftqq.com` 看一眼，不用主动刷 |

## 二、注册与获取 SendKey（以后换 key 时参考）

**1. 手机浏览器打开** `https://sct.ftqq.com`

**2. 点"GitHub 一键登录"** → 用 GitHub 账号授权 → 自动弹出微信扫码绑定

**3. 网页上出现 SendKey**，形如 `SCTxxxxxTxxxxxxxxxxxxx`（24 位），复制出来

**4. 默认微信推送方式：** 消息推到"方糖"公众号，打开公众号就能看到历史记录

> ⚠️ 免费版每天 5 条，订阅公众号后偶尔需要打开一下刷新额度，否则会限流。签到一天 1 条完全够用。

---

## 三、服务器侧 notify.conf 格式

```json
{
  "sendkey": "SCTxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
  "push_url": "https://sctapi.ftqq.com"
}
```

> ⚠️ SendKey 明文只存于服务器 `/opt/trae-checkin/notify.conf`（chmod 600），文档、git 仓库里一律脱敏或写占位符。

只有两个字段：
- `sendkey`：你的 SendKey
- `push_url`：接口域名，默认 `https://sctapi.ftqq.com`，一般不用改

**权限必须是 600**（只有 root 本人能读）：
```bash
chmod 600 /opt/trae-checkin/notify.conf
```

## 四、推送消息长什么样

服务器签到成功 → 微信公众号收到：

```
【Trae 签到结果】
时间：2026-11-05 00:17:42
结果：签到成功
积分：100（含额外 100）
来源：华为云服务器
```

今日已签（服务器先签、本机补签时）→：

```
【Trae 签到结果】
时间：2026-11-05 00:17:42
结果：今日已签到
积分：100（含额外 100）
来源：华为云服务器
```

签到失败 →：

```
【Trae 签到失败】
时间：2026-11-05 00:10:03
错误：401 Unauthorized
来源：华为云服务器
```

消息用 Markdown 格式，方糖公众号会渲染加粗。标题只分两类：**Trae 签到结果**（成功/已签）和 **Trae 签到失败**（出错）。

## 五、手动测推送（换 key 后验证）

本地 PowerShell：

```powershell
Invoke-RestMethod -Uri "https://sctapi.ftqq.com/<你的SendKey>.send?title=测试&desp=签到推送已接通"
```

返回 `code: 0` + `error: SUCCESS` = 成功。微信公众号应该立刻收到。

服务器上也能测：

```bash
curl "https://sctapi.ftqq.com/<你的SendKey>.send?title=服务器测试&desp=来自华为云 121.36.27.69"
```

## 六、改 SendKey

比如方糖账号被盗、想换个 key：

**① 先在方糖网页上生成新 key**（或重置旧 key）

**② 服务器覆盖 notify.conf**（不用改脚本，脚本只关心配置文件）：

本地 PowerShell：

```powershell
$conf = '{"sendkey":"<新key>","push_url":"https://sctapi.ftqq.com"}'
ssh root@121.36.27.69 "echo $conf > /opt/trae-checkin/notify.conf && chmod 600 /opt/trae-checkin/notify.conf"
```

**③ 试跑一条**：

```powershell
ssh root@121.36.27.69 "node /opt/trae-checkin/trae_checkin.js --no-delay"
```

## 七、方糖额度不够了怎么办？

免费版每天 5 条，签到一天 1 条，正常情况**永远够**。但如果你同时推了别的东西（比如服务器告警、其他平台签到），可能超：

| 方案 | 费用 | 说明 |
|---|---|---|
| 登录方糖公众号刷一次 | 免费 | 打开公众号任意看一眼，当天额度恢复 |
| 升会员 | 10 元/月 | 额度更高，但签到场景没必要 |
| 再加一个方糖账号 | 免费 | 注册第二个 GitHub → 第二个 SendKey，notify.conf 里写双 key（需改脚本支持） |

## 八、想换其他推送渠道？

方糖不是唯一选项，但对签到场景来说最简单。三种主流渠道对比：

| | 方糖/Server酱 | PushPlus | 企业微信群机器人 |
|---|---|---|---|
| 费用 | 免费 5 条/天 | 10 元/月会员 | **永久免费不限量** |
| 消息到达 | 公众号推送 | 公众号推送 | **企业微信 App / 微信** |
| 注册 | GitHub 登录 + 绑微信 | 实名 + 付费 | 建企微群 + 加机器人 |
| 稳定性 | 中等（偶尔限流） | 较好（付费有保障） | **最好（零限流）** |
| 适合场景 | 签到/轻量通知 | 多渠道统一推送 | 纯服务器运维群 |

如果以后想换成企业微信群机器人，脚本推送函数只要把 Server酱的 fetch 改成 Webhook 的 fetch，notify.conf 换成 webhook 地址就行，逻辑不用动。

## 九、代码里推送函数在哪

服务器脚本 `/opt/trae-checkin/trae_checkin.js` 里：

```js
// ---- Server酱推送 ----
let NOTIFY_CFG = null;
try { NOTIFY_CFG = JSON.parse(fs.readFileSync(NOTIFY, 'utf8')); }
catch { }

async function pushWechat(title, desp) {
  if (!NOTIFY_CFG || !NOTIFY_CFG.sendkey) return;  // 没有配置就静默跳过
  const url = `${NOTIFY_CFG.push_url}/${NOTIFY_CFG.sendkey}.send?title=${encodeURIComponent(title)}&desp=${encodeURIComponent(desp)}`;
  // fetch + JSON 解析 + 日志
}
```

特点：
- **notify.conf 不存在或 SendKey 为空 → 静默跳过推送**，不影响签到主流程
- **推送失败不影响签到结果**（try-catch 包着，推送异常只打日志）
- **签到退出码只由签到结果决定**，推送是附属行为

本机 `checkin_all.js` 里暂时没加推送（本机计划任务已经有日志 + 双重保险），如果想让本机也推，需要在 Trae 签到分支的成功/失败处调用同一个 `pushWechat()`。

## 十、安全提醒

SendKey 等同账号密码，泄露了别人能用你的额度发垃圾消息：

| 位置 | 状态 | 处理 |
|---|---|---|
| 服务器 `/opt/trae-checkin/notify.conf` | ✅ chmod 600，只有 root 能读 | 保持不动 |
| 本地 `.temp/notify.conf` | ⚠️ 部署完可以删 | `del .temp\notify.conf` |
| 本文档 | ✅ 记录了 SendKey | 别把整个仓库 push 到公开 GitHub |
| 飞书/微信里贴过 | ⚠️ 如果贴到了公开群，建议换 key | 方糖网页重置 key → 服务器重新上传 |
