# 故障排查手册

> 遇到问题先**定位在哪个环节坏了**，再按下面的章节对号入座。
> 新手不用全部看完，出了问题再翻。

---

## §1 连不上服务器（第 1 步）

| 现象 | 可能原因 | 怎么查 | 怎么修 |
|---|---|---|---|
| `ssh: connect to host 121.36.27.69 port 22: Connection timed out` | 服务器关机 / IP 错了 / 安全组没放行 22 | 华为云控制台看 ECS 状态是不是"运行中" | 开机；检查安全组出/入方向都放行 22 |
| `ssh: Connection refused` | 服务器开机了但 ssh 服务没跑 | 华为云 VNC 登录进去 `systemctl start ssh && systemctl enable ssh` | 启 ssh |
| `Permission denied (publickey,password)` | 密码错了 | 仔细输一遍，注意大小写 | 重输密码 |
| SSH 连得上但 root 密码提示改 | 云厂商强制改初始密码 | 按提示改完再连 | — |

## §2 本地解 token 报错（第 2 步）

| 报错 | 原因 | 修 |
|---|---|---|
| `未检测到 Trae CN 数据目录` | Trae 没登录 / 客户端叫旧名 | 打开 Trae 登录一次；还不行就 `echo %APPDATA%` 手动看目录名 |
| `未找到登录态数据` | storage.json 结构变了（Trae 升级过） | Trae 退出重开让它刷新登录态；再不行就重登账号 |
| `登录态中没有 token` | storage.json 损坏 | 重登 Trae |
| `node 不是内部或外部命令` | 没装 Node | 去 nodejs.org 装 LTS 版（22+ 或 24+ 都行），装完重开 PowerShell |

## §3 签到脚本报错（第 3/4 步）

远程 SSH 里跑 `node /opt/trae-checkin/trae_checkin.js --no-delay`，看报错内容：

| 报错 | 原因 | 修 |
|---|---|---|
| `读取凭证失败 - ENOENT` | token 文件没传上去 | 重跑第 3 步的上传命令 |
| `签到失败：401 Unauthorized` | token 失效了 | 本地重解 token 再上传，见第 5 步刷新 |
| `签到失败：xxx 积分为 0` | 今天已经签过了（服务端幂等） | 正常，不算失败 |
| `token 中缺少 device_id，签到可能被拒绝` | Trae 版本变了，device_id 换了位置 | 本地重启 Trae 让它写新的 device_id，重解重传 |
| `fetch failed` / `ECONNREFUSED` / `ETIMEDOUT` | 服务器没网 / DNS 解析不了 / 安全组没放行 443 | `curl -I https://api.trae.cn` 测试连通性；华为云安全组出站放行 443 |

## §4 cron 到点没跑

远程 SSH 里按顺序查：

**① cron 服务活着吗？**

```bash
systemctl is-active cron
```

不是 `active` 就 `systemctl start cron && systemctl enable cron`。

**② 任务写进去了吗？**

```bash
crontab -l | grep trae
```

没输出就重跑第 4 步 §4.2。

**③ 触发过吗？**

```bash
grep CRON /var/log/syslog | tail -10
```

有输出就能看到 cron 有没有尝试执行、执行时的错误。

**④ 日志里有内容吗？**

```bash
ls -la /opt/trae-checkin/checkin.log
tail -10 /opt/trae-checkin/checkin.log
```

如果日志文件存在但内容是空的，cron 可能用错了 node 路径。看 §4.2 写进去的 `/usr/bin/node` 和服务器上 `which node` 是不是同一个，不一样就把 crontab 里路径改过来。

**⑤ 最常见的坑：cron PATH 很短**

cron 执行时环境变量里只有 `/usr/bin:/bin`，本地能跑的 node 在 cron 里可能找不到。所以 §4.2 特意用 `$(command -v node)` 取了完整路径写进 crontab。如果你自己手写 `node trae_checkin.js` 而没写完整路径，大概率不会执行。

## §5 宝塔面板跟 cron 冲突？

服务器上装了宝塔面板，它自己也在管理 cron 任务。我们的做法是：

- **只增 Trae 那一行**，不删宝塔任何条目
- 用 `crontab -l | grep -vE 'trae'` 先过滤掉自己的旧行再追加，防止重复

如果你用宝塔界面手动加了同一个任务，**会重复签到**。要么删宝塔那条，要么别用宝塔加。

## §6 安全组 / 网络相关

华为云 ECS 默认安全组：

| 方向 | 协议 | 端口 | 用途 |
|---|---|---|---|
| 入方向 | TCP | 22 | SSH 登录（必需） |
| 入方向 | TCP | 3389 | RDP（这台是 Linux 不用开） |
| 出方向 | TCP | 443 | 签到请求出站（必需，否则 api.trae.cn 连不上） |
| 出方向 | TCP | 80 | 可选，apt update 需要 |

安全组在华为云控制台 → ECS → 网络与安全组 → 安全组 → 入方向规则里编辑。
