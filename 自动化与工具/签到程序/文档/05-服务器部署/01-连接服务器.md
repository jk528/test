# 第 1 步 · 连接服务器

> 目标：在本地 Windows 上打开终端，连上远程的 Linux 服务器。
> **这一步只做一次**，连上之后后面每步都复用这个终端。

---

## 方式 A：用 PowerShell（Windows 自带，推荐）

**1. 打开 PowerShell**

按 `Win` 键，输入 `powershell`，回车。

**2. 第一次连接**

把下面命令完整复制粘贴进去（把 `******` 换成你手里的密码）：

```powershell
ssh root@121.36.27.69
```

第一次会看到：

```
The authenticity of host '121.36.27.69 (...)' can't be established.
Are you sure you want to continue connecting (yes/no/[fingerprint])?
```

输入 `yes` 回车，然后输入密码回车。**注意：输入密码时屏幕不显示任何字符，这是正常的，输完直接回车。**

连上之后，提示符会变成 `root@xxx:~#` — 这就代表你现在"站在"服务器里了。

**3. 验证一下是 Linux**

```bash
uname -a
```

应该看到输出里有 `Linux`，再输：

```bash
node -v
```

应该看到 `v22.22.1` — Node 已经装好，不用自己装。

---

## 方式 B：如果你更喜欢图形界面（Xshell / FinalShell）

随便装一个 SSH 客户端（免费的很多，FinalShell 还有中文界面），新建连接：

| 字段 | 填什么 |
|---|---|
| 主机 / IP | `121.36.27.69` |
| 端口 | `22` |
| 用户名 | `root` |
| 密码 | 你那串 |

连上之后效果和 PowerShell 一样。

---

## 以后怎么连？

**方式 A 的好处：连上一次之后，本机的 SSH 公钥已经写进服务器，之后每次直接 `ssh root@121.36.27.69` 就不用输密码了。**

> ⚠️ 如果这台机器还没配过免密，就每次都输密码也行，不影响后续步骤。

---

## 连上之后要开的"本地终端"

**本地终端 = 你 Windows 上开的 PowerShell（或 cmd），用来执行本地命令（解 token、传文件、启动 SSH）。**

**远程终端 = SSH 连上之后的那个 `root@xxx:~#`，用来执行服务器上的命令。**

下文的命令我会用 `本地>` 和 `远程>` 标记清楚，你在哪个提示符下执行就行。
