## 三条技术主线（30 秒版）

| 主线 | 适用 | 关键技术 | 已攻克平台 |
|---|---|---|---|
| Electron 客户端解密 | PC 客户端本地存 token | storage.json / SQLite + DPAPI + AES-GCM("v10") / AES-CBC+SHA512 | Trae、TeleAgent、WorkBuddy、CodeArts、Qoder、OfficeAce、库库AI |
| 浏览器 Cookie 提取 | 网页版可签到 | VSS 卷影拷库（浏览器独占）→ DPAPI 主密钥 → AES-GCM 解密 → 剥 SHA256(host) 前缀 | 天翼、万兴、百度 |
| APK DEX strings | GitHub 无脚本+网页无入口 | 解压 APK → strings 提取 → 搜类名确认功能 → 搜 `/api/` 路径 → 实测 | 万兴脑图 |

## 最高频的坑（详细解法见总纲第二节）

1. Cookie 库被浏览器独占 → VSS 卷影拷贝
2. 新版 Chromium 明文前附 SHA256(host) 32 字节 → 剥除
3. SQLite 查 expires_utc 溢出 → CAST AS TEXT
4. 签到返回 200 ≠ 生效 → 对比签到前后资产数值
