## 一、调研阶段（排除法）

| 尝试 | 结果 |
|---|---|
| GitHub 搜索 mindmaster / edrawmind / edrawsoft / 万兴脑图 | 全是思维导图工具与破解包，**无签到脚本**；综合库（dailycheckin、checkbox）均不覆盖 |

| 结论 | 只能自己逆向，走 APK 路线 |

## 二、APK DEX strings 提取法（核心方法）

网页版没有入口时，接口路径盲猜全 404。标准动作：

1. 获取 APK（官网/应用商店/分享链接），改名 `.zip` 解压
2. 取 `classes.dex`、`classes2.dex` …（约 90MB 包）
3. 提取连续可打印 ASCII 字符串（≥4 字符）
4. **先搜类名**确认功能存在：`CheckInPresenter`、`ClockIn` → 命中，确认 APP 内有签到模块
5. **再搜接口路径**：`/api/` 开头的字符串 → 找到 `userapi.edrawsoft.cn` 域名下的端点
6. 用浏览器 Cookie 里的 token 逐个实测端点（GET 405 响应会提示应使用 POST）

### 提取到的接口

| 端点 | 方法 | 用途 |
|---|---|---|
| `https://userapi.edrawsoft.cn/api/user/{uid}/clockin` | POST | 签到（重复签到返回 `already check in`，幂等） |
| `.../clockin/list` | GET | 本周 7 天签到状态数组，如 `[1,1,1,1,1,1,1]` |
| `.../point` | GET | 当前积分余额 |

### 关键幸运点

**接口只要 Bearer token，无任何动态签名参数**（不像夸克网盘的 kps/sign/vcode），因此无需逆向签名算法，直接打通。

## 三、凭证方案：每次运行现提取

- 鉴权 token 藏在夸克浏览器 Cookie `EDCurrent` 中（JWT 格式）
- **JWT 有效期仅 2 小时** → 预存到配置文件没有意义
- 改为**每次签到运行时现从浏览器提取**（VSS 卷影 + DPAPI + AES-GCM 全链路，与天翼云盘同一套）
- 效果：无配置文件、零人工维护；只要浏览器里 mm.edrawsoft.cn 保持登录即可

**注意事项**：EDCurrent 是**会话 Cookie**——浏览器进程彻底退出（服务器重启/杀进程）即失效，需重新登录网页版。

## 四、落地

- 脚本：`scripts/edraw_checkin.js`（统一范式：--status / --no-delay / 退出码 0|1）
- 注册：`checkin_all.js` PLATFORMS 表 `{ name: '万兴脑图', group: 'daily', script: 'edraw_checkin.js' }`
- 实测：`--status` 返回本周全签 `[1,1,1,1,1,1,1]` + 积分 717；daily 组整组 4/4 通过

## 五、经验沉淀

1. **DEX strings 是 GitHub 无脚本时的兜底手段**：先类名后路径，10 分钟定位接口
2. **JWT 短寿不是障碍**：换个思路——不存凭证，每次现取，短寿反而无所谓
3. **签到验证要看资产数值变化**，不能只看 HTTP 200（夸克网盘 fr=pc 签到假成功的前车之鉴）
