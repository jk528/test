## 落地六步（30 秒版）

1. **写独立脚本** `scripts/xxx_checkin.js`：统一范式（--status 只读 / --no-delay / 退出码 0|1 / process.exitCode 自然退出 / 签到前随机延时 30~300s）
2. **凭证隔离**：`config/xxx_config.json`（纯 JSON 无注释）；config/ 目录已被 .gitignore 整目录排除
3. **接入主控**：`checkin_all.js` 的 `PLATFORMS` 注册表加一行 `{ name, group, script }`，主控 spawnSync 子进程零改动
4. **分组判断**：0 点刷新 → `ai` 组（00:05）；刷新晚或网盘类 → `daily` 组（10:35）
5. **三层实测**：node --check → --status → 真签一次 → 整组串联
6. **更新文档**：全流程总结加平台小节；凭证特殊时更新维护周期文档

## 血泪坑（已修复）

- **计划任务命令行**：中文路径下 .cmd 路径和 `>>` 重定向目标**都不要加引号**，否则任务秒退码 1 且无日志（2026-10-25 目录重构时实测六组对照实验定位）
- **cmd 括号块内 %VAR%** 解析期展开 → 变量读取放块外或用 goto
- **process.exit() 强杀** 在 Node 24+Windows 触发 libuv 断言 → 用 process.exitCode
