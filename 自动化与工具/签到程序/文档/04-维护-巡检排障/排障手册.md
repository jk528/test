# 签到失败排障手册

果使用说明.md](使用说明.md) 回答「怎么装、怎么跑」，本文件回答「客户端升级 / 系统变更后跑挂了，怎么救」。

**90% 的失败是三类根因**：① 客户端升级致登录态作废（最常见）→ 重新登录；② 客户端改名/换目录 → 探测失配；③ 运行时变动（卸载/换版本 Node）→ 找不到解释器。

先跑 `.\run_checkin.cmd --no-delay`（跳过随机延时）或看 `checkin_all.log`，按下表分流。

## 一、60 秒分流

| 现象 | 跳转 |
|---|---|
| `No Node.js runtime found` / `缺少 node:sqlite` | §四 |
| `未检测到数据目录` / `未找到...登录态文件` / `not_installed` | §三 |
| `登录态已过期` / `没有 token` / `not_logged_in` / `凭证已过期` | §二 |
| HTTP 4xx / 5xx、`业务错误` | §二（4xx）/ §五（5xx） |
| 果办报 `未发现 OfficeAce 本地 API` | §二 |
| Qoder 领不到但已过 10:30 | §二 |
| 想知道各文件干嘛的 | 果使用说明.md](使用说明.md) |

## 二、登录态失效（最常见）

**通用解法：打开对应客户端确认已登录，重跑脚本。**仍失败再对症：

| 平台 | 典型报错 → 处理 |
|---|---|
| Trae | `未检测到数据目录`：确认客户端已登录（升级常被踢下线）；新旧目录并存时脚本优先 `Trae CN`，必要时重命名旧目录 `TRAE SOLO CN` 避免读错 |
| TeleAgent | `登录态已过期`：客户端重登即可（DPAPI 主密钥重建会连带重写 token.json） |
| WorkBuddy | `accessToken 解密失败`：客户端重登；密钥获取已根治（进程内 binding → `.temp\wb_key.json` 缓存 → WorkBuddy.exe 自取），仅需 exe 存在。`领取返回 10001` = 已签竞态，正常 |
| CodeArts | `not_logged_in`：登录华为账号；`凭证已过期`：**先启动客户端在线几分钟**（每小时自动续期）再跑 |
| Qoder | `token 已过期`：客户端重登。脚本刷新 token 后**原子写回** auth.v1.dat（含 `.bak` 备份），与客户端共享凭证 |
| OfficeAce | `未发现本地 API`：**必须先启动果办客户端**（本地 API 调用）；`会话 Cookie 已过期`：客户端重登；`复查未见今日入账`：先在客户端界面手动点一次签到对比，详见 果果办签到逆向记录.md](果办签到逆向记录.md) 问题 13 |

另：客户端 UI 出现新活动标签（如 WorkBuddy 新赛季）属正常季节活动，接口不变；果办 `今日已签到` = 客户端整点已代领，正常。

**Trae 1024 签到抽奖（2026-10-19 新增，活动期至 1024 程序员节结束）**：签到成功后脚本自动调用 `activity/action`（`checkin_1024`）每日抽一次。日志出现 `1024 抽奖：活动不可用` = 今日已抽过或活动已结束，属正常；`抽奖成功！奖品：AI Build 专属抵扣券` 即抽到 10 元抵扣券。每日 00:00 重置，活动期内每天自动抽，无需人工干预。

## 三、探测失败（改名 / 迁移 / 卸载）

```powershell
reg query "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall" /s /f "Trae" /d   # 真实安装位置
Get-ChildItem "$env:APPDATA" -Directory | Where-Object Name -match 'Trae|qoder'        # 数据目录新旧名
Test-Path "$env:APPDATA\codearts-agent"; Test-Path "$env:USERPROFILE\.office-claw"     # 目录存在性
```

- 新旧目录并存 → 脚本优先新名；登录态若在旧目录，可重命名让脚本落到旧目录
- 自定义盘符安装 → 注册表 `InstallLocation` 是权威；绿色版/解压版探不到，需在 `checkin_all.js` 该平台的候选路径数组里补路径（§五）

## 四、运行时故障

- **`No Node.js runtime found`**：四级探测（PATH → Program Files → TeleAgent 自带 → Trae EXE）全空。安装 Node.js 24+（推荐）
- **`缺少 node:sqlite`**（仅 CodeArts）：主 Node 被卸载后落到旧版兜底运行时。装回 Node 24+ 即可，其余平台不受影响
- **计划任务没跑**：`Get-ScheduledTaskInfo -TaskName "统一签到"` 看 `LastTaskResult`：`0x0` 成功、`0x1` 有平台失败、`0x41301` 运行中；`0xC0000409` 为已修复的历史崩溃（Node 24 fetch 后 `process.exit` 强杀），复现说明回退了旧版脚本。旧入口名（`run_checkin_all.cmd` 等）已废弃，按 果使用说明.md](使用说明.md) §五重建任务

## 五、协议/结构变更（以上都试过仍失败）

客户端大版本升级可能改 API 地址、请求头、加密信封、凭证结构。从 `logs\checkin_ai.log` / `logs\checkin_daily.log` 定位平台与步骤后改 `scripts\checkin_all.js`：

| 平台 | 关键函数 | 搜索关键字 |
|---|---|---|
| Trae | checkinTrae() | `checkin_credits` |
| TeleAgent | checkinTeleAgent() | `TA_DATA_ROOT` |
| WorkBuddy | checkinWorkBuddy() | `WB_AUTH_DIR` |
| CodeArts | checkinCodeArts() | `CODEARTS_HOST` |
| Qoder | checkinQoder() | `auth.v1.dat` |
| OfficeAce | checkinOfficeAce() | `OFFICEACE_SESSION_COOKIE_PATH` |

> 若只是加密信封版本号变化（如 v10 → 其它），改 `aesGcmDecryptV10` 的前缀判断即可，不动业务逻辑。果办逆向细节见 果果办签到逆向记录.md](果办签到逆向记录.md)。
