## 一、青龙面板签到的基础配置逻辑

青龙（QingLong）是一个支持 Python3 / JavaScript / Shell / TypeScript 的定时任务管理平台，官方仅支持 Docker 部署。配置一个自动签到，本质是下面五步：

### 1. 部署面板

```bash
docker run -dit --name qinglong -p 5700:5700 \
  -v $PWD/ql/data:/ql/data \
  --restart unless-stopped whyour/qinglong:latest
```

部署后浏览器访问 `http://服务器IP:5700`，初始化账号密码。

### 2. 拉取脚本库（订阅管理）

在「订阅管理」中添加 Git 仓库地址，例如：

```
https://github.com/sitoi/dailycheckin.git
```

- 国内服务器建议加镜像前缀（如 `https://ghfast.top/`）提高拉取成功率
- 青龙会根据脚本内的 cron 注释自动创建定时任务，也可手动调整执行时间

### 3. 配置环境变量（核心步骤）

在「环境变量」中填写各平台凭证，常见类型：

| 凭证类型 | 典型平台 | 获取方式 | 过期风险 |
|---|---|---|---|
| Cookie（完整） | 百度网盘、B站、网易云、什么值得买 | 浏览器 F12 → 复制请求头 Cookie | 高（数周~数月），需定期检查 |
| BDUSS（Cookie 字段） | 百度贴吧 | 从 Cookie 中提取 BDUSS 字段 | 中，改密码即失效 |
| Token / P00001 | 爱奇艺 | Cookie 中提取关键字段 | 高，过期快 |
| 账号密码 | 天翼云盘、小米运动 | 直接填写 | 低，但接口变动会导致脚本失效 |
| refresh_token | 阿里云盘等 | OAuth 授权后获取 | 可自动续期，但官方接口调整频繁 |

### 4. 安装依赖

在「依赖管理」中安装脚本所需的 Python/Node 包（如 `requests`、`pycryptodome` 等），具体以脚本库 README 为准。

### 5. 配置消息推送（强烈建议）

支持 Bark、Server酱、钉钉、Telegram、企业微信等。配好后签到失败/成功都会推送到手机，**Cookie 过期能第一时间发现**。

### 日常维护要点

- Cookie 类凭证建议每月检查一次有效性
- 不要把环境变量提交到公开仓库（Cookie ≈ 账号密码）
- 脚本失效时先看日志，多数是平台接口变动，等仓库更新或换脚本

## 二、青龙面板 vs 直接跑脚本：好处在哪

| 维度 | 青龙面板 | 裸脚本（Windows 任务计划 / crontab） |
|---|---|---|
| 任务管理 | 网页可视化：任务、日志、变量集中管理，随时启停 | 分散，需逐个配计划任务 |
| 多账号支持 | 主流库原生支持多账号，变量按规则命名即可 | 需自己改脚本或复制多份 |
| 消息推送 | 内置 10+ 推送渠道，一处配置全局生效 | 需自己在脚本里实现 |
| 日志排查 | 每次执行有独立日志，网页直接查看 | 需自己重定向输出文件 |
| 脚本更新 | 订阅库一键更新，平台接口变了等作者修即可 | 需手动 git pull / 重新下载 |
| 资源占用 | 面板常驻约 300~500 MB 内存 + Docker 环境 | **平时零占用**，仅签到瞬间运行 |
| 部署门槛 | 需要 Docker 环境（云 VPS 可能因无嵌套虚拟化装不了） | 有 Python/Node 即可，几乎无门槛 |

**一句话总结**：

- 平台多、账号多、需要推送提醒、服务器支持 Docker → **青龙更省心**
- 只签几个平台、机器资源紧张（内存 <1GB 空闲）、或 VPS 装不了 Docker → **裸脚本更轻更稳**

> 注：本机（天翼云 4核8G，Windows Server 2022）因云平台未开放嵌套虚拟化，无法运行 Docker 版青龙，实际落地建议采用「Python + Windows 任务计划程序」的裸脚本方案，效果等同。

## 四、组合建议

**主用 1 个综合库 + 按需补充专项库，避免重复拉库：**

1. **主库**：`sitoi/dailycheckin` —— 一个库覆盖约 80% 主流平台
2. **专项**：`tunecc/DuPan` —— 补百度网盘
3. **长尾**：先去 `Wenmoux/checkbox` / `sudojia/AutoTaskScript` 搜有没有对应脚本，只加单个任务，不整库拉取
4. 不要同时拉 dailycheckin + checkinpanel + My-Actions，覆盖大量重复，会导致重复签到和任务冲突
