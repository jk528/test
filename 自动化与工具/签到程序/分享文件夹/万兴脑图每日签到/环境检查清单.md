# 万兴脑图 环境与配置检查清单

> 使用前逐项核对；缺失项按「解决方案」列处理。最后一节有一键自检命令。

## 一、运行环境

| 项 | 要求 | 检查方法 | 缺失解决方案 |
|---|---|---|---|
| Node.js | **22.5+**（纯刷新路径 18+ 即可；浏览器兜底提取用到内置 `node:sqlite`） | `node -v` 显示 v22.5 或更高 | 安装 Node 22.5+（<https://nodejs.org>） |
| 操作系统 | Windows | 当前系统为 Windows | Cookie 解密依赖 DPAPI（绑定当前 Windows 用户），脚本与计划任务仅面向 Windows |
| 夸克浏览器 | 已安装（凭证兜底提取来源，不依赖万兴客户端） | 确认已安装夸克浏览器 | 安装夸克浏览器 |
| **首次登录流程** | 在夸克浏览器打开 <https://mm.edrawsoft.cn/app> **退出并重新登录一次** | 首次使用前手动完成 | 只有该登录流程（refreshMode=1）才把 `refresh_token` 写入 Cookie，脚本才能提取；不做则兜底提取报「EDCurrent 缺 user_id/refresh_token 字段」 |
| 管理员权限 | 仅兜底提取时需要（VSS 卷影绕过浏览器独占锁） | 首次/排障时用管理员终端手动跑一次 | 用管理员权限的终端执行 `.\scripts\run_checkin.cmd --no-delay`；已有有效凭证后的日常运行不需要 |
| 计划任务 | 已注册「万兴脑图每日签到」 | `Get-ScheduledTask -TaskName "万兴脑图每日签到"` | 运行一次 `.\注册计划任务.ps1`（需以管理员身份）；卸载用 `-Remove` |
| 路径无空格 | 文件夹路径不含空格 | 查看当前路径 | 移到无空格路径后重新注册计划任务（否则任务秒退码 1 且无日志） |

## 二、基础配置清单

| 配置项 | 位置 | 必填 | 默认值 | 缺失/失效解决方案 |
|---|---|---|---|---|
| `refresh_token` / `user_id` | `config\edraw_config.json`（自动生成，含自续命） | 否（首次留空/不建均可，自动提取回填） | 无 | 脚本每次运行自动轮换并保存新值，30 天内跑过一次即永久续命 |
| **上次运行距今 <30 天** | `config\edraw_config.json` 的 refresh_token 时效 | **是** | 30 天轮换过期 | 超 30 天未运行则 refresh_token 失效：在夸克浏览器重新登录 <https://mm.edrawsoft.cn/app>，以管理员身份再跑一次让脚本重提取 |
| `delayMinSec` | `config.json`（模板根目录） | 否 | 30（秒） | 删除该文件即恢复默认 |
| `delayMaxSec` | `config.json`（模板根目录） | 否 | 300（秒） | 删除该文件即恢复默认 |

## 三、一键自检

```powershell
.\scripts\run_checkin.cmd --status --no-delay
# 退出码 0 = 环境与凭证就绪；非 0 按上方清单逐项排查
```
