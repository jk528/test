# 万兴脑图（MindMaster/EdrawMind）签到逆向记录

> 独立文档：记录万兴脑图每日签到接口的逆向分析过程与自续命机制，可脱离原项目单独阅读。
> 逆向日期：2026-10-25　|　路线：GitHub 无现成脚本 → 网页版无签到入口 → APK DEX strings 提取接口 → refresh_token 自续命闭环

## 一、目标

实现万兴脑图每日签到（签到送 AI 点数，APP 端专属活动）的自动化：
不打开 APP / 浏览器，直接调用后端 API 完成签到，且**凭证长期免维护**。

## 二、关键结论

| 项 | 值 |
|---|---|
| 签到 | `POST https://userapi.edrawsoft.cn/api/user/{uid}/clockin`（重复签到返回 `already check in`，幂等） |
| 本周状态 | `GET .../api/user/{uid}/clockin/list`（7 天 0/1 数组） |
| 积分 | `GET .../api/user/{uid}/point` |
| **刷新令牌** | `POST https://goapi.edrawsoft.cn/api/user/ws/account/refresh/token`，表单 `refresh_token=<JWT>` → 200 `{"status":"success","data":{"token":<新2h token>,"refresh_token":<轮换新refresh_token>}}` |
| 鉴权方式 | 请求头 `Authorization: Bearer <token>`，**无任何动态签名参数** |
| token 寿命 | access token **2 小时**（HS256，iss=EdrawSoft），即用即抛 |
| refresh_token | **30 天有效，每次刷新轮换**（旧值立即失效，必须每次保存新值） |
| 凭证载体 | 夸克浏览器 Cookie `EDCurrent`（JSON，含 user_id/token/refresh_token） |
| **签名域陷阱** | localStorage 里 mm 域下的 `access_token`/`refresh_token` 是**文档协作服务**的 HS512 令牌（`sub=weixin_*`），与账号刷新接口**签名域不同**，误用报 `signature is invalid` |
| **登录入口陷阱** | Cookie 是否含 `refresh_token` 取决于登录入口参数：旧流程 `refreshMode:0` 不含；**mm.edrawsoft.cn/app 的 `refreshMode:"1"` 流程才含**。找不对入口永远拿不到完整凭证 |
| 兜底提取 | EDCurrent 是 Chromium 加密 Cookie：VSS 卷影绕过浏览器独占锁 → DPAPI 解 `Local State` 主密钥 → AES-256-GCM 解密（需管理员权限） |

## 三、逆向步骤

### 1. 调研排除：没有现成的轮子

GitHub 搜索 mindmaster / edrawmind / edrawsoft 全是破解包，无签到脚本；
网页版没有签到入口（APP 端专属活动）。只能自己逆向，走 APK 路线。

### 2. APK DEX strings 提取法（核心方法）

接口路径盲猜全 404 时的标准动作：

1. 获取 APK 改名 `.zip` 解压，取 `classes*.dex`
2. 提取连续可打印 ASCII 字符串
3. **先搜类名**确认功能存在：`CheckInPresenter`、`ClockIn` 命中 → 签到模块存在
4. **再搜接口路径**：`/api/` 前缀 → 定位 `userapi.edrawsoft.cn` 域下的 clockin 端点
5. 搜 `refresh` → 找到 `ws/account/refresh/token` 碎片 + `RefreshTokenWorker`

幸运点：**接口只要 Bearer token，无动态签名**（不像某些网盘的 kps/sign/vcode 三件套），无需逆向签名算法。

### 3. 端点探测与路径拼接

| 技巧 | 发现 |
|---|---|
| 「405 + Allow 头」是路由探测器 | 405 说明路由存在但方法错，比 404 有价值 |
| 静态站 SPA fallback 伪装 200 | account 域 `/ws/*` GET 任何路径都回 index.html，必须用 POST 区分 |
| 账号中心 SPA 配置 | `wsidUrl="https://goapi.edrawsoft.cn/"` → `ws/` 前缀归属 goapi 网关 |
| 路径拼接实测 | `POST goapi.edrawsoft.cn/api/user/ws/account/refresh/token` 回 400 `The refresh_token field is required` → **真路由确认** |

### 4. 网页版主包是 APK 的解码器

APK strings 只给出路径碎片；mm 网页版主包（index-*.js）给出请求形状：
生产代码 `refreshToken()` = `goHttp.post("/user/ws/account/refresh/token", {data:{refresh_token}})`，
响应 `{token, refresh_token}` 回写 EDCurrent Cookie，并在过期前 90 秒自动调度刷新。
同时找到 `refreshMode:"1"` 配置——解释了为什么有的 Cookie 带 refresh_token、有的不带。

### 5. 凭证全域扫描与签名域甄别

对浏览器 Cookie / localStorage / Session Storage / IndexedDB 全域扫描：

- localStorage 里能扫到 JWT 键值，但验签不过——看 `iss`/`sub`/alg 区分：
  **HS512 + `sub=weixin_*` = 协作服务**（文档协作 wss 用）；**HS256 + `iss=EdrawSoft` = 账号服务**（签到用）。
- 同名 token 分属不同签名域，混用报 `signature is invalid`。
- 最终方案：**在夸克浏览器对 mm.edrawsoft.cn/app 退出并重新登录一次**，
  EDCurrent Cookie 即携带 refresh_token，脚本提取一次后进入自续命。

### 6. 推翻初版方案

初版结论「JWT 仅 2 小时、每次现从浏览器提取」实测不可行：浏览器 Cookie 是凌晨前写入的，
每天上午的计划任务必撞 token 过期。二次逆向找到刷新接口后改为自续命闭环，
浏览器提取降级为兜底路径（config 凭证失效时，用户重新登录后可再提取）。

## 四、自续命调用链（最终形态）

```
读 config/edraw_config.json 的 refresh_token（30d，缺失/过期 → 兜底：VSS+DPAPI 解浏览器 EDCurrent 重提取）
      │
      ▼
POST goapi.edrawsoft.cn/api/user/ws/account/refresh/token
      │  返回 { token(2h), refresh_token(新30d) }
      ▼
立即写回 config（轮换后旧值即死，先存再用，防凭证丢失）
      │
      ▼
Bearer token 调 userapi：
  GET /clockin/list  本周状态（今日已签则幂等跳过）
  随机延迟 30~300 秒（防检测，--no-delay 可跳过）
  POST /clockin      签到（重复签到返回 already check in，幂等）
  GET /point         积分复查
```

每天运行 = 每天轮换，30 天有效期永远用不完，**理论上永久免维护**。

- **零依赖**：只用 Node 内置模块（`fetch` / `crypto` / `node:sqlite` / `child_process`）
- **零配置**：凭证缺失时自动从浏览器提取并回填
- **幂等**：今日已签直接跳过，定时任务重复触发、手动补跑都安全

## 五、MindMaster 服务架构速览

```
客户端侧：
  手机 APP          凭证: SharedPreferences (WS_USER_ACCESS_TOKEN / WS_USER_REFRESH_TOKEN)
  网页版 (Vue SPA)  凭证: EDCurrent Cookie (refreshMode=1 登录才含 refresh_token)
                    协作: localStorage (HS512, 另一签名域)
        │ HTTPS
        ▼
服务侧 (CN 区)：
  userapi.edrawsoft.cn   业务 API：clockin / clockin/list / point ★
  goapi.edrawsoft.cn     聚合网关：ws/account/refresh/token ★ (30d 轮换)
  account.edrawsoft.cn   纯静态站（/ws/* 是前端路由假象）
  mindapi.edrawsoft.cn   文档协作 (wss)
  masterapi.edrawsoft.cn 云文档存储/同步
```
