# Qoder 环境与配置检查清单

> 使用前逐项核对；缺失项按「解决方案」列处理。最后一节有一键自检命令。

## 一、运行环境

| 项 | 要求 | 检查方法 | 缺失解决方案 |
|---|---|---|---|
| 操作系统 | Windows | — | 脚本与计划任务仅支持 Windows |
| Node.js | 18+（可选） | `node -v` | 未安装时 `run_checkin.cmd` 会用 Qoder 客户端自带运行时兜底；兜底也失败再装 Node 18+ |
| Qoder 客户端 | 已安装（国内版 Qoder CN 或国际版均可，自动探测）；**不可卸载**——风控请求头依赖客户端自带 `runtime-info.exe` 设备指纹程序 | 查看 `%LOCALAPPDATA%\Programs\Qoder CN` 或 `%LOCALAPPDATA%\Programs\Qoder` | 安装并登录客户端；报「未找到设备指纹程序」说明客户端被卸载/移动，需重装 |
| 客户端登录态 | 已登录，存在 `auth.v1.dat` | 查看 `%APPDATA%\com.qodercn.app.stable\auth.v1.dat`（国际版为 `%APPDATA%\com.qoder.app.stable\auth.v1.dat`） | 打开 Qoder 客户端登录；token 临期脚本会自动刷新并写回，彻底失效时重新登录客户端即可 |
| ⚠️ 计划任务触发时间 | **必须 ≥ 10:30**——活动每日 10:00（UTC+8）才刷新，早于 10:00 运行必然扑空（脚本提示「今日活动尚未刷新」并跳过） | `Get-ScheduledTask -TaskName "Qoder每日签到" \| Select-Object -ExpandProperty Triggers` | `.\注册计划任务.ps1 -Time "10:40"` 重新注册（脚本会对过早的时间发出警告） |
| 计划任务 | 已注册「Qoder每日签到」 | `Get-ScheduledTask -TaskName "Qoder每日签到"` | 运行一次 `.\注册计划任务.ps1`（默认 10:40；`-Remove` 卸载） |

## 二、基础配置清单

| 配置项 | 位置 | 必填 | 默认值 | 缺失/失效解决方案 |
|---|---|---|---|---|
| `delayMinSec` | `config.json` | 否 | 30（秒） | 文件可整体删除，删除后用默认值 |
| `delayMaxSec` | `config.json` | 否 | 300（秒） | 同上 |
| 计划任务触发时间 | `注册计划任务.ps1 -Time` | 否 | 10:40 | 必须 ≥ 10:30；改时间用 `-Time "HH:mm"` 重新注册 |

## 三、一键自检

```powershell
.\scripts\run_checkin.cmd --status --no-delay
# 退出码 0 = 环境与凭证就绪；非 0 按上方清单逐项排查
```
