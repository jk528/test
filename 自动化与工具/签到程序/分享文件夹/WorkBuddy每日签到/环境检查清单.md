# WorkBuddy 环境与配置检查清单

> 使用前逐项核对；缺失项按「解决方案」列处理。最后一节有一键自检命令。

## 一、运行环境

| 项 | 要求 | 检查方法 | 缺失解决方案 |
|---|---|---|---|
| 操作系统 | Windows 10/11 | — | 不支持其他系统 |
| Node.js | 18+（可选） | `node -v` | 官网安装即可；未安装时 `run_checkin.cmd` 自动依次兜底：`C:\Program Files\nodejs\node.exe` → 注册表探测到的 `WorkBuddy.exe`（ELECTRON_RUN_AS_NODE=1 模式） |
| WorkBuddy 客户端 | 已安装且已登录；**WorkBuddy.exe 必须存在**（解密 accessToken 的密钥 atRestSecretKey 需经 WorkBuddy.exe 原生绑定获取，但无需客户端正在运行） | 注册表 `HKCU\...\Uninstall` 含 WorkBuddy，或 `%LOCALAPPDATA%\Programs\WorkBuddy\WorkBuddy.exe` 等常见路径存在 | 安装 WorkBuddy 客户端并登录；报「无法获取 atRestSecretKey」时重装或重新登录 |
| 登录态数据 | `%LOCALAPPDATA%\CodeBuddyExtension\Data\Public\auth\workbuddy-desktop.info` 存在（兜底取同目录最新 .info 文件） | 文件是否存在 | 打开 WorkBuddy 客户端登录；报「登录态已过期」时重新登录客户端即可 |
| 解密密钥 | 无需手填：脚本自动经 WorkBuddy.exe 获取，并缓存到 `scripts\.temp\wb_key.json` | — | 客户端升级致密钥轮换时脚本自动清缓存重取；仍失败则打开客户端重新登录一次 |
| 网络 | 可访问 `https://copilot.tencent.com` | `curl https://copilot.tencent.com` | 检查网络 / 代理设置 |

## 二、基础配置清单

| 配置项 | 位置 | 必填 | 默认值 | 缺失/失效解决方案 |
|---|---|---|---|---|
| delayMinSec / delayMaxSec | config.json | 否 | 30 / 300 | 删除 config.json 即用默认 |
| 计划任务 | 注册计划任务.ps1 | 否（仅手动运行则无需） | 每天 00:10 | 运行一次 `.\注册计划任务.ps1`；`-Time "09:30"` 改触发时间，`-Remove` 卸载 |

无需任何手填密钥类配置：凭证与密钥均由脚本自动从本机客户端环境取用。

## 三、一键自检

```powershell
.\scripts\run_checkin.cmd --status --no-delay
# 退出码 0 = 环境与凭证就绪；非 0 按上方清单逐项排查
```
