# CodeArts 环境与配置检查清单

> 使用前逐项核对；缺失项按「解决方案」列处理。最后一节有一键自检命令。

## 一、运行环境

| 项 | 要求 | 检查方法 | 缺失解决方案 |
|---|---|---|---|
| 操作系统 | Windows 10/11 | — | 不支持其他系统（解密依赖 DPAPI，绑定当前 Windows 用户） |
| Node.js | **22.13+（硬性要求，推荐 24+）**：解密本地凭证依赖内置 `node:sqlite` 模块 | `node -v` | 官网安装 Node 22.13+ / 24+；未安装时 `run_checkin.cmd` 自动依次兜底：`C:\Program Files\nodejs\node.exe` → 注册表探测到的 `codearts-agent.exe`（ELECTRON_RUN_AS_NODE=1 模式，若该运行时缺少 node:sqlite 会明确报错） |
| CodeArts Agent 客户端 | 已安装且已登录华为账号；**建议保持客户端运行**（最小化即可）：STS 凭证 2 小时有效，客户端在线时每小时自动续期写回 | 数据目录 `%APPDATA%\codearts-agent\` 存在 | 安装 CodeArts Agent 客户端并登录华为账号 |
| 登录态数据 | `%APPDATA%\codearts-agent\User\globalStorage\state.vscdb` 存在且含华为云会话 secret | 自检命令输出「凭证 OK」 | 打开客户端登录华为账号；报「凭证已过期且客户端未在线续期」时打开客户端让其自动续期后重试 |
| 解密密钥 | `%APPDATA%\codearts-agent\Local State` 内含 DPAPI 加密主密钥，且当前 Windows 用户与登录客户端时一致 | 文件是否存在 | 换 Windows 用户后需在新用户下打开客户端重新登录 |
| 网络 | 可访问 `https://snap-access.cn-north-4.myhuaweicloud.com` | `curl https://snap-access.cn-north-4.myhuaweicloud.com` | 检查网络 / 代理设置 |

## 二、基础配置清单

| 配置项 | 位置 | 必填 | 默认值 | 缺失/失效解决方案 |
|---|---|---|---|---|
| delayMinSec / delayMaxSec | config.json | 否 | 30 / 300 | 删除 config.json 即用默认 |
| 计划任务 | 注册计划任务.ps1 | 否（仅手动运行则无需） | 每天 00:10 | 运行一次 `.\注册计划任务.ps1`；`-Time "09:30"` 改触发时间，`-Remove` 卸载 |

无需任何手填密钥类配置：凭证由脚本自动从本机客户端数据目录解密取用。

## 三、一键自检

```powershell
.\scripts\run_checkin.cmd --status --no-delay
# 退出码 0 = 环境与凭证就绪；非 0 按上方清单逐项排查
```
