# 百度网盘 环境与配置检查清单

> 使用前逐项核对；缺失项按「解决方案」列处理。最后一节有一键自检命令。

## 一、运行环境

| 项 | 要求 | 检查方法 | 缺失解决方案 |
|---|---|---|---|
| Node.js | 18+（用到内置 `fetch`） | `node -v` 显示 v18 或更高 | 安装 Node 18+（<https://nodejs.org>） |
| 操作系统 | Windows | 当前系统为 Windows | 脚本与计划任务仅面向 Windows，无跨平台方案 |
| 浏览器登录态 | 已登录 pan.baidu.com | 浏览器打开 pan.baidu.com 能看到自己的文件 | 先登录百度网盘网页版 |
| 计划任务 | 已注册「百度网盘每日签到」 | `Get-ScheduledTask -TaskName "百度网盘每日签到"` | 运行一次 `.\注册计划任务.ps1`（需以管理员身份）；卸载用 `-Remove` |
| 路径无空格 | 文件夹路径不含空格 | 查看当前路径 | 移到无空格路径后重新注册计划任务（否则任务秒退码 1 且无日志） |

## 二、基础配置清单

| 配置项 | 位置 | 必填 | 默认值 | 缺失/失效解决方案 |
|---|---|---|---|---|
| `cookie`（含 BDUSS） | `config\baidupan_config.json` | **是**（无自动提取） | 无 | 浏览器登录 pan.baidu.com，F12 → 网络 → 任意请求复制整段 Cookie（至少含 `BDUSS`/`STOKEN`/`BAIDUID`）；参照 `config\baidupan_config.example.json` 填写。失效表现：`errno=-6` / `error_code=-6`，重新复制即可 |
| 环境变量 `BAIDUPAN_COOKIE` | 系统/用户环境变量 | 否（可覆盖 cookie） | 无 | 不设置则读取配置文件 |
| `delayMinSec` | `config.json`（模板根目录） | 否 | 30（秒） | 删除该文件即恢复默认 |
| `delayMaxSec` | `config.json`（模板根目录） | 否 | 300（秒） | 删除该文件即恢复默认 |

## 三、一键自检

```powershell
.\scripts\run_checkin.cmd --status --no-delay
# 退出码 0 = 环境与凭证就绪；非 0 按上方清单逐项排查
```
