# 天翼云盘 环境与配置检查清单

> 使用前逐项核对；缺失项按「解决方案」列处理。最后一节有一键自检命令。

## 一、运行环境

| 项 | 要求 | 检查方法 | 缺失解决方案 |
|---|---|---|---|
| Node.js | **22.5+**（推荐 24；浏览器 Cookie 提取用到内置 `node:sqlite`） | `node -v` 显示 v22.5 或更高 | 安装 Node 22.5+（<https://nodejs.org>） |
| 操作系统 | Windows | 当前系统为 Windows | Cookie 解密依赖 DPAPI（绑定当前 Windows 用户），脚本与计划任务仅面向 Windows |
| 夸克浏览器登录态 | 夸克浏览器已登录 cloud.189.cn 网页版 | 夸克浏览器打开 <https://cloud.189.cn> 已登录 | **核心依赖**：Cookie 自动提取与失效续期都靠它；请先登录 |
| 管理员权限 | 仅 Cookie 失效重提取时需要（VSS 卷影） | 首次/排障时用管理员终端手动跑一次 | 用管理员权限的终端执行 `.\scripts\run_checkin.cmd --no-delay`；日常已有有效 Cookie 时不需要 |
| 计划任务 | 已注册「天翼云盘每日签到」 | `Get-ScheduledTask -TaskName "天翼云盘每日签到"` | 运行一次 `.\注册计划任务.ps1`（需以管理员身份）；卸载用 `-Remove` |
| 路径无空格 | 文件夹路径不含空格 | 查看当前路径 | 移到无空格路径后重新注册计划任务（否则任务秒退码 1 且无日志） |

## 二、基础配置清单

| 配置项 | 位置 | 必填 | 默认值 | 缺失/失效解决方案 |
|---|---|---|---|---|
| `cookie` | `config\tianyi_config.json`（自动缓存） | 否（推荐有；留空自动提取） | 无 | 脚本自动从夸克浏览器提取并回写；失效时自动重提取（需夸克仍登录 + 管理员权限） |
| `username` / `password` | `config\tianyi_config.json` | 否（仅兜底） | 无 | Cookie 与自动提取都失败时的兜底。**开启设备锁的账号会触发短信二次验证（result=-133），密码链路无法全自动**，建议保持夸克登录态走 Cookie 链路 |
| 环境变量 `TIANYI_COOKIE` / `TIANYI_USERNAME` / `TIANYI_PASSWORD` | 系统/用户环境变量 | 否（可覆盖） | 无 | 不设置则读取配置文件 |
| `delayMinSec` | `config.json`（模板根目录） | 否 | 30（秒） | 删除该文件即恢复默认 |
| `delayMaxSec` | `config.json`（模板根目录） | 否 | 300（秒） | 删除该文件即恢复默认 |

## 三、一键自检

```powershell
.\scripts\run_checkin.cmd --status --no-delay
# 退出码 0 = 环境与凭证就绪；非 0 按上方清单逐项排查
```
