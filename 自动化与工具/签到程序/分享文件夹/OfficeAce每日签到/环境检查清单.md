# OfficeAce（果办） 环境与配置检查清单

> 使用前逐项核对；缺失项按「解决方案」列处理。最后一节有一键自检命令。

## 一、运行环境

| 项 | 要求 | 检查方法 | 缺失解决方案 |
|---|---|---|---|
| 操作系统 | Windows | — | 脚本与计划任务仅支持 Windows |
| Node.js | 18+（可选） | `node -v` | 未安装时 `run_checkin.cmd` 会用果办客户端自带运行时兜底；兜底也失败再装 Node 18+ |
| 果办客户端 | 已安装 | 查看 `%LOCALAPPDATA%\Programs\OfficeAce` 是否存在 | 安装果办客户端 |
| 客户端登录态 | 已登录 | 查看 `%USERPROFILE%\.office-claw\session.cookie` 是否存在 | 打开客户端登录；报「本地会话已失效」时重新登录即可（Cookie 有效期约一个月） |
| ⚠️ **客户端运行中** | **签到执行时果办客户端必须处于运行状态**（签到走客户端本地 API `127.0.0.1`，由客户端进程承载云端凭证签名，无法离线直连；这是最易缺的环境项） | 任务管理器确认 OfficeAce 进程存在 | 启动果办客户端后重试；计划任务时间设在电脑已开机、客户端已启动之后 |
| 计划任务 | 已注册「OfficeAce每日签到」，触发时间在客户端已运行时段 | `Get-ScheduledTask -TaskName "OfficeAce每日签到"` | 运行一次 `.\注册计划任务.ps1`（`-Time "10:00"` 改时间，`-Remove` 卸载） |

## 二、基础配置清单

| 配置项 | 位置 | 必填 | 默认值 | 缺失/失效解决方案 |
|---|---|---|---|---|
| `delayMinSec` | `config.json` | 否 | 30（秒） | 文件可整体删除，删除后用默认值 |
| `delayMaxSec` | `config.json` | 否 | 300（秒） | 同上 |
| 计划任务触发时间 | `注册计划任务.ps1 -Time` | 否 | 00:10 | 默认时间在凌晨、客户端多未运行，建议改到客户端已启动时段（如 `-Time "10:00"`） |

## 三、一键自检

```powershell
.\scripts\run_checkin.cmd --status --no-delay
# 退出码 0 = 环境与凭证就绪；非 0 按上方清单逐项排查
```
