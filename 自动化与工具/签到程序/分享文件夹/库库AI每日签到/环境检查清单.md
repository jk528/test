# 库库AI 环境与配置检查清单

> 使用前逐项核对；缺失项按「解决方案」列处理。最后一节有一键自检命令。

## 一、运行环境

| 项 | 要求 | 检查方法 | 缺失解决方案 |
|---|---|---|---|
| 操作系统 | Windows | — | 脚本与计划任务仅支持 Windows |
| Node.js | 18+（可选） | `node -v` | 未安装时 `run_checkin.cmd` 会用库库AI 客户端自带运行时兜底；兜底也失败再装 Node 18+ |
| 百度账号 | 已开通库库AI | 浏览器能正常打开并登录 kuku.baidu.com | 用浏览器登录一次 kuku.baidu.com 即可开通 |
| ⚠️ **凭证配置文件** | **必填** `config\kuku_config.json`（含 `bduss`） | 查看该文件是否存在且 `bduss` 非空 | 浏览器登录文库（kuku.baidu.com）→ F12 → Application/应用程序 → Cookies → 复制 BDUSS；参照模板自带的 `config\kuku_config.example.json` 复制一份改名填入 |
| 计划任务 | 已注册「库库AI每日签到」 | `Get-ScheduledTask -TaskName "库库AI每日签到"` | 运行一次 `.\注册计划任务.ps1`（默认 00:10；`-Time` 改时间，`-Remove` 卸载） |

## 二、基础配置清单

| 配置项 | 位置 | 必填 | 默认值 | 缺失/失效解决方案 |
|---|---|---|---|---|
| `bduss` | `config\kuku_config.json`（或环境变量 `KUKU_BDUSS`） | **是** | 无 | 从浏览器 Cookie 复制 BDUSS 填入；报「登录态已失效（errno -6）」说明过期或复制错误，重新取一遍更新 |
| `stoken` | `config\kuku_config.json`（或环境变量 `KUKU_STOKEN`） | 否 | 空 | 留空且填了 `ptoken` 时脚本自动换取；失效后重新从 Cookie 复制或删除让脚本重取 |
| `ptoken` | `config\kuku_config.json` | 否 | 空 | 用于自动换取 STOKEN；可留空 |
| `uid` | `config\kuku_config.json`（或环境变量 `KUKU_UID`） | 否 | 空（服务端按 BDUSS 识别） | 可留空 |
| `version` | `config\kuku_config.json` | 否 | 1.6.28 | 可留空/删除 |
| `user_agent` | `config\kuku_config.json` | 否 | 带 GenFlowPro 标识的默认 UA | 可留空/删除 |
| `delayMinSec` | `config\kuku_config.json` | 否 | 30（秒） | 可留空/删除 |
| `delayMaxSec` | `config\kuku_config.json` | 否 | 300（秒） | 可留空/删除 |
| 计划任务触发时间 | `注册计划任务.ps1 -Time` | 否 | 00:10 | 改时间用 `.\注册计划任务.ps1 -Time "HH:mm"` |

> 注意：`kuku_config.json` 须为无 BOM 的纯 JSON（无注释/多余逗号），解析失败时用 VS Code 另存为 UTF-8。
> BDUSS 等同账号密码：该文件已被 `.gitignore` 排除，绝不提交 Git、绝不分享。

## 三、一键自检

```powershell
.\scripts\run_checkin.cmd --status --no-delay
# 退出码 0 = 环境与凭证就绪；非 0 按上方清单逐项排查
```
