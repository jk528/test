# TeleAgent 环境与配置检查清单

> 使用前逐项核对；缺失项按「解决方案」列处理。最后一节有一键自检命令。

## 一、运行环境

| 项 | 要求 | 检查方法 | 缺失解决方案 |
|---|---|---|---|
| 操作系统 | Windows 10/11 | — | 不支持其他系统（解密依赖 DPAPI，绑定当前 Windows 用户） |
| Node.js | 18+（可选） | `node -v` | 官网安装即可；未安装时 `run_checkin.cmd` 自动依次兜底：`C:\Program Files\nodejs\node.exe` → 客户端自带 Node 运行时 `%USERPROFILE%\.local\share\TeleAgent\runtimes\node\node.exe` → 注册表探测到的 `TeleAgent.exe`（ELECTRON_RUN_AS_NODE=1 模式） |
| TeleAgent 客户端 | 已安装且已登录 | 用户数据目录 `%USERPROFILE%\.local\share\TeleAgent\` 存在 | 安装 TeleAgent 客户端并登录 |
| 登录态数据 | `%USERPROFILE%\.local\share\TeleAgent\users\<用户目录>\app-auth\token.json` 存在（由 `current-owner.json` 指向当前用户目录） | 自检命令输出「检测到登录态文件」 | 打开 TeleAgent 客户端登录；报「登录态已过期」时重新登录客户端即可 |
| 解密密钥 | `%USERPROFILE%\.local\share\TeleAgent\Local State` 内含 DPAPI 加密主密钥，且当前 Windows 用户与登录客户端时一致 | 文件是否存在 | 换 Windows 用户后 DPAPI 解不开，需在新用户下打开客户端重新登录 |
| 设备信息 | `%USERPROFILE%\.local\share\TeleAgent\app-auth\device-meta.json` 含 deviceId | 文件是否存在 | 可缺省（请求头置空）；登录客户端后通常自动生成 |
| 网络 | 可访问 `https://agent.teleai.com.cn` | `curl https://agent.teleai.com.cn` | 检查网络 / 代理设置 |

## 二、基础配置清单

| 配置项 | 位置 | 必填 | 默认值 | 缺失/失效解决方案 |
|---|---|---|---|---|
| delayMinSec / delayMaxSec | config.json | 否 | 30 / 300 | 删除 config.json 即用默认 |
| 计划任务 | 注册计划任务.ps1 | 否（仅手动运行则无需） | 每天 00:10 | 运行一次 `.\注册计划任务.ps1`；`-Time "09:30"` 改触发时间，`-Remove` 卸载 |

无需任何手填密钥类配置：凭证由脚本自动从本机客户端数据目录解密取用。

## 三、一键自检

```powershell
.\scripts\run_checkin.cmd --status --no-delay
# 退出码 0 = 环境与凭证就绪；非 0 按上方清单逐项排查
```
