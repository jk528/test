## 三、每回输出模板（严格遵守，逐字照此结构）

```
### 第 N 回　标题上联　标题下联

**主线**：（30 字以内，"谁+做了什么+结果"）

**手法片段**：

1. **手法名**：「原文引用（50 字以内，逐字摘自该回文本）」——解析：信号与效果，一到两句，落在具体文字上，不空评。

2. ……

**本回命中**：手法A、手法B、手法C
```

格式细则：

1. 标题写作 `### 第 N 回　上联　下联`——**阿拉伯数字**，回号与回目之间、上下联之间用**全角空格 `　`** 分隔；回目取自源文件首行（形如"第三十一回　猪八戒义激猴王　孙行者智降妖怪"，丢掉"第三十一回"部分只留上下联）。
2. 回与回之间空一行；`**本回命中**` 行之后空一行再接下一回。
3. **片段条数 = 该回命中的手法数**（全集口径，不是精选）：该回识别到几种手法就写几条片段，不得只挑几个典型的写。
4. 同一手法**只举 1 个**最典型片段，不重复举例。
5. 两手法同源、无法拆成两条时，可**合条**写作 `**手法A（手法B）**` 或 `**手法A/手法B**`——此时片段条数可略少于手法数，但 `**本回命中**` 仍须列全。
6. `**本回命中**` 行的手法名以**顿号 `、`** 分隔，**不要**加"（N项）"之类后缀。
7. 每回区块内**不得**出现 `##` 级标题、不得出现"第一批"之类分组标题、不得写文件总标题。
8. 解析部分可直接以 `——解析：` 起（也可用 `——` 起），但每条必须给出"信号（原文怎么写的）→ 效果（这样达成什么）"。
9. 实测《西游记》单回命中约 **14–20** 个手法，即每回约 14–20 条片段。

## 四、质量要求

1. **引文逐字准确**：直接来自你读取的文本，禁止凭记忆改写或编造，禁止改写标点。
2. **解析克制具体**：不堆形容词；**禁用**"淋漓尽致""堪称经典""栩栩如生""跃然纸上"这类空评。
3. 每条解析一两句，必须落在具体文字上（指出是哪个词、哪个动作、哪个数字在起作用）。
4. 回号按你负责的区间**连续升序**排列。
5. 源文本存在个别录入讹字（如"不之"当作"不知"），**引文照录原件**，不要自行订正。

## 五、写入方式（直接决定任务成败）

**绝对不要**把全部回目做完才一次性写入——单次写入过大极易失败。

1. 完成**前 2 回**后，用 Write 工具把已完成的 2 回内容**一次性写入**你被指定的目标文件；
2. 之后每再完成 **1–2 回**，用 Edit 工具把新内容**追加**到该文件末尾（不要重复已写入的段落，不要加文件总标题）；
3. 若某次写入因内容过大失败，把该次内容拆成两半重试，先写小的、再追加大的；
4. 全部完成后，用 Read 工具回读目标文件，确认回目数量与顺序正确。
