# 《三国演义》第37-48回 白描写作手法逐回分析

### 第三十七回　司马徽再荐名士　刘玄德三顾草庐
**主线**：徐母自缢，玄德三顾草庐，风雪中遍访不遇。

**手法片段**：
1. **引语留白**：「骂得徐庶拜伏于地，不敢仰视，母自转入屏风后去了。少顷，家人出报曰：'老夫人自缢于梁间。'」——不写徐母如何走向死地，只写"转入屏风后"这一个消失动作，再由家人"出报"补叙结果。死亡被推到幕后，读者只听见"少顷"二字之间的沉默，空白处比正面描写更重。
2. **显示而非讲述**：「童子曰：'我记不得许多名字。'玄德曰：'你只说刘备来访。'」——玄德一长串官衔报出口，童子一句"记不得许多名字"便轻轻消解。不评玄德是否迂腐，只让两个声调碰撞，人物性情全在对话里自显。
3. **回声照应**：「行无数里，忽然朔风凛凛，瑞雪霏霏：山如玉簇，林似银妆。」——前文"遥望卧龙冈，果然清景异常"是晴日清景，此处再写景物却已换为风雪，同一地点两番落笔，气候映衬心境，由仰慕的轻松转为求贤的艰辛。
4. **独句落点**：「玄德曰：'此亦隐者之言也。'」——崔州平一番"治乱无常、逆天者劳"的大论之后，张飞骂"腐儒"，玄德只此一句收束。不辩驳、不赞同，把判断权留给读者，独句落地即止。
5. **第三拍转向**：「玄德闻歌曰：'此真卧龙矣！'滚鞍下马……诸葛均在后曰：'此非卧龙家兄，乃家兄岳父黄承彦也。'」——一误崔州平，再误石广元、孟公威，第三拍"此真卧龙矣"把期待推到顶点，随即被"乃家兄岳父"一句翻落。三访未成先经三误，每误一次，孔明的缺席反而更重一分。
6. **预叙**：「徽出门仰天大笑曰：'卧龙虽得其主，不得其时，惜哉！'」——孔明尚未出场，全书的终局已被司马徽一句笑先说出：得其主而不得其时。读者自此带着"惜哉"二字读此后一切用兵，隆中故事从源头就染上宿命底色。

**本回命中**：引语留白、显示而非讲述、回声照应、独句落点、第三拍转向、预叙

### 第三十八回　定三分隆中决策　战长江孙氏报仇
**主线**：三顾始见孔明，隆中对定三分；江东徐氏复仇，甘宁归吴。

**手法片段**：
1. **预叙**：「翻身将起，忽又朝里壁睡着。」——孔明"将起"是读者的期待被提起，"忽又朝里壁睡着"立即落空。一个翻身动作预埋了整回的节奏：好事多磨，人才难得一见。
2. **引语承载**：「大梦谁先觉？平生我自知，草堂春睡足，窗外日迟迟。」——四句诗不写孔明如何"高卧"，只以诗代行。醒来第一件事不是问来客，而是吟诗自况，人物风骨全由这二十字立住，比任何旁白都精准。
3. **动作承载**：「孔明笑曰：'愿闻将军之志。'玄德屏人促席而告曰……」——"屏人促席"四个字便完成从客套到密谋的切换。不写心理，不写氛围渲染，一个动作就让读者知道下面的话是"真话"。
4. **结果先行**：「先取荆州为家，后即取西川建基业，以成鼎足之势，然后可图中原也。」——三分天下尚未起步，隆中对已把终局先说出。先果后因的结构让读者全程带着"鼎足"之图去读后续，叙事获得了方向感。
5. **显示而非讲述**：「玄德拱立阶下。半晌，先生未醒。……童子欲报。玄德曰：'且勿惊动。'」——不写"玄德敬贤"，只写"拱立"与"且勿惊动"两个静止动作，任一个时辰流走；同屋张飞扬言"放一把火"，一静一动互照，求贤的诚意全在站姿里自显。
6. **蒙太奇并置**：「孔明曰：'曹操于冀州作玄武池以练水军，必有侵江南之意。可密令人过江探听虚实。'玄德从之，使人往江东探听。」——"使人往江东探听"是本回的剪辑点：镜头自此从隆中切往江东的练兵、复仇与聚将。荆州得贤与江东备战两条线并置一回之内，读者预先看见两股力量正朝同一场大战积攒。

**本回命中**：预叙、引语承载、动作承载、结果先行、显示而非讲述、蒙太奇并置

### 第三十九回　荆州城公子三求计　博望坡军师初用兵
**主线**：刘琦求计上楼抽梯，孔明博望初用火攻。

**手法片段**：
1. **第三拍转向**：「琦曰：'琦有一古书，请先生一观。'乃引孔明登一小楼，孔明曰：'书在何处？'琦泣拜曰……」——"请看古书"是第一拍，登楼是第二拍，"书在何处"逼出第三拍：真正的目的不是书，是"上不至天，下不至地"的密室求计。三次转折才到底牌，节奏层层递进。
2. **独句落点**：「孔明微笑。」——刘琦泣拜求救，玄德求计于孔明，孔明先说"此家事，亮不敢与闻"，旋即"微笑"。不解释为什么笑，让读者自行体会那笑里已是成竹在胸。
3. **显示而非讲述**：「张飞大笑曰：'我们都去厮杀，你却在家里坐地，好自在！'」——不评关张不服，只让张飞一句牢骚把军中疑虑全部带出。孔明回以"剑印在此，违令者斩"，对话对峙中人物关系自显。
4. **重复升级**：「云约走十余里，回马又战。不数合又走。」——"又战""又走"两次重复，每次都短促，节奏从诱敌到追击不断收紧，直到"一声炮响"火攻炸开，重复本身成了引信。
5. **结果先行**：「命孙乾、简雍准备庆喜筵席，安排功劳簿伺候。」——大战未发一箭，庆功的筵席与功劳簿已经备好。战局的结果在开打之前就由后勤细节提前泄露，悬念不在胜负而在"如何胜"，读者的注意力被全程引向调度本身。
6. **动作收尾**：「车中端坐一人，乃孔明也。关、张下马拜伏于车前。」——从领令时"看他如何调度"到战后"拜伏于车前"，关张由疑到服之间没有一句心理交代，全回的心结靠这一拜收拢。态度的转变落在下马与伏地的动作上，胜过任何"众人叹服"的陈述。

**本回命中**：第三拍转向、独句落点、显示而非讲述、重复升级、结果先行、动作收尾

### 第四十回　蔡夫人议献荆州　诸葛亮火烧新野
**主线**：刘表托孤而亡，蔡氏献荆州降曹；孔明火烧新野退敌。

**手法片段**：
1. **独句落点**：「二子曰：'破巢之下，安有完卵乎？'」——孔融被执、将斩，幼子对坐弈棋不避，只此一句。不写恐惧、不写哭号，一句话把"必死"的判断和从容的态度同时落地，悲剧力量全靠节制。
2. **显示而非讲述**：「蔡夫人闻之大怒，关上内门；使蔡瑁、张允二人把住外门。」——刘表病中写遗嘱，蔡夫人不争辩、不发话，直接"关上内门""把住外门"。两个动作就把擅权的手段和刘表的孤立同时显示，比写"蔡氏专权"有力十倍。
3. **结果先行**：「前番一把火，烧了夏侯惇大半人马；今番曹军又来，必教他中这条计。」——火攻新野尚未展开，孔明先说结果。读者带着"又是一条计"的预期进入后文，叙事节奏被加速。
4. **事实并置**：「只见四门大开……城中亦不见一人，竟是一座空城了。」——曹仁入城，期待抵抗，看见的是"四门大开""不见一人"。两件相反的事实并置，不解释"为什么空"，让读者自己感到恐惧。
5. **动作收尾**：「行到博陵渡口，只听喊声大起，一军拦路，当先大将，乃张飞也，大叫：'曹贼快来纳命！'」——全回从孔融之死一路铺到火攻水淹，结尾不落战绩盘点，而落在张飞渡口一拦、一声断喝上。两场屠杀之后以单人单骑的拦路动作收束，悬念被直接顶进下一回。

**本回命中**：独句落点、显示而非讲述、结果先行、事实并置、动作收尾

### 第四十一回　刘玄德携民渡江　赵子龙单骑救主
**主线**：玄德携民渡江，赵云长坂坡单骑救主。

**手法片段**：
1. **动作承载**：「玄德于船上望见，大恸曰：'为吾一人而使百姓遭此大难，吾何生哉！'欲投江而死，左右急救止。」——"欲投江而死"是表演还是真情不重要，重要的是这一个动作把"以人为本"从口号变成了可被百姓目击的行为。百姓的反应"闻者莫不痛哭"才是动作的落点。
2. **名词列锦**：「砍倒大旗两面，夺槊三条；前后枪刺剑砍，杀死曹营名将五十余员。」——"大旗""槊""名将"，名词密集排列，不渲染血腥场面，只以物代人、以数代量，战斗的烈度全在物件的清单里。
3. **长短句换挡**：「赵云三回五次请夫人上马，夫人只不肯上马。四边喊声又起。」——长句铺垫的焦灼被"四边喊声又起"五个字一刀截断。前面的重复请求是慢节奏的情感纠缠，短句一到，生死立刻逼上眉睫。
4. **显示而非讲述**：「糜芳面带数箭，踉跄而来，口言：'赵子龙反投曹操去了也！'」——不写"糜芳狼狈"，只写"面带数箭，踉跄"，视觉信号直接到位；不评赵云是否叛变，只让糜芳口中一句话引发张飞的暴怒，叙事张力全靠显示。
5. **引语承载**：「玄德泣曰：'举大事者必以人为本。今人归我，奈何弃之？'百姓闻玄德此言，莫不伤感。」——众将皆劝"暂弃百姓，先行为上"，玄德不辩利害，只此一句。一句台词扛起"携民渡江"全回的主题，紧随其后的"莫不伤感"以民声为引语作答，人物形象与君民信义同时立住。

**本回命中**：动作承载、名词列锦、长短句换挡、显示而非讲述、引语承载

### 第四十二回　张翼德大闹长坂桥　刘豫州败走汉津口
**主线**：张飞喝退曹军，玄德败走汉津口会合关羽刘琦。

**手法片段**：
1. **动作承载**：「玄德接过，掷之于地曰：'为汝这孺子，几损我一员大将！'」——"掷之于地"是全回最有力的单一动作。不写玄德内心如何权衡，一个掷的动作把"重将轻子"的姿态固化为千古名场面，赵云"泣拜"的忠义因此被推到顶点。
2. **重复升级**：「飞乃厉声大喝曰：'我乃燕人张翼德也！谁敢与我决一死战？'……飞睁目又喝曰：'燕人张翼德在此！谁敢来决死战？'……乃挺矛又喝曰：'战又不战，退又不退，却是何故！'」——三喝，一句比一句短，一句比一句逼。第一喝报姓名，第二喝加"在此"，第三喝只剩质问。重复中删除修饰，压迫感逐级攀升，到"夏侯杰惊得肝胆碎裂"自然引爆。
3. **陌生化**：「黄口孺子，怎闻霹雳之声；病体樵夫，难听虎豹之吼。」——不以战场术语写喝声之威，而以"黄口孺子""病体樵夫"两个不相干的意象来比喻曹军的崩溃，把恐惧从军事层面拉到生理层面，让读者重新感受那一声吼的物理冲击。
4. **显示而非讲述**：「骤马望西而走，冠簪尽落，披发奔逃。」——不写"曹操魂飞魄散"，只写冠簪落尽、头发披散：堂堂丞相的仪态在那一声喝之后全散了架。狼狈与恐惧全由外观自显，一个形象细节胜过百万大军溃逃的统计。
5. **动作收尾**：「鲁肃遂别了玄德、刘琦，与孔明登舟，望柴桑郡来。」——全回从长坂桥头的一声吼写到江面的重逢议事，结尾不落一句议论，只让一叶扁舟载走孔明。出使江东的大计被压缩成"登舟"一个动作，回末诗"只因诸葛扁舟去"即由此生出，下一回的舌战自此启程。

**本回命中**：动作承载、重复升级、陌生化、显示而非讲述、动作收尾

### 第四十三回　诸葛亮舌战群儒　鲁子敬力排众议
**主线**：孔明舌战江东群儒，以言激孙权。

**手法片段**：
1. **引语承载**：「鹏飞万里，其志岂群鸟能识哉？」——张昭以"管仲乐毅"相难，孔明不辩战绩，先以一比喻把对方降格为"群鸟"。整场辩论中孔明几乎全靠引语和比喻推进，不正面论证，而是用意象控制对话的制高点。
2. **第三拍转向**：「权起更衣，鲁肃随于权后。」——堂上张昭主降、众谋士附和是第一拍，孙权"沉吟不语"是暗流，"起更衣"则是物理空间的转换。场景从公堂转到后廊，密谈由此展开，叙事从"群声"收束到"一对一"。
3. **显示而非讲述**：「孔明致玄德之意毕，偷眼看孙权：碧眼紫髯，堂堂一表。孔明暗思：'此人相貌非常，只可激，不可说。'」——不叙述"孔明判断孙权性格"，而写"偷眼看"这个动作加内心独白，把策略的生成过程显示给读者，人物心机自显。
4. **情绪延迟**：「权听了孔明此言，不觉勃然变色，拂衣而起，退入后堂。众皆哂笑而散。」——激将法的成功不在当场，而在鲁肃来回穿梭之后"权回嗔作喜"才显效。情绪从"拂衣而起"到"回嗔作喜"隔了一整个来回，延迟让效果更真实。
5. **重复升级**：「张昭并无一言回答……虞翻不能对……步骘默然无语……薛综满面羞惭，不能对答……陆绩语塞……程德枢不能对。」——七儒轮番问难，七次以"不能对"收场；孔明的反击却逐次加码，由"哑然而笑"到"厉声曰"，再到"不足与语""请勿复言"。同一回合重复七遍而烈度攀升，直到"众人见孔明对答如流，尽皆失色"。
6. **问题收尾**：「吴国太曰：'汝何不记吾姐临终之语乎？'……毕竟说着甚的，且看下文分解。」——回末以一问收束：国太点破"临终之语"，孙权"如醉方醒"，但那句话的内容偏被扣住，叙事悬停在"究竟说的什么"上。答案押给下一回，问题本身成了钩子。

**本回命中**：引语承载、第三拍转向、显示而非讲述、情绪延迟、重复升级、问题收尾

### 第四十四回　孔明用智激周瑜　孙权决计破曹操
**主线**：孔明以铜雀台赋激周瑜，孙权决计破曹。

**手法片段**：
1. **动作承载**：「权拔佩剑砍面前奏案一角曰：'诸官将有再言降操者，与此案同！'」——不写孙权"下定决心"的内心过程，只写一剑砍去奏案一角。"砍案"这个动作把犹豫一劈为二，决断不在言语而在动作，读者看见的是物理的断裂。
2. **引语承载**：「揽二乔于东南兮，乐朝夕之与共。」——孔明诵赋至此，周瑜"勃然大怒"。不解释"二乔"是谁，引语本身就是引信。赋文之美与激将之毒并存于同一句，文学的雅和策略的狠被装进一行字里。
3. **事实并置**：「程普曰：'都督知江东早晚属他人否？'……黄盖忿然而起，以手拍额曰：'吾头可断，誓不降曹！'」——文官来劝降、武将来请战，两组人马前后脚入场，周瑜对两边都说"吾亦欲降久矣""吾正欲与曹操决战"。同样的话对不同的人说，事实并置之下周瑜的城府不点自明。
4. **陌生化**：「江东去此两人，如大木飘一叶，太仓减一粟耳。」——不直接说"送两个女人给曹操"，而以"大木飘一叶""太仓减一粟"比喻江东失此二人无关紧要。用日常尺度的比喻来处理"美人计"的荒诞，让读者在陌生的意象里重新掂量那场战争的荒谬。
5. **显示而非讲述**：「有要战者，有要降者，互相争论。瑜曰：'不必多言，来日都到府下公议。'众乃辞去。周瑜冷笑不止。」——四拨人马轮番进言：文官劝降，武将主战，周瑜一概"自有定议"，末了只"冷笑不止"。不写他心中早有成算，四个字把全局在握的从容和对纷纭众议的不屑一并显出。
6. **预叙**：「周瑜谢出，暗忖曰：'孔明早已料着吴侯之心。其计画又高我一头。久必为江东之患，不如杀之。'」——破曹大计刚定，周瑜已在暗忖里给孔明定了性："久必为江东之患"。一句内心独白预演此后十几回的瑜亮斗法，群英会、借箭、受刑皆由此生发；读者带着这份预知看两人并肩，合作与杀机同时在场。

**本回命中**：动作承载、引语承载、事实并置、陌生化、显示而非讲述、预叙

### 第四十五回　三江口曹操折兵　群英会蒋干中计
**主线**：三江口初战曹军败，群英会蒋干盗书中反间计。

**手法片段**：
1. **引语留白**：「瑜口内含糊曰：'子翼，我数日之内，教你看操贼之首！'干勉强应之。瑜又曰：'子翼，且住！……教你看操贼之首！……'及干问之，瑜又睡着。」——周瑜"含糊""睡着"之间的话，句子被省略号截断，话说到一半就灭。留白处全是蒋干的恐惧和联想，读者和蒋干一起在断裂处填空。
2. **显示而非讲述**：「瑜携干手，同步出帐外。左右军士，皆全装惯带，持戈执戟而立。瑜曰：'吾之军士，颇雄壮否？'」——不叙述"周瑜有意炫耀军威震慑蒋干"，只写"携干手""出帐外"的动作加一句问话。蒋干的反应"面如土色"在前文已铺好，此处只显示场景，威压自显。
3. **物件承载**：「内有一封，上写'蔡瑁张允谨封。'干大惊，暗读之。」——整条反间计的核心不是对话，是一封信。信件作为物件被推到前台，蒋干"暗藏于衣内"的动作让情节由看转为偷，物件的流转完成了计谋的全部逻辑。
4. **结果先行**：「操曰：'军若练熟，吾首级献于周郎矣！'蔡、张二人不知其意，惊慌不能回答。操喝武士推出斩之。须臾，献头帐下，操方省悟曰：'吾中计矣！'」——曹操先说结果（首级将献周郎），再杀人，杀完才省悟。结果的预感和事后的醒悟并置，反间的闭环在一句独白里完成。
5. **独句落点**：「却见玄德背后一人，按剑而立，乃云长也。孔明喜曰：'吾主无危矣。'」——惊与安之间没有一句过渡：壁衣里密排刀斧手，孔明"大惊"，转脸看见按剑而立的云长，只四字收束。一人一剑替代所有解释，判断落地即止。

**本回命中**：引语留白、显示而非讲述、物件承载、结果先行、独句落点

### 第四十六回　用奇谋孔明借箭　献密计黄盖受刑
**主线**：孔明草船借箭，周瑜黄盖定苦肉计。

**手法片段**：
1. **结果先行**：「孔明曰：'只消三日，便可拜纳十万枝箭。'……愿纳军令状：三日不办，甘当重罚。」——借箭尚未开始，三日之限已立。读者带着"三天怎么造十万支箭"的悬念进入大雾之夜，结果先行制造了全程的紧张感。
2. **蒙太奇并置**：「是夜大雾漫天，长江之中，雾气更甚，对面不相见。」与「孔明促舟前进」并「曹寨中……箭如雨发」——雾、船、箭三个画面对切。孔明船上"酌酒取乐"的闲与曹营"乱箭射之"的急被同一片大雾缝合，蒙太奇让读者同时看到两边的荒诞对比。
3. **显示而非讲述**：「瑜推翻案桌，叱退众官，喝教行杖。」——不写"周瑜假意大怒"，只写"推翻案桌"这一动作。苦肉计的真假全靠这一桌一杖来支撑，读者要到最后"肃方悟"才确认，显示本身始终不揭底。
4. **独句落点**：「孔明笑而不言。」——鲁肃告蔡中蔡和之降多系诈降，孔明只"笑而不言"。不解释、不点破，四个字把"我早知道"的从容和"你还需要成长"的含蓄同时收住。
5. **动作承载**：「各出掌中之字，互相观看，皆大笑。原来周瑜掌中字，乃一'火'字；孔明掌中，亦一'火'字。」——破曹大计不出自任何一段对话：两人各在掌心暗写，同时摊开，同是一个"火"字。战略的默契全由暗写、同观、大笑三个动作承载，无声处把吴蜀的同盟凝固成回目上一桩公案。
6. **引语留白**：「诸将皆来动问。盖不言语，但长吁而已。」——诸将动问，黄盖一句不答，只有一声长吁。苦肉计的剧痛、委屈与不能出口的机密全被抽进这声空白；读者须待阚泽开口"莫非苦肉计乎"才得九分真相，留白本身成了计谋的一部分。

**本回命中**：结果先行、蒙太奇并置、显示而非讲述、独句落点、动作承载、引语留白

### 第四十七回　阚泽密献诈降书　庞统巧授连环计
**主线**：阚泽献诈降书，庞统授连环计，徐庶识破而不言。

**手法片段**：
1. **显示而非讲述**：「泽面不改容，仰天大笑。操教牵回，叱曰：'吾已识破奸计，汝何故哂笑？'泽曰：'吾不笑你。吾笑黄公覆不识人耳。'」——不写"阚泽镇定自若"，只写"面不改容，仰天大笑"。以笑代辩，把被动翻转为主动，曹操反被牵着走，人物胆气全靠这一个笑来显示。
2. **引语承载**：「岂不闻背主作窃，不可定期？倘今约定日期，急切下不得手，这里反来接应，事必泄漏。」——阚泽不靠情感说服曹操，只靠一个逻辑：投降不能定期。引语即论证，曹操"改容下席而谢"是对逻辑而非情感的服从，说服的力量在说理本身。
3. **事实并置**：「瑜作色曰：'子翼何故欺吾太甚？'……便教左右：'送子翼往西山庵中歇息。'」与「只听得读书之声……见一人挂剑灯前，诵孙、吴兵书。」——周瑜"作色"赶人与蒋干"信步"遇庞统，两件事前后脚发生。一个赶一个引，并置之下读者自行拼出连环计的入口：不是偶遇，是布局。
4. **第三拍转向**：「统拜别，至江边，正欲下船，忽见岸上一人，道袍竹冠，一把扯住统曰……」——庞统连环计已成、将离曹营，叙事已近尾声，忽然一只手扯住他。第三拍从"成功脱身"转向"被人识破"，全回的安全感在一把手中碎裂，结尾的悬念由此弹起。
5. **结果先行**：「统密谓肃曰：'欲破曹兵，须用火攻；但大江面上，一船着火，余船四散；除非献连环计，教他钉作一处，然后功可成也。'」——连环计尚未出笼，整条因果链——火攻、船散、锁船、功成——已先摊给读者。后文曹操步步入彀，读者全程拿着答案看棋局，叙事的方向感由此先行铺定。
6. **动作收尾**：「一把扯住统曰：'你好大胆！黄盖用苦肉计，阚泽下诈降书，你又来献连环计：只恐烧不尽绝！'」——庞统智赚曹操、全身而退的从容到此为止：一只手从岸上伸来扯住他，三条毒计被一语道破。全回的安全感碎在这一扯里，回末停在魂飞魄散的一瞬，识破与反识破的悬念直接顶入下回。

**本回命中**：显示而非讲述、引语承载、事实并置、第三拍转向、结果先行、动作收尾

### 第四十八回　宴长江曹操赋诗　锁战船北军用武
**主线**：曹操长江赋诗，锁战船操练水军，周瑜见风吐血。

**手法片段**：
1. **引语承载**：「对酒当歌，人生几何：譬如朝露，去日苦多。」——《短歌行》全篇嵌入叙事，不写曹操此刻如何踌躇满志，只让诗代他说话。"月明星稀，乌鹊南飞；绕树三匝，无枝可依"四句既是诗情也是谶语，引语在此承担了双重叙事功能：表现雄心与预兆覆亡。
2. **长短句换挡**：「操大怒曰：'汝安敢败吾兴！'手起一槊，刺死刘馥。众皆惊骇。遂罢宴。」——宴饮赋诗的长节奏被"手起一槊"四个字一刀截断。前文铺陈的从容与豪迈在这一槊之后全部变成反讽，短句的暴力终止了长句的抒情。
3. **反讽与距离**：「操立于将台之上，观看调练，心中大喜，以为必胜之法。」——读者已知连环计是火攻陷阱，曹操"以为必胜之法"的判断与读者的认知形成反讽。叙事不点破，只让曹操"大喜"，距离由此产生：他越高兴，读者越不安。
4. **动作收尾**：「一阵风过，刮起旗角于周瑜脸上拂过。瑜猛然想起一事在心，大叫一声，往后便倒，口吐鲜血。」——全回以一个倒地动作收束。不解释周瑜想起了什么（东风之患），只写"大叫一声""往后便倒""口吐鲜血"三个动作连续砸下，结尾被钉在身体的崩塌上。
5. **预叙**：「程昱曰：'船皆连锁，固是平稳；但彼若用火攻，难以回避。'……'方今隆冬之际，但有西风北风，安有东风南风耶？'」——连环锁船的致命处与破解的开关被提前摊开：程昱一句"火攻难以回避"说出败局，曹操一句"安有东风南风耶"又亲手把转机预告给读者。此后两回的借东风、纵火全在这两句对答里预演完毕。
6. **结果先行**：「今吾有百万雄师，更赖诸公用命，何患不成功耶！收服江南之后，天下无事，与诸公共享富贵」——赤壁未开一船，曹操已在酒宴上把"收服江南之后"的太平图景先分派完毕。胜局作为既成事实先于战事出口，紧接的一槊刺死刘馥随即戳破这份从容，结果先行的大话与丧钟互为反证。

**本回命中**：引语承载、长短句换挡、反讽与距离、动作收尾、预叙、结果先行
