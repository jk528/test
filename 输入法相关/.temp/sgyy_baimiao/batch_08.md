# 《三国演义》第85-96回 白描写作手法分析

### 第85回　刘先主遗诏托孤儿　诸葛亮安居平五路
**主线**：刘备白帝城托孤孔明，孔明安居退魏五路大军。

**手法片段**：
1. **回声照应**：「朕观此人，言过其实，不可大用。丞相宜深察之。」——解析：刘备临终对马谡的判断，埋伏至95回街亭败亡方应验，跨越十余回的远距离回声，使"言过其实"四字成为全书因果链的一环。
2. **显示而非讲述**：「孔明独倚竹杖，在小池边观鱼。后主在后立久，乃徐徐而言曰：'丞相安乐否？'」——解析：不写"孔明胸有成竹"，而用观鱼动作显示其镇定；后主"立久"二字写出等候之久与孔明之从容，信息全由画面传达。
3. **引语承载**：「君才十倍曹丕，必能安邦定国，终定大事。若嗣子可辅，则辅之；如其不才，君可自为成都之主。」——解析：托孤之言不借助叙述评价，全靠刘备亲口说出，"君可自为成都之主"一句将信任与试探并置，孔明"汗流遍体，手足失措"的反应成为引语的附着力。
4. **预叙**：「丞相不知为何，数日不出视事。」——解析：先抛出"数日不出"的异常悬念，后主、群臣、太后三层追问，层层积压后才在小池边揭晓退兵之策，悬念前置、答案后置，制造阅读期待。

**本回命中**：回声照应、显示而非讲述、引语承载、预叙、结果先行、物件承载

### 第86回　难张温秦宓逞天辩　破曹丕徐盛用火攻
**主线**：邓芝使吴通好，秦宓天辩折张温，徐盛火攻破曹丕。

**手法片段**：
1. **动作承载**：「芝整衣冠而入……并无惧色，昂然而行。至殿前，又见鼎镬内热油正沸。左右武士以目视之，芝但微微而笑。」——解析：不写"邓芝勇敢"，而以整衣冠、昂然行、微微笑三个递进动作承载胆识，油鼎沸与微笑的对峙全靠身体语言完成。
2. **特写**：「先于殿前立一大鼎，贮油数百斤，下用炭烧。待其油沸，可选身长面大武士一千人，各执刀在手，从宫门前直摆至殿上」——解析：张昭之策被放大为视觉特写——鼎、油、炭、千名执刀武士，从宫门到殿上的纵深排列，将恐吓手段具象化为一个可怖场面。
3. **引语承载**：「天有头乎？」「有头。」「头在何方？」「在西方。《诗》云：'乃眷西顾。'以此推之，头在西方也。」——解析：秦宓天辩以连续问答推进，才学不靠旁白评价，全由对答内容承载，张温"无言可对"是引语较量的自然结果。
4. **蒙太奇并置**：「原来徐盛束缚芦苇为人，尽穿青衣，执旌旗，立于假城疑楼之上。」——解析：一夜之间连城数百里的奇景与曹丕隔岸遥望的画面并置，真城与假城、震撼与真相在读者视角中同时呈现。

**本回命中**：动作承载、特写、引语承载、蒙太奇并置、显示而非讲述、情绪延迟

### 第87回　征南寇丞相大兴师　抗天兵蛮王初受执
**主线**：孔明南征，反间计破三路叛军，一擒孟获。

**手法片段**：
1. **预叙**：「攻心为上，攻城为下；心战为上，兵战为下。愿丞相但服其心足矣。」——解析：马谡此言为后续七擒七纵的全局策略定调，预叙了"服心"而非"灭类"的方针，成为此后数回的叙事总纲。
2. **显示而非讲述**：「吾非不用汝二人，但恐以中年涉险，为蛮人所算，失其锐气耳。」——解析：孔明不说真实意图，而以"不识地理"为由搪塞，赵云魏延"各有愠色"后被激将深入，策略全靠人物反应显示，叙述者不点破。
3. **反讽与距离**：「山僻路狭，误遭汝手，如何肯服！」——解析：孟获每被擒皆不服，叙述者不评判谁对谁错，保持距离感，让"不服"本身成为推动七擒的叙事动力，反讽在于擒者比被擒者更耐心。

**本回命中**：预叙、显示而非讲述、反讽与距离、引语承载、第三拍转向

### 第88回　渡泸水再缚番王　识诈降三擒孟获
**主线**：孔明渡泸水二擒三擒孟获，识破诈降。

**手法片段**：
1. **回声照应**：「吾擒此人，如囊中取物耳。直须降伏其心，自然平矣。」——解析：回声87回马谡"攻心为上"之言，三擒后孔明向诸将明言"诚欲服其心，不欲灭其类"，前后呼应构成主题回声。
2. **物件承载**：「半渡皆倒；急救傍岸，口鼻出血而死。」——解析：泸水毒气不靠形容词渲染，而以"口鼻出血而死"的物件化身体反应承载毒性之烈，死亡画面落地。
3. **重复升级**：孟获一擒不服"山僻路狭"，二擒不服"手下之人自相残害"，三擒不服"吾弟贪口腹之故"——解析：三次被擒、三次借口、三次释放，每轮借口递减、孔明手段递增，重复中升级张力。

**本回命中**：回声照应、物件承载、重复升级、显示而非讲述、预叙

### 第89回　武乡侯四番用计　南蛮王五次遭擒
**主线**：四毒泉困蜀军，山神指路得解，杨锋擒孟获。

**手法片段**：
1. **名词列锦**：「一名哑泉，其水颇甜，人若饮之，则不能言，不过旬日必死；二曰灭泉，此水与汤无异，人若浴之，则皮肉皆烂，见骨必死；三曰黑泉……四曰柔泉……」——解析：四泉以名词铺排，每泉配一种死法，信息密度极高，不抒情而恐怖自生，是典型的名词列锦。
2. **结果先行**：「孔明垂泪而叹曰：'吾虽有功于社稷，必损寿矣！'」——解析：（此句在90回，本回对应的是山神指路的结果先行）老叟先说"丞相勿忧。老夫指引一处，可以解之"，给出结果（有解）再展开过程（万安溪、安乐泉），先安人心再述路径。
3. **动作承载**：「二子举杯诣孟获、孟优前。二人接杯，方欲饮酒，锋大喝一声，二子早将孟获、孟优执下座来。」——解析：杨锋擒孟获全靠动作完成——举杯、接杯、大喝、执下，四个动作一气呵成，无一句心理描写。

**本回命中**：名词列锦、结果先行、动作承载、陌生化、回声照应

### 第90回　驱巨善六破蛮兵　烧藤甲七擒孟获
**主线**：破祝融夫人与木鹿大王，盘蛇谷烧藤甲军，七擒孟获归服。

**手法片段**：
1. **结果先行**：「孔明垂泪而叹曰：'吾虽有功于社稷，必损寿矣！'」——解析：盘蛇谷火攻成功，不先写胜利，先写孔明垂泪自责，结果（胜）与代价（损寿）并出，以情绪先行颠覆常规胜利叙事。
2. **蒙太奇并置**：「满谷中火光乱舞，但逢藤甲，无有不着。将兀突骨并三万藤甲军，烧得互相拥抱，死于盘蛇谷中。」——解析：火光、藤甲、拥抱、死亡四个画面高速切换，孔明"在山上往下看"的俯视视角与谷中惨象并置，胜利与悲悯同框。
3. **重复升级**：「七擒七纵，自古未尝有也。吾虽化外之人，颇知礼义，直如此无羞耻乎？」——解析：七次擒放积累到第七次，孟获从"如何肯服"到"肉袒谢罪"，重复结构在此达到质变临界点，量变引发心服。
4. **动作收尾**：「丞相天威，南人不复反矣！」——解析：以孟获跪拜表态收束全回，南征叙事由此闭合，"不复反"三字是动作后的定音。

**本回命中**：结果先行、蒙太奇并置、重复升级、动作收尾、引语承载、反讽与距离

### 第91回　祭泸水汉相班师　伐中原武侯上表
**主线**：祭泸水班师，曹丕死曹睿即位，孔明上出师表北伐。

**手法片段**：
1. **引语承载**：「先帝创业未半，而中道崩殂；今天下三分，益州罢敝，此诚危急存亡之秋也。」——解析：出师表全文嵌入叙事，不靠叙述者总结孔明心志，全由表文自身承载，"鞠躬尽瘁"之意在文中自然流出，是最长的一处引语承载。
2. **物件承载**：「和面为剂，塑成人头，内以牛羊等肉代之，名曰馒头。」——解析：祭泸水不用人头而用馒头替代，以一个具体物件承载孔明"不妄杀"的仁政理念，馒头成为叙事符号。
3. **独句落点**：「先帝创业未半，而中道崩殂。」——解析：出师表首句独立成段后缓缓展开，独句先落定基调——未竟之业与危急之势，再铺陈细节，呼吸感极强。

**本回命中**：引语承载、物件承载、独句落点、预叙、回声照应、结果先行

### 第92回　赵子龙力斩五将　诸葛亮智取三城
**主线**：赵云力斩韩德四子，孔明智取安定南安天水，姜维识破计谋。

**手法片段**：
1. **动作承载**：「长子韩瑛，跃马来迎；战不三合，被赵云一枪刺死于马下……云在中央独战三将……韩琪中枪落马……却被云一箭射中面门，落马而死」——解析：赵云力斩四将全以动作完成——刺、战、拨箭、射中，无一句"英勇"评价，七十老将之威全在动作链中。
2. **预叙**：「近闻诸葛亮杀败夏侯楙，困于南安，水泄不通，安得有人自重围之中而出？又且裴绪乃无名下将，从不曾见」——解析：姜维一出场即以推理识破孔明诈计，预叙了"天水不易取"的困难，为下回姜维归降铺垫。
3. **情绪延迟**：「云仰天叹曰：'吾不服老，死于此地矣！'」——解析：赵云被困垓心从辰时杀至酉时，情绪积累到"仰天叹"才爆发，延迟半天后张苞救兵到，情绪先到最低点再反转。

**本回命中**：动作承载、预叙、情绪延迟、显示而非讲述、结果先行

### 第93回　姜伯约归降孔明　武乡侯骂死王朝
**主线**：姜维降蜀，孔明骂死王朗，大破曹真劫寨之计。

**手法片段**：
1. **引语承载**：「皓首匹夫！苍髯老贼！汝即日将归于九泉之下，何面目见二十四帝乎！老贼速退！可教反臣与吾共决胜负！」——解析：孔明骂王朗的长段引语是全回核心，不靠叙述者判断王朗之恶，全由孔明之口完成道德审判，引语本身即行动。
2. **动作收尾**：「王朗听罢，气满胸膛，大叫一声，撞死于马下。」——解析：骂罢即死，以"撞死于马下"一个动作收束对决，干净利落，不写王朗心理过程，死亡动作自身即结论。
3. **显示而非讲述**：「维人困马乏，不能抵当，勒回马便走。忽然一辆小车从山坡中转出……孔明唤姜维曰：'伯约此时何尚不降？'」——解析：姜维归降不写内心挣扎，而以穷途末路、前后无路的处境显示其被迫，孔明"执维手"的动作完成收编。

**本回命中**：引语承载、动作收尾、显示而非讲述、预叙、特写

### 第94回　诸葛亮乘雪破羌兵　司马懿克日擒孟达
**主线**：孔明乘雪破羌兵铁车，司马懿倍道擒杀孟达。

**手法片段**：
1. **蒙太奇并置**：孔明祁山破羌兵与司马懿宛城擒孟达两条线交替推进——解析：一西一东，一智一速，两个战场交叉剪辑，孔明"掷书于地而顿足"与司马懿"以手加额"形成蒙太奇对比，叙述者在两条线间快速切换。
2. **结果先行**：「孔明看毕，掷书于地而顿足曰：'孟达必死于司马懿之手矣！'」——解析：先给出结果判断（孟达必死），再倒叙司马懿如何倍道而行、如何八日到新城，结果前置制造紧迫感。
3. **事实并置**：「宛城离洛阳约八百里，至新城一千二百里。若司马懿闻达举事，须表奏魏主。往复一月间事」与司马懿「不待圣旨，星夜而去」——解析：孟达的算盘与司马懿的实际行动并置，"一月"与"不待奏闻"的事实对比，不评价谁对谁错，差距自明。

**本回命中**：蒙太奇并置、结果先行、事实并置、预叙、动作承载

### 第95回　马谡拒谏失街亭　武侯弹琴退仲达
**主线**：马谡违令失街亭，孔明空城退司马懿。

**手法片段**：
1. **回声照应**：「马谡无知，坑陷吾军矣！」——解析：85回刘备遗言"马谡言过其实，不可大用"在此应验，孔明拍案大惊是远距回声的共振点，"坑陷吾军"四字扣合"不可大用"的预言。
2. **显示而非讲述**：「孔明乃披鹤氅，戴纶巾，引二小童携琴一张，于城上敌楼前，凭栏而坐，焚香操琴。」——解析：空城计不写"孔明镇定"，而以披鹤氅、携琴、焚香、操琴四个动作显示从容，十五万大军与二千五百人的悬殊全靠画面呈现。
3. **引语留白**：「亮平生谨慎，不曾弄险。今大开城门，必有埋伏。我兵若进，中其计也。」——解析：司马懿退兵的理由由他自己说出，叙述者不评判对错，留白之处在于——读者知道孔明确无伏兵，司马懿的判断恰好被孔明算准，这层反讽不点破。
4. **独句落点**：「吾不如孔明也！」——解析：司马懿得知真相后一句独白收束全回核心，五个字浓缩悔意与敬畏，独立成句，呼吸停顿。

**本回命中**：回声照应、显示而非讲述、引语留白、独句落点、预叙、结果先行

### 第96回　孔明挥泪斩马谡　周鲂断发赚曹休
**主线**：孔明斩马谡自贬三等，周鲂断发赚曹休大败于石亭。

**手法片段**：
1. **引语承载**：「丞相视某如子，某以丞相为父。某之死罪，实已难逃；愿丞相思舜帝殛鲧用禹之义，某虽死亦无恨于九泉！」——解析：马谡遗言以典故（殛鲧用禹）承载求托之情，不直说"请照顾我儿子"，引语自身完成情感传递。
2. **回声照应**：「吾非为马谡而哭。吾想先帝在白帝城临危之时，曾嘱吾曰：'马谡言过其实，不可大用。'今果应此言。」——解析：直接回扣85回遗诏，孔明自述哭因，将个人悲痛与先帝识人之明并置，回声在此闭合，从85回到96回构成完整因果环。
3. **动作承载**：「鲂乃用剑割发掷于地曰：'吾以忠心待公，公以吾为戏，吾割父母所遗之发，以表此心！'」——解析：周鲂诈降不以言辞说服，而以"割发掷地"的动作承载诚意，曹休"深信之"是动作效果的自然结果，断发即欺诈本身。
4. **结果先行**：「孔明挥泪斩马谡」——解析：回目即结果，正文先写王平述职、再写马谡入帐、最后才到行刑，结果先行而过程后置，"挥泪"二字将执法与悲痛并提。

**本回命中**：引语承载、回声照应、动作承载、结果先行、重复升级、反讽与距离
