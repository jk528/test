### 第 1 回　甄士隐梦幻识通灵　贾雨村风尘怀闺秀

**主线**：甄士隐赠银助贾雨村进京，自己连遭失女火烧，随跛道出家。

**手法片段**：

1. **数字对比**：「炼成高十二丈、见方二十四丈大的顽石三万六千五百零一块。那娲皇只用了三万六千五百块」——解析：两个同口径数字直接相减，"单单剩下一块未用"，石头被弃的处境不靠形容词，靠算术落地。

2. **显示而非讲述**：「雨村收了银衣，不过略谢一语，并不介意，仍是吃酒谈笑」——解析：五十两白银加两套冬衣只换"略谢一语"，作者不评其凉薄，四个动作排开，人品自见。

3. **预叙**：「好防佳节元宵后，便是烟消火灭时」——解析：僧人偈语把失女与火灾的结局提前挂出，此后几段按部就班兑现，读者先知后事，只看士隐一步步走进去。

4. **回声照应**：「这官儿好面善，倒象在那里见过时」——解析：结尾回到当初"回头一两次"的丫鬟，雨村发迹由一双旧眼睛认出，中段的回顾与结尾的重逢互相扣紧。

**手法片段**：

2. **特写**：「大门外虽冷落无人，隔着围墙一望，里面厅殿楼阁也还都峥嵘轩峻」——解析：借雨村过街一望的细部代表二府全貌，外冷落、内峥嵘，正是"百足之虫，死而不僵"的实景版。

4. **回声照应**：「偶因一回顾，便为人上人」——解析：两句诗收上回丫鬟两次回顾之尾，娇杏命运就此结清。

### 第 5 回　贾宝玉神游太虚境　警幻仙曲演红楼梦

**主线**：宝玉午睡梦游太虚幻境，见册闻曲，与可卿成姻后坠入迷津。

**手法片段**：

1. **名词列锦**：「案上设着武则天当日镜室中设的宝镜，一边摆着赵飞燕立着舞的金盘」——解析：宝镜、金盘、宝榻、连珠帐串成一件件带典故的器物名单，秦氏卧房的艳冶全由名词铺出。

2. **重复升级**：「宝玉看了，益发解说不出是何意思」——解析：从"不甚明白"到"解说不出"再到"仍不解"，三翻册子三番不解，懵懂步步加深，谶语与读者之知的落差越拉越大。

4. **问题收尾**：「我的小名儿这里从无人知道，他如何得知，在梦中叫出来？」——解析：以秦氏之问结束全回，不作解答，可卿与幻境的关系留给读者自己接。

### 第 6 回　贾宝玉初试云雨情　刘老老一进荣国府

**手法片段**：

1. **陌生化**：「忽见堂屋中柱子上挂着一个匣子，底下又坠着一个秤陀似的，却不住的乱晃」——解析：挂钟在村妪眼中成"匣子坠秤陀"，贵族计时器换了农家度量衡，两个尺度并置，荣府之阔与来客之窘同时变具体。

2. **动作承载**：「凤姐也不接茶，也不抬头，只管拨那灰，慢慢的道："怎么还不请进来？"」——解析：三个"不"加一个"慢慢的"，当家奶奶的威重全在拨灰的手上，来人的分量也在这一声慢问里定下。

2. **物件承载**：「接着房门响，平儿拿着大铜盆出来，叫人舀水」——解析：回目"贾琏戏熙凤"的正事，只以帘内笑声与一盆要舀的水交代，意思全落在器物上，一笔不逾界。

3. **引语留白**：「我就知道么，别人不挑剩下的也不给我呀」——解析：抢白之后紧接"周瑞家的听了，一声儿也不敢言语"，前后不添解释，锋芒与处境全凭这句冷语与这片沉默立住。

4. **预叙**：「我明儿也要剃了头跟他作姑子去呢，可巧又送了花来，要剃了头，可把花儿戴在那里呢？」——解析：惜春戏语与送花撞在一起，玩笑成了判词，归宿提前点破。

4. **叙述距离**：「旁边伏侍的人只见他先还拿着镜子照，落下来，仍睁开眼拾在手内，末后镜子掉下来，便不动了。」——解析：贾瑞之死不写身内，只写旁人眼见的镜子起落，到"众人上来看时，已经咽了气了"才确认，当时所见与事后确认两步分开。
