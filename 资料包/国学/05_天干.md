# 天干

> 分卷 05。本篇讲「十分」：十天干的训诂、属性、合化、相冲与纪时用法。天干与地支配合成六十甲子，地支部分见 06 卷。

---

## 一、总述

十天干：**甲、乙、丙、丁、戊、己、庚、辛、壬、癸**。

其基本结构是「五行 × 阴阳」：

- 木：甲（阳）、乙（阴）
- 火：丙（阳）、丁（阴）
- 土：戊（阳）、己（阴）
- 金：庚（阳）、辛（阴）
- 水：壬（阳）、癸（阴）

天干最早用于**纪日**，甲骨卜辞中已见干支相配的连续纪日；后扩展至纪年、纪月、纪时，并成为命理、中医运气学说的基础符号。

---

## 二、十干名义训诂

下列训诂以《史记·律书》《汉书·律历志》为主。二书文字略有异同，且汉人训诂多牵合阴阳消息，**不宜当作字源学结论**，只宜视为汉代宇宙论的解释。

| 天干 | 训诂 | 大意 | 出处 |
|---|---|---|---|
| 甲 | 万物剖符甲而出也 | 种子破壳而出 | 《史记·律书》 |
| 乙 | 言万物生轧轧也 | 幼芽屈曲生长 | 《史记·律书》 |
| 丙 | 言阳道著明 | 阳气昭著 | 《史记·律书》 |
| 丁 | 言万物之丁壮也 | 长成壮实 | 《史记·律书》 |
| 戊 | 丰楙于戊 | 繁茂 | 《汉书·律历志》 |
| 己 | 理纪于己 | 条理纪识 | 《汉书·律历志》 |
| 庚 | 言阴气庚万物 | 阴气更变万物 | 《史记·律书》 |
| 辛 | 言万物之辛生 | 新生而含艰辛 | 《史记·律书》 |
| 壬 | 言阳气任养万物于下也 | 阳气在下怀任养育 | 《史记·律书》 |
| 癸 | 言万物可揆度也 | 可揆测度量 | 《史记·律书》 |

> 说明：「戊己」二干在《史记·律书》中无完整训释，上表取《汉书·律历志》补足。各家注疏尚有异说，引用时宜并存。

## 四、天干合化

### 1. 五组合化

| 组合 | 化 | 口诀 |
|---|---|---|
| 甲 + 己 | 化土 | 甲己合化土 |
| 乙 + 庚 | 化金 | 乙庚合化金 |
| 丙 + 辛 | 化水 | 丙辛合化水 |
| 丁 + 壬 | 化木 | 丁壬合化木 |
| 戊 + 癸 | 化火 | 戊癸合化火 |

规律：相隔五位相合（甲 1 与己 6、乙 2 与庚 7……），合而化出的五行，恰与该组在「五运」中的配属一致。

### 2. 合化的条件

合化不是见到两干相邻就成立，需满足：

1. **相邻**：两干须在天干序列中紧邻（年干与月干、月干与日干等）。
2. **得月令**：月支须为化神之旺地。
3. **有根**：地支须有化神之根气。

不满足则「合而不化」，只论「合」不论「化」。**这是命理实务中分歧最大的环节之一，属 C 级用法，不可当作定论。**

## 五、天干相冲

| 冲 | 关系 |
|---|---|
| 甲 ↔ 庚 | 阳木冲阳金 |
| 乙 ↔ 辛 | 阴木冲阴金 |
| 丙 ↔ 壬 | 阳火冲阳水 |
| 丁 ↔ 癸 | 阴火冲阴水 |

戊、己属土居中，无冲。相冲之说出自术数，经典无明文，属 C 级。

## 六、天干配五运（五运六气，C 级）

| 年干 | 五运 |
|---|---|
| 甲、己 | 土运 |
| 乙、庚 | 金运 |
| 丙、辛 | 水运 |
| 丁、壬 | 木运 |
| 戊、癸 | 火运 |

阳干为「太过」，阴干为「不及」。如甲年为土运太过，己年为土运不及。此系统见于《素问》运气七篇，用于推算年度气候倾向与疫病规律。

## 七、天干纪时

### 1. 纪年

十干与十二支依次相配，得六十甲子，循环纪年。如「甲子」之后为「乙丑」，至「癸亥」为一周。

### 2. 纪月：五虎遁

月干由年干推定，因正月建寅，故称「五虎遁」：

> 甲己之年丙作首，乙庚之岁戊为头，
> 丙辛必定寻庚起，丁壬壬位顺行流，
> 若问戊癸何方发，甲寅之上好追求。

| 年干 | 正月（寅月）干支 |
|---|---|
| 甲、己 | 丙寅 |
| 乙、庚 | 戊寅 |
| 丙、辛 | 庚寅 |
| 丁、壬 | 壬寅 |
| 戊、癸 | 甲寅 |

推出正月后，按月序顺推即得全年月干。**月份以节气划分（立春为正月之始），不以农历初一划分**，这是最常见的出错点。

### 3. 纪日

干支纪日自先秦赓续至今，是世界上最长的连续纪日系统之一。日干需查历书或依公式推算，无「口诀」可一步得出。

### 4. 纪时：五鼠遁

时干由日干推定，因子时起算，故称「五鼠遁」：

> 甲己还加甲，乙庚丙作初，
> 丙辛从戊起，丁壬庚子居，
> 戊癸何方发，壬子是真途。

| 日干 | 子时干支 |
|---|---|
| 甲、己 | 甲子 |
| 乙、庚 | 丙子 |
| 丙、辛 | 戊子 |
| 丁、壬 | 庚子 |
| 戊、癸 | 壬子 |

推出子时后，按十二时辰顺推即得全日时干。

## 八、天干与五常、六神

| 天干 | 五行 | 五常 | 六神（C 级） |
|---|---|---|---|
| 甲、乙 | 木 | 仁 | 青龙 |
| 丙、丁 | 火 | 礼 | 朱雀 |
| 戊 | 土 | 信 | 勾陈 |
| 己 | 土 | 信 | 螣蛇 |
| 庚、辛 | 金 | 义 | 白虎 |
| 壬、癸 | 水 | 智 | 玄武 |

六神配干为六爻预测用法，其中土分勾陈、螣蛇二神，故「五干配六神」而非「十干配六神」。

## 十、常见误读

1. **把甲当成「第一等」**：甲只是序列之首，不含优劣判断。
2. **合化无条件成立**：忽略月令与根气，见合即化，是最常见的命理误用。
3. **月份按农历初一换**：干支月以节气换，二者可差半月。
4. **把汉代训诂当字源**：「甲，剖符甲而出」是汉代宇宙论解释，不是甲骨文本义。
5. **阴阳干混用**：同一五行，阳干与阴干的性情、力度在术数中判然有别，不可笼统称「木」。
