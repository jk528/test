# 地支

> 分卷 06。本篇讲「十二分」：十二支的训诂、属性、藏干、刑冲合害与纪时用法。与天干配合成六十甲子，天干部分见 05 卷。

---

## 一、总述

十二地支：**子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥**。

地支是一个**十二元的周期符号**，同时承担五套编码：

1. **时序**：十二月、十二时辰。
2. **空间**：十二方位。
3. **动物**：十二生肖。
4. **五行阴阳**：水火各二、木金各二、土四。
5. **关系网络**：六合、三合、三会、六冲、相刑、六害、六破。

地支的复杂度远高于天干，原因就在第五套：**关系是成对定义的，牵一发动全身。**

## 二、十二支名义训诂

以下以《汉书·律历志》《史记·律书》为主，汉人训诂多就阴阳消息立说，非字源学结论。

| 地支 | 训诂 | 大意 |
|---|---|---|
| 子 | 孳也 | 万物孳萌于下 |
| 丑 | 纽也 | 阴气在上，万物厄纽未敢出 |
| 寅 | 髌也（一作引） | 万物始生，引而伸之 |
| 卯 | 冒也 | 万物冒地而出 |
| 辰 | 震也（一作伸） | 万物震动而长 |
| 巳 | 已也 | 阳气已出，阴气已藏 |
| 午 | 咢也（一作仵） | 阴阳交午，万物丰满 |
| 未 | 昧也 | 日中则昃，阴气渐长 |
| 申 | 身也（一作伸） | 万物身体皆成 |
| 酉 | 緧也（一作老） | 万物皆老 |
| 戌 | 灭也 | 万物衰灭 |
| 亥 | 该也（一作荄） | 万物收藏，该阂于下 |

> 异文与异说并存，上表取通行一说。引用时如涉及具体字义，须核对所据注疏。

### 需要特别注意的两点

1. **子、午的「体阳用阴」**：子为阳支，但所藏本气为癸（阴水）；午为阳支，但所藏本气为丁（阴火）。这是「体阳用阴」说的由来，命理中极为重要。
2. **土占四支**：辰、戌、丑、未为四土，但性质不同——辰为湿土、戌为燥土、丑为寒土、未为暖土。四土不可笼统等同。

## 四、藏干表

地支中所含天干称「藏干」，分本气、中气、余气。此表为命理通行用法（C 级），各派略有出入。

| 地支 | 本气 | 中气 | 余气 |
|---|---|---|---|
| 子 | 癸 | — | — |
| 丑 | 己 | 癸 | 辛 |
| 寅 | 甲 | 丙 | 戊 |
| 卯 | 乙 | — | — |
| 辰 | 戊 | 乙 | 癸 |
| 巳 | 丙 | 庚 | 戊 |
| 午 | 丁 | 己 | — |
| 未 | 己 | 丁 | 乙 |
| 申 | 庚 | 壬 | 戊 |
| 酉 | 辛 | — | — |
| 戌 | 戊 | 辛 | 丁 |
| 亥 | 壬 | 甲 | — |

**校验要点**：藏干是「十神」推算的起点，一旦本气取错，整盘结论全错。凡遇流派差异（如午中是否藏己、亥中是否藏戊），须先声明所据流派。

## 五、地支关系

### 1. 六合

| 组合 | 化 | 说明 |
|---|---|---|
| 子 + 丑 | 化土 | 子丑合 |
| 寅 + 亥 | 化木 | 寅亥合 |
| 卯 + 戌 | 化火 | 卯戌合 |
| 辰 + 酉 | 化金 | 辰酉合 |
| 巳 + 申 | 化水 | 巳申合（亦论合中有刑） |
| 午 + 未 | 化土（一说化火） | 午未合，亦称「日月之合」 |

六合为「合的六组」，两两相对，位置固定。

### 2. 三合局

| 三支 | 合局 | 长生—帝旺—墓库 |
|---|---|---|
| 申、子、辰 | 水局 | 申（长生）、子（帝旺）、辰（墓） |
| 亥、卯、未 | 木局 | 亥、卯、未 |
| 寅、午、戌 | 火局 | 寅、午、戌 |
| 巳、酉、丑 | 金局 | 巳、酉、丑 |

三合局强调**三者齐备**：缺一支则不成局，只论半合。

### 3. 三会方局

| 三支 | 会方 | 五行 |
|---|---|---|
| 寅、卯、辰 | 东方 | 木 |
| 巳、午、未 | 南方 | 火 |
| 申、酉、戌 | 西方 | 金 |
| 亥、子、丑 | 北方 | 水 |

三会的力量通常大于三合，因其为**方位之会**而非**气局之合**。

### 4. 六冲

| 冲 | 说明 |
|---|---|
| 子 ↔ 午 | 水火相冲 |
| 丑 ↔ 未 | 土土相冲 |
| 寅 ↔ 申 | 木金相冲，亦为刑 |
| 卯 ↔ 酉 | 木金相冲 |
| 辰 ↔ 戌 | 土土相冲 |
| 巳 ↔ 亥 | 火水相冲，亦为冲中带克 |

规律：**相隔六位相冲**。六冲是地支关系中最激烈的一组。

### 5. 相刑

| 类型 | 组合 | 别称 |
|---|---|---|
| 无礼之刑 | 子、卯 | 子卯相刑 |
| 无恩之刑 | 寅、巳、申 | 三刑 |
| 恃势之刑 | 丑、戌、未 | 三刑 |
| 自刑 | 辰、午、酉、亥 | 各见同支为自刑 |

相刑的吉凶判断争议极大，**不同流派对「刑」的取义（刑罚、刑伤、刑克）不同**，不可一概而论。

### 6. 六害与六破

| 六害 | 六破 |
|---|---|
| 子 ↔ 未 | 子 ↔ 酉 |
| 丑 ↔ 午 | 丑 ↔ 辰 |
| 寅 ↔ 巳 | 寅 ↔ 亥 |
| 卯 ↔ 辰 | 卯 ↔ 午 |
| 申 ↔ 亥 | 巳 ↔ 申 |
| 酉 ↔ 戌 | 未 ↔ 戌 |

害、破的力量弱于冲、刑，多用于细断，属 C 级。

## 七、六十甲子与空亡

### 1. 六十甲子的构成

十干与十二支相配，**阳干只配阳支，阴干只配阴支**，故得 5 × 6 × 2 = 60 组，而非 120 组。这一规则称「阴阳相配」，是理解六十甲子的关键。

### 2. 六旬与空亡

| 旬 | 起讫 | 空亡 |
|---|---|---|
| 甲子旬 | 甲子—癸酉 | 戌、亥 |
| 甲戌旬 | 甲戌—癸未 | 申、酉 |
| 甲申旬 | 甲申—癸巳 | 午、未 |
| 甲午旬 | 甲午—癸卯 | 辰、巳 |
| 甲辰旬 | 甲辰—癸丑 | 寅、卯 |
| 甲寅旬 | 甲寅—癸亥 | 子、丑 |

每旬十日配十二支，余二支无天干可配，故称「空亡」（旬空）。空亡为六爻、命理常用概念，属 C 级。

## 九、常见误读

1. **把生肖等同于地支**：生肖是地支的民俗附着物，地支的历法功能不依赖生肖。
2. **农历月与节气月混同**：干支月以节气换月，与农历初一可差半月。
3. **见合即合、见冲即凶**：合有合而不化，冲有冲而反成，须结合全局。
4. **把「三刑」当固定凶格**：刑的取义各派不同，不可绝对化。
5. **土支不分燥湿**：辰戌丑未四土性质迥异，混用会导致推断失真。
6. **子午阴阳看反**：子午为阳支而藏阴干，须以「体阳用阴」处理。
