# 07 泌尿系统 —— 净水厂与下水系统

> 覆盖零件：总表 060–063
> 肾的特点："静音器官"——肾单位不可再生，且损伤到失代偿之前往往没有症状，靠化验单说话；膀胱与尿道的特点：管理规则简单（不憋尿+多饮水+卫生），但极易被坏习惯击穿。

## 1. 肾脏（060）

### 1.1 零件参数

- 每侧约100万个肾单位（合计约200万），**不可再生**。
- 每天滤过约180L原尿，浓缩成1-2L尿液排出。

### 1.2 日常养护

| 项 | 口径 |
|---|---|
| 饮水 | 男约1700ml/女约1500ml/天参考；尿色保持淡黄 |
| 不憋尿 | 憋尿增加反流与感染风险 |
| 盐<5g/天 | 高血压肾损伤第一推手 |
| 慎用药 | 长期自行服止痛药（NSAIDs）伤肾；马兜铃酸类草药=肾衰黑名单，"偏方"慎入 |
| 控糖压 | 糖尿病与高血压是尿毒症两大主因 |
| 控腰围 | 肥胖相关肾病 |

### 1.3 定期保养

- 每年：尿常规+肾功能（肌酐）+泌尿系B超。
- 糖尿病/高血压者加尿微量白蛋白/肌酐比值（早期损伤的敏感指标）。

### 1.4 磨损信号

- 持续泡沫尿（细密且经久不散）、夜尿明显增多（≥2次且渐增）、眼睑/下肢水肿、血压莫名升高、乏力+面色苍白（肾性贫血）。

### 1.5 常见故障与禁忌

| 故障 | 要点 |
|---|---|
| 肾结石 | ≤6mm多可自行排出（多饮水+适度跳动）；绞痛发作就医 |
| 慢性肾病 | 按分期管理，早中期可控——靠化验单早发现 |
| 肾小球肾炎 | 尿检发现蛋白/潜血，遵医嘱 |

- 禁忌：长期高蛋白极端饮食叠加脱水、运动后只灌冰水不补水、滥用"补肾偏方"。

## 2. 输尿管（061）

- 蠕动泵管道；结石最爱卡在三个生理狭窄处（肾盂出口/跨髂血管/膀胱壁内段），典型绞痛从腰部放射至腹股沟。

## 3. 膀胱（062）

| 维度 | 内容 |
|---|---|
| 零件参数 | 容量约400-500ml，尿意约200-300ml起；健康节律=白天每2-4小时1次、夜间0-1次 |
| 日常养护 | 不憋尿；凯格尔盆底训练（见下） |
| 磨损信号 | 尿急尿频尿痛（尿路感染）、无痛性血尿（红旗，需排查肿瘤）、尿不尽+夜尿多（男性先查前列腺，联动14章） |
| 禁忌 | 长期憋尿（弹性下降+反流感染） |

### 凯格尔运动（男女通用，每天3组）

1. 找准肌肉：排尿中断的肌群即盆底肌（确认后正常排尿时别再练习中断）。
2. 收缩5秒→放松10秒，10-15次为一组，每天3组。
3. 呼吸均匀不憋气，腹臀大腿不代偿发力；产后与前列腺术后康复核心，坚持8-12周见效。

## 4. 尿道（063）

| 性别 | 要点 |
|---|---|
| 女性 | 尿道短而直（约4cm），尿感风险高：从前向后擦拭、性行为后排尿、避免久坐闷湿 |
| 男性 | 排尿后轻挤会阴排残尿；血尿+排尿困难及时就诊 |

## 5. 尿色速查卡

| 颜色 | 含义 | 动作 |
|---|---|---|
| 透明无色 | 水偏多 | 无碍 |
| 淡黄 | 理想状态 | 保持 |
| 深琥珀 | 缺水 | 补水 |
| 浓茶色 | 肝胆问题或肌肉溶解可能 | 观察持续即就医 |
| 洗肉水色 | 血尿 | 就诊 |
| 浑浊絮状 | 感染可能 | 就医 |
