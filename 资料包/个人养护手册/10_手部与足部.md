# 10 手部与足部 —— 全身执行末端

> 覆盖零件：总表 088–096（095 跟腱详见09章，本章补充足部应用）
> 手与足的特点：单位面积骨头最密集（手27块、足26块/只）、使用频率最高的末端零件；足部还是"每天承受体重×数千步冲击"的重负荷零件，鞋是它的第一件护具。

## 1. 手（088–091）

### 1.1 零件参数

- 每只手27块骨（腕8+掌5+指14）；拇指对掌功能=人类招牌，值得专门保护（091）。

### 1.2 日常养护

| 场景 | 要点 |
|---|---|
| 鼠标手 | 腕中立位（不背伸悬空）、鼠标垫腕托、每小时手指伸展10次 |
| 重复劳损 | 腱鞘炎（桡骨茎突"妈妈手"：握拳尺偏试验诱发痛）；处理=减载+支具+冰敷，顽固者局部注射遵医嘱 |
| 保暖 | 冷水刺激加重僵硬；洗碗用温水 |

### 1.3 腕管综合征（089）

- 正中神经在腕管受压；特征=夜间麻醒、甩手缓解，晚期大鱼际萎缩。
- 处理梯度：夜间腕中立位支具（一线）→减载调整工位→手术松解（有效率高）。

### 1.4 手指屈肌腱与腱鞘（090）

- 弹响指（扳机指）：晨起屈伸卡顿伴弹响；休息+支具+遵医嘱处理。

### 1.5 关节自检（手是风湿病的"显示屏"）

- 晨僵>30分钟+多关节对称肿痛=类风湿信号→风湿免疫科。
- 用多痛多、休息缓解、单个大关节=骨关节炎倾向（联动08章软骨）。

### 1.6 禁忌

- 对手指麻木不当回事（神经压迫拖延=恢复变慢）；暴力扳拽指关节。

## 2. 足（092–096）

### 2.1 零件参数

- 每只足26块骨、约30余个关节（口径略有差异）；足弓三点支架（093）；日均承受数千步冲击。

### 2.2 鞋的保养学（足的第一护具）

| 要点 | 说明 |
|---|---|
| 下午试鞋 | 足部一天后略胀，尺寸更真实 |
| 足趾空间 | 最长趾距鞋头约1cm |
| 跟高 | 2-3cm内；>5cm前足与膝压力陡增 |
| 跑鞋寿命 | 约500-800km或6-12个月（缓冲衰减肉眼难辨） |
| 轮换 | 两双轮换更耐用 |

### 2.3 足底筋膜（094）

- 晨起第一步刺痛+近足跟压痛=足底筋膜炎倾向。
- 处理：小腿与足底牵拉（脚趾上扳）、网球滚足底、减量、支撑鞋垫；多为自限但改摩擦源才能不复发。

### 2.4 跟腱（095，机制详见09章）

- 足部应用要点：跑步加量遵循约10%周增幅；晨起跟腱痛先热身再跑；断裂信号（"被踢一脚"）立即就医。

### 2.5 脚趾与拇外翻结构（096）

- 拇外翻=尖头高跟鞋+遗传共同作用；宽鞋头+分趾垫控制，畸形进展影响功能则手术评估。

### 2.6 趾甲与甲沟（联动11章103）

- 平剪不剪太短（留约1mm白边），嵌甲勿自行抠挖。

### 2.7 足癣与灰指甲

- 透气鞋袜+保持干爽；毛巾拖鞋与家人分开；抗真菌足疗程（症状消失后再坚持1-2周）。

### 2.8 糖尿病足专题（重点）

| 每日动作 | 说明 |
|---|---|
| 双足视诊 | 含足底（用镜子），查伤口/水疱/变色 |
| 水温<37℃ | 先用手/温度计试水（神经病变者温觉差，易烫伤） |
| 不赤脚 | 室内外都穿鞋袜；袜口不紧 |
| 每年筛查 | 10g尼龙丝触觉检查+足背动脉触诊 |
| 伤口2周不愈 | 立即就医，勿自行处理 |

- 禁忌：烫脚"越烫越养生"（糖尿病与循环差者烫伤高发）、修脚店处理糖尿病足伤口、鸡眼贴自行腐蚀。

### 2.9 信号

- 红旗：静息足痛、夜间垂腿缓解的足痛（缺血信号）、足部伤口不愈。
