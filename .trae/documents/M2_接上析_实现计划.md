# M2「接上析」实现计划（最小闭环版）

## Context

M1 已完成（commit 776f237）：Tauri2 + Vue3 + Monaco 阅读器 + Python sidecar 骨架，能读《红楼梦.txt》120 回，书签锚定物理行。

M2 最小闭环目标：**让 sidecar 跑起来，分析当前章情感，把七色底色画回正文**。砍掉 SQLite、人物高亮、分词输出，后续再扩展。

数据流：
```
打开书 → 前端取当前章文本 → Rust invoke → sidecar 分析 → 段落级情感回传 → Reader 叠加七色着色
```

## 实现步骤

### 步骤 1：Python sidecar 新增情感分析方法

**文件**：`app/sidecar/honglou_sidecar.py`（扩展）

1. **加载分析引擎**（进程启动时一次性加载）：
   - 把 `基础/` 目录路径通过环境变量或参数传入 sidecar（dev 态相对 src-tauri 上溯到 `红楼梦范例/基础/`）
   - `import sys; sys.path.insert(0, 基础目录)` 后 `from emotion_analysis import EmotionAnalyzer`
   - 实例化 `EmotionAnalyzer()`（自动加载 DUTIR 七类词典）
   - `import jieba; jieba.load_userdict(基础/红楼梦分词词典.txt)`

2. **新增方法 `analyze_sentiment`**：
   - params：`{text: str}`（章内文本，按 \n 分行）
   - 逻辑：逐行 `jieba.lcut(line)` → `analyzer.analyze_words(words)` → 取七类计数的主导情绪 + 极性
   - 返回：`{paragraphs: [{line_offset, dutir_top, polarity, intensity, weights}]}`
   - line_offset 是章内 0-based 相对行号，前端加章节起始行号得全局物理行

3. **主导情绪判定**：七类计数最大的那个为 dutir_top；polarity = (好+乐 - 哀-怒-惧-恶) / total；无情感词则 dutir_top=null（不着色）

### 步骤 2：Rust 壳拉起 sidecar 进程

**文件**：`app/src-tauri/src/lib.rs`（扩展）+ 新建 `app/src-tauri/src/sidecar.rs`

1. **`sidecar.rs`** —— 长驻 sidecar 进程管理：
   - `SidecarManager`：持有 `Child` + `BufWriter<ChildStdin>` + `BufReader<ChildStdout>`，用 `Mutex` 包裹
   - `spawn()`：`Command::new(python_path).arg(sidecar_path).stdin(Stdio::piped()).stdout(Stdio::piped()).spawn()`
   - Python 路径：dev 态用 `C:\Users\代\.venvs\honglou\Scripts\python.exe`（或环境变量 `HONGLOU_PYTHON` 覆盖）
   - sidecar.py 路径：dev 态相对 `CARGO_MANIFEST_DIR` 上溯到 `app/sidecar/honglou_sidecar.py`
   - `call(method, params)` -> `Value`：写一行 NDJSON 请求到 stdin，读一行 stdout 响应，JSON 反序列化
   - `shutdown()`：发 `shutdown` 方法，等进程退出（应用退出时调）

2. **`lib.rs`** —— 新增 invoke 命令：
   - `call_sidecar(method: String, params: Value)` -> `Result<Value, String>`：从 `tauri::State` 取 SidecarManager，调 `call(method, params)`
   - `shutdown_sidecar()`：应用退出时调用
   - `SidecarManager::spawn()` 在 `tauri::Builder::setup()` 中初始化，存入 `tauri::State`

3. **`Cargo.toml`** —— 新增依赖：`serde_json`、`once_cell`

### 步骤 3：前端 sidecar 调用封装

**文件**：`app/src/lib/tauri.ts`（扩展）+ 新建 `app/src/lib/sidecar.ts`

1. **`sidecar.ts`**：
   ```ts
   export interface EmotionSpan {
     line_offset: number;       // 章内 0-based 相对行
     dutir_top: string | null; // 好/乐/哀/怒/惧/恶/惊，null=无情感
     polarity: number;          // -1 ~ 1
     intensity: number;        // 0 ~ 1
     weights: Record<string, number>;
   }
   export async function analyzeSentiment(text: string): Promise<EmotionSpan[]>
   ```

2. **实现**：`analyzeSentiment` 调 `invoke<Value>('call_sidecar', {method: 'analyze_sentiment', params: {text}})`，取 `result.paragraphs`

### 步骤 4：Reader.vue 扩展 —— 情感着色

**文件**：`app/src/components/Reader.vue`（扩展）

1. **新增 props**：`emotions: EmotionSpan[]` + `emotionBaseLine: number`（章节起始物理行）

2. **renderDecorations() 扩展**（在现有章节标题/书签装饰后追加）：
   - 遍历 emotions，每个 span 的全局物理行 = `emotionBaseLine + line_offset`
   - 生成 `isWholeLine: true` 装饰，className = `"hl-emo-" + dutir_top`（如 `hl-emo-哀`）
   - dutir_top=null 的跳过（不着色）

3. **CSS**（七类七色低饱和底色）：
   - `hl-emo-好` → `#e8f5e9`（淡绿）
   - `hl-emo-乐` → `#fff8e1`（淡黄）
   - `hl-emo-哀` → `#e3f2fd`（淡蓝）
   - `hl-emo-怒` → `#ffebee`（淡红）
   - `hl-emo-惧` → `#f3e5f5`（淡紫）
   - `hl-emo-恶` → `#eceff1`（淡灰）
   - `hl-emo-惊` → `#fff3e0`（淡橙）

4. **图例栏**：阅读区顶部加一行可折叠的情绪图例（七色色块 + 标签），可开关情感着色显示

### 步骤 5：App.vue 集成 —— 分析触发

**文件**：`app/src/App.vue`（扩展）

1. **新增 ref**：`currentEmotions: EmotionSpan[]`、`emotionBaseLine: number`、`analyzing: boolean`

2. **loadBook() 扩展**：读完文本 + parseChapters 后，取第 1 章文本（`physicalLines.slice(chapters[0].line, chapters[1].line)`），调 `analyzeSentiment()`，存入 `currentEmotions`，`emotionBaseLine = chapters[0].line`

3. **翻章触发**：`selectChapter()` 中取该章文本 → 调 `analyzeSentiment()` → 更新 ref。已分析章暂不缓存（最小闭环，后续加 SQLite 再缓存）

4. **传给 Reader**：`<Reader :emotions="currentEmotions" :emotion-base-line="emotionBaseLine" ...>`

## 关键约束

- **锚点一致**：emotions 的全局物理行 = `emotionBaseLine + line_offset`，与书签同坐标系
- **不破坏 M1**：情感着色是叠加装饰，现有阅读/书签功能不受影响
- **复用资产**：`基础/emotion_analysis.py` 直接 import，不重写引擎
- **sidecar 生命周期**：长驻进程，应用退出时发 shutdown 再 kill
- **性能**：单章 30-60 段，分析 < 2 秒，不阻塞阅读（异步调用 + loading 状态）

## 验证

1. **sidecar 命令行单测**：手动喂 NDJSON `{"id":1,"method":"analyze_sentiment","params":{"text":"今日非常开心。宝玉十分悲伤。"}}` 给 sidecar，验证返回 JSON 含 dutir_top=乐/哀
2. **端到端**：
   - `pnpm build` + `cargo check` 通过
   - `pnpm tauri dev` 开窗，打开红楼梦.txt
   - 第 1 章自动分析 → 正文出现七色背景（哀段淡蓝、乐段淡黄等）
   - 翻到其他章 → 重新分析 → 着色更新
3. **性能**：单章分析 < 2 秒，分析时显示 loading
