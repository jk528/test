## 核心理念

1. **提示词即控制**：一句话控制阅读方式，解决 8+ 通道组合爆炸
2. **骨架稳定，内容可变**：框架留扩展性，大模型自打磨维度内容
3. **万维不局限**：多后端、多引擎、多数据源、新维度随时可扩展
