## 一、前置知识

### 1.1 当前 VBA 项目现状

#### 核心工作流

```
文件导入(TXT/Word/Excel) → 数据源A列(文本) + B列(章节目录)
  → 正则匹配目录(C5) → 目录补全(C6) → 目录表
  → 点击目录跳转 → 数据源定位
  → 字符级上色(Characters.Font.Color) → 章节频率统计
  → 字典查询(Like模糊匹配) → 频率矩阵
  → 字频统计(逐字进字典) → 按章节分布
  → 数据聚合(规则字符串) → 折线堆叠图
```

### 1.3 关键技术映射

理解 VBA 到 Electron 的概念对应关系是迁移的基础：

| VBA 概念 | Electron 等价 | 迁移说明 |
|---------|-------------|---------|
| `Range.Characters(start,len).Font.Color` | Monaco Tokenizer + CSS 主题 | 性能提升 100 倍+ |
| `VBScript.RegExp` | JavaScript `RegExp` | 语法几乎一致 |
| `Scripting.Dictionary` | `Map` / `Object` / `Record<string,T>` | — |
| `Range.Find` | `String.indexOf` / `RegExp.exec` | 内存操作，无 COM 开销 |
| `ADODB.Stream` (UTF-8读取) | `fs.readFile` + `iconv-lite` | Node.js 原生 |
| `Open For Binary` + BOM检测 | `jschardet` + `iconv-lite` | 成熟库，准确率更高 |
| `Range.Value = dataArray` 批量写入 | Vue 响应式渲染 | — |
| `xlLineStacked` 图表 | ECharts `type:'line', stack:'total'` | 交互式、可缩放 |
| `Application.ScreenUpdating` | 无需（DOM diff 自动优化） | — |
| Ribbon 菜单 (C1-C28) | Vue 组件 + 事件 | — |
| 工作表(Sheet) | Vue 路由页面 / 标签页 | — |
| `ThisWorkbook` 事件 | Electron 主进程事件 | — |

// src/main/fileImport/encodingDetect.ts
// 对应 VBA: DetectEncoding
import * as jschardet from 'jschardet'
import * as iconv from 'iconv-lite'

export function detectAndDecode(buffer: Buffer): string {
  const detected = jschardet.detect(buffer)
  const charset = detected.encoding || 'utf-8'
  return iconv.decode(buffer, charset)
}

// src/main/fileImport/txtReader.ts
// 对应 VBA: ImportTextDataToSheet
import { readFileSync } from 'fs'

export function readTxtFile(filePath: string): TextContent {
  const buffer = readFileSync(filePath)
  const text = detectAndDecode(buffer)

  // 对应 VBA: ConvertTextTo2DArray
  const lines = text.split(/\r?\n/).filter(l => l.trim() !== '')

  return {
    lines,                        // 文本行数组（对应数据源A列）
    totalLines: lines.length,
    sourcePath: filePath,
  }
}
```

**关键差异**：
- VBA 用 `Open For Binary` + 手动 BOM 检测 → Electron 用 `jschardet` 库（更准确）
- VBA 逐行 `Line Input` + `&` 拼接 → Electron 用 `buffer` 一次性读取 + `split`（快 10 倍+）
- VBA 写入 Excel 单元格 → Electron 存入内存数组 + Vue 响应式渲染

// src/main/chapterDetect/regexMatch.ts
// 对应 VBA: 正则查询优化
export interface Chapter {
  title: string
  lineIndex: number    // 对应数据源行号
}

export function detectChapters(
  lines: string[],
  patterns: string[]    // 对应 C2 单元格的正则
): Map<number, string> {
  const combinedPattern = patterns.join('|')
  const regex = new RegExp(combinedPattern)
  const matches = new Map<number, string>()

  lines.forEach((line, index) => {
    const match = line.match(regex)
    if (match) {
      matches.set(index, match[0])
    }
  })

  return matches
}

// src/main/chapterDetect/catalogFill.ts
// 对应 VBA: 正则后辅助目录优化（向下填充）
export function fillCatalog(
  lines: string[],
  chapterMatches: Map<number, string>
): string[] {
  const catalog = new Array(lines.length).fill('')
  let lastValid = ''

  lines.forEach((line, index) => {
    const match = chapterMatches.get(index)
    if (match) {
      lastValid = match
    }
    catalog[index] = lastValid
  })

  return catalog  // 对应数据源B列
}
```

**关键差异**：
- VBA 用 `VBScript.RegExp` → JS 用原生 `RegExp`（语法几乎一致）
- VBA 用 Dictionary 存匹配 → JS 用 `Map`（更高效）
- 向下填充逻辑完全一致：遍历 + lastValid 变量

// 对应 VBA: Color_SS_TO_SS_22（但实现方式完全不同）

import * as monaco from 'monaco-editor'

// 注册自定义语言（TxtNovel）
monaco.languages.register({ id: 'txt-novel' })

// 定义上色规则（对应 VBA 的高亮词数组 + 4色循环）
const COLORS = ['var(--color-red)', 'var(--color-green)',
                'var(--color-blue)', 'var(--color-cyan)']

export function setupColoring(keywords: string[]) {
  // 为每个关键词分配一个 token 类型和颜色
  const rules = keywords.map((word, i) => ({
    word,
    token: `keyword-${i}`,
    color: COLORS[i % 4],
  }))

  // 注册 Tokenizer 规则（替代 Characters.Font.Color）
  monaco.languages.setMonarchTokensProvider('txt-novel', {
    tokenizer: {
      root: rules.map(r => [r.word, r.token]),
    },
  })

  // 注册主题颜色（替代 RGB() 赋值）
  monaco.editor.defineTheme('novel-theme', {
    base: 'vs',
    inherit: true,
    rules: rules.map(r => ({ token: r.token, foreground: r.color })),
    colors: {},
  })
}
```

**关键差异**：
- VBA：`Characters(start,len).Font.Color = RGB(...)` 逐个 COM 调用 → 极慢
- Monaco：注册 Tokenizer 规则后，编辑器内部用 C++ 自动着色 → 极快
- VBA 上色 10 万字需 3-10 分钟 → Monaco 着色 10 万字 < 1 秒
- VBA 4 色循环 `Select Case mm` → Monaco 主题规则 `rules: [{token, foreground}]`

// src/renderer/src/composables/useChapterNavigation.ts
// 对应 VBA: D_CatalogJump.InitializeCatalogJump

export function useChapterNavigation(
  editor: monaco.editor.IStandaloneCodeEditor,
  chapters: Ref<Chapter[]>
) {
  function jumpToChapter(chapter: Chapter) {
    // 对应 VBA: Cells(行号, 1).Select
    editor.revealLineInCenter(chapter.lineIndex + 1)
    editor.setPosition({
      lineNumber: chapter.lineIndex + 1,
      column: 1,
    })
  }

  function searchInChapters(keyword: string): SearchResult[] {
    // 对应 VBA: ExecuteSearch (Like "*" & searchTerm & "*")
    const results: SearchResult[] = []
    const model = editor.getModel()!

    for (const chapter of chapters.value) {
      const matches = model.findMatches(
        keyword, false, false, false, null, false
      )
      matches.forEach(m => {
        results.push({
          chapter: chapter.title,
          line: m.range.startLineNumber,
          text: model.getLineContent(m.range.startLineNumber),
        })
      })
    }
    return results
  }

  return { jumpToChapter, searchInChapters }
}
```

**关键差异**：
- VBA 用 `Range.Find` + `Cells.Select` → Monaco 用 `findMatches` + `revealLineInCenter`
- VBA 全局变量 `htcz` 控制跳转开关 → Vue 响应式状态 `isNavEnabled`
- VBA UserForm3/4 多匹配选择 → Vue 组件弹窗

// src/main/dataAnalysis/aggregation.ts
// 对应 VBA: AggregateDataWithArrays

export function aggregateData(
  data: number[][],     // 原始数据矩阵
  rules: AggregationRule[] // 对应 VBA 规则字符串 "20,1|50,2"
): number[][] {
  return data.map(row => {
    const result: number[] = []
    for (const rule of rules) {
      for (let i = 0; i < rule.length; i++) {
        const start = i * rule.step
        const end = start + rule.step
        const sum = row.slice(start, end).reduce((a, b) => a + b, 0)
        result.push(sum)
      }
    }
    return result
  })
}

#### 数据模型设计

```typescript
// src/shared/types.ts

// 文本内容（对应数据源 A 列）
interface TextContent {
  id: string
  lines: string[]           // 文本行
  sourcePath: string        // 源文件路径
  encoding: string          // 编码
  totalLines: number
}

// 章节目录（对应数据源 B 列 + 目录表）
interface Chapter {
  title: string
  lineIndex: number         // 起始行号
  endIndex: number          // 结束行号
  level: number             // 层级（对应 .md ATX 标题层级）
}

// 上色规则（对应 READ_上色.bas 的 searchTexts 数组）
interface ColorRule {
  id: string
  keyword: string
  color: string             // CSS 颜色值
  enabled: boolean
}

// 查询结果（对应字典查询结果）
interface SearchResult {
  lineIndex: number
  text: string
  chapter: string
  matchCount: number
}

// 字频统计（对应 to___字频音333）
interface FrequencyStat {
  character: string
  totalCount: number
  byChapter: Map<string, number>  // 章节→出现次数
}

// 聚合规则（对应 VBA 规则字符串 "20,1|50,2"）
interface AggregationRule {
  length: number            // 生成列数
  step: number              // 每列合并原始列数
}

// 图表配置（对应 CreateCombinedChartOnSheet）
interface ChartConfig {
  type: 'line' | 'bar' | 'stacked-line'
  xAxis: string[]
  series: { name: string; data: number[] }[]
}
```

#### IPC 通道设计（完整版）

```typescript
// src/shared/ipc.ts

// 文件操作
'file:import'          → (filePath: string) → TextContent
'file:importDirectory' → (dirPath: string) → TextContent[]
'file:exportTxt'       → (content: string, path: string) → void

// 章节操作
'chapter:detect'       → (lines: string[], patterns: string[]) → Chapter[]
'chapter:fill'         → (lines: string[], chapters: Chapter[]) → string[]
'chapter:jump'         → (lineIndex: number) → void  // 渲染进程内

// 上色操作
'color:getRules'       → () → ColorRule[]
'color:saveRules'      → (rules: ColorRule[]) → void
// 上色在渲染进程内完成（Monaco Tokenizer），无需 IPC

// 查询操作
'search:query'         → (keyword: string, lines: string[]) → SearchResult[]
'search:batch'         → (keywords: string[], lines: string[]) → Map<string, SearchResult[]>

// 数据分析
'analysis:frequency'   → (lines: string[], chapters: string[]) → FrequencyStat[]
'analysis:aggregate'   → (data: number[][], rules: AggregationRule[]) → number[][]
'analysis:chart'       → (config: ChartConfig) → void  // 渲染进程内

// EPUB
'epub:convert'         → (filePath: string) → TextContent
```
