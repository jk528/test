## 一、全链总览

```
TXT文件
  │
  ▼ ① 文件导入（READ_TXTTOEXCEL.bas）
  │   ComprehensiveDataImport()
  │   → 选文件 → 检测编码 → 按编码读取 → 正则过滤 → 转数组 → 批量写入 → 格式化
  │
  ▼ ② 数据落位（数据源工作表）
  │   A列 = 文本内容（每行一条）
  │   B列 = 目录/章节
  │   C列 = 正则表达式（目录生成的前置，需用户预先填好）
  │
  ▼ ③ 目录生成（READ_正则查询替换目录.bas）
  │   正则查询优化() → 正则后辅助目录优化()
  │   → 读取C列正则模式 → 遍历A列文本执行匹配 → 向下填充目录
  │   → "目录"工作表 A5起 = 章节目录列表
  │
  ▼ ④ 字频统计（Read_最新字频.bas）★聚合前置
  │   to___字频音333()
  │   → 选文件(All Files) → Word.Application读取 → 正则提取中文 → 字典逐字统计
  │   → 冒泡排序升序（ascending=True，低频在前）
  │   → ArrayToDictWithPipe 按频率聚合同字（"字1|字2|字3"）
  │   → rex2：对每个字组，在数据源A列逐行正则匹配，按匹配次数×B列目录累加
  │   → 结果横向追加到"目录"工作表（每列=一个字组在各章节的命中分布）
  │
  ▼ ⑤ 数据聚合（READ_聚合生成折线堆叠图.bas）
  │   ProcessAndAggregateData()
  │   → 选"目录"工作表中的字频数据范围
  │   → 输入MOD值 → 输入聚合规则(长度,间距|长度,间距)
  │   → ValidateParameters → ParseInputStringToArray
  │   → AggregateDataWithArrays（三层嵌套循环求和）
  │   → 输出到新工作表
  │
  ▼ ⑥ 图表生成
  │   CreateCombinedChartOnSheet()
  │   → xlLineStacked 堆叠折线图
  │   → X轴=目录(章节)，Y轴=命中次数，图例=各聚合组
  │
  ▼ 最终产物
    "聚合结果 MOD_X 颗粒度_Y" 工作表 + 堆叠折线图

  ※ 独立分支：READ_最新字频2.bas（to_字频音__重复字）
     → 逐字处理（无ArrayToDictWithPipe）→ 找重复字 → 输出到"重复字"工作表
     → 不参与聚合链，是独立的重复字检测功能
```

## 二、阶段①：TXT 导入详解

### 2.1 入口 `ComprehensiveDataImport()`

用户选择文件 → 判断类型 → 选择处理方式 → 选择导入方式 → 调用 `ImportTextDataToSheet`

### 2.2 编码检测 `DetectEncoding(filePath)`

```
读取文件前4字节
├── FF FE → UTF-16LE
├── FE FF → UTF-16BE
├── EF BB BF → UTF-8 BOM
└── 无BOM → 逐字节扫描高位模式 → UTF-8 或 ANSI
```

### 2.3 按编码读取

| 编码 | 读取方式 |
|------|----------|
| ANSI | Open For Input 逐行 Line Input |
| UTF-8 | ADODB.Stream + Charset="utf-8" |
| Unicode | FileSystemObject.OpenTextFile + TristateTrue |

### 2.4 文本处理（3种模式）

- 模式1：保留空格和全角空格，正则 `[\u4e00-\u9fa5a-zA-Z0-9 \u3000]`
- 模式2：只保留中文/英文/数字，正则 `[\u4e00-\u9fa5a-zA-Z0-9]`
- 模式3：正常读取，保留所有内容

非目标字符替换为 `|` 作为分隔符。

### 2.5 转二维数组 `ConvertTextTo2DArray`

- 模式1/2：按 `|` 分割，每段一行
- 模式3：统一换行符后 Split，每行一条

### 2.6 批量写入 + 格式化

```vba
Range("A1").Resize(rowCount, 1).Value = dataArray  ' 一次性写入
' FormatSheet: 列宽200、字号26、自动换行、浅蓝色背景
```

## 三、阶段②③④：数据落位 + 目录生成 + 字频统计（聚合前置）

### 3.1 数据源工作表结构（阶段②）

```
A列          B列           C列
文本内容      目录/章节      正则表达式(目录生成前置)
"第一行文本"  "第一章"      "第.*章"
"第二行文本"  "第一章"
"第三行文本"  "第二章"
```

> **隐藏依赖**：C列的正则表达式需要在目录生成(③)之前由用户预先填好，否则正则查询无模式可用。

### 3.2 目录生成（阶段③）

正则查询优化() → 正则后辅助目录优化() → "目录"工作表 A5起生成章节列表：

```
"目录"工作表：
A5: 第一章
A6: 第二章
A7: 第三章
...
```

> **隐藏依赖**：rex2(④)从"目录"工作表 A5:A&L 读取章节名初始化字典。如果目录生成(③)未执行，rex2 无章节可累加。

### 3.3 字频统计 rex2（阶段④，聚合的真正前置）★关键

> **仅 `Read_最新字频.bas`（`to___字频音333()`）参与聚合链。**
> `READ_最新字频2.bas`（`to_字频音__重复字()`）是独立的重复字检测功能，不参与聚合。

字频统计分三步：

**Step 1 - 字频统计：** 选文件（`All Files (*.*)` 过滤器，通过 `Word.Application` 打开）→ 正则 `[^\u4e00-\u9fa5]` 过滤非中文 → 字典逐字统计 → `BubbleSort2DArray(sortedArray, 2, True)` **升序排列**（低频在前，高频在后）

> **偏差修正**：原文档写"冒泡排序降序"，实际 `ascending=True` 为升序。排序方向决定 rex2 处理字组的顺序，进而决定字频列在"目录"工作表的排列（左=低频，右=高频）。聚合规则"20,1|50,2"中前20列直接取值——如果列顺序搞反了，高频字组会被直接取值而低频字组被聚合求和，语义完全不同。

**Step 2 - 按频率聚合同字（ArrayToDictWithPipe）：** 将相同频率的字用 `|` 连接为一个字组，如频率3的字有"的|了|是"

**Step 3 - rex2 反向匹配数据源：**

```vba
' rex2(n, nn, drr) 参数说明：
'   n  = 频率值（如 100），用于表头"频率:" & n 和计算"字数" & count2 / n
'   nn = 字组模式（如 "的|了|是"），用作正则 .Pattern
'   drr = 数据源 A1:B&LL 的二维数组

' ① 从"目录"工作表读取章节名，初始化字典 d2（键=章节名，值=0）
L = Sheets("目录").Range("A1048576").End(xlUp).Row
brr = Sheets("目录").Range("A5:A" & L)
For j = 1 To L - 4
    d2.Add brr(j, 1), 0
Next

' ② 对数据源逐行正则匹配，按匹配次数×目录累加
For i = 1 To UBound(drr)
    sr = drr(i, 1)                            ' 数据源A列文本
    With Reg
        .Global = True
        .Pattern = nn                         ' 如 "的|了|是"
        If .Test(sr) Then
            Set mat = .Execute(sr)
            For m = 1 To mat.count            ' ★关键：按匹配次数累加
                d2(drr(i, 2)) = d2(drr(i, 2)) + 1   ' 按B列目录累加
            Next
        End If
    End With
Next

' ③ 结果横向追加到"目录"工作表
With Sheets("目录")
    mm = .[xfd3].End(xlToLeft).Column         ' 行3最右非空列
    ' 统计零值和非零值
    For Each key In d2.keys
        If d2(key) = 0 Then count = count + 1
        Else: count2 = count2 + d2(key)
    Next
    .Cells(5, mm + 1).Resize(d2.count, 1) = Application.Transpose(d2.items)
    .Cells(4, mm + 1) = "字数" & count2 / n    ' 平均每字命中次数
    .Cells(3, mm + 1) = "合计:" & count2       ' 总命中次数
    .Cells(2, mm + 1) = "频率:" & n            ' 该字组的频率
    .Cells(1, mm + 1) = "总空:" & d2.count & "_" & count  ' 章节总数_零命中数
End With
```

> **偏差修正**：原文档伪代码 `If .Test(drr(i, 1)) Then d2(...) = d2(...) + 1` 每行只+1。实际代码 `For m = 1 To mat.count: d2(...) = d2(...) + 1: Next` **按匹配次数累加**。若一行文本为"我的是了的了是"，字组"的|了|是"匹配5次，实际+5而非+1。

**rex2 输出后，"目录"工作表结构变为：**

```
行1:  总空:30_5     |  总空:28_3     |  总空:25_2     ...
行2:  频率:3        |  频率:5        |  频率:8        ...
行3:  合计:12       |  合计:45       |  合计:120      ...
行4:  字数:4        |  字数:9        |  字数:15       ...
行5:  第一章        |  2             |  5             |  12    ...
行6:  第二章        |  3             |  8             |  18    ...
行7:  第三章        |  7             |  15            |  25    ...
      A列(目录)       B列(低频字组)    C列(中频字组)    D列(高频字组)
```

> 列排列顺序由排序方向决定：升序排列 → 左低频右高频。

**每列 = 一个字组在各章节的命中次数分布**，这就是聚合的输入数据。

### 3.4 READ_最新字频2.bas（独立分支，非聚合前置）

`to_字频音__重复字()` 与聚合链**完全无关**：

| 对比项 | Read_最新字频.bas（聚合前置） | READ_最新字频2.bas（独立功能） |
|--------|-------------------------------|-------------------------------|
| ArrayToDictWithPipe | ✅ 使用，按频率分组 | ❌ 不使用，逐字处理 |
| rex2 的 .Pattern | 字组"的\|了\|是" | 单个字"的" |
| rex2 逻辑 | 按目录累加命中次数 | 找重复字（m>1时记录），递减频率计数 |
| 输出目标 | "目录"工作表横向追加 | "重复字"工作表 |
| 文件选择 | All Files (*.*) | 文本文件 (*.txt) |
| 是否聚合前置 | ✅ 是 | ❌ 否 |

## 四、阶段⑤：数据聚合详解

### 4.1 主过程 `ProcessAndAggregateData()` 流程

```
Step1: 选数据范围 (Application.InputBox Type:=8)
Step2: dataArray = inputRange.Value           ' 读入二维数组
Step3: rowCount = UBound(dataArray,1)         ' 行数
       colCount = UBound(dataArray,2)         ' 列数
       colCount2 = Min(colCount, 255)          ' 用于MOD默认值
Step4: 输入MOD值 (≤255，默认=colCount2)       ' 聚合后的列数
Step5: 检查 colCount > modValue               ' 列数必须大于MOD才需聚合
Step6: 输入聚合规则 "长度,间距|长度,间距"      ' 如 "20,1|50,2"
Step7: ValidateParameters()                   ' 验证参数合法性
Step8: parsedData = ParseInputStringToArray() ' 解析规则为二维数组
Step9: ReDim resultArray(1 To rowCount, 1 To modValue) As Double
Step10: AggregateDataWithArrays()              ' 核心聚合求和
Step11: 新建工作表，写入结果 + 复制目录列 + 复制表头(Offset(-3))
Step12: CreateCombinedChartOnSheet()          ' 生成堆叠折线图
```

### 4.2 聚合规则格式

格式：`长度,间距|长度,间距...`

- **长度**：该规则组输出多少个聚合列
- **间距**：每个聚合列由多少个原始列求和得到
- **|**：分隔多个规则组

示例 `20,1|50,2`：
- 第一组：输出20列，每列由1个原始列直接取值（不聚合）
- 第二组：输出50列，每列由2个原始列求和
- 总消耗原始列数 = 20×1 + 50×2 = 120
- 总输出聚合列数 = 20 + 50 = 70（应等于MOD值）

### 4.3 规则解析 `ParseInputStringToArray()`

将 `"20,1|50,2"` 解析为二维数组 `parsedData`：

```
parsedData(0,0)=20  parsedData(0,1)=1  parsedData(0,2)=20   ' 长度,间距,消耗列数
parsedData(1,0)=50  parsedData(1,1)=2  parsedData(1,2)=100  ' 长度,间距,消耗列数
```

**余数处理**（当原始列数未被规则完整覆盖时）：
- `remainingColumns = totalColumns - 已消耗列数`
- `granularity = modValue - 已分配聚合列数`
- 若 `remainingColumns = 0 And granularity = 0` → `dataOffset = 2`（跳过余数组）
- 若能整除（remainder = 0）→ `dataOffset = 1`，追加1组规则
- 若有余数（remainder ≠ 0）→ `dataOffset = 0`，追加2组规则分别处理整除部分和余数部分

> **dataOffset 取值规则**：控制聚合循环上界 `UBound(parsedData, 1) - dataOffset`。值为2时跳过最后2组（余数组），值为1时跳过最后1组，值为0时使用全部组。

### 4.4 核心聚合算法 `AggregateDataWithArrays()` 逐行详解

```vba
' 初始化结果数组为0（VBA的ReDim已自动清零，此循环可省略）
For i = 1 To rowCount
    For aggregateColumnIndex = 1 To modValue
        resultArray(i, aggregateColumnIndex) = 0
    Next
Next

' ① 遍历每一行
For i = 1 To rowCount
    aggregateColumnIndex = 0
    k = 0                                      ' k = 原始列游标

    ' ② 遍历每个规则组
    For L = 0 To UBound(parsedData, 1) - dataOffset
        currentLength = parsedData(L, 0)       ' 该组输出列数
        currentSpacing = parsedData(L, 1)      ' 该组求和间距

        ' ③ 遍历该组每个聚合列
        For u = 1 To currentLength
            sumValue = 0

            ' ④ 遍历间距内的原始列求和
            For m = 1 To currentSpacing
                k = k + 1
                If k <= UBound(dataArray, 2) Then
                    If IsNumeric(dataArray(i, k)) Then
                        sumValue = sumValue + CDbl(dataArray(i, k))
                    End If
                End If
            Next m

            ' 写入聚合结果
            If aggregateColumnIndex < modValue Then
                aggregateColumnIndex = aggregateColumnIndex + 1
                resultArray(i, aggregateColumnIndex) = sumValue
            End If
        Next u
    Next L
Next i
```

**三层嵌套循环结构：**
- 外层 `For i`：遍历每一行
- 中层 `For L → For u`：遍历规则组 → 遍历该组每个输出列
- 内层 `For m`：在间距内对原始列求和

**游标 k 的作用：** 全局列游标，跨规则组连续推进。第一组消耗 k=1~20，第二组从 k=21 开始。

### 4.5 具体示例

假设：1000行×120列数据，MOD=70，规则 `20,1|50,2`

```
第一组(20,1)：k=1→20,  每列取1个原始列, 输出20列  (直接取值)
第二组(50,2)：k=21→120, 每列取2个原始列求和, 输出50列 (两两求和)

结果：1000行×70列
- 第1~20列 = 原始第1~20列（不聚合）
- 第21~70列 = 原始第21+22, 23+24, ..., 119+120（两两求和）
```

### 4.6 输出到工作表

```vba
' 新建工作表
Set newSheet = ThisWorkbook.Sheets.Add(...)
newSheet.Name = "聚合结果 MOD_ _" & modValue & "颗粒度_ _" & inputString

' 一次性写入聚合结果（B2起）
newSheet.Range("B2").Resize(rowCount, modValue).Value = resultArray

' 复制表头（从选中区域上方3行复制，即"频率"行）
If inputRange.row > 1 Then
    inputRange.Offset(-3, 0).Resize(1, inputRange.Columns.count).Copy _
    Destination:=newSheet.Range("B1").Resize(1, inputRange.Columns.count)
End If

' A列添加目录标题
newSheet.Cells(1, 1).Value = "目录"

' 如果选中区域不在A列，复制源数据A列（目录列）
If inputRange.Column > 1 Then
    wsSource.Range(wsSource.Cells(inputRange.row, 1), _
                   wsSource.Cells(inputRange.row + rowCount - 1, 1)).Copy _
    Destination:=newSheet.Range("A2").Resize(rowCount, 1)
End If

' 自动调整列宽
newSheet.Columns.AutoFit
```

> **偏差修正**：原文档未提及表头复制的 `Offset(-3, 0)` 偏移。实际代码从选中区域上方3行复制1行作为表头（即"目录"工作表的第2行"频率:XXX"行）。

## 五、阶段⑥：图表生成详解

### 5.1 `CreateCombinedChartOnSheet(ws, dataRange, inputString)`

```vba
' 清除旧图表
On Error Resume Next
ws.ChartObjects.Delete
On Error GoTo 0

' 创建图表对象（1400×900像素）
Set chartObj = ws.ChartObjects.Add(Left:=0, Top:=0, Width:=1400, Height:=900)

With chartObj.Chart
    .ChartType = xlLineStacked              ' 堆叠折线图
    .SetSourceData Source:=dataRange        ' 数据源=目录+聚合结果
    .PlotBy = xlColumns                     ' 按列绘制（每列一个数据系列）

    .HasTitle = True
    .ChartTitle.text = "聚合数据堆叠图: " & inputString
    .ChartTitle.Font.Size = 14
    .ChartTitle.Font.Bold = True

    .Axes(xlCategory, xlPrimary).HasTitle = True
    .Axes(xlCategory, xlPrimary).AxisTitle.text = "目录"   ' X轴
    .Axes(xlValue, xlPrimary).HasTitle = True
    .Axes(xlValue, xlPrimary).AxisTitle.text = "词量"      ' Y轴

    .HasLegend = True
    .Legend.Position = xlLegendPositionBottom    ' 图例在底部
End With
```

### 5.2 图表数据范围

```
dataRange = newSheet.Range(Cells(1,1), Cells(rowCount+1, modValue+1))
           = A1起 ~ (rowCount+1)行 × (modValue+1)列
           = 目录列 + modValue个聚合列
```

- **X轴**：目录（A列，章节名）
- **Y轴**：词量（聚合求和值）
- **数据系列**：modValue 个系列，每个系列一列聚合数据
- **堆叠效果**：同一X轴点上所有系列的Y值堆叠显示

## 七、依赖关系

### 7.1 依赖关系图

## 八、优化设计方案

### 8.1 架构层优化：流水线自动化

**现状问题**：用户需手动执行5步（导入→填正则→目录生成→字频统计→聚合），每步之间无自动衔接。

**设计方案：PipelineController 主控流程**

```
用户选TXT文件
  │
  ├─→ ① 自动导入到数据源
  ├─→ ② 提示用户填入/选择正则模式（或从模板库选）
  ├─→ ③ 自动执行目录生成
  ├─→ ④ 自动执行字频统计（选同一文件，无需二次选择）
  ├─→ ⑤ 自动检测"目录"工作表字频列数，预填MOD和规则建议
  ├─→ ⑥ 用户确认后自动执行聚合并生成图表
  └─→ ⑦ 输出结果 + 一键导出PNG
```

**关键改进点：**

| 改进 | 实现方式 | 价值 |
|------|----------|------|
| 消除二次选文件 | 字频统计自动复用①中选择的文件路径 | 减少用户操作 |
| 自动检测字频列数 | 扫描"目录"工作表行3非空列数 | 预填MOD默认值 |
| 智能推荐聚合规则 | 根据列数自动推荐"n,1\|m,2"使n+m=MOD | 降低使用门槛 |
| 前置检查 | 执行每步前检查依赖是否就绪 | 避免空跑报错 |

### 8.2 数据层优化：rex2 性能与精度

**现状问题**：rex2 对每个字组遍历数据源全部行，N个字组×M行=O(N×M)次正则匹配，大数据量时慢。

**设计方案：**

```
优化A - 预编译正则缓存：
  将 RegExp 对象按字组预创建并缓存，避免每次 rex2 重复创建/销毁

优化B - 批量字组合并匹配：
  将多个低频字组合并为一个超大正则模式一次性匹配
  用回溯确定命中的是哪个字组，减少总匹配次数

优化C - 文本预处理索引：
  导入时为每行文本构建字符集位图（哪些字出现过）
  rex2 先查位图快速过滤不可能命中的行，再做正则确认
  预期减少60-80%的正则调用
```

### 8.3 算法层优化：聚合引擎增强

**现状问题**：聚合仅支持求和，余数处理复杂，70个图表系列可读性差。

**设计方案：聚合引擎 v2**

```
┌─ 聚合方式扩展 ──────────────────────────────────┐
│  当前: 仅 Sum                                    │
│  扩展: Sum / Avg / Max / Min / Count / Median    │
│  接口: 聚合规则增加第3参数 "长度,间距,方式"       │
│  示例: "20,1,sum|50,2,avg"                       │
└──────────────────────────────────────────────────┘

┌─ 余数处理重构 ──────────────────────────────────┐
│  当前: dataOffset + 两种分支，逻辑分散            │
│  重构: 独立函数 HandleRemainder()                │
│  策略: 余数列均匀分配到各规则组，而非集中追加      │
│  测试: 增加 6 种边界用例覆盖                       │
└──────────────────────────────────────────────────┘

┌─ 图表可读性 ────────────────────────────────────┐
│  当前: 70个系列一张堆叠折线图，图例密密麻麻        │
│  方案1: 分组子图——按规则组拆成多张小图            │
│  方案2: 热力图——章节×字组矩阵，颜色深浅=命中数    │
│  方案3: Top-N系列——只显示合计值最高的N个系列       │
│  方案4: 交互式——点击图例显隐对应系列               │
└──────────────────────────────────────────────────┘
```

### 8.4 健壮性优化：错误防护

| 问题 | 现状 | 设计方案 |
|------|------|----------|
| 工作表名称冲突 | MsgBox报错后退出 | 自动加时间戳后缀，如 `聚合结果_MOD70_20261020_0406` |
| 排序方向隐式依赖 | 升序排列但无注释 | 在rex2输出列头标注"频率(升序)"，聚合时自动检测列顺序 |
| C列空值 | 正则查询静默无结果 | 执行前检查C列非空，提示"请先在C列填入正则表达式" |
| "目录"工作表不存在 | rex2运行时报错 | 执行前检查工作表是否存在，提示"请先执行目录生成" |
| rex2匹配次数溢出 | 长文本大量匹配可能超Integer | 用Long替代Integer累加 |
| 输入验证不足 | 只检查格式 | 增加语义验证：Σ(长度ᵢ×间距ᵢ)≤colCount，Σ长度ᵢ=MOD |

### 8.6 性能优化

| 问题 | 现状 | 优化方案 | 预期收益 |
|------|------|----------|----------|
| 结果数组初始化 | 双重循环清零 | `ReDim` 后 VBA 自动清零，删除初始化循环 | 减少 rowCount×modValue 次循环 |
| IsNumeric 逐次判断 | 每个单元格调用 | 预扫描列类型，布尔标志数组跳过非数值列 | 减少~50%类型检查 |

| rex2 正则对象 | 每次调用重新创建 | 模块级静态对象复用 | 减少对象创建开销 |

### 8.7 算法复杂度分析

```
聚合算法:
  时间复杂度: O(rowCount × Σ(长度ᵢ × 间距ᵢ))
             = O(rowCount × colCount)   ' 理想情况每列恰好访问一次
  空间复杂度: O(rowCount × colCount)    ' 原始数组 + 结果数组

rex2算法:
  时间复杂度: O(字组数 × 数据源行数 × 平均匹配次数)
  空间复杂度: O(章节数)                   ' 字典 d2

当 rowCount=10000, colCount=120, modValue=70 时：
  - 聚合: 原始数组120万 + 结果数组70万 + 求和~120万次 → <1秒
  - rex2: 120个字组 × 10000行 = 120万次正则匹配 → 主要瓶颈
```

## 十、一句话总结与修正

### 10.1 用户提出的总结

> "词频在各章节的折线可控聚合折线图"

### 10.2 准确性评估

| 要素 | 用户表达 | 实际情况 | 是否准确 |
|------|---------|----------|---------|
| 统计对象 | "词频" | **字频**——对文本逐字统计频率（非词语），再按频率分组 | ⚠️ 不准确，应为"字频" |
| 分布维度 | "在各章节" | 字组在各章节（目录）的命中次数分布 | ✅ 准确 |
| 图表类型 | "折线…折线图" | **堆叠**折线图（xlLineStacked），"折线"重复了两次 | ⚠️ 缺少"堆叠"，且有冗余 |
| 聚合特性 | "可控聚合" | 用户通过规则"长度,间距\|长度,间距"自定义控制列合并方式 | ✅ 准确 |

### 10.3 修正后的一句话总结

> **字频统计在各章节的命中分布，经用户自定义规则聚合后，生成堆叠折线图。**

拆解：
- **字频统计**——对文本逐字统计出现频率，按频率分组（同频字用`|`连接为字组）
- **在各章节的命中分布**——每个字组反向匹配数据源文本，按章节累加匹配次数
- **用户自定义规则聚合**——通过"长度,间距"规则控制列合并粒度（如前20列保留细节、后50列两两合并）
- **堆叠折线图**——X轴=章节，Y轴=命中次数，每个聚合列一个数据系列，纵向堆叠

### 步骤间依赖链

```
① TXT导入 ──→ ② 目录生成 ──→ ③ 字频rex2 ──→ ④ 聚合 ──→ ⑤ 图表
     │              │                │              │
     │              │                │              │
   产出:          产出:            产出:          产出:
   数据源A列     "目录"A5起       "目录"B5起     新工作表
   文本数据      章节名列表       字频命中列     聚合结果
                                  (每列=一字组
                                   在各章节命中)
```

> 每步的完成标志是下一步的前置条件。跳过任何一步会导致后续步骤无数据可处理或报错。

## 十二、数据纯净度要求

> 用户一步步手动操作的原因是不确定中间数据是否"干净"。以下逐环节列出数据纯净度要求，以及不满足时会**悄悄出错**（不报错但结果错）的场景。

### 12.1 总览：纯净度检查清单

```
环节          要检查什么                          不纯的后果
─────────────────────────────────────────────────────────────
①导入后       A列不能有空行                       rex2跳过空行，该章节计数偏低
              A列每行是完整语义单元               断句错误→章节归属错乱

②目录生成后   B列目录名与"目录"A列完全一致         ★最危险：rex2会创建新key，命中算到不存在的章节
              "目录"A5起无重复章节名              d2.Add报错（重复key）
              "目录"A5起无空行                    空行被当作章节名加入字典
              C列正则模式有效                     正则查询无结果，目录为空

③字频统计后   统计文件含中文字符                   Text2为空→无字可统计→rex2无数据
              "目录"工作表有章节名                 rex2初始化字典为空→无法累加

④聚合时       选中范围全是数值                     ★IsNumeric静默跳过文本=数据丢失不报错
              从B5起选，不选A列                   A列是章节名(文本)→被静默跳过
              列数>MOD值                          提示"无需聚合"退出
```

### 12.2 逐环节详解

#### ① TXT导入后：数据源A列

| 要求 | 通俗解释 | 不满足的后果 |
|------|---------|-------------|
| A列无空行 | 每行都得有文字，不能中间夹空行 | rex2遍历时跳过空行，但B列目录还在→该章节命中次数偏低，**不报错** |
| A列每行是完整语义单元 | 模式1/2按`\|`分割断句，如果`\|`位置不对，一句话被切成两行 | 章节归属可能错乱→统计的不是完整句子的字频 |
| 编码可识别 | 文件不是损坏的、不是混合编码 | 编码检测失败→乱码或读取报错 |

#### ② 目录生成后：数据源B列 + "目录"工作表

| 要求 | 通俗解释 | 不满足的后果 |
|------|---------|-------------|
| ★ **B列目录名与"目录"A列完全一致** | "第一章"不能写成"第一章 "（多空格）、"第一章\n"（多换行）、"第1章"（数字vs汉字） | **最危险的隐患**：rex2用字典key匹配，"第一章" ≠ "第一章 "。不匹配的行会**新建一个key**而不是累加到已有章节→命中次数算到了不存在的章节，**不报错但数据全错** |
| "目录"A5起无重复章节名 | 不能有两个"第一章" | rex2的 `d2.Add brr(j,1), 0` 遇到重复key会报错 |
| "目录"A5起无空行 | 章节名列表中间不能有空行 | 空行会被当作章节名加入字典→聚合时多出一行空章节 |
| C列正则模式有效 | 正则表达式语法正确（如"第.*章"不能写成"第*章"） | 正则查询无匹配→目录为空→后续全链无数据 |

#### ③ 字频统计后：rex2输出

| 要求 | 通俗解释 | 不满足的后果 |
|------|---------|-------------|
| 统计文件含中文字符 | 文件里得有中文，不能是纯英文/纯数字 | 正则`[^\u4e00-\u9fa5]`过滤后Text2为空→无字可统计→rex2无输出，**不报错** |
| Word能打开文件 | 文件没损坏、没加密 | Word.Application报错或挂起 |
| "目录"工作表A5起有章节名 | 步骤②必须已完成 | rex2初始化字典d2为空→无法累加→所有命中为0，**不报错** |

#### ④ 聚合时：用户选范围

| 要求 | 通俗解释 | 不满足的后果 |
|------|---------|-------------|
| ★ **选中范围全是数值** | 只能选B5起的数字区域，不能选到行1-4的"频率:100"等文字 | **IsNumeric静默跳过文本单元格**=数据丢失，**不报错但聚合结果缺数据** |
| 从B5起选，不选A列 | A列是章节名（文字），不是数字 | A列被IsNumeric跳过→聚合结果少一列，**不报错** |
| 列数 > MOD值 | 选的列数得大于聚合目标列数 | 提示"无需聚合"退出（这个会报错，不算隐患） |
| 规则覆盖所有列 | `Σ(长度ᵢ × 间距ᵢ)` 应等于选的列数 | 未覆盖的列被忽略→数据丢失，**不报错** |

### 12.3 最危险的3个"静默出错"场景

> 以下场景**不会报错**，程序正常跑完，但结果数据是错的。

**场景1：章节名不一致（最常见）**

```
数据源B列:  "第一章 "  ← 末尾多了个空格
"目录"A列:  "第一章"   ← 没有空格

rex2执行时:
  d2.Add "第一章", 0          ← 从"目录"工作表初始化
  d2("第一章 ") = d2(...) + 1  ← 数据源B列是"第一章 "
                                 字典里没有"第一章 "这个key
                                 VBA字典会自动新建！
结果: "第一章"的命中=0（永远是0）
      "第一章 "的命中=实际值（但这个key不在"目录"工作表里）
      → 聚合时"第一章"那行全是0，图表上该点为0
```

**场景2：选范围选到了文本行头**

```
用户选中: A1:D30  ← 从第1行开始选
实际数据: 第1-4行是"总空:30_5""频率:3"等文本
          第5行起才是数字

聚合执行时:
  IsNumeric("总空:30_5") = False → 跳过
  IsNumeric("频率:3") = False → 跳过
  结果: resultArray前4行全是0
  → 图表上前4个X轴点的Y值全是0
```

**场景3：空行导致章节计数偏低**

```
数据源:
  A5: "这是第五章的内容"   B5: "第五章"
  A6: ""                  B6: "第五章"   ← 空行！
  A7: "继续第五章"        B7: "第五章"

rex2执行时:
  i=5: .Test("这是第五章的内容") = True → d2("第五章") += 匹配次数
  i=6: .Test("") = False → 跳过（空行没有文本可匹配）
  i=7: .Test("继续第五章") = True → d2("第五章") += 匹配次数

结果: "第五章"的命中少了A6那行应有的贡献
      → 图表上"第五章"的Y值偏低
```

### 12.4 建议的纯净度检查方案

```
在每步执行后、下一步执行前，自动检查：

步骤①后:
  □ A列是否有空行          → 遍历A列，发现空行则警告
  □ A列是否有乱码           → 检查是否含?或□等替换符

步骤②后:
  □ B列每个值是否在"目录"A列中存在  → 逐行比对，发现不一致则警告
  □ "目录"A5起是否有重复值          → 字典去重检查
  □ "目录"A5起是否有空行            → 遍历检查

步骤③后:
  □ "目录"工作表B5起是否有非数值    → IsNumeric逐格检查
  □ 每列的合计是否>0                → 全0列说明该字组未命中任何章节

步骤④前:
  □ 选中范围的起始行是否≥5          → 避免选到行头文本
  □ 选中范围是否包含A列             → A列是文本，不应包含
  □ 规则覆盖列数是否=选中列数        → 避免遗漏
```

> 这些检查可以用一段独立的 VBA 函数 `ValidateDataPurity()` 实现，在每步执行后自动调用，发现问题弹窗警告而非静默继续。这是 §八 优化方案中健壮性优化的具体落地。
