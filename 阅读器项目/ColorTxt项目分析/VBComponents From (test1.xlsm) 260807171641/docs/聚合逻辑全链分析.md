# 聚合逻辑全链分析：从 TXT 导入到折线图（修正版）

> 完整追踪从 TXT 文件导入 → 数据源 → 目录生成 → 字频统计 → 数据聚合 → 堆叠折线图的全链逻辑。
> **修正**：聚合的前置数据是字频统计（rex2）的输出，不是正则查询匹配结果。

---

## 一、全链总览

```
TXT文件
  │
  ▼ ① 文件导入（READ_TXTTOEXCEL.bas）
  │   ComprehensiveDataImport()
  │   → 选文件 → 检测编码 → 按编码读取 → 正则过滤 → 转数组 → 批量写入 → 格式化
  │
  ▼ ② 数据落位（数据源工作表）
  │   A列 = 文本内容（每行一条）
  │   B列 = 目录/章节
  │
  ▼ ③ 目录生成（READ_正则查询替换目录.bas）
  │   正则查询优化() → 正则后辅助目录优化()
  │   → "目录"工作表 A5起 = 章节目录列表
  │
  ▼ ④ 字频统计（Read_最新字频.bas / READ_最新字频2.bas）★聚合前置
  │   to___字频音333() / to_字频音__重复字()
  │   → 选文件 → 提取中文 → 字典逐字统计 → 冒泡排序降序
  │   → ArrayToDictWithPipe 按频率聚合同字（"字1|字2|字3"）
  │   → rex2：对每个字组，在数据源A列逐行正则匹配，按B列目录累加命中次数
  │   → 结果横向追加到"目录"工作表（每列=一个字组在各章节的命中分布）
  │
  ▼ ⑤ 数据聚合（READ_聚合生成折线堆叠图.bas）
  │   ProcessAndAggregateData()
  │   → 选"目录"工作表中的字频数据范围
  │   → 输入MOD值 → 输入聚合规则(长度,间距|长度,间距)
  │   → ValidateParameters → ParseInputStringToArray
  │   → AggregateDataWithArrays（三层嵌套循环求和）
  │   → 输出到新工作表
  │
  ▼ ⑥ 图表生成
  │   CreateCombinedChartOnSheet()
  │   → xlLineStacked 堆叠折线图
  │   → X轴=目录(章节)，Y轴=命中次数，图例=各聚合组
  │
  ▼ 最终产物
    "聚合结果 MOD_X 颗粒度_Y" 工作表 + 堆叠折线图
```

## 二、阶段①：TXT 导入详解

### 2.1 入口 `ComprehensiveDataImport()`

用户选择文件 → 判断类型 → 选择处理方式 → 选择导入方式 → 调用 `ImportTextDataToSheet`

### 2.2 编码检测 `DetectEncoding(filePath)`

```
读取文件前4字节
├── FF FE → UTF-16LE
├── FE FF → UTF-16BE
├── EF BB BF → UTF-8 BOM
└── 无BOM → 逐字节扫描高位模式 → UTF-8 或 ANSI
```

### 2.3 按编码读取

| 编码 | 读取方式 |
|------|----------|
| ANSI | Open For Input 逐行 Line Input |
| UTF-8 | ADODB.Stream + Charset="utf-8" |
| Unicode | FileSystemObject.OpenTextFile + TristateTrue |

### 2.4 文本处理（3种模式）

- 模式1：保留空格和全角空格，正则 `[\u4e00-\u9fa5a-zA-Z0-9 \u3000]`
- 模式2：只保留中文/英文/数字，正则 `[\u4e00-\u9fa5a-zA-Z0-9]`
- 模式3：正常读取，保留所有内容

非目标字符替换为 `|` 作为分隔符。

### 2.5 转二维数组 `ConvertTextTo2DArray`

- 模式1/2：按 `|` 分割，每段一行
- 模式3：统一换行符后 Split，每行一条

### 2.6 批量写入 + 格式化

```vba
Range("A1").Resize(rowCount, 1).Value = dataArray  ' 一次性写入
' FormatSheet: 列宽200、字号26、自动换行、浅蓝色背景
```

## 三、阶段②③：数据落位 + 目录生成 + 字频统计（聚合前置）

### 3.1 数据源工作表结构（阶段②）

```
A列          B列
文本内容      目录/章节
"第一行文本"  "第一章"
"第二行文本"  "第一章"
"第三行文本"  "第二章"
```

### 3.2 目录生成（阶段③）

正则查询优化() → 正则后辅助目录优化() → "目录"工作表 A5起生成章节列表：

```
"目录"工作表：
A5: 第一章
A6: 第二章
A7: 第三章
...
```

### 3.3 字频统计 rex2（阶段④，聚合的真正前置）★关键

字频统计分三步：

**Step 1 - 字频统计：** 选TXT/Word文件 → 正则 `[^\u4e00-\u9fa5]` 过滤非中文 → 字典逐字统计 → 冒泡排序降序

**Step 2 - 按频率聚合同字（ArrayToDictWithPipe）：** 将相同频率的字用 `|` 连接为一个字组，如频率100的字有"的|了|是"

**Step 3 - rex2 反向匹配数据源：**

```vba
' 对每个字组nn，在数据源逐行正则匹配，按目录累加命中
For i = 1 To UBound(drr)
    .Pattern = nn              ' 如 "的|了|是"
    If .Test(drr(i, 1)) Then   ' 数据源A列文本
        d2(drr(i, 2)) = d2(drr(i, 2)) + 1   ' 按B列目录累加
    End If
Next

' 结果横向追加到"目录"工作表
.Cells(5, mm + 1).Resize(d2.count, 1) = Transpose(d2.items)
```

**rex2 输出后，"目录"工作表结构变为：**

```
行1:  总空:50_30    |  总空:45_25    |  总空:38_20    ...
行2:  频率:100      |  频率:95       |  频率:90       ...
行3:  合计:320      |  合计:280      |  合计:250      ...
行4:  字数:3.2      |  字数:2.9      |  字数:2.6      ...
行5:  第一章        |  5             |  3             |  2     ...
行6:  第二章        |  8             |  6             |  4     ...
行7:  第三章        |  12            |  9             |  7     ...
      A列(目录)       B列(字组1命中)    C列(字组2命中)    D列(字组3命中)
```

**每列 = 一个字组在各章节的命中次数分布**，这就是聚合的输入数据。

## 四、阶段③：数据聚合详解

### 4.1 主过程 `ProcessAndAggregateData()` 流程

```
Step1: 选数据范围 (Application.InputBox Type:=8)
Step2: dataArray = inputRange.Value           ' 读入二维数组
Step3: rowCount = UBound(dataArray,1)         ' 行数
       colCount = UBound(dataArray,2)         ' 列数
Step4: 输入MOD值 (≤255)                       ' 聚合后的列数
Step5: 输入聚合规则 "长度,间距|长度,间距"      ' 如 "20,1|50,2"
Step6: ValidateParameters()                   ' 验证参数合法性
Step7: parsedData = ParseInputStringToArray() ' 解析规则为二维数组
Step8: ReDim resultArray(1 To rowCount, 1 To modValue)  ' 初始化结果
Step9: AggregateDataWithArrays()              ' 核心聚合求和
Step10: 新建工作表，写入结果
Step11: CreateCombinedChartOnSheet()          ' 生成堆叠折线图
```

### 4.2 聚合规则格式

格式：`长度,间距|长度,间距...`

- **长度**：该规则组输出多少个聚合列
- **间距**：每个聚合列由多少个原始列求和得到
- **|**：分隔多个规则组

示例 `20,1|50,2`：
- 第一组：输出20列，每列由1个原始列直接取值（不聚合）
- 第二组：输出50列，每列由2个原始列求和
- 总消耗原始列数 = 20×1 + 50×2 = 120
- 总输出聚合列数 = 20 + 50 = 70（应等于MOD值）

### 4.3 规则解析 `ParseInputStringToArray()` 

将 `"20,1|50,2"` 解析为二维数组 `parsedData`：

```
parsedData(0,0)=20  parsedData(0,1)=1  parsedData(0,2)=20   ' 长度,间距,消耗列数
parsedData(1,0)=50  parsedData(1,1)=2  parsedData(1,2)=100  ' 长度,间距,消耗列数
```

**余数处理**（当原始列数未被规则完整覆盖时）：
- `remainingColumns = totalColumns - 已消耗列数`
- `granularity = modValue - 已分配聚合列数`
- 若能整除 → 追加一组规则
- 若有余数 → 追加两组规则分别处理整除部分和余数部分
- `dataOffset` 控制遍历上界偏移

### 4.4 核心聚合算法 `AggregateDataWithArrays()` 逐行详解

```vba
' 初始化结果数组为0
For i = 1 To rowCount
    For aggregateColumnIndex = 1 To modValue
        resultArray(i, aggregateColumnIndex) = 0
    Next
Next

' ① 遍历每一行
For i = 1 To rowCount
    aggregateColumnIndex = 0
    k = 0                                      ' k = 原始列游标

    ' ② 遍历每个规则组
    For L = 0 To UBound(parsedData) - dataOffset
        currentLength = parsedData(L, 0)       '     该组输出列数
        currentSpacing = parsedData(L, 1)      '     该组求和间距

        ' ③ 遍历该组每个聚合列
        For u = 1 To currentLength
            sumValue = 0

            ' ④ 遍历间距内的原始列求和
            For m = 1 To currentSpacing
                k = k + 1
                If k <= UBound(dataArray, 2) Then
                    If IsNumeric(dataArray(i, k)) Then
                        sumValue = sumValue + CDbl(dataArray(i, k))
                    End If
                End If
            Next m

            ' 写入聚合结果
            If aggregateColumnIndex < modValue Then
                aggregateColumnIndex = aggregateColumnIndex + 1
                resultArray(i, aggregateColumnIndex) = sumValue
            End If
        Next u
    Next L
Next i
```

**三层嵌套循环结构：**
- 外层 `For i`：遍历每一行
- 中层 `For L → For u`：遍历规则组 → 遍历该组每个输出列
- 内层 `For m`：在间距内对原始列求和

**游标 k 的作用：** 全局列游标，跨规则组连续推进。第一组消耗 k=1~20，第二组从 k=21 开始。

### 4.5 具体示例

假设：1000行×120列数据，MOD=70，规则 `20,1|50,2`

```
第一组(20,1)：k=1→20,  每列取1个原始列, 输出20列  (直接取值)
第二组(50,2)：k=21→120, 每列取2个原始列求和, 输出50列 (两两求和)

结果：1000行×70列
- 第1~20列 = 原始第1~20列（不聚合）
- 第21~70列 = 原始第21+22, 23+24, ..., 119+120（两两求和）
```

### 4.6 输出到工作表

```vba
' 新建工作表
Set newSheet = ThisWorkbook.Sheets.Add(...)
newSheet.Name = "聚合结果 MOD_ _" & modValue & "颗粒度_ _" & inputString

' 一次性写入聚合结果（B2起）
newSheet.Range("B2").Resize(rowCount, modValue).Value = resultArray

' A列复制目录
newSheet.Range("A2").Resize(rowCount, 1) = 源数据A列

' B1行复制表头
newSheet.Cells(1, 1).Value = "目录"
```

## 五、阶段④：图表生成详解

### 5.1 `CreateCombinedChartOnSheet(ws, dataRange, inputString)`

```vba
' 清除旧图表
ws.ChartObjects.Delete

' 创建图表对象（1400×900像素）
Set chartObj = ws.ChartObjects.Add(Left:=0, Top:=0, Width:=1400, Height:=900)

With chartObj.Chart
    .ChartType = xlLineStacked              ' 堆叠折线图
    .SetSourceData Source:=dataRange        ' 数据源=目录+聚合结果
    .PlotBy = xlColumns                     ' 按列绘制（每列一个数据系列）

    .HasTitle = True
    .ChartTitle.Text = "聚合数据堆叠图: " & inputString

    .Axes(xlCategory).AxisTitle.Text = "目录"   ' X轴
    .Axes(xlValue).AxisTitle.Text = "词量"      ' Y轴

    .HasLegend = True
    .Legend.Position = xlLegendPositionBottom    ' 图例在底部
End With
```

### 5.2 图表数据范围

```
dataRange = newSheet.Range(Cells(1,1), Cells(rowCount+1, modValue+1))
           = A1起 ~ (rowCount+1)行 × (modValue+1)列
           = 目录列 + modValue个聚合列
```

- **X轴**：目录（A列，章节名）
- **Y轴**：词量（聚合求和值）
- **数据系列**：modValue 个系列，每个系列一列聚合数据
- **堆叠效果**：同一X轴点上所有系列的Y值堆叠显示

## 七、优化方案

### 7.1 性能优化

| 问题 | 现状 | 优化方案 | 预期收益 |
|------|------|----------|----------|
| 结果数组初始化 | 双重循环清零 | `ReDim` 后 VBA 自动清零，可删除初始化循环 | 减少 rowCount×modValue 次循环 |
| IsNumeric 逐次判断 | 每个单元格调用 | 预扫描列类型，用布尔标志数组跳过非数值列 | 减少~50%类型检查 |
| CDbl 逐次转换 | 每次求和都转换 | 预转换整行为 Double 数组 | 减少类型转换次数 |
| ScreenUpdating | 未关闭 | 聚合前关闭，结束后恢复 | 避免写入时刷屏 |
| 图表系列过多 | 70个系列一张图 | 可选分组子图或热力图 | 提升可读性 |

### 7.2 健壮性优化

| 问题 | 现状 | 优化方案 |
|------|------|----------|
| 工作表名称冲突 | 仅 MsgBox 报错 | 自动加时间戳后缀 |
| 余数处理复杂 | dataOffset + 两种分支 | 重构为独立函数 HandleRemainder()，增加测试 |
| 越界保护 | k 和 aggregateColumnIndex 各有检查 | 统一在循环上界用 Min(理论值, 上限) |
| 错误处理 | 仅区分 1004/424 | 增加 13(类型不匹配)、9(下标越界) |
| 输入验证 | 只检查格式 | 增加语义验证：总消耗列数≤原始列数，总聚合列数=MOD |

### 7.3 功能增强

| 增强项 | 方案 |
|--------|------|
| 多种图表类型 | 增加参数选择 xlLineStacked/xlColumnStacked/xlAreaStacked |
| 聚合方式扩展 | 当前仅求和，增加平均值/最大值/最小值/计数 |
| 预览模式 | 聚合前显示前5行预览，确认后再全量执行 |
| 规则保存 | 常用规则存到配置工作表，下次直接选择 |
| 批量聚合 | 一次输入多组规则，批量生成多张聚合表+图表 |
| 导出图表 | 完成后可选导出为 PNG/EMF 图片 |

```
现状：全部逻辑在单个 .bas 文件，主过程150行
建议拆分：
├── modAggregateMain.bas      ' ProcessAndAggregateData 主流程
├── modAggregateCore.bas      ' AggregateDataWithArrays 核心算法

```

### 7.5 算法复杂度分析

```
时间复杂度: O(rowCount × Σ(长度ᵢ × 间距ᵢ))
           = O(rowCount × colCount)   ' 理想情况每列恰好访问一次
空间复杂度: O(rowCount × colCount)    ' 原始数组 + 结果数组

当 rowCount=10000, colCount=120, modValue=70 时：
- 原始数组: 10000×120 = 120万元素
- 结果数组: 10000×70 = 70万元素
- 求和操作: ~120万次（每列访问一次）
- 实际运行: <1秒（内存操作，无IO）
```

### 7.6 与TXT导入的衔接优化

| 问题 | 方案 |
|------|------|
| 聚合依赖手动选范围 | 导入后自动识别数值列范围，预填到InputBox |
| 目录列需手动确认 | 自动检测A列是否有文本（目录），B列起是否有数值 |
| 导入后不知何时聚合 | 导入完成提示"检测到N列数值数据，是否启动聚合？" |
| 两次操作割裂 | 可在导入流程末尾增加"聚合并生成图表"选项 |
