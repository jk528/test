# ColorTxt 阅读器 — 功能概述（完整版）

> 基于从 `test1.xlsm` 提取的 66 个 VBA 组件，覆盖 TXT/EPUB 读取、目录生成、正则查询、字典查询、文本上色、跳转导航、字频统计、数据聚合可视化等全部功能链。

---

## 一、系统架构总览

系统以 Excel 工作簿为载体，通过多个工作表协作实现"文本阅读器"功能。核心工作表：

| 工作表 | 角色 | 说明 |
|--------|------|------|
| 数据源 | 文本存储 | A列=全文文本（每行一条），B列=所属目录/章节 |
| 目录 | 章节索引 | A列=目录条目，后续列=各查询词的命中统计 |
| 目录2 | 查询结果 | B列=匹配词条，C列=所属目录，点击触发双筛选跳转 |
| 排序 | 分析结果 | 按查找顺序/词频/去词频三种排序展示 |
| 查询 | 交互入口 | 用户输入查询词，显示匹配结果+频率统计 |
| 重复字 | 字频分析 | 重复字统计结果输出 |
| 聚合结果 | 数据可视化 | 聚合求和后生成堆叠折线图 |

工作表分5大类管理（`SheetManager.bas`）：**开发、阅读、分析、打字、常识**，通过 `ShowCategory` 按类显示/隐藏。

## 二、核心功能链（按执行顺序）

### 2.1 文件导入 — `READ_TXTTOEXCEL.bas`

**入口：** `ComprehensiveDataImport()`

**流程：** 选文件 → 检测类型 → 选处理方式 → 选导入方式 → 执行导入 → 格式化

1. **文件选择** (`SelectMultiTypeFile`)：支持 `.xls/.xlsx/.xlsm/.xlsb/.doc/.docx/.docm/.txt`
2. **类型检测** (`DetectFileType`)：按扩展名判断 Excel/Word/TXT
3. **处理方式选择** (`SelectProcessMode`)：模式1保留部分标点 / 模式2不保留标点 / 模式3正常读取
4. **导入方式选择** (`SelectImportMethod`)：1=当前Sheet / 2=新建Sheet / 3=新建Excel / 4=指定单元格

**TXT导入核心** (`ImportTextDataToSheet`)：读取文件字节 → 检测编码 → 按编码读取 → 按模式处理文本 → 转二维数组 → 批量写入 → 格式化

**编码检测** (`DetectEncoding`)：BOM头判断（UTF-16LE/UTF-16BE/UTF-8 BOM）+ 无BOM时逐字节高位模式分析

**文本处理**：正则过滤非目标字符，以 `|` 作分隔符。模式1保留 `[\u4e00-\u9fa5a-zA-Z0-9 \u3000]`，模式2保留 `[\u4e00-\u9fa5a-zA-Z0-9]`

**导出**：`ExportToWord`、`ExportToTXT`

### 2.4 正则查询与目录生成 — `READ_正则查询替换目录.bas`

**正则查询** `正则查询优化()`：C列正则模式用 `|` 合并 → 遍历A列执行Replace和Execute → 字典统计频率 → 输出I/J/K列 → "排序"工作表三种排序

**正则替换** `正则替换优化()`：构建替换字典 → 合并文本 → 逐个替换 → 输出I列和"替换后文本"工作表

**目录生成** `正则后辅助目录优化()`：读J列 → 非空值保存为当前目录 → 空值向上继承（向下填充逻辑）→ 输出B列和"目录"工作表

### 2.13 数据聚合与可视化 — `READ_聚合生成折线堆叠图.bas` ★补充

**入口：** `ProcessAndAggregateData()`

**流程：** 选数据范围 → 输入MOD值(≤255) → 输入聚合规则(长度,间距|长度,间距) → 验证参数 → 解析规则 → 内存聚合求和 → 输出新工作表 → 生成堆叠折线图

| 函数 | 作用 |
|------|------|
| `ProcessAndAggregateData` | 主过程 |
| `AggregateDataWithArrays` | 核心聚合：三层嵌套循环（遍历行×遍历规则组×遍历间距求和） |
| `ParseInputStringToArray` | 解析"长度,间距\|长度,间距"格式，处理余数 |
| `CreateCombinedChartOnSheet` | 创建 xlLineStacked 堆叠折线图 |
| `GetPositiveInteger` / `ValidateParameters` / `ParsePartDetails` | 输入验证辅助 |

结果写入新工作表"聚合结果 MOD_X 颗粒度_Y"

### 2.14 字频统计 — `READ_字频音.bas` / `Read_最新字频.bas` / `READ_最新字频2.bas` ★补充

**通用流程：** 选Word/TXT文件 → 提取文本 → 正则过滤非中文 → 字典逐字统计 → 冒泡排序降序 → rex2正则匹配数据源 → 输出

| 文件 | 特殊功能 |

| `READ_字频音.bas` | 基础版：统计后生成拼音，输出到新工作表 |
| `Read_最新字频.bas` | 增强版：ArrayToDictWithPipe按频率聚合同字（\|连接），rex2输出到"目录"横向追加列 |
| `READ_最新字频2.bas` | 重复字版：rex2记录重复出现位置(m>1)，输出到"重复字"工作表 |

**rex2逻辑**：遍历字频结果 → 对数据源A列每行正则匹配 → 统计每个字命中次数 → 横向追加到工作表

## 三、数据流总图

```
TXT/Word/Excel/EPUB文件
       │
       ▼
  ComprehensiveDataImport  ──→  数据源工作表(A列=文本, B列=目录)
       │
       ├──→ 正则查询优化 ──→ 排序工作表(三种排序)
       │         │
       │         └──→ 正则后辅助目录优化 ──→ 目录工作表(A列=章节)
       │
       ├──→ 字典查询 ──→ 查询工作表(结果+频率) + 目录工作表(新增统计列)
       │
       ├──→ 目录跳转(InitializeCatalogJump) ──→ 数据源对应行
       │
       ├──→ 双筛选跳转(目录2点击) ──→ 数据源对应行
       │
       ├──→ 优化查询(OptimizedSearch) ──→ 目录2 + 上色
       │
       ├──→ 文本上色(Color_SS_TO_SS_22) ──→ 数据源着色 + 目录统计
       │
       ├──→ 字频统计(字频音/最新字频/重复字) ──→ 重复字工作表 / 目录横向追加
       │         │
       │         └──→ 拼音转换(pinyin) ──→ 字频+拼音输出
       │
       ├──→ 数据聚合(ProcessAndAggregateData) ──→ 聚合结果工作表 + 堆叠折线图
       │
       └──→ 数据统计(CountConsecutive/CountOccurrences/DictionarySort) ──→ C-D列
```

## 四、关键技术点

| 技术点 | 实现 |
|--------|------|
| 编码检测 | BOM头判断 + 逐字节高位模式分析 |
| 文本处理 | VBScript.RegExp 正则替换非目标字符为分隔符 |
| 批量写入 | 先组装二维数组，一次性 Range.Value = array |
| 模糊搜索 | VBA Like 运算符 ("*" & term & "*") |
| 频率统计 | Scripting.Dictionary 键值计数 |
| 多色着色 | cell.Characters(start, length).Font.Color 逐次着色 |
| 页面隔离 | xlSheetVeryHidden 隐藏非当前类页面 |
| EPUB转换 | 重命名为ZIP → WinRAR解压 → 遍历HTML提取文本 |
| 数据聚合 | 三层嵌套循环内存求和 + xlLineStacked堆叠折线图 |
| 字频分析 | 正则过滤中文 → 字典统计 → 冒泡排序 → rex2反向匹配数据源 |
| 拼音映射 | 20830字 Select Case 拆分5个子函数 |
| 鼠标滚轮 | Windows API Hook (MouseScroll) |
