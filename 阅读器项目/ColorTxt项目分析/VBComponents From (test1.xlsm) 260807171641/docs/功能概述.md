# ColorTxt 阅读器 — 功能概述

> 基于从 `test1.xlsm` 提取的 VBA 组件，分析 TXT 文件读取后目录生成、查询、上色、跳转等完整功能链。

---

## 一、系统架构总览

系统以 Excel 工作簿为载体，通过多个工作表（Sheet）协作实现"文本阅读器"功能。核心工作表：

| 工作表 | 角色 | 说明 |
|--------|------|------|
| 数据源 | 文本存储 | A列=全文文本（每行一条），B列=所属目录/章节 |
| 目录 | 章节索引 | A列=目录条目，后续列=各查询词的命中统计 |
| 目录2 | 查询结果 | B列=匹配词条，C列=所属目录，点击触发双筛选跳转 |
| 排序 | 分析结果 | 按查找顺序/词频/去词频三种排序展示 |
| 查询 | 交互入口 | 用户输入查询词，显示匹配结果+频率统计 |

工作表分5大类管理（`SheetManager.bas`）：**开发、阅读、分析、打字、常识**，通过 `ShowCategory` 按类显示/隐藏。

## 二、核心功能链（按执行顺序）

### 2.1 文件导入 — `READ_TXTTOEXCEL.bas`

**入口：** `ComprehensiveDataImport()`

**流程：**
```
选文件 → 检测类型 → 选处理方式 → 选导入方式 → 执行导入 → 格式化
```

**关键步骤：**

1. **文件选择** (`SelectMultiTypeFile`)：支持 `.xls/.xlsx/.xlsm/.xlsb/.doc/.docx/.docm/.txt`
2. **类型检测** (`DetectFileType`)：按扩展名判断 Excel/Word/TXT
3. **处理方式选择** (`SelectProcessMode`)：
   - 模式1：保留部分标点（保留空格和全角空格）
   - 模式2：不保留标点（只保留中文/英文/数字）
   - 模式3：正常读取（保留所有内容）
4. **导入方式选择** (`SelectImportMethod`)：
   - 1=当前ActiveSheet A1导入
   - 2=新建Sheet导入
   - 3=新建Excel导入
   - 4=选择指定单元格导入

**TXT导入核心** (`ImportTextDataToSheet`)：

```
读取文件字节 → 检测编码 → 按编码读取内容 → 按模式处理文本 → 转二维数组 → 批量写入单元格 → 格式化
```

**编码检测** (`DetectEncoding`)：
- 通过 BOM 头判断：UTF-16LE (FF FE)、UTF-16BE (FE FF)、UTF-8 BOM (EF BB BF)
- 无 BOM 时逐字节检查高位模式判断 UTF-8 或 ANSI

**编码读取**：
- ANSI → `Open...For Input` 逐行读取
- UTF-8 → `ADODB.Stream` + Charset="utf-8"
- Unicode → `FileSystemObject.OpenTextFile` + TristateTrue

**文本处理** (`ProcessTextWithSpaces` / `ProcessTextWithoutPunctuation`)：
- 用正则表达式过滤非目标字符，以 `|` 作为分隔符
- 模式1保留：`[\u4e00-\u9fa5a-zA-Z0-9 \u3000]`
- 模式2保留：`[\u4e00-\u9fa5a-zA-Z0-9]`

**文本转数组** (`ConvertTextTo2DArray`)：
- 模式1/2：按 `|` 分割
- 模式3：按行分割（`CustomReplaceAndSplit` 统一换行符后 Split）

**格式化** (`FormatSheet`)：
- 列宽200、字号26、自动换行、浅蓝色背景

### 2.3 初始化 — `READ_初始化.bas`

| 子过程 | 作用 |
|--------|------|
| `还原_初始化` | 清空目录/目录2/排序/数据源/查询，设置数据源表头（目录/匹配词/替换词/正则匹配/频率/出现顺序等） |
| `还原_目录__排序` | 清空目录、排序、数据源E列以后 |
| `还原_排序` | 清空排序、数据源E列以后 |

数据源表头（B1起）：`目录 | 匹配词 | 替换词/匹配② | 正则匹配 | 频率 | 出现顺序 | 频率 | XXX | 全词`

---

### 2.4 正则查询与目录生成 — `READ_正则查询替换目录.bas`

#### 2.4.1 正则查询 `正则查询优化()`

**数据位置：** C列=正则表达式，A列=待处理文本

**流程：**
1. 读取C列所有正则模式，用 `|` 合并为一个复合模式
2. 遍历A列每行文本，执行正则 `Replace`（替换为"xxx"）和 `Execute`（提取匹配）
3. 用字典统计每个匹配项的出现次数（`matchDict`）
4. 用第二个字典保留重复项的顺序（`duplicateMatchDict`，键=`内容_序号`）
5. 输出到I列（替换结果）、J列（匹配项，用`|`分隔后分列）、K列（重复项）
6. 输出到"排序"工作表：
   - A-B列：按查找顺序排序
   - D-E列：按词频降序排序
   - G列：按顺序去词频排序

#### 2.4.2 正则替换 `正则替换优化()`

**数据位置：** C列=匹配词，D列=替换词，A列=待处理文本

**流程：** 构建替换字典 → 合并所有文本为一个字符串 → 逐个正则替换 → 拆分回数组 → 输出到I列和"替换后文本"工作表

#### 2.4.3 目录生成 `正则后辅助目录优化()`

**流程：** 读取J列（正则查询的匹配结果列）→ 遇到非空值保存为当前目录 → 遇到空值用上一个有效目录填充 → 输出到B列和"目录"工作表A5起

**核心逻辑：** 向下填充目录——第一个有效目录会被后续空行继承，直到遇到下一个非空值。

---

### 2.5 目录跳转 — `D_CatalogJump.bas`

**入口：** `InitializeCatalogJump()`

**流程：**
1. `GetCatalogItems()`：读取"目录"工作表A5起的目录条目，在"数据源"A列逐个匹配（不区分大小写）
2. `ProcessCatalogResult()`：
   - **1个匹配** → 激活数据源并选中对应行
   - **多个匹配** → 存入全局变量 `g_catalogArray`，弹出 `UserForm4` 供用户选择

---

### 2.6 双筛选跳转 — `Sheet8.txt`

**入口：** 目录2工作表的 `Worksheet_SelectionChange` 事件（点击B列单元格触发）

**流程：**
1. `DoubleFilterSearch(selectedCell)`：
   - 第一次筛选：数据源B列（目录）必须等于选中单元格右侧C列的目录值
   - 第二次筛选：数据源A列文本 `Like` 模糊包含选中单元格B列的词条
2. `ProcessDoubleFilterResult(matchArray)`：
   - **1个匹配** → 跳转到数据源对应行
   - **多个匹配** → 存入 `g_matchArray`，弹出 `UserForm3`

**与目录跳转的区别：** 目录跳转是单条件精确匹配；双筛选是"目录相等 + 词条包含"双重条件。

---

### 2.7 优化查询 — `Sheet6.txt`

**函数：** `OptimizedSearch(ParamArray args())`

**两种调用模式：**
- **单参数** `OptimizedSearch(CT)`：纯词条模糊搜索（`Like "*" & CT & "*"`）
- **双参数** `OptimizedSearch(ML, CT)`：先按目录ML过滤，再按词条CT模糊搜索

**结果处理：** 写入"目录2"工作表 → 调用 `ColorizeMatches` 为匹配文本上色

**上色逻辑** (`ColorizeMatches`)：定义4色数组（红/绿/蓝/青），逐个单元格查找匹配位置，按出现次序循环着色。

---

### 2.8 字典查询 — `READ_字典查询.bas`

**入口：** `字典查询()`（查询工作表B3单元格输入查询词）

**流程：**
1. `ExecuteSearch(searchTerm)`：遍历数据源A列，`Like` 模糊匹配，收集结果到Collection，同时用字典统计B列（目录）频率
2. 结果输出到查询工作表A6起（全文+目录），C6起（目录+频率）
3. `UpdateBackendData()`：在"目录"工作表新增一列，填入各目录的命中次数，首行=总结果数，次行=查询词
4. 新建以查询词命名的工作表，写入结果并排序

**批量查询** `批量词条查询()`：用户选择单元格范围，逐个调用 `字典查询2` 执行查询并更新后台数据。

---

### 2.9 文本上色 — `READ_上色.bas`

| 子过程 | 功能 |
|--------|------|
| `Color_ONE_TO_SS` | 单个固定词在选区内查找，多次出现循环4色着色 |
| `Color_SS_TO_SS` | 多词数组在选区内查找，每个单元格独立处理 |
| `Color_SS_TO_SS_2` | 用户选词，在数据源全列查找，首次命中着红色，统计命中所在目录数 |
| `Color_SS_TO_SS_22` | 增强版：同一单元格内多次命中循环4色着色，统计目录命中 |

**着色方案：** 第1次红色、第2次绿色、第3次蓝色、第4次及以后青色

**目录统计逻辑：** 上色时同步用字典记录命中行对应的B列目录值，完成后在"目录"工作表新增一列显示各目录命中次数。

---

### 2.10 页面管理 — `SheetManager.bas`

**分类体系：**

| 分类 | 包含页面 |
|------|----------|
| 开发 | 首页、通知、变量管理器、版本、测试、开发者工具 |
| 阅读 | 数据源、查询、排序、目录、重复字、目录2 |
| 分析 | 排序、目录、对应目录详细、词频、重复字、标红 |
| 打字 | 打字页面、打字数据库、码字数据统计 |
| 常识 | 五行、正则、图例 |

**核心操作：**
- `ShowCategory(category)`：显示该类页面，隐藏其他页面（`xlSheetVeryHidden`）
- `InitializeCategory(category)`：创建/清空并初始化该类所有页面
- `InitializeSheet(ws)`：按页面名设置标题、表头、按钮、冻结窗格等

---

### 2.11 工作簿事件 — `ThisWorkbook.txt`

**启动时** (`Workbook_Open`)：
1. 到期检测（2036-10-01），过期则解除隐藏属性并删除文件
2. 调用 `ShowReadingCategory` 显示阅读类页面
3. 绑定快捷键：`Ctrl+A`=查找、`Ctrl+D`=下查、`Ctrl+S`=上查、`Ctrl+Z`=返回
4. 选中"数据源"工作表

**窗口激活/停用时**：重新绑定/解绑快捷键

---

### 2.12 目录导航窗体 — `目录.frm`

- **搜索框**：输入Sheet名片段，模糊匹配所有工作表名
- **列表框**：列出匹配结果，点击激活对应工作表
- **初始化**：调用 `ShowAllPages` 显示全部页面，启用鼠标滚轮滚动

## 三、数据流总图

```
TXT/Word/Excel文件
       │
       ▼
  ComprehensiveDataImport  ──→  数据源工作表(A列=文本, B列=目录)
       │
       ├──→ 正则查询优化 ──→ 排序工作表(三种排序)
       │         │
       │         └──→ 正则后辅助目录优化 ──→ 目录工作表(A列=章节)
       │
       ├──→ 字典查询 ──→ 查询工作表(结果+频率) + 目录工作表(新增统计列)
       │
       ├──→ 目录跳转(InitializeCatalogJump) ──→ 数据源对应行
       │
       ├──→ 双筛选跳转(目录2点击) ──→ 数据源对应行
       │
       ├──→ 优化查询(OptimizedSearch) ──→ 目录2 + 上色
       │
       └──→ 文本上色(Color_SS_TO_SS_22) ──→ 数据源着色 + 目录统计
```

## 四、关键技术点

| 技术点 | 实现 |
|--------|------|
| 编码检测 | BOM头判断 + 逐字节高位模式分析 |
| 文本处理 | VBScript.RegExp 正则替换非目标字符为分隔符 |
| 批量写入 | 先组装二维数组，一次性 `Range.Value = array` |
| 模糊搜索 | VBA `Like` 运算符 (`"*" & term & "*"`) |
| 频率统计 | `Scripting.Dictionary` 键值计数 |
| 多色着色 | `cell.Characters(start, length).Font.Color` 逐次着色 |
| 页面隔离 | `xlSheetVeryHidden` 隐藏非当前类页面 |
| EPUB转换 | 重命名为ZIP → WinRAR解压 → 遍历HTML提取文本 |
