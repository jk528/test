# 聚合可控分析 — VBA 全流程自动化工具

## 概述

本工具将 ColorTxt 项目的聚合分析全链重构为 **6 个阶段化 VBA 模块**，实现一键自动化完成：TXT 导入 → 章节分割 → 字频统计 → 可控聚合 → 堆叠折线图。

编码检测逻辑参考 `splittxt3`（三段采样 + BOM 优先 + UTF-8 多字节序列验证）。

---

## 模块结构

```
聚合可控分析/
├── modEncoding.bas    Phase 0: TXT 编码自动检测与读取
├── modImport.bas      Phase 1: TXT 导入与数据源工作表构建
├── modChapter.bas     Phase 2: 章节分割与正则识别
├── modFreqStats.bas   Phase 3: 字频统计（rex2 核心）
├── modAggregate.bas   Phase 4: 可控聚合
├── modChart.bas       Phase 5: 堆叠折线图生成
├── modMain.bas        主控模块：一键入口 + 分步入口
└── 使用说明.md        本文件
```

## 使用方法

### 方式一：一键聚合分析（推荐）

1. 打开 Excel/WPS 的 VBA 编辑器（Alt+F11）
2. 将 7 个 `.bas` 模块逐一导入（文件→导入文件）
3. 运行宏 `一键聚合分析`
4. 按提示依次：
   - 选择 TXT 文件
   - 输入字符组（或使用默认 8 组高频虚词）
   - 输入聚合规则（或使用默认 `20,1|50,2`）
   - 输入图表标题
   - 确认执行
5. 自动完成全流程，查看"聚合结果"工作表和图表

### 方式二：快速聚合分析

运行宏 `快速聚合分析`，仅选择文件，其余使用默认参数。

### 方式三：分步执行（调试用）

| 宏名 | 功能 |
|------|------|
| `步骤1_导入TXT` | Phase 0+1: 编码检测 + TXT 导入 |
| `步骤2_章节分割` | Phase 2: 多正则章节识别 |
| `步骤3_字频统计` | Phase 3: 字符组命中统计 |
| `步骤4_可控聚合` | Phase 4: 按规则聚合列 |
| `步骤5_生成图表` | Phase 5: 堆叠折线图 |

### 方式四：仅生成图表

若已手动调整"聚合结果"工作表，运行 `仅生成图表` 直接从数据生成图表。

## 参数说明

### 字符组格式

用**逗号**分隔不同组，**竖线**分隔组内字符：

```
的, 了|着|过, 是|为, 在|有, 不|没, 我|你|他, 这|那, 一|二|三
```

- 第1组 `的` → 统计"的"在各章出现次数
- 第2组 `了|着|过` → 统计"了""着""过"命中次数之和
- 以此类推

### 聚合规则格式

`长度,间距|长度,间距|...`

| 规则 | 含义 |
|------|------|
| `20,1` | 前 20 列每列独立（间距 1） |
| `50,2` | 接下来 50 列每 2 列合并为 1 列 |
| `20,1\|50,2` | 先 20 列独立，再 50 列按 2 合并 |
| `10,1\|20,2\|30,5` | 三段式：独立→两两合并→五五合并 |
| `0,1` | 全部独立（不聚合） |

**规则示例**：8 个字符组，规则 `4,1|4,2`
- 第 1~4 列：每列独立 → 输出 4 列
- 第 5~8 列：每 2 列合并 → 输出 2 列
- 总输出：6 列

## 工作表说明

| 工作表 | 用途 | 结构 |
|--------|------|------|
| 数据源 | 存储导入的 TXT 全文 | A列=文本行, B列=目录标记, C列=正则标记 |
| 目录 | 章节列表 + 字频矩阵 | A列=章节标题, B列=章号, C列起=各字符组命中数 |
| 聚合结果 | 聚合后的数据 | A列=章节标题, B列起=聚合后各列 |

## 编码检测支持

| 编码 | 检测方式 | 说明 |
|------|----------|------|
| UTF-8 BOM | BOM 标记 (EF BB BF) | 最可靠 |
| UTF-16LE | BOM 标记 (FF FE) | Windows 常见 |
| UTF-16BE | BOM 标记 (FE FF) | 较少见 |
| UTF-8 无BOM | 三段采样 + 多字节序列验证 | 检测率 ~95% |
| ANSI/GBK | 排除法（非 UTF-8 则判定） | 中文系统默认 |

## 优化要点

1. **编码检测**：三段采样（头/中/尾各 100 字节），避免局部误判
2. **批量写入**：数组→Range 一次性赋值，替代逐行 Cells，性能提升 100x+
3. **预编译正则**：章节扫描和字频统计前统一创建 RegExp 对象，避免循环内重复创建
4. **倍增扩容**：章节数组初始 2048，不够时翻倍，万章级只需扩容 3 次
5. **中文数字**：支持"三百一十"→310、"一万二千"→12000 等全格式转换
6. **聚合边界保护**：规则段长度超过剩余列时自动截断，不会越界
7. **图表渐变色**：HSL 色相均匀分布，避免默认颜色重复

## 与原 ColorTxt 项目的对比

| 维度 | 原 ColorTxt | 本工具 |
|------|-------------|--------|
| 触发方式 | 手动逐步执行各宏 | 一键自动化 |

| 错误处理 | 静默跳过 | 每步检查 + 明确提示 |
| 代码组织 | 66 个 VBA 组件混合 | 6 个阶段化模块清晰分层 |

## 注意事项

1. **导入顺序**：7 个模块无依赖顺序，可任意顺序导入
2. **工作表覆盖**：每次执行会清空"数据源""目录""聚合结果"工作表
3. **大文件**：10 万行以上 TXT 建议先用 `步骤1_导入TXT` 测试编码检测
4. **正则扩展**：在 `modChapter.bas` 的 `GetDefaultPatterns` 中添加新正则
5. **字符组扩展**：在 `modFreqStats.bas` 的 `GetDefaultCharGroups` 中修改默认组
