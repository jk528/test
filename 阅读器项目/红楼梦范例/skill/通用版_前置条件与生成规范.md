# 小说双轨六要素分析报告 — 通用前置条件与生成规范

> **文档用途**：适用于任意小说（中文/英文/其他语言）的逐章双轨六要素分析。所有路径、阈值、规则均为参数化变量，修改§0.1参数表 + §0.2小说画像即可切换分析目标。
>
> **版本绑定**：归档规范 v1.3 = 分析流程 v2.0 = 空白模板 V3.4

---

### 0.3 情感分类体系配置

> 核心设计：JSON 字段名采用 `{TAXONOMY}_{LABEL}` 统一命名规则，下游报告生成逻辑只需替换前缀和标签列表即可适配任意分类体系。

#### 预定义分类体系

| 体系代号 | 适用语言 | 类别数 | 类别列表 | 正面 | 负面 | 中性 | 极性来源 |
|---------|---------|--------|---------|------|------|------|---------|
| `DUTIR-7` | 中文 | 7 | 好/乐/哀/怒/惧/恶/惊 | 好,乐 | 哀,怒,惧,恶 | 惊 | Hownet |
| `VADER-3` | 英文 | 3 | positive/negative/neutral | positive | negative | neutral | VADER compound |
| `Plutchik-8` | 通用 | 8 | joy/trust/fear/surprise/sadness/disgust/anger/anticipation | joy,trust | fear,sadness,disgust,anger | surprise,anticipation | NRC |
| `NRC-8` | 通用 | 8 | joy/trust/fear/surprise/sadness/disgust/anger/anticipation | 同Plutchik | 同Plutchik | 同Plutchik | NRC lexicon |
| `custom` | 任意 | 自定义 | 用户定义 | 用户定义 | 用户定义 | 用户定义 | 用户定义 |

#### 各体系 JSON 字段命名规则

| 体系 | 情绪字段格式 | 正面合计 | 负面合计 | 极性字段 |
|------|------------|---------|---------|---------|
| `DUTIR-7` | `dutir_好.count` / `dutir_好.pct` / `dutir_好.words` | `dutir_pos` | `dutir_neg` | `hownet_pos_pct` / `hownet_neg_pct` |
| `VADER-3` | `vader_positive.count` / `vader_positive.pct` / `vader_positive.words` | `vader_pos` (=`vader_positive.count`) | `vader_neg` (=`vader_negative.count`) | `vader_compound` |
| `Plutchik-8` | `plutchik_joy.count` / `plutchik_joy.pct` / `plutchik_joy.words` | `plutchik_pos` (joy+trust) | `plutchik_neg` (fear+sadness+disgust+anger) | `nrc_pos_pct` / `nrc_neg_pct` |
| `custom` | `{TAXONOMY}_{label}.count` / `.pct` / `.words` | `{TAXONOMY}_pos` | `{TAXONOMY}_neg` | 自定义 |

```python
class EmotionDictAdapter:
    """通用情感词典适配器接口，各体系实现以下方法"""

    def __init__(self, dict_dir: str, **kwargs):
        """加载词典"""

    def analyze_words(self, words: list) -> dict:
        """
        返回:
        {
            "emotion_counts": {label: count, ...},     # 各类别词数
            "emotion_words": {label: [word, ...], ...}, # 各类别匹配词
            "total_emotion_words": int,                  # 总情感词数
            "positive_emotion_count": int,               # 正面合计
            "negative_emotion_count": int,               # 负面合计
            "neutral_emotion_count": int,                # 中性合计
            "pos_count": int, "neg_count": int,          # 极性词典
            "pos_percentage": float, "neg_percentage": float,
            "pos_words": [str], "neg_words": [str],
            "total_sentiment_words": int,
        }
        """

# ---- 已有实现 ----
# dutir_hownet: emotion_analysis.py 中的 EmotionAnalyzer + SentimentAnalyzer

# ---- 需用户自行实现的适配器 ----
# vader_adapter.py:
class VADERAdapter(EmotionDictAdapter):
    def __init__(self, dict_dir, **kwargs):
        from vaderSentiment.vaderSentiment import SentimentIntensityAnalyzer
        self.analyzer = SentimentIntensityAnalyzer()

    def analyze_words(self, words):
        pos_words, neg_words, neu_words = [], [], []
        for w in words:
            score = self.analyzer.polarity_scores(w)['compound']
            if score >= 0.05: pos_words.append(w)
            elif score <= -0.05: neg_words.append(w)
            else: neu_words.append(w)
        total = len(pos_words) + len(neg_words) + len(neu_words)
        return {
            "emotion_counts": {"positive": len(pos_words), "negative": len(neg_words), "neutral": len(neu_words)},
            "emotion_words": {"positive": pos_words[:30], "negative": neg_words[:30], "neutral": neu_words[:30]},
            "total_emotion_words": total,
            "positive_emotion_count": len(pos_words),
            "negative_emotion_count": len(neg_words),
            "neutral_emotion_count": len(neu_words),
            "pos_count": len(pos_words), "neg_count": len(neg_words),
            "pos_percentage": round(len(pos_words)/total*100, 1) if total else 0,
            "neg_percentage": round(len(neg_words)/total*100, 1) if total else 0,
            "pos_words": pos_words[:30], "neg_words": neg_words[:30],
            "total_sentiment_words": total,
        }
```

### 0.5 依赖检查清单

| 检查项 | 路径 | 通过条件 | 不满足时处理 |
|--------|------|---------|-------------|
| 原文拆分目录 | `{SPLIT_DIR}` | 存在且含 txt 文件 | 先拆分原文（见§0.6） |
| 情绪分析结果 | `{EMOTION_DIR}` | 存在且含 emotion.json | 先生成（见§0.7-0.8） |
| 情绪分析脚本 | `{EMOTION_SCRIPT}` | 文件存在 | 从基础库复制 |
| 情感词典 | `{DICT_DIR}` | 根据`{DICT_ADAPTER}`检查对应词典 | 见§0.3适配器说明 |
| 停用词 | `{STOPWORDS_FILE}` | 文件存在 | 从基础库复制 |
| 输出目录 | `{OUTPUT_DIR}` | 存在（不存在则创建） | `New-Item -ItemType Directory` |

### 0.6 原文拆分流程

1. **识别章节标记**：使用 `{CHAPTER_REGEX}` 正则匹配
2. **拆分输出**：每章一个 txt，文件名 `{章号三位}_{字数}_{标题}.txt`
3. **字数统计**：正文字数（不含标题行和末行标记）
4. **首行**：章节标题
5. **段落格式**：每段以 `{PARA_INDENT}` 开头
6. **末行**：`{CHAPTER_END}`

### 0.7 分词流程

根据 `{TOKENIZER}` 选择分词引擎：

```python
import os, json

SPLIT_DIR = r"{SPLIT_DIR}"
TOKENIZED_DIR = r"{TOKENIZED_DIR}"
TOKENIZER = "{TOKENIZER}"
SEG_DICT_FILE = r"{SEG_DICT_FILE}"

os.makedirs(TOKENIZED_DIR, exist_ok=True)

if TOKENIZER == "jieba":
    import jieba
    if os.path.exists(SEG_DICT_FILE): jieba.load_userdict(SEG_DICT_FILE)
    tokenize = lambda text: list(jieba.cut(text, cut_all=False))
elif TOKENIZER == "pkuseg":
    import pkuseg
    seg = pkuseg.pkuseg(user_dict=SEG_DICT_FILE if os.path.exists(SEG_DICT_FILE) else None)
    tokenize = lambda text: seg.cut(text)
elif TOKENIZER == "空格分隔":
    import re
    tokenize = lambda text: [w.strip(".,!?;:\"'()[]{}") for w in re.split(r'\s+', text) if w.strip()]
else:
    raise ValueError(f"不支持的TOKENIZER: {TOKENIZER}")

for fname in sorted(os.listdir(SPLIT_DIR)):
    if not fname.endswith('.txt'): continue
    chapter_num = fname[:3]
    with open(os.path.join(SPLIT_DIR, fname), 'r', encoding='utf-8') as f:
        text = f.read()
    words = tokenize(text)
    with open(os.path.join(TOKENIZED_DIR, f"{chapter_num}.json"), 'w', encoding='utf-8') as f:
        json.dump(words, f, ensure_ascii=False)
```

**分词JSON格式**：JSON数组，元素为词字符串。emotion_analysis.py 兼容纯字符串数组 / `{word:xxx}`对象数组 / `{words:[...]}`对象。

### 0.8 情绪JSON生成流程

```python
import os, json, sys
from collections import Counter

# ============ 配置（从小说画像注入） ============
TOKENIZED_DIR = r"{TOKENIZED_DIR}"
EMOTION_DIR = r"{EMOTION_DIR}"
DICT_DIR = r"{DICT_DIR}"
TAXONOMY = "{EMOTION_TAXONOMY}"           # 如 dutir / vader / plutchik
LABELS = "{EMOTION_LABELS}".split(',')     # 如 ['好','乐',...]
POS_LABELS = "{POSITIVE_EMOTIONS}".split(',')
NEG_LABELS = "{NEGATIVE_EMOTIONS}".split(',')
NEU_LABELS = "{NEUTRAL_EMOTIONS}".split(',')
ADAPTER = "{DICT_ADAPTER}"                 # dutir_hownet / vader / nrc / custom
POS_FIELD = "{POS_FIELD}"                  # 如 hownet_pos_pct / vader_compound
NEG_FIELD = "{NEG_FIELD}"

# ============ 加载适配器 ============
sys.path.insert(0, DICT_DIR)

if ADAPTER == "dutir_hownet":
    from emotion_analysis import EmotionAnalyzer, SentimentAnalyzer
    ea = EmotionAnalyzer(dict_dir=os.path.join(DICT_DIR, "情感词典_DUTIR"))
    sa = SentimentAnalyzer(
        dict_dir=os.path.join(DICT_DIR, "情感词典_Hownet"),
        negation_file=os.path.join(DICT_DIR, "否定词.txt"),
        degree_file=os.path.join(DICT_DIR, "递进词.txt"))
    adapter = ea  # EmotionAnalyzer.analyze_words 返回统一结构
    polarity = sa
elif ADAPTER == "vader":
    from vader_adapter import VADERAdapter
    adapter = VADERAdapter(dict_dir=DICT_DIR)
    polarity = adapter  # VADER 本身包含极性
elif ADAPTER == "nrc":
    from nrc_adapter import NRCAdapter
    adapter = NRCAdapter(dict_dir=DICT_DIR)
    polarity = adapter
else:
    raise ValueError(f"不支持的适配器: {ADAPTER}")

# ============ 停用词 ============
stopwords = set()
sw_file = os.path.join(DICT_DIR, "停用词.txt")
if os.path.exists(sw_file):
    with open(sw_file, 'r', encoding='utf-8') as f:
        stopwords = set(l.strip() for l in f if l.strip())
sw_dir = os.path.join(DICT_DIR, "停用词库")
if os.path.isdir(sw_dir):
    for swf in os.listdir(sw_dir):
        with open(os.path.join(sw_dir, swf), 'r', encoding='utf-8') as f:
            stopwords.update(l.strip() for l in f if l.strip())

# ============ 逐章分析 ============
os.makedirs(EMOTION_DIR, exist_ok=True)
TAX_PREFIX = TAXONOMY.lower().split('-')[0]  # dutir / vader / plutchik

for fname in sorted(os.listdir(TOKENIZED_DIR)):
    if not fname.endswith('.json') or 'emotion' in fname: continue
    chapter_num = fname[:3]
    with open(os.path.join(TOKENIZED_DIR, fname), 'r', encoding='utf-8') as f:
        data = json.load(f)
    words = [w for w in data if w and w not in stopwords] if isinstance(data, list) else \
            [item['word'] if isinstance(item, dict) else item for item in data]

    result = adapter.analyze_words(words)
    word_counts = Counter(w for w in words if w)
    total = result['total_emotion_words']

    output = {"chapter": chapter_num}
    for label in LABELS:
        cnt = result['emotion_counts'].get(label, 0)
        output[f"{TAX_PREFIX}_{label}"] = {
            "count": cnt,
            "pct": round(cnt / total * 100, 1) if total else 0,
            "words": str(result['emotion_words'].get(label, [])[:15])[1:-1]
        }
    output[f"{TAX_PREFIX}_total"] = total
    output[f"{TAX_PREFIX}_pos"] = result['positive_emotion_count']
    output[f"{TAX_PREFIX}_neg"] = result['negative_emotion_count']
    output[f"{TAX_PREFIX}_neu"] = result['neutral_emotion_count']

    # 极性词典数据
    sent_result = polarity.analyze_words(words) if polarity is not adapter else result
    output[POS_FIELD] = sent_result.get('pos_percentage', sent_result.get('pos_percentage', 0))
    output[NEG_FIELD] = sent_result.get('neg_percentage', sent_result.get('neg_percentage', 0))
    output["top_words"] = [{"word": w, "count": c} for w, c in word_counts.most_common(30)]

    with open(os.path.join(EMOTION_DIR, f"{chapter_num}_emotion.json"), 'w', encoding='utf-8') as f:
        json.dump(output, f, ensure_ascii=False, indent=2)
```

### 0.10 emotion_analysis.py 模块说明

| 类名 | 功能 | 输入 | 输出 |
|------|------|------|------|
| `EmotionAnalyzer` | DUTIR 7大类情绪统计 | 词列表 / JSON分词文件 | emotion_counts(7类词数)、emotion_words(匹配词)、emotion_percentages(占比) |
| `SentimentAnalyzer` | Hownet 正负极性统计（含否定翻转+程度加权） | 词列表 / JSON分词文件 | pos_count/neg_count/pos_percentage/neg_percentage/sentiment_score |
| `dual_track_analysis()` | 双轨整合分析 | JSON分词文件路径 | sentiment + emotion 综合结果 |

**否定翻转机制**：滑动窗口=5词，奇数次否定翻转，程度副词加权（extreme=2.5x, very=2.0x, more=1.5x, ish=0.75x）

**词典规模**：DUTIR 7大类27,414词；Hownet pos+neg 19,472词

#### JSON 字段映射表

> 字段名中 `{TAX}` = `{EMOTION_TAXONOMY}` 小写前缀（如 `dutir`/`vader`/`plutchik`），`{label}` = `{EMOTION_LABELS}` 中的各类别。

| JSON 字段 | 类型 | 说明 | 报告映射 |
|-----------|------|------|---------|
| `chapter` | string | 章号 | §1.2 |
| `{TAX}_{label}.count` | int | 各类词数 | §5.7.1 词数列 |
| `{TAX}_{label}.pct` | float | 各类占比(%) | §5.7.1 占比列（精确X.X%） |
| `{TAX}_{label}.words` | string | 代表词汇 | §5.7.1 词汇列（取前5） |

| `{TAX}_pos` | int | 正面合计({POSITIVE_EMOTIONS}之和) | §5.1 正面行 |
| `{TAX}_neg` | int | 负面合计({NEGATIVE_EMOTIONS}之和) | §5.1 负面行 |
| `{TAX}_neu` | int | 中性合计({NEUTRAL_EMOTIONS}之和) | §5.1 中性行 |
| `{POS_FIELD}` | float | 极性正面(%) | §5.7.3 + §8.2 |
| `{NEG_FIELD}` | float | 极性负面(%) | §5.7.3 + §8.2 |
| `top_words` | array | 高频词`[{word,count}]` | §5.5 TOP10 |

> DUTIR-7 示例：`{TAX}`=dutir, `{label}`=好/乐/哀/怒/惧/恶/惊, `{POS_FIELD}`=hownet_pos_pct
> VADER-3 示例：`{TAX}`=vader, `{label}`=positive/negative/neutral, `{POS_FIELD}`=vader_compound

#### 数据换算公式

| 报告字段 | 公式 | 格式 |
|---------|------|------|
| §5.1 正面占比 | `round({TAX}_pos/{TAX}_total*100)` | `~整数%` |
| §5.1 负面占比 | `round({TAX}_neg/{TAX}_total*100)` | `~整数%` |
| §5.1 中性占比 | `round({TAX}_neu/{TAX}_total*100)` | `~整数%` |
| §5.7.2 正面词数 | `{POSITIVE_EMOTIONS}` 各`.count`之和 | 整数 |
| §5.7.2 负面词数 | `{NEGATIVE_EMOTIONS}` 各`.count`之和 | 整数 |
| §5.7.2 正负比 | `正面/负面` | 保留2位小数 |
| §5.7.2 主导情绪 | 词数最多类别 | `情绪字(占比%)` 半角括号1位小数 |
| §5.7.2 丰富度 | `有词类别数/{EMOTION_LABELS}总数` | `N/{N}` |
| §5.7.3 正面·极性 | `{POS_FIELD}` | `X.X%` |
| §5.7.3 正面·情绪 | `round({TAX}_pos/{TAX}_total*100,1)` | `X.X%` |

### 2.3 words 字段处理

JSON words 为 Python repr 字符串（如 `"'词1', '词2', '词3'"`），处理：去引号 → 逗号分隔 → 取前5 → 中文逗号连接。

### §五 情感词三维统计

#### §5.1 情感词分布总览

正面=`{TAX}_pos`（`{POSITIVE_EMOTIONS}`之和），负面=`{TAX}_neg`（`{NEGATIVE_EMOTIONS}`之和），中性=`{TAX}_neu`（`{NEUTRAL_EMOTIONS}`之和），合计=`{TAX}_total`。占比 `~整数%`。代表词汇取 words 前5。

#### §5.2 情感基调判定

正面>40% → 正面主导；负面>40% → 负面主导；中性>60% → 中性主导

#### §5.3 情感趋势

按段落区间拆解3-6段情感曲线

#### §5.4 与前章对比

第N章列"第N-1章（基准）+第N章"，占比用 `~整数%`。第1章用"—"占位。第N-1章数据从上一章 emotion.json 取。

#### §5.5 高频词汇TOP10

取 `top_words` 前10条。人名标"中性（人名）"。

#### §5.6 情感词处理记录

否定翻转/递进加权/一词多义/虚词排除均填"—"说明

#### §5.7 各类情绪分布（{EMOTION_TAXONOMY}）

**§5.7.1** 各类别×(count/pct/words)，占比精确 `X.X%`（不加~）

**§5.7.2** 正面=`{POSITIVE_EMOTIONS}`之和，负面=`{NEGATIVE_EMOTIONS}`之和，中性=`{NEUTRAL_EMOTIONS}`之和；正负比保留2位小数；主导情绪 `情绪字(占比%)`；丰富度=`有词类别数/{LABELS_COUNT}`

**§5.7.3** 极性(`{POS_FIELD}`/`{NEG_FIELD}`) vs 情绪(`{TAX}_pos%`/`{TAX}_neg%`)，差异≤15%一致，≤25%基本一致

```python
import re, os

def split_novel(novel_path, split_dir, chapter_regex, para_indent="　　", chapter_end="(本章完)"):
    """将整本小说txt按章拆分为独立文件"""
    with open(novel_path, 'r', encoding='utf-8') as f:
        text = f.read()

    # 匹配所有章节标题
    pattern = re.compile(chapter_regex)
    matches = list(pattern.finditer(text))

    os.makedirs(split_dir, exist_ok=True)

    for i, match in enumerate(matches):
        ch_num = i + 1
        start = match.start()
        end = matches[i + 1].start() if i + 1 < len(matches) else len(text)

        # 提取标题行
        line_end = text.index('\n', start) if '\n' in text[start:end] else end
        title_line = text[start:line_end].strip()

        # 提取正文
        body = text[line_end:end].strip()
        # 统计字数（去除空白和标记）
        word_count = len(re.sub(r'\s+', '', body))

        # 写入文件
        filename = f"{ch_num:03d}_{word_count}_{title_line}.txt"
        filepath = os.path.join(split_dir, filename)

        with open(filepath, 'w', encoding='utf-8') as f:
            f.write(title_line + '\n')
            # 每段加缩进
            for para in body.split('\n'):
                para = para.strip()
                if para:
                    f.write(f"{para_indent}{para}\n")
            f.write(f"{chapter_end}\n")

        print(f"拆分: 第{ch_num}章 {title_line} ({word_count}字)")

# 使用
split_novel(
    novel_path=r"c:\Users\xxx\三国演义.txt",
    split_dir=SPLIT_DIR,
    chapter_regex=CHAPTER_REGEX
)
```

```python
from collections import Counter

sys.path.insert(0, DICT_DIR)
from emotion_analysis import EmotionAnalyzer, SentimentAnalyzer

os.makedirs(EMOTION_DIR, exist_ok=True)
ea = EmotionAnalyzer(dict_dir=os.path.join(DICT_DIR, "情感词典_DUTIR"))
sa = SentimentAnalyzer(
    dict_dir=os.path.join(DICT_DIR, "情感词典_Hownet"),
    negation_file=os.path.join(DICT_DIR, "否定词.txt"),
    degree_file=os.path.join(DICT_DIR, "递进词.txt"))

# 停用词
stopwords = set()
with open(os.path.join(DICT_DIR, "停用词.txt"), 'r', encoding='utf-8') as f:
    stopwords = set(l.strip() for l in f if l.strip())

for fname in sorted(os.listdir(TOKENIZED_DIR)):
    if not fname.endswith('.json') or 'emotion' in fname: continue
    ch_num = fname[:3]
    with open(os.path.join(TOKENIZED_DIR, fname), 'r', encoding='utf-8') as f:
        words = [w for w in json.load(f) if w and w not in stopwords]

    emo = ea.analyze_words(words)
    sent = sa.analyze_words(words)
    wc = Counter(w for w in words if w)
    total = emo['total_emotion_words']

    output = {"chapter": ch_num}
    for e in ['好','乐','哀','怒','惧','恶','惊']:
        c = emo['emotion_counts'].get(e, 0)
        output[f"dutir_{e}"] = {"count": c, "pct": round(c/total*100,1) if total else 0,
                                "words": str(emo['emotion_words'].get(e,[])[:15])[1:-1]}
    output.update({
        "dutir_total": total, "dutir_pos": emo['positive_emotion_count'],
        "dutir_neg": emo['negative_emotion_count'], "dutir_neu": emo['neutral_emotion_count'],
        "hownet_pos": sent['pos_count'], "hownet_neg": sent['neg_count'],
        "hownet_pos_pct": sent['pos_percentage'], "hownet_neg_pct": sent['neg_percentage'],
        "hownet_total": sent['total_sentiment_words'],
        "top_words": [{"word": w, "count": c} for w, c in wc.most_common(30)]})

    with open(os.path.join(EMOTION_DIR, f"{ch_num}_emotion.json"), 'w', encoding='utf-8') as f:
        json.dump(output, f, ensure_ascii=False, indent=2)
    print(f"情绪: {ch_num}")
```

```python
import re, os, json

def tokenize_english(text):
    """英文分词：按空格+标点切分"""
    words = []
    for token in re.split(r'\s+', text):
        # 去除标点但保留词
        word = token.strip(".,!?;:\"'()[]{}""''")
        if word:
            words.append(word)
    return words

for fname in sorted(os.listdir(SPLIT_DIR)):
```

### 报告完整性校验

```python
import os, re, json

def validate_report(report_path, emotion_path, event_density=500):
    """校验单份报告是否达标"""
    issues = []

    with open(report_path, 'r', encoding='utf-8') as f:
        report = f.read()

    # 检查九大模块是否齐全
    sections = ['§一', '§二', '§三', '§四', '§五', '§六', '§七', '§八', '§九']
    for s in sections:
        if s not in report:
            issues.append(f"缺失模块 {s}")

    # 检查事件数量
    star_count = report.count('★')
    diamond_count = report.count('◆')
    if star_count < 5:
        issues.append(f"★核心事件不足: {star_count}件 (需≥5)")
    if diamond_count < 4:
        issues.append(f"◆关键事件不足: {diamond_count}件 (需≥4)")

    # 检查情感数据与JSON一致性
    with open(emotion_path, 'r', encoding='utf-8') as f:
        emo = json.load(f)

    dutir_total_in_json = emo['dutir_total']
    if str(dutir_total_in_json) not in report:
        issues.append(f"dutir_total({dutir_total_in_json})未在报告中出现")

    # 检查约数/精确格式
    # §5.1应为约数 ~整数%
    if '~' not in report:
        issues.append("§5.1缺少约数格式 ~整数%")

    # §5.7应为精确 X.X%
    if not re.search(r'\d+\.\d%', report):
        issues.append("§5.7缺少精确格式 X.X%")

    return issues

# 批量校验
for ch in range(START_CHAPTER, END_CHAPTER + 1):
    ch_str = f"{ch:03d}"
    report = os.path.join(OUTPUT_DIR, f"{ch_str}_*_V34_分析报告.md")
    emotion = os.path.join(EMOTION_DIR, f"{ch_str}_emotion.json")

    # Glob 匹配报告文件
    import glob
    reports = glob.glob(report)
    if not reports:
        print(f"❌ 第{ch}章: 报告文件不存在")
        continue

    issues = validate_report(reports[0], emotion, EVENT_DENSITY)
    if issues:
        print(f"⚠️ 第{ch}章: {'; '.join(issues)}")
    else:
        print(f"✅ 第{ch}章: 校验通过")
```

### 情绪JSON格式校验

```python
def validate_emotion_json(json_path, taxonomy="dutir", labels=None, pos_field="hownet_pos_pct", neg_field="hownet_neg_pct"):
    """校验emotion.json字段完整性（分类体系无关）"""
    with open(json_path, 'r', encoding='utf-8') as f:
        data = json.load(f)

    if labels is None:
        labels = ['好','乐','哀','怒','惧','恶','惊']  # 默认DUTIR

    issues = []

    # 必填字段
    required = ['chapter', f'{taxonomy}_total', f'{taxonomy}_pos', f'{taxonomy}_neg', f'{taxonomy}_neu', 'top_words']
    for field in required:
        if field not in data:
            issues.append(f"缺失字段: {field}")

    # 极性字段
    if pos_field not in data:
        issues.append(f"缺失极性字段: {pos_field}")
    if neg_field not in data:
        issues.append(f"缺失极性字段: {neg_field}")

    # 各类别子字段
    for label in labels:
        key = f'{taxonomy}_{label}'
        if key in data:
            for sub in ['count', 'pct', 'words']:
                if sub not in data[key]:
                    issues.append(f"{key}缺失子字段: {sub}")
        else:
            issues.append(f"缺失类别: {key}")

    # top_words 格式
    if 'top_words' in data:
        if not isinstance(data['top_words'], list):
            issues.append("top_words应为数组")
        elif len(data['top_words']) < 10:
            issues.append(f"top_words不足10条 (实际{len(data['top_words'])})")

    return issues

# 使用示例
# DUTIR-7:  validate_emotion_json(path, "dutir", ['好','乐','哀','怒','惧','恶','惊'], "hownet_pos_pct", "hownet_neg_pct")
# VADER-3:  validate_emotion_json(path, "vader", ['positive','negative','neutral'], "vader_compound", "vader_neg_pct")
# Plutchik-8: validate_emotion_json(path, "plutchik", ['joy','trust','fear','surprise','sadness','disgust','anger','anticipation'], "nrc_pos_pct", "nrc_neg_pct")
```

## 十四、增量处理机制

```python
import os, glob

def get_pending_chapters(output_dir, emotion_dir, start, end, version_tag="V34"):
    """获取待处理章节列表（跳过已存在且非空的报告）"""
    pending = []
    for ch in range(start, end + 1):
        ch_str = f"{ch:03d}"
        # 检查报告是否已存在且非空
        pattern = os.path.join(output_dir, f"{ch_str}_*_{version_tag}_分析报告.md")
        existing = glob.glob(pattern)
        if existing and os.path.getsize(existing[0]) > 1000:
            # 报告已存在且>1KB，跳过
            continue
        # 检查情绪JSON是否存在
        emotion_path = os.path.join(emotion_dir, f"{ch_str}_emotion.json")
        if not os.path.exists(emotion_path):
            print(f"⚠️ 第{ch}章: 情绪JSON不存在，跳过")
            continue
        pending.append(ch)
    return pending

# 使用
pending = get_pending_chapters(OUTPUT_DIR, EMOTION_DIR, START_CHAPTER, END_CHAPTER)
print(f"待处理: {len(pending)}章 → {pending}")
# 输出示例: 待处理: 27章 → [1, 2, 3, ..., 27]
```
