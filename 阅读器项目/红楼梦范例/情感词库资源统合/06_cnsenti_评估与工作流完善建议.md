## 一、仓库概览

cnsenti 是一个 Python 中文情感分析库，可对文本进行**正负情感分析**和**情绪分析（7大类）**。默认使用知网 Hownet 词典做极性分析，使用大连理工大学情感本体库做细粒度情绪分析。

**核心定位**：开箱即用的中文情感分析工具包，封装了词典 + 计算逻辑，pip install 即可使用。

---

## 二、核心功能

### 2.1 功能模块

| 模块 | 文件 | 功能 | 使用词典 |
|------|------|------|---------|
| Sentiment | sentiment.py | 正负情感词计数 + 情感值计算 | 知网Hownet（默认）/ 自定义词典 |
| Emotion | emotion.py | 7大类情绪词分布统计 | 大连理工大学情感本体库（DUTIR） |

### 2.2 Sentiment 类 — 正负情感分析

**默认词典**：知网 Hownet 褒贬义词典

**功能**：
- 统计文本中正面词数量、负面词数量
- 计算情感值（正面词数 - 负面词数）
- 支持导入自定义正面/负面词典（txt格式）
- 支持程度副词加权（adj_adv参数）

**使用示例**：
```python
from cnsenti import Sentiment

senti = Sentiment()
result = senti.sentiment_count('我好开心啊，非常非常非常高兴！')
# 返回: {'pos': 3, 'neg': 0, 'pos_word': ['开心', '高兴', ...], 'neg_word': []}

# 支持自定义词典
senti = Sentiment(pos='正面词.txt', neg='负面词.txt')
```

### 2.3 Emotion 类 — 情绪分析（7大类）

**默认词典**：大连理工大学情感本体库（DUTIR）

**功能**：
- 统计文本中7大类情绪词的分布
- 7大类：好、乐、哀、怒、惧、恶、惊
- 返回各类情绪词数量及具体词列表

**使用示例**：
```python
from cnsenti import Emotion

emotion = Emotion()
result = emotion.emotion_count('我好开心啊，今天真的很快乐！')
# 返回: 
# {
#   '好': 0, '乐': 2, '哀': 0, '怒': 0,
#   '惧': 0, '恶': 0, '惊': 0,
#   '好_word': [], '乐_word': ['开心', '快乐'], ...
# }
```

## 四、技术特点

### 4.1 优点

| 特点 | 说明 |
|------|------|
| 开箱即用 | `pip install cnsenti` 即可使用，无需额外配置 |
| 双模式 | 支持极性分析（正/负）+ 细粒度情绪分析（7大类） |
| 自定义词典 | 支持导入自定义txt格式的正面/负面词典 |
| 词典封装 | 内置Hownet + DUTIR两大权威词典，开箱即用 |
| Python库 | 纯Python实现，易于集成到现有项目 |
| 结果详细 | 返回词数量 + 具体匹配词列表，便于验证 |

### 4.2 局限

| 局限 | 说明 |
|------|------|
| ⚠️ 停止维护 | 已并入cntext，不再单独更新 |
| 基于词匹配 | 纯词典匹配，不考虑语义/上下文 |
| 无否定词处理 | 未内置否定翻转逻辑（如"不开心"=负面） |
| 无程度副词处理 | sentiment.py程度副词支持不完善 |
| 词典较旧 | Hownet和DUTIR版本较老（2020年入库） |
| 分词依赖 | 需要先分词，但未内置分词工具 |

## 六、工作流完善建议

### 6.1 当前工作流回顾

当前红楼梦情感分析工作流：
```
原文 → 分词 → 情感词匹配（正/负/中） → 否定翻转 → 递进加权 → 情感统计
                ↑
         基础/否定词.txt
         基础/递进词.txt
         基础/停用词库/
```

### 6.2 引入cnsenti思路后的完善方案

#### 方案一：增加7大类情绪分析维度（推荐）

在现有正/负/中三维统计基础上，增加7大类细粒度情绪分析：

```
原文 → 分词 → 情感词匹配 → 否定翻转 → 递进加权 → 极性统计（现有）
              ↓
         7类情绪词匹配 → 情绪分布统计（新增）
                          好/乐/哀/怒/惧/恶/惊
```

**实现步骤**：
1. 引入DUTIR 7分类词典（可从cnsenti或大工官网获取）
2. 增加`emotion_count()`函数，统计7类情绪词分布
3. 在分析报告中增加"情绪七维分布"章节
4. 可做逐章情绪变化趋势图

**对红楼梦分析的价值**：
- 超越简单正负面，深入分析人物情绪类型
- 可对比不同人物的情绪特征（如黛玉多哀，凤姐多怒）
- 可追踪全书情绪变化曲线（盛极而衰的情绪体现）

#### 方案二：补充Hownet词典扩大覆盖面

将Hownet词典与现有基础库合并，扩大情感词覆盖范围：

**实现步骤**：
1. 获取Hownet正面词/负面词文件
2. 与现有情感词做并集（去重）
3. 验证在红楼文本中的覆盖率提升

#### 方案三：参考cnsenti代码优化计算逻辑

cnsenti的sentiment.py和emotion.py中有可参考的计算逻辑：

**可借鉴点**：
- 词典加载方式（从txt文件读取到set）
- 词匹配算法（遍历 + 统计 + 返回匹配词列表）
- 自定义词典接口设计

## 八、结论

### 8.1 能不能参考使用？

**✅ 能，且有较高参考价值，主要体现在：**

1. **DUTIR 7大类情绪词典**：是最有价值的部分，可直接用于红楼梦细粒度情绪分析
2. **Hownet极性词典**：可补充现有情感词库，扩大覆盖面
3. **算法实现思路**：sentiment.py和emotion.py的代码逻辑可参考
4. **自定义词典设计**：支持自定义词典的接口设计值得借鉴

### 8.2 工作流能完善吗？

**✅ 能，完善空间很大，核心完善方向：**

1. **从3维到10维**：正/负/中（3维）→ 正/负/中 + 好/乐/哀/怒/惧/恶/惊（10维）
2. **从词数到分布**：单纯词数统计 → 情绪类别分布 + 强度分布
3. **从章节到人物**：章节级情感 → 人物级情绪画像
4. **从静态到动态**：单章分析 → 全书120回情绪变化曲线

### 8.3 注意事项

1. cnsenti 已停止维护，建议直接看 cntext
2. 纯词典匹配有局限，需结合否定词、程度副词等处理（项目已有这部分）
3. 红楼梦古白话文本的情感词覆盖率需要实测验证
4. 7类情绪分类与现有3维体系如何融合，需要设计好输出结构
