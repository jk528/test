## 三、情感词典分类体系

### 3.1 大连理工情感词汇本体分类（7大类）

| 情感大类 | 情感子类 | 说明 |
|---------|---------|------|
| 乐 | 快乐、安心、尊敬、赞扬、喜爱、祝愿 | 正面愉悦类情感 |
| 好 | 感动、感激、敬佩、思念 | 正面褒奖类情感 |
| 怒 | 愤怒、憎恶、妒忌、怀疑、责备 | 负面愤怒类情感 |
| 哀 | 悲伤、失望、内疚、思念、慌、恐惧、羞愧 | 负面悲伤类情感 |
| 惧 | 恐惧、羞愧、慌张 | 负面恐惧类情感 |
| 恶 | 憎恨、厌烦、讽刺、责备 | 负面厌恶类情感 |
| 惊 | 惊讶、惊奇 | 中性惊讶类情感 |

> 注：具体子类以原始词典为准，上述为常见分类框架。

### 3.2 极性分类体系（二分/三分）

| 分类方式 | 类别 | 说明 |
|---------|------|------|
| 二分法 | 正面 / 负面 | 最简单的极性分类 |
| 三分法 | 正面 / 中性 / 负面 | 增加中性类别 |
| 强度分级 | 极弱/弱/中/强/极强 | 情感强度量化 |

### 3.3 领域分类

| 领域 | 代表词典 | 适用场景 |
|------|---------|---------|
| 通用领域 | NTUSD、Hownet、清华褒贬义词典 | 通用文本情感分析 |
| 金融领域 | 姜富伟金融词典(2020)、姚加权金融词典(2021)、Davion股吧词典 | 金融文本、股吧、研报分析 |
| 学术领域 | 大连理工情感词汇本体 | 学术研究、情感计算 |
| 社交媒体 | BosonNLP情感词典 | 微博、评论等社交媒体文本 |

### 6.1 优先获取路径

| 需求 | 推荐仓库 | 理由 |
|------|---------|------|
| 通用情感词典最全 | ppzhenghua/SentimentAnalysisDictionary | 8类词典+234星+更新到2025 |

| 学术研究/7分类 | 大连理工情感词汇本体 | 学术权威+437引用+7大类情感 |

### 6.2 注意事项

1. **版权问题**：各词典仅供科研教学使用，商用需联系原作者
2. **编码问题**：中文词典可能存在GBK/UTF-8编码差异，使用时注意转换
3. **版本问题**：部分原始数据源已失效（如keenage.com、清华NLP旧站），建议从GitHub镜像获取
4. **分词配合**：情感词典需配合分词工具（jieba/NLPIR等）使用
