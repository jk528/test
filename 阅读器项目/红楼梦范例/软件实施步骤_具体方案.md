## S1 章节拆分引擎（M1）

### 目标与输入输出

| 项 | 内容 |
|---|---|
| 输入 | 整本 `红楼梦.txt`（或任意中文小说 TXT） |
| 输出 | `红楼梦_拆分/{章号:03d}_{字数}_{章名}.txt`，共 120 份 |
| 锁定口径 | 文件名 3 段式；段落以全角空格 U+3000 开头；末行 `(本章完)` |

### 选型

| 候选 | 能力 | 建议 |
|---|---|---|
| 自研 `re` 正则 | 完全可控、零依赖 | **首选**，既有规则即由此实现 |
| cn2an | 「第壹佰贰拾回」→「第120回」 | 推荐引入，解决章号排序 |
| chardet | 自动探测 UTF-8 / GBK / GB18030 | 推荐引入，解决导入乱码 |
| ebooklib | 解析 EPUB/MOBI | P2 扩展 |

- cn2an：https://github.com/Ailln/cn2an ｜ https://pypi.org/project/cn2an/
- chardet：https://github.com/chardet/chardet
- ebooklib：https://github.com/aerkalov/ebooklib

### 核心代码

```python
# split_chapters.py
import os, re, json
import chardet, cn2an
from config import ROOT, SPLIT_DIR

CHAP_RE = re.compile(
    r'^[　\s]*(第[零一二三四五六七八九十百千两壹贰叁肆伍陆柒捌玖拾0-9]+[回章节卷])'
    r'[　\s]*(?P<title>[^\n]{0,60})$', re.M)

def read_text(path):
    raw = open(path, 'rb').read()
    enc = chardet.detect(raw)['encoding'] or 'utf-8'
    return raw.decode(enc, errors='ignore')

def split_by_title(text):
    marks = list(CHAP_RE.finditer(text))
    if not marks: return []
    return [(m.group(0).strip(),
             text[m.start():(marks[i+1].start() if i+1 < len(marks) else len(text))].strip('\n'))
            for i, m in enumerate(marks)]

def normalize(body):
    body = body.replace('\r\n', '\n').replace('\r', '\n')
    lines = ['　' + ln.strip() for ln in body.split('\n') if ln.strip()]
    return '\n'.join(lines) + '\n(本章完)'

def chapter_no(title):
    m = re.match(r'^第([零一二三四五六七八九十百千两壹贰叁肆伍陆柒捌玖拾0-9]+)[回章节卷]', title)
    if not m: return 0
    s = m.group(1)
    try:    return int(cn2an.cn2an(s, 'smart'))
    except: return int(s) if s.isdigit() else 0

def run(src='红楼梦.txt'):
    text = read_text(os.path.join(ROOT, src))
    os.makedirs(SPLIT_DIR, exist_ok=True)
    manifest = []
    for title, body in split_by_title(text):
        no, body = chapter_no(title), normalize(body)
        name = f"{no:03d}_{len(body)}_{title}.txt"
        open(os.path.join(SPLIT_DIR, name), 'w', encoding='utf-8').write(body)
        manifest.append({"no": no, "title": title, "chars": len(body), "file": name})
    json.dump(manifest, open(os.path.join(ROOT, '拆分清单.json'), 'w', encoding='utf-8'),
              ensure_ascii=False, indent=2)
    print(f"✅ 共拆分 {len(manifest)} 章")

if __name__ == '__main__':
    run()
```

### 验收标准

- [ ] 产出正好 **120** 个 `.txt`
- [ ] 文件名匹配 `^\d{3}_\d+_.+\.txt$`，章号 001–120 连续无缺号
- [ ] 每章末行为 `(本章完)`，正文段首为全角空格
- [ ] 第 81 章应为 `081_06893_第81章　占旺相四美钓游鱼　奉严词两番入家塾.txt`

- 回目里的全角空格易被编辑器转半角，写文件时须显式用 `'\u3000'`
- 章名超 60 字符会被正则截断；Windows 路径长度上限需留意

| **jieba** | **首选**。纯 Python、MIT、`load_userdict` 可加载项目已有 663 行红楼梦词典、支持词性标注与关键词抽取；**120 份历史产物即由它产出，口径已锁定** |

| SnowNLP | 内置情感打分（自训语料非词典法），可作 M3 交叉参考，**不作主引擎** |

### 核心代码

```python
# tokenize.py —— jieba 分词引擎
import os, json, glob
from collections import Counter
import jieba
from config import SPLIT_DIR, TOKEN_DIR, TOKEN_TXT, SEG_DICT, STOP_FILES

# 1. 一次性初始化（务必在循环外，避免重复加载词典）
jieba.initialize()                    # 手动初始化，1~3 秒
jieba.load_userdict(SEG_DICT)         # 载入红楼梦专名/人名词典
# jieba.set_dictionary('data/dict.txt.big')   # 原文含繁体时切换大词典

# 2. 停用词（主表 + 停用词库 4 表并集）
def load_stopwords(paths):
    sw = set()
    for p in paths:
        if os.path.isfile(p):
            with open(p, 'r', encoding='utf-8') as f:
                sw.update(l.strip() for l in f if l.strip())
    return sw

STOPWORDS = load_stopwords(STOP_FILES)

# 3. 分词
def tokenize_text(text):
    words = [w.strip() for w in jieba.lcut(text, cut_all=False) if w.strip()]
    return [w for w in words if any('\u4e00' <= c <= '\u9fff' for c in w)]

# 4. 批量跑 120 章
def run():
    os.makedirs(TOKEN_DIR, exist_ok=True); os.makedirs(TOKEN_TXT, exist_ok=True)
    for path in sorted(glob.glob(os.path.join(SPLIT_DIR, '*.txt'))):
        ch = os.path.basename(path)[:3]
        words = tokenize_text(open(path, 'r', encoding='utf-8').read())

        json.dump(words, open(os.path.join(TOKEN_DIR, f'{ch}.json'), 'w', encoding='utf-8'),
                  ensure_ascii=False)                                    # JSON（list[str]）
        open(os.path.join(TOKEN_TXT, f'{ch}.txt'), 'w', encoding='utf-8').write(' '.join(words))

        top = Counter(w for w in words if w not in STOPWORDS).most_common(30)
        print(f'  {ch}: {len(words)}词   Top3={[w for w, _ in top[:3]]}')
    print('✅ 分词完成')

if __name__ == '__main__':
    run()
```

> **性能提示**：jieba 首次加载词典需 1–3 秒并生成缓存。服务常驻时应**进程内只初始化一次**；每次独立进程调用时请设置 `jieba.dt.tmp_dir` 到可写目录。

## S3 情感分析引擎（M3）

### 目标与输入输出

| 项 | 内容 |
|---|---|
| 输入 | `红楼梦_分词结果/{章号}.json` |
| 输出 | `情感分析结果/{章号}_emotion.json` |
| 字段 | `dutir_{好乐哀怒惧恶惊}`(count/pct/words)、`dutir_total/pos/neg/neu`、`hownet_pos/neg/pct/total`、`top_words`(30) |
| 引擎 | 直接复用 `基础/emotion_analysis.py`（EmotionAnalyzer + SentimentAnalyzer，零依赖） |

### 选型

| 方案 | 原理 | 建议 |
|---|---|---|
| **项目内置双引擎** | DUTIR 七类 + Hownet 极性 + 否定翻转 + 程度加权 | **首选主引擎**。已有 120 章产物、口径明确、返回具体匹配词、可解释 |
| cnsenti / cntext | 词典法，封装 Hownet + DUTIR | **词典来源**可借鉴；注意其**无否定翻转与程度加权**，本项目引擎更强 |
| SnowNLP | 自训语料情感打分 | P2 交叉参考，口径不同不宜混用 |
| BERT 类模型 | 预训练微调 | P2 远期；古白话微调成本高，且丧失词级可解释证据 |

**官方地址**

- cnsenti：https://github.com/hiDaDeng/cnsenti ｜ https://pypi.org/project/cnsenti/
- cntext（升级版）：https://github.com/hiDaDeng/cntext
- DUTIR 情感词汇本体：http://ir.dlut.edu.cn/info/1013/1142.htm

### 核心代码

```python
# emotion_pipeline.py —— 双轨情感统计
import os, sys, json, glob
from collections import Counter
from config import BASE_DIR, TOKEN_DIR, EMO_DIR, STOP_FILES
sys.path.insert(0, BASE_DIR)
from emotion_analysis import EmotionAnalyzer, SentimentAnalyzer

EMOTIONS = ['好', '乐', '哀', '怒', '惧', '恶', '惊']

def load_stopwords(paths):
    sw = set()
    for p in paths:
        if os.path.isfile(p):
            with open(p, 'r', encoding='utf-8') as f:
                sw.update(l.strip() for l in f if l.strip())
    return sw

def run():
    ea = EmotionAnalyzer(dict_dir=os.path.join(BASE_DIR, '情感词典_DUTIR'))
    sa = SentimentAnalyzer(dict_dir=os.path.join(BASE_DIR, '情感词典_Hownet'),
                           negation_file=os.path.join(BASE_DIR, '否定词.txt'),
                           degree_file=os.path.join(BASE_DIR, '递进词.txt'))
    stopwords = load_stopwords(STOP_FILES)
    os.makedirs(EMO_DIR, exist_ok=True)

    for path in sorted(glob.glob(os.path.join(TOKEN_DIR, '*.json'))):
        ch = os.path.basename(path)[:3]
        words = [w for w in json.load(open(path, 'r', encoding='utf-8'))
                 if w and w not in stopwords]

        emo, sent = ea.analyze_words(words), sa.analyze_words(words)
        wc, total = Counter(w for w in words if w), emo['total_emotion_words']

        out = {"chapter": ch}
        for e in EMOTIONS:
            c = emo['emotion_counts'].get(e, 0)
            out[f'dutir_{e}'] = {
                "count": c,
                "pct": round(c / total * 100, 1) if total else 0,
                "words": ', '.join(emo['emotion_words'].get(e, [])[:15]),
            }
        out.update({
            "dutir_total": total,
            "dutir_pos": emo['positive_emotion_count'],
            "dutir_neg": emo['negative_emotion_count'],
            "dutir_neu": emo['neutral_emotion_count'],
            "hownet_pos": sent['pos_count'], "hownet_neg": sent['neg_count'],
            "hownet_pos_pct": sent['pos_percentage'], "hownet_neg_pct": sent['neg_percentage'],
            "hownet_total": sent['total_sentiment_words'],
            "top_words": [{"word": w, "count": c} for w, c in wc.most_common(30)],
        })
        json.dump(out, open(os.path.join(EMO_DIR, f'{ch}_emotion.json'), 'w', encoding='utf-8'),
                  ensure_ascii=False, indent=2)
        print(f"  {ch}: total={total} pos={emo['positive_emotion_count']} neg={emo['negative_emotion_count']}")
    print('✅ 情绪 JSON 生成完成')

if __name__ == '__main__':
    run()
```

**算法口径（必须与既有报告一致）**

- 否定词：窗口 = 5，**奇数次翻转、偶数次还原**
- 程度副词权重：`very=2.0 / extreme=2.5 / more=1.5 / ish=0.75`；项目递进词表默认 `1.5`
- 一个词只归入一个情绪类别（`break` 提前跳出）

# analyze.py —— LLM 深度分析调度器
import os, glob, json, time
from jinja2 import Template
from openai import OpenAI
from config import SPLIT_DIR, EMO_DIR, REPORT_DIR

client = OpenAI(api_key=os.getenv("LLM_API_KEY", "sk-local"),
                base_url=os.getenv("LLM_BASE_URL", "https://api.openai.com/v1"))
MODEL = os.getenv("LLM_MODEL", "gpt-4o-mini")

# 1. 提示词模板：由 V3.4 任务说明书 + 空白模板合成
PROMPT = Template("""你是《红楼梦》文本分析专家。请严格按「双轨六要素 V3.4」九大模块，
为第{{ no }}章（{{ title }}，{{ chars }} 字）生成分析报告。

【硬性规则】
1. 事件数下限 ≥ {{ chars // 500 }} 件；事件 ID 规则 E{{ no }}-{序号}；分级 ★/◆/◇。
2. §五 情感数据必须直接引用下方 JSON，不得自行估算。
3. §六 人物出场须标注段落索引。
4. 输出格式：先输出 ```json 结构化块（见 SCHEMA），再输出完整 Markdown 报告。

【本章情绪数据 JSON】
{{ emotion_json }}

【结构化输出 SCHEMA】
{"chapter":int,"events":[{"id":str,"level":str,"summary":str,"para":int}],
 "persons":[{"name":str,"level":str,"para":int}],
 "emotion":{"tone":str,"dutir":{"好":int,"乐":int,"哀":int,"怒":int,"惧":int,"恶":int,"惊":int}},
 "foreshadows":[...],"conflicts":int}

【本章原文】
{{ text }}""")

# 2. 断点续跑：已生成且体积达标则跳过
def pending(range_=(1, 120)):
    todo = []
    for ch in range(range_[0], range_[1] + 1):
        hits = glob.glob(os.path.join(REPORT_DIR, f'{ch:03d}_*_V3.5_分析报告.md'))
        if hits and os.path.getsize(hits[0]) > 1000:
            continue
        if not os.path.exists(os.path.join(EMO_DIR, f'{ch:03d}_emotion.json')):
            print(f'⚠️ 第{ch}章: 情绪 JSON 不存在，跳过'); continue
        todo.append(ch)
    return todo

# 3. 单章分析
def analyze_one(no):
    ch = f'{no:03d}'
    src = glob.glob(os.path.join(SPLIT_DIR, f'{ch}_*.txt'))[0]
    text = open(src, 'r', encoding='utf-8').read()
    title = os.path.basename(src).split('_', 2)[2].replace('.txt', '')
    emo = open(os.path.join(EMO_DIR, f'{ch}_emotion.json'), 'r', encoding='utf-8').read()

    prompt = PROMPT.render(no=no, title=title, chars=len(text),
                           emotion_json=emo, text=text)
    for attempt in range(3):                                   # 失败重试 3 次
        try:
            resp = client.chat.completions.create(
                model=MODEL, temperature=0.2, max_tokens=8000,
                messages=[{"role": "user", "content": prompt}])
            out = os.path.join(REPORT_DIR, f'{ch}_{title.split("　")[0]}_V3.5_分析报告.md')
            open(out, 'w', encoding='utf-8').write(resp.choices[0].message.content)
            return True
        except Exception as e:
            print(f'  第{no}章 第{attempt+1}次失败: {e}')
            time.sleep(2 ** attempt)                            # 指数退避
    return False

if __name__ == '__main__':
    todo = pending((1, 120))
    print(f'待处理 {len(todo)} 章')
    for no in todo:
        print(f'  第{no}章 {"✅" if analyze_one(no) else "❌"}')
```

# events.py —— 事件表构建与合规校验
from collections import Counter

def parse_events(structured):
    return [{
        'event_id': ev['id'], 'chapter': structured['chapter'],
        'level': ev['level'], 'summary': ev['summary'],
        'para': ev.get('para'), 'five_w_one_h': ev.get('5w1h', {}),
    } for ev in structured.get('events', [])]

def check_events(rows, chars):
    low, problems = chars // 500, []
    if len(rows) < low: problems.append(f'事件数 {len(rows)} < 下限 {low}')
    if any(r['para'] is None for r in rows): problems.append('存在缺少段落索引的事件')
    dist = Counter(r['level'] for r in rows)
    if not dist: problems.append('事件分级为空')
    return {'count': len(rows), 'lower_bound': low,
            'level_dist': dict(dist), 'problems': problems}
```

```python
# persons.py —— 共现网络 + 关系图导出
import itertools
import networkx as nx
from pyvis.network import Network

def build_graph(chapter_persons, alias=None):
    """chapter_persons: {章号: [人物, ...]}；同章共现即连边"""
    alias = alias or {}
    G = nx.Graph()
    for ch, names in chapter_persons.items():
        std = sorted({alias.get(n, n) for n in names})
        for a, b in itertools.combinations(std, 2):
            if G.has_edge(a, b):
                G[a][b]['weight'] += 1; G[a][b]['chapters'].append(ch)
            else:
                G.add_edge(a, b, weight=1, chapters=[ch])
    return G

def key_metrics(G):
    return {'degree': dict(nx.degree_centrality(G)),
            'between': dict(nx.betweenness_centrality(G))}

def export_html(G, path='人物关系图.html'):
    net = Network(height='720px', width='100%', bgcolor='#ffffff', font_color='#1f2d3d')
    for n in G.nodes:
        net.add_node(n, label=n, size=10 + 2 * G.degree(n))
    for a, b, d in G.edges(data=True):
        net.add_edge(a, b, value=d['weight'], title=f"共现 {d['weight']} 次")
    net.show(path, notebook=False)
```
